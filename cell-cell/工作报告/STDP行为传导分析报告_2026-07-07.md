# STDP→行为传导失效分析报告

**日期**：2026-07-07  
**范围**：T-062 ~ T-070 + 架构讨论  
**核心问题**：STDP权重分化真实存在，但无法传导至行为输出

---

## 一、已确认的事实

### 1.1 STDP权重分化是真实的

AG平台五种子统计（T-060综合报告）：

| 指标 | 值 | 结论 |
|------|-----|------|
| w_ccw 最终 | 0.2994（五次完全相同） | STDP确定性，非随机 |
| w_cw 最终 | 0.0029（五次完全相同） | 方向性一致 |
| \|Δw\| | 0.2965 | 权重变化幅度显著 |
| DR5% | 50.0% ± 0.1% | 随机基线，无行为效应 |

**结论1**：STDP在`d1_phasic→spinal`束上的权重分化真实、确定、可复现。  
**结论2**：这个权重变化对DR5（方向正确率）无任何可测量的影响。

### 1.2 Foraging窗口过短（T-062/T-067实测）

```
fill轨迹（T-062, 200k步）：
  0~35k步：fill 0.30→1.00（Foraging窗口，STDP活跃）
  35k~200k步：fill≈1.00（STDP冻结，占总时间82.5%）

fill轨迹（T-067, 200k步）：
  ~35k步fill饱和后，4条竞争束均以相同速率衰减至零
  正确束vs反接束：Δw(20k)=+0.0035 → Δw(100k)=+0.0000
```

**结论3**：单次Foraging窗口太短，STDP无法在其中完成稳定的方向选择。

## 二、调参实验：T-070

### 2.1 调参目标与设计

基于"Foraging窗口太短"的诊断，尝试通过参数调整延长STDP活跃期：

| 参数 | 原值 | 新值 | 预期效果 |
|------|------|------|---------|
| BMR（基础代谢率） | 0.0025/步 | 0.003/步 | fill下降更快→更多Foraging时间 |
| VitalOsc amplitude | 0.005 | 0.003 | body更稳定→减少无效游走 |

### 2.2 T-070实验结果

**配置**：单热源[70,50,25]，body[10,50,25]，fill₀=0.3，50k步

| 步数 | η% | fill | dist | DA |
|------|-----|------|------|-----|
| 10k | 88.3% | 0.523 | 53.3 | 1.000 |
| 20k | 94.1% | 0.799 | 22.3 | 1.000 |
| 30k | 68.6% | **1.000** | 20.6 | 1.000 |
| 40k | 51.5% | 1.000 | 21.9 | 1.000 |
| **预测50k** | **~41%** | 1.000 | — | — |

**表面看η=41%很高，实际是测量陷阱**：

η仅来自步骤0~25k（fill从0.3爬升至1.0的"单次填充阶段"），之后fill饱和不再计入。  
在200k步实验中，这41%会摊薄为：20,580步 / 200,000步 = **10.3%**——比T-062的13.4%更低。

### 2.3 VitalOsc降低的反效果

**发现**：降低VitalOsc amplitude恰好破坏了cycling机制。

```
VitalOsc=0.005（原）：body随机游走步幅大→偶尔漂出热源半径(>30)→
                      fill短暂下降→Foraging窗口重新开放
VitalOsc=0.003（新）：body步幅小→牢固粘在热源旁→fill持续=1.0→
                      STDP持续冻结→cycling更少
```

VitalOsc承担双重功能：**初始探索**（寻找热源）+ **自然离源**（创造cycling条件）。降低它对两者均有损害。BMR提升(0.003)只有在body离开热源时才有效，而VitalOsc降低减少了body离源的概率。

**操作结果**：VitalOsc已撤回至0.005，BMR保留0.003（commit 86057a4）。

### 2.4 参数调整的根本局限

本次实验揭示了参数空间内调整的天花板：

> 调整参数改变的是**现有行为的速率**，不改变**行为的种类**。

fill cycling机制本身的逻辑决定了：只要摄食速率 > BMR，fill就会趋向饱和。要延长Foraging窗口，要么降低摄食效率（饿更久），要么增加BMR超过摄食速率（持续饥饿）。这两者都会影响生存稳定性，且不解决STDP→行为传导断路的根本原因。

## 三、断路的本质：信号模式太少

### 3.1 当前系统的宏观状态空间

实验表明系统实际上只有两种稳定宏观状态：

```
状态A：觅食态（fill < 0.85, DA > 0.1）
  - STDP活跃，权重分化
  - 行为：向热源方向运动（硬连线反射弧主导）
  - 持续时间：~25k步（单次）

状态B：饱腹态（fill ≈ 1.0）
  - STDP冻结（DA→LTP门关闭）
  - 行为：在热源附近随机振荡
  - 持续时间：~175k步（主体）
```

STDP能学习的信号模式上限由这两个状态的**切换频率**决定，不是由环境的实际丰度决定。

### 3.2 耦合的机械性：缺少弹性领地带宽

当前每个耦合点是瞬时响应，没有自己的时间积分窗口：

| 耦合 | 当前实现 | 问题 |
|------|---------|------|
| DA → STDP | `ltp = eligibility × DA(t)`，点采样 | DA此刻为0→LTP此刻为0，无缓冲 |
| fill → STDP门控 | `fill ≥ 0.85 → DA门关闭`，阶跃 | 二值切换，无过渡区 |
| fill → DA | `da_gate.step(fill_fraction, dt)`，实时 | fill=1.0→DA立刻衰减 |
| VitalOsc → Motor | 每步直接注入，无相位记忆 | 不构成周期性机会窗口 |

**已有弹性结构（部分对的地方）：**
- `eligibility_trace`：pre/post轨迹有衰减τ，这是正确的时间积分方向
- `EMA hunger`（τ=1000步）：慢积分，但只影响VitalOsc，不进入STDP
- RC膜时间常数：各神经元τ不同，天然提供时间尺度分离
- Ca²⁺动力学：HC层有真实的时间积分

**缺失的弹性结构：**
- DA信号的慢积分版本（STDP看到的应是"过去τ_slow步的DA趋势"而非"此刻DA"）
- fill→STDP的软门控（不是0/1阈值，而是平滑的调制函数）
- 各层之间的时间尺度分离（不同路径在不同时间尺度上竞争，而非所有路径瞬时同步）

### 3.3 "弹性领地带宽"的含义

这不是参数问题，是信号处理架构问题：

> 当前：STDP响应**此刻的DA值**
> 需要：STDP响应**一段时间内DA的时间积分**（慢特征）

类比：视觉皮层的方向柱不是响应"此刻的光子位置"，而是响应特定**时空模式**。每个突触应有自己的时间感受野，而不是瞬时采样器。

在fill→STDP门控上：
```
当前（硬门）：
  if fill ≥ 0.85: STDP_gain = 0
  else:           STDP_gain = 1

需要（软门）：
  DA_slow = EMA(DA, τ=5000)   ← 慢积分，不随fill瞬时归零
  STDP_gain = f(DA_slow)      ← 平滑调制
```

这样fill=1.0期间的短暂DA静默不会立刻冻结所有权重；fill再次下降时STDP从上次中断处继续，而非从零开始。

## 四、STDP→行为传导的断路位置

根据T-067（交叉接线）、T-066（镜像几何）和T-068拟设计的诊断，断路可能在：

```
phasic_left/right
    ↓ [D1束，STDP分化真实]
spinal_ccw/cw
    ↓ [spinal→yaw，w=0.020，frozen]         ← 可能断路B
yaw_ccw/yaw_cw
    ↓ [yaw→Motor，STDP]
Motor
    ↓ [gain=0.1，delay=2步]
行为
```

**最可能的断路B**（relay→yaw直接通路压过spinal→yaw）：

`relay→yaw`是硬连线反射弧，权重远大于`spinal→yaw`（w=0.020）。即使spinal权重被STDP分化，它对yaw的影响也远小于relay的直接驱动。行为由relay决定，STDP的分化在spinal层被淹没。

但这是**增益问题**（gain problem），不是信号模式问题。即使修复了断路B，如果STDP只能在25k步的单次Foraging窗口内工作，它学到的内容仍然不稳定（T-067验证：20k步Δ=+0.0035，到100k步Δ≈0）。

**断路B修复 + 信号模式问题共存**：两者都需要解决，但前者在现有架构内可尝试（提高spinal→yaw增益），后者需要架构层面的调整。

## 五、聚焦路径：如何在现有架构内推进

按照实验聚焦原则（当前阶段专注"STDP如何影响行为"），可行的最小修改：

### 路径A：修复断路B（增益校准）
**操作**：将`bundle_spinal_to_yaw`的`synapse_gain`从当前值提升至能与`relay→yaw`竞争的水平  
**代价**：可能引起yaw振荡（需实测）  
**验证**：T-071（断路诊断）先测量两路电流比，确定需要提升多少倍

### 路径B：在DA→STDP之间加慢积分
**操作**：在STDP的`learn()`里，用`DA_ema = EMA(DA, τ=5000)`替代点采样`DA(t)`  
**代价**：约10行代码改动，在`bundle.py`的`learn()`内  
**效果**：fill=1.0期间权重不再立刻冻结，Foraging窗口结束后学习还能惯性延续数千步  
**风险极低**：τ=5000仅影响STDP速率，不影响RC物理方程

### 路径C（AG报告建议，较大改动）
全连接方案（L→L, L→R, R→L, R→R），让STDP从四条通路中自然选择  
**代价**：需要设计新的四束结构，验证周期更长

## 六、结论

| 问题层次 | 诊断 | 当前状态 |
|---------|------|---------|
| 断路（增益） | relay→yaw压过spinal→yaw | T-071待验证 |
| 窗口（时长） | Foraging窗口仅13-17%，fill快速饱和 | 参数调整天花板已触及 |
| 信号模式（架构） | 只有2个宏观状态，DA→STDP瞬时耦合，无弹性 | 需在STDP路径上加慢积分 |

三个层次中，**路径B（慢积分DA）**改动最小、直接针对信号模式问题、且在现有架构约束内。它给STDP一个弹性的时间缓冲，让权重变化能跨越fill饱和期存活，不依赖cycling频率的提升。
