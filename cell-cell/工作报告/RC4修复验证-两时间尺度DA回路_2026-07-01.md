## 一、RC-4 根因回顾

| 症状 | 原因 |
|------|------|
| soma_to_da 权重 300k 步几乎不变（Δw < 0.003）| DA 是 tonic（恒定 0.24），post_trace ≈ 0 → STDP LTP ≈ 0 |
| 权重方向由 hash 初始化随机决定（非热梯度）| 全对全 soma_to_da（4 patch → 3 DA）：某侧升温时另侧降温，总输入恒定 |

**结构性缺陷**：`soma_to_da` 是全对全连接，4 个 relay 的热信号相互抵消，DA 无法感知体相对热源的方向运动。

---

## 二、实现方案：两时间尺度 relay 差减回路

### 生物依据

BIO: SA（slowly adapting）热感受器 WDR interneurons subtract background to encode temperature change rate  
REF: Duclaux & Kenshalo 1980; Morin & Bushnell 1998 Prog. Brain Res. 113:303

### 电路结构

```
relay (fast, τ=20k steps)  ──┐
                              ├─ soma_to_da (W+, excitatory) ──→ DA
slow_relay (slow, τ=300k) ──┤
                              └─ slow_to_da (W-, inhibitory) ──→ DA

Net DA ∝ relay.act - slow_relay.act = dT/dt 信号（phasic）
```

### 参数推导

| 参数 | 值 | 推导依据 |
|------|-----|---------|
| capacitance | 300.0 | τ = C × r_leak = 300 × 1.0 = 300 time units = 300k steps @ dt=0.001 |
| r_leak | 1.0 | V_ss = relay.act × 1.0（与 relay 激活幅度匹配）|
| inertia | 1.0 | 无放大：scaled_current = I_ext（避免溢出）|
| channel name | "pass_thru" | 非 "default" → 触发 multi-channel 模式：activation = vmem（线性）|
| gm | 0.001 | 接近零：减少反馈电流干扰（仅微量离子电流）|
| leak_conductance | 0.0 | 禁用 multi-channel 模式下的双重泄漏 |
| slow_to_da initial_weight | 0.5 | 与 soma_to_da 对称（差减实现基线抑制）|
| slow_to_da synapse_gain | -1.0 | 抑制性（减去热背景）|

### 关键技术细节

**Multi-channel 激活公式**（neuron.py 行 452）：
```python
self.activation = max(-10.0, min(10.0, vm))  # linear: activation = vmem
```
确认 slow_relay 传出的是膜电压（线性），而非 MOSFET 二次方公式。

**relay → slow_relay 传播**：relay 是非脉冲神经元，SynapticBundle.propagate() 使用 `src.activation`（非 pre_trace），因此 relay.activation = (vmem - v_th)² 正确传入 slow_relay。

## 四、机制分析

### 为什么 wR > wL 现在正确？

**Before RC-4（hash 初始化 + tonic DA）：**
```
hash init: wL=0.585 > wR=0.466（随机，偶然方向错）
STDP: post_trace(DA) ≈ 0 → LTP ≈ 0 → decay 主导 → weights 微弱下降
结果: 300k 步后 Δw < 0.003，hash 随机方向永远保留
```

**With RC-4（phasic DA）：**
```
初始权重从 0 开始（decay 压力为 0）
DA 从 0 → 0.23 快速上升 → post_trace 高峰
relay_right 比 relay_left 更快激活（src1 在右，右侧温度更高）
→ pre_trace_right > pre_trace_left
→ STDP: w_right 增长更快
→ 50k 步内权重方向确定并保持
```

### slow_relay 的时间动力学

```
τ_fast (relay)      = C × r_leak = 2.0 × 10 = 20k steps  ←→ 达到稳态
τ_slow (slow_relay) = C × r_leak = 300 × 1.0 = 300k steps ←→ 仍在充电

在 300k 步实验期间：
- fast relay: 迅速跟踪皮肤温度 T_skin
- slow relay: 缓慢充电，跟踪热背景 T_avg
- DA ∝ relay.act - slow_relay.act ≈ dT/dt（phasic 信号）
```

## 五、实现代码摘要

```python
# nexus_v1/circuit/variant_adapter.py :: _init_da_circuit()
# RC-4: Slow relay neurons — thermal derivative (phasic DA)
# BIO: SA WDR thermoreceptor background subtraction (Duclaux & Kenshalo 1980)
for pid in self.somatosensory.patch_ids:
    cfg_slow = NeuronConfig(
        neuron_id=f"slow_relay_{pid}",
        capacitance=300.0,   # τ_slow = C × r_leak = 300k steps
        r_leak=1.0,          # V_ss = relay.act × 1.0 (scale-matched)
        inertia=1.0,         # no amplification
        channels=[ChannelConfig(name="pass_thru", v_threshold=0.0, gm=0.001,
                                tau_gate=0.0, reversal=0.0, sign=1.0)],
        leak_conductance=0.0,
    )
    self._slow_relays[pid] = Neuron(cfg_slow)

# relay → slow_relay (frozen pass-through)
# slow_relay → DA (inhibitory baseline subtraction, frozen)
```
