## 背景：为什么从 TSS-2b 走到这里

TSS-2b 曾宣称 `Λ_support^(1)`（嵌套支撑范围的尺度生成算子资格）。复核后发现该
资格不成立：`Y_broad^cut` 切断 N_Δ 后与 `Y_local` 完全恒等（2.328029==2.328029），
说明 local/broad 只是同一求和算子在两张不同输入表上的读出，不存在"尺度专属
变换"。已提交降格修正（`1de8b9f`）：

- `LambdaScaleCircuit` 两组 bundle 改用 `physical_seed = 70000+site`，
  local/broad 对同一物理站点共享同一权重（此前用 bundle_id 派生扰动，站点
  在两个窗口里的权重不同，构成命名污染）
- 文档资格降格：`Λ_support^(1)` → `Λ_nested^(1)`（嵌套支撑集合的结构读出）
- 测试新增恒等断言 `|Y_broad^cut − Y_local| < 1e-9`，作为未来重新宣称尺度资格
  的守卫

评判随后要求：先审计一个"广域独有目标"（`N_Δ`）与源站点28之间的 `Θ`（时间先后）
关系能否成立，再决定是否建电路。

## TSS-3a：距离-延迟审计（已提交 `1a79fa6`）

### 与评判原始框架的两处分歧（已用实测数据坐实）

评判最初提议选站点12做 `28≺12`，理由是"12∈N_Δ 比已有近邻更有判别力"。复核
发现两个问题：

1. **N_LOCAL/N_BROAD 不是几何窗口，与距离不可分。** 实测站点坐标：
   ```
   N_LOCAL 最远站点 24：d=2.9742
   N_DELTA 最近站点 15：d=1.8222   ← 两集合在距离上重叠
   ```
   根因：`test_tss2a_scale_audit.py` 里 `N_LOCAL` = "radius=2.0下响应≥0.01的
   实测激活集合"，不是几何半径内的点集。
2. **Θ_28,X 读的是站点 collector，位于 Λ collector（读 N_LOCAL/N_BROAD）的
   上游。** 改变支撑窗口归属根本不影响 Θ 关系能否形成，评判提出的"实验区分"
   不存在。

### 审计结果（5组种子 × 5候选站点，跨进程可复现）

| 站点 | d(距28) | Δt 范围（5种子） | 判定 |
|---|---|---|---|
| 31 | 1.09 | 8~31 | 极差>Δt本身，方法伪影，判据在近距站点上失效 |
| 15 | 1.82 | 254~310 | 50≤Δt<600，可复用 slow 窗口 |
| **12** | **2.38** | **629~678** | **≥600，超出 T1 适用域** |
| 21 | 2.83 | 328~353 | 50≤Δt<600，可复用 slow 窗口，跨种子抖动最小 |
| 24 | 2.97 | 283~312 | 50≤Δt<600，可复用 slow 窗口 |

**真实发现（未钉死具体机制，冻结为观察结论）**：外部几何距离、HeatSource衰减
因子和内部collector发生延迟之间不存在已验证的单调关系——`site24`（d=2.97，
衰减因子仅0.01）onset 比 `site12`（d=2.38，衰减因子0.208）快一倍，且5组独立
种子下两者的 Δt 分布区间完全不重叠（无交集），不是偶然波动。评判据此裁定：
关系目标必须依据真实动力测量选择，不能只按距离/温度/集合归属推断。

同时定位了探针方法的边界：近距离链路（d~1.09）绝对延迟只有个位数到三十步，
落入~20~55步的跨种子抖动地板，"相对极差"判据在短延迟关系上不可信,仅适用于
远距站点。

### 选点裁定：21，不是12/24

评判最终选 `28≺21`：时间资格达标（同24），且21∈N_Δ，保留了未来做"局部支撑
内关系 vs 广域独有支撑关系"结构区分的可能性（**但本轮不做这个区分**，21∈N_Δ
不进入任何运行时判断）。

### 当前阻塞：T-T3-3 不产生 RelationOccurrence

两个父 occurrence 齐备，但 relation collector 从未越过阈值，`completed=0`。
10000步诊断实测：

```
collector_a_prec_d_slow.V 峰值 ≈ 0.09    (阈值 v_peak=0.23，差2.5×)
trace_a_slow.act          峰值 ≈ 0.07    (T1标定于d=1.09，本场景d=2.83信号更弱)
```

**根因（非DEG）**：T1 的 collector 权重常量（`_W_TRACE_TO_COLLECTOR=0.5`/
`_W_RAW_XI_TO_COLLECTOR=0.15`）标定于 d=1.09 场景，直接复用到 d=2.83 时驱动
强度不足以越过 AND 门阈值——这正是评判 Q3 事先提醒的"可复用作首轮结构先验，
不能直接宣称已标定"，实测证实了这一点。

**提出的修复（评判225958裁定：统一×2.5方案不批准，需先做三条件诊断）**

评判指出两个问题：
1. `0.09×2.5=0.225<0.23`，刚好不够（线性估计本身也达不到阈值）
2. 同时放大 trace 和 raw 两路可能让单路先越阈，破坏 AND 选择性

**三条件贡献诊断（EXP-T3-02，本轮已执行）**：

切断方式：对 `bundles_rprec3_to_collector` 里对应 bundle 令 `synapse_gain=0`。

```
V_both  = 0.10476   (trace + raw，正常运行)
V_trace = 0.02427   (只有 trace_a_slow → collector)
V_raw   = 0.08239   (只有 raw_xi_d → collector)
θ = 0.23
```

按评判公式计算可行区间：

```
lo = 1.1×0.23 / V_both  = 1.1×0.23 / 0.105 = 2.415
hi = 0.8×0.23 / max(V_trace,V_raw) = 0.8×0.23 / 0.082 = 2.233
```

**lo > hi，区间倒置，统一缩放不可行。**

根因：raw 通道比 trace 通道强 3.4×（0.082 vs 0.024）。统一放大时 raw 路会在
AND 门越阈之前已经单独越过 `0.8θ`，破坏选择性。

**独立缩放推导**（两路各自贡献约一半的 `1.1θ=0.253`）：

```
目标各路贡献 ≈ 0.127
s_trace = 0.127 / 0.02427 = 5.23  → 取 5.3
s_raw   = 0.127 / 0.08239 = 1.54  → 取 1.6

验证三约束（θ=0.23，裕量下限0.8θ=0.184，裕量上限1.1θ=0.253）：
  V_trace_scaled = 5.3×0.024 = 0.129 < 0.184 ✓ (单路不越阈)
  V_raw_scaled   = 1.6×0.082 = 0.132 < 0.184 ✓ (单路不越阈)
  V_both 估计    ≈ 0.261     > 0.253 ✓ (双路越阈, 线性估计)
```

拟定 T3 专属常量（T1/T2 不改）：

```python
_W_TRACE_TO_COLLECTOR_T3  = 2.65  # 0.5  × 5.3  # EXP-T3-02
_W_RAW_XI_TO_COLLECTOR_T3 = 0.24  # 0.15 × 1.6  # EXP-T3-02
```

`V_both=0.261` 是线性估计，需实测一次验证 collector 真正发火后回填 EXP-T3-02
注释，作为与实测闭合的参数溯源记录。评判225958 裁定区间不存在时"才分别调整
trace 与 raw 通道"——本方案完全符合该路径，待应用+实测+提交。
