## 一、涌现机制分类框架

本项目的机制分两类：
- **EP-xxx（Emergent Pathway）**: 真实通过 SynapticBundle+STDP 传导的信号路径

## 二、EP-xxx：真实涌现路径

### EP-001: 前庭 STDP 权重学习

**路径**: `afferent → enc → col → motor`（4 跳 SynapticBundle）

```
afferent_reg/irr (L3)
  │ [vest_to_enc_*, SynapticBundle, Memristor×Neuron]
encoding_{axis} (L4)
  │ [enc_to_col_*, SynapticBundle, Memristor×Neuron]
column_{axis} (L5)
  │ [col_to_motor_*, SynapticBundle, Memristor×Neuron]
motor_{xyz} (L6)
```

**真实涌现**: Memristor 电导随 STDP 规则（Bi & Poo 1998 LTP/LTD 窗口）更新。回归测试 21/21 PASS 中的 C1-C5 层信号深度测试验证了此路径确实传递信号。

**污染程度**: 前庭部分（非热觉）未被 HC-005/006 直接污染——但 HC-008（HairCell trace 覆盖）和 HC-002（全对全 soma_to_da 拓扑）影响其 DA 调制。信号传播本身（propagate）是真实的。

### EP-002: DA 三因子学习门控（部分有效）

**路径**: `shadow → DA → STDP_gating → bundle.learn()`

```
shadow_sandbox （Xin tension）
  │ [bundles_shadow_to_da, SynapticBundle]
da_neurons (DA 层)
  │ [DA 电压调制 bundle.plasticity_by_stage]
main bundles STDP update
```

**真实涌现**: DA 神经元通过 SynapticBundle 接收 shadow Xin 信号，DA 电压确实调制 STDP 的 plasticity_by_stage。RC-4 phasic DA 被验证可打破 tonic DA 的 STDP 对称死锁（Phase 3 实验：wR≠wL 出现，而旧 Phase 3 wR=wL 均锁定）。

**污染程度**: DA *来源* 被 HC-006（feed_alignment）和 HC-017（CPC 直接注入）污染；但 DA→STDP 的门控机制本身（SynapticBundle → DA 电压 → plasticity_by_stage）是真实结构。

### EP-003: Xin 残差累积与结构生长

**路径**: `bundle.compute_xin() → config.xin_tension → sprout/prune/mitosis`

```python
# bundle.py ~420-440
xi = abs(predicted - actual)
config.xin_tension += xi - config.xin_tension / XIN_LEAK_TAU
```

**真实涌现**: Xin 确实在 SynapticBundle 上以 |预测-实际| 累积，驱动结构生长（`_structural_growth()` 在 `xin_tension > XI_SPROUT` 时创建新 Bundle）。这是项目最核心的信息处理原理，代码路径完整。

**污染程度**: HC-019（activity_match 预筛选）阻止了部分 sprout，但不影响 Xin 累积本身。HC-007 导致 therm 轴 extra_to_enc 跳的 Xin 为零（无 Bundle），即热觉路径的 Xin 累积从起点就缺失。

### EP-004: ShadowSandbox 自由能计算（结构性，部分有效）

**路径**: `shadow_enc → shadow_col → shadow_mot（SynapticBundle 传播）→ 自由能 F`

```python
# shadow_sandbox.py
# 自由能 F = -log(P(activations)) 通过 shadow bundle 激活状态计算
K_ema = Σ weight × activation_product
F = -log(K_ema) if K_ema > 0
```

**真实涌现**: Shadow 层使用真实 SynapticBundle（col_shadow/mot_shadow），自由能通过权重矩阵和激活的物理乘积计算。K_ema 的增长/收缩确实反映 shadow 电路对 Xin 的结构响应。

**污染程度**: HC-011（mot_assignment 字符串匹配）固定了 shadow col→mot 拓扑；HC-021（abs(xi)）抹除 Xin 方向性；HC-035/037 有两个直接能量赋值路径（当前 disabled）。Shadow 自由能计算部分有效，但 shadow 运动分配不能学习。

### EP-005: VascularCooling 能量输送（物理，无污染）

**路径**: `World.heat_sources → proximity → EnergyStore → PowerRail → neuron.energy`

```python
# world.py, variant_adapter.py
proximity = 1.0 - d / r
deposit = CONSUME_RATE × proximity × dt
energy_store.fill += deposit
```

**真实涌现**: Body 接近热源→ proximity 增加→ EnergyStore.fill 增加→ PowerRail 电压更高→ 神经元能量充足→ 信号更强。这是真实的物理能量链，无 HC 污染。

**污染程度**: HC-029（MIN_ALIVE=2）保证始终有热源，减少了真正的生存压力；但能量输送机制本身干净。

### EP-006: 自适应 Memristor 权重（STDP 原语，无污染）

**路径**: `pre_spike → pre_trace → STDP_window × post_trace → Δw → Memristor.conductance`

**真实涌现**: Memristor 实现了真正的模拟记忆——电导随 STDP 规则连续更新，与生物突触可塑性同构。这是项目四原语中最干净的一个。

**污染程度**: HC-010（AGC）每步覆盖 STDP 结果，干扰 Memristor 学习效果；HC-008 在前庭路径用 Ca²⁺ 替换 STDP trace。但 Memristor 原语本身是纯净的，其他路径（如 soma_to_da Bundle）的 STDP 不受上述 HC 影响。

### EP-007: 神经元 AdEx 尖峰动力学（物理原语，无污染）

**路径**: `membrane.inject() → C×dV/dt = -V/R + I → v_peak → spike → STDP_trace`

**真实涌现**: 所有 Neuron 实例使用真实 RC 电路方程（非 Python if 模拟），b_adapt 产生真实自适应，v_reset 产生真实不应期。21/21 回归测试中的多层信号深度测试验证了尖峰动力学正常工作。

**污染程度**: HC-042（能量耗尽时强制 ×0.5）、HC-043（±10 钳位）是局部近似，但不破坏整体动力学。HC-013 导致 Motor 神经元缺少 bc_current 基线，使 Motor 层尖峰活动低于预期。

## 七、V2.0 后预期的真正涌现

移除全部 HC-CRITICAL 后，以下行为**可能**从结构中涌现（需实验验证）：

1. **方向性热趋性**: 当 patch-specific soma_to_da + transducer 换能束就位时，right patch 更热→ right-specific DA↑→ right side STDP LTP → wR > wL → motor_yaw_right 增强 → body 右转。这是完整的结构涌现链，每一步通过 SynapticBundle + STDP + Memristor 原语完成。

2. **能量依赖的行为切换**: PowerRail 在能量低时限流 → 神经元活动降低 → Xin 累积加速（信号弱→预测误差大）→ 结构生长加速 → 新束连接激活能量获取路径。

3. **Xin 驱动的电路自适应**: 当身体远离热源时，thermo_to_relay 束累积 Xin → sprout 在热觉→运动路径上形成新连接 → 热觉驱动运动的结构路径逐渐形成。

4. **DA 调制的学习速度控制**: 成功接近热源（前/后 patch 差异产生 feed_approach_relay 激活）→ DA 升高 → plasticity_by_stage 增大 → STDP 学习更快。失败（远离）→ DA 低 → 学习慢，保留当前结构。

这些机制在 V1 中因 HC-005/006/007/012 的存在而从未被测试。V2.0 的第一个实验应在所有 P0/P1/P2 修复完成后进行。

---

## 八、结论

1. **V1 不是失败的实验，而是未完成的脚手架**：信号链结构（EP-001～007, SM-001～017）基本完整，但被 Python 语义层（HC-005/006/007/012 等）短路。

2. **回归测试 21/21 PASS 仍有价值**：测试的是电路结构完整性，不是行为语义。V2.0 应保留并扩展这套测试，加入「热觉 Bundle STDP 验证」测试。

3. **V2.0 不是推倒重来**：根据三列表，约 70% 的代码（SynapticBundle、Neuron、物理原语、观测基础设施）直接保留；删除约 25 个代码块（行数约 150-200 行）；新建约 17 个 SynapticBundle + 若干 Neuron/ChannelConfig（行数约 300-400 行）。

4. **下一步（最小 P0 修复）**：删除 HC-005/006/018，修复 HC-013，重定义 DR5，运行回归测试验证结构不退化，然后用单热源 500k 步实验测量「真正的」热趋性起步状态（预计 DR5 将从 96% 跌至 ~50%，这才是真正的基线）。
