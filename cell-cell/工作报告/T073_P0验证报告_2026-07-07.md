## 四、异常观察：Motor 神经元全程 0 激活

```
motor_move_x     peak = 0.0000
motor_move_y     peak = 0.0000
motor_move_z     peak = 0.0000
```

Body 仍然在靠近热源（dist: 60 → 9.8），但 **Motor 神经元未参与**。

### 根因

`variant_adapter.py:1537-1539` 中存在热对流漂移（World 2.0 Boussinesq 近似）：

```python
_CONV_K = getattr(self, '_conv_k', 0.5)  # k_conv=0.5
_grad = self.world.gradient_at(self.world.body.position)
self.world.body.velocity[0] += _CONV_K * _grad[0] * dt
self.world.body.velocity[1] += _CONV_K * _grad[1] * dt
```

`k_conv=0.5` 将热梯度直接写入 body velocity，**完全绕过 Motor→Muscle→Body 链**。

### 影响评估

| 项目 | 评估 |
|:---|:---|
| T-073 权重保留测试 | **有效**——测试的是"权重在 fill 饱和后能否保留"，与 Motor 激活无关 |
| 历史行为实验（DR5%、热趋性）| **部分污染**——body 的接近运动包含两部分：对流漂移（被动）+ Motor 驱动（主动），目前主动部分 = 0 |
| T-074 必要性 | **确认**——muscle.gain 标定（及 Col→Motor 链路诊断）是行为闭环的前置必要条件 |

## 五、D1 束权重变化细节

P0 修复核心机制验证：

```
fill 饱和前：  LTP = E × DA_ema（DA_ema 从 0 渐增到 0.89）
               LTD = ltdRate × pre × post × DA_ema（同步）
               decay = 1e-6 × w（≈ 3e-7/步，可忽略）

fill 饱和后：  DA_ema ≈ 0.995（未下降，因 DA 维持 1.0）
               LTP ≈ LTD（平衡状态，权重冻结在 0.2994）
               decay = 1e-6 × 0.2994 ≈ 3e-7/步（175k 步才损失 5%）
```

P0 前（T-067 场景）：fill 饱和后 DA 降至 0，LTP=0，但 `decay_rate_by_stage[0]=0.025` 导致每步衰减 ~0.004，740 步后权重归零。P0 修复将 decay 降低 25,000 倍。

## 六、DA 全程 = 1.0 的原因分析

预期：fill 饱和（fill=1.0）后 DA 应下降（"饱腹 → 降 DA"）。  
实测：DA = 1.0 全程不变。

推测原因：DA 信号的主要驱动在本场景中来自**热源接近感**（thermo_delta 路径），而非饥饿状态。Body 全程保持在热源 10 units 以内，thermo_delta→relay→VTA 路径持续激活，使 DA 无法归零。

→ "fill 饱和后 DA 渐衰"场景需要**body 离开热源区域**才能触发，而本实验 body 通过对流漂移一直贴着热源。T-072（热源消失多周期）将能测试这个场景。
