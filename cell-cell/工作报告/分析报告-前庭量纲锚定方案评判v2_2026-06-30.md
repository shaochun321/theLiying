## 一、v2.0 / v1.1 的核心修正：评判

### 1.1 增益分类法则（v1.1 §3.2）——正确，且重要

这是两份文档中最有价值的修正。原先"所有增益都是无量纲纯数"的表述确实错误：

| 增益 | 正确量纲 | 物理含义 |
|------|---------|---------|
| g_MET | [A·s/rad] | 单位角速度产生的电流积分 |
| G_HC_Aff | [1/(V·s)] | 单位 HC 膜电位对应的发放率 |
| G_Aff_Enc | [V·s] | 单次发放贡献的 Enc 电位积分 |
| η_motor | [N/V] | 单位 Motor 膜电位产生的推力 |

这个分类给出了一个具体的可测量标准：**凡是跨物理量界面的转换（电压↔电流、发放率↔电压、电压↔力），增益必须携带量纲。** 凡是同量纲传递（V→V），增益才是纯数。

这直接解释了为什么当前参数难以独立验证——大量无量纲标注实际上掩盖了跨模态常数的物理含义。

### 1.2 量纲传递链（v1.1 §3.2.3）——基本正确，有一处技术细节

文档给出的完整链：
```
ω (rad/s) → [g_MET A·s/rad] → I_MET (A) → [G_HC, 无量纲] → I_HC (A)
→ [G_HC_Aff 1/(V·s)] → f_Aff (1/s) → [G_Aff_Enc V·s] → V_Enc (V)
→ [G_Enc_Col 无量纲] → ... → [η_motor N/V] → F (N)
```

量纲验证：
- ω × g_MET = [rad/s × A·s/rad] = A ✓
- I_HC × G_HC_Aff = [A × 1/(V·s)] = A/(V·s)... 不是 1/s

**这里有量纲错误**：G_HC_Aff 的输入应该是 HC 膜电位（V），不是电流（A）。如果 HC 输出是膜电位 V_HC：
- V_HC × G_HC_Aff = [V × 1/(V·s)] = [1/s] = spikes/s ✓

所以链条里 HC 层需要区分：电流增益 G_HC（A→A，无量纲）和随后的 V_HC 产生（I→V 通过 R_HC，单位 Ω），再到 G_HC_Aff（V→f，单位 1/(V·s)）。这比文档中写的更细，但不影响最终结论。

### 1.3 v2.0 §5.2 公式——缺少 R_Enc，单位不闭合

文档中写：
```
G_Aff_Enc = V_Enc,target / ( f_Aff × Q_spike × N_conv )
```

量纲验证：
- 分子：V
- 分母：(1/s) × C × 1 = C/s = A
- 结果：V/A = Ω

不是 [V·s]，而是 Ω。**缺少 R_Enc 在分母中**。正确公式是：

```
G_Aff_Enc [V·s] = V_Enc,target / ( f_Aff × N_conv )     ← 直接定义

synapse_gain [无量纲] = G_Aff_Enc / ( Q_spike × R_Enc )
                     = V_Enc,target / ( f_Aff × N_conv × Q_spike × R_Enc )
```

代入实际数值（代码中实测逻辑，以 hebbian.py:343-344 注释为准）：
```
V_ss = f_Aff × W × synapse_gain × dt × R_enc     [来自代码注释]
     = 2 × 2.5 × 16.0 × 0.001 × 5 = 0.40 V ✓
```

所以代码中的 `synapse_gain=16.0` 是**无量纲**的（它是 G_Aff_Enc 与 Q_spike × R_Enc 的比值），而文档中的 G_Aff_Enc [V·s] 是：
```
G_Aff_Enc = synapse_gain × W × dt × R_enc
           = 16.0 × 2.5 × 0.001 × 5.0 = 0.20 V·s（在 f_Aff=1 Hz 时产生 0.20 V steady-state）
```

这不是错误，而是文档的 G_Aff_Enc 与代码的 synapse_gain 之间差了一层 (W × dt × R_enc) 的转换。**v2.0 §5.2 的公式漏掉了这一层**。

### Phase 1：扫描实验（立即可执行）

**文件**：`nexus_v1/tests/exp_vest_calibration_scan.py`

**协议**：
- 隔离 VestibularChainV2，不启动 VariantCircuit 全系统

**输出**：

**关键约束**：零代码改动，纯测量。

### Phase 2：锚定计算（Phase 1 数据出来后，纯数学）

**使用修正后的公式**：
```
# 锚定假定（初始）：1.0 [无量纲 yaw 输入] = 1.0 deg/s
#
# 代码中 synapse_gain 的物理含义（基于 hebbian.py:343-344 注释）：
# V_ss = f_Aff × W × synapse_gain × dt × R_enc
# 所以 G_Aff_Enc [V·s] = synapse_gain × W × dt × R_enc
#                      = synapse_gain × 2.5 × 0.001 × 5.0
#
# 反推步骤：
# Step 1. 从扫描数据取 yaw=1.0 时的 f_reg_measured
# Step 2. 从文献取灵敏度 S = 1.0 spikes/s/deg/s（Lasker 2008）
# Step 3. 校验比 K = f_reg_measured / (1.0 deg/s × S)
#          K≈1 → 锚定假定自洽；K>>1 → 调整假定
# Step 4. 从锚定假定推导 G_MET_eff [A·s/rad]（经过 cupula 力学中间步）
# Step 5. 检查 G_MET_eff 是否对应 Fettiplace 2014 的 30-50 pS/nm 范围
```

**关键数值检查**（填扫描数据后执行）：

| 需要验证的量 | 公式 | 生物范围 | 通过标准 |
|------------|------|---------|---------|
| g_MET_eff | 从锚定角速度 + Steinhausen 模型 → I_MET / ω | 24–60 pS/nm | ±20% |
| 灵敏度一致性 | f_reg / (omega_phys × S) | ≈ 1.0 | 0.5–2.0 |
| 耳石通道交叉 | oto_x=6.0 的 m/s² 量级与 yaw 的 rad/s 量级之比 | 无量级跳变 | 无 >10× 差异 |

## 六、一处待澄清的技术细节

v2.0 §5.2 中 N_conv=10（"文献收敛比中值"）与代码实际 N_conv=2（每轴 1 reg + 1 irr Aff → 各一个 Enc）之间的差距：

| N_conv 假设 | 推导 synapse_gain | 说明 |
|------------|-----------------|------|
| N_conv=2（代码实际）| ≈ 12.0 | 用实际结构推导，最贴近现实 |
| N_conv=10（文献中值）| ≈ 2.4 | 反映"应该有的"生物收敛比，说明当前结构的 SNR 缺失 |

两个数字都有意义：12.0 是当前 N=2 架构的修正目标，2.4 是生物目标（N=10 的理论值，未来若扩充 Aff 数量时的参考）。Phase 2 计算时两个都给出，用 N_conv=2 的值（12.0）作为当前实验的参数候选。
