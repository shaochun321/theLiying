### 4. MOSFET 输出是 I 还是 G

**是电流 I**（`I = gm·(V−θ)`，阈下硬截零 DEG-019）。因此 P0-5 判为情况 A：
反馈电流直接由 conduct 给出，**PowerRail 不再乘进电流**——其职责限定为
供电记账（IR 压降、v_actual）与能源账本数据源。第二轮 `×V_rail` 的写法作废。

### 5. feedback 方程

```text
I_fb(V) = Σ_{n=1}^{N} MOSFET_n.conduct(V_read) = N·gm·max(0, V_read − θ)，N=3
V_{n+1} = min(V_c, λ·V_n + [I_fb(λV_n) + k_in·u]·dt/C)，λ = e^{−dt/(RC)}
```

N=3 是物理支路数（三个同型 FET 并联）。增益来源 = 支路数 × 器件真实 gm，
不再引用任何 DA 线路数值（P1-7 履行）。

### 6. input transduction 方程

输入 = 分级关系电流 c_ro（真实 C1 链路 E^↑→H_τ→C_Θ 产出，幅度实测 0.434031）。
换能：`ΔQ = k_in·c_ro·dt`，k_in=0.5（frozen 权重语义）。未插入 binary event
中转（候选消费的就是 graded current，无需 RelationEventAdapter 二次换能）。
