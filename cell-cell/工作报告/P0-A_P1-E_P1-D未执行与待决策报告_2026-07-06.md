## 二、P1-E DelayedBundle SPINAL→MAIN

**原始计划：** 给脊髓→主电路传导路径加入物理时延（模拟脊髓→脑干传导速度差异）。  
**当前状态：** ⏸ 暂缓，**前置条件未满足**。

**前置条件：** 神经元需要有物理坐标（position 属性），用于 D_REGION 审计（距离→延迟步数推导）。

**代码现状：**
```python
# Neuron 类目前没有 position 属性
# VestibularChain 中 DelayedBundle 已用于 HC→Aff（T-012），
# 但延迟是固定值（0.7ms Aα 传导），不依赖坐标
```

**实现 P1-E 需要的前置工作（未完成）：**
1. 给每个 Neuron 对象添加 `position: tuple[float,float,float]` 属性（需修改 NeuronConfig）
2. 基于区域标签（region=0x01 脊髓，0x02 脑干，...）推导标准传导距离
3. D_REGION 审计：验证不同路径延迟差 ≥ 2 步

**待决策（继承补充说明 Q2）：**
- **候选 A（推荐）：** 将现有 spinal_ccw→yaw_ccw + spinal_cw→yaw_cw 从 SynapticBundle 替换为 DelayedBundle（物理意义：脊髓→中脑传导延迟约 10-30ms）
- **候选 B：** 保留即时束，新增平行延迟束
- 但均需先建立坐标系，当前均不可执行

**推荐决策：** P1-E 整体推迟，不在当前实验序列中执行。可在 T-057 200k 验证通过后，作为独立工程任务立项。

**对当前测试（T-054~T-057）的影响：** 无。延迟模型缺失不影响权重学习的方向性，只影响时序精度。

### 3.2 P1-D Step2（稳态基线学习器）

**原始描述（补充说明）：** "稳态基线学习器（依赖 D1）"  
**核心含义：** CPC 的 `_cap_ref`（参考电容，当前 leak=R×100 极慢）目前是固定参考点（V=0.7 homeostatic setpoint 是硬设的）。Step2 要让 `_cap_ref` 随系统实际稳态动态更新，避免参考点与实际运行点偏离导致持续 DA 激活。

**代码现状（circulation_proportion.py:148）：**
```python
self._cap_ref.leak(R * 100, dt)   # 极慢衰减，V_ref 趋近某个缓慢均值
# 但 _cap_ref 从未被 inject()，它只靠缓慢 leak 趋零
# 实际 V_ref 可能长期 ≠ 设计中的 0.7
```

**三问评估：**

| 问题 | 状态 |
|------|------|
| Q1 生物对应物 | ✅ 下丘脑 set-point 的稳态学习（Cabanac 1971 调节点重置理论） |
| Q2 物理结构 | ✅ `_cap_ref` 接入当前 `rho_h` 的慢速积分 → Hebbian 更新 |
| Q3 参数依据 | ❌ 学习率未定（需要实测 V_ref 当前值及漂移速度）|

**Step1 取消后的影响：** Step2 的目标（让 V_ref 跟踪真实稳态）与 Step1（feed_alignment 修复）不直接耦合。Step2 可独立实施。

**但当前是否需要？** 从 T-036/T-044 结果看，fill 稳定（未归零，未饱和），DA 有脉冲响应，homeostatic 系统运行正常。`V_ref` 漂移如果存在，应该在 200k 步后才显现。

**建议：** T-057（200k 验证）后观察 `circ['deviation']`（DA 激活的稳态值）。若持续偏高（>0.3），说明 V_ref 偏离，再执行 Step2。当前不需要。

### 3.3 P1-D Step3（对数放大器）

**原始描述（补充说明）：** "技术难度高，单独立项，预估工时远超 7h"  
**含义：** 对 _cap_feed 的输入信号做对数压缩（Wide Dynamic Range 问题：摄食率从 0 到 1 有 2 个量级的动态范围，线性 CPC 无法同等响应两端）。

**三问评估：**

| 问题 | 状态 |
|------|------|
| Q1 生物对应物 | ✅ Weber-Fechner 定律（感觉强度∝log刺激）；孤束核的对数响应特性（Bhaskara 2011） |
| Q2 物理结构 | ❌ 对数函数无法直接用 Capacitor/MOSFET 原语表达；需引入新半导体原语或用指数衰减逼近 |
| Q3 参数依据 | ❌ 尚无实测动态范围数据 |

**结论：** Q2 无法回答，当前不可实施。属于远景任务，不纳入近期计划。
