## 1. 背景与动机

ν 框架来自 `nexus_v1/ledger/nu_framework_stub.py`，定义了 Xin 张力回路的"功率通量"诊断量：

```
ν(t) = ξ|O−P| − ξ²/R_ξ
```

**物理含义：**
- `ξ`：bundle 的 Xin 张力（预测残差的积分动量）
- `|O−P|`：单步预测残差（输出 vs 预测之差的绝对值）
- `R_ξ = 1000.0`：Xin 耗散时间常数（XIN_LEAK_TAU，bundle.py）
- `ν > 0`：充电态（误差注入 > 耗散）→ 探索期、可塑性开放
- `ν < 0`：放电态（耗散 > 误差注入）→ 巩固期、权重稳定

ν 探针是 V2.0 触发条件评估的关键量化工具。

---

## 2. 实现方案

### 2.1 |O−P| 的只读推算

bundle.py 中 Xin 更新公式：
```
ξ_new = ξ_old × exp(−dt/τ) + |O−P| × dt
```

反推 |O−P|（不修改 bundle，纯只读）：
```
|O−P|[t] = (ξ[t] − ξ[t−1] × exp(−dt/1000)) / dt
```

### 2.2 文件结构

```
nexus_v1/ledger/nu_probe.py     — NuProbe / NuSnapshot / NuReport
nexus_v1/ledger/__init__.py     — 注册导出
nexus_v1/tests/exp_nu_probe_smoke.py  — 5k 步烟雾测试
```

### 2.3 NuProbe API

```python
probe = NuProbe(ema_alpha=0.001)   # α=1/1000 → ~1000步平滑窗口

# 每步（circuit.step() 之后）调用
probe.update(circuit, step, dt=0.001)

# 每 N 步报告
report = probe.report(step)
print(probe.format_report(report, top_n=8))

# 属性
probe.system_nu_ema     # 全系统 ν EMA（所有 bundle 之和）
probe.charging_fraction  # 充电 bundle 占比
```

## 6. 已知限制

1. **慢时间尺度 EMA**：`ema_alpha=0.001` 在 5k 步窗口内 EMA 仍在积累（非稳态）。需要 >10k 步才能看到真实稳定值。
2. **|O−P| 近似精度**：一阶差分反推 |O−P| 在 dt=0.001 和 τ=1000 下精度极高（leak_factor ≈ 0.999999），可忽略。
3. **负 ξ 的处理**：部分 bundle（如 shadow_to_da）ξ 为负（这是合法的抑制性张力）。当前 ν 公式对负 ξ 照常计算，`ξ × |residual|` 会产生负的充电贡献——行为正确，待理论确认。
