## 一、P6：yaw vs pitch 权重分化根因分析

### 1.1 问题

P0 冻结扫描的 S1 基线 CSV 显示，6 轴的 met_to_hc 权重在 3000 步 WARMUP 后存在 ~32% 非同构：

| 轴 | 权重（WARMUP 后）| f_reg @ amp=6 |
|----|----------------|----------------|
| yaw | 0.5195 | 9.0 Hz |
| pitch | 0.5579 | 15.0 Hz |
| roll | 0.4415 | 14.5 Hz |
| oto_x | 0.5559 | 11.5 Hz |
| oto_y | 0.4155 | 23.5 Hz |
| oto_z | 0.3852 | 19.5 Hz |

"yaw 最弱 canal（斜率 1.21 Hz/unit）而 pitch 最强（2.25 Hz/unit）"的问题提出：两者参数完全相同，为何权重分化？

### 1.2 根因：哈希对称破缺机制

根因在 `nexus_v1/circuit/bundle.py:112-128`：

```python
# Symmetry breaking: each weight gets deterministic variation
# based on (bundle_id, source_idx, target_idx) hash.
# BIO: synaptic strengths are never perfectly uniform in vivo.
for i_s, _s in enumerate(sources):
    row = []
    for i_t, _t in enumerate(targets):
        seed = hash((config.bundle_id, i_s, i_t)) % 10000
        variation = (seed / 10000.0 - 0.5) * 0.5   # [-0.25, +0.25]
        w0 = config.initial_weight * (1.0 + variation)
```

**关键机制**：

1. 每个 bundle 按 `(bundle_id, src_idx, tgt_idx)` 的哈希值确定初始权重变体
2. `"met_to_hc_yaw"` 与 `"met_to_hc_pitch"` 的 bundle_id 不同 → 不同哈希 → 不同初始权重 w0
3. 变体范围：`initial_weight=0.5` × (1 ± 25%) → w0 ∈ [0.375, 0.625]
4. Python 的 `hash()` 受 PYTHONHASHSEED 影响（Python 3.3+ 默认随机化）→ **每次 Python 会话的初始权重分配都不同**

### 1.3 STDP 放大路径

初始权重差异经过 3000 步 WARMUP 后：

```
不同 hash → 不同 w0 → 不同 HC 驱动电流 → 不同 Ca 释放 → 不同 STDP 轨迹
→ 3000 步后：权重部分均值化但未完全收敛 → ~32% 残余非同构
```

3000 步 = 3 秒 = 6 个 2Hz 周期，对 STDP 完全收敛而言偏少。STDP 提供了部分均匀化压力，但不足以消除初始的 ±25% 差异。

**证据**：
- 初始理论范围：[0.375, 0.625]（±25% of 0.5）
- 实测 WARMUP 后范围：[0.385, 0.558]（略微压缩）
- STDP 确实起了均匀化作用，但不够充分

### 1.4 yaw 弱于 pitch 的本质

> **yaw 斜率 < pitch 斜率，不是 yaw 的生物学属性，而是本次 Python 会话的哈希种子给 yaw 分配了更低的初始权重。**

在另一个 Python 会话中，"最弱 canal"完全可能是 pitch 或 roll。

注意：P3 熵审计中 oto_y 权重 = 0.5942（World 仿真中最高），而 S1 CSV 中 oto_y 权重 = 0.4155（控制扫描中最低）。同一条链路，不同历史输入，权重完全不同——这进一步说明权重是输入历史的函数，不是"结构常数"。

### 1.5 结论

| 问题 | 答案 |
|------|------|
| yaw 为何比 pitch 弱？| 本次会话的哈希种子给 yaw 分配了更低初始权重 |
| 非同构是结构缺陷吗？| 否——这是有意设计的对称破缺（BIO:真实突触权重天然不均匀）|
| 需要修改代码吗？| 否——机制正确，STDP 均值化压力也正常工作 |
| 下次扫描还会是 yaw 最弱吗？| 不确定——取决于新的 PYTHONHASHSEED |

**建议（可选）**：如需可重复的 S1 快照，可在扫描脚本前设置 `PYTHONHASHSEED=42` 或使用固定随机种子初始化权重。目前不需要。

### 3.2 Shannon 公式来源疑问

文档 §7 给出 `C(N) = B × log₂(1+√N)`，无具体文献来源。  
标准 Shannon-Hartley 定理给出 C = B×log₂(1+SNR)，SNR∝√N 来自群体编码平均。  
该公式形式合理，但应标注来源（Zohary et al. 1994; Shadlen & Newsome 1998）。  
**对当前决策无影响**——规模泛化无论如何都不是当前计划。

### 3.3 P_S(N) = N² 假设

文档假设 P_S(N) ∝ N²，来自"Aff→Enc 收敛比为 N"。  
但实际上若采用 N:1 收敛（每 N 个 Aff 收敛到 1 个 Enc），连接数增长为 N，不是 N²。  
N² 成立的条件是全连接（每个 Aff 连接到每个 Enc），更符合 one-hot 激活假设。  
**需在设计时明确收敛拓扑**，但同样对当前决策无影响。
