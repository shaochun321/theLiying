## 文件1 的 2 处必改（进入阶段A的门票）

### 必改 1：废弃 Softmax，改为 WTA 自然输出

**当前（违规）：**
```python
P(a_i) = exp(V_dec_i / T) / sum_j(exp(V_dec_j / T))
```

**合规替代：**
- WTA 侧向抑制（已设计，`W_lateral = -0.5`）天然产生 winner-take-all
- 决策神经元的 `activation` 直接作为选择信号强度，无需归一化
- 低通滤波用 `Capacitor(r_leak=1/500)` 实现

**工作量：** 极小（删除 Softmax 层，Capacitor 低通本已存在类似实现）

---

### 必改 2：废弃 `||Δy - Δŷ||²` 范数，改为 Capacitor 误差积分

**当前（违规）：** Python 范数计算决定哪个方向获得偏置电流

**合规替代（物理电路）：**
```
误差电流 I_err = ŷ_d - y_actual
→ 流入"方向误差 Capacitor"（每方向一个，C=1, r_leak=1/200）
→ Capacitor 电压 V_err 越高 = 预测误差越大
→ MOSFET（Vth=某阈值，gm=0.5）将 V_err 转为抑制电流
→ 注入对应方向的决策神经元（误差大 → 更强抑制）
→ 误差最小的方向自然胜出（物理涌现，无 Python 选择）
```

**工作量：** 中（3个新 Capacitor + 3个 MOSFET + 3条抑制 SynapticBundle）

## 文件2 的重做路线图

不建议按当前文件2 的版本直接实施。建议以下重做框架：

### 重做版核心约束
1. **不动主分支**：所有验证在 ShadowSandbox 或独立 worktree 中进行
2. **用 Xin 替代互信息**：`Inefficiency = Energy_Consumed / Xin_contribution`（纯物理量）
3. **用 λ_metabolic 差异化替代 ORC 驱动删除**：拓扑重要的束设极低 λ，不重要的束用正常 λ 自然衰减
4. **ORC 仅作 INFRA 诊断**：类似 EntropyLedger，每 1000 步计算，只输出报告，不驱动决策

### 重做版最小可行实验（MVE）
在当前 ShadowSandbox 中添加 4 条全连接 phasic→spinal 束（与当前 2 条并行），初始权重 0.001，正常 STDP 学习，200k 步观察哪条束的权重自然长出：
- 如果 L→L / R→R（正确方向）权重增长 > L→R / R→L（错误方向）：✅ 涌现假设成立
- 如果随机涌现：❌ 需要更多的结构约束（距离依赖权重、初始相位偏置）

这个 MVE 不需要废除任何当前架构，仅在 Shadow 层添加 4 条观察束。
