## 一、修复背景

Phase 5 v2 实验（5/6 DR PASS）唯一失败项 DR3 的根因已由 Route A/B 探测定量确认：

| 指标 | 数值 |
|------|------|
| 神经网络 drain/步 | 3.24×10⁻³ 绝对单位 |
| 世界能量 deposit/步（原 rate=0.15）| 4.99×10⁻⁵ 绝对单位 |
| drain/deposit 比 | **65×** |

修复方案：`CONSUME_RATE = 9.75`（= 0.15 × 65），使 deposit 速率在 body 位于 d=20、r=30 时与 drain 精确平衡：

```
deposit/step = 9.75 × (1 - 20/30) × 0.001 = 9.75 × 0.333 × 0.001 ≈ 0.00325
drain/step                                                              ≈ 0.00324
```

## 五、关键发现分析

### 5.1 DR3 PASS：代谢修复完全有效

fill 从初始 0.500 缓降至最低 0.441（step 250k），之后**自然回升至 0.492（step 450k）**。这一回升不是偶然——它是物理机制正常运行的结果：

```
body 靠近热源 → 距离 d 缩小 → proximity = (1 - d/r) 增大
→ deposit/step = 9.75 × proximity × 0.001 上升
→ deposit > drain → fill 净增
```

这种**代谢-趋热耦合**是真正的物理涌现：body 不是被编程为"靠近热源补充能量"，而是因为靠近热源的物理结果自然产生了能量正反馈。生物类比：深海热液口生物（化能自养）靠近热液口获得更高能量通量。

### 5.2 DR5 大幅提升：94.77% vs 79.59%

v2 中 DR5=79.59% 的条件下，body 在 fill 耗尽（200k 步）后开始随机游走，拉低了 500k 步的整体对齐率。P6 P0 中 fill 从未耗尽，body 持续主动运动，DR5 从 79.59% 提升至 94.77%——证明 DR3 修复不仅解决了代谢问题，还间接改善了热趋向质量。

### 5.3 DR2 擦边 FAIL：+0.9636 vs 目标 1.0

Δx@200k = +0.9636 是 x 轴位移，差目标 3.6%。两点说明：

**（1）3D 接近量已超目标**：
- dist@200k = 19.120，从 20.000 减少 0.880 → 接近量接近阈值
- dist@250k = 18.683，减少 1.317 → 3D 接近量早已超过 1.0

**（2）x 轴位移低于 3D 位移的原因**：
body 在三维空间运动（vestibular 信号覆盖 yaw/pitch/roll + oto_x/y/z），而热源在纯 x 方向（[70,50,50]）。body 向热源方向的净移动在 y/z 方向也有分量，导致纯 x 轴数值低于 3D 总接近量。

实测：dist 从 20.000 减少 0.880 但 Δx=+0.9636，说明 body 净 y/z 位移约 1.87 units，方向分散化导致 x 轴的热源导向不如 3D 接近量表现准确。

DR2 指标本身是合理的（测量最终 x 轴导向），但对于 vestibular 多轴驱动的系统，单轴测量可能不如 3D 距离更能反映真实热趋向。

### 5.4 fill 恢复是系统动力学正常的证明

v2 实验中 fill 单调下降至 0，无法恢复。P6 P0 中 fill 先降后升，在 fill 最低点（250k）之后的 200k 步内回升了 0.051。这是一个**双向平衡点的动力学收敛**：body 距离 d* 使 deposit(d*)=drain 是一个吸引子，body 趋近该距离时 fill 稳定化。

## 八、Phase 6 P1 建议

**DR2 修复（差 3.6%）：**

DR2 标准为 Δx(200k) > 1.0。gap 极小，有两个修复路径：

| 方案 | 操作 | 风险 |
