Phase 4-C 实验暴露了一个反常现象：Noether 账本显示"无能量违规"，但 Motor 神经元被一个与学习完全无关的信号主导，STDP 权重在 200k 步内被清零。

## 问题一：DEVIATION_MOTOR_GAIN 主导 Motor 端（CRITICAL）

### 量化数据

| 信号来源 | 均值注入量 [V/step] | 占比 |
|---------|------------------|------|
| DEVIATION_MOTOR_GAIN | **117.73** | **99.996%** |
| VitalOscillator | 0.0003 | 0.0003% |
| STDP bundles→Motor | 0.0042 | 0.004% |

**比值：DEVIATION÷STDP = 27,733×。STDP 贡献 0.004% 的注入量。**

### 机制分析

`DEVIATION_MOTOR_GAIN = 1/dt = 1000`（dt=0.001，为常数）。当 `homeo_deviation > 0.1` 时，向所有 Motor 神经元注入 `(deviation - 0.1) × 1000` V/step。

关键发现：**此注入在 fill=0.69（健康能量）下全程 100% 激活**：
- 30k 步平均 fill = 0.689，最低 0.677（从未低于 0.5）
- deviation 平均 0.186，始终 > 0.1 阈值
- DEVIATION 激活比例 = **100.0%**

这说明 DEVIATION_MOTOR_GAIN 的触发条件不依赖能量危机，而是由 `homeo_deviation` 的基线值（0.186）决定。系统在代谢健康状态下也处于"紧急模式"。

### 对学习的影响

Motor 神经元的激活由 DEVIATION_MOTOR_GAIN 决定，与 STDP bundle 权重无关。STDP 更新机制需要：
1. 突触前激活 × 权重 → 突触后激活
2. 突触后激活 ↔ 期望激活 → Xin 张力 → STDP 更新

当突触后（Motor）激活被 27,733× 更强的外部注入覆盖后，STDP 更新仍然会发生，但它更新的方向是"如何预测 DEVIATION_MOTOR_GAIN 的输出"，而不是"如何让 Motor 实现有用行为"。

### Motor 饱和比例

| 神经元 | 饱和时间（act>0.95） |
|--------|---------------------|
| move_x_m10000 | **31.4%** ← WARNING |
| move_z | **28.1%** ← WARNING |
| move_z_m20000 | **28.2%** ← WARNING |
| move_x, move_y, move_y_m10000, move_x_m30000 | <1% |

## 问题二：5/6 前庭通道在 Column 层完全静默（STRUCTURAL）

### 量化数据

| 前庭轴 | Column 层均值激活 | 状态 |
|--------|----------------|------|
| yaw | 0.000000 | **SILENT — 不可达** |
| roll | 0.000000 | **SILENT — 不可达** |
| oto_x | 0.000000 | **SILENT — 不可达** |
| oto_y | 0.000000 | **SILENT — 不可达** |
| oto_z | 0.000000 | **SILENT — 不可达** |
| pitch | 0.003933 | minimal（最高达 1.0，但均值极低） |
| therm_front/back/left/right | 0.002-0.004 | minimal |

**5 个前庭通道（yaw/roll/oto_x/y/z）在 Column 层 max=0.0000，即一次都没有激活。**

### 为什么这是严重问题

项目定义的 6 层信号链：MET→HC→Aff→Enc→Col→Mot

- L4_Enc → L5_Col 相关系数 = **0.886**（高度相关，通路本身通畅）
- L5_Col 均值激活 = **0.0014**（信号内容接近零）

信号传输链在物理上是接通的，但传输的是近零信号。Column 层得到 Enc 层的信号，但 Enc 层的内容对这 5 个轴几乎为零。

### 信号链各层状态（30k 步均值）

```
L1_MET   act=0.0162  E=0.5055
L2_HC    act=0.1093  E=1.0000   ← HC 层激活（化学感应起效）
L3_Aff   act=0.0006  E=0.9614   ← Aff 层几乎静默！
L4_Enc   act=0.1074  E=0.9970   ← Enc 有信号（来源？）
L5_Col   act=0.0014  E=0.9997   ← Col 几乎静默
L6_Mot   act=0.2871  E=0.9763   ← Mot 有激活（来源=DEVIATION，不是 Col）
```

奇异点：L3_Aff (0.0006) ≈ 0，L4_Enc (0.1074) 却有信号。这意味着 Enc 的激活不来自 Aff 链，很可能来自热觉链的侧路（therm 通道绕过 Aff 直接到 Enc？）。

### Variant Contracts 验证

运行 `run_variant_contracts.py`：
```

G3 FAIL: Variant depth ≥ 6 (actual=4)
```

Variant circuit 6 层信号深度从未达到满贯，当前只有 4 层有意义激活。

## 问题三：KCL 违规 290/299 次（PHYSICS — 已检测但未上报）

### 量化数据

Noether 探针在 30,000 步中运行了 299 次检查：
- **kcl_charge 违规：290/299 次（97%）**
- 能量守恒平均误差：0.001250（< 0.1%，正常范围）
- 权重稳定性：0.00338397 drift/step

**重要**：Noether 探针 **早已在运行并检测到这个问题**，但从未打印输出！数据被存储在 `circuit._noether_probe` 中，只有显式调用 `print_report()` 才能看到。在正常 `circuit.step()` 中，这 290 次违规完全无声。

### KCL 违规的物理含义

KCL（基尔霍夫电流定律）：进入节点的电荷 = 流出节点的电荷 + 储存的电荷。违规意味着电荷在某处被无账本地创造或消灭。

最可能的原因：`membrane.inject()` 直接向电容注入电荷，不经过标准 Bundle 电荷跟踪机制。Noether 的 KCL 计算基于 `_q_in / _q_out` 字段，如果 inject() 只更新电压而不更新这些字段，就会有系统性的 KCL 失衡。

能量守恒误差 < 0.1%（正常），说明能量总量守恒，但电荷分配不符合 KCL。这是**结构层面的问题**，不是数值精度问题。

## 问题五：Variant Contracts 2/5 失败（INTEGRATION）

```
GATES: 2/5 PASSED
FAIL G1: Mother not degraded (depth=4, spk=116)
PASS G2: Variant ≥ Mother (depth 4≥4, mot 142≥38)
```

### 母本与变体的关键差异

| 指标 | Mother | Variant | 比例 |
|------|--------|---------|------|
| Motor 峰电位数 | 38 | 142 | Variant 3.7× 更多 |
| Motor 层能量 | 2.03 | **0.08** | Variant **25× 更低** |
| Col 层能量 | 5.01 | **3.10** | Variant 38% 能量损失 |
| 信号深度 | 4 | 4 | 无改善 |
| 最低能量 | 0.0235 | **0.0010** | Variant 22× 更低 |

**关键矛盾**：Variant 的 Motor 峰电位是 Mother 的 3.7 倍，但 Motor 层能量是 Mother 的 1/25。这说明：
- Variant 的 Motor 神经元频繁发放（DEVIATION_MOTOR_GAIN 驱动），但每次发放的能量极低
- Mother 的 Motor 神经元发放较少（Bundle 信号驱动），但每次发放的能量正常

这是"峰电位数量"与"峰电位质量"分离的直接证据。

## 小结

这 41 个异常分布在三个维度：

1. **信号量级失衡**（异常 01）：一个非 Bundle 注入点产生的效应比所有学习信号的总和大 27,733 倍。
2. **通路静默**（异常 02-06）：6 层信号链路本身是通的，但内容是零。L4→L5 相关系数 0.886，但 L5 激活均值 0.0014。
3. **预测质量崩溃**（异常 07-40）：58 个 Bundle 中 40 个 Xin 张力常态为负，意味着全局范围内目标激活远大于预测，体感层发散（3.28×超限）是主要驱动力。
