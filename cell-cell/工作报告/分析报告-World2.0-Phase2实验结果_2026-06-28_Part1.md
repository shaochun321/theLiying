## 3. 参数标定：k_conv 临界值发现

### 3.1 三次实验记录

| 实验版本 | k_conv | 100k 步时 dist_surface | 结果 |
|--------|--------|----------------------|------|
| Phase 2 v1 | 0.15 | ~28.98（从 22 增至 34） | FAIL：Langevin 压过漂移 |
| Phase 2 v2 | 0.40 | ~30.97（从 22 增至 31） | FAIL：仍被压制 |
| Phase 2 v3 | 0.50 | ~15.66（从 22 减至 16）| PASS：正常接近 |

### 3.2 根本原因分析

Langevin OU 噪声经由 OTOLITH_GAIN(500) 放大后注入前庭链，最终驱动运动神经元产生约 **0.054 units/step** 的随机外向速度。

对流漂移提供的内向速度：
```
v_conv = k_conv × |∇T| / μ
       = k_conv × 0.115 / 0.5   (at dist_surface≈22)
```

临界条件 `v_conv ≥ v_motor_noise`：
```
k_conv ≥ 0.054 / (0.115 / 0.5) = 0.054 × 0.5 / 0.115 ≈ 0.235
```

但实测 k_conv=0.40 时仍然失败（dist 从 22 增至 31），说明实际阈值更高，约为：
```
k_conv_threshold ≈ 0.47（实测 0.50 正常，0.40 失败）
```

**原因**：∇T 随距离变化，k_conv=0.40 时漂移随 dist 增加而减弱，进入"失控-衰减"循环（越远→漂移越弱→motor 噪声越占优→越远）。k_conv=0.50 提供的初始加速度足以打破此循环。

### 3.3 结论

**Phase 2 必须使用 k_conv=0.50（Phase 1 值）**。k_conv 降低存在存在相变：低于阈值时 body 永远无法接近热源，STDP 无学习机会（chicken-and-egg）。

Phase 2 的正确认知：
- 物理漂移把 body 带入接近区域（与 Phase 1 相同）
- STDP **在接近过程中**学习方向性权重
- 500k 步后权重比 w_front/w_brake 应超过 Phase 1 结束时的初始值
