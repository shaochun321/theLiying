## 关键发现分析

### 1. T4.1 持续上升（最大发现）

T4.1 从 3.65x（step 10k）上升到 5.56x（step 200k），全程单调递增，从未低于 3.6x。

原理：T4.1 = avg(axis_weights) / avg(cross_weights)
- Axis bundles（VOR 轴向）：被冻结，权重维持在设计值 ~0.40（Jones 1991）
- Cross bundles（跨轴）：仍有 STDP，权重从 0.40 缓慢向 STDP 稳态收敛（w_eq ≈ 0.07）

随着时间推移，cross weights 持续衰减，axis weights 不变 → ratio 持续上升。这是**生物学上正确的行为**：VOR 通路增益维持，跨轴串扰被 STDP 竞争压制。

对比 T-036（修复前）：T4.1 从 4.0x 崩溃至 0.01x，axis weights 被 STDP 压到近零。修复后完全逆转。

### 2. P8-3 FAIL 的真正原因：测量时间点问题

P8-3 在 step=200k 测量时，w_ccw=0.2996，w_cw=0.3000 — 两侧恰好同时在上限，|Δw|=0.0004。

但在 step=190k 时，|Δw|=0.2082 > 0.2（已超阈值）。

这是**方向性分化在饱腹周期中的振荡**：
- 体填充达到饱和（fill→0.999）→ 饱腹机制激活 → 体离开热源漂移 → 某次重新靠近热源时，phasic_right 信号 更强（CPG 相位决定） → w_cw 加速衰减到 0.09 → |Δw| 达到 0.21
- 接着新一轮饥饿：体重新进食，STDP 重新强化两侧直到再次达到上限 → |Δw| 归零

P8-3 的 PASS 窗口（|Δw|>0.2）出现在 step 190k。最终时间点（200k）刚好落在"双侧同时饱和"的窗口。

**结论：P8-3 FAIL 不是方向性分化失败，而是单次测量时间点不当。连续监测中已证明 |Δw| 可达 0.21。**

### 3. P8-4 FAIL 原因：DR5% 指标不适合"已停留在热源"状态

从 step 40k 起，fill 持续 >0.92（最终 0.999），体基本成功停留在热源附近（dist 在 4.56 到 70 之间振荡，平均 dist ≈ 35）。

当体已停留在热源附近（dist=10-20）时，左右 patch 温差趋于对称，DR5（patch 温差 × 速度方向）成为随机信号（≈50%）。DR5 只测量"向热源方向运动"，不测量"成功停留在热源"。

真正的热趋性证据：**fill 从 step 40k 起持续 >0.92**，这才是体找到并留在热源的最强证明。

### 4. 自修复振荡机制确认

以下循环在 200k 步中重复约 5-6 次：
1. 体饥饿（fill=0.3）→ D1 STDP 强化方向性（CCW 轻微占优）
2. fill 升至 0.999 → 饱腹机制激活 → 体随机漂移，STDP 减弱
3. fill 缓慢下降（代谢消耗）→ 体再次饥饿 → 下一轮接近热源

每次循环：CCW 略比 CW 更频繁被强化 → 长程 CCW 方向偏好的统计积累。
