## 1. D1 架构概述

D1（Phasic Relay Arc）是 mallow-dust-devil 分支的热觉方向学习弧，连接从热感受器到脊髓转向中间神经元：

```
relay_left → [frozen, τ=5000] → slow_relay_left (SA2 基线)
relay_left → [frozen, +W_P=0.02]  → phasic_left
slow_relay_left → [frozen, -W_P=0.02] → phasic_left   (KCL 差分 = dT/dt)
phasic_left → [STDP, DA-gated, elig_trace] → spinal_ccw
spinal_ccw → [frozen, w=0.002] → yaw_ccw_neuron
```

同理 right → spinal_cw → yaw_cw_neuron。

## 4. 关键发现

### 4.1 接近行为：显著改善

**DR5=100%** 在步骤 40k-120k（6万步连续完美接近）。旧基线在同期仅 50-86%。  
D1 的 phasic relay → spinal_ccw/cw → yaw 弧提供了正确的方向性热觉驱动。

### 4.2 到达时间提前

旧基线需要 ~140k 步才接近 d≈1.0；D1 系统在 120k 步时 d=0.4，在 140k 时 d=0.0（精确到热源中心）。  
加速到达的原因：D1 yaw 控制更精确，减少了偏向行为，使 k_conv × ∇T 的对流推力更有效。

### 4.3 接近阶段 yaw 控制

| 阶段 | d 范围 | yaw 范围 | 评估 |
|------|--------|----------|------|
| 主动接近 (20k-80k) | 17→7 | 1.33°→27.96° | ✅ < 30° 全程 |
| 近源 (80k-120k) | 7→0.4 | 27.96°→42.16° | ⚠️ 超过 30° 但方向正确 |
| 到达后 (120k-200k) | 0.4→0.0 | 42°→81° | ⚠️ 轨道漂移（见下） |

### 4.4 到达后 yaw 累积（待解问题）

到达热源后（step 120k-200k），yaw 持续从 42° 累积至 81°（~10°/20k步）。

**原因分析：**
- 到达后 body 在热源附近做轨道运动（VitalOscillator 驱动）
- 轨道运动产生温度变化（dT/dt ≠ 0）→ phasic 持续激活
- phasic → spinal_ccw/cw 继续驱动 yaw（单方向）
- DR5 下降至 35-63%（轨道期移入和移出）

**预期解决方案：** D2 spinal → motor 连接（驱动身体向热源平移），使到达后能通过向热源移动来补偿 yaw 偏移。

### 4.5 nu_ema = 0 全程

Shadow ν 全程为 0。这是已知问题（shadow 层未在当前电路图中产生足够信号）。待后续专项修复。

### 4.6 relay→DA 权重演化

r2d_F（前方 patch 的 relay→DA 权重）在 step 40k 快速从 0.086 升至 0.300（饱和）。  
这是合理行为：body 面向热源（前方温度高 → front patch 激活 → relay→DA 强化）。

## 5. D1 参数工程决策回顾

### 5.1 spinal→yaw w=0.002（非原设计 0.5）

**问题：** slow_relay 冷启动（τ=5000步），warmup 期 phasic 伪激活（≈32×steady-state），以 w=0.5 驱动 yaw 扭矩为 HC-016 的 6×，破坏 col→motor STDP（T4.1 从 3.07x 降至 0.90x）。

**解决：** w=0.002 将 warmup 扰动降至 HC-016 的 0.5%，T4.1 恢复至 3.07x。

**代价：** D1 到 yaw 的输出驱动仅 0.4%（相对 w=0.5），方向学习的主要路径在 phasic→spinal STDP 内部，而不是输出权重。

**待优化：** D2 可将 spinal→yaw 从 frozen 0.002 升级为 STDP，在 STDP 建立方向选择性后逐步增强。

### 5.2 D1 神经元排除出 get_all_neurons()

**问题：** 6 个 D1 神经元加入 census → energy_per_neuron 稀释 ~7% → ECM gate_col 变化 → col→motor STDP 破坏（T4.1 从 2.48x 降至 0.73x）。

**解决：** D1 神经元不加入 vascular census。D1 bundles 仍在 get_all_bundles()（Noether/Xin 正常）。
