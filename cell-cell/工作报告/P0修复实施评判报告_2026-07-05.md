## P0-1 评判：PhasicRelayNeuron 物理下限钳位

### 三问核查

**Q1. BIO：** K⁺ 逆转电位（约 -90mV）限制膜电位超极化深度。✅ 生物合理。

**Q2. PHYS：**
- phasic 神经元配置：`NeuronConfig(..., spiking=False, channels=[ChannelConfig(name='phasic_l', v_threshold=0.0001, gm=10.0)])`
- 因 channel name ≠ 'default'，走 **multi-channel 路径**：`activation = max(-10.0, min(10.0, vm))`
- vm 无界 → vm = -10.x → activation = -10.0（确认根因 ✅）
- `self.phasic_left._membrane` 是 `Capacitor` 对象，可通过 `discharge_to(v)` 设置电压

**Q3. 参数：** `v_floor = -0.1`，对应 E_K ≈ -90mV（归一化单位）。合理。

### 实施差异（需要调整）

**方案说法：** "在 PhasicRelayNeuron 的膜电位更新逻辑中施加钳位"

**实际限制：** phasic 是标准 `Neuron` 类，没有 `PhasicRelayNeuron` 子类。修改 Neuron 类会影响所有神经元（违反不改母代码原则）。

**正确实施位置：** `VariantCircuit.step()` 中 `phasic_left.step()` 和 `phasic_right.step()` 之后，紧接着添加：

```python
# P0-1: 物理下限钳位 — K+ 逆转电位底板（防超极化致盲）
# BIO: E_K ≈ -90mV；归一化 = -0.1V；τ=15000 不变（TRPV1 脱敏物理事实）
# REF: 最终架构裁决 P0-1，2026-07-05
for _pn in [self.phasic_left, self.phasic_right]:
    if _pn._membrane.voltage < -0.1:
        _pn._membrane.discharge_to(-0.1)
        _pn.activation = max(-10.0, -0.1)  # = -0.1，同步 activation
```

`discharge_to()` 是 Capacitor 类的已有方法（line 93-96，用于 spike reset），合法接口。不修改母代码。

**输出端 ReLU：** bundle_d1_phasic_left_to_spinal_ccw.propagate() 使用 phasic.activation。钳位后 activation 最低 -0.1，bundle sg=+1.0 → 输出电流最低 = -0.1 × w（轻微负值，而非 -10.0 × w）。这比施加额外 ReLU 更物理正确：允许极小负值代表"低于中性"，而非硬截断。

**结论：P0-1 可实施，钳位在 VariantCircuit.step() 中，不改母代码。✅**

## P0-3 评判：EnergyStore 不可减免 BMR

### 三问核查

**Q1. BIO：** 任何耗散结构必须有基础代谢率（ATP 合酶空转、膜离子泵维持）。热力学第二定律。✅

**Q2. PHYS 位置：**
- `EnergyStore.tick(dt)` 已有 RC 漏电实现（line 195–204）
- 在同方法末尾添加额外定速消耗
- YolkSac 输入：0.001/步（DT 无关）
- 现有 RC 漏电（DT=1.0，Q≈500）：`dQ = 500 × 1.0 / (5000×1000) = 0.0001/步`
- 合计输入：0.001 + 0（进食前）= 0.001/步 → fill 净增长（冷区永生根因）

**BMR=0.002/步（DT=1.0）时净能量流：**
| 来源 | 量（DT=1.0） |
|------|------------|
| YolkSac | +0.001 |
| RC 漏电 | -0.0001 |
| BMR | -0.002 |
| **净流量** | **-0.0011/步** |

冷区 fill 将以约 0.0011/步速率下降 → 1000 步内 fill 降 0.001 → 产生真实饥饿压力。✅

**Q3. 实施差异：** 方案写 `self.charge -= BMR * dt`，但 EnergyStore 没有 `self.charge`；内部存储是 `self._cap.charge`（Capacitor 对象）。需要通过 `_cap.inject()` 接口写入，并更新 `_total_basal_drain` 维持 Noether 守恒。

**正确实施：**

```python
def tick(self, dt: float = 0.001):
    # 现有 RC 漏电
    q_before = self._cap.charge
    self._cap.leak(self.config.r_leak, dt)
    drained = q_before - self._cap.charge
    self._total_basal_drain += drained
    
    # P0-3: 不可减免基础代谢率（BMR）
    # BIO: ATP 合酶空转 + 膜离子泵 — 任何活体不可避免的能耗
    # REF: 最终架构裁决 P0-3，2026-07-05；PHYS: 热力学第二定律
    BMR = 0.002  # 能量/步，DT 无关（YolkSac 同约定）
    # ⚠️ YolkSac 不随 dt 缩放（0.001/步定速），BMR 亦不缩放
    bmr_drain = min(BMR, self._cap.charge)  # 不可透支
    if bmr_drain > 0:
        self._cap.inject(-bmr_drain, 1.0)
        self._total_basal_drain += bmr_drain
```

**注意：** BMR 与 dt 无关（仿照 YolkSac 约定），而非 `BMR * dt`。建议在 EnergyStoreConfig 中添加 `bmr_rate: float = 0.002` 参数以便后续调节。

**Noether 守恒：** 通过 `_total_basal_drain += bmr_drain` 维持守恒等式，不破坏现有 Noether 审计。✅

**结论：P0-3 可实施，需调整实施方式（_cap.inject 而非 self.charge）。✅**
