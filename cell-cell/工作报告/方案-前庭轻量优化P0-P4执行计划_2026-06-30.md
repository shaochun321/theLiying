## Same-Modal Gain Table (dimensionless)

| Gain | Code param | Value | Rationale |
|------|-----------|-------|-----------|
| G_HC | bundles_met_to_hc synapse_gain | 5.0 | HC current amplification |
| G_HC2 | bundles_hc_to_aff synapse_gain | 20.0 | HC→Aff coupling |
| G_Enc_Col | bundles_vest_enc_to_col synapse_gain | — | Enc→Col voltage relay |
| G_Col_Motor | col_to_motor synapse_gain | 0.1 | FIX-016/017 scaled |

## ν Power Formula (corrected 2026-06-30)

ν(t) = ξ|O−P| − ξ²/R_ξ

Where:
  ξ = Xin tension (accumulated prediction error)
  O = observed afferent output
  P = predicted output
  R_ξ = Xin dissipation resistance

Physical interpretation:
  Term 1 (ξ|O−P|): error-injection power (positive = charging)
  Term 2 (ξ²/R_ξ): Joule dissipation (always negative)
  ν > 0: exploration / charging state
  ν < 0: consolidation / discharging state

Note: path optimization functional ∫P_spike dt has dimension [J] (action),
not [W] (power). Follows minimum-action principle (not minimum-power).
