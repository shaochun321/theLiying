## 二、根因分析

### 2.1 _NU_SCALE 量级失配

```python
# nexus_v1/circuit/variant_adapter.py:369
self._NU_SCALE = 1.0 / 176.0  # BIO-CAL-2026-07-04: ν_90th = 176.2 (20k baseline)
```

校准时间：2026-07-04（nu_probe.py 初版）  
校准时 ν_90th ≈ 176.2  
当前 ν 实测（5k步后）：~10⁶ → 10⁹（增长约 6 个量级）

**原因：** T-047 之后 shadow 层新增 16 条 bundle，Xin 张力大幅增长。此外，T-048（饥饿调制）、T-043（交叉抑制）等多项变更使 xin_max 从 ~176 增长到 ~8470+。

每步注入量：`I = ν × _NU_SCALE`  
校准时：`I = 176 × (1/176) = 1.0 A`（合理）  
当前：`I = 10⁶ × (1/176) ≈ 5682 A`（已经过饱和，但…）

### 2.2 Capacitor τ 完全放电

nu_neuron 配置（variant_adapter.py:370-378）：
```python
self.shadow_nu_neuron = Neuron(NeuronConfig(
    neuron_id='shadow_nu',
    capacitance=0.1,      # C = 0.1 F
    r_leak=1.0,           # R = 1.0 Ω
    # → τ = R×C = 0.1 s
    channels=[ChannelConfig(name='nu_thresh', v_threshold=0.9, gm=1.0)],
    ...
))
```

`τ = R × C = 1.0 × 0.1 = 0.1`  
`dt = 1.0`（仿真步长）  
`exp(-dt/τ) = exp(-10) ≈ 4.5 × 10⁻⁵`

**意义：** 每步注入的电荷，99.995% 在同一步内被 Capacitor.leak() 清空。

稳态电压：
```
V_ss = I × dt × exp(-10) / C
     = 5682 × 1.0 × 4.5×10⁻⁵ / 0.1
     ≈ 2.56 V
```

理论上不为零（≈ 2.56V >> v_threshold=0.9）。但实测 activation ≈ 0。

### 2.3 multi-channel 模式的额外衰减

nu_neuron 使用 channel='nu_thresh'（非 'default'），进入 multi-channel 路径（neuron.py ~439-466）：

```python
# multi-channel mode:
for name, gate in self._channels.items():
    gate.update_gate(vm, dt)
    g = gate.gated_conduct(vm)
    i_channel = cfg.sign * g * (vm - cfg.reversal)
    i_total += i_channel
# 额外注入：
i_leak = self.config.leak_conductance * (vm - self.config.leak_reversal)
i_total += i_leak
self._membrane.inject(-i_total, dt)   # ← 再次注入离子电流
self.activation = max(-10.0, min(10.0, vm))
```

Neuron.step() 中调用顺序：
1. 外部注入：`_membrane.inject(signal, dt)` → charge += signal×dt
2. Capacitor.leak()：charge *= exp(-10) ≈ 0
3. multi-channel 离子电流：`inject(-i_total, dt)` → 进一步衰减
4. activation = max(-10, min(10, vm))

关键问题：步骤 2 后 vm 已接近 0，步骤 3 的 `i_leak = leak_conductance × (vm - leak_reversal)` 若 leak_reversal=0 则 i_leak ≈ 0，不影响结论。  
但 MOSFET gate：若 vm < v_threshold=0.9，`gated_conduct(vm)=0`，i_channel=0。  
→ 步骤 3 实质上无贡献。

**真正根因是步骤 2（τ=0.1 << dt=1.0）造成完全放电。**

## 三、待决策项

需用户确认以下两种修复路径之一：

### 方案 A：延长 τ（最小改动）

```python
# 将 r_leak=1.0 改为 r_leak=100.0 → τ=10（10步时间常数）
# 或 r_leak=1000.0 → τ=100（100步时间常数，更稳定）
```

**效果：** `exp(-dt/τ) = exp(-1/100) ≈ 0.990`（每步保留99%），nu_neuron 可积累电荷。  
**风险：** τ 延长后响应变慢；_NU_SCALE 可能需要同步下调（当前 ν≈10⁶ 时注入量仍然极大）。

### 方案 B：重新校准 _NU_SCALE

当前 ν_90th 需要重新测量（上次校准后 shadow 层架构大变化）。  
需运行 nu_probe.py 重新统计当前 ν 分布，再定 _NU_SCALE = 1 / ν_90th_new。  
同时修复 τ（两个问题必须同时修）。

### 方案 C：更换 nu_neuron 为简单 pass-through 积分器

去掉 channel，改为 default 模式 + 较长 τ，让 activation = gated_conduct(vm) ≥ 0：

```python
channels=[]  # default 模式
capacitance=10.0, r_leak=100.0  # τ=1000步
```

**此方案改动最小、物理最清晰。**
