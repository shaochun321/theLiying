## 一、HC-008 Ca²⁺ 子系统分析（Phase 4b 前置调查）

### 1.1 关键发现：正常输入下 release_rate = 0

调查 Phase 4b 行为异常（单调接近，无撤退）时，对 HC-008 fix 进行了深入分析：

```
输入水平    V_mem    release_rate    pre_trace (HC-008)
  0.1      0.153      0.000000         →0 (衰减至0)
  0.3      0.248      0.000000         →0
  0.5      0.341      0.000000         →0
  1.0      0.565      0.000000         →0
  2.0      0.961      0.011375       非零（极弱）
  5.0      1.812      0.072543       可见
```

**根本原因**：`gated_conduct = m_gate × conduct(vm)`，其中 `m_gate = conduct(vm) / gm`，导致输出为**二次方**响应（而非线性）。在小超阈值激励（Ca 通道阈值=0.308，正常输入 V_mem=0.341，超阈仅 0.033）时：
- 线性响应（linear）：g = 0.17 × 0.033 = **0.0056**
- 二次响应（gated）：g = 0.0056² / 0.17 = **0.000185**（小 30×）

Ca²⁺ 电容电压稳态 = i_ca × ca_r_leak ≈ 0.000185 × 20 = **0.0037**（< ca_release_threshold=0.01）→ release_rate = 0。

### 1.2 HC-008 对行为的实际影响

HC-008 fix 将 `hc.pre_trace` 改为 Ca²⁺ 信号（0 for normal inputs）。但这个 pre_trace 只在 `hc_to_aff` 束（学习规则 = "frozen"）中作为源神经元 pre_trace 使用。**Frozen 束不做 STDP → pre_trace 不影响任何学习。**

因此 HC-008 **直接不影响任何 STDP 权重更新**。

### 1.3 Phase 4b 单调接近的真实原因

Phase 4 vs Phase 4b 行为差异的真实原因分析：

| 因素 | Phase 4 (radius=30) | Phase 4b (radius=50) | 影响 |
|------|-------------------|---------------------|------|
| 能量收益 | 负（d>13mm 即净亏损）| 正（d=16.7mm 有正收益）| Phase 4b 体运动更快速定向 |
| fill_zero 时机 | step 445,399 | step 203,155 | Phase 4b 学习时间缩短 2.2× |
| fill_zero 前学习量 | 445k 步 | 203k 步 | Phase 4 积累了更复杂的方向权重 |
| sysv @200k | +8,870 | +108,391 | 因**体位置不同**（d=15 vs d=22.8），热/痛觉 ν 不同 |

**结论**：Phase 4b 的单调接近主要由 **radius=50 正能量效应**（快速定向运动）+ **fill_zero 时间短**（203k vs 445k，方向学习不充分）导致，不是 HC-008 STDP 变化的直接后果。HC-008 是生物学正确的修复，保持不变。

## 二、V2.0 Phase 2 实施：DelayedBundle

### 2.1 背景和触发

V2.0 Phase 1（空间脚手架）已完成：
- 36/73 神经元有 anatomic 位置（24 前庭 + 12 热感/noci/relay）
- `neuron_positions` 和 `distance_matrix` 属性已实现

V2.0 Phase 2 主要项 DelayedBundle 现在实施，因为：
1. Phase 3 4/5 PASS（用户授权进入 V2.0）
2. 代码结构清晰（纯继承，不修改母本）
3. 即使对前庭链τ=0步也是重要的基础设施

### 2.2 实现方案

**新文件**：`nexus_v1/circuit/bundle_v2.py`  
**类**：`DelayedBundle(SynapticBundle)`

核心设计：
- 每个 (source_i, target_j) 对维护独立的环形缓冲区（deque, maxlen=τ+1）
- `propagate()` 推入当前信号，读取 τ 步前的信号
- 信号选择与基类相同（spiking/non-spiking/CRI）
- `apply_to_targets()` 由基类继承（不注入，只返回电流）

**延迟公式**（已验证）：
```
τ_ms    = d_ij_mm / v_cond_mm_per_ms
τ_steps = round(τ_ms / (dt_s × 1000))
```

### 2.3 纤维类型预设

| 类型 | v_cond (mm/ms) | 典型 τ | 生物对应 |
|------|----------------|--------|---------|
| Aα (V_COND_AALPHA=50) | 50 | 0步 @d=2mm | 前庭/本体感觉有髓纤维 |
| Aδ (V_COND_ADELTA=5) | 5 | 2步 @d=10mm | 快痛/温觉薄髓鞘纤维 |
| C  (V_COND_C=0.5) | 0.5 | 20步 @d=10mm | 慢痛/热觉无髓鞘 C 纤维 |

### 2.4 延迟计算验证

| 场景 | d_ij | v_cond | τ_ms | τ_steps | 正确性 |
|------|------|--------|------|---------|-------|
| 前庭 HC→Afferent（Aα）| 2mm | 50mm/ms | 0.04ms | **0步** | ✅ 等效瞬时 |
| 热觉 noci→relay（C）| 10mm | 0.5mm/ms | 20ms | **20步** | ✅ 显著延迟 |
| 混合位置（一端 None）| — | — | — | **0步** | ✅ 回退到瞬时 |

### 3.3 DelayedBundle 实际影响分析

当前所有有位置神经元的最大延迟：
- 前庭链（Aα, d=2-3mm）：τ = 0步 → **无实际延迟效果**
- 热/noci 链（C, d=2-3mm）：τ = 2-4步 @ V_COND_C → 可接受的微小延迟

**结论**：DelayedBundle 代码已就绪，但在当前神经元距离范围内（<5mm）对行为几乎无影响。当系统扩展到更大神经元间距（皮层-脊髓通路 d=10-30mm）时，这个基础设施将发挥作用。
