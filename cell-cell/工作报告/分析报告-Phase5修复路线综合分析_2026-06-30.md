## 二、Route A：单参数扫描结果（50k 步 × 3 条件）

### 2.1 实验设计

| 条件 | oto 幅度 | muscle gain | 目的 |
|------|----------|-------------|------|
| Cond1 | 6.0 | **0.1** | 仅提升 oto，保持 baseline gain |
| Cond2 | **3.0** | 0.3 | 仅提升 gain，保持 baseline oto |
| Cond3 | 6.0 | 0.3 | 两者均提升（v2 参考） |

所有条件共享：`LATERAL_GAIN=0.3`，`stdp_lr=0.005`，body=[50,50,50]，heat=[70,50,50]

### 2.2 实验结果

| 条件 | Δx@50k | speed | fill@50k | drain/10k | \|Δw\| |
|------|--------|-------|----------|-----------|-------|
| Cond1 (oto↑) | +0.0534 | 0.00319 | 0.338 | **0.0324** | 0.0216 |
| Cond2 (gain↑) | +0.1787 | 0.00838 | 0.338 | **0.0324** | 0.0216 |
| Cond3 (v2 ref) | +0.1212 | 0.00661 | 0.338 | **0.0324** | 0.0215 |

### 2.3 关键发现

#### 发现 1：muscle gain 是位移主导因子

```
gain=0.3 alone  → Δx +0.1787  (147% of combined v2)
oto=6.0 alone   → Δx +0.0534  (44% of combined v2)
Both combined   → Δx +0.1212  (100% baseline)
```

**muscle gain 是 body 位移的主导因子，oto 幅度贡献次之。** 更意外的是：两者合并后效果反而低于 gain 单独使用，提示高 oto 可能引入额外噪声或振动干扰（运动方向随机化）。

#### 发现 2：三个条件能耗速率完全相同

**三个条件 fill drain 均为 0.0324/10k，三位小数完全一致。** 这意味着：

- oto 幅度（3.0 vs 6.0）不影响 fill 消耗速率
- muscle gain（0.1 vs 0.3）不影响 fill 消耗速率
- **fill 消耗来源与 oto 输入幅度和肌肉功无关**

三个条件的共同项是：`LATERAL_GAIN=0.3`（SomatosensoryChain 侧向抑制网络激活）。推断：**fill 消耗的主导来源是 SomatosensoryChain + VestibularChainV2 等基础网络的常态放电**，而非输入幅度变化。

#### 发现 3：v1 基线能耗对比

v1（oto=3.0，gain=0.1，无 somatosensory 激活）：drain ≈ 0.0036/10k

Route A 所有条件：drain = 0.0324/10k

**比值 9×**：Phase 5 v2 相对 v1 增加的主要能耗不是 oto 或 gain 提升，而是 SomatosensoryChain 激活（`LATERAL_GAIN=0.3`）带来的额外网络负担。

## 三、Route B：能量再生探测结果（100k 步）

### 3.1 实验设计

参数与 v2 相同（oto=6.0，gain=0.3），仅增加 `REGEN_PROB=0.001`（世界热源再生）。

### 3.2 结果

| 步数 | fill | 热源数 | speed |
|------|------|--------|-------|
| 0 | 0.500 | 1 | 0 |
| 10k | 0.468 | 5 | 0.00956 |
| 50k | 0.339 | 5 | 0.00984 |
| 100k | **0.209** | 5 | 0.01208 |

- drain/10k = 0.0292（与 v2/v3/Route A 完全一致）
- 结论：**REGEN_PROB 无效**

### 3.3 根因分析

`consume_nearby(pos, rate=0.15, dt=0.001)` 在 body 位于 [50,50,50]、热源 [70,50,50]（半径 30）时的实际 deposit：

```
proximity = 1 - 20/30 = 0.333
deposit/step = 0.15 × 0.333 × 0.001 = 5.0×10⁻⁵ 绝对单位/步
```

对应 fill fraction（capacity=1000）：`5.0×10⁻⁵/1000 = 5.0×10⁻⁸/步`

神经网络 drain（0.0324/10k 步 = 3.24×10⁻⁶ fill fraction/步 = 3.24×10⁻³ 绝对单位/步）：

| 指标 | 数值 |
|------|------|
| 神经网络 drain/步 | 3.24×10⁻³ 绝对单位 |
| 世界能量 deposit/步 | 5.0×10⁻⁵ 绝对单位 |
| **比值（drain/deposit）** | **≈ 65×** |

**神经网络消耗速率比世界能量补充速率高 65 倍。** 增加热源数量（1→5）不能改变 deposit/drain 比例，因为 deposit 受 `max_deposit_per_step=0.05` 和 proximity 限制，而 drain 来自神经放电这一完全独立的过程。

## 四、综合分析：DR3 修复可行性矩阵

### 4.1 各参数影响总结

| 参数 | 对位移 (DR2) | 对能耗 (DR3) | 结论 |
|------|-------------|-------------|------|
| oto 幅度 ↑ | 弱（44%贡献） | **无影响** | 高 oto 高位移效率低，有噪声代价 |
| muscle gain ↑ | **强（147%贡献）** | **无影响** | 位移最高效但不耗能 |
| REGEN_PROB ↑ | 无 | **无影响** | 世界能量 65× 不够 |
| LATERAL_GAIN ↑ | 间接（方向学习） | **≈9× drain 主因** | somatosensory 负担重 |

### 4.2 修复方向评估

| 路线 | 方法 | DR2 影响 | DR3 修复可能性 | 评估 |
|------|------|----------|--------------|------|
| **路线 A1** | gain=0.3, oto=3.0 | 强保留 | 无（drain 相同） | ✗ 无效 |
| **路线 A2** | gain=0.3, oto=1.5 | 削弱 | 无（drain 相同） | ✗ 无效 |
| **路线 B** | REGEN_PROB 提升 | 无 | deposit 65× 差距无法弥合 | ✗ 无效 |
| **路线 C** | max_deposit_per_step 提升 65× | 无 | **有效**（EnergyStore 参数调整） | ✓ 推荐 |
| **路线 D** | LATERAL_GAIN 降低（0.3→0.1） | 削弱 | 部分（降低 somatosensory 负担） | △ 权衡 |
| **路线 E** | consume rate ↑（0.15→9.75） | 无 | **有效**（variant_adapter 参数） | ✓ 推荐 |

### 4.3 推荐修复路线

**路线 E（首选）：提升 `CONSUME_RATE` 至 9.75**

```python
# variant_adapter.py:719
CONSUME_RATE = 9.75  # BIO: 深海热液口化能自养菌 C/N 代谢效率校准
                      # 原值 0.15 × 65 = 9.75（补偿 65× 的 drain/deposit 比）
```

- 不改变神经网络结构
- 不影响 DR2（位移由 gain 驱动，不受能量补充影响）
- 符合 RULES.md 精神：代谢效率是可调参数，不影响信号路径

**路线 C（备选）：提升 `max_deposit_per_step`**

```python
# energy_store.py:EnergyStoreConfig
max_deposit_per_step: float = 3.25  # 原值 0.05 × 65
```

两条路线等效。路线 E 更接近生物类比（有机体从热液口摄取能量的速率），推荐路线 E。
