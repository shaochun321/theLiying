## 三、物理定义（强制三问）

**Q1 生物/物理对应物**：DN 分流抑制/横向抑制池是真实皮层机制（REF: Carandini & Heeger 2012, Nature Reviews Neuroscience）。T3-B 让 ξ_a、ξ_b 两条通道共享**同一个**`DivisiveNormalizationReceptor`池实例（而非各自独立池），物理对应"两个感受野竞争同一片横向抑制神经元"——这正是路径判别阶段（12.2 第1点）已确立的路径B机制。

**Q2 物理结构**：`Sources(ξ_a,ξ_b) → SynapticBundle(Bundle_a,Bundle_b) → Targets(channel_a_collector,channel_b_collector)`，DN 作为插入在 `propagate()` 输出和 `.step()` 输入之间的补偿级联，与 `compensation.py` 里其他补偿组件的使用方式同构，不是新发明的写入路径。符合"多路输入汇聚前先求和"的 8 步调度协议（这里"多路"指共享池的两路输入：池更新必须用两路之和，读出必须分别用 `dt=0`，顺序不能颠倒）。

**Q3 参数依据**：
- `_W_XI_TO_CHANNEL=0.3`：直接复用 T1 `_W_XI_TO_TRACE` 已验证取值（同一 ξ 源，pre_trace 量级同为 O(1)）。
- DN 池参数（`sigma=1.0`/`pool_capacitance=5.0`/`pool_r_leak=5.0`）：首轮直接沿用类默认值，作为 EXP 起点，**明确预期需要多轮 Model-before-tune 式校准**（本版参数未经过完整校准循环，如实标注）。
- Channel collector：结构复用 T1 `_trace_config()` 同款"显式 v_threshold=0，大 gm 补偿二次压缩"范式（T1 EXP-T1-02 已证实），`_CHANNEL_GM=20.0` 沿用 T1 trace 量级。

## 四、电路结构

```
ξ_a (thermal_quantum_collectors["thermpt28_warm"]，复用T0/T1冻结点a)
    │
    └─(bundle, frozen, w=0.3)→ channel_a_collector (非spiking Neuron, RC 读出)
ξ_b (thermal_quantum_collectors["thermpt31_warm"]，复用T0/T1冻结点b)
    │
    └─(bundle, frozen, w=0.3)→ channel_b_collector (非spiking Neuron, RC 读出)

shared_pool = DivisiveNormalizationReceptor(sigma=1.0, pool_capacitance=5.0, pool_r_leak=5.0)
              # a/b 共享同一实例

step_rpart(dt):
    i_a_raw = bundle_a.propagate()[0]
    i_b_raw = bundle_b.propagate()[0]
    shared_pool.normalize(i_a_raw + i_b_raw, dt)   # 真实dt，更新池一次
    y_a = shared_pool.normalize(i_a_raw, 0.0)       # dt=0，只读
    y_b = shared_pool.normalize(i_b_raw, 0.0)       # dt=0，只读
    channel_a_collector.step(y_a, dt)
    channel_b_collector.step(y_b, dt)
```

新文件 `nexus_v1/relations/ratio_r_part.py`，`RPartCircuitT3(VariantCircuit)`，子类叠加，不修改母本。

**已发现并处理的真实结构性特性**（如实记录，同 T1/T3 报告一贯做法）：首次跑测试时 T-RPT-2/T-RPT-4 用精确相等断言失败，实测 `i_a_raw/i_b_raw` 比值约 1.049。**根因核实**：`bundle_rpart_xi_a_to_channel`/`bundle_rpart_xi_b_to_channel` 用不同 `bundle_id` 字符串，`Memristor` 按 `hash((bundle_id,i,j))` 施加对称性打破扰动（`bundle.py:169-171`，T1 已记录的同一机制），导致两条标称权重相同的 Bundle 实际电导不同——**这是电路结构本身的真实特性**（每个 Bundle 独立随机化，防止病理对称性），不是 DN 池数学有误（DN 池本身精确对称，扰动来自更上游）。处理方式：把精确相等断言改为相对容差 25%（覆盖已观测的 ~8% 量级偏差，留足余量），不强行让 hash 扰动"消失"。
