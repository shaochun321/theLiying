## 三、核心发现

### 3.1 原假设完全失效

Ia 互抑束不是 spinal 被压制的原因。

**量化对比：** 扫描A与扫描B的 spinal_mean 在每个权重点的差值均 < 0.003（全部在噪声范围内）。两条 F-I 曲线几乎重合。

**推论：**
- **Ia 压制比 ≈ 1.0×**（实际上没有压制）
- Ia 互抑束（sg=-1.0，w=0.1）对 spinal 的抑制贡献可以忽略不计

### 3.2 真正的根本原因：phasic 钳位

spinal_mean 的负值来自 D1 bundle 的反向驱动，不是 Ia：

```
P0 修复（commit cac24ca）设置了 phasic 钳位 = -0.1V
当 body 远离热源时：phasic = relay - slow_relay ≈ 0
phasic 被钳位于 -0.1V（防止负值蔓延的设计）
→ D1 bundle 输出：phasic × w_D1 × sg = (-0.1) × w × 1.0 = -0.1w（负电流）
→ spinal 被 D1 自身的负向驱动拉低
```

**数值验证：** 随 w_D1 从 0.001 增大到 0.300，spinal_mean 从 -0.028 单调减小到 -0.039（差值 = 0.011），与预期的 D1 负向贡献成正比。

### 3.3 yaw_mean 恒为 ~0.65，与 D1 权重无关

yaw 激活由主前庭-运动链（Vestibular→Enc→Col→Motor）驱动，D1→spinal→yaw 路径在稳态下贡献接近零：

```
spinal_act ≈ -0.03（负值，MOSFET 截止区）
→ bundle_spinal_to_yaw 传递电流 = 0.020 × 1.0 × (-0.03) = -0.0006
→ 与 yaw 基线 0.65 相比可忽略不计
```

### 3.4 F-I 曲线测量的是"稳态"，不是"学习时"

实验中 body 从 [10,50,25] 出发，8k 步内无法到达热源 [70,50,25]。  
因此 phasic 信号全程 ≈ 0（钳位状态），D1 驱动 spinal 负值。

**这与实际 STDP 学习情形不同：**

| 情形 | phasic 状态 | spinal 状态 | D1 STDP 效果 |
|:---|:---|:---|:---|
| F-I 诊断（稳态） | ≈ -0.1V（钳位） | 持续负值 | 无学习 |
| 实际热趋性实验 | 周期性正脉冲（接近热源时） | 短暂正向激活 | LTP 捕获 ✓ |

**结论：** F-I 曲线衡量的是"脉冲间期"的静息态，不代表 STDP 窗口内的激活水平。T-036/T-038 观察到的 |Δw|=0.299 和 DR5%=75% 是这些短暂正向激活积累的结果。

## 四、对后续任务的影响

### 4.1 T-045（降低 D1 initial_weight）→ 取消

原本 T-045 是"如果 T-042 显示 spinal 处于饱和区，则降低 initial_weight"。

**结论：spinal 完全不在饱和区——连点火阈值都未达到。** initial_weight=0.1 没有过饱和问题，T-045 不需要执行。

### 4.2 T-043（yaw 层交叉抑制束）→ 参数重新推导

原计划用 rheobase_A/B 和增益曲线推导 T-043 参数。由于 F-I 曲线全负，原推导路径失效。

**替代推导方法（基于实际 STDP 学习窗口）：**

在 T-038（50k步，DR5%=75%）中，spinal_ccw 在 phasic 爆发期的瞬态激活估算：

```
phasic 峰值 ≈ 0.15（接近热源时，relay - slow_relay 峰值）
D1 bundle 在 w=0.1 时的 spinal 驱动：0.1 × 1.0 × 0.15 = 0.015
加上 Ia（sg=-1.0，w=0.1）的反向贡献：0.1 × (-1.0) × spinal_cw ≈ 0
净 spinal_ccw 瞬态电压 ≈ +0.015 × R_leak = +0.015 × 5.0 = 0.075 V
```

此时 spinal_ccw_to_yaw 对 yaw_ccw 的贡献：  
`0.020 × 1.0 × 0.075 = 0.0015`（微弱正向）

**交叉抑制参数建议（保守对称设计）：**

```
W_CROSS = 0.020（等于正束，1:1 差分放大）
SG_CROSS = -1.0（抑制性）
```

效果：当 spinal_ccw 短暂为 +0.075 时：
- yaw_ccw 增加：+0.0015
- yaw_cw 减少：-0.0015
- 净差分：0.003（约为无交叉抑制的 2×）

**背景态影响（spinal < 0）：** 当 spinal_ccw ≈ -0.028 时，交叉束向 yaw_cw 注入：
`0.020 × (-1.0) × (-0.028) = +0.00056`（微弱正向，与 yaw 基线 0.65 相比可忽略）。

### 4.3 P0-C 参数计划重新考量

Ia 参数（sg=-1.0，w=0.1）对当前电路的影响可以忽略（Ia 压制比≈1）。

这意味着：
1. 在当前工作点下，Step 6 的 Ia 互抑束实际上是近乎无效的硬件——拓扑正确但没有做实质性工作
2. 调整 Ia 参数（更改 w 或 sg）不会显著影响 spinal 的激活模式
3. T-043 的交叉抑制设计在生物力学上仍然合理，但效果主要依赖 phasic 爆发期，不依赖稳态

### 6.2 关键附加发现：sp_peak 为正值

**spinal_mean 为负，但 spinal_peak 为正（0.12–0.19）。**

phasic 信号的 mean ≈ -0.080 而 peak ≈ 0.261，表明 phasic 在绝大多数时间为负（钳位），但在 body 接近热源时短暂爆发至 0.26。正是在这些瞬态正向脉冲期间：

1. phasic 爆发 → D1 bundle 向 spinal 注入正电流
2. spinal 短暂越过零，达到峰值 0.13–0.19
3. STDP 的 eligibility trace 累积 → LTP 发生
4. 绝大多数时间 spinal 为负 → 拉低均值 → F-I 曲线全负

**这完全解释了 T-041 观察到的 |Δw|=0.299：STDP 工作在 sp_peak 瞬间，而非均值。**
