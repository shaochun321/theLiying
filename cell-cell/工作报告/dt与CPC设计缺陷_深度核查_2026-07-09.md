# dt 与 CPC 设计缺陷深度核查

**日期：** 2026-07-09  
**代码基线：** J:\cell-cc main @ 44d0add  
**核心结论：** dt 分裂使三因子 STDP 的时间常数漂移 1000×，导致不同实验在物理上运行的是完全不同的系统；CPC 主输出已被取代成为死代码；两者叠加从根本上阻断了可重复、可累积的学习涌现。

### 1.2 β 漂移：DA_ema 的 1000× 问题

**代码：** `bundle.py:382`
```python
_beta = dt / (dt + self.config.da_ema_tau)
```

其中 `da_ema_tau = 5000.0`（`bundle.py:121`），注释明写"simulation STEPS, not seconds"。

| dt | β = dt/(dt+5000) | 有效 EMA 时间常数（步） | 物理意义 |
|----|-----------------|----------------------|---------|
| 0.001 | ≈ 2.0 × 10⁻⁷ | **≈ 5,000,000 步** | DA_ema 近乎冻结，跟踪窗口 5M 步 |
| 1.0 | ≈ 2.0 × 10⁻⁴ | **≈ 5,000 步** | 符合注释设计意图 |

**漂移倍数：1000×。** dt=0.001 时 DA_ema 约等于常数（每步只更新 0.00002%），三因子 LTP 的门控信号实际失效。

**注释声称"β 显式依赖 dt 因此 dt-safe"是错误自我认知。** 真正的 dt-safe 公式要求 τ 以秒为单位：`β = dt/(dt + τ_seconds)`。而代码中 τ 是"步数"——这意味着该公式只在 dt=1.0（步长=1步）时才与设计意图一致。

**同样的问题出现在 eligibility 衰减（`bundle.py:398-399`）：**
```python
decay_factor = 1.0 - dt / max(self.config.eligibility_tau, 1.0)
```
`eligibility_tau=300`（步）。dt=0.001 时每步衰减因子 0.9999967（τ≈300,000 步）；dt=1.0 时 0.9967（τ≈300 步）。同样 1000× 差距。

### 1.3 pre_trace 的双故障模式

**代码：** `neuron.py:587-589`
```python
decay_pre = math.exp(-dt / max(self.config.trace_tau_pre * 0.001, 0.001))
self.pre_trace = self.pre_trace * decay_pre + abs(self.activation)
```

`trace_tau_pre = 20.0`（neuron.py:94），代码内部 ×0.001 转秒，即 τ_pre = 20ms = 0.02s。

**dt=0.001（原始设计）：**
- `decay_pre = exp(-0.001/0.02) = exp(-0.05) ≈ 0.9512`
- 稳态放大：`1/(1 - 0.9512) ≈ 20.5×`（STDP_freeze_rootcause 报告的推导正确）
- pre_trace 有记忆，能积累连续活动

**dt=1.0（T 系列实验）：**
- `decay_pre = exp(-1.0/0.02) = exp(-50) ≈ 1.9 × 10⁻²²`
- pre_trace 每步被清零：`pre_trace ≈ abs(activation)（当前步）`
- **时序积累完全消失，STDP 退化为纯瞬时 Hebbian**
- STDP_freeze_rootcause 报告的"20.5× 稳态放大"论断**在 DT=1.0 的实验中完全不成立**

**结论：** 两个 dt 各自触发不同故障：
- dt=0.001 → DA_ema 冻结（β≈0），三因子门控失效
- dt=1.0 → pre_trace 瞬时化，时序信用分配失效

没有任何一个 dt 值让三因子 STDP 按设计工作。

### 1.4 其他 τ 失效（随 dt=1.0 放大 1000×）

以下组件的 τ 均按 dt=0.001 标定，在 dt=1.0 下时间常数放大 1000×：

| 组件 | 参数 | 标定假设 | dt=1.0 下实际 |
|------|------|---------|--------------|
| `_feed_rate_cap`（V_feed）| C=1, R=5 → τ=5000步 | dt=0.001 → τ=5s | dt=1.0 → τ=5000s |
| `satiety_neuron` | C=50, R=1 → τ=50000步 | dt=0.001 → ~30-60s | dt=1.0 → 50000s |
| `_da_local`（D2R积分器）| τ_D2=1s（d2_da_r_leak=1.0） | 秒单位，**dt-safe** ✅ | 正确（见下文例外） |
| `circulation_proportion` 电容 | τ=RC=10000步 | dt=0.001 → 10s | dt=1.0 → 10000s |
| Cupula 高通 `_TAU_CUPULA=4000步` | dt=0.001 → τ=4s（前庭生理） | dt=1.0 → 4000s |

**例外（真正 dt-safe 的组件）：**
- `neuron.py` 的 `decay_pre/post`（使用 exp(-dt/τ_seconds) 形式，τ×0.001）
- D2Autoreceptor 内部积分器（使用 `exp(-dt/τ_D2)` 形式）
- HebbianCircuit 的 TemporalCoupler（使用 exp 衰减）

这说明代码并非完全没有 dt-safe 意识——问题出在 `bundle.py` 的 β/eligibility 和多个组件的积分电容使用了**步数而非秒数**的 τ。

---

### 1.5 根本影响：为什么 dt 分裂阻断涌现

三因子 STDP 的工作前提是：
1. **pre_trace（τ≈20ms）**：记录突触前活动历史
2. **eligibility trace（τ≈300步≈0.3s@dt=0.001）**：桥接 pre-post 共现与延迟奖励
3. **DA_ema（τ≈5000步≈5s@dt=0.001）**：平滑奖励信号

在 dt=1.0 的实验中：
- pre_trace 瞬时化（没有历史）
- eligibility trace 的实际 τ 与设计意图一致（300步，勉强正确）
- DA_ema 的实际 τ=5000步（在 dt=1.0 语境下=5000s，远超任何行为周期）

即使 DA 信号瞬间变化，DA_ema 需要 5000 步才能反映出 50% 的变化，而一个完整的热源接近-撤退周期约 20000 步——这意味着 STDP 看到的 DA 变化，是几个周期之前的混合平均，无法进行精确的时间信用分配。

## 二、CPC 设计错位

### 2.1 CPC 是什么

CPC = `CirculationProportionCircuit`（`nexus_v1/components/circulation_proportion.py`）。  
生物对应：下丘脑稳态整合核团（视前区/外侧下丘脑，Saper 2002）。  
初始化：`variant_adapter.py`（约 L430 区块），`self.circulation_proportion = CirculationProportionCircuit()`。

CPC 接收三路输入积分：
1. `thermal_stability`：体温稳态偏差
2. `body_speed`：运动速率
3. `feed_alignment`：摄食对齐（V_feed）

输出两个量：
- `deviation`：稳态偏差标量
- `da_current`：MOSFET 比较器电流（**设计上应注入 DA**）

---

### 2.2 主输出 `da_current` 已被遗弃（死代码）

**`circulation_proportion.py` docstring 全文强调 `da_current` 是主输出：**
```
# circulation_proportion.py:9 "output: DA_excitation_current"
# L84: "Comparator output: da_current injected into DA neurons"
# L131: "Returns: {'da_current': float, 'deviation': float, ...}"
```

**但 `variant_adapter.py` 中，`circ = self.circulation_proportion.step(...)` 之后：**
```python
# L1817: # Replaces c3_da_current (absolute deviation) with rate-of-change gate.
# L417:  # Replaces c3_da_current from circulation_proportion (absolute deviation).
circ['deviation']  # ← 只读这个
# circ['da_current']  ← 从未出现在任何赋值/传参语句中
```

`grep -n "da_current" nexus_v1/circuit/variant_adapter.py` 结果：仅出现在注释（L417、L1817、L3366），**无任何读取赋值**。

**CPC 的 MOSFET 比较器（circulation_proportion.py:108-111, L175）每步照计算，结果丢弃。** 这是真正的死代码。

**取代者：** `da_gate`（`DADifferentialGate`，L1817-1821），用 d(fill)/dt 代替绝对 deviation 驱动 DA，语义从"稳态偏差→DA"变成了"奖励率变化→DA（RPE）"。概念更清晰，但设计文档未更新，CPC 的 da_current 比较器沦为永久运行的无效代码。

---

### 2.3 唯一生效的输出路径（调运动幅度）

`deviation → cpc_dev_neuron → bundle_cpc_to_vital → vital_amp_neuron → VitalOscillator.deviation_mod`

- `deviation` 读取（`variant_adapter.py:1848`）→ 注入 `cpc_dev_neuron`
- `bundle_cpc_to_vital`（frozen，w约0.3，sg=0.3，`variant_adapter.py:1846`）
- `vital_amp_neuron` 同时接收 `satiety_to_vital`（sg=-1.0，w=0.5，`L1069-1070`）
- KCL 求和：CPC 正向唤醒 + 饱腹负向抑制，净效果取决于两者相对大小
- **无联合标定证据**：CPC 增益（gain=0.3）与 satiety 增益（w×sg=0.5×(-1.0)=-0.5）未做对称设计

---

### 2.4 V_feed → CPC 在 dt=1.0 下失效

V_feed 是 CPC 的第三路输入（feed_alignment），通过 `_feed_rate_cap` 积分平滑：
```python
# variant_adapter.py:1004-1005
# τ = C×R/dt = 1.0×5.0/dt = 5000 步 @dt=0.001（注释 L1002 明确写 /dt）
self._feed_rate_cap = Capacitor(capacitance=1.0, leak_resistance=5.0)
```

**注意：** 该注释罕见地写了 `/dt`，说明作者意识到 dt 会改变步数。但这个正确意识没有被推广到其他组件。

在 dt=1.0 的进食实验（T-032 系列等）中，`_feed_rate_cap` 的物理 τ 变成 5000s（约83分钟），V_feed 对进食事件的响应极慢，CPC 的 feed_alignment 输入实际上是一个几乎不变的常数。CPC 的稳态整合功能在 dt=1.0 下完全变形。

---

### 2.5 结论：dt 与 CPC 的交叉影响

```
DT 分裂
  ↓ 1000× τ 漂移
  ├─ DA_ema 冻结（三因子 LTP 门控失效）
  ├─ pre_trace 瞬时化（时序信用分配失效）
  ├─ _feed_rate_cap τ = 5000s（V_feed 输入常数化）
  └─ CPC 积分电容 τ 放大 1000×（稳态偏差信号变形）

CPC 设计错位
  ├─ da_current 死代码（每步白算）
  ├─ deviation→vital 被 satiety 稀释（无联合标定）
  └─ V_feed→CPC τ 失效（dt=1.0 下不按设计工作）
```

两者叠加的结果：**在 dt=1.0 的 T 系列实验中，三因子 STDP 的所有三个要素（pre_trace 时序、eligibility 积分、DA 信号变化）都无法在设计意图的时间尺度上正常工作。DA_ema 因 CPC 失效部分缺少正确的稳态信号，同时因 dt 漂移而跟踪窗口比设计大 1000×。这从根本上阻断了可重复学习的涌现。**

## 三、修复优先级建议（仅规划，不执行）

> 用户说明"修改数值随意便可"，此处仅列出修复方向，不提供具体参数值。

**P0（阻断涌现的根因，必须先修）：**
1. 统一 DT：新实验全部确认 DT=0.001 或 DT=1.0 之一，并同步更新所有 τ 标注
2. 或者：把 `bundle.py` 的 τ 改为秒单位（`eligibility_tau_s`、`da_ema_tau_s`），用 `β = dt/(dt + τ_s)` 和 `exp(-dt/τ_s)` 统一写法

**P1（功能性修复，P0 后做）：**
3. DA_ema 基线减法：`LTP = gain × E × max(0, DA_ema - DA_baseline)`
4. CPC da_current 清理：移除 da_current 比较器或重新接入 DA 系统（选其一，避免两个 RPE 信号叠加）
5. pre_trace 归一化：加 (1-decay_pre) 因子

**P2（信号质量改善）：**
6. eligibility_tau 和 da_ema_tau 对齐（建议 τ_ema ≤ 3×τ_elig）
7. satiety_to_vital 与 bundle_cpc_to_vital 做联合增益标定
