## 问题背景

VestibularChain 的 canal 三轴（yaw/pitch/roll）在 `VariantCircuit.step()` 中始终注入 0 信号：半规管神经通路已建好，但无输入驱动。导致 yaw 转向时 MET_yaw→HC_yaw→Aff_yaw 全程静默，相当于只有耳石而无半规管的单侧感知。

## Phase 0：Cupula 高通滤波器实现（commit `1c2cfd9`）

**修改文件：** `nexus_v1/circuit/variant_adapter.py`

**生物模型：** Steinhausen (1931) 扭摆 — 过阻尼 Cupula 偏转 θ ∝ 头部角速度 ω，持续旋转时适应（τ≈4s）。

**离散 IIR 实现：**
```
θ[t] = ALPHA × (ω[t] - ω[t-1]) + (1-ALPHA) × θ[t-1]
ALPHA = dt / (dt + 4000)   ← 必须动态计算，禁止硬编码
```

**注入点：** `mechanical_inputs['yaw'] += θ × ANGULAR_GAIN`（耳石注入之后）

**初始增益：** ANGULAR_GAIN = 5000（待 Phase 0.5 校准）

## Phase 0.5：ANGULAR_GAIN 校准（实验 T-076a，commit `d35ac6b`）

**实验设计（`exp_T076a_canal_gain_calibration.py`）：**  
5k 步旋转实验（0~2k FREE / 2k~3k SPIN扭矩0.02 / 3k~5k COAST）

**增益迭代过程：**

| ANGULAR_GAIN | MET_yaw峰值 | J2状态 |
|:---|:---|:---|
| 5,000 | 0.0002 | FAIL（过弱） |
| 100,000 | 0.035 | FAIL（仍不足） |
| 300,000 | **0.32** | **PASS** |

**根本原因：** MET 传输函数为平方律 `gm×(V-Vth)²`（非线性），峰值为瞬态叠加（非稳态），需要 3× 更大的增益才能达到估算目标。

**最终设定：** `_ANGULAR_GAIN = 300000`

**T-076a 结果（4/4 PASS）：**
- J1 PASS: canal 信号非零（6.14e-2）
- J2 PASS: MET_yaw = 0.32，在 [0.1, 5.0) 非饱和区间
- J3 PASS: MET_yaw = 0.032 > 0.001
- J4 PASS: SPIN/FREE 信号比 20.73×（高通滤波器正常工作）

**注：** canal（角速度）与 otolith（线性加速度）物理量纲不同，不做信号幅值直接对比。

## Phase 1：旋转激活验证（实验 T-076b，commit `1b64339`）

**实验设计（`exp_T076b_rotation_activation.py`）：**  
5k 步四区段（0~1k BASELINE / 1k~2k ONSET / 2k~4k ADAPT / 4k~5k STOP）

**关键测量数据：**

| 阶段 | MET_yaw | Cupula θ | omega |
|:---|:---|:---|:---|
| BASELINE (静止) | 0.000 | ~0 | ~0 |
| ONSET 峰值 | 2.03 | 5.57e-7 | 6.1e-4 |

| STOP (停止后) | 0.000 | -1.22e-6 | -3.89e-3 |

**T-076b 结果（4/4 PASS）：**

| 判定 | 条件 | 结果 |
|:---|:---|:---|
| J1 PASS | onset_peak (2.03) > baseline+3σ (0) | ✅ 旋转开始时激活 |
| J2 PASS | adapt_late (0.49) < onset_peak×0.5 (1.01) | ✅ 75.7% 适应衰减 |
| J3 PASS | theta_stop_min (-1.22e-6) < 0 | ✅ Cupula 停止反向 |
| J4 PASS | baseline_max (0.0) < 0.01 | ✅ 基线干净 |

**物理解释：**
- J3 判定基于 Cupula θ（非 MET 激活）：MET 经半波整流不可负，停止响应需要对向毛细胞才能作为神经信号传出。θ 反向是 Cupula 弹回的正确物理表现。
- 适应时间常数从数据估算：MET 在 2k 步内衰减 75.7%，对应 τ_adapt ≈ 2000/ln(4.1) ≈ 1400 步（目标 τ=4000，仍在适应中——与初始方案一致）。
