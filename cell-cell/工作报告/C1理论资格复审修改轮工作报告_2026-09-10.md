## 四、P1-2：A9 运行时谱系缺口登记（_diag_c1_runtime_lineage_collision）

两层审计，exit 0 = **缺口已正确复现并登记，不是 A9 PASS**：

1. **接口审计**：`inspect.signature(RelationEventAdapter.step)` 参数恰为 `['self', 'r_current', 'dt']`，无任何 occurrence/epoch/instance/window/ledger 端口——运行时身份在物理路径上**不存在**（若接口未来变化，断言失败强制重审）；
2. **行为审计**：case A（lineage 声明 = RelA/Epoch1 + RelB/Epoch1）与 case B（RelA/Epoch1 + RelB/Epoch2）喂完全相同的 r trace X → adapter pulses 逐位相同（X=[100], Y=[400]）、c_ro trace 逐位相同（fires=[400]）。lineage 只能以 INFRA 元数据形式"声明"——无处可传入，这正是缺口本身。

**按 P1-3 明确不做**：不给 `adapter.step` 加 `relation_occurrence` 参数，不写 `if epoch_mismatch: return 0`——那会让 Python/INFRA 身份直接决定 BIO/SEMI 物理输出，无理论裁定支持。未来方向（已写入 diag 与台账）：物理信号路径保持原样 + 独立 lineage audit/binding sidecar（sidecar 不得改变 spike/Θ/gate），待理论裁定后另轮实现。
