## 一、执行摘要

**发现 60 个硬编码违规**（HC-001～HC-060，含此前已知的 5 个），分布于：

| 严重度 | 数量 | 核心影响 |
|--------|------|---------|
| CRITICAL | 9 | 直接伪造实验结论、污染 STDP 方向、Silent Bug 导致 FIX-017 从未生效 |
| HIGH | 17 | 系统性绕过 SynapticBundle 层，可塑性路径不可见 |
| MEDIUM | 25 | 参数未接地、物理计算近似 |
| LOW | 9 | 可疑模式，需进一步确认 |

**最严重结论**：

> V1 电路的所有热趋性实验结果（Phase 5/6/7/8 全部 DR5 PASS，Phase 3 DR2）**不能归因于 STDP 涌现**。真正驱动行为的是两个并行的 Python 层：HC-005（G_ORIENT 直接计算 yaw）和 HC-006（feed_alignment 直接注入 DA），而 DR5 benchmark 本身也使用了电路无法访问的全局梯度（HC-012）。三重污染使所有热趋性指标完全无效。

## 二、CRITICAL 级违规（9 项）

### HC-005: G_ORIENT=200 热梯度→yaw 语义注入 ⚠️（已登记，最高优先级）

```python
# variant_adapter.py ~726
G_ORIENT = 200.0
delta_T_orient = self._patch_temps['right'][0] - self._patch_temps['left'][0]
mechanical_inputs['yaw'] += delta_T_orient * G_ORIENT
```

**类别**: SEMANTIC_MATH + GOAL_HARDCODED  
**影响**: 
- Phase 6/7 DR5≈96% 完全由此制造
- Phase 3 DR2 dist 减少完全由此驱动
- Phase 8 wR>wL "方向正确" 是 G_ORIENT 推动 body→S1 导致的被动 STDP 跟随，不是学习

**V2.0 修复**: 删除；改为 `thermo_patch_right → relay_right → motor_yaw_right` SynapticBundle

### HC-006: feed_alignment 点积注入 DA 奖励 ⚠️

```python
# variant_adapter.py ~762-775
heat_dir = normalize(src.position - body.position)
vel_dir = normalize(body.velocity)
alignment = dot(heat_dir, vel_dir)          # 语义数学：Python 直接判断「朝热源？」
feed_alignment = max(0.0, alignment) * thermal_err  # max() 硬编码「接近=好」
# → 注入 CirculationProportionCircuit → 影响 DA
```

**类别**: SEMANTIC_MATH + DIRECT_INJECT + GOAL_HARDCODED  
**影响**:
- DA 奖励信号被 Python 向量点积污染，整个 DA 三因子学习失效
- HC-005 + HC-006 共同作用：两套平行 Python 系统同时驱动 yaw 和 DA，STDP 只是附带跟随
- 无法判断 STDP 权重变化是「学到行为」还是「被 Python 推动而被动更新」

**V2.0 修复**: 删除此代码块；接近信号应从 front/back patch relay 激活差异中物理涌现

### HC-007: extra_axes 直接注入 Encoding（热觉 STDP 永久残废）⚠️

```python
# hebbian.py ~547-561

    enc.step(tonic_val * 5.0, dt)   # 直接注入，gain=5.0 无 BIO:，无 SynapticBundle
```

**类别**: DIRECT_INJECT + SEMANTIC_MATH  
**影响**:
- 热觉（therm）及所有 extra-axis 信号在整个项目生命周期内没有第一跳可塑性
- STDP 无法在 therm→enc 边界学习（无 Memristor，无 pre/post trace 跨 Bundle 传播）
- Xin 残差无法在此处累积，结构生长（sprout/prune）对热觉路径盲目
- 所有热觉驱动的「权重分化」报告均描述的是 enc_to_col、col_to_mot 层的间接效应，不是感觉转导层的学习

**V2.0 修复**: 创建 `bundles_extra_to_enc`（BundleConfig），synapse_gain=5.0 移入 BundleConfig，STDP 正常工作

### HC-008: HairCell activation 和 STDP trace 被 Ca²⁺ 覆盖 ⚠️

```python
# vestibular/chain.py ~351, 354-357

hc.pre_trace = (hc.pre_trace * decay) + hc.release_rate   # STDP trace 被替换
```

**类别**: DIRECT_INJECT  
**影响**:
- HC 神经元 STDP 每步以 Ca²⁺ release_rate 覆盖，而非膜电位动态
- 前庭 STDP 在 MET→HC 边界基于错误信号，导致前庭方向权重偏差
- 与 HC-002（全对全 soma_to_da）叠加，共同解释了 wR-wL 方向持续错误

**V2.0 修复**: 创建 ReleaseNeuron（TYPE:BIO, IHC active zone），通过 SynapticBundle 连接 HairCell

### HC-009: thermoreceptors.step(T) 直接注入 + noci 跨模态融合 ⚠️

```python
# somatosensory/chain.py ~345, 357-360
self.thermoreceptors[pid].step(T, dt)   # L0 感觉边界违规，无换能束
noci_total = abs(dT) * NOCI_DT_GAIN + damage * 10.0   # TRPV1/TRPA1 在 Python 融合
```

**类别**: SEMANTIC_MATH + DIRECT_INJECT + GOAL_HARDCODED  
**影响**:
- 热觉信号路径的最上游（感觉边界）即违规，无法在此处建立 STDP
- `abs(dT)` 抹除温度变化方向信息（升温 vs 降温应有不同行为含义）
- NOCI_DT_GAIN=200 和 damage×10.0 是任意比例，无 BIO: 推导

**V2.0 修复**: 创建 `transducer_env_to_thermo_{pid}` 换能 SynapticBundle（gain=BIO 推导值）

### HC-010: AutomaticGainControl 每步覆盖 STDP 动态 ⚠️

```python
# compensation.py ~155-203
gain_t = K / (1.0 + activity_ema / target_activity)  # target_activity=1.0
neuron._membrane.charge *= gain_t                     # 每 dt 覆盖所有神经元
```

**类别**: GOAL_HARDCODED + SEMANTIC_MATH  
**影响**:
- base_gain=20 是 Turrigiano 2008 生物范围（1.5-2×）的 10-13×，属于超生物增益
- tau_agc=0.1 (100ms) vs 生物稳态塑性时间尺度（小时-天），时间压缩 ~10^6×
- AGC 在全局每步覆写 STDP 的结果，使学习效果变成 AGC 和 STDP 的混合体，无法分离

**V2.0 修复**: 完全删除 AutomaticGainControl；稳态从权重衰减 + PowerRail 能量限制自然涌现

### HC-011: shadow motor 分配 if/elif 字符串匹配 ⚠️

```python
# shadow_sandbox.py ~243-255
if axis == 'yaw':    mot_assignment[axis] = 'x'
elif axis == 'pitch': mot_assignment[axis] = 'y'
```

**V2.0 修复**: 删除 mot_assignment，改为全 col→mot 稀疏连接（all axes × 3 motors, w=0.001）

### HC-012: world.gradient_at() 提供 DR5 特权信息 ⚠️

```python
# world.py ~204-217
def gradient_at(self, pos, eps=0.5):
    dT_dx = (T(x+eps) - T(x-eps)) / (2*eps)  # 全局梯度计算，电路无法访问
    return [dT_dx, dT_dy, dT_dz]
# exp_phase5_*.py:
DR5 = dot(world.gradient_at(pos), body.velocity)  # 使用特权信息判断涌现
```

**类别**: SEMANTIC_MATH  
**影响**:
- DR5 benchmark 本质上是「Python 计算热趋性」，与 HC-005/HC-006 构成三重自验证
- 所有 Phase 5/6/7/8 的 DR5 PASS 记录不能作为热趋性涌现的证据
- `thermal_gradient_dot_velocity` 存入 MotionState（HC-018），有被行为门控消费的风险

**V2.0 修复**: 重命名为 `_gradient_diagnostic()`；DR5 改用 patch 温差（T_front - T_back）

## 七、实验结论重评

| 实验 | 历史结论 | 重评结论 | 失效原因 |

| Phase 5 DR5≈90% | 热趋性涌现 | 无效 | HC-005 + HC-006 + HC-012 三重污染 |
