## 一、任务背景

用户提供《基础生成元构建总纲——(ξ/r≺/r→/rρ) 架构与实施边界》，要求：

1. 评估该方案是否可采纳；
2. 将其**同时应用到运动状态和温感**——经与用户确认，含义为**双轨并行**（温感轨 + 运动轨各自独立走一遍 Phase 0～4，不建跨模态 Bundle），而非让 r≺/r→/rρ 跨模态读取"温度变化是否先于运动"这类关系（后者被排除，因其超出方案 Phase 4 明确划定的边界——方案 Phase 4 仍不接 Motor）；
3. 运动侧的 ξ 源选取存在歧义（温感侧已有 64 条 warm/cool 尖峰 collector 作为现成 ξ，运动侧没有对应的现成结构），需专项路线分析。

本报告分两部分：**方案评估**（§二）+ **运动侧 ξ 源路线分析**（§三）。不含代码改动——Phase 0 的具体实施是后续独立报告。

## 二、方案评估

### 2.1 方案定义回顾

三类关系生成元，全部读取底层 ξ 采集器，全部终止于 Collector（Phase 4 仍明确不接 Γ/Motor/Shadow/TOPR/Xin/STDP/DA/CPC）：

| 生成元 | 定义 | 结构 |
|---|---|---|
| r≺（时间关系） | Ω≺[ξₐ,ξᵦ] | 双向历史痕迹耦合（谁先谁后） |
| r→（方向关系） | Ω→[ξₐ,ξᵦ,πₐ→ᵦ,πᵦ→ₐ] | 生成元间双向结构传播，最小三节点链 ξ₁↔ξ₂↔ξ₃ |
| rρ（占比关系） | (ρₐ|ab, ρᵦ|ab) | 共享池 + 分流抑制的占比近似 |

### 2.2 优点（与项目规范高度一致，建议采纳）

| 维度 | 评价 |
|---|---|
| 结构优先、零语义硬编码 | 完全符合 RULES.md /「Structure-First」：禁 `sign()`/点积/Python 除法，方向从结构涌现 |
| 只用已有组件 | 明确禁止新造 `DelayLine`/`RatioDivider`/`DirectionOperator` 类，强制复用 Neuron/SynapticBundle/Collector |
| Phase 门控 + 全量回归 | 每阶段专项探针 + 完整回归双通过才进下一层——与刚完成的温感 Ω 层节奏一致 |
| 终止于 Collector | 不接下游，回归 21/21 不受冲击（Ω 层同样策略：collector 神经元排除出 census） |
| 已吸取历史教训 | 显式区分「纯延迟 vs RC 痕迹」、用 `synapse_gain=-1.0` 实现抑制（Memristor 权重非负） |

### 2.3 落地前必须处理的隐患

**1. 「ξ」一词二义性（关键）。**
方案里的「ξ Collector」实指前庭12/感温64的**尖峰特征检测器**（sensory feature），而代码里 `Xin=|ξ|` 特指 `BundleConfig.xin_tension`（`nexus_v1/circuit/bundle.py:44`，`compute_xin()` 在 `bundle.py:559-628` 产生的 PI 预测残差）。二者**不是同一个东西**：

```
方案口径的 ξ = 尖峰特征检测器输出（前庭12/感温64）——本质是感觉信号
代码口径的 ξ = xin_tension = PI(预测 − 实际)          ——本质是预测残差
```

这对温感轨没有影响（温感轨的 64 warm/cool collector 本来就是方案口径的 ξ）；但对运动轨会造成 ξ 源歧义——运动侧没有现成的「尖峰特征检测器」，只有连续标量残差（efference error / ν_xyz）和 Bundle 级 xin_tension。详见 §三。

**2. r→ 与现有温感 Ω 层不可混淆。**
温感 Ω 层的 6 方向 collector（`variant_adapter.py:1791-1908`）是**预设方向模态**——由 `compute_coupling_weights()` 的 cos² 几何在构造期硬接入权重（`skin_network.py:60-105`）。而方案的 r→ 是**生成元之间的双向结构传播关系**（ξ₁↔ξ₂↔ξ₃ 最小三节点链，验证"传播方向"本身而非预设方向）。方案文档第 115 行已自行声明这一区别——落地时必须新建三节点链结构，不能把已完成的 Ω 层直接当作 r→ 交差。

**3. rρ 是消除硬编码的机会。**
运动侧 `MotionState.polarization = max(|ν_i|)/Σ|ν_i|`（`variant_adapter.py:2162-2168`）是 **Python 直接算的占比**——`sum_abs = sum(abs_nu); ms.polarization = max(abs_nu) / sum_abs`——这正是方案 rρ 应该结构化替代的对象。这是把 rρ 应用到运动侧的最强理由，且验收标准与方案 Phase 3 的"输入占比排序正确 / 交换输入则交换输出 / 近似互补"完全对应。

**4. RC 时间尺度必须逐生成元重标。**
温感 Ω 层的血泪教训（详见关联报告）：新聚合层复用旧电容常量 `capacitance=0.5`（xi 层设计），因上游是阵发性（burst-decay，~10-15 步）而非持续输出，导致 `dV=I·dt/C` 单步增益太小，膜电压永远够不到 v_peak 一半，**Ω 层完全不发放**。修复 = 独立设定 `_OMEGA_ENSEMBLE_CAPACITANCE=0.05`（xi 层的 1/10）、`_OMEGA_COLLECTOR_CAPACITANCE=0.002`（ensemble 的 1/25）。

**结论对本方案的约束**：r≺/r→/rρ 每个生成元都必须走一遍 Phase 0 的峰值/衰减/静息探针独立重标电容常量，**禁止**复用 ξ 层或 Ω 层已标定的常量。

**5. census / T4.1 保护。**
新 collector 神经元必须**排除出** `get_all_neurons()`（`variant_adapter.py:4279-4290`，避免稀释 `energy_per_neuron` → 破坏 T4.1 col→motor STDP 选择性——与 D1/satiety 排除同一理由）；bundles 则**必须进** `get_all_bundles()`（`variant_adapter.py:4381-4396`，供 Noether/Xin/熵账本追踪）。方案 census 要求已覆盖此原则，但落地时需显式写死。

### 2.4 评估结论

**方案方法论可直接采纳。** 温感轨基本无障碍（ξ 源、Collector 范式、RC 标定流程均有 Ω 层先例可循）；运动轨需先解决 ξ 源定义歧义，见下节。

## 三、运动侧 ξ 源路线分析报告

### 3.1 已核实的关键代码事实

**事实 1：Bundle 只能读取神经元的三种输出之一。**
`SynapticBundle._propagate()`（`bundle.py:243-256`）：

```python
if src.config.spiking and hasattr(src, '_calcium_integrator') and src._calcium_integrator is not None:
    a_src = src.calcium_rate      # spiking + CRI
elif src.config.spiking:
    a_src = src.pre_trace         # spiking（EPSP-like 时间展宽）
else:
    a_src = src.activation        # 非 spiking（瞬时值）
```

**源必须是一个 `Neuron` 对象**——这是硬约束，不存在绕过方式（方案本身也禁止"绕过 Bundle 的私有膜电位读取"）。

**事实 2：`xin_tension` 不是神经元属性，是 `BundleConfig` 上的裸 float。**
`bundle.py:44`：`xin_tension: float = 0.0`，由 `compute_xin(dt)` 在 `bundle.py:559-628` 每步更新（PI 形式：`ξ(t+dt) = ξ(t)·exp(−dt/τ_I) + R(t)·dt`）。它不挂在任何 Neuron 上，**Bundle 的 `_propagate()` 无法读取它**——因为 `_propagate()` 只遍历 `self.sources`（Neuron 列表），不会去读别的 Bundle 的 config 字段。

**事实 3：运动侧已存在"残差→神经元"的转换范式，且已被项目接受。**
`circuit/decision_adapter.py:270-275`（T-080 决策电路 Phase B）：

```python
_i_err_dT   = self.pred_dT.activation   - _dT_actual
_i_err_domg = self.pred_domg.activation - _domg_actual
self.err_dT.step(_i_err_dT, dt)      # 残差作为电流注入，产生可读 activation
self.err_domg.step(_i_err_domg, dt)
```

这证明"预测残差 → 注入专用误差神经元 → 变成可被 Bundle 读取的 activation"是项目已验证、已落地的合法结构（非新造组件，只是复用 Neuron.step() 的电流注入接口）。

### 3.2 三条候选路线对比

| | 路线1：复用运动神经元 | 路线2：新建运动 ξ 采集层 | 路线3：复用 xin_tension |
|---|---|---|---|
| ξ 源 | `move_x/y/z`、`yaw_ccw/cw` 的 `pre_trace` | efference error（`variant_adapter.py:2174-2176`）/ ν_xyz 包成误差神经元 | 各运动 Bundle 的 `xin_tension` |
| 语义 | 运动**特征/状态**（非残差） | 运动**预测残差**（真正意义上的 ξ） | 代码定义的**真 ξ**（PI 残差） |
| 结构可行性 | ✅ spiking 神经元，`pre_trace` 直接可读，零新结构 | ⚠️ 需建误差神经元层，但范式已存在（err_dT/err_domg，见事实3） | ❌ float，Bundle 无法读取（见事实2） |
| 与方案 ξ 口径一致性 | ✅ 与温感 64（同为特征检测器，非残差）同口径 | ✅ 最贴近方案"ξ=预测残差"的原始定义 | ✅ 定义上最贴近，但… |
| 硬编码风险 | 无（走 `pre_trace`，标准 Bundle 通路） | 低（pred−actual 是差分放大器结构，同 yaw ccw−cw 已被接受的先例边界） | **高**：要读到它必须绕过 Bundle 直接访问另一 Bundle 的 config float，违反方案明文禁止的"绕过 Bundle 的私有膜电位读取" |
| 工作量 | 最小 | 中（部分可复用 err_dT/err_domg） | — |

### 3.3 关键结论：路线3 不能独立成立

用户最初倾向"路线1和3都可以"。核实后需要修正：

> **`xin_tension` 是裸 float，不是神经元属性**。要把它接入 r≺/r→/rρ 生成元（这些生成元的 Bundle 输入端只认 Neuron），**必须先造一个神经元把这个 float 作为电流注入、转换成 activation**——而这个转换步骤，其结构与 §3.1 事实3 的 err_dT 完全相同，也就是**路线2 本身**。
>
> 因此：
> - **"naive 路线3"**（直接读 float，绕过 Bundle）= 违反方案明令禁止的"绕过 Bundle 私读"，不可采纳；
> - **"proper 路线3"**（先建神经元转换 float → activation，再接 Bundle）在结构上**塌缩成路线2**，不是独立的第三条路线。
>
> 真正互斥的选择只在 **路线1（运动特征，零新结构）** 与 **路线2（运动残差，新建误差神经元层）** 之间。

### 3.4 推荐

**首轮 Phase 0～4 走路线1**：

1. **口径对称**：两轨都以"底层尖峰特征检测器输出"为 ξ（温感=64 warm/cool collector 的 spiking 输出，运动=move_x/y/z + yaw_ccw/cw 的 spiking 输出），方法论完全平行，不需要为运动轨单独发明一套"什么是 ξ"的论证。
2. **零新结构，回归风险最低**：直接复用已存在、已在 census 中的 spiking 神经元，Phase 0 不引入新的膜/电容参数。
3. **物理意义明确**：`move_x/y/z`、`yaw_ccw/cw` 是真实物理运动信号，r≺（谁先动）、r→（激活如何在轴间/左右传播）、rρ（轴间占比）都有清晰的物理对应。
4. **rρ 首轮即可替代 `polarization` 硬编码**（§2.3 第3点），是本轨最直接的可交付收益。

**路线2 作为独立的后续升级**（非首轮，不与首轮同时引入）：等路线1 验证方法论跑通、Phase 0～4 全部通过后，再启动一个新的 Phase（可编号为运动轨 Phase 5 或独立子方案），复用 `err_dT`/`err_domg` 范式，把 efference error 包装为真正的运动残差 ξ 采集层，使运动轨与方案"ξ=预测残差"的原始定义完全对齐。一次只引入一处新结构，避免同时调试两套未标定的电路。

**路线3（naive）不采纳**；若后续确实需要接入 `xin_tension` 语义，等价于执行路线2。
