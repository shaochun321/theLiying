## 三、Motor → Muscle → Body（运动物理层）

### 3.1 Motor 神经元配置（hebbian.py:228-309）

```
neuron_id: "motor_{move_x/y/z}"
capacitance=0.3  (τ_m = 1.5ms)

spiking=True
use_fatigue=True  (FatigueCapacitor，防过载)
bc_current=0.01  (微弱基础驱动)
```

### 3.2 Motor → Muscle 转换（variant_adapter.py:1339-1358）

```python
# motor activation → raw force
force_i = motor_neurons[name].activation × muscle.gain (默认 0.1)
forces_raw = [force_x, force_y, force_z]
```

**重要：Motor 输出不直接控制 yaw 转速。**  
`move_x/y` 通过坐标变换影响线性加速度，yaw 由独立的脊髓弧控制（见第四节）。

### 3.3 Body frame → World frame 旋转矩阵

```python
cos_yaw = cos(body.yaw); sin_yaw = sin(body.yaw)
forces_world_x = forces_body_x × cos_yaw - forces_body_y × sin_yaw
forces_world_y = forces_body_x × sin_yaw + forces_body_y × cos_yaw
forces_world_z = forces_body_z
```

### 3.4 Body 物理步进（world.py:427-449）

```python
a_i = (forces_i - friction × velocity_i) / mass
acceleration_i = a_i   # ← 记录，反馈给耳石
velocity_i += a_i × dt
position_i += velocity_i × dt
# 环形边界（position ∈ [0,100]）
```

## 四、Yaw 转向：独立 D1 脊髓反射弧

**这是理解运动控制的最关键结构——yaw 转向完全独立于前庭 L1-L6 主链。**

文件：`variant_adapter.py:726-900`（定义），`1603-1631`（执行）。

### 4.1 信号流

```
温感 relay（SomatosensoryChain）
  ↓ [frozen, w ≈ 6.67e-5（慢分量）]
slow_relay（低通，τ≈15s，去除 tonic 背景）
  ↓ 差分（phasic = relay_act - slow_relay_act）
phasic_left / phasic_right（捕捉温度上升沿）
  ↓ D1 STDP（DA-gated, eligibility_trace）
spinal_ccw / spinal_cw（脊髓转向中间神经元）
  ↓ [frozen, w=0.200, sg=1.0]        ← T-071: 0.100→0.200
yaw_ccw_neuron / yaw_cw_neuron
  ↓
_yaw_torque = (yaw_ccw.act - yaw_cw.act) × 0.1
  ↓
body.apply_yaw_torque(torque, dt)
  ↓
body.angular_velocity += torque/inertia × dt × exp(-γ × dt)
```

## 五、反馈闭环（Body → 前庭）

### 5.1 角速度 → 半规管（yaw 完整闭环）

```
body.apply_yaw_torque(torque, dt)
  → body.angular_velocity 更新
  → Cupula 高通滤波（IIR, τ=4000步, variant_adapter.py:1588-1591）
  → mechanical_inputs['yaw'] = cupula_theta × 300000
  → MET yaw 激活 → 前庭主链
```

物理闭环延迟：1 步（cupula 的前一步状态）。

### 5.2 线性加速度 → 耳石（位移闭环）

```
body.step(forces) → acceleration 计算（world.py:427-439）
  → mechanical_inputs['oto_*'] = acceleration × 500（variant_adapter.py:1569-1571）
  → MET oto_x/y/z 激活 → 前庭主链
```

## 六、complete 步序（每步 step() 的执行顺序）

```
1. 计算 mechanical_inputs（耳石/半规管/温觉 patch）
2. VestibularChain.step(mechanical_inputs)  → L1-L4 更新
3. SomatosensoryChain.step(skin_temps)      → relay/phasic 更新
4. HebbianCircuit._propagate_bundles()      → L4-L6 bundle 传播
5. D1 脊髓弧传播（phasic→spinal→yaw）
6. Yaw torque 计算 + body.apply_yaw_torque()
7. Motor → Muscle → Body 力学更新
8. Body.step(forces) → 位置/速度/加速度更新
9. World.step() → 热场更新
10. 下一步开始，cupula 读 body.angular_velocity
```

## 七、结构性缺陷

### 缺陷 1：move_x 多源汇聚——加速度与转向信号混叠

move_x（前进轴）的驱动源（全部 KCL 求和）：

| 来源 | 增益 | 机制 |
|------|------|------|
| col_yaw → move_x | SG=10.0, w≈0.4 | VOR 主链 |
| therm_front → move_x | SG=+10.0, w≈0.1 | 前热→前进（差分） |
| therm_back → move_x | SG=-10.0, w≈0.1 | 后热→后退（差分） |
| spinal_fwd → move_x | w=0.2, sg=1.0 | D1 前进弧 |
| col→motor_cross | SG=0.7, w≈0.05 | 交叉弱束 |
| vital_oscillator | — | 基础运动 |
| C.04 deviation 反射 | gain=1.0 | 稳态偏差直注 |

**后果：** 当体向前运动（加速度增大→oto_x↑→col_oto_x↑），col_oto_x→move_x 与 therm_front→move_x 在同一神经元上叠加，无法区分"感知到向前运动"和"感知到前方更热"。运动传感器信号污染热感知。

### 缺陷 2：温觉 DA 学习淹没前庭 VOR 学习

- 温觉 col→motor：eligibility_trace + DA-gated LTP，lr=0.05，权重可快速分化
- 前庭 col→motor：标准 STDP（无 eligibility），lr=0.05，但无 DA 门控 → 学不到"何时放大"
- 结果：热趋性学习完成后，VOR 精调几乎没有空间

### 缺陷 3：Cupula 增益 300000 的稳定性风险

- T-076a 校准确保"MET_yaw 峰值≈0.32"，但这依赖特定实验条件下的增益匹配
- 在 dt=1.0 时，cupula 高通滤波的 α=dt/(dt+4000)=1/4001，每步角速度贡献仅 0.025%，但乘以 300000 后净增益仍=300000/4001≈75
- 若脊髓弧产生持续转矩（spinal_ccw 持续激活），cupula 在 dt=1.0 下几乎不会产生有效的负反馈（τ 被放大 1000×），可能导致发散

### 缺陷 4：Col→Motor yaw 通路（L5→L6）与 D1 脊髓弧功能重叠

前庭主链的 `col_yaw→move_x`（SG=10.0）理论上控制前进；但 yaw 由 D1 弧独立控制（不经 col_yaw→move_x）。问题在于：**两者都写进 move_x**，前庭的 col_yaw 信号（本应编码水平角速度）却通过 move_x 影响前进运动，而不是直接影响 yaw 转速。这是 VOR 通路的语义错位。
