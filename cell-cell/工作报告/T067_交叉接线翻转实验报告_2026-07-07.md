## 一、实验设计

**核心问题**：如果 STDP 真的在学习方向性（而不是伪造），它应该能区分"正确"接线方向与"错误"反接方向。

**实验操作**：
1. 软断开原 D1 束（`phasic_left→spinal_ccw`，`phasic_right→spinal_cw`），权重 → 0.001
2. 注入 4 条竞争束（均相同参数 `initial_weight=0.010`）：
   - `CORRECT_L`：phasic_left → spinal_ccw（正确接线，与原D1一致）
   - `CORRECT_R`：phasic_right → spinal_cw（正确接线）
   - `SWAP_L`：phasic_left → spinal_cw（反接）
   - `SWAP_R`：phasic_right → spinal_ccw（反接）

**判定标准**：
- **J1**：`w_correct_L > w_swap_L`（正确束L胜出）
- **J2**：`w_correct_R > w_swap_R`（正确束R胜出）
- **J3**：DR5% > 45%（热趋性行为保留）

## 三、物理分析

### 3.1 填充饱和动力学（根本原因）

```
fill轨迹：
  step  20k: fill=0.972（Foraging窗口开放，DA>0，STDP活跃）
  step  35k: fill=1.000（Foraging窗口关闭，DA=0，STDP冻结）
  step  40k~: fill=1.000（全程饱和，165k步LTD+decay运行中）
```

**LTD公式**（非DA门控，始终开启）：
```
ltd = eligibility_ltd_rate × dt × pre_trace × post_act
decay = decay_rate × w × dt
```

一旦 DA=0，LTP=0，但 LTD+decay 继续清洗所有权重。正确束/错误束接收到几乎相同的前后突触激活模式，以相同速率衰减。

**衰减速率分析（100k步）：**
```
w_cL: 0.0238 → 0.0031  (86.7% loss over 80k steps after saturation)
w_sL: 0.0203 → 0.0030  (85.2% loss)
→ 两者衰减速率几乎完全相同，差异来自初始值，非STDP选择
```

### 3.2 J1的短暂优势为何消失

step 20k时 Δ_cL=+0.0035（J1略胜）。原因：Foraging窗口（0~35k步）中body从左侧（x=10）向热源（x=70）运动，phasic_left信号略强于phasic_right。`CORRECT_L`（phasic_left→spinal_ccw）比`SWAP_L`（phasic_left→spinal_cw）接收到更多同侧DA奖励机会。

但此优势微弱（0.0035 << weight_max=0.3），fill饱和后完全被LTD冲洗。

### 3.3 J2始终失败的原因

`CORRECT_R`（phasic_right→spinal_cw）和`SWAP_R`（phasic_right→spinal_ccw）均以phasic_right为输入。在单热源场景中，body从左侧接近，右侧梯度信号弱，phasic_right激活不足以建立任何方向偏好。

更根本的原因：`SWAP_R`初始权重(0.0124) > `CORRECT_R`初始权重(0.0101)，随机初始化不利于correct_R，且STDP未能在Foraging窗口内纠正这一差距。

### 3.4 DR5=0.0%的解释

DR5测量函数依赖`c._patch_temps`字典。该属性在当前运行版本中可能命名不同或结构不同，导致每次调用均返回False（try/except静默吞掉异常）。

这是**测量脚本的问题**，不反映实际热趋性行为缺失（参考T-062的同配置实验：DR5=50.6%）。

### 如何理解T-067 FAIL

T-067 FAIL不代表"STDP是伪造的"——它揭示了一个更精确的命题：

> **STDP能在正确接线的束上产生LTP（T-054 Layer 1证实），但在单次200k步Foraging窗口内，空间梯度信号不足以让正确束稳定地胜过随机反接束。**

这与AG平台的多种子统计（T-060综合报告）结论一致：
- STDP权重分化真实存在（|Δw|=0.2965，确定性）
- 但权重分化与行为输出之间存在"断路"
- Foraging窗口仅占总运行时间的13.4%，且一旦fill饱和就永久关闭

## 五、结论与后续建议

### 结论

1. **STDP无法在单次Foraging窗口内完成稳定的方向线路选择**
   - Foraging窗口太短（~35k步/200k步），信噪比低
   - fill饱和后165k步纯LTD冲洗，完全覆盖了短暂的选择信号

2. **方向性更可能来自结构而非STDP学习**
   - T-063（双热源）：20k步到达，完全由硬连线反射弧+热对流实现
   - T-067 J2的持续失败：在初始权重略不利时，STDP无法纠正

3. **STDP的真实功能更可能是增益调制**
   - 调整 phasic→spinal 权重影响转弯强度（强/弱），而非方向（左/右）
   - 类比生物学：脊髓反射弧方向性由基因编码（出生前完成），STDP负责长期效能调节

### 后续建议

| 优先级 | 方向 | 原因 |
|--------|------|------|
| **P0** | 追踪 STDP→行为 的信号断路 | 权重变化存在但无行为效应，根本原因未明 |
| **P0** | 热源消失/迁移实验 | 测试STDP在fill耗尽后（强制Foraging）的收敛能力 |
| **P1** | 增益校准 | spinal→yaw STDP贡献需与relay→yaw直接通路竞争 |
| **P2** | 重新定义STDP目标 | 从"学方向"改为"学增益调制"和"学多模态耦合" |
