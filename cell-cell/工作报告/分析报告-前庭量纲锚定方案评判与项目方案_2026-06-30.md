## 二、逐项评判

### 2.1 初步方案

**正确的部分：**

1. **扫描实验优先**（§2）：在改任何参数之前先测量当前系统的输入-输出特性曲线——这是正确的科学方法。不测量就猜参数是 DEG-017 的成因。

2. **物种选择**（§3）：C57BL/6 小鼠。文献数据最丰富，选择合理。Goldberg 2000、Lasker et al. 2008、Fettiplace & Kim 2014 均为该领域标准文献。

3. **反推锚定的思路**（§4）：从可测量的 Aff 发放率出发，结合文献灵敏度反推物理单位，是可操作的。不需要直接测量生物样品，只需要模型扫描 + 文献数字。

4. **后续推导链**（§5）：从锚定点推导 gm → HC 增益 → synapse_gain → α 的链条结构正确，方向由外向内。

**关键错误（会违反 RULES.md）：**

> **S4："更新 `chain_v2.py` 参数"；S5："更新 `hebbian.py` 参数"**

`chain.py`、`chain_v2.py`、`hebbian.py` 均是 mother code。RULES.md 明确：**不修改 mother code 添加特性**，新参数通过继承/适配器接入。

`synapse_gain=16.0` 在 `hebbian.py:349` — 如果直接改这里：
- 会影响所有继承 HebbianCircuit 的实验
- 可能使 21/21 PASS 退化（DEG-004 历史：Enc 无法过阈的根因就是增益不足）
- 无法独立回滚

**正确做法**：锚定完成后，在 VariantCircuit（或实验脚本）层通过覆写 `BundleConfig.synapse_gain` 测试新值，不动 `hebbian.py`。

**另一个问题——"1 步 = ? 秒"未显式约定**：

初步方案默认 `dt=0.001` 对应 1 ms。这在项目中确实是约定，但需要显式写入锚定假定，否则 FIFO 延迟（2 步 = 2 ms）等时域参数的物理解释无法闭合。

### 2.2 补充文档

**全部采纳的部分：**

1. **§4.0 锚定假定的显式声明**：`1.0 无量纲 = 1.0 deg/s` 作为起点，通过自洽性检验验证。这是方法论上的正确处理——先定义，再验证，而不是等"确定后再写"。

2. **§2.1.1 频率匹配**：扫描实验使用 2 Hz（与 Lasker et al. 2008 一致），而不是实验脚本当前的正弦频率。这一点必须执行，否则反推结果无法与文献对比。

3. **§2.1.2 同构性检验**：yaw/pitch/roll 是否可用同一模板。代码层面三者共用同一 `chain.py` 配置，理论上是同构的，但要用数据确认——扫描结果三条曲线若斜率差 < 5%，可合并为一个 `VestibularPrimitive` 模板。

4. **§5.1 synapse_gain 反推公式**：
   ```
   synapse_gain = V_Enc_target / (f_Aff × Q_spike × R_Enc × N_conv)
   ```
   代入示例（f_Aff=50 Hz，N_conv=10）得 2.4，与当前 16.0 差 7×。这个差距的来源是 N_conv 假设——实际模型 N=2，不是 10。代入 N_conv=2：
   ```
   synapse_gain = 0.30 / (50 × 5e-5 × 5.0 × 2) = 12.0
   ```
   更接近现有 16.0，误差来自 Aff 实际发放率低于 50 Hz（实测约 2 Hz）。这说明 16.0 是为了补偿 2 Hz 发放率而不得不提高的，公式是自洽的。

5. **S3.5 粒度决策**：用扫描数据决定是"统一模板"还是"独立建模"——这个决策点是合理的工程门。

**需要修改的部分：**

S7"全链路校准"的目标文件仍然是 `chain_v2.py` / `hebbian.py`。按上文原则，需改为通过 VariantCircuit 覆写。

### 2.3 ν框架文档

**哪些是正确的：**

1. **ν 的物理定义**（§2.2）：ν = d/dt(½C_ξξ²) = Xin 张力储能的时间导数，量纲是功率（W）。这在理论上是对的。Xin 张力（|pred - actual|的漏积分）已在项目中实现（`TOPRXinLedger`）。ν 就是这个积分量的功率导数。

2. **探索态/固化态的物理判据**（§2.2）：ν > 0 → 张力增长 → 探索；ν < 0 → 张力降低 → 固化。这给 sprout/prune 提供了热力学依据，比当前基于 Xin 幅度阈值的判据更基本。

3. **带宽作为涌现量**（§6）：Bandwidth ~ ν/E_total，带宽不独立设定而由能量储备和张力共同决定。这是 DEG-015/016/017 的根本解法方向——如果带宽从结构中涌现，就不需要手动设定 synapse_gain 的数值。

4. **短连接串联的能量最优性**（§5）：长连接功率损耗高，驱动拓扑演化优选短连接。这是 Xin 驱动 sprout 的物理意义。

**哪些现在不实施：**

P1→P4 roadmap（ν嵌入TSI账本 → 元构建定义 → 短连接串联 → 带宽校准）属于 **Phase 2+ 基础架构**。原因：

- 当前没有 `ν_k` per-element 的数据结构
- TSI 账本存在于 `NoetherProbe` 但未连接到 ν
- Shadow 层计算自由能/收缩，但不输出 ν 
- 实现完整 ν 框架需要在 hebbian.py/variant_adapter.py 主链路上加新计算路径 → 仍然是 mother code 修改

**保留 ν 框架作为路线图文档**，不进入当前 sprint。

## 三、项目实际执行方案

### 整体策略

### Phase 1：扫描实验（立即可执行，约 1 天）

**目标**：测量当前系统的 Aff 发放率 vs 输入幅度曲线，作为量纲锚定的数据基础。

**实验设计**：`nexus_v1/tests/exp_vest_calibration_scan.py`

```
扫描协议：
  频率：2 Hz（对齐 Lasker et al. 2008）
  幅度：0.5, 1.0, 1.5, ..., 10.0（每轴 20 个点）
  每点运行：5000 步（末尾 2000 步取平均发放率）
  轴：yaw, pitch, roll, oto_x, oto_y, oto_z（共 6 × 20 = 120 次测量）
  环境：隔离 VestibularChainV2，不启动 VariantCircuit 全系统
```

**输出**：
1. 每轴的 `{amplitude: [f_reg_Hz, f_irr_Hz]}` 标定表（CSV）
2. 同构性判断：yaw/pitch/roll 斜率差 < 5% → 同构；oto_x/y/z 同理
3. 当前工作点的精确值：`oto_x=6.0` 对应 `f_reg=? Hz`

**关键约束**：
- 纯读取，零写入，不改任何神经参数
- 可以不连接 World/Body（只需前庭链路）

---

### Phase 2：锚定计算（Phase 1 完成后当天，纯数学）

**输入**：Phase 1 扫描数据 + Goldberg 2000 / Lasker 2008 文献灵敏度

**锚定假定（补充文档 §4.0 策略）**：

```
起始约定：1.0 无量纲 yaw = 1.0 deg/s（初始假定）

自洽检验：
  1. 从假定推导：在 1.0 deg/s 输入下，Aff 应发放多少 Hz？
     = 1.0 deg/s × 灵敏度(1.0 spikes/s/deg/s) = 1.0 Hz
  2. 对比扫描曲线：在 yaw=1.0 时，实测 f_reg = ? Hz
  3. 如果实测值 ≈ 1.0 Hz，假定自洽；若偏差 >2×，调整假定比例
```

**对 oto_x 做类似推导**（灵敏度 35 spikes/s/g）

**产出文件**：标定计算表，记录：
- 物理锚点：`1 无量纲 = ? deg/s 或 m/s²`
- 验证：反推 g_MET 是否在 24–60 pS/nm 范围内
- 当前工作点 `oto_x=6.0` 的物理量级

---

### Phase 3：UNIT 注释注入（Phase 2 完成后，纯注释）

在 `nexus_v1/vestibular/chain.py` 和 `nexus_v1/circuit/hebbian.py` 中，对关键参数加 `# UNIT:` 和 `# CALIB:` 注释，解释物理含义。

**例（chain.py MET 配置）**：
```python
gm=2.0,  # UNIT: [A/V·no-dim-input]; CALIB: with anchor yaw=1.0→0.35rad/s,
         # g_MET_eff ≈ 2.0 × K_mech corresponds to ~30 pS/nm (Fettiplace 2014 range)
```

**例（hebbian.py Aff→Enc bundle）**：
```python
synapse_gain=16.0,  # CALIB: engineering compensation for f_Aff=2Hz (target 50-100Hz,
                    # Goldberg 2000). Physically: with N_conv=2, f_Aff=2Hz, V_target=0.30,
                    # Q_spike=5e-5, R_Enc=5.0 → gain_bio=0.30/(2×5e-5×5×2)=300.
                    # Current 16.0 is valid working point; gap explained by
                    # Aff rate deficit (DEG-017). Do NOT change without full DR revalidation.
```

**约束**：纯注释，不改执行路径。21/21 PASS 不受影响。

### Phase 5（时序在 Phase 1-4 之后，非当前 Sprint）：ν 框架最小实现

ν 框架文档的核心贡献是定义了一个**可审计的功率流**结构。最小可实现的起点：

# 在 nexus_v1/ledger/ 下新建 nu_probe.py
