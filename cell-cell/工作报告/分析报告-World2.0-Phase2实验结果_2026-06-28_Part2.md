## 5. 行为轨迹分析（Phase 2 v3，k_conv=0.50）

### 5.1 三阶段轨迹

```
第一阶段：接近（步 0 → 70k）
  dist_surface: 22.42 → 14.65   ↓ 7.77 units
  yaw: 0° → 38.8°               旋转（对流引导转向）
  fill: 0.521 → 0.506           稳定，供能≈消耗
  w_front: 0.0099 → 0.0133      STDP 学习开始（+34%）
  w_brake: 0.0099 → 0.0108      对称增长（+9%）
  比值: 1.00 → 1.23             方向性偏置出现

第二阶段：平台期（步 70k → 130k）
  dist_surface: 14.65 → 19.16   开始后退（对流+STDP 未压过 Langevin）
  yaw: 38.8° → 64.8°            继续旋转（已偏离热源方向）
  fill: 0.506 → 0.310           缓慢下降
  w_front: 0.0133 → 0.0133      权重冻结（无新热觉信号→STDP 停止）
  w_brake: 0.0108 → 0.0107      权重冻结
  比值: 1.23 → 1.24             学习停止

第三阶段：能量崩溃（步 130k → 250k）
  dist_surface: 19.16 → 37.82   持续后退
  fill: 0.310 → 0.000           fill 清零
  yaw: 64.8° → 97.3°            body 面向背面（90°= 侧面，>90°= 背向）
  w_front: 0.0133 → 0.0129      轻微衰减（STDP 反向调？）
  w_brake: 0.0107 → 0.0103      轻微衰减
  实验在 250k 步提前终止
```

### 5.2 能量收支核算

| 距离区间 | 典型 mouth_intake/step | 代谢消耗/step（估计） | 净收支 |
|---------|----------------------|-------------------|-------|
| dist_surf < 15 | 0.000232 | 0.001/step | -0.00077 |
| dist_surf 15-25 | 0.000194-0.000355 | 0.001/step | -0.0006 |
| dist_surf > 25 | ≈0 | 0.001/step | -0.001 |

**关键发现**：即使在最近点（dist_surface=14.65），mouth_intake 仍远低于代谢消耗（约 23%）。这意味着 eta=0.15 仍不足以平衡代谢需求，fill 单调下降不可避免。

原因：圆柱热源温度场衰减快（Gaussian 分布），body 半径=6，圆柱半径=6，接触面积有限。口腔只能采集 front patch 的部分温度，而 front patch 在 dist_surface=14 时的温度约为 T_env+2.8，远低于 Phase 2 方案预估值。

### 5.3 偏转角分析

yaw 单调增加，最终达到 97°，导致 body 完全背向热源。这是对流力与 YAW_GAIN 相互作用的结果：

```python
# variant_adapter.py 中
apply_yaw_torque(delta_T_lr × YAW_GAIN)  # YAW_GAIN=0.1
```

当 body 靠近热源时，左右皮肤贴片温差 delta_T_lr 随方向不同而变化，产生转向力矩。问题在于 yaw 没有复位机制，旋转逐步累积，最终 body 背向热源且 STDP 无法学习矫正，因为偏转方向不走 bundle `therm_left/right→move_y`（已被冻结）。

## 6. 验收标准判定

### W10：dist_surface 减少 >5 单位

```
初始 dist_surface（Phase 1 参考）：~23.42（由初始位置 [75,35,25] 和热源 [50,50,25] 计算）
最小 dist_surface：14.65（步 70k）
减少量：8.77 units（> 5.0）
```

**W10：PASS** ✓

### W11：STDP 方向性权重比 w_front/w_brake > 2.0

```
最终 w_front：0.0129
最终 w_brake：0.0103
比值：0.0129 / 0.0103 = 1.252（< 2.0）

峰值比（步 70k）：0.0133 / 0.0108 = 1.231
```

STDP 有方向性偏置信号（前束比后束重 23%），但远未达到 2.0 目标。

**根本原因**：
1. 仅一次接近周期（约 70k 步），STDP 学习时间太短
2. 初始权重 0.01 ≈ 饱和权重 0.3 的 3.3%，从零学习到比值 2.0 需要多次接近
3. 接近后 body 偏转，热觉信号消失，STDP 学习停止（无输入）

**W11：FAIL** ✗（实测 1.25，目标 2.0）

### W12：500k 步全程 fill > 0.05

```
fill 在步 250k 降至 0.000（提前终止）
```

**根本原因**：能量供给速率（mouth_intake）无法覆盖代谢消耗，且 body 仅有一次接近热源的机会（约 70k 步），之后 fill 单调下降。

**W12：FAIL** ✗（fill=0 at 250k < 500k）

## 7. 根本原因综合分析

### 7.1 核心矛盾：单次接近-撤退循环

Phase 2 v3 的轨迹本质上是**单次接近-撤退循环**：

```
t=0:       body 远离热源（dist=22）
t=0~70k:   对流物理驱动接近（k_conv=0.5）
t=70k:     最近点（dist=14.65）；STDP 开始积累方向偏置
t=70k~:    Langevin 噪声 + yaw 偏转压过微弱 STDP 力，body 开始撤退
t=250k:    fill=0，实验终止
```

STDP 理论上正确运作（前束比后束重 23%），但在单次接近中积累的权重不足以在下次循环中改变轨迹。**需要多次接近循环**。

### 7.2 yaw 积累问题

`YAW_GAIN=0.1` 产生的转向力矩使 body 在 250k 步内偏转了 97°，完全背向热源。这是**无阻尼积分**行为：对流引起转向，但没有机制把 yaw 拉回 0°（面向热源方向）。

物理修复：
- 需要一个 yaw 恢复力（"前庭前庭反射" = 头部向前力矩）
- 或使用多个热源包围 body，从对称性避免偏转累积

### 7.3 能量预算误估

Phase 2 方案预估 eta=0.15 能在 dist_surface≈10 时平衡代谢消耗，但实测显示：
- 实际最近点 dist_surface=14.65（未到 10）
- 该距离处 mouth_intake/step ≈ 0.000232，为代谢消耗的约 23%
- 即使到 dist=10，供能速率预计也仅约 0.000400/step（估算），仍远低于 0.001/step 代谢速率

**结论**：当前热源场强度和口腔 eta 参数下，单热源能量模式无法维持正能量平衡。

## 8. Phase 3 改进方向

### 8.1 优先修复（必须解决）

**P3-FIX-01：多热源环绕配置**

将热源从单点改为 3 个 120° 分布：

```python
sources = [
    CylindricalHeatSource(center=[50,50,25], energy=8000, radius=6),
    CylindricalHeatSource(center=[30,70,25], energy=8000, radius=6),
    CylindricalHeatSource(center=[70,70,25], energy=8000, radius=6),
]
```

效果：
- body 无论朝向都能感受到热源（yaw 偏转不会导致完全失温）
- 接近任何一个热源都能获得能量
- 多次接近机会，STDP 积累更多学习周期

**P3-FIX-02：增大热源能量密度（eta 或 source energy）**

在当前参数下能量供给速率严重不足。两个选项：
- 选项 A：eta 从 0.15 提升至 0.50（激进）
- 选项 B：heat_source 温度场 peak_temperature 从默认提升 3-5×

选项 A 更简单，选项 B 更物理（改变温度梯度而非采集效率）。

**P3-FIX-03：STDP 学习率提升（eligibility_gain）**

Phase 2 方向性比值仅 1.25，70k 步接近期太短。建议：
- 将 STDP `eligibility_gain` 从默认值提升 3-5×
- 使 STDP 在单次接近中积累足够权重差异，以在下次接近中产生行为差异

**P3-FIX-04：yaw 恢复力（避免 body 背向热源）**

添加微弱的 yaw 恢复弹性：

```python
# variant_adapter.py 或 exp_world2_phase3.py
yaw_restoring = -0.001 * body.yaw  # 线性弹性恢复至 yaw=0
apply_yaw_torque(yaw_restoring)
```

这是物理的（弹性复位力），不是语义硬编码（仅让 body 倾向于面向初始方向）。

### 8.2 可选改进

| 改进 | 预期效果 | 风险 |
|------|---------|------|
| 多热源 120° 分布 | 解决 yaw 偏转导致失温 | 场干扰可能影响梯度感知 |
| eta 0.15→0.50 | 解决能量崩溃 | 可能掩盖真实热感觉能力 |
| eligibility_gain ×3 | 加快 STDP 学习 | 可能导致权重过快饱和 |
| yaw 弹性 | 防止偏转 | 略微"作弊"（不是纯物理涌现） |
| 预训练接近相（物理漂移先跑 50k 步） | 让 STDP 从已知近处开始 | 不测试从远处出发的真实能力 |

### 8.3 Phase 3 建议实验方案

```
Phase 3 目标：STDP 在多次接近循环中学习热觉趋向行为

参数设置：
  热源：3 × CylindricalHeatSource（120° 分布，energy=8000 each）
  eta：0.50（能量平衡）
  eligibility_gain：×3（加快学习）
  yaw 弹性：-0.001 × yaw（弱恢复力）
  k_conv：0.50（保持，已知 0.47 是临界值）
  步数：500k（全程）

接受标准（建议）：
  W13: dist_surface 最小值 < 12 units（更近接触）
  W14: w_front/w_brake 比值在第 200k 步达到 >1.5
  W15: fill 在全程 500k 步保持 >0.05
  W16: 至少 3 次 dist_surface < 15 的接近周期
```

## 9. 总结

| 方面 | Phase 2 发现 |
|------|-------------|
| **DIAG-1** | enc_therm ≥ 0.05、col_therm ≥ 1Hz，两者 PASS（需 5000 步预热）|
| **k_conv 临界值** | 0.47（实测），低于此值 body 永远漂离，STDP 无学习机会 |
| **STDP 启动** | 方向性学习有信号（比值 1.25），但单次接近周期不足以达到 2.0 目标 |
| **能量平衡** | 即使在最近点，mouth_intake 仅覆盖约 23% 代谢消耗 |
| **yaw 积累** | 250k 步内偏转 97°，导致 body 完全背向热源 |
| **Phase 3 方向** | 多热源 + 更高 eta + 更快 STDP + yaw 弹性 |

**Phase 2 总评**：物理基础扎实（W10 通过，体现真实接近行为），STDP 有启动信号（比值 >1.0），但单次接近周期+能量崩溃组合导致 W11/W12 失败。Phase 3 需解决「多次循环」和「能量平衡」两个核心问题。
