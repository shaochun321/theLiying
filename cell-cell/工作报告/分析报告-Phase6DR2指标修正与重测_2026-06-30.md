## 二、DR2 指标修正原因

### 原定义（错误）

```
DR2: Δx(200k) > 1.0
```

Δx 测量 body x 轴绝对位移。问题：该生物有六轴前庭驱动（yaw/pitch/roll + oto_x/y/z），body 在三维空间运动。x 轴位移可能因 y/z 方向同时运动而偏大或偏小，不能准确反映热趋向（靠近热源）的实际程度。

### 证据（Phase 6 P0 数据）

```
body 从 [50,50,50] 移动，热源在 [70,50,50]（纯 x 方向）
P0 结果@200k：Δx=+0.9636，3D 距离缩减=0.880
```

Δx(0.964) > 3D 距离缩减(0.880)，说明 body 同时在 y/z 方向漂移了约 1.87 units，部分抵消了 x 方向的接近量。Δx 指标**高估**了热趋向程度。

### 修正定义

```
DR2: 3D 距离缩减(200k) > 1.0
    = init_dist - dist(200k) > 1.0
    = 20.000 - dist(200k) > 1.0  →  dist(200k) < 19.0
```

3D 距离缩减直接测量 body 距热源的实际接近量，是热趋向的物理上正确的度量。

## 四、关键发现分析

### 4.1 结果变异性揭示随机轨迹的影响

同一参数组合（gain=0.3, oto=6.0, lateral=0.3）、两次独立运行：

| 指标 | Phase 6 P0 | **本次重测** | 差异 |
|------|-----------|-------------|------|
| 3D 距离缩减@200k | 0.880 | **0.614** | -30% |
| |Δw|@50k | 0.022 | **0.112** | +5× |
| DR5 grad·v | 94.77% | **80.67%** | -14% |
| dist@450k | 17.240 | **19.015** | 较慢 |

**根本原因**：Langevin 噪声（随机游走分量）导致每次 body 轨迹不同。本次 body 在 y/z 方向漂移更多（约 2.1 units，P0 仅 1.87 units），产生：
- 更丰富的 somatosensory 左右温差 → |Δw| 高 5×（更好的方向学习）
- 但 x 方向净进入慢 → 3D 距离缩减率低 30%

这不是 bug：**学习（|Δw|）和接近（3D dist）在随机轨迹下存在探索-利用权衡**。横向游走时学到更清晰的方向，但耗费了直线接近的时间。

### 4.2 DR2 指标的时间窗口问题

body 在 500k 步内**单调接近**热源（dist 从 20.000 → 19.015，持续减少），但 200k 检查点时仅达 0.614，而 500k 时达 0.985（距阈值仅差 0.015）。

两次运行的对比：

```
P0 run:          200k→0.880,  通过时间 ≈ 210k（推算）
本次 run:        200k→0.614,  通过时间 ≈ 550k（外推）
两次运行均单调接近，但速率差 ≈ 1.8×
```

**结论**：DR2 在 200k 步检查热趋向的**即时成果**，但对于随机动力学系统，200k 步内的具体数值高度依赖于随机种子决定的轨迹形状。

### 4.3 DR2 阈值/窗口评估

DR2 的设计意图是验证"在有限时间内产生宏观热趋向位移"。问题是：

| 条件 | 200k 缩减 | 500k 缩减 | 是否最终接近 |
|------|-----------|-----------|------------|
| P6 P0 | 0.880 | 2.760 | ✓（最终接近量大） |
| 本次 | 0.614 | 0.985 | ✓（接近但慢） |

两次运行均单调接近，行为方向一致（热趋向成立），差异仅在速率。如果 DR2 改为"500k 步内 3D 距离缩减 > 1.0"，两次均应通过（本次 0.985 接近但略差）。

## 五、DR2 修订建议

基于两次运行的数据，建议将 DR2 修改为：

```
DR2（修订）: 500k 步内达到的最大 3D 距离缩减 > 1.0
           等价于：min_dist(0–500k) < 19.0
```

**理由**：
1. 系统**确实**在接近热源（行为正确），200k 的快照因随机轨迹方差大而不稳定
2. 500k 步内"是否曾接近超过 1.0 units"是更鲁棒的热趋向判断
3. Phase 6 P0 的 max 缩减 = 2.760（dist@450k=17.240），本次 max 缩减 = 0.985（dist@450k=19.015）
4. 本次结果仍差 1.5%（0.985 vs 1.0），若扩展至 600k 应能通过

**或者**：若保持 200k 窗口，建议降低阈值至 0.5（本次为 0.614，均应通过），反映更保守的中程热趋向证据要求。

**在此不单方面修改 DR2 定义，待用户确认后执行。**
