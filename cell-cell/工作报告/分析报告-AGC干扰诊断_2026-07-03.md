# 分析报告：AGC 干扰诊断

**日期**：2026-07-03  
**性质**：AGC 系统对 Phase 3/STDP 的干扰风险评估  
**结论提前**：当前 AGC 对 STDP 无直接干扰。两套 AGC 系统功能完全独立。

---

## 一、调查背景

初始分析（2026-06-末）将 HC-010（`compensation.py` 中的 synaptic AGC）标记为"Phase 3 主要风险"。进一步调查发现该判断有误——HC-010 描述的是一个**从未被实例化**的休眠代码，而运行中的 AGC 系统不影响 STDP。

本报告厘清两套 AGC 系统的关系，给出正式的无干扰判定。

---

## 二、两套 AGC 系统

### 2.1 Synaptic AGC（`components/compensation.py`）— HC-010，休眠

**位置**：`nexus_v1/components/compensation.py`  
**类名**：`AutomaticGainControl`  
**配置参数**：`tau_agc=0.1`  
**实例化状态**：**从未被实例化**

关键证据：
```python
# neuron.py NeuronConfig 中
use_agc: bool = False  # 默认 False
```

`NeuronConfig.use_agc` 全局默认 `False`。翻查所有 NeuronConfig 的创建点（`vestibular/chain.py`, `circuit/hebbian.py`, `circuit/variant_adapter.py`），无一传入 `use_agc=True`。因此 `compensation.py` 中的 `AutomaticGainControl` 类虽然存在，但**在整个系统运行期间零实例**。

**HC-010 风险级别**：LOW（休眠代码，不影响当前实验；应在 V2.0 清理中移除以防误触发）。

### 2.2 Circuit-Level AGC（`components/agc.py`）— VariantCircuit.agc，活跃

**位置**：`nexus_v1/components/agc.py`  
**类名**：`AutomaticGainControl`（同名，不同文件）  
**实例化**：在 `VariantCircuit.__init__` 中实例化为 `self.agc`  
**参数**：`tau=40_000`（40k 步时间常数，约 40 秒仿真时间）  
**BIO 对应**：HPA 轴/皮质醇（下丘脑-垂体-肾上腺轴，慢速应激调控）

**作用范围**：

```python
# variant_adapter.py 中 agc 的使用方式
noise_scale = self.agc.gain * base_exploration_noise
```

`agc.gain` 仅调制 **Langevin 探索噪声**（随机运动成分），不接触任何 STDP 学习率、bundle 权重、或神经元膜电位。

**作用机制**：当系统能量（`energy_store.fill_fraction`）持续下降时，agc.gain 缓慢上升，增加探索力度（对应"皮质醇升高 → 更强的觅食行为"）。反之，能量充足时 gain 缓慢下降趋近 1.0。

---

## 三、STDP 通路检查

STDP 学习由 `SynapticBundle.learn(dt)` 驱动，涉及三个信号：

| 信号 | 来源 | AGC 干扰？ |
|------|------|-----------|
| `pre_trace` | 源神经元激活历史 | ❌ 无 |
| `post_trace` | 目标神经元激活历史 | ❌ 无 |
| `stdp_lr` | BundleConfig 中的学习率 | ❌ 无（agc 不修改此字段）|

VariantCircuit 中的 `agc.gain` 没有任何路径通往 `stdp_lr`、`pre_trace` 或 `post_trace`。

---

## 四、Phase 3 实验中的 AGC 观测

Phase 3 log 输出（step 50000）：

```
50000   9.735 S1  0.1043 0.0999 0.0989 0.0945  -0.0044 -0.0044  0.489  0.8438  +6465.827  95%  100.0%  1.14
```

`agc=1.14`：gain 仅比基线高 14%（极轻微激活）。原因是 fill 从 0.500 降至 0.489（约 2% 下降），触发了微弱的 HPA 响应。这是正常生理状态，不会影响实验结果。

**预测**：随着 body 接近热源（fill 可能回升），agc 会缓慢降回 1.0。整个 500k 步实验期间 agc 不会显著偏离 1.0±0.2 的合理范围。

## 五、结论

| 评估项 | 结论 |
|--------|------|
| Synaptic AGC（compensation.py）是否运行？ | ❌ 否，`use_agc=False` 全局，零实例 |
| Circuit AGC（agc.py）是否影响 STDP？ | ❌ 否，仅调制 Langevin 噪声 |
| HC-010 是否需要立即修复？ | ⚠️ 否，休眠代码，推迟至 V2.0 清理 |
| Phase 3 中 agc.gain 是否异常？ | ✅ 正常，1.14（+14%），不影响结果 |
| **综合判断：AGC 是否干扰 Phase 3？** | **❌ 不干扰** |

---

## 六、建议

1. **HC-010 清理**（V2.0）：移除 `compensation.py` 中 `use_agc=False` 对应的死代码，消除未来误触发风险。
2. **无需任何 Phase 3 代码改动**：AGC 两套系统均对 STDP 无干扰，实验可以原样继续。
3. **agc 列保留在日志中**：作为 HPA 轴健康度指标，正常范围 [0.5, 2.0]；超出此范围说明能量持续异常（需要另行排查）。
