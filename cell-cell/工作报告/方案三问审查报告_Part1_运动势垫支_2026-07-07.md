## 组件 1：置信度积分器（§4.1）

### Q1 生物对应物
→ 纹状体神经元积分皮层输入。  
**✅ 强对应**——纹状体的密集棘神经元（MSN）确实对输入脉冲进行时间积分（Mink 1996 PBNM; Grillner 2005 Nat Rev Neurosci）。

### Q2 物理结构
→ `τ dV/dt = -V + R_in·spikes`，等价于 `Capacitor + Neuron` 原语。  
输入 = 核团脉冲输出（物理信号），**不读取权重矩阵**。  
**✅ 完全合规**——可直接用现有 Neuron 类实现（`NeuronConfig(use_calcium_rate_integrator=True)` 或直接 Capacitor）。

### Q3 参数来源
- `τ_conf = 5000步`：来源为"与 P0 的 DA_EMA 对齐"。**⚠️ 自引，非独立推导。**
- 建议：在影子模式中测量核团脉冲的实际时间常数（ISI 统计），从 ISI 均值 × 5 反推 τ_conf。

**结论：✅ 合规，参数需实验标定。**

## 组件 2：FSM 前向感官预测矩阵（§4.2）

### Q1 生物对应物
→ 小脑皮层浦肯野细胞-平行纤维系统（M→S前向预测）。  
**✅ 强对应**（Wolpert 1998 Science; Ito 2008 Nat Rev Neurosci; Shadmehr 2010 Annu Rev Neurosci）。  
正向模型在生物学上与逆向模型（STDP 核团）物理分离，文件1 的隔离设计有坚实的生物根基。

### Q2 物理结构
更新公式：`ΔW = -η(ŷ-y)·M^T`  
→ **⚠️ 争议区：** 这是矩阵乘法（Python 数学），但它不是"判断朝热源"的语义结论——它是标准 LMS/Widrow-Hoff 学习规则的矩阵形式。

**→ 建议实现方式：** 把 FSM 做成 `SynapticBundle(learning_rule='error_driven')`：
- Sources = Motor 输出神经元（efference copy）
- Targets = 感官预测神经元
- 误差电流从比较器反馈到 bundle 的 `learn()` 接口

这样误差驱动更新就在现有 SynapticBundle 框架内，不需要裸 Python 矩阵操作。

### Q3 参数来源
- `η_fsm = 1e-4`：来源为"远慢于 STDP 学习率，确保不震荡"。**⚠️ 工程估算。**
- 建议：从感官信号的变化率标定——`η_fsm ≈ Δy_typical / Δt_typical`，确保收敛步数 ≈ 10-100k。

**结论：⚠️ 架构合法，必须用 SynapticBundle 实现，不能用裸矩阵运算。**

## 组件 3：误差比较器 + GABA 抑制（§4.3）

### Q1 生物对应物
→ 攀缘纤维（预测误差编码）+ SNr GABA 强直性抑制（disinhibition）。  
**✅ 经典小脑-基底节双重机制**，文献极其充分（Albus 1971; Ito 1989; Hikosaka 1989）。

### Q2 物理结构
- 比较器 = KCL 电流差分（`I_error = ŷ - y_actual`）：**✅ 合规**
- 误差神经元 = MOSFET 阈值门控：**✅ 合规**
- GABA 突触 = 固定负权重 SynapticBundle（`sg=-1.0`）：**✅ 合规**

### Q3 参数来源
- `W_inhib = -1.0`：**❌ 未说明来源。** 建议：从误差信号的典型幅度反推（使一次误差事件约抽干决策神经元 50% 电荷）。
- `θ_error`：**❌ 未给值。** 建议：= 感官通道本底噪声的 3σ（在 ShadowSandbox 的安静期测量）。

**结论：✅ 架构合规，2 个参数需补充推导。**

## 组件 4：微运动搭便车探测（§4.4）

### Q1 生物对应物
→ CPG 相位重置机制 + 被动感知（Passive Sensing）。  
**✅ 有依据**（Grillner 2006 Nat Rev Neurosci; Pearson 1993 Annu Rev Neurosci）。

### Q2 物理结构
**❌ 违规点（严重）：** 匹配度计算 `M_d = -||Δy_d - Δŷ_d||²` 是 Python 范数。  
这直接决定"哪个方向的决策神经元获得偏置电流"——**这是用 Python 数学决定语义选择，属于硬编码。**

**→ 修复方案（完全物理化）：**
1. 误差电流 `I_error = ŷ_d - y_actual` 流入一个**误差 Capacitor**（每个方向一个）
2. 误差大 → Capacitor 电压高
3. MOSFET 将 Capacitor 电压转为抑制电流，**注入对应决策神经元**（误差大 = 更强抑制）
4. 误差小的方向自然获得相对优势

全程无 Python 范数，仅 Capacitor + MOSFET + SynapticBundle。

### Q3 参数来源
- 偏置电流强度：随修复方案确定（由 Capacitor 充放电常数决定）。

**结论：❌ 必须改为 Capacitor 积分实现，范数计算=硬编码。**

## 组件 6：Softmax 输出（§4.5）

### Q1 生物对应物
→ **❌ 无明确对应。** Softmax `P = exp(V/T)/Σexp(V/T)` 是机器学习数学，自然界不存在"温度参数 T 的指数归一化"神经机制。

### Q2 物理结构
→ **❌ 纯 Python 数学，无 Capacitor/MOSFET 原语。**

### Q3 参数来源
→ `T = 0.5`（温度）：**❌ 完全无来源。**

**→ 废弃建议：** WTA 侧向抑制天然产生 winner-take-all 效果，不需要显式 Softmax 归一化。决策神经元的膜电位直接代表选择强度。如果需要概率解释，用侧向抑制后的 `activation / max_activation` 替代（但不必输出为概率）。

**结论：❌ 废弃 Softmax，用 WTA 自然输出替代。**
