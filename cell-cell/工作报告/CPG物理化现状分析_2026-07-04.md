# CPG 物理化现状分析报告

**日期：** 2026-07-04  
**背景：** 用户询问"VitalOscillator 中的 math.sin 已被替换为 AdEx 半中心振荡器"是否属实，以及这是否意味着 CPG 物理化不需要实施。

---

## 1. 事实核查：VitalOscillator 的实际实现

### 1.1 VitalOscillator 从未主要依赖 math.sin

`nexus_v1/components/vital_oscillator.py` 当前实现：

```
VitalOscillator
├── _osc_x: ResonantOscillator(f=2.00 Hz, μ=2.0)  ← VdP 振荡器
├── _osc_y: ResonantOscillator(f=2.11 Hz, μ=2.0)  ← VdP 振荡器
└── _osc_z: ResonantOscillator(f=1.93 Hz, μ=2.0)  ← VdP 振荡器
```

该文件中仅有两处 `math.pi`，用于设定初始相位偏移量（**静态常数**，非振荡运算）：
```python
phase_offset=math.pi * 0.7    # _osc_y 的起始相位
phase_offset=math.pi * 1.3    # _osc_z 的起始相位
```

振荡本身完全由 `ResonantOscillator.step(dt)` 完成，ResonantOscillator 是 Van der Pol 方程的数值积分：
```
dx/dt = y
dy/dt = -ω₀²x - μ(x² - 1)y
```
这是**物理实现**（等效于 LC 谐振腔 + 负阻器件），不是 `math.sin` 硬编码波形。

**结论：VitalOscillator 的振荡从未使用 math.sin 产生。**

### 1.2 代码库中不存在 AdEx 半中心振荡器

搜索范围：`nexus_v1/` 全目录，`*.py` 文件，关键字 `AdEx|half.center|HalfCenter|adex_half`：

| 文件 | 命中内容 | 性质 |
|------|---------|------|
| `vestibular/chain.py` line 22 | `AdEx model: spike detection...`（注释） | 文档注释，非实现 |
| `components/neuron.py` lines 5, 13, 468 | `AdEx spike generation`（afferent 模式） | **树突尖峰探测**，非振荡器 |
| `components/oscillator.py` line 26 | `CPG half-center mutual inhibition (Marder...)` | 生物学参考，非实现 |

**结论：代码库中不存在 AdEx 半中心振荡器。用户的前提不成立。**

## 2. math.sin 实际出现的位置

代码库中 `math.sin` 有三处，均与 VitalOscillator 无关：

### 位置 A：`motor_decision.py` lines 202, 221

```python
# Kuramoto 相位耦合公式（谐振锁相）
dphi += self.COUPLING_K * math.sin(self._phases[j] - self._phases[i] - target_offset)

# 节律包络计算
envelope = 0.5 + 0.5 * math.sin(self._phases[i])
```

所属类：`MotorDecisionLayer.MotorRhythm`（脊髓 CPG 运动节律层）。

**关键事实：** 模块顶部注释明确写明：
> "Currently: all three sub-layers are PASSTHROUGH (placeholder)."

此代码**当前为直通（不改变 Motor 输出）**，`math.sin` 存在但不被执行路径使用。这是 HC 技术债的候选（HC-025 等），但目前不影响行为。

### 位置 B：`components/oscillator.py` lines 97, 174, 189, 239

`ResonantOscillator` 内部 VdP 方程求解时使用 `math.sin` 作为三角辅助函数（相位计算），这是数值积分的标准做法，属于**物理模型内部运算**，不是替代物理的硬编码。

### 位置 C：`circuit/variant_adapter.py` line 1084

```python
math.sin(self.world.body.yaw)
```
几何坐标变换，非振荡。

## 3. 已完成的 CPG 物理化：CPGNeuron

commit 7f6269f 实现了 `nexus_v1/components/cpg_neuron.py`：

**功能：** 解决 relay_to_da STDP 在 DA 神经元达到稳态后冻结的问题（`post_trace = |d(activation)/dt| → 0`）。

**实现：** VdP 振荡器（ResonantOscillator，2Hz）→ 整流 → 冻结 SynapticBundle → DA 神经元。

**生物对应：** VTA 多巴胺神经元固有节律起搏（Grace & Bunney 1984, J Neurosci 4:2877）。

```
CPGNeuron (VdP, 2Hz)
    └─ bundle_cpg_to_da [frozen, w=0.1, sg=1.0]
        └─ DA neurons
           维持 post_trace > 0 → STDP 不冻结
```

这是**针对 DA 节律起搏的特定 CPG 物理化**，已完整实现。

## 4. CPG 物理化状态总结

| 组件 | 状态 | 实现质量 |
|------|------|---------|
| VitalOscillator（生命体基础节律） | ✅ 已物理化 | 三频 VdP，李萨如轨迹，能量耦合 |
| CPGNeuron（VTA 节律起搏） | ✅ 已物理化 | VdP 2Hz，解决 STDP 冻结 |
| MotorDecisionLayer.MotorRhythm（脊髓 CPG 步态） | ⚠️ 占位符，有 HC 风险 | 有 math.sin，但当前 PASSTHROUGH，未接入 Motor 输出 |

### 关于"不需要实施 CPG 物理化"的判断

如果此判断确实在某次对话中出现，最可能的理由是：

1. **VitalOscillator 和 CPGNeuron 已经覆盖了当前需要的两个 CPG 功能**（生命体基础运动 + DA 节律维持）。
2. **MotorRhythm 是占位符**，目前 Motor 输出完全由 `bundles_col_to_motor` STDP 驱动，MotorRhythm 的 math.sin 尚未接入，不产生实际效果。

但这个判断是**有条件的**：一旦 MotorRhythm 从 PASSTHROUGH 变为实际接管 Motor 调制，其中的 `math.sin` 就会成为 HC 违规（Kuramoto 耦合直接用 Python 数学计算步态节律，绕过 SynapticBundle 物理结构）。

---

## 5. 结论与建议

**用户前提不成立：** VitalOscillator 中的 math.sin 并未被替换为 AdEx 半中心振荡器，因为：
- VitalOscillator 从未用 math.sin 产生振荡（一直使用 VdP/ResonantOscillator）
- 代码库中不存在任何 AdEx 半中心振荡器实现

**当前 CPG 物理化程度：**
- 已完成：VitalOscillator（生命体心跳）+ CPGNeuron（DA 节律）
- 占位待实施：MotorRhythm（脊髓步态 CPG），目前 PASSTHROUGH 安全，但 math.sin 是潜在 HC 债

**建议：** 将 `motor_decision.py` MotorRhythm 的 HC 风险登记到 `docs/technical_debt_hardcoding.md`（建议编号 HC-026），在进入步态 CPG 实施阶段时，用 ResonantOscillator 双核半中心相位竞争（互抑制束，如 `oscillator_a_inhibit_b` SynapticBundle）替换 Kuramoto math.sin。**当前不需要紧急实施**，因为 MotorRhythm 是 PASSTHROUGH。
