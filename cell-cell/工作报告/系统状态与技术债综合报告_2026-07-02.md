### 3.2 当前最大阻塞：body 离开 d<12 学习窗口

Phase 3 基线揭示：proj 只在 d<12 发放，STDP 只在 body 接近期间积累。500k 步内 body 有效学习时间 < 50k 步（仅接近热源的短暂瞬态）。此后 450k 步随机游走、能量消耗，权重冻结。

**根本原因**：body 接近热源后，没有机制保持它在 d<12 持续停留并累积权重。STDP 学习速度慢（stdp_lr=0.005，单次接近只有几百步），单次窗口产生的权重增量 (~0.01) 不足以显著影响 motor 输出。

**CPGNeuron 的具体改善**：现在 DA.post_trace ≠ 0 → 在 d<12 停留期间每步都有 STDP 更新（而不是只在接近/撤离瞬态）。d=8 静止热源 3k 步已观察到 front-back 权重分化。这是之前从未观察到的稳态学习。

### 3.3 HC-010 (AGC) 的隐患

`tau_agc=0.1` 时间常数 1000× 压缩（0.1s 对应生物几小时稳态塑性），AGC 每步执行增益调整 `gain(t) = K/(1 + ā/1.0)`，`K=20`。这个机制每步主动覆盖 STDP 积累的电路状态，等效为对 STDP 权重施加强制均值回归。只要 AGC 开着，即使 relay_to_da STDP 方向正确，权重也会被拉回基线。**这是下一轮实验可能仍然失败的主要隐患**。

## 四、本轮诊断根因记录

以下两项根因在本次会话中通过物理分析确认，是理解 relay_to_da 信号路径当前状态的必要背景。详细推导见 `cell-cell/工作报告/分析报告-TSI-ν-熵方案评判与DA冷启动根因_2026-07-02.md` §三/§四。

---

### 4.1 relay.vm 高幅值根因：V_ss 稳态收敛，非 Bug

**现象**：relay 神经元膜电位在 d=8 近距热源时达到 5-7V，看起来像溢出（v_peak ≈ 0.5V，但 vm 远超此值）。

**根因**：物理稳态收敛，不是 bug。

```
V_ss = I_thermo × r_relay_leak
```

relay 的漏电阻 `r_leak = 10`。d=8 近距时热换能电流 I_thermo ≈ 0.5-0.7A，稳态电压 V_ss ≈ 5-7V。激活函数 `activation = sigmoid(V/v_peak)` —— 高 vm 映射为高激活（接近饱和），系统是收敛的，不是发散的。

**lateral_gain=0.3 的角色**：侧抑制是必要稳定机制。无侧抑制时，patch 内相邻 relay 神经元的高激活会形成正反馈放大。当前 `lateral_gain=0.3` 是工程调参，无 BIO/REF 依据，违反"无来源不填参数"原则（DEG 待登记，参见 2.5 节）。

**结论**：不需要代码修复。relay.vm 高幅值是正确的物理行为。后续需补充 lateral_gain 的生物依据并登记 DEG 条目。

---

### 4.2 增益扫描颠覆性发现：P2"relay 不开门"是冷启动误读

**P2 诊断原结论**（2026-06）：d>12 时 relay.vm=0.02-0.05，结论为"relay 在远距不开门，需增大 THERMAL_TRANSDUCTION_GAIN"。

**颠覆发现**：P2 诊断是冷启动测量误差，结论无效。

relay 的 RC 充电时间常数：
```
τ = C × R = 2.0 × 10.0 = 20,000 步  （= 20 秒 @ dt=0.001）
```

P2 诊断在 t ≈ 200 步时测量，此时 relay.vm 仅充电至稳态的：
```
V(t=200) ≈ V_ss × (1 − exp(−200/20000)) ≈ 0.01 × V_ss
```
即仅到稳态的 1%。P2 测到 0.02-0.05V，是因为 relay 几乎还未充电，不是信号路径不通。

**校准扫描结果（本次，3000 步预热后测量）**：

| 条件 | relay.vm | relay.act | 状态 |
|------|---------|---------|------|
| d=20，gain=0.1（默认）| **0.703V** | **0.165** | relay 已开门 ✓ |
| d=12，gain=0.1 | 1.4-1.8V | 0.40-0.50 | relay 强激活 |
| d=8，gain=0.1 | 5-7V | ≈1.0 | 饱和（收敛稳态）|

relay 在 d=20 默认增益下约 1200 步后进入有效激活范围。

**THERMAL_TRANSDUCTION_GAIN 重新评估**：

增益提高的唯一合理场景是让 proj 在 d=20 放电（relay.act > 0.35 需 gain ≥ 0.5）。但 gain 增大在 d=8 近距时会导致热感受器饱和，信号失真。proj 在 d<12 以 gain=0.1 自然开门，实验已通过。

**决策（已定）：不增加 THERMAL_TRANSDUCTION_GAIN**。gain=0.1 足够；近距饱和风险高于扩大 d=20 学习窗口的收益。
