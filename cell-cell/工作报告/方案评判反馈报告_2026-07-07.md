## 一、STDP架构修复方案反馈

### 1.1 P0（DA慢积分 + 活动性LTD双门控）

**评分：✅ 通过，可立即实装**

设计正确。将 DA(t) 点采样替换为 EMA（τ=5000步），并让 LTD 活跃分量同样受 DA_ema 门控，使 fill 饱和期权重进入"冻结保鲜态"。

**与实验数据对齐**：

T-067 核心失效机制的实测轨迹：
```
w_CORRECT_L 变化轨迹：
  20k步：+0.0035（STDP活跃，LTP > LTD）
  35k步：fill饱和，DA_raw→0，当前LTP立刻归零
  100k步：w ≈ 0.0000（175k步无门控LTD冲洗）
```

P0 修复后的预期：
- fill饱和后 Δw ≈ 0（DA_ema双向门控），权重进入冻结保鲜态
- 第二次觅食窗口开放时，从 w=0.0035 继续累积，而非从零重建
- λ_metabolic ≈ 1e-6/步 × 175k步 → 保留率约84%（vs 当前≈0%）

**一处必须处理的技术细节**：

方案中 β 计算写作：
```
β = dt / (dt + τ_DA)，τ_DA = 5000步
```

当 DT=1.0 时，β = 1.0 / (1.0 + 5000) ≈ 0.0002，数值正确。但代码注释必须显式写明这里的 τ 是**仿真步数**而非秒，并让计算依赖 DT 参数：

```python
# τ_DA_steps=5000 → 对应生物学约5s @ dt=0.001s convention
# WARNING: τ must be in simulation steps, NOT seconds.
beta = dt / (dt + 5000.0)   # dt is the loop DT (typically 1.0)
```

直接硬编 β=0.0002 会在 DT 变化时静默失效，重演 Phase B 的 exp(-50)≈0 陷阱。

### 1.2 P1（WTA竞争侧抑制）

**评分：⚠️ 方向正确，参数需保守**

在 spinal_ccw ↔ spinal_cw 之间插入 frozen 抑制束，让 STDP 从共模饱和变为真正竞争——方向无误，T-063 的双束同时饱和（w_ccw=w_cw=0.300）正是这一缺陷的直接证据。

**参数风险**：

方案提出 `initial_weight = 0.1-0.15`。但 T-042 的 F-I 曲线诊断（2026-07-06）已记录：过强的交叉抑制会导致 spinal 层全列静默。T-043 当时将同类型束的权重设为 w=0.020（sg=-1.0），正是基于这个教训。

在同层级（spinal）的神经元上以 5-7 倍于 T-043 的权重引入侧抑制，有引发振荡或静默的合理风险。

**建议**：
- 从 `w=0.020`（与 T-043 对齐）开始
- 先做 50k 短程验证：观察 spinal_ccw/cw 激活是否出现振荡或死锁
- 确认无异常后，再逐步上调至 w=0.05/0.10 观察竞争效果

---

### 1.3 P2远期（学习目标重定向）

**评分：✅ 架构蓝图正确，但存在一项执行时序遗漏**

P2 正确地指出缺陷1（D1 STDP 在重建 relay→yaw 已提供的方向极性）是四项缺陷中的根本原因，增益调制架构蓝图合理。

**遗漏的中间验证步骤**：

P0/P1 实装完成后，DR5 可能提升，但这种提升有两种解释：
1. STDP 真正学到了增益调制能力（学习效果）
2. spinal→yaw 的边际增益提升（纯物理增益，不是学习）

不加区分直接解读为"STDP 有效了"属于诈胡风险。

**必须在 P0/P1 验收后立即执行**：T-039 诈胡核查重跑——全冻结 STDP，观察 DR5 是否变化。如果冻结 STDP 后 DR5 不变，说明 P0/P1 的改善仍是纯增益问题（缺陷1依然是主因）；如果变化了，才能认为 STDP 学习开始真正影响行为。这个区分直接决定 P2 的紧迫程度。

---

### 1.4 执行顺序问题

**评分：❌ 需要修改**

方案提出的执行顺序：
```
半规管补全（阶段0-1）→ P0（DA慢积分）→ P1（WTA）→ 验证
```

**问题**：半规管补全在 P0/P1 之前上线，会同时改变：
- 进入 STDP 的信号结构（前庭输入从 [0,0,0] 变为真实角速度）
- STDP 内部的学习动力学（P0 改变权重衰减，P1 改变竞争结构）

两个系统同时变化，实验结果无法归因——如果 DR5 提升了，不知道是来自 STDP 修复还是前庭信号改善。

**建议的顺序**：
```
P0（DA慢积分+LTD双门控）
    ↓ 50k短程验证：fill饱和后w_ccw保留率>80%
P1（WTA侧抑制，w=0.020起）
    ↓ 50k短程验证：无振荡/静默，两束出现剪刀差
T-039诈胡核查重跑
    ↓ 区分增益效果 vs 学习效果
T-072多周期实验（200k）
    ↓
半规管信号注入 + 增益校准（不污染STDP控制组）
    ↓
T-061四组消融重做
```

## 二、半规管补全方案反馈

### 2.1 生物物理模型

**评分：✅ 通过**

Steinhausen 扭摆模型的过阻尼近似（一阶高通滤波）推导正确，τ_cupula ≈ 4s 的生物学取值有文献支撑，量纲链闭合（见方案第八节）。

### 2.2 dt陷阱（关键风险，方案未解决）

**评分：❌ 必须在实装前明确处理**

方案第2.2节写道：
```
α ≈ 0.00025（当 dt=1ms, τ=4s）
```

这是用**物理时间**算出的 α。但全体正式实验（T-033 至 T-072）使用 DT=1.0，不是 0.001。

用 DT=1.0 直接计算：
```
α = 1.0 / (1.0 + 4.0) = 0.2
```

这意味着 Cupula 时间常数变为 4 仿真步，而不是 4000 步（对应生物学 4 秒）。高通截止频率比意图高出约 1000 倍，实际上等于完全没有滤波——每步的输出几乎就是原始角速度，没有任何高通整形效果。

这与 Phase B P1 的 exp(-50)≈0 陷阱性质完全相同（项目记忆已记录此陷阱）。

**修复方法**：实装时使用步数域的 τ，并且让它依赖 DT 参数：

```python
TAU_CUPULA_STEPS = 4000  # 对应生物学4s @ 1ms convention
# 若DT=1.0，则4000步约等于4s物理时间
ALPHA_CUPULA = DT / (DT + TAU_CUPULA_STEPS)  # ≈ 0.00025

# 在步骤循环中：
filtered = ALPHA_CUPULA * (raw - prev_raw) + ALPHA_CUPULA * prev_filtered
```

### 2.3 ANGULAR_GAIN 标定

**评分：⚠️ 公式正确，但参数值需实测**

公式 `ANGULAR_GAIN ≈ a_max / (ω_max × R_body)` 量纲推导正确。

但方案用的示例数字（a_max=1.0, ω_max=2.0, R_body=0.5 → GAIN=1.0）是假设值，不是实测值。`body.angular_velocity` 的实际范围和 `mechanical_inputs` 中耳石信号的实际动态范围，需要在阶段0.5的校准实验中测量，不应提前硬填。

建议阶段0.5的验收标准改为定量化：打印半规管信号峰值与耳石信号峰值之比，调整 ANGULAR_GAIN 使比值在 0.5~2.0 范围内（同量级但不超过一倍），而非泛泛地"相似动态范围"。

### 2.4 废除融合层（取模废除）

**评分：✅ 强烈支持**

取模操作 `(x²+y²+z²)^0.5` 摧毁符号信息，左转/右转无法区分，STDP 方向分化基础被破坏。废除此操作并将三路带符号信号直接注入 MET，是正确且必要的设计决策。

### 2.5 "STDP自组织互补滤波"的表述风险

**评分：⚠️ 机制正确，但前提条件缺失**

方案第四节写道：
> "STDP自己就是那个完美的互补滤波器。"

这个机制在生物学上是合理的，但当前系统的 STDP 有缺陷4（DA点采样）和缺陷3（无竞争），自组织互补滤波无法在这两个缺陷存在的情况下可靠涌现。

如果执行者按方案先做半规管补全，再期待 STDP 自组织出互补滤波，结果大概率是看不到这个现象，然后误判半规管补全失败。

**建议**：在方案第四节添加前提条件声明：
> "此机制依赖 STDP P0（DA慢积分）和 P1（WTA竞争）修复完成后才能激活。半规管补全应在 STDP 基础修复验证通过后执行。"

### 2.6 T-061 重做设计

**评分：✅ 正确，前提条件需补充**

四组消融设计（全前庭/仅耳石/仅半规管/全消融）是完整的，实验逻辑严密。

但 T-061 重做需要以以下三件事为前提：
1. 半规管信号已注入（阶段0完成，传入纤维发放率有变化）
2. STDP P0/P1 已修复（否则消融效果被 STDP 失效掩盖）
3. 诈胡核查已完成（确认方向性来自前庭输入而非其他路径）

缺少任何一项，消融实验的阴性结果都无法确定归因。
