### P0-3 FAIL ❌：BMR 饥饿压力（冷区 fill 下降）

```
fill_final = 0.9994  (阈值 < 0.999)
```

**表观原因：** fill 从 0.546（5k）→ 0.999（35k→50k），BMR=-0.002/step 完全被热场摄食（max_deposit=0.12/step）压制。

**根本原因：** P0-3 的验证前提是"body 持续处于纯冷区，无法摄食"。T-033 使用与 T-032 相同的单热场设置，body 随机游走必然周期性进入热场（r=30）。摄食速率（0.12/step）比 BMR 大 60倍，任何进入热场的时刻都能迅速填补能量消耗。

**结论：** P0-3 在 T-033 环境下**必然 FAIL**，这不是修复本身的问题，而是验证实验设计的缺陷。正确的 P0-3 验证需要无热源环境（第一阶段实验），参见`两阶段实验.md`评判报告。

## 新发现：yaw STDP 权重全面衰减

这是 T-033 最重要的非预期发现。

### 数据

| Step | w_ccw | w_cw | Δw |
|------|-------|------|----|
| 5k | 0.0373 | 0.0365 | -0.0008 |
| 10k | 0.0164 | 0.0163 | -0.0002 |
| 20k | 0.0075 | 0.0074 | -0.0000 |
| 50k | 0.0030 | 0.0030 | -0.0000 |

权重从初始 ~0.037 衰减 90% 至 0.003，且两侧同步衰减（无分化）。

**对比 T-032：** step 10k 时已达 w=0.299（接近上限 0.300），双侧全部饱和。

### 根本原因：phasic ≈ 0.000 导致无 pre-synaptic 信号

yaw STDP 的更新依赖 phasic_left/right 的 activation（pre-synaptic）。

T-033 全程 pL = pR ≈ 0.000，意味着 phasic 无活动 → pre_trace → 0 → 无 LTP → 只有 eligibility trace 的衰减（LTD）→ 权重侵蚀。

### 为什么 phasic ≈ 0？

phasic = relay.activation - slow_relay.activation（差分信号，检测热感知变化速率）

**T-033 的体温动态：**
- Body 从 dist=20（热场内）出发，前 5k 步移动到 dist=50（热场外）
- 在热场内：relay 激活，slow_relay（τ=15000）也在同步建立
- 离开热场后：relay 快速衰减，slow_relay 也较快追随（因为 τ 大，但初始建立阶段短）
- 到 5k 时：relay ≈ 0，slow_relay ≈ 0（两者都已衰减），phasic ≈ 0

**T-032 中 phasic ≠ 0 的原因：**
T-032 运行中 pL=-1.36（step 10k），pL=-10.0（step 30k）。这些大负值是 slow_relay 过冲驱动的异常超极化——而 P0-1 修复的正是这个异常。

换言之：**T-032 的 yaw 权重饱和本身就是 P0-1 修复的目标异常！** 是 phasic 的病理性超极化（-10V）持续驱动了 STDP，而非正常的热场梯度信号。

### 正确的 phasic 信号应该何时出现？

phasic（差分）应在 **热感知状态发生变化时**（冷→热的转变边界）产生信号：
- Body **首次从冷区进入热场**：relay 快速上升，slow_relay 还在低位 → phasic **正值**（大）
- 这个正值 phasic + DA奖励 = yaw STDP 的正确学习窗口

T-033 中 body 从 dist=20（已在热场内）开始，错过了这个"冷→热进入"的关键时刻。

### 结论

这一发现验证了`两阶段实验.md`方案的物理正确性：
1. **第一阶段（冷区起步）：** body 从距离热场很远处开始，fill 因 BMR 下降产生真实饥饿
2. **第二阶段（首次接触热场）：** relay 从零激活而 slow_relay 仍在低位 → phasic 大正值 + DA 进食奖励脉冲 → yaw STDP 有机会学习方向
