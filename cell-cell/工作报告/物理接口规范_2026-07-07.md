## 一、皮肤感觉系统 (somatosensory/chain.py)

### 1.1 热感受器（Thermoreceptor — TRPV3/TRPM8 通路）

**微分方程（RC 膜模型）：**
```
dV/dt = (I_input - V/R) / C
τ_th = C × R
V_ss = I_input × R
```

**激活动力学（BIO：TRPV3/TRPM8 慢适应）：**

| 参数 | 值 | 标记 | 来源 |
|------|-----|------|------|
| `capacitance` C | 1.0 | `[校准]` | EXP-016: 原5.0→1.0，5×加速平衡；τ_th=5s匹配TRPV3慢适应 |
| `r_leak` R | 5.0 | `[校准]` | τ_th = C×R = 5.0 步（≈5s），V_ss=T_skin×5.0 |
| `v_threshold` | 0.01 | `[校准]` | 低阈值确保皮肤温度范围(0.1–0.3)内产生分级响应 |
| `gm` | 1.0 | `[归一化]` | 无来源 |
| `tau_gate` | 0.0 | `[实测]` | BIO：DC慢适应传感器，无瞬时门控（TRPV3特性） |
| `reversal` | 0.0 | `[归一化]` | 无来源 |
| 生物时间常数 τ_th | 5000步=5s | `[实测]` | BIO：TRPV3/TRPM8通道热整合τ≈1–10s（Caterina et al.1997） |

> **接口说明**：稳态输出 V_ss = I_skin × R；输入为皮肤贴片瞬时温度 T_skin（来自 SkinPatch）。

### 1.2 伤害感受器（Nociceptor — TRPV1/TRPA1 AC微分器）

**微分方程（超快 RC 微分器）：**
```
τ_noci = C × R = 0.02 × 50 = 1 ms
V_ss = I_noci × R = (dT/dt × GAIN_NOCI) × 50
```

| 参数 | 值 | 标记 | 来源 |
|------|-----|------|------|
| `capacitance` C | 0.02 | `[校准]` | EXP-016：裸露神经末梢膜面积极小，25×缩小；τ_noci=1ms |
| `r_leak` R | 50.0 | `[校准]` | τ_noci=C×R=1ms；V_ss=I×50，放大dT/dt信号 |
| `v_peak` | 0.01 | `[校准]` | EXP-016：原0.5→0.01，50×降低阈值；使热梯度距离可触发 |
| `b_adapt` | 0.02 | `[手工]` | "适度适应允许簇发"，无文献 |
| `tau_w` | 5.0 | `[手工]` | "较长适应衰减"，无来源 |
| `NOCI_DT_GAIN` | 200.0 | `[校准]` | EXP-016：心跳速度0.00025→dT/step≈5e-5；I_noci=5e-5×200=0.01 |
| 生物参数 | BIO | `[实测]` | C纤维检测dT/dt≥0.001°C/s（TRPV1通道灵敏度，Julius & Basbaum 2001） |

> **接口说明**：输入为 |dT_skin/dt|，通过 NOCI_DT_GAIN 转换为电流注入；spike output 编码温度变化速率。

### 1.5 甲基化适应层（thermal_membrane.py）

**微分方程（细菌趋化蛋白类比）：**
```
dM/dt = (T - M) / τ_methyl
adapted_signal = T - M       ← 当前温度与适应基线之差
dT_dt = (T_now - T_prev) / dt  ← 时间微分信号

约束：adapted ∈ [-5.0, 10.0]，dT ∈ [-10.0, 10.0]
```

| 参数 | 值 | 标记 | 来源 |
|------|-----|------|------|
| `methylation_tau` τ | 200 步 | `[实测]` | BIO：C. elegans AFD神经元适应动力学（Mori & Ohshima 1995）；细菌MCP时间感知（Paster & Bhatt, eLife 2021） |
| 输出钳位 | ±5/10 | `[手工]` | 无来源 |

> **关键洞察**：bacteria/AFD检测的是dT/dt，而非直接∇T（Paster & Bhatt 2021）。ThermalMembrane实现的是时间比较而非空间梯度传感。

## 二、口器 (thermal_mouth.py)

### 2.1 两池RC热力学模型

**微分方程（双池热交换）：**
```
dT_mouth/dt = (T_env - T_mouth)/τ_heat - (T_mouth - T_body)/τ_cool

热摄取通量：
Q_flux = k × A × ΔT     其中 ΔT = max(0, T_env - T_mouth)
E_intake = η × Q_flux × dt
```

| 参数 | 值 | 标记 | 来源 |
|------|-----|------|------|
| `tau_heat` | 13 步 | `[推导]` | DERIVED：由稳态温度条件推导：T_ss=(T_env/τ_h+T_body/τ_c)/(1/τ_h+1/τ_c)=4.0@T_env=5 |
| `tau_cool` | 50 步 | `[手工]` | DESIGN：慢排热维持ΔT≈1，无文献 |
| `conductance` k | 2.0 | `[归一化]` | NORM：与SkinPatch.conductance一致 |
| `area` A | 1.0 | `[归一化]` | 单位面积，量纲一致性 |
| `eta` η | 0.06 | `[校准]` | T-029 (commit 818ce17) 修正：0.02→0.06；T-074实测 τ_fill=6691步/τ_approach=1931步（比0.289），摄食动力学正常 |
| `local_offset` | [2.0, 0.0, 0.0] | `[推导]` | 有效半径(1.30)+0.5口器延伸+0.2边距 |

**能量守恒约束（Noether）：**  
热源损失 = 全部 Q_flux（非仅η份额）；η控制ATP产量。

> **⚠️ 待标定参数**：`eta`=0.02 当前为实验估计值，无直接生物学参考；`tau_cool`=50纯手工设定。

## 四、运动输出系统 (muscle.py)

### 4.1 肌肉力学方程

**微分方程（延迟线性增益）：**
```
raw_force = motor_activation × gain
raw_force = clamp(raw_force, -max_force, +max_force)
delayed_force = FIFO_buffer[delay_steps]  ← 神经传导延迟
energy_cost = |raw_force| × energy_cost_per_force
```

| 参数 | 值 | 标记 | 来源 |

## 五、世界/身体力学 (world.py)

### 5.1 皮肤贴片热力学（SkinPatch）

**微分方程（Fourier热传导+Langevin噪声）：**
```
q_dot = k × (T_env - T_skin)
dT_skin/dt = q_dot / C_th

[SDE Itô约定] dT_noise = N(0, σ) × √dt
  其中 σ² = 2 × G × k_B × T_env² / C²  （涨落-耗散定理）
```

### 5.2 身体运动力学（Body）

**微分方程（粘性流体中Newton力学+过阻尼角动力学）：**
```
线速度：
  a_i = (F_i - μ × v_i) / m
  dv_i/dt = a_i
  dx_i/dt = v_i

偏航（过阻尼，精确半步解）：
  ω_new = (ω + τ_net/I × dt) × exp(-γ × dt)
  yaw += ω × dt

世界边界：
  Toroidal wrapping [0, 100]
```
