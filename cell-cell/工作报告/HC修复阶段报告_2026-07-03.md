## 2. 核心修复技术分析

### 2.1 HC-009：体感换能层重构

**原状态（违规）**：
```python
# 在 somatosensory/chain.py step() 中
self.thermoreceptors[pid].step(T * 0.1, dt)      # 直接注入，STDP 盲
self.nociceptors[pid].step(noci_total, dt)         # 直接注入，STDP 盲
```

**修复后（合规）**：
```
T_skin → ThermalInputNeuron.step(T, dt)
       → transducer_thermo_{pid}.propagate()  [frozen, synapse_gain=0.1]
       → thermoreceptor.step(current, dt)

noci_total → NociInputNeuron.step(noci_total, dt)
           → transducer_noci_{pid}.propagate() [frozen, synapse_gain=1.0]
           → nociceptor.step(current, dt)
```

**关键设计决策**：
- `plasticity=False (learning_rule="frozen")`：TRPV3/TRPM8/TRPV1/TRPA1 换能系数是演化固定的物理常数，不是可学习参数。三层论证：量纲锚定 / 演化固定 / 神经生物学证据（Brauchi 2004, Caterina 1997）。
- 新增 8 个 ThermalInputNeuron/NociInputNeuron（4 个 patch × 2），8 个 transducer bundle，全部纳入 `get_all_neurons()` / `get_all_bundles()` census，Noether 审计可见。
- SkinPatch τ=5000 步（5s）已处理热积分，transducer step() 不再叠加 RC 动力学（绕过 super().step()），仅更新 traces 维持 Bundle/Census 可见性。

### 2.2 HC-014：thermal_stability 的电路化

**原状态（违规）**：Python 软 sigmoid 直接用原始物理量：
```python
thermal_err = abs(self.thermal_membrane._prev_T - self.thermal_membrane._methylation)
thermal_stability = 1.0 / (1.0 + thermal_err * 10.0)
```

**修复后（合规）**：从 somatosensory relay 电路输出涌现：
```python
relay_vals = [soma_output[pid]["relay_activation"] for pid in soma_output]
soma_relay_avg = sum(relay_vals) / max(len(relay_vals), 1)
thermal_stability = max(0.0, 1.0 - soma_relay_avg)
```

**意义**：thermal_stability 现在反映的是电路真正感知到的热激活强度，而非原始物理温度的 Python 公式。当体感 relay 安静（无明显热刺激）时 thermal_stability 接近 1.0；relay 高度激活时 thermal_stability 趋向 0。这让 CPC（循环比例控制器）的稳态判断来自电路内部，而非外部全知物理量。

### 2.3 HC-017：RPE/hunger DA drive 路径修正

**原状态（违规）**：在 bundle 传播之前直接注入 DA 神经元膜：
```python
# 在所有 bundle 累积之前执行（line ~1033）
for nid, neuron in self.da_neurons.items():
    neuron._membrane.inject(_da_drive * 0.1, dt)
```

**修复后（合规）**：在所有 bundle 传播完成后，注入 da_input_currents 字典：
```python
# 在 CPG bundle 累积之后、neuron.step() 之前（line ~1317-1322）
if _da_drive > 0:
    rpe_current = _da_drive * DA_INJECT_SCALE
    for nid in da_input_currents:
        da_input_currents[nid] += rpe_current
```

**意义**：RPE/hunger 驱动现在通过 neuron.step() 的正常 input_current 参数输入，与 bundle 电流处于同一物理路径，Noether 能量平衡可见。原 inject() 路径绕过了膜动力学的时序（注入时神经元尚未 step），修复后时序正确：所有 bundle 传播 → 累积 input_currents → 统一 step()。

### 2.4 HC-024：死代码清除

hunger_drives 在 Phase 1 DISABLED 后恒为 `{'x':0,'y':0,'z':0}`，但 for 循环和 inject 调用仍保留，形成"存在但永不执行"的 HC 幻象。直接删除，无行为变化。

## 5. 未修复 HC 技术债现状

### 5.1 DEFERRED（本阶段暂缓）

**HC-016**（Motor deviation inject，`1/dt` 技巧）：
- 物理正确性：inject(I, dt) 中 I = deviation/dt，使 dV/step = deviation/C，dt 不变量。
- 问题：若转为 input_current pathway，RC 动力学的离散化会引入 dt 依赖，在 dt=1.0（回归测试）和 dt=0.001（实验）下行为不同。
- 所需设计：需要为 deviation→motor 信号单独引入 DeviationInputNeuron 并解耦 dt-invariant 保证，工作量较大，暂缓。

**HC-023**（Motor lateral inhibition inject）：
- 问题：`motor_lateral_inhibition.compute_inhibition()` 本身是 Python 计算（WTA/softmax 风格），若要彻底结构化需要引入侧抑制中间神经元（3 对）和相应 Bundle，涉及新的生物对应物设计。
- 暂缓原因：行为影响弱（inhibition < 0 才触发，多数情况下 < 0 的轴仅 1-2 个），结构化成本高。
