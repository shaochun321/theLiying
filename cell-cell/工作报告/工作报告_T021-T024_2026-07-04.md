## 四、T-022：CPC feed channel 无界爆炸修复

### 问题

`CirculationProportionCircuit`（CPC）的三路信号之一 `feed_alignment` 使用 `max(thermo_vals) - min(thermo_vals)` 作为皮肤温度对比度计算：

```python
feed_alignment = max(thermo_vals) - min(thermo_vals)  # 旧代码（已删除）
```

该计算本身物理上无上界。STDP 在长期训练中会使 thermo_activation 权重持续增长，导致 feed_alignment 从初始值 ~0.01 在5000步内爆炸到8.1+。结果：`v_feed` 主导 CPC 三路电容，`rho_homeo` 从正常 ~0.70 崩塌至 0.06，CPC 偏差信号失效。

**诊断**：diag_t022_cpc.py 实测验证了爆炸轨迹。

### 修复

`variant_adapter.py` 中将 `feed_alignment` 冻结为 0.0，待 DigestiveInterface → CPC 量纲校准路径完成后再接入：

```python
# T-022 清洁化：feed channel 暂禁用（0.0），待 DigestiveInterface → CPC 量纲校准后接入。
# 原 max(thermo)-min(thermo) 无上界（STDP 下可增长到 5+），破坏 rho_homeo。
feed_alignment = 0.0
```

同步更新了 `circulation_proportion.py` 的 docstring，标注 feed_alignment 当前为暂禁用状态。

**验证**：修复后 rho_h 从初始 0.94 正确收敛至 ~0.70（CPC 设定点）。

## 五、T-023：SkinPatch/Body 物理几何属性

### 目的

为后续热传导量纲桥接和规模泛化（面积/体积映射）提供物理基础。

### 实现

在 `components/world.py` 中添加：

**全局常数**（量纲锚点）：
```python
BODY_SCALE_M: float = 0.01   # 1 sim_unit = 0.01 m
SKIN_DEPTH_M: float = 0.002  # 皮肤厚度 2 mm
```

**SkinPatch 新增属性**：
```python
@property
def area_m2(self) -> float:
    # 体V=9 sim_units³ → r=1.29 cm → 球面积/12贴片 = 1.74 cm²
    ...

@property
def volume_m3(self) -> float:
    return self.area_m2 * SKIN_DEPTH_M
```

**Body 新增属性**：
```python
@property
def effective_radius_m(self) -> float: ...

@property
def surface_area_m2(self) -> float: ...
```

**物理依据**：球体V=9 sim³，换算r_body≈1.29 cm，总表面积≈20.8 cm²，每贴片1.74 cm²。皮肤深度2mm来自人体表皮+真皮层厚度（浅层温度感受器分布深度）。

## 六、T-024：前庭 Phase B — N=1→3 毛细胞扩展

### 背景与目的

壶腹嵴上并行排列 Type I（快响应、高增益）和 Type II（慢响应、低增益）两型毛细胞，在频域上分工编码高频瞬态加速度与低频稳态加速度（Goldberg 2000）。当前每轴仅有1个毛细胞，无法实现频域分离。

### 方案审计修正

原提交方案（T-024审计修正版）中存在两处参数基线错误：

| 参数 | 计划基线 | 实际代码基线 | 修正后 |
|---|---|---|---|
| MET→HC synapse_gain | 1.0 | **5.0** | HC_0/1: 5.0, HC_2: 4.0 |
| HC→Aff synapse_gain（N=3） | 1.0/3=0.33 | 20.0/3=**6.67** | 6.67/HC |

若按原方案实施，Aff 接收到的总电流约为正确值的 1/60，前庭链将完全沉默。

### 实现

`VestibularChain.__init__` 新增 `n_hair_cells` 参数（默认=1，完全向后兼容）：

**HC 分型参数**（每轴，N=3）：

| HC | capacitance | r_leak | τ（步数） | MET增益 | HC→Aff增益 | 可塑性 | 类型 |
|---|---|---|---|---|---|---|---|
| HC_0 | 1.0 | 5.0 | 5000 | 5.0 | 6.67 | STDP | Type I-like |
| HC_1 | 2.0 | 5.0 | 10000 | 5.0 | 6.67 | frozen | 混合型 |
| HC_2 | 4.0 | 5.0 | 20000 | 4.0 | 6.67 | frozen | Type II-like |

- HC_0 保持 STDP（延续原有学习动态）；HC_1/2 为 frozen（固定频率域滤波器）
- 所有 HC 共用同一套 3通道HH + Ca²⁺ 子系统（保留原有物理模型完整性）
- KCL 守恒：3 × 6.67 = 20.01 ≈ 20.0（原 HC→Aff 增益）

**步进逻辑**：N个HC并行运行，各自独立的MET→HC传播；Aff电流从N个 `b_hc_aff.propagate()` **累加后一次注入** Aff（KCL加法，非多次step）：

```python
total_aff_r = sum(b.propagate()[0] for b in hc_aff_list)
aff_r.step(total_aff_r, dt)
```

**census 变化**（N=3时）：

| 组件 | N=1 | N=3 | 变化 |
|---|---|---|---|
| HC 神经元（前庭层） | 6 | 18 | +12 |
| 总前庭神经元 | 24 | 36 | +12 |
| MET→HC bundle | 6 | 18 | +12 |
| HC→Aff bundle | 12 | 36 | +24 |

Aff 神经元数量不变，census 无污染。

### 验收

```
✓ 21/21 回归 PASS
✓ census: N=3时 +12 HC，Aff不变
✓ KCL守恒：3×6.67=20.0001 (< 0.001误差)
✓ τ分频结构：capacitance [1.0, 2.0, 4.0] 各不相同
✓ N=1接口：bundle ID / synapse_gain 零改动
```
