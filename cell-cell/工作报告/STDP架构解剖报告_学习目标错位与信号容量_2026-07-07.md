# STDP架构解剖报告：学习目标错位与信号容量分析

**日期**：2026-07-07  
**范围**：D1弧学习设计 / CPC架构 / 梯度维度压缩 / 信号容量上限  
**起因**：T-062~T-070实验系列证明STDP权重分化真实（|Δw|=0.2965），但行为无改变（DR5=50.0%）。本报告从架构层面重新检查"STDP在学什么"，以及"它应该学什么"。  
**结论摘要**：D1弧正在学习一个已经由硬连线提供的方向映射（redundant re-learning）；CPC完全手工参数化；梯度被压缩至1D；信号模式容量仅1。这四项缺陷共同解释了实验中观察到的所有失效现象。

---

## 一、完整电路拓扑（D1弧）

### 1.1 代码位置与实际连线

以下是 `nexus_v1/circuit/variant_adapter.py` 中 D1弧的完整实现（约第695-800行）：

```
relay_left
  │
  ├──[frozen, w=_W_P=0.02, g=+1.0]──→ phasic_left  (rate-of-change neuron)
  │
slow_relay_left
  │
  └──[frozen, w=_W_P=0.02, g=-1.0]──→ phasic_left  (subtraction: relay - slow_relay)
                                            │
                                            └──[STDP, DA-gated, init_w=0.1, w_max=0.3]──→ spinal_ccw
                                                                                               │
                                                                                               └──[frozen, w=0.5]──→ yaw_ccw_neuron
                                                                                                                         │
                                                                                                                         └──→ Motor
```

镜像右侧（完全对称）：
```
relay_right → phasic_right → spinal_cw → yaw_cw_neuron → Motor
```

中间层 slow_relay_left 由以下构造：
```
relay_left ──[frozen, w=1/R_slow≈6.67e-5, RC_slow]──→ slow_relay_left
```
`slow_relay_left` 是 `relay_left` 经过大时间常数RC的低通滤波输出（慢适应）。

### 1.2 每个节点的物理含义

| 节点 | 数学含义 | 生物类比 |
|------|---------|---------|
| `relay_left` | 左侧皮肤温度 T_L(t) | 热感受器（TRP通道）绝对激活 |
| `slow_relay_left` | T_L 的低通平均 ⟨T_L⟩ | SA（慢适应）感受器适应水平 |
| `phasic_left` | T_L(t) − ⟨T_L⟩ ≈ dT_L/dt | RA（快适应）感受器 / I型机械感受器的速率分量 |
| `spinal_ccw` | 脊髓CCW转向中间神经元 | 脊髓反射弧的中间神经元（Ia内部通路） |
| `yaw_ccw_neuron` | CCW偏航驱动 | 前庭-眼动反射核（VOR驱动信号） |

`phasic_left` 计算的正是**温度变化率**——当 body 接近热源（T_L 上升）时该神经元激活，当body停留在热源旁（T_L 稳定）时该神经元静默。

### 1.3 STDP束的参数

```python
# bundle_d1_phasic_left_to_spinal_ccw
initial_weight  = 0.1       # 初始值
weight_max      = 0.3       # 饱和上限
stdp_lr         = 0.001     # 基础LR
eligibility_gain = 0.05     # LTP系数
eligibility_ltd_rate = 0.01 # LTD系数
decay_rate      = 1e-5      # 权重自然衰减
```

T-062实测结果：200k步后 w_ccw→0.2994（接近w_max），w_cw→0.0029。|Δw|=0.2965。

## 二、已存在的硬连线方向映射

### 2.1 relay_left → yaw_ccw 的存在

在同一 `variant_adapter.py` 中（第HC-016修复后，约第800-830行附近），存在以下硬连线束：

```
relay_left ──[frozen, HC-016修复的thermo_to_yaw束]──→ yaw_ccw_neuron
relay_right──[frozen, mirror]──────────────────────→ yaw_cw_neuron
```

该束的物理含义：**左侧温度高 → 激活CCW偏航**（向左转）。这是完整的热趋性方向反射弧。

### 2.2 这意味着什么

D1弧的STDP在学习：
> "左侧温度上升（phasic_left激活） → 强化 → CCW转向（spinal_ccw激活）"

但 relay→yaw 的硬连线已经实现：
> "左侧温度高（relay_left激活） → 直接驱动 → CCW转向（yaw_ccw激活）"

**两条路径的逻辑目标完全相同：左侧热 → 左转。**

区别仅在于信号类型：
- D1弧用的是**温度变化率**（phasic，适合接近过程）
- relay→yaw用的是**温度绝对值**（DC，适合持续刺激）

但在实际实验条件下（体沿直线接近热源），两者高度正相关：温度上升时既有 relay_left 激活，也有 phasic_left 激活。在统计上，两者提供的方向信息几乎冗余。

### 2.3 T-062的解释

以下是 T-062 的实测轨迹（200k步）：

```
DR5（方向正确率）  ≈ 50.0% ± 0.1%（全程随机基线）
|Δw|              = 0.2965（STDP分化真实）
```

STDP权重分化真实，DR5不变——这恰好是**冗余强化**的特征：STDP在强化一条已经由relay→yaw硬连线承载的方向信息。STDP对行为的边际贡献为零，因为行为已经由硬连线的直接通路决定了。

**STDP的"成功"（权重分化到0.30）不会提升DR5，因为relay→yaw早已把行为定好了。**

## 三、方向映射的正确归属

### 3.1 什么应该是先天固化（innate）

进化/发育中固化的内容通常是：
1. **方向极性**（左热→左转）：这是本体感觉反射，先于经验存在
2. **运动肌群对应**（CCW = 左转）：肌骨系统的物理连接关系
3. **痛觉/危险反射**：不能等待学习的逃逸反应

`relay_left → yaw_ccw`（硬连线）正确地表达了这种先天极性。D1弧如果仅仅是在学习同样的极性，则是在浪费学习资源。

### 3.2 什么应该是经验学习（learned）

高等动物行为实验表明，学习获得的通常是：
1. **增益调制**（gain modulation）：在什么上下文下，强化或抑制这个反射？
   > 例："饥饿时热趋性反射增益×3；饱腹时增益×0.5"
2. **时序门控**（temporal gating）：在哪个生命状态阶段，允许这个反射发生？
3. **条件化**（conditioning）：将某个无关刺激（CS）与反射刺激（US）关联

D1弧目前的STDP学的不是这三种之一，而是在重新建立方向极性。

### 3.3 正确的STDP目标应该是什么

如果目标是"让STDP调制热趋性"，STDP束的target不应该是 `spinal_ccw`（方向神经元），而应该是**relay→yaw束本身的增益调制权重**——即在relay→yaw通路上插入一个可学习的增益控制节点：

```
[应有的架构]：

context_neuron（表达当前生命状态：饥饿/饱腹/危险/安全）
    │
    └──[STDP]──→ relay_yaw_gain_modulator（门控神经元）
                         │
                         └──[调制]──→ relay_left → yaw_ccw 的突触权重

```

这样STDP学的是：**"在什么上下文下（饥饿/接近热源的速率/过去N步的经历），应该加强还是抑制天生的热趋反射。"**

这才是神经可塑性的正确功能：**不是构建方向映射，而是调制方向映射的时空有效性**。

## 四、CPC的完整架构分析

### 4.1 代码确认（nexus_v1/components/circulation_proportion.py）

```python
@dataclass
class CirculationProportionConfig:
    v_ref: float = 0.5                  # 目标：代谢流均分（手工）
    deviation_threshold: float = 0.01   # 死区（手工，从0.05下调）
    deviation_gain: float = 1.0         # 偏差增益（手工，从0.3上调）
    homeo_capacitor_tc: float = 50.0    # 时间常数（手工）
    motor_capacitor_tc: float = 50.0    # 时间常数（手工）
    feed_capacitor_tc: float = 50.0     # 时间常数（手工）
```

`step()` 方法：
```python
def step(self, thermal_stability, body_speed, feed_rate, dt):
    # 计算三路电容电压（低通积分）
    v_homeo = self._c_homeo.charge / self._c_homeo.capacity
    v_motor = self._c_motor.charge / self._c_motor.capacity
    v_feed  = self._c_feed.charge  / self._c_feed.capacity

    # MOSFET比较器：偏差→DA电流
    rho_homeo = v_homeo / (v_homeo + v_motor + v_feed + 1e-9)
    deviation = abs(rho_homeo - self.config.v_ref)
    if deviation > self.config.deviation_threshold:
        self._da_current = (deviation - self.config.deviation_threshold) * self.config.deviation_gain
    else:
        self._da_current = 0.0
    # 无任何 learn() 调用，无任何权重
```

**结论**：CPC是纯计算电路，不含任何学习机制。所有参数均为手工设定常数。

### 4.2 CPC的功能定位

CPC度量的是**代谢流比例偏离稳态的程度**，并将这种偏离转化为DA激励：

```
rho_homeo（体内平衡消耗占比）
    │
    ↓ |rho_homeo - v_ref| > threshold？
    │
    └──→ da_current = (deviation) × gain   → DA上升（表示系统不在稳态）
```

这类似于下丘脑的**稳态调节器**（homeostatic regulator）：检测内环境偏离，触发动机（Drive）激活。这确实应该是半硬编码的——偏离稳态本身就是刺激行为的生物学基础，不应该"学习到后才开始工作"。

### 4.3 CPC应否引入学习

部分参数有自适应的合理性：

| 参数 | 当前 | 应否自适应 | 理由 |
|------|------|----------|------|
| `v_ref=0.5` | 固定 | **可自适应** | 不同生理状态下稳态比例不同（如运动员vs静止者的代谢分配） |
| `deviation_threshold=0.01` | 固定 | 可调 | 但这是敏感度参数，生物学上相对稳定 |
| `deviation_gain=1.0` | 固定 | 可调 | 与DA神经元的响应曲线有关，相对稳定 |
| `tc=50` | 固定 | 不需要 | RC时间常数有明确的生物学基础 |

**结论**：CPC的核心逻辑（偏离→DA）是正确的硬编码；`v_ref`有自适应的合理性，但这不是当前优先级。CPC不是STDP→行为传导失效的原因，但它的固定 `v_ref=0.5` 意味着"稳态定义"是人工给定的，未来体型/代谢变化时需要手动重调。

## 五、梯度维度压缩分析

### 5.1 热梯度的真实维度

空间中热源的温度梯度是3D向量场：
```
∇T(r) = [∂T/∂x, ∂T/∂y, ∂T/∂z]
```

对于点热源（如实验中的 [70, 50, 25]），这简化为：
```
∇T ≈ k × (r_source - r_body) / |r_source - r_body|^3
```

这个向量有三个分量，每个分量都携带独立的方向信息。

### 5.2 当前架构的维度投影

当前皮肤感受器（somatosensory）将热梯度投影到以下坐标系：

```python
# somatosensory/chain.py 中的 patch 分布（6面体）
patches = {
    'front': body_forward_direction,    # 前方
    'back':  -body_forward_direction,   # 后方
    'left':  body_left_direction,       # 左方
    'right': -body_left_direction,      # 右方
    'top':   body_up_direction,         # 上方
    'bottom':-body_up_direction,        # 下方
}
```

但进入STDP学习路径的只有：
```
relay_left  (左侧patch温度)
relay_right (右侧patch温度)
```

**前方/后方的温差信号（approach/retreat）完全没有进入学习路径。**

### 5.3 前/后信号的关键性

热趋性行为中，**前方热 vs 后方热**的对比才是最直接的"我是否在接近热源"的信号：

```
T_front > T_back → 热源在前方 → 继续前进
T_front < T_back → 热源在后方 → 需要180°转向
```

当前系统通过yaw旋转来趋热，而不是直线前进——这使得前/后信号的重要性略低于左/右。但这本身也是架构的选择，并非必然。在更完整的设计中，前/后温差应触发"直线加速"（pitch/roll变化），左/右温差触发"yaw转向"。

### 5.4 参考系漂移问题

最严重的维度问题不是"少了哪些轴"，而是**参考系定义本身随body旋转而漂移**。

当前STDP学习的关联是：
```
"左侧patch温度上升" → "CCW转向"
```

但"左侧"是在**body固连坐标系（body frame）**中定义的。当body的yaw角变化时：
- yaw=0°：body heading朝+x，"左"= +y方向
- yaw=90°：body heading朝+y，"左"= -x方向
- yaw=180°：body heading朝-x，"左"= -y方向

同一个热源在世界坐标系的固定位置 [70, 50, 25]，在body frame中随着yaw的变化，时而在"左侧"，时而在"右侧"，时而在"前方"。

**STDP学的是body frame的关联，但热源在world frame是固定的。**这导致：
- body转向90°后，"左侧热→左转"的规则突然变成了"后方热→左转"（在world frame中是错误的）
- 每次body旋转，已学到的关联就部分失效

这是当前 T-040（CPG随机，方向反转）观察到的行为不稳定性的深层原因之一：学习是在旋转坐标系中进行的，没有经过从body frame到world frame的坐标变换。

### 5.5 正确的梯度编码应该是什么

理想情况下，输入STDP的信号应该是：
```
∇T · v̂_heading   （梯度与前进方向的点积，"是否在接近热源"）
∇T · v̂_left      （梯度与左方向的点积，"热源偏左多少"）
|∇T|             （梯度幅度，"热源有多近"）
```

这些量在world frame中定义，与body旋转无关，学到的关联是稳定的。要实现这种编码，需要在patchinput → relay层面做坐标变换——但这涉及到把yaw/pitch/roll状态反馈到感知层，在现有架构中代价较高（且不符合纯结构涌现原则）。

## 六、STDP信号容量的数学上限

### 6.1 单束单Memristor = 1个实数

当前每条STDP束的权重矩阵为 **1×1**（单个Memristor）：
```python
self._memristors = [[Memristor(initial_weight=w0)]]  # shape: (1,1)
```

一个Memristor存储一个实数 w ∈ [w_min, w_max]。这个实数编码的是：

> "在过去所有经历中，pre神经元的激活与post神经元的激活的**总体正相关程度**（加权DA调制）。"

它只能存储一个方向的偏好强度，不能存储：
- 条件偏好（"在X条件下偏好A，在Y条件下偏好B"）
- 时序偏好（"在时刻t偏好A，在时刻t+k偏好B"）
- 竞争选择（"在同等激励下选A还是选B"）

### 6.2 两束无竞争 = 无方向选择

```
bundle_d1_phasic_left_to_spinal_ccw   (w_ccw, STDP)
bundle_d1_phasic_right_to_spinal_cw   (w_cw,  STDP)
```

这两条束**共享同一个DA信号**，且没有侧抑制（lateral inhibition）。

在DA奖励时：
- T_L上升 + T_R平静 → phasic_L激活，phasic_R不激活 → 只有 w_ccw 被LTP
- T_L上升 + T_R同时上升（两侧均匀接近热源）→ phasic_L≈phasic_R → **w_ccw 和 w_cw 同时被LTP**

第二种情况（均匀接近，body正对热源）在T-062中频繁发生，导致两束权重同时上升。只有在body偏转（非正面接近）时，两束才有差异。

**没有竞争机制，两束各自朝w_max饱和，不互相抑制。** 这就是为什么 T-062 最终 w_ccw=0.2994 AND w_cw=0.0029——并非CCW获胜，而是CCW收到的奖励信号更多（body在T-062的几何设置中偏左接近热源）。如果几何设置不同，结果可能是CW=0.30，CCW=0.003。

### 6.3 正确的竞争机制

典型的侧抑制（WTA, Winner-Take-All）应为：

```
spinal_ccw ──[inhibitory bundle, frozen]──→ spinal_cw
spinal_cw  ──[inhibitory bundle, frozen]──→ spinal_ccw
```

这样当phasic_left强烈激活spinal_ccw时，spinal_ccw同时抑制spinal_cw，两者形成竞争。DA奖励时，获胜方（激活更高的方向）权重增强，失败方权重被间接抑制。

这是生物学上**基底神经节**的核心计算：通过D1/D2通路的直接/间接通路实现"哪个action的Q值更高就选哪个"的竞争选择（Mink 1996, Frank 2005）。

## 七、宏观状态空间与学习容量

### 7.1 当前只有2个稳定宏观状态

```
状态A（觅食态）：fill < 0.85 AND DA > 0.1
  ├─ 持续时间：~25k步（单次Foraging窗口）
  ├─ 占总时间：13-17%（T-062/T-064实测）
  └─ STDP门控：开放（LTP激活）

状态B（饱腹态）：fill ≈ 1.0
  ├─ 持续时间：~175k步（主体）
  ├─ 占总时间：83-87%
  └─ STDP门控：关闭（DA≈0，LTP=0，但LTD仍在侵蚀权重）
```

STDP在200k步实验中的有效学习时间：**~25k步**。

### 7.2 信号模式多样性不足

在这25k步内，系统经历的信号模式非常单调：

```
fill: 0.30 → 1.00 (单调上升，不重复)
DA:   低 → 高 → 最终稳定高
dist: 60 → 0 (单调下降)
phasic_L/R: 接近时激活，到达后静默
```

这是一个单次事件的展开，而不是反复出现的经历。STDP设计用于处理**统计意义上反复发生的时序关联**（Hebb 1949），但当前25k步只给了它一次体验。

对比：人类学习骑车需要数百次反复；条件反射（Pavlov）需要数十次配对；线虫的热趋性条件化（Mori & Ohshima 1995）需要30-60分钟的预处理。25k步对于统计学习来说可能只相当于一两次。

### 7.3 DA→STDP的时间积分缺失

当前三因子STDP的学习规则：
```python
# bundle.py: learn()
ltp = eligibility_gain × E(t) × DA(t)   # 点采样 DA(t)
ltd = eligibility_ltd_rate × dt × pre_trace × post_act
w  += (ltp - ltd - decay_rate × w) × dt
```

`DA(t)` 是**此刻**的DA值，点采样。这导致：
- fill=1.0导致DA=0时，LTP**立刻归零**，不管过去25k步建立的eligibility有多高
- LTD仍然在以固定速率侵蚀所有权重
- 一旦fill饱和，STDP从净增变为净减（LTD无门控，LTP有门控）

**T-067的实测证据（T=100k步后Δw→0）**：
```
T-067 w_CORRECT_L 变化：
  20k步：+0.0035（STDP活跃期内，LTP>LTD）
  35k步：fill饱和，DA→0，LTP=0，LTD持续
  100k步：w_CORRECT_L ≈ 0.0000（LTD把全部增益侵蚀殆尽）
```

即：STDP在单次Foraging窗口内学到的权重，被180k步的LTD完全磨平。

## 八、四项架构缺陷的完整目录

综合以上分析，STDP→行为传导失效的原因可以精确归纳为四项相互独立的架构缺陷：

### 缺陷 1：学习目标冗余（Direction Learning Redundancy）

**现象**：D1 STDP学习`phasic_left→spinal_ccw`，即"左侧温度变化率→CCW转向"。  
**问题**：这一方向映射已由`relay_left→yaw_ccw`硬连线提供。STDP在强化已存在的结构。  
**后果**：STDP权重分化不增加行为能力（DR5不变），因为行为由硬连线决定，STDP是边际添加。  
**正确目标**：STDP应学习**反射增益的上下文调制**，而非方向极性本身。

### 缺陷 2：梯度维度压缩（Gradient Dimensionality Reduction）

**现象**：输入STDP的信号只有left/right两路，不包含front/back和gradient magnitude。  
**问题**：3D梯度被压缩至1D，丢失"是否在接近热源"（前/后分量）的核心信息；参考系随body旋转漂移。  
**后果**：学到的关联在body转向后部分失效；无法区分"直接接近"和"侧面滑行"。  
**正确目标**：输入信号应在world frame中编码（或至少包含前/后分量），参考系稳定。

### 缺陷 3：竞争机制缺失（No Competitive Inhibition）

**现象**：CCW束和CW束没有侧抑制连接，DA同等奖励两者。  
**问题**：在均匀接近（body正对热源）时，两束同时获得LTP，权重同向上升。  
**后果**：STDP无法完成真正的方向选择（WTA），结果取决于几何偶然性而非学习。  
**正确目标**：引入`spinal_ccw → spinal_cw`的抑制束（frozen），形成竞争选择结构。

### 缺陷 4：时间积分断裂（DA Temporal Integration Missing）

**现象**：LTP使用点采样`DA(t)`，LTD无DA门控，fill饱和后LTP立刻归零。  
**问题**：单次Foraging窗口（25k步）内学到的权重，被其后175k步的无门控LTD完全侵蚀。  
**后果**：跨周期学习不能累积（T-067验证：100k步时权重回零）。  
**正确目标**：引入DA的慢时间积分（EMA），使STDP响应"过去τ_slow步的平均DA"，而非瞬时值。

## 九、缺陷的相互作用与实验表现对应

这四项缺陷不是独立的，它们共同放大效果：

```
缺陷4（时间积分断裂）
  → Foraging窗口结束后权重归零
  → 缺陷1学到的已是冗余信息，丢失更无关紧要
  → 即使缺陷4修复，缺陷1导致STDP"成功学到"也不改变行为

缺陷3（无竞争）
  → 两束同时增强，无方向选择
  → 行为表现为"随机偏CCW"（w_ccw稍高于w_cw），不是"学到的左转"
  → 配合缺陷2（1D梯度），方向选择准确率上限 < 70%

缺陷2（梯度1D）
  → 参考系漂移导致学到的关联在body旋转后失效
  → 即使所有其他缺陷修复，长期统计准确率仍受限
```

这解释了为什么T-062~T-067系列实验中：
- **权重分化总是真实的**（phasic_left确实在接近热源时激活，STDP确实在学）
- **行为从不改变**（硬连线relay→yaw已经处理了行为，STDP的贡献是零）
- **跨周期改善从不出现**（缺陷4：权重在fill饱和期被LTD清空）

## 十、最小可行修复路径（优先级排序）

基于上述分析，按照"改动最小、验证最快、增益最大"的原则排序：

### P0：缺陷4修复 — DA慢积分（约10行代码）

**操作位置**：`nexus_v1/circuit/bundle.py` → `learn()` 方法  
**改动内容**：将 `DA(t)` 替换为 `DA_slow = α × DA(t) + (1-α) × DA_slow_prev`（EMA，τ=5000步，α=1/5000）  
**预期效果**：fill饱和后STDP不立刻冻结；已建立的eligibility在后续τ_slow步内继续工作  
**验证方式**：T-072（热源消失多周期）中观察 w_ccw 在第二次Foraging窗口开放时是否从非零值开始继续增加

**风险极低**：τ=5000步仅影响STDP时间尺度，不影响RC物理方程、KCL守恒、能量守恒。

### P1：缺陷3修复 — 竞争侧抑制（约15行代码）

**操作位置**：`variant_adapter.py` → D1弧构造区域  
**改动内容**：在 `spinal_ccw` 和 `spinal_cw` 之间添加frozen inhibitory束（w=0.3, g=-1.0）  
**预期效果**：当phasic_left强烈激活时，spinal_ccw同时抑制spinal_cw，形成真正的WTA  
**验证方式**：T-067变体（交叉接线）中竞争束的权重分化应更快、更稳定

### P2：缺陷1修复 — 学习目标重定向（架构级，需三问前置）

**操作位置**：需要重新设计D1弧的downstream target  
**改动内容**：将STDP束的target从 `spinal_ccw` 改为 relay_to_yaw束上的增益调制节点  
**前置条件**：三问（Q1生物对应物/Q2物理结构/Q3参数依据）  
**预期效果**：STDP不再学习方向极性（已由硬连线提供），而是学习"何时加强/抑制热趋反射"  
**风险较高**：需要引入新的神经元类型或突触调制机制

### P3：缺陷2修复 — 梯度维度扩展（架构级，需三问前置）

**操作位置**：somatosensory/chain.py + variant_adapter.py  
**改动内容**：将front/back温差信号引入STDP路径；或在relay层实现body frame→world frame的部分修正  
**前置条件**：三问  
**备注**：这是最大的架构改动，建议在P0/P1验证后再评估

## 十二、结论

本报告通过代码分析和实验数据交叉验证，证明了以下核心论点：

1. **D1弧STDP正在学习方向极性**（左热→左转），而这个映射已由硬连线提供，STDP的贡献是零边际。这是最根本的设计错误：STDP的target选择错了层次。

2. **CPC完全硬编码**，是正确的工程决策（稳态调节不需要学习），但其`v_ref`设定点的固定性意味着"稳态定义"是人工给定的。

3. **梯度被压缩到1D**（left/right），在旋转参考系中学到的关联不稳定，前/后分量（直接接近信号）被完全忽略。

4. **信号容量上限=1**：单Memristor × 无竞争 × 2个宏观状态 × 无时间积分 = STDP实际只能编码一个静态偏好，且会在fill饱和期被LTD侵蚀殆尽。

**短期可操作的改进**：P0（DA慢积分，10行）+ P1（竞争侧抑制，15行），预计可将跨周期权重保留率从当前≈0%提升至>50%，并让STDP开始真正产生竞争选择。但这仍然是在缺陷1（学习目标冗余）存在的情况下改进的，行为变化的绝对幅度仍然有限。

**中期架构目标**：重定义D1弧的STDP目标为"反射增益调制"而非"方向极性学习"，并在relay→yaw路径上插入可学习的增益控制节点。这才是STDP在神经生物学中的真实功能角色。
