# 方案三问审查报告 Part 2：《静默中继与拓扑保真度修剪统一框架》

**日期：** 2026-07-07  
**审查依据：** RULES.md 三问 + 结构涌现约束  
**结论：理念有生物根基，但工程路径有根本性缺陷，建议回炉重做**

---

## 总体定位

文件2 描述的是一个"从头自组织"方案——废除现有所有人工预设拓扑，通过全连接初始化 + Ollivier-Ricci 曲率修剪，让方向选择从活动相关性中自发涌现。

**核心矛盾：** 这与当前进行中的实验（T-071 修复 H-B 断路）形成架构层面的直接冲突——T-071 是在修复现有预设拓扑中的断路问题，而文件2 的 V1 要求将这套预设拓扑全部废除。

以下逐条审查揭示了三类根本性缺陷。

---

## 缺陷一：V1 全连接废预设拓扑（架构层面，不可回滚）

### 内容
"扩展 phasic→spinal 为 4 条全连接束（L→L, L→R, R→L, R→R），废除预设方向映射，200k 验证：出现方向分化"

### Q1 生物对应物
✅ 有依据。发育中脊髓中间神经元确实双侧投射，方向选择通过STDP涌现。Science 2024 论文证实轴突活动相关性预测修剪结果。

### Q2 物理结构问题
当前 `phasic_left → spinal_ccw` 是经 T-041/T-065/T-071 系列验证的热趋性核心（DR5% 60-71%，43步重定位新热源）。V1 要求：
1. 把这条已验证的有向连接拆成 4 条全连接束（2条正向 + 2条错误方向）
2. 全部从 `w_0 = 0.001` 随机初始化
3. 等待 200k 步自发涌现方向分化

**风险点：**
- 当前所有热趋性行为（DR5%=60-71%）**归零**，无保证能在 200k 步内重新涌现
- V4 翻转验证是"初始权重相等，CPG随机相位"——这意味着"胜出方随CPG相位随机化"，即**方向是随机的**，不能保证热趋性方向正确
- **没有回滚路径**：一旦 V1 启动并废除预设拓扑，当前状态无法快速恢复

### Q3 参数来源
| 参数 | 状态 |
|:---|:---|
| `w_0 = 0.001` | ❌ 无实验依据（为何是 0.001？） |
| `λ`（距离衰减常数）| ❌ **完全未定义** |
| `L_ij`（节点间物理距离）| ❌ cell-cc 的 World 坐标系中未定义神经元物理位置 |
| 全连接 4 束的 STDP 参数 | ❌ 均未定义 |

**3 个核心参数缺失 2.5 个。**

**结论：❌ V1 是一个高风险不可回滚操作。不应在主分支执行。**

## 缺陷二：Ollivier-Ricci 曲率的可实施性

### 内容
`κ(u,v) = 1 - W_1(μ_u, μ_v) / d(u,v)`，用于识别拓扑重要边，驱动二维修剪判据

### Q1 生物对应物
⚠️ ORC 是数学工具，不是直接的生物机制。文件声称"移除负 ORC 边会迅速降低神经网络性能"——这是在宏观连接组（840节点，81,434 连接）上的实证。  
**Cell-cc 有 226 条 bundle，远小于统计有效样本量，ORC 结论不直接适用。**

### Q2 物理结构
ORC 需要计算 Wasserstein 距离（W₁），这是一个最优传输问题，**必须用 Python 离线求解**（POT 库或自定义实现），无法用 Capacitor/MOSFET 原语实现。

**这本身不违规**——类似 EntropyLedger 的 INFRA 诊断工具。但关键问题是修剪动作如何触发：

| 修剪触发方式 | 合法性 |
|:---|:---|
| Python 判断 `if κ(e) > threshold: delete bundle` | ❌ **违规**——Python 语义决定物理结构 |
| Python 判断后设置 `λ_metabolic ↑`，通过自然衰减修剪 | ⚠️ 中间地带，仍需用户确认 |
| ORC 结果驱动 MOSFET 抑制电流，自然减弱突触传导 | ✅ 合规，但工程复杂度高 |

### Q3 参数来源
| 参数 | 状态 |
|:---|:---|
| `κ_threshold`（修剪 ORC 阈值）| ❌ "静态分位数法"，哪个分位数？未定义 |
| `A_threshold`（活动度阈值）| ❌ **完全未定义** |
| `T_prune`（修剪触发间隔）| ❌ **完全未定义** |

**结论：⚠️ ORC 仅可作为离线诊断工具（INFRA），不能直接驱动 bundle 删除。修剪决策需要物理化。**

## 缺陷三：代谢-信息效率指标（互信息 = 硬编码）

### 内容
`Inefficiency(n_i) = Energy_Consumed(n_i) / Mutual_Information_Contribution(n_i) > ε_waste`  
其中 `Mutual_Information_Contribution` = 节点活动与系统全局运动势 ν 下降之间的互信息

### Q1 生物对应物
✅ 高能耗低贡献神经元被修剪的概念有生物基础（Bhaskara 2011 下丘脑代谢门控）。

### Q2 物理结构
- `Energy_Consumed`：✅ EnergyStore 已实现
- `Mutual_Information_Contribution`：**❌ 这是统计量计算**：需要估计概率分布 p(活动|ν变化)，再计算 KL 散度/互信息。这是 Python 数学直接判断"哪个神经元对热趋性有贡献"——**语义硬编码**。

**核心问题：** 互信息计算给出的是"有没有因果关联"的语义结论，但 RULES.md 要求因果关联从物理结构涌现，不能由数学公式直接判断。

**→ 替代方案：** 用 `Xin tension`（预测残差张力）作为代理量：
```
Inefficiency(n_i) = Energy_Consumed(n_i) / sum(|xin| of all bundles sourced/targeted by n_i)
```
`Xin` 是纯物理量（已在 TOPRXin 框架中定义），不需要统计推断。

### Q3 参数来源
- `ε_waste`：**❌ 完全未定义**

**结论：❌ 互信息计算 = 语义硬编码，必须替换为 Xin 代理量。**

## 缺陷四：静默中继的"保护"机制

### 内容
低活动度 + 高拓扑重要性（负ORC）的边 → **保留（静默中继）**，不修剪

### Q1 生物对应物
✅ 潜伏突触（Latent Synapse）的概念有神经科学基础（Bhaskara 2011; Bhaskara 2017）。

### Q2 物理结构问题
"保护免修剪"如何实现？

| 保护方式 | 合法性 |
|:---|:---|
| Python `if ORC < threshold: skip_prune` | ❌ Python 条件控制物理结构 |
| 设置极低的 `lambda_metabolic`（自然慢衰减）| ✅ 合规，通过物理速率自然区分 |
| 通过高 `xin_tension` 维持（预测残差维持束存活）| ✅ 合规，TOPRXin 框架已支持 |

**正确实现：** 静默中继应通过**自然的低代谢衰减速率**（`lambda_metabolic ≈ 1e-8`）在 200k 步内自然存活，无需 Python 主动保护。真正不重要的连接（高正ORC，低活动度，低Xin）通过正常 STDP 衰减被自然修剪。

**"去沉默化"（Reactivation）**：触发条件和机制**完全未定义**。

**结论：⚠️ 静默中继保护可物理化（低 lambda），但去沉默化机制需要重新设计。**

## 重做建议

如果要保留统一框架的核心价值（从全连接中自组织涌现），建议按以下方向重构：

### 保留的有价值部分
1. **全连接初始化 + 距离依赖权重**：合法，Biology 支持，只需定义 λ
2. **二维修剪判据的概念**：低活动度 × 低Xin → 自然衰减（不需要 ORC）
3. **V4 翻转验证实验设计**：验证方法本身合理
4. **渐进 V1-V4 阶段**：工程路径结构良好

### 需要重新设计的部分
1. **用 Xin tension 替代互信息**（纯物理量，已在框架中定义）
2. **用自然衰减替代 Python 驱动修剪**（`lambda_metabolic` 差异化 = 不同存活率）
3. **ORC 降级为诊断工具**（INFRA），不进入在线决策路径
4. **V1 在独立 worktree 中验证**，不在主分支执行
5. **补充 λ、A_threshold、T_prune 的实验推导方案**
