## 一、Ca²⁺ 通道物理化方案审计

### 1.1 总体判断

**Phase A（独立组件，不接入电路）：方向正确，有两个需要在编码前锁定的设计缺口。**  
**Phase B（接入 HairCell）：时机判断完全正确，当前不阻塞任何工作。**

### 1.2 设计缺口一：单位系统未解决（阻塞实施）

文档第 3.2 节参数表：

```
V_half（激活半程电压）= -41 mV   ← 生物学单位
k（斜率因子）         = 5 mV     ← 生物学单位
E_Ca（反转电位）      = 50 mV    ← 生物学单位
g_max                = 2.0 nS    ← 生物学单位
```

仿真器的神经元电压是**无量纲归一化值**。HairCell 的 MOSFET 阈值 `v_threshold=0.308`，正常工作区间约 0.2–0.8——这不是毫伏，是任意归一化单位。

如果 `CalciumChannel.conductance(V_m)` 直接接收归一化 V_m，代入 `exp(-(V_m - (-41.0)) / 5.0)` 会得到：
```
V_m = 0.341（正常输入）
指数项 = exp(-(0.341 + 41.0) / 5.0) = exp(-8.268) ≈ 0.000257
g_ca ≈ 2.0 × (1 - 0.000257) ≈ 2.0 nS（几乎最大值！）
```

这与物理意图相反——在正常激励下通道应当几乎关闭，而非全开。

**必须在 Phase A 实现前锁定的桥接约定：**

| 问题 | 选项 A | 选项 B |
|------|--------|--------|
| CalciumChannel 接受哪个单位的 V_m？ | 接受生物学 mV，提供 `v_sim_to_mv(v)` 转换 | 改写参数为仿真单位（V_half≈0.308, k≈0.05）|
| 对应实现 | `I_Ca = channel.current(v_sim_to_mv(n.membrane.voltage))` | 参数锚定到 HC MOSFET 阈值，注释保留生物学来源 |
| 推荐 | — | **推荐选项 B**：不引入额外转换层，参数含义更直接 |

选项 B 的具体推导：HC MOSFET 在 `v_threshold=0.308` 附近激活。对应生物学 -41mV 激活半程，换算比例约 `0.308/(-41) ≈ -0.0075 V_sim/mV`（注意符号：生物膜电位在激活时从 -70mV 上升到 -41mV；仿真归一化电位从 0 上升到 0.3）。

实际操作最简：**直接用 HC 的实测阈值定义 V_half，k 设为 HC 正常超阈范围的 10%**：
```python
# BIO: CaV1.3 半激活电压 -41mV (Bao 2003)，映射到仿真归一化单位
V_half = 0.308   # 对应生物学 -41mV（HC MOSFET 阈值）
k      = 0.030   # 斜率因子（约10% 超阈范围）
# REF: Bao et al. 2003 J Neurophysiol — 比例锚定到 HC v_threshold
```

### 1.3 设计缺口二：CalciumDynamics 极性约定不明确

文档的 RC 积分器：
```python
def step(self, I_Ca, dt):
    dV = (I_Ca - self.V_ca / self.R_ca) / self.C_ca * dt
    self.V_ca += dV
    return self.V_ca
```

CaV1.3 的 Ca²⁺ 电流是**内向电流**（电流从胞外流向胞内），在标准电生理约定下 I_Ca < 0。代入后 `dV = (负值 - V_ca/R_ca)/C_ca × dt`，导致 V_ca 下降而非积累——与"钙缓冲充电"的意图相反。

有两种修正方式，需要明确选择一种：

**修正 A**：取绝对值，用 `|I_Ca|` 作为充电驱动：
```python
dV = (abs(I_Ca) - self.V_ca / self.R_ca) / self.C_ca * dt
# 注释：I_Ca 为内向（负），取绝对值表示钙离子内流量
```

**修正 B**：反转 current 函数的符号约定，令输出 > 0 表示内向流：
```python
def current(self, V_m):
    # 内向电流取正值（生物学约定取反）
    return self.conductance(V_m) * (self.E_Ca - V_m)  # 注意顺序
```

推荐**修正 B**：在 current 函数处统一处理符号，后续代码更清晰。

### 1.4 参数 R_ca、C_ca 缺乏单位和依据

文档列出：
- `C_ca = 10.0  # 钙缓冲电容`
- `R_ca = 100.0  # 钙清除电阻`

对应时间常数 τ = R×C = 1000（单位？）。文档声称 τ_ca = 50ms，但 1000 ÷ 50ms = 20（dt换算因子）——这意味着 dt=0.001s=1ms，所以 τ=1000步×1ms/步=1000ms=1s，而非 50ms。

**要求**：在注释中明确：
```python
self.C_ca = 10.0   # 归一化钙缓冲电容
self.R_ca = 5.0    # 归一化钙清除电阻
# τ = R×C = 50步 = 50ms (at dt=0.001s)
# BIO: 钙缓冲清除时间常数 50ms (Burrone & Lagnado 2000)
```

（原 R=100 给出 τ=1000ms=1s，超出文献范围。需要重新推导或引用支持 1s 时间常数的文献。）

## 二、器官到神经结构映射表草案审计

### 2.1 总体判断

**框架成立，物理几何决定神经容量这一原则与建构定律和 TSI 账本完全自洽。**  
**以下评估分为：确认正确的结论 / 需要补充的信息 / 需要修正的内容。**

### 2.2 确认正确的结论

**前庭密度数据**（综合反馈已锚定）：

| 参数 | 采纳值 | 置信度 |
|------|--------|--------|
| ρ_hc（毛细胞密度）| 20,000/mm²（保守值；范围 20k-100k）| 中（内部来源矛盾 3-5×，取下界）|
| ρ_aff（传入纤维密度）| 30,000/mm² | 中 |
| 收敛比 | 2:1–3:1（毛细胞→传入）| 中 |

**皮肤热感受器密度**：ρ_thermo≈1-5/mm²，与 TRPV3/TRPM8 稀疏分布一致，可采纳。

**时间常数修正**：SkinPatch τ=5ms → 5s，生物组织热扩散率 ~0.14 mm²/s，穿透 1mm 皮肤需秒级，文献反馈确认正确。

**Langevin 噪声离散化**：使用 `sqrt(dt)` 而非 `dt`，这是非协商的 SDE 物理要求。

### 2.3 需要补充的信息（不阻塞 V2.0 启动）

**皮肤痛觉感受器密度 ρ_noci 内部矛盾：**
- 草案正文：100-200/mm²
- 草案第四节：5-10/mm²
- 差异：约 20× 倍

综合反馈指出这可能是"游离神经末梢总数"（100-200）与"TRPV1 特异性标记密度"（5-10）的概念差异。当前体感重构（12 贴片）不依赖这个数字——痛觉束 synapse_gain 和数量设计与 ρ_noci 解耦。但在进入 Phase B 规模泛化之前，这个参数必须明确。

**口器热感受器密度 ρ_mouth**：文献缺失，当前口器模型（η=0.50 热换能器）已足够，不阻塞任何近期工作。

### 2.4 一处计算路径值得验证

映射表中的量纲链：

```
A_patch × ρ_thermo = N_thermo
A_patch(中环) ≈ 10 mm²（BodySurface 网格计算）
ρ_thermo = 2.0/mm²
N_thermo = 20 → 远期目标 20-40 个热感受器（合理）
```

但当前方案的中环 4 个贴片 + 上下环各 4 个，总计 12 个贴片。若每贴片面积约 10mm²，体表总面积约 120mm²。小鼠体表面积~20cm²=2000mm²。这意味着 12 贴片只覆盖体表的约 6%——在 4→12 扩展后，空间采样率仍然极低。

**这不是错误，而是现阶段的合理简化**。但后续讨论规模泛化意义时，应明确标注当前是"稀疏原型"而非"完整覆盖"。

### 2.5 换能束 source 类型问题（跨文档核心缺口，Part 2 详述）

映射表在 3.2 节提出"换能束（transducer_env_to_thermo_{pid}）"，source 为 `skin_patch_{pid}`。这引出了一个在全部七份文档中都未被正面回答的设计问题——SkinPatch 不是 Neuron，SynapticBundle 要求 source 是 Neuron。这个桥接问题将在 Part 2 体感重构章节中详述。

### 2.6 框架价值（超出直接实施范围的战略意义）

物理几何 → 神经容量映射框架的最大价值是**提供了参数选择的计算路径**：
- 在过去，`synapse_gain=16`（工程补偿值）没有推导来源
- 框架给出：`synapse_gain ∝ 1/N_aff`，在 N=1 时对应生物目标值 0.48 需要 33× 补偿，这个补偿量可从 ρ_hc、A_crista 推导，不再是任意值
- 这是把"无来源参数"转化为"有物理推导参数"的方法论，与三问规范一致
