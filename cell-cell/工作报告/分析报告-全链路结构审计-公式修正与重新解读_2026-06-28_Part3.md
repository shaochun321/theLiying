## A. 发现的公式错误

### 错误来源

在 `nexus_v1/ledger/signal_path_audit.py` 的 `measure()` 方法中：

**错误代码（原始版本）：**
```python
if rec.deviation > 0.1:
    rec.motor_drive = (rec.deviation - 0.1) / max(dt, 1e-9)  # 除以 dt！
```

**实际代码（variant_adapter.py line 762-767）：**
```python
DEVIATION_MOTOR_GAIN = 1.0
deviation = circ['deviation']
if deviation > 0.1:
    motor_drive = (deviation - 0.1) * DEVIATION_MOTOR_GAIN  # 乘以 1.0！
```

`DEVIATION_MOTOR_GAIN = 1.0`（不是 `1/dt = 1000`）。公式错误产生 1000× 放大效应。

### 修正前后对比

| 指标 | Part 1 数据（错误） | 修正后数据 |
|------|------------------|----------|
| mean_motor_drive | 117.73 V/step | **0.014** A |
| max_motor_drive | 145.25 | 0.044 |
| DEVIATION 激活比例 | 100.0% | **63.3%** |
| DEVIATION/STDP 比值 | 27,733× | **1.3×（含 inertia）** |
| V_ss(R_leak=5.0) | 0.58 V | **0.071 V < v_peak** |

注：`Signal_path_audit.py` 已修正为正确公式（commit annotation: AUDIT-CORRECTION 2026-06-28）。

## B. 修正后的真实机制

### V_ss 分析

Motor 神经元参数：
- `capacitance = 0.3 F, r_leak = 5.0 Ω, v_peak = 0.2 V, v_threshold = 0.15 V`

V_ss（稳态电压）= mean_motor_drive × R_leak = 0.014 × 5.0 = **0.071 V < threshold(0.15)**

**结论：在 0-30k 步的探索/接近阶段，DEVIATION_MOTOR_GAIN 单独无法驱动 Motor 发放。Motor 的发放需要 STDP + DEVIATION 的联合驱动。**

### 真实信号量级关系（修正后，0-30k步）

| 信号来源 | 有效电流（到达膜） | 比例 |
|---------|----------------|------|
| DEVIATION（mean active） | 0.014 A | 48% |
| STDP max bundle（inertia×2） | 0.0107 A | 37% |
| STDP remaining bundles | ~0.003 A | ~10% |
| VitalOscillator | ~0.0004 A | ~1.4% |

**STDP 是竞争性的，贡献约 37-47% 的等效注入。** 这与 Part 1 "STDP 被淹没"的结论完全相反。

## C. 阶段性 DEVIATION 主导分析

虽然 0-30k 步 DEVIATION 不主导，但从 Phase 4-C 长程数据可知：

| 阶段 | 步数区间 | deviation | motor_drive | DEVIATION/STDP 估算 |
|------|---------|----------|------------|---------------------|
| 探索/接近 | 0-30k | 0.120 | 0.014 | ~1-2× |
| 轨道锁定 | 30k-130k | 0.186 | 0.086 | ~10-20× |
| 能量崩溃 | 130k-200k | 0.3+ | 0.2+ | >50× |

**轨道锁定期**（Phase 4-C step 30k 开始）：body_speed 高 → v_motor 高 → rho_homeo = 0.514 < set_point 0.7 → deviation = 0.186 → motor_drive = 0.086 → V_ss = 0.43 V >> v_peak = 0.2。

此时 DEVIATION 确实主导（~10-20×），但这是轨道锁定的**后果**，不是**原因**。

**能量崩溃期**（fill → 0）：deviation → 0.3+，motor_drive → 0.2+，V_ss → 1.0+ V，DEVIATION 完全主导，权重清零。

## E. 轨道锁定的物理机制分析

从 Phase 4-C 数据（0-30k步回放）：

```
step  5,000: dist_surface=9.30, yaw=0.6°
step 10,000: dist_surface=8.60, yaw=2.8°  ← 接近中
step 15,000: dist_surface=8.03, yaw=6.4°
step 20,000: dist_surface=7.85, yaw=8.7°  ← 速度变慢
step 25,000: dist_surface=7.27, yaw=8.1°  ← yaw 方向开始曲折
```

接近速度：从 5k→10k 步降低了 0.70 m（5s），到 20k→25k 步降低了 0.58 m（5s）——接近速度在减慢，同时 yaw 角度增加，表明运动轨迹从径向变为切向。

这是经典的**轨道过渡**：径向速度减小，切向速度增加，在临界点形成圆轨道。

**问题本质**：k_conv=0.47 提供的热对流力是各向同性的（同等提升所有方向的运动能力），包括切向运动。而学习只影响 Motor 输出，Motor 增益=0.5 下对运动的控制力已是 Phase 4-B 实验优化后的最大可用量。当热对流力产生轨道动力学时，Motor 的有限控制力无法克服。

## I-2. Soma_Therm "发散"的真实原因（补充诊断）

从 `somatosensory/chain.py` 找到根因：

```python
def _thermoreceptor_config(patch_id: str) -> NeuronConfig:
    # V_ss = I × R = T_skin × 5.0
    # 校准注释："For T_skin=0.2: V_ss=1.0"
    capacitance=1.0,
    r_leak=5.0,
    ...
    # 激活值被 clamp 到 max(-10, min(10, gm × V_m))
    # 不是 max(0, min(1, ...))!
```

**设计假设**：T_skin ≤ 0.2（常温距离），V_ss = 0.2 × 5.0 = 1.0，激活 ≤ 1.0。

**实验条件**：CylindricalHeatSource(T_surface=5.0, sigma=25.0)，体靠近热源时 T_skin ≈ 0.55。

**V_ss = 0.55 × 5.0 = 2.75**。MOSFET 输出 = 2.75（clamp 范围 [-10, 10]，不是 [0, 1]），所以激活 = 2.74。

**结论**：Soma_Therm=2.74 是**稳态**，不是发散。校准假设（T_skin ≤ 0.2）在当前实验参数（T_surface=5.0）下不成立。

**最小修复方法**（属于已有组件 BUG 修复，不是新功能）：
```python
r_leak=1.0,  # V_ss = T_skin × 1.0 ≤ 1.0  (只要 T_skin ≤ 1.0)
```
或者在注入前归一化：`T_normalized = T_skin / max(T_surface)` 后再注入。

修复优先级：高。该错误导致 40/58 束的 Xin 张量被污染为负值，Xin 系统的诊断价值大打折扣。
