# 皮肤-温感链路 全通路梳理

**日期：** 2026-07-09  
**代码基线：** J:\cell-cc main @ 44d0add（variant_adapter.py 3734 行）  
**核心发现：** 两套并行温感系统均处于活跃状态（ThermalMembrane 单点 + SomatosensoryChain 12-patch）；温觉已建立 3 条独立的运动驱动路径；中层（relay→enc）开局零权重是涌现的主要瓶颈。

---

## 零、两套并行温感系统概览

```
┌─────────────────────────────────────────────────────────────────┐
│系统 A：ThermalMembrane（单点标量，"第 7 轴 therm"）              │
│  body 中心一点采样 → therm(T-M) + dtherm(dT/dt)                │
│  → mechanical_inputs['therm']                                   │
│  → HebbianCircuit enc_reg_therm / enc_irr_therm                 │
│  → Col_therm → Motor(cross 束弱驱动)                            │
│  → MotionState.thermal 记录                                     │
│  状态：✅ 仍然活跃（variant_adapter.py:391, 1407）               │
├─────────────────────────────────────────────────────────────────┤
│系统 B：SomatosensoryChain（12-patch 空间分辨率）                 │
│  3 环 × 4 方向：top/mid/bot × front/back/left/right             │
│  每 patch 3 神经元：thermo_input → noci_input → relay           │
│  → relay_to_enc（空间分辨率进 Encoding，STDP，开局 w=0）         │
│  → relay_to_da（空间感觉→DA，经 proj 三级，STDP）               │
│  → thermo_to_yaw（HC-016A 先天反射，frozen）                    │
│  → bundles_therm_z（T-084 变体，top/bot→move_z，STDP）          │
│  → col→motor 差分束（mid-ring 4 条，STDP，DA-gated）            │
│  状态：✅ 已实例化，每步 step（variant_adapter.py:299, 639）     │
└─────────────────────────────────────────────────────────────────┘
```

**两套系统并存但未融合**：系统 A 的输出（scalar therm）走"第 7 轴"进 Hebbian 基类；系统 B 的空间输出走 `relay_to_enc` 绕开基类直接注入。两者各自进入 Encoding 层但对应不同的 enc 神经元（`enc_reg_therm` vs `enc_reg_therm_{pid}`）。

## 一、换能层（温度场 → 第一个神经元）

### 1.1 World 温度场

`world.py:192-202`：
```python
temperature_at(pos) = ambient_temp + Σ (T_src × max(0, 1 - d/radius))
```
线性衰减，单点标量。body 的 4 个 patch 位置（±1 偏移）可采样到不同温度。

### 1.2 系统 A：ThermalMembrane

**文件：** `nexus_v1/components/thermal_membrane.py:79-105`

```
输入: world.temperature_at(body.position)  ← 中心单点
自适应: M += (T_raw - M) × dt/τ_methyl  (τ=200步, thermal_membrane.py:62)
输出:
  therm  = clamp(T_raw - M,  -5, 10)   (tonic，适应后温差)
  dtherm = clamp(dT/dt × k, -10, 10)   (phasic，变化率)
换能系数: 无增益（直接输出适应后的温差）
注入: mechanical_inputs['therm'] = therm_signal（variant_adapter.py:1407-1410）
设计理念: C.elegans AFD 式单神经元，无方向概念（thermal_membrane.py:7, 25）
```

variant_adapter.py 中 ThermalMembrane 的引用：
- L391：`self.thermal_membrane = ThermalMembrane()`（实例化）
- L1329-1330：`ms.thermal = self.thermal_membrane._prev_T - self.thermal_membrane._methylation`（MotionState 记录）
- L1407：`therm_signal = self.thermal_membrane.sense()`（每步感测）

**结论：ThermalMembrane 仍然活跃，非死代码。**

### 1.3 系统 B：SomatosensoryChain

**文件：** `nexus_v1/somatosensory/chain.py`

**12 个 Patch ID：** top ring（`top_front/back/left/right`）+ mid ring（`front/back/left/right`）+ bot ring（`bot_front/back/left/right`）（chain.py:48-52）。

**每 patch 的换能神经元（transducer_neurons.py）：**

| 神经元类型 | 类名 | 换能方式 | 激活公式 |
|-----------|------|---------|---------|
| thermo_inputs[pid] | ThermalInputNeuron（L63） | 直接温度级别 | `activation = max(0, T_raw - 0.05)` |
| noci_inputs[pid] | NociInputNeuron（L127） | 伤害性刺激 | `activation = max(0, noci_total)` |
| — | ThermalDeltaNeuron（L252） | 升温速率 | `activation = max(0, dT_raw × 200)`（只对升温响应，半波整流） |

**noci_total 计算（chain.py:454-456）：**
```python
noci_total = abs(dT) × NOCI_DT_GAIN(=200.0) + damage × 10
damage = max(0, T_skin - 0.8)
```
`NOCI_DT_GAIN=200` **在 Python 里预乘，不走 bundle**（chain.py:454）——这是换能层唯一残留的非结构化硬编码。

**采样位置（variant_adapter.py:626-638）：**
```python
BODY_RADIUS = 1.0
patch_positions = {
    'front':  body.pos + [0, 0, +BODY_RADIUS],
    'back':   body.pos + [0, 0, -BODY_RADIUS],
    'left':   body.pos + [-BODY_RADIUS, 0, 0],
    'right':  body.pos + [+BODY_RADIUS, 0, 0],
    'top_*':  z + BODY_RADIUS （top ring）
    'bot_*':  z - BODY_RADIUS （bot ring）
}
```

## 三、温觉 → DA 链路（两条并行）

### 3.1 条 1：thermo_delta_to_da（phasic，先天固定）

**文件：** `transducer_neurons.py:299-327`，`variant_adapter.py:3083-3089`

```
源: ThermalDeltaNeuron[pid]（每 patch，只对 dT/dt>0 响应）
目标: 全部 DA 神经元（da_vta_0/1/2）
学习: frozen（先天硬连线，进化固定）
参数: w=0.1, weight_max=0.1, synapse_gain=1.0
bundle 数量: ×12（全部 12 个 patch）
生物学: 热起始 Aδ 纤维 → Lamina I → LPB → VTA（Norris 2021）
功能: 升温相位触发即时 DA 爆发（phasic）
```

### 3.2 条 2：relay_to_da（tonic，可学习，经 proj 三级）

**文件：** `variant_adapter.py:2956-3034`

**三级结构：**
```
relay_{pid}
  ↓ [relay_to_proj, frozen, w=0.3, sg=1.0]  ← 固定传递
proj_{pid}（lamina I/III，spiking + CRI + Zener clamp v_clamp=1.0）
  ↓ [relay_to_da 别名 soma_to_da, STDP + eligibility]
da_neurons（全部）
```

**relay_to_da（STDP 段）参数（variant_adapter.py:3013-3032）：**
```
learning_rule: stdp
use_eligibility_trace: True
initial_weight: 0.1, weight_max: 0.3
stdp_lr: 0.005
synapse_gain: 0.2
eligibility_tau: 300（步）
eligibility_ltd_rate: 0.01
da_ema_tau: 5000（步）——受 dt 分裂问题影响
每 patch 独立一条 STDP 束（HC-002 修复后，方向信息保留）
bundle 数量: ×patch 数（~12）
```

**proj 神经元配置（variant_adapter.py:2956-2977）：**
```
spiking=True, v_peak=0.05
CalciumRateIntegrator（CRI）门控 → 平滑发放率
Zener clamp v_clamp=1.0 → 防止过饱和
```

**两条通路的互补关系：**
- `thermo_delta_to_da`：phasic，升温时即时爆发，为 relay_to_da 的 STDP 提供 causal pre-post 共现触发
- `relay_to_da`：tonic，关联强化，学习"哪个方向的 relay 激活应该带来更多 DA"

## 四、温觉 → 运动链路（三条并行）

### 4.1 路径 A：HC-016A 先天热趋反射（thermo_input → yaw）

**文件：** `variant_adapter.py:3241-3283`（`_init_yaw_bundles()`）

```
源: thermo_inputs['left']  → 目标: yaw_ccw_neuron（左热→逆时针）
源: thermo_inputs['right'] → 目标: yaw_cw_neuron （右热→顺时针）
学习: frozen（先天交叉脊髓热趋向反射，Mori & Ohshima 1995）
参数: w=0.3, weight_max=0.3, synapse_gain=1.0
```

**为什么用 thermo_input 而非 relay：**
relay 有侧抑制（front↔left/right 侧抑制束），会污染 left/right 方向信号。thermo_input 是原始换能桥，无侧抑制（chain.py:3245-3246 注释）。

### 4.2 路径 B：relay → enc → col → motor（空间分辨率主链）

**relay → enc（`_init_relay_to_enc`，variant_adapter.py:3196-3239）：**
```
束 ID: relay_to_enc_{pid}
源: relay_{pid} → 目标: enc 层 reg_therm_{pid} 神经元
学习: stdp
initial_weight: 0.0  ← 开局零权重（关键瓶颈）
weight_max: 0.4
synapse_gain: 0.4
lr: 0.005
每 patch 1:1 独立束，保留完整空间分辨率
（bundle 约 12 条，所有 patch）
```

**内部机制：** `_propagate_bundles()` override（L1523-1547）将 bundle 电流反算为 `tonic_val`，注入 `mechanical_inputs["therm_{pid}"]`，交给基类 step() 驱动 enc 神经元。

**enc → col（hebbian.py:471-514）：**  
所有 12 个 `therm_{pid}` 轴均建有 `enc_to_col_{axis}` STDP 束（SG=4.0，w0=0.15，lr=0.008），空间分辨率传递到 column 层。

**col → motor（差分，mid-ring 4 条，hebbian.py:583-624）：**
```
therm_front → move_x: SG=+10.0  STDP + DA-gated eligibility
therm_back  → move_x: SG=-10.0  （差分对，前后温差→前进/后退）
therm_left  → move_y: SG=+10.0
therm_right → move_y: SG=-10.0  （差分对，左右温差→左/右转）
w0=0.1, weight_max=0.5, lr=0.05
```

**注意：** 这 4 条差分束在 **母本 Hebbian 基类** 中定义，只覆盖 mid-ring。

### 4.3 路径 C：bundles_therm_z（T-084 变体补丁，top/bot → move_z）

**文件：** `variant_adapter.py:909-932`（`bundles_therm_z`）

源: col_therm_{top/bot}_{front/back/left/right}（8 个 top/bot ring col）
目标: motor_move_z
参数:
  top ring: SG=+2.5（上方热→上升）
  bot ring: SG=-2.5（下方热→下潜）

## 七、缺陷定位

### 缺陷 1（最严重）：relay→enc 开局零权重

`relay_to_enc` 束 `initial_weight=0.0`（variant_adapter.py:3226）。开局时 STDP 净贡献 = EXTRA_AXIS_GAIN（0.04），等于旧直注。空间分辨率进运动主链的真正强度完全依赖 STDP 学习，而学习的前提是 DA 信号正常（受 dt 问题影响）。

**影响**：在 dt=1.0 下，DA_ema 跟踪极慢（τ≈5000步×dt=1=5000s），relay_to_da 的 STDP 几乎不更新。relay_to_enc 即使具备 STDP，也因 DA 门控失效而停滞。**空间温觉进运动主链的路径存在，但在当前 dt=1.0 实验条件下近乎冻结。**

### 缺陷 2：yaw 方向覆盖不完整（只有左/右，无前/后方向性转向）

HC-016A 和 D1 arc 只接 mid-ring left/right（`thermo_inputs['left'/'right']`），`front/back` 不参与 yaw 控制。
- 热源在正前方：front/back phasic 激活强，但 yaw 无响应；只有 move_x 差分（前进/后退）起作用
- 热源在正侧面：left/right phasic 激活，yaw 响应正确
- 热源在斜前方：left/right 有微弱信号（跨 BODY_RADIUS=1 的温差），yaw 响应弱

**影响**：body 对斜前方热源的追踪，主要依赖前进（move_x）+ 转向（yaw）的组合。若热源在正前方，只会前进不会精细对准。方向覆盖是笛卡尔 XY 差分，不是极坐标转向。

### 缺陷 3：两套温感系统未融合——潜在的信号冲突

系统 A（ThermalMembrane）的 `therm` 轴进 `enc_reg_therm`；系统 B 的 `relay_to_enc` 产出 `therm_{pid}` 进 `enc_reg_therm_{pid}`。两者对应不同的 enc 神经元，尚未冲突。

但在 col→motor 层，系统 A 通过 col_to_motor_cross（w0=0.05，弱）驱动 move_x/y；系统 B 的差分束（±10 SG，强）驱动同一个 move_x/y。两者在同一 motor 神经元上 KCL 叠加——系统 A 的无方向信号会干扰系统 B 的方向性差分。

### 缺陷 4：母本/变体两套机制未统一

- mid-ring col→motor：**母本 hebbian.py** 定义，代码清晰
- top/bot col→motor（bundles_therm_z）：**变体 variant_adapter.py** 补丁定义

两套用不同的初始化、参数对象，且母本注释"no therm→move_z"已过时但未删。任何阅读 hebbian.py 的人会得到错误的链路印象。

### 缺陷 5：NOCI_DT_GAIN=200 在 Python 预乘（非 bundle 结构）

`chain.py:454`：`noci_total = abs(dT) × 200.0 + damage × 10`。这步计算在送入 NociInputNeuron 之前在 Python 里完成，绕过了 SynapticBundle 的传播机制。HC-009 修复了 thermo/noci bundle 化，但 dT×200 这一步仍是硬编码标量乘法——违反 CLAUDE.md 的结构优先原则。
