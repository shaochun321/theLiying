# Cell-CC 项目介绍与总结

> 撰写时点：2026-09-06（基础生成元时间支路 M1+M2 完成当日）
> 性质：项目的规范性介绍文档——对外展示、写作素材、重启导读均以此为起点。

---

## 一、一段话介绍

**Cell-CC 是一个只用四种半导体原语搭建的神经形态生命模拟器。** 它用 `Capacitor`（膜/记忆）、`MOSFET`（阈值/离子通道）、`Memristor`（可塑突触）、`PowerRail`（代谢能量）四个元件类，搭出了一条从机械/温度感受到肌肉输出的完整感觉运动链——228 个神经元、468 条突触束、6 个处理层——让一只虚拟生物在有热源的世界里移动、进食、学习。项目的核心约束只有一条：**每个组件必须映射到一个真实的生物或物理对象，每个行为必须从结构中涌现，而不是从公式中输出。** 在这条约束下，项目走过了"做出涌现→证伪自己的涌现→重建真实涌现→为'发生'与'先后'本身建立物理理论"的完整历程。

## 三、架构：四个顶层系统

```
nexus_v1/    organism——物理与学习的活体（主系统）
tss/         TSS 理论轨——时间/空间/尺度生成算子研究线（只读挂载,零反向耦合）
governance/  并行审计者——物理定律熔断器(Fuse)+熵账本+公理裁决
experiments/ 前代 Morphosphere 实验存档
```

### 3.1 organism（nexus_v1/）——一个神经元类走天下

设计上最激进的决定：**全部 228 个神经元是同一个 `Neuron` 类**，全部 468 条连接是同一个 `SynapticBundle` 类。毛细胞、传入纤维、编码层、运动神经元的差异全部来自配置（`NeuronConfig`）与补偿子电路（电压调节器、偏置电流、钙速率积分器……），不来自子类化。信号链：

```
MET(机械换能) → HairCell → Afferent → Encoding → Column → Motor → Muscle → Body → World → 回环
```

七条感觉轴：三个半规管轴（yaw/pitch/roll）+ 三个耳石轴（oto_x/y/z）+ 温度轴。学习机制：STDP/三因子资格迹 + 多巴胺调制 + 结构生长（sprout/prune/mitosis），生长的唯一驱动力是 **Xin**——每条突触束上累积的预测残差 |predicted − actual|。

配套的可观测性栈全部只读：Noether 探针（能量/电荷 KCL/Landauer 界守恒检查）、熵账本（逐层能量/热/ISI 熵）、结构熵。**观察者不许写回**是铁律，违反即登记。

### 3.2 TSS 理论轨（tss/）——为"发生"本身建物理理论

organism 跑通之后，项目问了一个更深的问题：**一个有限、耗散、只有局部感知的物理系统，如何从真实过程中取得"发生"（occurrence），并在内部生成时间、空间、尺度的组织？** 这条研究线不满足于"用 if 语句判断事件发生了"——它要求发生检测、历史保持、先后比较全部由物理载体承担。截至本文撰写日，时间支路已完整走通：

```
真实热源 → collector(p_α 实时发生) → E^↑ 首次进入门(b^↑) → H_τ 历史保持核(h^τ) → C_Θ 比较器 → r_{i≺j} 时序关系
              活体神经元               饱和刷新RC门          泄漏电容            NMDA型乘法符合
```

每一级都是电容/MOSFET 电路，零软件时钟、零数组缓存、零站点专属参数;"i 先于 j"这个判断的负例（只有 i、只有 j、顺序颠倒、同步、超窗）全部由 MOSFET 阈下截零**物理地**形成，而不是代码分支。三个站点对的真实链路实测延迟（321/360/312 步）与独立审计测量吻合，关系输出通过了阻断实验（下游电容 0.2146 vs 0.0）。

### 3.3 governance（治理层）——诚实标注的并行审计

物理定律熔断器（权重越界/电压发散/熵减/负能量 → 熔断异常）+ 治理账本 + 公理裁决器每步运行。2026-09 审计曾发现其中四个组件是从未接线的死代码——已修复接线并把文档改为如实描述。这个"审计审计者"的事件本身就是项目方法论的一个注脚。

## 四、方法论——项目最独特的资产

这个项目最有价值的产出可能不是任何一段代码，而是一套在人机协作中演化出来的**研究纪律**：

**1. 强制三问。** 任何新信号路径或新参数，动手前必须回答：生物对应物是什么（要有文献或既有引用链）？物理结构是什么（Sources→Bundle→Targets，每端是真实对象）？每个参数的依据是什么（推导或实验来源，"没有依据=不能填这个数字"）？答不出就停下。

**2. 语义硬编码禁令。** 用 Python 数学直接计算语义结论（如 `sign(∇T·v)` 判断"朝热源"）、绕过突触束直接注入电流、把行为目标写进代码——全部禁止。判据一句话："如果你写了一个 if 或公式来决定 DA 的增减，就是硬编码。"

**3. 评判-降格循环。** 每个阶段完成后交给独立评判审查，评判有权把成果"降格"——项目史上 Λ 尺度算子被降格为"Σ 嵌套支撑"、事件绑定器被降格为"谱系记账"、E^↑ 第一版被降格为"判定规则而非物理算子"。降格不是失败，是把宣称收缩到证据支持的范围。

**4. 三注册表追踪。** 降级（DEG）、修复（FIX）、硬编码（HC）各有编号注册表，交叉引用，测试文件里埋锁定断言防止已知问题静默复发。

**5. 冻结契约。** 已验证的资产明确冻结（"不扩展门、不重构 occurrence.py"），新工作不许顺手重构——防止"迁移+改名冒充新资格"。

## 五、发展历程与关键转折

| 阶段 | 内容 | 关键事件 |
|---|---|---|
| Morphosphere 前代 | 早期实验体系 | 存档于 experiments/，路径硬编码，被现系统取代 |
| 信号链打通 | MET→Motor 六层贯通 | 信号深度 6/6，能量/NaN/放电率系列修复（DEG-001~014）|
| 热趋性涌现期 | 让虫子学会找热源 | Phase 3~8 系列实验，DR5 指标一度达 96% |
| **大证伪** | 全链路硬编码审计 | **60 条 HC 违规；发现 DR5≈96% 是 `G_ORIENT=200` 硬编码直接制造的假涌现；涌现真实性自评 ~55%** |
| 重建期 | 删除硬编码,重建真实路径 | patch 温差重定义指标、物理化换能层、eligibility trace 修复；真实但更弱的方向学习(|Δw|≈0.3)重新涌现 |
| 理论转向 | 从"行为涌现"到"发生的物理" | TSS 轨启动：生成元/发生/关系的形式化+物理化，90+ commits |
| 时间支路完成 | M1 H_τ + M2 统一Θ | 2026-09-06：先后关系的全物理链路走通，九条资格全 PASS |

**大证伪是全项目最重要的事件。** 项目曾拥有一个 96% 达标的热趋性指标——然后自己的审计发现这个数字由一行 `mechanical_inputs['yaw'] += delta_T * 200` 直接制造，benchmark 本身还在用电路无法访问的全局梯度信息作弊。项目选择了全部推倒：删除硬编码、重定义指标、接受"真实但难看"的数字。此后的所有结果都带着这次证伪留下的免疫系统（防复发钩子、指标合法性审查）。

## 六、诚实的局限

- **热趋性行为未完全涌现**：清除硬编码后，方向学习真实发生（权重分化、LTD 涌现），但稳定的趋热行为仍依赖部分几何效应；单纤维 N=1 使信噪比比生物低约 87 倍（DEG-016），单次实验结果对随机种子敏感。
- **参数量纲欠债**：机械输入无物理单位锚点（DEG-015），部分增益是工程倒推（DEG-017），前庭量纲锚定只完成了一部分。
- **传入放电率 2 Hz vs 生物 20-100 Hz**（DEG-004）：层契约两项 CRITICAL 违约的根因，登记后长期未修。
- **理论轨的空间/尺度支路缺失**：Σ 缺输入端口、Λ 无不可约载体——按纪律"保持缺失，不写占位电路"，不假装完成。
- **两份 DEG 注册表编号分叉**（DEG-015 起同号异义），待合并裁定。
- **无直接商业价值**：这是基础研究。诚实评估见《项目应用价值评估_2026-09-06.md》——价值在方法论内容、作品集与潜在学术产出，不在变现。

## 七、总结：这个项目证明了什么

1. **四个元件类足以承载一条完整的感觉运动生命回路**——不需要深度学习框架，不需要浮点张量，物理原语的组合就能产生感知、学习与行动。
2. **"涌现"极易造假，且造假者往往是无意的自己。** 本项目用 60 条硬编码审计和一次彻底的自我证伪演示了如何识别假涌现——这可能比"做出涌现"更有方法论价值。
3. **"事件发生了"、"A 先于 B"这类看似必须用软件逻辑表达的判断，可以完全物理化**：一个饱和刷新 RC 门、一个泄漏电容、两个 MOSFET 的乘积，就构成了零软件时钟的时序关系检测器，且每个参数都有推导来源。
4. **人机协作的基础研究需要纪律而不只是热情**：强制三问、评判降格、注册表追踪、冻结契约——这套流程的全程留痕本身就是一份稀缺的公开样本。

**下一步（若继续）**：C0/C1 首个耦合生成元（时间方向优先）→ 事件核/生长远景；或按应用评估落地写作与开源包装。
