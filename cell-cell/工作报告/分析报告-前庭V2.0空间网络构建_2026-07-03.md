## 一、背景与目标

前庭系统（`nexus_v1/vestibular/chain.py`）包含 6 轴 × 4 神经元层 = 24 个前庭神经元，但缺少任何空间坐标信息。V2.0 架构规划中提出了两个依赖空间坐标的功能：

1. **`τ_ij = d_ij / (v_cond × dt)`** — 距离比例的轴突传导延迟（RingBuffer 实现）
2. **`P_S = η_s × (dw/dt)² × d_ij`** — 距离惩罚的 STDP（抑制远距离强连接）

这两个功能都需要神经元有物理位置坐标，但不需要立即实现功能逻辑——先建脚手架，逐步填充。

## 二、实施内容

### 2.1 NeuronConfig 新增 `position` 字段

**文件**：`nexus_v1/components/neuron.py`

```python
# Physical spatial position (mm, labyrinth/body frame).
# REF: Highstein & Holstein 2006 "The Vestibular System" — labyrinth anatomy.
# Used to compute pairwise neuron distance matrix for:
#   - Future τ_ij = d_ij / (v_cond × dt) synaptic delay (V2.0 RingBuffer)
#   - Future P_S = η_s × (dw/dt)² × d_ij distance-penalized STDP
# None = position not yet assigned (abstract or unlocated neuron).
position: Optional[Tuple[float, float, float]] = None
```

变更范围：仅在 `NeuronConfig` dataclass 末尾追加一个 Optional 字段，默认值 `None`。对所有现有神经元（未指定位置的）行为零影响。

### 2.2 前庭神经元空间坐标定义

**文件**：`nexus_v1/vestibular/chain.py`

坐标系：+x=前（anterior），+y=外侧右（lateral right），+z=上（superior），原点=前庭中心。坐标单位 mm。

参考文献：
- REF: Goldberg et al. 2012 "The Vestibular System: A Sixth Sense" — Ch.2
- REF: Gray's Anatomy (2020) — inner ear labyrinthine anatomy

#### 感觉上皮位置（MET + HairCell 共享）

| 轴 | 位置 (mm) | 生物对应物 |
|----|----------|-----------|
| yaw | (1.5, 2.5, 0.0) | 水平半规管前壶腹（horizontal canal anterior ampulla）|
| pitch | (2.5, 0.0, 2.0) | 前半规管（anterior/superior canal）前壶腹 |
| roll | (0.0, 1.5, 2.5) | 后半规管（posterior canal）后壶腹 |
| oto_x | (0.5, 0.0, -1.0) | 椭圆囊（utricular macula），x 轴毛细胞朝向 |
| oto_y | (0.0, 0.5, -1.0) | 椭圆囊，y 轴朝向 |
| oto_z | (0.0, 0.0, -2.0) | 球囊（saccular macula），垂直重力轴 |

#### Scarpa 节位置（Afferent 神经元）

Scarpa 节（初级传入纤维胞体）位于感觉上皮内侧约 2 mm 处（-x 方向）。

公式：`_afferent_pos(axis) = (base_x - 2.0, base_y, base_z)`

## 三、暂未修复的问题：HC-008

`chain.py` 第 373-379 行存在已知的硬编码违规（HC-008）：

```python
hc.activation = hc.release_rate  # bridge: release → propagation
```

这行代码将 HairCell 的 MOSFET 输出覆盖为 Ca²⁺ 释放率，属于语义硬编码违规（丢弃了半导体物理结果）。

**为何本次不修复**：
- 修复此行需要引入独立的 `ReleaseNeuron`（Ca²⁺→囊泡释放的物理建模），并重新校准 `hc_to_aff` bundle 的增益，大概率导致回归失败。
- HC-008 在技术债登记中标注为 **MEDIUM**（不阻断当前热趋性实验）。
- 正确修复路径：V2.0 结构阶段，以独立 PR 形式进行，不与正在运行的实验混合。
