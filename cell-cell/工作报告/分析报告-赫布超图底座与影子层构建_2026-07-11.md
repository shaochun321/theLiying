# 分析报告：赫布超图底座与影子层构建机制

**日期：** 2026-07-11
**类型：** 架构分析（代码层 + 知识库概念层交叉核查）
**范围：** 赫布超图（Hebbian Hypergraph）架构定义、影子层构建机制、赫布超图完整子系统清单

---

## 一、核心结论（先给答案）

1. **"赫布超图"不等于 `HebbianCircuit` 类**。"赫布超图"是项目的**顶层架构概念**（河床/底座），代码里的 `HebbianCircuit`（`nexus_v1/circuit/hebbian.py`）只是它的**核心骨架实现之一**——负责前庭链→Encoding→Column→Motor 的 7 轴主环路。完整的"赫布超图架构"横跨多个文件：`hebbian.py`（主环路）、`bundle.py`（超边本体）、`shadow_sandbox.py`（影子层）、`variant_adapter.py`（外层整合）。

2. **"超图"（hypergraph）的字面依据**：普通图的一条边只连 2 个节点，`SynapticBundle`（超边）可以连 **N 个源神经元 → M 个目标神经元**（一条边承载 N×M 的 Memristor 权重矩阵）。这就是"超图"而非"图"称谓的直接代码证据。

3. **影子层不是深拷贝，是"工厂重建"**：`ShadowSandbox.initialize()` 用同一套 `Neuron`/`SynapticBundle` 母本类、独立的 `create_shadow_config()` 工厂函数，**重新构造**一套结构同构、参数慢化（τ×3）的镜像神经元/超边，而非复制主电路对象引用。驱动信号靠主电路 bundle 的 `xin_tension`（预测残差张力）经路由表注入，只读不写回。

4. **赫布超图架构包含的完整子系统**（知识库确认）：超边（Binding Layer）、STDP/BCM/Frozen 三态学习、Xin/TOPR 预测残差环流、结构生长（sprout/prune/mitosis/apoptosis）、影子沙盒、守恒律/熵账本审计——这些不是"外挂"，而是赫布超图"运行时"本身涌现的动态行为。

## 二、超图（Hypergraph）：字面依据

### 2.1 超边的代码证据

`SynapticBundle` 构造签名（`nexus_v1/circuit/bundle.py:152-153`）——sources 和 targets 都是 `List[Neuron]`：
```python
def __init__(self, config: BundleConfig,
             sources: List[Neuron], targets: List[Neuron]):
```

核心数据结构是一个 sources × targets 的 Memristor 矩阵（`bundle.py:165-176`）：
```python
self._memristors: List[List[Memristor]] = []
for i_s, _s in enumerate(sources):
    row = []
    for i_t, _t in enumerate(targets):
        m = Memristor(w=w0)
        row.append(m)
    self._memristors.append(row)
```

传播时对每个 source×target 对求和到目标（`bundle.py:243-263`）。

**普通图的边只连 2 个节点；这里一条 bundle 可以连 N 个源到 M 个目标——这正是超边（hyperedge）的定义。**

### 2.2 实际的超边实例

- **enc→col**（`hebbian.py:508-512`）：2 源（reg + irr 编码神经元）→ 1 目标（列神经元），2×1 超边。
- **col→motor cross-axis**（`hebbian.py:630-654`，`bundle_id="col_to_motor_cross"`）：**7 源（全部列神经元）× 3 目标（全部运动神经元）= 21 个 Memristor**，是最典型的超边，注释原话："a 7×3 cross bundle accumulates 21× faster than a 1×1 axis bundle"。

### 2.3 知识库对"超边"的正式定义

`modeling_hypergraph_math.2026.5.22.md`（《前庭赫布超图：完整数学建模》）§1.2：
> 每个超边 $b_k$ 连接源集 $S_k$ 到目标集 $T_k$

## 三、赫布（Hebbian）：学习规则

### 3.1 学习实现位置

`SynapticBundle.learn()`（`bundle.py:310-511`），学习规则由**目标神经元的成熟阶段**决定（`bundle.py:339-363`）：

| 成熟阶段 M | 学习规则 | 代码位置 |
|---|---|---|
| M=0 spine | **STDP**：`ltp = src.pre_trace * tgt.post_trace`，乘性软边界 | `bundle.py:437-452` |
| M=1 column | **BCM** 滑动阈值 | `bundle.py:454-477` |
| M=2 area | frozen（冻结不学习）| `bundle.py:348-349` |
| cross_axis 角色 | hebbian_decay（纯 Hebbian + 衰减，避免 BCM 抹掉跨模态弱权重）| `bundle.py:479-496` |

可选三因子 eligibility trace（`bundle.py:390-435`）：LTP 受 DA 门控，`ltp = eligibility_gain × E(t) × DA_ema`，用于热差分通路。

## 四、HebbianCircuit：主环路骨架的完整结构

### 4.1 构建的层（`hebbian.py:347-654`）

| 层 | 位置 | 神经元数 |
|---|---|---|
| Encoding | `:370-377` | 每轴 2 个（reg_ + irr_）|
| Column | `:382-385` | 每轴 1 个 |
| Motor | `:388-390` | 固定 3 个（move_x/y/z）|

所有神经元统一用 `Neuron` 母本类，配置函数在 `hebbian.py:32-308`。

### 4.2 层间 bundle

- `bundles_vest_to_enc`（`:409-463`）：afferent→encoding，1×1，`stdp_lr=0.01`
- `bundles_enc_to_col`（`:471-514`）：编码→列，2×1 超边
- `bundles_col_to_motor`（`:520-654`）：轴特异强连接 + 热差分对（三因子 DA 门控）+ 7×3 cross-axis 弱连接超边

### 4.3 结构生长机制（sprout/prune/mitosis/apoptosis）

- **sprout**：`_structural_growth()` Phase 1（`:901-979`）。真正复制在 `SynapticBundle.sprout()`（`bundle.py:783-854`），子 bundle 继承父的 sources/targets（可跨目标变异 CROSS_PROB=0.3），初始权重 1e-4。触发：`xi = abs(bundle.config.xin_tension) > XI_SPROUT(0.3)` 且源神经元能量足够。
- **prune**：Phase 2（`:981-1016`），判定在 `SynapticBundle.should_prune()`（`bundle.py:858-906`）——只剪 sprouted bundle，grace_period=5000 步后 `mean_weight<0.005` 连续 2 次即剪。
- **mitosis**：`_check_mitosis()`（`:1072`），分裂逻辑在 `Neuron.split()`（`neuron.py:666-716`），由 FatigueCapacitor 电压累积驱动（`V_fat > 0.4` 持续 30000 步）。仅 motor 神经元开启。
- **apoptosis**：能量 < 0.05 持续 30000 步移除（原始 3 个 motor 永不死）。

生长调度在 `step()`（`:747-767`）：每 `SPROUT_INTERVAL=10000` 步检查一次。

### 4.4 Xin（预测残差）驱动自组织

计算于 `SynapticBundle.compute_xin()`（`bundle.py:559-640`），PI 形式：`预测 = Σ W_ij × a_i(t-dt)`，残差累积带泄漏：`ξ(t+dt) = ξ(t)·exp(-dt/1000) + R(t)·dt`。存储在 `bundle.config.xin_tension`（每条**超边**上，不是神经元上）。

Xin 通过 `update_fruit()`（`bundle.py:642-749`）状态机转成结构决策：正 ξ（欠预测）→ 降低 sprout 阈值；负 ξ（过预测）→ 强制 prune。这是"赫布超图自组织"的核心机制——**学习改权重（连续、每步）**，**生长改拓扑（离散、每万步）**，两者通过 Xin/能量/疲劳弱耦合。

### 4.5 get_all_neurons() / get_all_bundles()：基类 vs 子类

基类简单聚合四层（`hebbian.py:1239-1254`）；`VariantCircuit` 覆盖后追加 DA/体感/影子/能量感知/Renshaw 等全部子系统（`variant_adapter.py:3662, 3718`）——这两个方法是 Noether/熵账本/血管供能审计的唯一枚举入口，遗漏即对账本"隐形"。

## 五、影子层（ShadowSandbox）：如何从赫布超图底座构建

### 5.1 构建方式：工厂重建，不是深拷贝

`initialize(circuit)`（`shadow_sandbox.py:196-337`）逐层用 `Neuron(create_shadow_config(...))` **新建**神经元，没有任何 `copy.deepcopy`，也不引用主电路 Neuron 对象。复制的是**结构（数量+拓扑）+ 参数语义**，不是对象本身：

```python
for axis in axes:
    for kind in ["reg", "irr"]:
        nid = f"s_enc_{kind}_{axis}"
        self.neurons[nid] = Neuron(create_shadow_config(nid, "encoding"))
```

轴集合用 `circuit.all_axes`（含 vestibular 6 轴 + 12 个 thermal patch = 18 轴），比主 Enc 层更宽——目的是跨模态耦合，故影子层不是主层的严格镜像，而是"更宽的全轴镜像"。

### 5.2 命名规则与地址

`s_enc_reg/irr_{axis}` / `s_col_{axis}` / `s_mot_{x|y|z}`；`_assign_regions()` 用前缀 `s_enc_/s_col_/s_mot_/shadow_` 判为 `REGION_SHADOW=0x05`。

### 5.3 与主电路的参数差异（刻意不同，不是复制）

`create_shadow_config`（`:32-125`）：3× 慢时标（capacitance=3.0 → τ=15，主电路 τ=5）、per-layer 分化组件（enc 用 DivisiveNormalizationReceptor，col 用 spiking+CalciumRateIntegrator）、`maturation_stage=1`（触发 BCM）、`theta_m_tau=10000.0`（极慢稳态阈值）。

### 5.4 影子层内部镜像拓扑

- `s_enc_to_col_{axis}`：2 源→1 目标，`w=0.1`
- `s_col_to_mot_{axis}_to_{mot}`：全连接 all-to-all，`w=0.001`（休眠）
- `s_cross_{i}_{j}`：C(n,2) 跨轴 col↔col 休眠关联纤维，`w=0.001`，delay_steps=2 —— **这是影子层独有的、主电路没有的内部结构**，用于计算 ds²/κ。

### 5.5 驱动信号：Xin 张力路由

`_xin_routing` 表（`initialize()` 末尾，`:320-336`）：主电路 bundle id → 影子 enc 神经元：
```python
main_bid = f"enc_to_col_{axis}"
self._xin_routing[main_bid] = [f"s_enc_reg_{axis}", f"s_enc_irr_{axis}"]
```

`observe()`（`:494-636`）每 `SHADOW_K=10` 步注入：
```python
for b in circuit.get_all_bundles():
    xi = b.config.xin_tension
    for nid in self._xin_routing.get(b.id, []):
        accumulated_currents[nid] += xi * self.XIN_GAIN   # XIN_GAIN=3.0
```
**signed xi**（不取绝对值，HC-021 fix）——影子 enc 的 MOSFET 半波整流：正 xi（欠预测）激活，负 xi（过预测）亚阈静默。

### 5.6 额外前馈通路：`_init_shadow_input_bundles()`

`variant_adapter.py:1223-1308`，三类 frozen（无 STDP）低增益 bundle：
1. Motor efference copy：`motor_neurons[move_x/y/z]` → `s_mot_{x/y/z}`，w=0.1
2. Somatosensory relay：12 个体感 patch → `s_enc_reg_therm_{patch}`，w=0.1
3. Energy → shadow col：`average_energy_neuron` → `s_col_therm_front`，w=0.2

### 5.7 在 VariantCircuit 里的挂接

`__init__`（`:1209-1213`）：
```python
self.shadow_sandbox.initialize(self)   # 传入整个电路，只读依赖注入
self._init_shadow_input_bundles()
```
`initialize(self)` 传入整个电路的意义：影子层需要读取主电路的 `all_axes`、`get_all_bundles()`（拿 xin_tension）、`energy_store`（缴代谢税），但从不写回（`observe()` 注释原话："PURE OBSERVER — does NOT modify the main circuit"）。

census 归属：`get_all_neurons()` 纳入影子神经元（`:3681-3683`）；`get_all_bundles()` **只**纳入跨界的 `_shadow_input_bundles`（`:3771-3773`），影子内部 bundle（`s_enc_to_col_` 等）不进主电路 Noether/Xin 账本，只在 `shadow_sandbox.bundles` 里由 `observe()` 内部处理。

### 5.8 影子层计算什么

- **自由能 K 与运动势 ν**（`_update_free_energy`，`:687-699`）：`K = Σxi²`（Xin 张力平方和），`K_ema = K_ema×0.99 + K×0.01`，`ν = K_ema 变化率`。
- **收缩度 κ**（`_update_kappa`，`:859-899`）：`κ = Σg_ij·δa_i·δa_j / Σ(δa_i)²`，跨轴 bundle 权重作度规张量，κ>1 膨胀/κ<1 收缩/κ→0 坍缩。
- 其他：ds²（神经时空间隔）、权重变化率（novelty→DA）、代谢税（防"永动机癌细胞"）。
- **已知问题**：K_ema 无界增长发散（`run_full_audit.py` 标记 DEG-P4-003，发散阈值 10.0），是既有 P2/P4 级审计告警，非本报告新发现。

### 5.9 完整数据流图

```
主电路 (VariantCircuit / HebbianCircuit)
│
├─[Xin 张力路径]───────────────────────────────
│   enc_to_col_{axis}.xin_tension ─┐
│   met_to_hc_{axis}.xin_tension  ─┤ (signed xi × XIN_GAIN=3.0, via _xin_routing)
│                                  ▼
│                          s_enc_reg/irr_{axis} (MOSFET 半波整流)
│
├─[前馈输入, frozen]────────────────────────────
```

### 6.4 影子层的原始设计意图

`cell-cell/2026-05/analysis_shadow_layer.2026.5.18.md`：
> 影子层正在做的事：记录 CPG 门控导致的**周期性预测中断**。这正是 Column 前向模型应该解决的问题。

生物学对应：Xin 张力 = 预测编码误差信号（前额皮层→感觉皮层）；休眠果实 = 记忆痕迹（hippocampal engram）；影子层+Column = 前额-小脑环路。

`modeling_hypergraph_math.2026.5.22.md` §9 明确影子层当前是**降级实现**（DEGRADED），完整设计意图是运行自己 T/O/P/R/Xin 生命周期的副本沙盒，通过层级变分推断提取运动势，`degraded_from = "hierarchical_variational_sandbox"`。

**关键架构原则**（§5.3）：
> 超边集合 $\mathcal{B}$ 由结构给定，不由影子层决定。影子层可以利用已有超边，但**不能创建新的超边**。影子层 = 探照灯，不是建筑工。

### 6.5 母本分化原则与赫布超图的关系

"母本"指 `Neuron`/`SynapticBundle` 两个母本类，赫布超图的所有节点和超边都从这两个母本"分化"而来（`cell-cell/专题分析/母本分化与元件构建原则-融合版.md`，CLAUDE.md 级法则）：
> **绝对禁止**：修改母本类内部核心代码硬编码特化功能；派生特化子类（如 `ShadowNeuron`）；在 `step()` 里加 if/else 区分"主层 vs 影子层"。
> **只允许**：从统一母本出发，通过**物理配置差异**与**外挂补偿组件**派生行为。

这解释了为什么影子层、绑定层、交界层"都是同一个超图的子图"——共用同一套母本类，只是配置不同。

## 八、总结

赫布超图 = **系统的底座结构** = 节点（神经元，从 `Neuron` 母本分化）+ 超边（突触束，从 `SynapticBundle` 母本分化）构成的、带物理属性（电阻/电容/能量）的完整拓扑。它是"整个系统的数学结构"，其上通过功能分区涌现出交界层、影子层、绑定层等所有子图；环流、STDP/BCM 学习、Xin/TOPR 反馈、结构生长、守恒审计都是这个超图"运行时"的动态行为，而非独立外挂系统。

代码里的 `HebbianCircuit` 类是这个架构概念的**核心骨架实现**（7 轴主环路），影子层（`ShadowSandbox`）通过独立工厂函数**重建**（而非拷贝）一套结构同构、参数慢化的镜像子图，靠主电路 bundle 的 Xin 张力驱动，只读观察，唯一出口是 ν→DA 门控。
