## 3. 发现的真实问题

### P2-A1b-0（一）：低端边界矛盾已实测坐实并解释清楚

**先用命令行独立进程直接核实矛盾本身**：
```
不固定 PYTHONHASHSEED: 3次独立进程运行 u=0.0005 → 0/1/0次触发
固定 PYTHONHASHSEED=0:  3次独立进程运行 u=0.0005 → 全部第4449步触发
```
确认 P2-A1a-R 报告"u≤0.0005全部不触发（真正静默）"确实是过强的错误结论，
根因是 Memristor ±25%对称性打破扰动依赖 Python 逐进程随机化的字符串
`hash()`（`site_selection.py` docstring 已警告过），u=0.0005 恰好卡在
触发临界点。

**多种子多观测窗实验揭示了一个更深层的事实**：静默可能根本不是 u 的
绝对属性，而是**观测窗长度的函数**——
- u=0.0004：T_obs=5000 时 0/10 触发（看似"静默"）；T_obs=20000 时
  **9/10 触发**。
- u=0.0005：T_obs=5000 时 8/10（80%）；T_obs=20000 时 10/10（100%）。
- u≥0.0006：两种观测窗下均 10/10（100%）触发。
- **确定性核实**：固定 `PYTHONHASHSEED=0`，同一 u 独立跑3次完全一致
  （n_occ=1, l_first=4449 每次相同）——确认整条链路本身是确定性的，
  唯一的非确定性来源就是逐进程随机化的 hash()。

`u_on(T_obs)` 经验区间：`T_obs=5000` 时 `[0.0005,0.0006]`；`T_obs=20000`
时 `[0.0004,0.0005]`——**证实评判的判断：不能冻结单一数值，必须写成
观测窗的函数**。

### P2-A1b-0（二）：生成元级可区分度——测量方法本身有一处自我发现的缺陷已修正

初版测量"窗口末尾ensemble的pre_trace"全部读到精确的0——**这是测量方法
本身的问题，不是生成元的问题**：发生次数少（2~7次）且集中在观测窗早期
（`l_first`在384~583步），窗口末尾（第5000步）早已衰减回静息，只采样
末态是假阴性。改用"整个观测窗内的峰值"（复用项目已建立的
`PeakDecayRestProbe.peak`/`peak_pre_trace`方法论）后重新测量：

- 标量指标（`n_occ`/`l_first`/`f_occ`/`mean_t_active`）在 u<0.05 区间
  内随 u 清晰变化，u≥0.05 起精确恒定——与 `𝒟_disc^L1=u<0.05` 的转折点
  一致。
- ensemble 峰值 `pre_trace` 向量本身在 u∈[0.02,0.08] **全程都接近饱和**
  （恒为~1.816，u=0.02时与u=0.08时相差仅约0.01%）——技术上超过判定
  阈值算"可区分"，但**这个残余梯度极其微弱，和 L1 那种整数级
  （4→5→6→...→10）的清晰变化完全不是一个量级**。这提示：即便在
  `𝒟_disc^L1` 区间内，ensemble 群体本身携带的信息量可能远小于表面
  `𝒟_disc^G=𝒟_disc^L1` 这个结论所暗示的程度——闭合层面的可区分性
  （`L_first`/`f_occ`）更可能是由触发/退出**时序**差异驱动的，而不是
  ensemble 群体编码本身携带丰富的分级信息。这是留给未来（P2-B 检验
  内部占比ρ候选测度时）需要正视的真实限制，不应被这轮"可区分=True"
  的粗略判定掩盖。

### P2-A1b-1：皮肤输出分布——确认线性系统预期行为，无异常

- 静息基线：`[0,0,0]`（符合默认ambient_temperature=0）。
- 剂量-响应扫描：s1稳态温度与注入幅度**严格成正比**（0.01→0.618，
  50.0→3091.30，比例吻合），确认 `ThermalFieldGraph` 的线性扩散动力学。
- **脉冲持续时间（回落到峰值10%以内）恒为425步，与注入幅度完全无关**
  ——线性RC系统的预期行为（衰减时间常数只由kappa/r_leak决定，不由
  幅度决定），非异常。
- 温度数值动态范围很大：剂量扫描下全节点温度范围 `[0.44, 3091.30]`——
  这个跨越4个数量级的范围是未来 P2-A1b-2 选择 `κ_i` 的直接依据：若
  要把这个范围映射进生成元的 `𝒟_disc` 区间（u<0.05），需要相应量级的
  缩放增益，不能凭感觉猜。
- T-STP-6/7/8六场景在本轮剂量下的具体数值也一并记录，供后续参考。

## 5. 冻结契约

- **`u_on` 不得被写成单一数值**：任何后续文档/代码引用低端启动边界，
  必须显式标注对应的观测窗 `T_obs`，或直接引用区间/分布。
- **`𝒟_disc^G` 与 `𝒟_disc^L1` 数值上重合（u<0.05），但不代表两者等价**：
  ensemble群体编码本身在这个区间内可能携带远少于表观判定所暗示的信息
  量（峰值向量几乎饱和），P2-B 若要用ensemble内部占比作为自然化候选
  测度，必须重新专门验证，不能因为本轮"生成元整体可区分=True"就默认
  ensemble携带丰富分级信息。
- **q_i^skin 的动态范围（约4个数量级，0.44~3091.30 在本轮剂量下）是
  P2-A1b-2 选择 `κ_i` 的实测依据**，不得脱离这份数据凭空选择增益。
