# T-078 w_ccw 异常衰减根因分析报告

**日期：** 2026-07-07  
**脚本：** `nexus_v1/tests/exp_T078_wcw_trace.py`  
**结论：根因已确认 — `_apply_metabolic_tax()` 被 P0 钳位的 phasic 能量耗尽触发**

---

## 问题背景

T-039b（诈胡核查）显示：全冻结 STDP 后，50k 步内 `w_ccw` 漂移 = **0.0443**（FAIL），而 `w_cw` 几乎不变。  
预期：lambda_metabolic 产生 ~0.000006 漂移；实际 = 0.0443，差 **7000×**。

---

## 根因定位过程

### 阶段 1：排除 lambda_metabolic 小幅漂移

per-step 追踪显示：freeze 后 `dw_ccw ≈ -1.4e-9/step`，50k 步理论漂移 = 0.000007。远低于观测值，排除为主因。

### 阶段 2：排除 learn() 多次调用

monkey-patch `SynapticBundle.learn` 后确认：每步仅调用一次，不存在重复调用。

### 阶段 3：发现间歇性大幅跳变

每 100 步采样后发现：

| 区间 | Dw_ccw/100步 | Dw_cw/100步 | 特征 |
|:---|:---|:---|:---|
| 步 0~2000 | ~-4e-8 | ~-4e-8 | 对称小幅衰减 |
| 步 2100+ | ~-1.8e-4 | ~-1.8e-4 | **突变！1000× 放大** |

**步 2100 是体进入热源（dist=17）的时刻。**

### 阶段 4：定位调用栈

对 `Memristor.apply_dw` 设置 traceback 钩子（仅对 `|dw| > 1e-5` 触发），得到：

```
STEP 2100: CCW apply_dw=-0.000162  w_before=0.081144
File "hebbian.py", line 844, in _apply_metabolic_tax
    m.apply_dw(dw, bundle.config.weight_min, bundle.config.weight_max)
```

→ 调用方为 `_apply_metabolic_tax()`，不是 `learn()`。

### 阶段 5：能量场诊断

```python
# 步 2099 状态
phasic_left.energy  = 0.001000   # << ENERGY_FLOOR = 0.3
phasic_right.energy = 1.000000
phasic_left.activation  = -0.1000  # P0 钳位已激活
phasic_right.activation = -0.0503  # 尚未完全钳位
```

**计算验证（完全吻合）：**
```
avg_src_energy = 0.001  <  ENERGY_FLOOR = 0.3   → 触发
deficit = 1 - 0.001/0.3 = 0.9967
decay_rate = 0.9967 × 0.002 = 0.001993
dw = -0.001993 × 0.081144 = -0.000162  ✓ 与观测值完全一致
```

## 根本原因

**完整因果链：**

```
体接近热源（dist < radius=30）
  ↓
P0 钳位：phasic_left.activation → -0.1V
  ↓
phasic_left 能量耗尽：energy → 0.001（低激活 = 无 ATP 输入）
  ↓
_apply_metabolic_tax()（每 100 步）：avg_src_energy < 0.3
  ↓
decay_rate ≈ 0.002，dw = -0.002 × w ≈ -0.000162/步
  ↓
D1 CCW 束权重快速衰减（50k 步漂移 0.044）
```

**关键性质：**
- 只影响 CCW 束（源 = phasic_left），因 phasic_left 先被钳位
- 与 STDP 冻结状态无关（metabolic tax 未受 freeze_all_stdp 保护）
- 衰减在体靠近热源时持续发生，即学习最需要的时刻

## 对 T-039b 的影响

T-039b J2 FAIL（w_ccw 漂移 0.0443）**并不代表真实的 STDP 学习方向性问题**，而是 metabolic tax 的物理副效应。  
T-039b 设计的诈胡验证逻辑失效：即使没有真实 STDP，w_ccw 也会因能量耗尽而衰减。

---

## 修复方案

### 方案 A（推荐）：为 phasic 神经元维持最低能量

在 P0 钳位代码中，钳位激活时同时补充 phasic 能量：
```python
self.phasic_left.activation = -0.1
self.phasic_left.energy = max(self.phasic_left.energy, 0.5)  # 防止 metabolic tax
```

### 方案 B：排除 D1 束于 metabolic tax

在 `_apply_metabolic_tax()` 中跳过 D1 bundle：
```python
if 'd1_phasic' in bundle.config.bundle_id:
    continue
```

### 方案 C（根治）：PowerRail 维持 phasic 能量

phasic 神经元应由 PowerRail 供能（生物对应：运动神经元有专属能量储备），使其能量不随激活状态波动。
