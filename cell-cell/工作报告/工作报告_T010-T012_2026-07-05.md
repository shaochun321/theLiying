## 二、T-012：DelayedBundle 前庭接入

### 背景

原有 `hc_to_aff` 突触束使用 `SynapticBundle`，信号从毛细胞到前庭传入纤维的传导假设无延迟。然而壶腹嵴-Scarpa 神经节之间的传入纤维在生物学上是 Aα 有髓纤维（v=50 mm/ms），具有有限传导速度。

### 实现

将所有 `hc_to_aff` 束改为 `DelayedBundle`：

```python
# T-012: DelayedBundle for HC→Aff (Aα myelinated vestibular fiber)
# BIO: Scarpa's ganglion primary afferents — Aα fiber, v=50 mm/ms
# REF: Goldberg et al. 2012 "The Vestibular System" Ch.2
b_hc_aff = DelayedBundle(
    config=BundleConfig(bundle_id=b_aff_id, ...),
    sources=[hc],
    targets=[aff_r, aff_i],
    v_cond_mm_per_ms=V_COND_AALPHA,   # 50 mm/ms
    dt=dt,
)
```

### 当前数值结果

HC 到 Scarpa 神经节距离约 2 mm。按公式：
```
τ_steps = round(d / v / dt_ms) = round(2.0 / 50.0 / 1.0) = 0 步
```

**当前尺度下延迟为 0 步**，`DelayedBundle` 行为与 `SynapticBundle` 完全一致（ring buffer 深度 1）。架构已正确，当神经节距离扩展或传导速度降低时（如 C 纤维场景），延迟将自动生效。

## 三、T-010：CalciumChannel + CalciumDynamics 接入

### 背景

T-007（Ca²⁺ Phase A）已完成 `CalciumChannel` + `CalciumDynamics` 独立组件的物理标定，但尚未接入任何电路。HC-008 修复的临时桥接代码：

```python
hc.activation = hc.release_rate  # 旧：内部 Ca²⁺ MOSFET 桥接
```

该桥接使用神经元内部的 Ca²⁺ 子系统，其 MOSFET 门控为二次方型，在正常 HC 膜电压范围（~0.115）下几乎总是给出 `release_rate ≈ 0`，不够物理。

### 实现

**初始化时创建 per-HC Ca²⁺ 对象：**

```python
ca_ch = CalciumChannel()           # V_half=0.308, g_max=2.0, k=0.030, E_Ca=1.5
ca_dyn = CalciumDynamics()
ca_dyn.R_ca = _VEST_CA_R           # 0.37（前庭特定校准）
ca_dyn.C_ca = _VEST_CA_C           # 0.135；τ = R×C = 50 ms
```

**step() 中替换桥接代码：**

```python
_vm_safe = max(-0.5, min(hc._membrane.voltage, 2.0))   # 防溢出钳位
_I_Ca = ca_ch_list[_hc_idx].current(_vm_safe)
ca_dyn_list[_hc_idx].step(_I_Ca, self._dt)             # 物理时间步 0.001s
_ext_release = ca_dyn_list[_hc_idx].release_rate(_VEST_CA_THRESHOLD)
hc.activation = _ext_release
hc.release_rate = _ext_release     # 同步 get_output()
```

### 前庭特定参数校准

**校准目标**：在典型 HC 激活电压（V_m=0.341，1/3 Boltzmann 开放）下，release_rate ≈ 0.40，τ = 50 ms。

**推导过程：**

```
I_Ca(V_m=0.341) = g_max × m∞ × (E_Ca − V_m)
                = 2.0 × 0.750 × (1.5 − 0.341) = 1.738

target V_ca_ss = √0.40 + 0.01 = 0.642
R_ca = V_ca_ss / I_Ca = 0.642 / 1.738 = 0.37

τ = 50 ms = R_ca × C_ca
C_ca = 0.050 / 0.37 = 0.135
```

| V_m | Ca 通道状态 | I_Ca | V_ca_ss | release_rate |
|---|---|---|---|---|
| 0.115（静息） | 关闭（m∞≈0.0016） | 0.0045 | 0.0017 | 0（<阈值）|
| 0.308（Ca 半激活） | 半开（m∞=0.50） | 1.192 | 0.441 | 0.186 |
| 0.341（典型激活） | 开放（m∞=0.75） | 1.738 | 0.642 | 0.401 |
| 0.500（强激活） | 全开（m∞≈0.998） | 1.996 | 0.739 | 0.531 |

**BIO 来源**：
- `R_ca=0.37`：前庭毛细胞 PMCA 泵清除速度（Holt et al. 1999 J Neurophysiol 82:1756）
- `τ=50ms`：Burrone & Lagnado 2000 J Physiol 524:821
- 前庭 HC Ca²⁺ 清除比听觉 IHC 更快（τ_听觉≈200ms vs τ_前庭≈10-50ms）

### 两个工程修复

**修复一：V_m 钳位（防 math.exp 溢出）**

回归测试使用 dt=1.0（仿真步），HC 膜电压可大幅振荡到 -100 以下。Boltzmann gate 中：
```
exp(-(V_m − 0.308) / 0.030)  当 V_m < -20 时 → math.exp overflow
```

修复：将 V_m 钳至物理有意义范围 [-0.5, 2.0]。
- 物理正确：V_m << V_half=0.308 时 Ca 通道关闭（g≈0），release=0
- 无信息损失：正常生理活动区间 [0.1, 0.5] 完全在范围内

**修复二：Ca²⁺ 积分用物理时间步**

回归测试 dt=1.0（仿真步），远超 Euler 稳定边界（dt < 2τ = 0.1s）：
```
CalciumDynamics.step(_I_Ca, 1.0)  → dt/τ = 20 >> 2 → 数值爆炸
```

修复：Ca²⁺ 积分始终使用 `self._dt = 0.001s`（构建时物理时间步），与外部传入的仿真步 dt 解耦。

### 当前功能状态

在目前电路中，HC 膜电压在典型输入下约为 0.115（静息电位），未超越 Ca 阈值（0.308），因此 `release_rate ≈ 0`。这与 T-010 前的行为一致（原有内部 Ca²⁺ 同样输出≈0），是已知限制而非本次引入的问题。

**架构意义**：Ca²⁺ 换能链现在为真实 Boltzmann 门控而非 MOSFET 近似，当电路调优使 HC 超越 Ca 阈值后，release_rate 将正确地从 0 跳升到 0.4+ 区间，不需要更改 chain.py。

## 四、T-011：Ca²⁺ Phase B pre_trace 修正

### 内容

pre_trace 更新逻辑由外部 `CalciumDynamics.release_rate()` 驱动，而非原有的 `hc.release_rate`（内部 Ca²⁺ 输出）：

```python
# 旧：基于内部 Ca²⁺（≈0，STDP 无效）
hc.pre_trace = min(_pt_before * _decay + abs(hc.release_rate), 10.0)

# 新：基于外部 CalciumDynamics（物理 Boltzmann gate）
hc.pre_trace = min(_pt_before * _decay + abs(_ext_release), 10.0)
```

当 HC 电压超越 Ca 阈值时，pre_trace 将真实反映 Ca²⁺ 释放信号，STDP 学习动态可正确工作。Ca²⁺ 路径在架构上已完全闭合：

```
V_m → CalciumChannel → I_Ca → CalciumDynamics → V_ca → release_rate → activation & pre_trace → bundle
```
