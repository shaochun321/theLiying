## 目标

评判裁定 `EntryBoundaryDetector`（TSS-R1a）只是**实时参考检测器**，不是物理生成算子——
它保存 ARMED/ACTIVE/REFRACTORY 状态、计算无脉冲间隔、抑制同一发生内的重复脉冲、产生
新脉冲，这是真正的过程变换 E^↑: p_α(t) ↦ b_α^↑(t)，但只存在于 Python 控制逻辑中。

本轮 R1b 只回答一个问题（不写生产代码）：

> 现有神经元、电容、门控和不应期结构，能否实现与参考检测器相同的
> "首次通过、重复抑制、静默后重置"过程？

目标物理结构需满足：

```
p_α(t) → b_α^↑(t)   (ARMED 时首次脉冲)
       → 0           (ACTIVE 期间重复脉冲)
ACTIVE --τ_gap--> REFRACTORY --τ_rearm--> ARMED
```

## 裁定结论（三段分别判定）

### 第一段：ARMED→ACTIVE 首次脉冲 + ACTIVE 期间重复抑制 —— **可实现，有现成同构先例**

项目里已有一个结构完全同构的物理机制：**FatigueCapacitor**（`neuron.py:481-524`，
TYPE:SEMI，BIO: Ca²⁺ 依赖 K⁺ 通道 / Na⁺ 通道慢失活）。其工作方式与 E^↑ 所需的
"进入后自我抑制、静默后自动复位"逐条对应：

```
neuron.py 现有 FatigueCapacitor            E^↑ 所需语义
────────────────────────────────────       ──────────────────────────
每次 spike → _fatigue_cap.charge += Q      首次通过后 → 进入门被自身输出充电
V_fat 抬高有效阈值（-fatigue_k × V_fat）    ACTIVE 期间抑制后续重复输出
_fatigue_cap.leak(fatigue_r_leak, dt)      静默期间抑制量按 τ = C·R 自然衰减
V_fat 跌回低位 → 阈值恢复 → 可再次发放      衰减到位 → 自动重新武装
```

这不是"可以类比"，而是同一个电路拓扑：一个自抑制 RC 环（spike 自充电 + 泄漏恢复 +
乘性/加性抬阈）。`D2Autoreceptor`（DA 神经元自身释放 DA → 局部 [DA] 电容积分 →
GIRK 超极化电流回灌自身）是同一范式的第二个实例，`CalciumRateIntegrator`
（spike → Ca 池充电 → RC 泄漏 → MOSFET Zener 钳位）是第三个。

结论：**E^↑ 的核心语义（首次进入产生脉冲 + 同一发生内抑制重复）不需要任何新原语**，
用 `Capacitor` + `MOSFET` 按 FatigueCapacitor 同一模式接一个自抑制门即可，
Python 的 `_phase` 枚举可以完全消掉。

### 第二段：ACTIVE→退出判定（τ_gap）—— **可实现，且不必用整数计步**

`occurrence.py` 已经证明了另一条路：用 `pre_trace`（leaky 积分量，本质是 RC 衰减的
标量实现）+ `theta_down` 阈值做退出判定——"是否还处于活动期"由**电压是否跌破阈值**
决定，不是数无脉冲步数。

因此 `gap_steps=500` 可以换成"进入门 Capacitor 的 τ_leak"：只要相邻 spike 间隔
（ISI）小于 τ_leak，Capacitor 就来不及跌破阈值，门保持关闭（抑制重复）；ISI 显著
大于 τ_leak 时电压自然跌破，门重新打开。效果与计步等价，但载体是真实 RC 衰减。

量化对照（EXP-R1A-01 实测数据，TSS-R1a 报告已记录）：
- 正常发放簇内 ISI 集中在 **120~316 步**（dt=0.001 → 0.12~0.32 s）
- 真实退出事件的间隔为 **4257 / 5927 步**（21/24 站点各一次）
- 两者相差 **13~50 倍**，中间有极宽的分离带

所以退出判定不需要精确标定就能可靠分离两类间隔——中间有一个数量级的余量，
不是需要小心调参的临界点。

**参数表达修正**（评判 `document - 2026-08-05T170306.100.md` 指出）：
本报告初稿写成 `τ_gap ∈ (0.32 s, 4.2 s)`，把"重新开门时间"直接等同于 RC 时间
常数，这是错的。真正决定开门时刻的是三者联合：

```
t_open = τ_g · ln(V_H / θ_g)
```

需要满足的是 `0.316 s < t_open < 4.257 s`，等价于两个资格不等式：

```
V_H·exp(-0.316/τ_g) > θ_g     最大簇内间隔后仍关门
V_H·exp(-4.257/τ_g) < θ_g     真实静默退出后已重新开门
```

区间仍然很宽（无需网格搜索），但**必须联合确定 τ_g / V_H / θ_g 三者**，
只冻结 τ_g=1 s 不等于恢复时间已确定。方案 v2 的 Q3 给出了三者的具体取值
（全部取项目既有默认值：V_H=1.0、θ_g=0.3、τ=1.0 → t_open=1.204 s=1204 步，
落在分离带几何中位 1160 步附近，差 3.8%）。

### 第三段：REFRACTORY→ARMED（τ_rearm）—— **不能实现，且是继承债务**

`rearm_min_steps` 的语义是：静默已达到退出阈值**之后再等一段固定步数**才重新武装。
这是一个**独立于衰减本身的第二时钟**。

审计发现：`occurrence.py:329-344` 的 `REFRACTORY` 阶段用的同样是纯整数计步
（`if t_step - self._t_down >= self.rearm_min_steps`），不是任何 Capacitor 泄漏或
MOSFET 门控的产物。

**关键判定：这个物理映射缺口不是 `entry_boundary.py` 新引入的，是从
`occurrence.py` 继承来的，此前所有资格审计从未把它单独挑出来过。**

进一步核查 `rearm_min_steps=500` 的标定来源
（`tests/exp_P2A1b_3_closure_calibration.py:65-70`）：

```
rearm_min_steps=0:    3次伪发生 [1077, 1227, 1541]（间隔150/314步）
rearm_min_steps=200:  2次 [1277, 1741]
rearm_min_steps=500:  1次 [1577]  ← 收敛到真实的那一次
rearm_min_steps=1000: 1次 [2077]（同样收敛，但更晚）
rearm_min_steps=2000: 0次（3000步内还未完成rearm，过度保守）
```

这份标定证明的是"500 能把伪发生收敛为 1 次"——即它实际扮演的角色是
**去抖动/防重复计数滤波器**，与 `theta_down` 退出判定要解决的是**同一个问题**
（同一次物理支撑期内不要重复计数），而不是一个独立的生理不应期。

也就是说：τ_gap 和 τ_rearm 目前很可能是同一个物理量被拆成了两个软件参数。
若确实需要两个不同时间尺度（例如生物上"突触抑制恢复"与"突触后不应期"是两种
机制、两个时间常数），当前代码里找不到任何依据——Q3 答不上来。

## 发现的真实问题

**1. τ_rearm 的双时钟结构在全项目范围内都缺物理依据（继承债务，非本轮引入）**

`occurrence.py` 和 `entry_boundary.py` 都用整数计步实现 `rearm_min_steps`。前者是
P2-A 阶段就已冻结并被 `occurrence_tap.py` / `r2_fork.py` / 多个测试消费的既有资产，
标定文档只证明了"这个值能抑制伪发生"，没有回答"为什么退出判定之后还需要第二个
独立时钟"。这是本轮审计的主要发现——如果 R1b 只盯着 `entry_boundary.py` 改，
会把同一个缺口留在 `occurrence.py` 里，下次审计再次被指出。

**2. 计步器不等于物理载体，即使它的数值有实测依据**

评判已明确指出这一点，本轮核实确认：`gap_steps=500` 有 EXP-R1A-01 的 ISI 分布支撑
（作为判定规则合格），但"500 步"这个整数由 Python `int` 字段保存、由
`t_step - self._t_exit` 比较推进，没有任何 `Capacitor.charge` 或 `MOSFET.m_gate`
参与。τ_gap = 500·Δt = 0.5 s 需要落到某个具体的 C·R 上才算物理化。

**3. collector 神经元当前并未启用 FatigueCapacitor——它的自抑制只有 AdEx 适应电流**

核对 `_thermal_quantum_collector_config`（`variant_adapter.py:378-404`）：
`spiking=True`，`b_adapt=0.01`，`tau_w=1.0`，但**没有** `use_fatigue=True`
（全项目仅 `circuit/hebbian.py:284` 一处启用了 Fatigue）。

这意味着 collector 现有的唯一 spike 后自抑制是 AdEx 的 `_w_adapt`
（`neuron.py:507` `self._w_adapt += self.config.b_adapt`，`tau_w=1.0` → τ=1.0 s）。
而 τ_w=1.0 s **正好落在**上面算出的 τ_gap 可行区间 (0.32 s, 4.2 s) 内——这是一个
值得注意的巧合，也是方案里"复用既有适应电流而非新加电容"这条路线的依据来源。
但要注意 `_w_adapt` 抑制的是 collector 自身的发放，不等于 E^↑ 门的开闭，两者
不能直接混同（详见方案 §风险 R2）。

**修正一处此前的手推错误**：报告与方案初稿曾把 oracle 开门步数写成

的 REFRACTORY→ARMED 判断在探测 spike 到达**前**已经完成计步比较
（`t_step - self._t_exit >= rearm_min_steps`，见 `entry_boundary.py:177`），
探测 spike 只是"顺便"用第一个满足条件的步来验证，不额外占用一步。
这处偏差不影响任何判定结论（T-R1B-8 用的是实测值，不是手推值）。

## 冻结契约

```
R1b-1 首次通过 + 重复抑制：可用现有 Capacitor + MOSFET 实现，
      有 FatigueCapacitor / D2Autoreceptor / CalciumRateIntegrator 三个同构先例，
      不需要新原语。                                             判定：可实现

R1b-2 静默退出判定：可用 RC 泄漏 + 阈值替代整数计步。
      实测 ISI 簇内 120~316 步 vs 真实退出 4257/5927 步，相差 13~50 倍。
      开门时刻由 t_open = τ_g·ln(V_H/θ_g) 三者联合决定（非 τ_g 单独），
      需 0.316s < t_open < 4.257s。                              判定：可实现

R1b-3 重新武装（τ_rearm）：整数计步，无物理载体。
      缺口在 occurrence.py 与 entry_boundary.py 中同时存在（继承债务）。
      标定记录只证明它是去抖动滤波器，与 theta_down 解决同一问题，
      未证明需要独立的第二时间常数。
      裁定（评判 170306.100）：E^↑ 新支路采用单时钟；不得宣称已证明
      occurrence.py 的双时钟在所有用途上多余，只登记债务保持不动。
                                                                判定：单时钟

R1b-4 collector 当前未启用 FatigueCapacitor，唯一 spike 后自抑制是
      AdEx 适应电流（b_adapt=0.01, tau_w=1.0s）。                判定：已核实

R1b-5 FatigueCapacitor 不足以单独作先例——它没有钳位，持续发放下靠
      充电率/泄漏率达到率依赖稳态，恢复时间随发放率变化。E^↑ 要求恢复

      当前可用作硬阈值整流器，但依赖实现行为而非注释语义。
      登记为独立技术债，不在 R1b 范围内修。                      判定：脆弱点登记
```

## 未完成项 / 下一步

R1b 审计本身已通过（评判 `170306.100`：审计结论基本通过）。路线已裁定为
**单时钟**，v1 方案的"路线甲/路线乙"二选一关闭，路线乙（查文献补双时钟 Q3）
被明确禁止。

但 v1 方案的实现步骤 S1 被**否决**，原因是一处推导错误：v1 规定"被抑制的
重复脉冲不再给电容充电"，这让门测量的是「距首次脉冲多久」而非
「距最近一次脉冲多久」，持续发生中途会自行开门并重复输出 b^↑。
正确结构是**可重触发、饱和刷新型 RC 抑制门**：每枚脉冲都刷新抑制电压，
但由 Zener 钳位限幅在 V_H。

方案已修订为 v2（`claudecode方案/TSS-R1b_E上箭头物理载体实现方案_2026-08-05.md`），
状态改为**可执行**：

```
S1  可重触发饱和 RC 门（每枚 spike 刷新 + Zener 钳位 + 泄漏后判定的顺序）
S2  参数验证（不是反推——三个参数全取项目既有默认值，t_open 自动落在分离带）
S3  资格测试 T-R1B-1~9（构造脉冲序列，不做逐步等价）
S4  跨站点 28/31/21/24 同参数验证
S5  全量回归 21/21 + R1a 的 6/6 不受影响
```

另外撤销了 v1 的一项判据：`b^↑_physical ≡ b^↑_reference` 逐步等价**不成立
也不应要求**——三个开门阈值互不相同（物理门 1204 步 / oracle rearm=0 为 501 步
/ oracle rearm=500 为 1001 步）。强行等价意味着用软件整数反推物理时间常数，
因果方向与整条主线相反。逐步等价降级为"事件计数旁证"，且必须在测试里显式
断言其成立前提（实测流没有 gap 落在 [501,1204) 分歧区间）——否则又会重犯
"在一条实测流上一致 ⇒ 算子相等"的老错（同 TSS-2b 的 Λ 资格）。

附带旁证：两个 oracle 变体（rearm=0 / rearm=500）在实测流上给出**相同**事件
计数——实测数据分辨不出第二个时钟做了什么，这是 R1b-3 判定的又一条独立支持。
