## 一、任务背景与 Gate C 的具体要求

方案原文（v2 计划 T2 段落）明确：

> **编码前必须先单独出一份「方向关系电路定义报告」**。核心：**方向不是 Bundle 名称**——把 Bundle 命名为 a→b 不会让它自动成为方向关系；若只建 `ξ_a→D_a→b`、`ξ_b→D_b→a`，输出只能证明「哪个源激活」，退化成源身份检测。

方向检测必须**同时**满足三要素：
1. **结构邻接**：(a,b) 确实相邻；
2. **起点痕迹**：ξ_a 的活动沿 a→b 支路传播；
3. **终点耦合**：传播痕迹与 ξ_b 的**当前**活动在终点耦合。

以及我方在 v2 计划落地时的独立补充（批判二未点破，见计划 §四 T2"我方补充"段）：

> 仅「邻接」不足以区分 r→ 与「恰好邻接的 r≺」——若传播支路与 r≺ 历史支路用同一种**对称** RC 机制，两者无法区分。真正的区别须是：r→ 的 a→b 与 b→a 传播支路**物理不对称**。

本报告的任务：把这四点要求转化为一份可直接编码的具体电路设计，**在动手写 Neuron/Bundle 代码之前**想清楚，避免退化成源身份检测。

## 二、T1 完成后新增的关键输入（为什么现在能写好这份设计）

T1（r≺）的标定过程（见 `工作报告/基础生成元温感轨T1_...`）暴露了三个直接影响 T2 设计的事实：

1. **`Neuron` 单通道模式的 `activation` 是 `gm×(vm-vth)²` 二次压缩**（非线性门控，非 bug），意味着任何新生成元的 trace/collector 神经元都要么显式设 `v_threshold=0` 并配合足够大的 `gm`，要么接受非线性放大器的性质——T2 的传播中继神经元设计必须从一开始就考虑这一点，不能重复 T1 尝试 1/2 的教训。
2. **`Capacitor` 稳态电压 `V_ss=I×R_leak` 与 `C` 无关**，`R_leak` 决定增益、`C` 决定到达稳态的时间常数——这给 T2 的传播延迟中继神经元提供了独立调节"传播强度"与"传播时间尺度"的自由度，不必像最初 T1 那样把两者绑死。
3. **真实 ξ^occ 源（感温量子元链路）有 ~400 步启动延迟 + 驱动停止后的半自主残余振荡**，不适合做"精确时序判别"的驱动源——T2 的验证必须采用 T1 已确立的方法论：**先用合成脉冲（直接控制 `pre_trace`）验证生成元电路本身的方向判别逻辑**，真实链路只做结构连通性冒烟测试，不作为方向精度的证据来源。

## 四、核心设计决策：用真实几何距离驱动的传播延迟中继，区别于 r≺ 的纯 RC 记忆

### 4.1 问题：如果照搬 T1 的双分支 RC trace 结构，会退化成什么？

若 T2 直接复用 T1 的机制（`ξ_a → RC trace → 与 ξ_b 重合 → collector`，仅把"哪个是 a 哪个是 b"换成邻接点），那么 T2 和"恰好建在相邻两点上的 r≺"**没有任何结构性区别**——只是把 T1 的 {28,31} 换成 T2 的 {31,28} 而已。这正是方案原文警告的"退化成源身份/时序检测"，也是我方在 v2 计划中补充的"仅邻接不足以区分"论点的具体体现。

### 4.2 设计决策：传播中继必须携带"这是沿一条具体物理边传播"的信息，r≺ 没有这个信息

r≺ 检测的是"任意两个信号谁先谁后"，天然不携带空间信息（两个 ξ 可以毫无空间关系）。r→ 检测的是"发生沿哪条结构路径能够传播"——这要求传播中继的动力学**编码传播所需的物理量**（距离/传导速度），而不只是"记住源信号最近是否活跃"。

具体机制：**用 `BundleConfig.delay_steps`（既有字段，`circuit/bundle.py:38`，语义即"轴突传导延迟"）承载传播时延，延迟量取自 T0 冻结的真实边距离，而非拍脑袋常数或运行时坐标计算**：

```
delay_ab_steps = round(d_ab / v_edge)
```

**量纲修正（纳入交叉比对第三份批判点5，本次追加）**：初版把 `v_edge` 类比成真实生物传导速度（"myelinated axon ~100m/s, unmyelinated ~1m/s"），但 `d_ab` 是 T0 冻结的**模型球面单位**距离（半径 `_THERM_LOCAL_R=2.0`，不是米），二者量纲不匹配——`d_ab / v_edge` 要得到"步数"，中间缺一个把模型距离单位换算成米的长度尺度映射 `ℓ0`（`d_ab^phys = ℓ0 × d_ab^model`），而本报告和母本代码都未定义过这个 `ℓ0`，硬套 `100 m/s` 这样的真实生物速度是量纲错误。

**修正**：不引入定义不出来的 `ℓ0`，直接把 `v_edge` 定义在**模型单位**下，不再引用任何真实生物速度锚点：

```
v_edge  的量纲 = [模型距离单位 / 仿真步]
delay_ab_steps = round(d_ab / v_edge)      （d_ab 取 T0 冻结值：1.0916 或 1.1612，模型单位；v_edge 待实施阶段标定）
```

`v_edge` 具体取值的标定目标：使 `delay_31_28`/`delay_28_23` 落在个位数到几十步量级（同原意图），但换算过程全程在模型单位内闭合，不再需要也不再引用真实世界的 m/s 数值。具体数值在实施阶段用 T1 式的"Model before tune"实测标定，本报告不预先编造。

**这一步是 delay_steps 在本项目中少数真正合适的用法**——T0 的五项核实结论明确说"delay_steps 是矩形 FIFO 时移，不具备 RC 积分器的连续衰减动力学"，正因如此它不适合 T1（需要连续衰减的"记忆强度"），但恰好适合 T2（"信号从 A 点传到 B 点需要一段固定的物理传输时间"本来就应该是离散的传输延迟，不是记忆衰减）。这是"同一字段，不同生成元里的正确/错误用法"的一个具体案例，值得写进代码注释防止未来误用。

### 4.3 完整电路（每条边，以 31↔28 为例）

```
ξ_31 → [Bundle: delay_steps=delay_31_28, frozen] → 传播延迟中继神经元 P_{31→28}
                                                          │
                                                          ├→(Bundle)→ D_{31→28} Collector
ξ_28 (raw, 同一步内) ─────────────────────────────────────┘

ξ_28 → [Bundle: delay_steps=delay_31_28（同一条边，同一距离）, frozen] → 传播延迟中继神经元 P_{28→31}
                                                          │
                                                          ├→(Bundle)→ D_{28→31} Collector
ξ_31 (raw, 同一步内) ─────────────────────────────────────┘
```

**关键澄清（回应"物理不对称"要求）**：两个方向共享**同一条边的同一个距离值**（距离对称，物理上 A→B 和 B→A 的传输时延本应相等，这是"沿同一条真实边传播"的物理事实，不是缺陷）。**真正的不对称性不在"延迟量的大小"，而在传播中继的动力学类型本身**——P（延迟线）与 T1 的 trace（RC 积分器）是两种不同的物理机制：延迟线只做"搬运"，不做"记忆强度衰减判断"；RC trace 做的是"记忆强度衰减判断"，不做"搬运"。r→ 和 r≺ 因此在结构上不可混淆，即使建在同一对相邻点上，方向判别逻辑也天然不同——这就同时满足了方案的"方向不是 Bundle 命名"要求（判别来自延迟-重合机制本身，不是靠给 Bundle 取名 `a_to_b`）和我方"物理不对称"补充（不对称体现在**机制类型**而非**同边延迟量**上，这是本报告对 v2 计划原表述的一处精确化：原表述"传播支路物理不对称"容易被误读为"延迟大小不同"，实际应理解为"与 r≺ 的 RC 记忆机制相比，delay-line 是不同类的物理过程"）。

### 4.4 终点耦合的判别逻辑（对应三要素之三）

Collector 同时接收：① 传播延迟中继 `P_{a→b}` 的输出（ξ_a 信号经过 delay_steps 步物理传输后到达）；② ξ_b 的**当前**（同一步）信号。当且仅当"ξ_a 在 delay_steps 步之前发生过 + ξ_b 现在也在发生"时，两路电流同时到达 collector 才会重合触发——这与 T1 collector 的 AND 门标定方法论完全一致（非对称权重、`v_peak` 阈值实测标定，见 §五）。

## 六、验证方式（编码后必须满足，本报告先定验收标准）

### 6.1 结构性验收（禁止事项检查清单）
- [ ] 未使用 `sign()`/点积/坐标差计算方向；
- [ ] 未在运行时读取节点的世界坐标（坐标只在 T0 冻结阶段用于**选点**，不用于方向判别的运行时逻辑）；
- [ ] `D_{a→b}` 与 `D_{b→a}` 的判别逻辑对称（同一套 config 工厂函数，只是源/目标互换），不能靠"提前写死哪个方向该赢"；
- [ ] 未复用温感 Ω 层的 RF collector（Ω 是预设方向模态，非本生成元的双向结构关系）。

### 6.2 功能性验收（合成脉冲测试，同 T1 T-TRP-3/4 方法论）
1. **正向传播**：在 ξ_31 上打一个合成脉冲，delay_31_28 步之后在 ξ_28 上打一个合成脉冲（模拟真实的空间传播延迟）→ `D_{31→28}` 应强响应，`D_{28→31}` 不应响应。
2. **反向传播**：反过来（先 28 后 31，间隔同一 delay）→ `D_{28→31}` 应强响应，`D_{31→28}` 不应响应。
3. **无延迟对照**（同一步触发两点，不满足"传播所需的最小延迟"）→ 两个方向都不应强响应（证明生成元确实在检测"符合传播时延的重合"，不是任意重合都算数）。
4. **frozen 权重不变**、**静息无虚假发放**：同 T0/T1 已确立的探针范式。

### 6.3 与 r≺ 的区分验收 —— 拓扑判据（纳入交叉比对第五份批判点3，取代原"不能被r≺模拟"表述）

`r_edge-lag` 升格为 `r→`（结构方向关系）须**同时**通过以下 5 项拓扑判据，全部用合成脉冲在 Phase 4 集成阶段测（同 T1 T-TRP-3/4 方法论），不再靠"输出波形是否能被 r≺ 参数化模拟"这种不可证伪的判据：

5. **边依赖性**：移除边 e=(a,b) 上的传播 Bundle 后，`r_a⇢b^e` 应归零，即使 a、b 仍以相同时差（人为在电路外同步注入合成脉冲）先后发生——证明关系确实依赖这条边的物理连接，不是单纯"两个信号凑巧有时差"。
6. **非边排除性**：对冻结拓扑中没有直接邻接的点对（如 31 与 23 之间，二者只通过 28 间接相连），即使人为给两点施加与真实邻接边完全匹配的时差，也**不应**产生直接边关系 `r_31⇢23^direct=0`——证明关系不会因为时差匹配就凭空跨接不存在的边。
7. **方向交换性**：交换发生顺序（先驱动 a 后驱动 b，改为先驱动 b 后驱动 a）后，`r_a⇢b ↔ r_b⇢a` 应对应交换——同 T1 T-TRP-3 已验证的方向不对称性。
8. **路径可组合性**：在链 31↔28↔23 上依次触发 31→28→23，应形成两条**局部边**关系 `r_31⇢28`、`r_28⇢23`，但**不应自动产生** `r_31⇢23^direct`（那需要走两跳，不是直接边）——证明关系是逐边局部的，不会因路径传递而凭空产生跨边的"直接"关系。
9. **标签协变性**：交换节点编号（如把 28、31 的标签互换）但保持拓扑结构与驱动方式不变，输出应随结构一起交换——证明判别逻辑不绑定具体点编号，是真正的结构关系而非硬编码在特定索引上。

满足以上 5 项后，才能说 `r_edge-lag` 携带了 r≺ 没有的**结构支撑**（不依赖任何边、不排除非边、无法组合成局部路径的关系，只是"波形恰好对得上"的时序检测，本质仍是 r≺ 的特例）。此时更准确的定义是 `r→ = 有向发生 + 冻结邻接边支撑`，而不是"波形无法被另一种时间核拟合"。

## 七、已知局限与后续待办

- 本报告尚未标定任何具体数值（`v_edge`、trace/collector 参数、权重），这是**有意为之**——按项目"Model before tune"原则，具体数值必须在实施阶段用实测数据推导，不能在设计报告里预先编造。
- `delay_steps` 是否会像 T0 五项核实结论提到的那样"与 pre_trace 产生二次时间扩展"，在 T2 的具体接线里需要重新核实一次（T0 的核实用的是通用最小复现实验，不是针对 T2 具体拓扑的核实）。
- T2 的"`v_edge`"常量目前只有"delay_steps 落在个位数到几十步量级"这个粗略要求，实施时需要结合真实驱动动态（如 T1 诊断出的 ~400 步启动延迟）重新评估这个量级是否合理——如果真实源的启动延迟本身就有几百步的方差，个位数到几十步的传播延迟窗口可能被启动延迟的噪声完全淹没，这是需要在实施阶段用合成脉冲测试之外，**额外做一次"真实源背景噪声 vs 传播延迟窗口"的信噪比评估**的开放问题。
- **本轮追加修正（第三份批判）**：① 量纲错误已修（`v_edge` 改为模型单位速度，不再引用未定义的真实生物速度锚点，见 §四.2）；② 生成元命名降级为 `r_edge-lag` 原型（见报告顶部）。
- **本轮追加修正二（第五份批判）**：升格 `r→` 的判据从"不能被 r≺ 模拟"（不可操作，见报告顶部说明）改为 §6.3 的 5 项拓扑判据（边依赖性/非边排除性/方向交换性/路径可组合性/标签协变性）。
