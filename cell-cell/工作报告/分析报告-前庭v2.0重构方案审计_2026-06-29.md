## 一、两份文件的关系与性质

**主方案**：提出五项重构：拓扑地址空间、软饱和传导、能量门控增益 G_eff、FIFO 传导延迟、oto 轴平等拓扑权。

## 二、逐条核验

### 2.1 软饱和传导（替换 PowerRail 硬截断）

**主方案提出**：将 `max(0, 1 - I·r)` 替换为 `I / (1 + I·r)`。

**代码核验**：  
`nexus_v1/components/semiconductor.py` 第 285-289 行：
```python
def draw(self, current: float) -> float:
    return max(0.0, self._vdd - current * self._r_internal)
```
Aff 神经元：`r_supply=0.05`，硬截断临界点 HC_act = vdd/（W×gain/inertia×r_supply）= 1.0/（0.8×20/0.5×0.05）= 1.0/(1.6) = **0.625**

修正：临界点是 0.625，不是审计报告中的 1.0（计算时漏了 inertia 分母）。即 HC_act > 0.625 时 PowerRail 就开始限流，HC_act > 1.25 时完全断流。

**评价**：软饱和是正确的工程方向。现有 PowerRail 硬截断在 HC 强激活时产生信息损失（不连续），软饱和 `I/(1+Ir)` 在数学上严格更优，且纳入 TSI 功率审计意义明确。**此项修复在 v2.0 中应当采纳。**

---

### 2.2 能量门控动态增益 G_eff（修复 Aff→Enc 3% 裕量）

**主方案提出**：
$$G_{eff} = G_0 \times (1 + \alpha \cdot P_{avail}/P_{baseline})$$
α=0.1（保守），G₀ 不变。

**补充文件的数学推导**：
- 需要弥合 2 Hz → 12.5 Hz，即需要约 6.25× 增益放大
- α=0.1，能量满载时 G_eff = G₀ × 1.1
- **1.1× 绝对无法闭环**，前庭静默问题不解决

**补充文件的修正方案**：
$$G_{eff} = 16.0 \times (1 + 0.1 \cdot P_{avail}/P_{baseline})$$
G₀=16.0（治病），α=0.1（维稳），职责清晰。

**代码核验**（对照当前 hebbian.py 标定注释）：
```
当前：synapse_gain=2.0，按 12.5 Hz 标定
目标：synapse_gain_eff=16.0，使 2 Hz 时 V_ss_enc = 2×2.5×16×0.001×5 = 0.40 V > 阈值 0.30 V ✓
```

**但存在一个未解决的矛盾**：  
主方案声称"synapse_gain 保持 2.0（保护热觉回归测试），仅修改 effective_gain"。然而：
- 回归测试中 oto_x 是强驱（amplitude=200），Aff 发放约 10 Hz
- G₀=16.0 时：V_ss_enc = 10 × 2.5 × 16 × 0.001 × 5 = **2.0 V >> v_peak_enc=0.3 V**
- Enc 完全饱和（持续发放）→ T2.2 安静编码上升，T2.3 选择性比值可能 FAIL

主方案回避了"G₀ 提高后如何保护回归测试"这个问题。补充文件识别了漏洞但没有解决回归测试的兼容性。

**结论**：G₀=16.0 + α=0.1 的数学方向正确，但必须同步核查并调整 T2.2/T2.3 阈值。主方案关于"保护热觉回归测试"的承诺在 G₀=16.0 下无法兑现。

### 2.3 FIFO 传导延迟

**主方案提出**：基于拓扑距离计算延迟，Aff→Enc 延迟 3000 步（3 秒）。

**代码核验（与当前测试框架对比）**：

| 指标 | 数值 |
|------|------|
| 回归测试总步数 | 10,000 步 |
| Aff→Enc 延迟 | 3,000 步 |
| 信号到达 Enc 的时间 | 测试进行 30% 时 |
| 实际有效学习窗口 | 7,000 步（70%） |
| T5.1 测量的 Xin 频率窗口 | 全 10,000 步 |

**3,000 步延迟使 Aff→Enc 的前 3 秒完全无信号。** 当前 T5.1 测量的 Xin 是从第 0 步开始的，若 Enc 在前 3,000 步没有输入，Xin 的时域分布会严重扭曲，T5.1 大概率 FAIL。

补充文件提出 FIFO 用噪声预填充（σ=0.01），这缓解了"启动静默"但无法解决 3,000 步真实延迟对测试的影响。

**更根本的问题**：3,000 步延迟意味着 1ms × 3000 = 3 秒。在 1ms 时间步长的仿真中，"脑干到主层"用 3 秒传导，远超生物 VOR 反射（5-10ms，即 5-10 步）。即使考虑仿真缩放，这个数字也需要重新标定。

**结论**：FIFO 延迟作为架构概念是正确的（赋予信号时空结构），但 3,000 步的绝对值与当前测试框架和生物标定均不兼容。建议修正为 50-100 步（50-100ms），与主方案信号流图中 MET→HC 的"50步延迟"量级一致。

### 2.4 拓扑距离层级（三级约束）

**补充文件的方案**：
- 簇内距离（yaw/pitch/roll 内部，oto_x/y/z 内部）= 1
- 簇间距离（半规管 vs 耳石）= 3
- 跨模态距离（前庭 vs 热觉）= 10

**评价**：三级约束在数学上严格满足偏序关系（1 < 3 < 10），且符合解剖学（半规管与耳石在颅骨中确实空间分离）。这是此方案中逻辑最严密的部分。

**STDP 引导效果**：距离=3 的簇间连接成本是距离=1 的三倍，STDP sprout 时会优先在簇内形成连接，只有强相关信号才会跨簇。距离=10 的跨模态连接成本极高，几乎不会被 sprout，符合"多感觉整合需要高度相关才能建立"的生物原则。

**结论**：此设计在三级约束明确后完全自洽，建议保留。

---

### 2.5 oto 轴获得平等拓扑权

**主方案提出**：取消强拓扑束 vs 弱跨轴束的硬编码区分，全部 Col 节点通过 STDP 竞争性学习建立运动映射。oto 初始权重 0.25（当前 0.05）。

**代码核验**：  
当前 oto 轴没有任何拓扑束（只有 cross bundle W_max=0.15），yaw/pitch/roll 有专用拓扑束（W=0.4, gain=10.0）。两者强度差约 15×。

补充文件的oto STDP 建议：以 LTD 为主，无 DA 强化时权重缓慢衰减，防止 oto 轴权重无意义增长。这解决了"oto 轴没有明确学习目标"的问题。

**评价**：此设计方向正确。在生物中，耳石投影（平移感知）确实通过经验依赖可塑性建立运动映射，而非硬连线。但需注意：若 P2 未修复（Enc 无信号），oto Col 层也不会激活，STDP 依然无法运行——oto 平等拓扑权的前提是 Enc 层有信号。

### 2.6 补充文件的三项实施细节

| 细节 | 评价 |
|------|------|
| FIFO 用 σ=0.01 高斯噪声预填充 | 正确，防止启动"感觉剥夺"；需确认噪声不触发 T5.1 的基线 Xin 异常 |
| P_avail 用 τ=500步慢速低通滤波 | 正确，防止能量脉冲（进食）导致增益突变与运动输出震荡 |
| oto 轴 STDP 偏向 LTD | 正确，无明确奖励信号时防止权重随机漂移；与 DA 门控学习兼容 |

## 四、总体判断

### 方案价值

这两份文件共同构成了一个**架构级别的设计提案**，不是修补 Bug，而是为 v2.0 前庭子网提供完整的设计框架。主方案识别了正确的问题，补充文件的数学审计质量高，识别了主方案的致命漏洞并给出了可操作的修正。

### 核心问题清单（需在实施前解决）

**P1（致命）：FIFO 延迟数值需重新标定**
- 3000 步（3秒）不兼容当前测试框架（10k步总长）
- 建议：50-100步（50-100ms），或基于仿真缩放因子重新推导

**P2（重要）：G₀=16.0 对回归测试 T2.2/T2.3 的影响需量化**
- 强输入下 Enc 将饱和（V_ss=2.0V），需验证 T2.2/T2.3 是否仍 PASS
- 或：设计一个饱和防护机制（Enc 的 DivisiveNormalization）

**P3（次要）：oto 平等拓扑权依赖 Enc 层有信号**
- 在 G₀=16.0 修复前，oto Col 依然静默，平等拓扑权无法发挥作用
- 建议：先修复 G₀，再启用 oto 平等连接

### 实施建议

方案适合作为 **World 2.0 的基础架构**，不建议直接打补丁到 v1.x：

```
v1.x（当前）：维持 21/21 PASS，仅执行 P1 修复（已完成）
v2.0（新建）：以此方案为蓝图，在新 circuits/ 目录构建
   Step 1：实现 SoftSaturator + 软饱和传导（不触碰旧代码）
   Step 2：以 G₀=16.0 重标定 Aff→Enc（新 vestibular_enc.py）
   Step 3：实现拓扑地址表 + 三级距离约束
   Step 4：FIFO 延迟（延迟值需重新标定后再实施）
   Step 5：oto 平等拓扑 + LTD 偏向 STDP
```

## 五、结论

补充文件对主方案的审计是正确的。两份文件合在一起，形成了一个**基本完整、局部待修正**的前庭 v2.0 设计：

- **采纳**：软饱和、G₀=16.0+α=0.1、三级拓扑约束、oto LTD、P_avail 低通滤波

- **附加工作**：验证 G₀=16.0 对 T2.2/T2.3 的具体影响，决定是否需要 Enc 的饱和保护

若确认进入 v2.0 重构，建议从 S1（拓扑地址枚举）开始，按主方案路线图逐步实施。
