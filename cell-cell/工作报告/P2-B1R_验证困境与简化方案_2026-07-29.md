# P2-B1R 验证困境与简化方案建议

## 问题总结

经过多轮实验，发现P2-B1R的"学习→冻结→复放→比较响应"验证方案遇到根本性障碍：

1. **Collector激活不足**：在10k步复放中完全不激活；即使50k步也只激活2%的时间
2. **权重变化信号微弱**：Δw≈0.001（1%增长），在整体DA动力学中被噪声淹没
3. **单束贡献有限**：新增bundle只有1条，DA神经元还接收大量其他输入

## 已验证的事实（P2-B1）

T-RPP-1~5 已经证明：
- ✓ 学习资格链路真实工作（DA门控→Δw≠0）
- ✓ 有学习vs无学习产生权重差异（T-RPP-4）
- ✓ 关系地址正确注册（T-RPP-5）

## 评判文档的真实意图

评判要求验证`D(Y_enabled⁺, Y_blocked⁺) > ε`，核心是：
> 关系结构是否真的改变了未来，而不只是自身权重发生变化？

**关键洞察**：P2-B1的T-RPP-4已经部分回答了这个问题——它比较了"有学习vs无学习"两个电路的**最终DA状态**，证明权重差异确实导致下游状态差异。

## 建议的简化验证方案

**方案A：扩展T-RPP-4为轨迹比较**
不做"复放"，而是在训练过程中记录DA轨迹，比较学习组vs基线组的差异：
```python
# 学习组：DA=0.5，权重增长
# 基线组：DA=0.5，但bundle frozen
# 比较：两组的DA膜电位轨迹差异
```
优势：绕过collector激活不足的问题，直接测量训练中的差异。

**方案B：承认当前限制，记录为DEG-017**
将"单束贡献在多输入DA神经元中信噪比不足"登记为已知缺陷：
- P2-B1已验证学习机制本身工作
- 未来作用的完整验证需要等P2-B1K（事件核），届时可以设计**专用的下游响应测量点**
