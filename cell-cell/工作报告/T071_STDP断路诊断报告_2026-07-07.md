## 问题陈述

STDP 权重变化真实存在（|Δw| = 0.2965），但 DR5 = 50%（随机基线）。断路在哪？

## 根本原因分析（三层）

### 层 1：结构性权重过弱
`bundle_spinal_ccw_to_yaw` 权重固定为 `_W_SPINAL_WTA = 0.020`（`T-042` 标定）。
即使 D1 bundle 满权重（w=0.3），注入 yaw_ccw 的电流：
```
I_max = 0.064 × 0.020 = 0.0013  （vs 反射弧峰值 1.36）
```
比值 = 0.1%。**结构上无法对行为产生显著影响**。

### 层 2：学习窗口错误
- 体在热源外（dist > 30）时 relay_left = 0 → phasic_left ≈ 0 → D1 STDP 前驱迹 ≈ 0
- 体进入热源（dist < 30）时 DA 峰值（DA_ema ≈ 3.0）且 phasic 有迹

但这时 phasic_left 被 P0 钳制 = **-0.1V**（防伪奖励机制）。

### 层 3：D1 弧学到了负强化
- 钳制后 phasic = -0.1 → spinal_ccw = -0.047（负值）
- `bundle_spinal_ccw_to_yaw` 将负 spinal 电流注入 yaw_ccw（**抑制性**）
- 结果：DA 奖励期间 D1 弧**学到的是减少 yaw_ccw 激活**（与目标相反！）

但因层 1 的权重过弱，这个负强化效果几乎不可见（< 0.1%）。

---

## 为什么 D1 权重仍在增长？

```
d1_w: 0.0923 → 0.2994（5k步内增长3×）
```

增长主要发生在体进入热源时（步 4300-4500）：
- pre_trace(phasic_left) = |activation| = 0.1（绝对值）
- DA_ema ≈ 3.0（高奖励）
- 三因子 STDP: Δw ∝ pre_trace × DA_ema → LTP

但这次 LTP 是在体**已经在热源内**时发生的，学到的是"在热源内时维持现状"，不是"朝热源方向运动"。

---

## 结论

**DR5 = 50% 的直接原因：**
D1 学习弧即使满权重（w=0.3）也只能提供反射弧 0.1% 的电流。热趋性行为由 `thermo→yaw` 反射弧（HC-016）主导，D1 STDP 的学习结果对行为无实质影响。

**这不是 STDP 本身的问题**，是 `bundle_spinal_ccw_to_yaw` 的结构权重（0.020）过小，使学习弧在功能上"断路"。

---

## 建议修复方向（供用户决策）

| 选项 | 做法 | 风险 |
|:---|:---|:---|
| A. 提升 `sp2y_w`（0.02 → 0.2~0.5） | 增大 spinal→yaw 影响力，让 D1 学习可见 | T4.1/T4.2 可能失调，需重新标定 |
| B. 移除 D1 弧，依赖反射弧 | 接受 HC-016 反射弧主导热趋性，简化架构 | 失去长期学习可塑性 |
| C. 不修改（现状） | DR5 由反射弧驱动，D1 贡献<0.1%，21/21 回归 PASS | 方向性来自反射弧而非 STDP |
