## 二、架构分析：热觉双通道结构

本次执行最重要的发现是热觉系统实际上存在**两条独立的并行通道**，方案文档对此描述不清晰：

### 通道 1：ThermalMembrane → enc_therm → col_therm → Motor（时序通道）

```
World.temperature_at(body.position)
    └→ ThermalMembrane.sense()  → adapted = T - methylation  [τ=200步]
           └→ mechanical_inputs['therm']
                  └→ enc_reg_therm.step(tonic_val * 5.0, dt)
                         └→ col_therm.step()
                                └→ motor_neurons（via col_to_motor_cross，gain=0.7）
```

**生物模型**：C. elegans 时序热感受（klinokinesis）——单点传感器，感受 dT/dt。

**当前问题**：
- `adapted = T_raw - methylation`：body 静止时 methylation ≈ T_raw → adapted ≈ 0
- tonic_val 在 10k 步时仅 ~0.001（极小）
- enc_therm V=0.24 < v_peak=0.35 → 从不放电
- col_therm V=0.05 < v_peak=0.20（已降低）→ 从不放电
- 结果：Motor 基本无热觉驱动 → body 速度 ~0.001 unit/s

**本次修正**（hebbian.py）：
- col_therm v_peak：0.25 → 0.20（新增 `_thermal_column_config`）
- enc→col therm synapse_gain：3.0 → 4.5
- **效果有限**：因为 enc_therm 本身不放电，下游修正无法生效

### 通道 2：SomatosensoryChain 4 patches → relay → soma_to_da → DA（空间通道）

```
World.temperature_at(patch_position)
    └→ SomatosensoryChain.step()
           ├→ nociceptors[left/right/front/back]  ← |dT|
           └→ relays[left/right/front/back]        ← T × relay_gain
                  └→ soma_to_da bundle
                         └→ DA neurons（STDP 权重学习）
```

**生物模型**：空间温度梯度感受——4 个皮肤贴片测量身体周围温度差异。

**当前状态**（运行正常）：
- skin_right T=1.93 > skin_left T=1.60（热源在右侧）
- relay_right ema=1.58 > relay_left ema=1.04
- w_right 缓慢增长至 0.514 > w_left=0.493

## 五、失败原因分析

### DR2 失败：body 运动量极小

**根本原因**：klinokinesis 基底不足。

当前 Motor 驱动来源：
1. **VitalOscillator**：注入 ~0.01 振幅到 Motor 膜（极小）
2. **vestibular → col → motor**：col_to_motor_cross（gain=0.7，weight=0.05）+ axis bundles（仅 yaw/pitch/roll）
3. **thermal pathway**：col_therm 不放电 → 零贡献

计算：
- Motor EMA ≈ 0.007-0.014（亚阈值）
- Body 速度 ≈ 0.001 unit/s = 0.001 mm/s（相对于 world 单位）
- 500k 步 × 0.001 unit/step × dt=0.001 → 总位移 ≈ 0.5 units（低于 DR2 阈值 1.0）

实际测得距离变化 -0.29（500k 步）≈ 半个 DR2 阈值，**仍然是热趋向信号**，只是太慢。

### DR4 失败：分化在 240k 步才稳定

原因：STDP 需要足够多的 pre-post 时序相关事件才能建立方向性偏置。
- 100k 步时有短暂下降（STDP 双向性导致权重振荡）
- 150k 步后才重新单调增长
- 与 DR2 密切相关：body 运动量少 → 皮肤温差小 → relay 激活差异小 → STDP 信号弱 → 分化慢

### DR5 失败：grad_dot_v ≈ 0

完全由 DR2 失败导致：body 不动 → velocity ≈ 0 → grad_dot_v = ∇T · v = 0。

## 六、正面结论

尽管 3/6 PASS，以下发现具有重要意义：

### 6.1 方向性权重分化已涌现（DR1 PASS）

**物理证据**：w_right=0.5139 > w_left=0.4926，差值 0.0213 > 阈值 0.02。

这是结构性涌现，不是硬编码：
- soma relay 因 right patch 温度更高而多放电
- soma_to_da STDP 根据时序相关性增加 w_right
- 没有任何代码显式计算"右边"方向
- 完全由 `SynapticBundle.propagate() + STDP` 完成

### 6.2 热趋向行为早期萌发

距离轨迹 -0.29 units（500k 步内，方向连续一致）证明：
- 系统正在学习向热源靠近（而非随机游走）
- 若延长到 2M 步，预计能达到 DR2 阈值

### 6.3 代谢稳定性（DR3/DR6 PASS）

- 能量 fill 从 0.50 降至 0.32（健康下降，未耗尽）
- DA 无任何饱和（浓度 0.15-0.21）
- 证明 500k 步时间尺度的代谢可持续性

## 九、总结

Phase 5 实验在"方向性权重分化"层面取得突破性进展：soma relay → DA STDP 路径在 500k 步内成功建立了 w_right > w_left 的方向性编码，体现了"行为从结构中涌现"的设计原则。

DR2/DR4/DR5 失败的根本原因是 klinokinesis 基底（body 运动量）不足——这是一个独立的 Motor 层驱动问题，而非热觉路径本身的问题。距离轨迹（-0.29 units，方向一致）已证明热趋向行为的早期萌发。

**下一纪元核心任务**：提升 body 运动量（延长步数 or 增加 vestibular 幅度），使 DR2 可以通过。热觉方向性编码本身已在本次实验中得到物理验证。
