## 评判纠正（201310）

1. **`radius=2.0/3.0`是两次不同的外部发生过程**，不是同一活动云被两个
   内部算子同时处理——ω_{r=2}≠ω_{r=3}。TSS-2b必须用单次驱动。
2. **"几何预测与实测不一致"只是候选机制**，不能钉死为memristor哈希
   扰动——可能还涉及皮肤节点间传播/上游残余状态/公共内部链路等，
   TSS-2b设计不依赖该归因。

## 修正（评判204602 独立复核后，本轮已执行）

初版"差异来自真实结构支撑范围"成立，但**资格名称过强**，且含一个物理
污染缺陷。四点修正：

**1. 物理污染：bundle_id 泄漏进权重（S0-bX1 门回归）**

`bundle.py:194-204` 用 bundle_id 的 crc32 生成 ±25% 权重扰动。
`lambda_local_site20_to_col` 与 `lambda_broad_site20_to_col` 是不同字符串
→ 同一物理站点在两个窗口拿到不同权重。初版 `Y_broad^cut=2.4918` vs
`Y_local=2.3280` 那 7% 差**全部**是命名污染，无结构成分。9c8528d（S0-bX1，
同日）已为此冻结 `physical_seed` 字段，本文件当时未使用。

已修：两组 bundle 改用 `physical_seed=_PHYS_SEED_BASE + site`。修正后
`Y_broad^cut ≡ Y_local`（2.328029 == 2.328029，diff=0.00e+00 逐位相同）。

**2. 资格降格：`Λ_support^(1)` 尺度算子 → `Λ_nested^(1)` 嵌套支撑范围**

上述恒等式的含义：不存在两个算子，只有**一个求和 collector 作用在两张
输入表上**。补测不可约性：`Y_broad=3.5424` vs `Y_local+Y_delta=3.9983`
（ratio 0.886），次可加性仅来自 collector 自身 `v_peak` 钳位与漏电非线性，
而 local 用的是同一个非线性——广域侧没有细尺度不可见的量出现。

故从"与 Θ_≺/Σ_support 并列的第三个基础算子"清单**撤下**，归为
`Σ_support` 子情形。升格所缺检验：证明 `Y_broad` 无法由
`{Y_local, Y_delta}` 经细尺度同类运算重构（参照 P2-C1F-d 对 `K_R2` 的
不可约性检验）。`test_generator_lambda.py` 的恒等断言即该门槛守卫。

**3. 切断实验有一半是同义反复**

`Y_local` 不变是构造保证的（`bundles_local` 不含 `N_Δ` 站点，是另一批
对象），只验证确定性，不构成资格证据。真正带信息的仅 `Y_broad` 改变——
而任何求和节点砍掉 7/16 输入都会变。测试注释已标注该边界。

**4. 命名归属（采纳评判建议）**

```
radius_2 / radius_3   = calibration provenance（仅 TSS-2a 资产发现与标定）
N_LOCAL / N_BROAD     = frozen physical support sets（运行时唯一依据）
```

已确认运行时不读取 HeatSource 半径与坐标决定成员资格。

## 发现的真实问题

**方法论问题（非新bug，同已知HeatSource._drift问题同一类）**：
`langevin_noise.py`用`random.gauss()`消耗全局`random`状态，full/cut两次
独立驱动之间随机噪声轨迹不同，导致`Y_local`产生~0.6%虚假差异（不是
N_Δ切断的真实影响）。固定`random.seed()`后完全消除，这是对照实验的
正确控制变量。

**升级为方法论约束（评判204602 复核）**：评判判为"不是当前阻塞"，但该
0.6% 是**跨 run 噪声地板**，而项目所有切断/消融实验都是跨 run 对照——
任何小于此量级的效应都不可信。应登记为约束（改局部 RNG 或保存/恢复
随机状态），而非"以后最好"。

一条澄清，避免误伤已有结论：**P2-B1R 的 0.117% 不受影响**。
`test_r_prec_replay_aprime.py` 回放录制好的 trace 序列并直接设置
`collector.pre_trace`，learned/baseline 两组输入按构造完全相同，
Langevin 噪声不进入测量路径。
