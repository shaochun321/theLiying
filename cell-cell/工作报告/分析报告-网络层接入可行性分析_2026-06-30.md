## 一、网络层概述

`VestibularNetworkLayer` 实现了以下五项基础设施（V-N1～V-N5）：

| 编号 | 能力 | 实现 | 描述 |
|------|------|------|------|
| V-N1 | 地址系统 | `VestibularAddress(region, layer, tau_class, axis, index)` | 5维拓扑坐标，唯一标识每个神经元 |
| V-N2 | 距离函数 | `l_total(a, b)` | 空间距离 + 时间常数差 → 总导线长度 |
| V-N3 | FIFO 延迟 | `delay(src, dst)` + `FIFODelayBuffer` | 基于传导速度（1000 mm/ms）的离散延迟 |
| V-N4 | 增益系数 | `gain_coeff(src, dst)` = G_BASE × f(P_avail) × f(L_tau) | 能量门控 + 时间常数匹配 |
| V-N5 | 邻近查询 | `nearby(addr, radius)` | 拓扑距离内的近邻神经元 |

**核心价值**：将生物拓扑知识（传导速度、神经元层次、模态距离）嵌入结构，而非硬编码为 Python 逻辑。


## 二、候选接入区域

以下 5 个子系统被列为潜在接入候选，按可行性排序。

---

### 区域 A：SomatosensoryChain（脊髓体感链路）

**现状**：
- 4 个皮肤贴片（front/back/left/right）→ Nociceptor → Relay → soma_to_da
- 贴片间有侧抑制（lateral_gain=0.05，邻接对）
- 无 FIFO 延迟，无正式地址系统
- Bundle: soma_to_da（所有 relay → DA neurons），无拓扑感知

**生物依据**：
- 脊髓背角 → 延髓中继：导线长度 ≈ 30-50 cm，传导速度 ≈ 1 m/s (Aδ 纤维) → 延迟 ≈ 300-500 ms = 300-500 步
- 同侧 patch 比对侧 patch 更近（left/front 比 left/back 近）
- TRPV1 通道（热感受器）激活时间常数与 τ_class 概念吻合

**网络层接入方案**：

```python
# 建议的 SomatosensoryAddress（对齐 V-N1 规范）
SomatosensoryAddress(
    region = 0x03,       # 脊髓背角（区别于 0x02 前庭）
    layer  = 1,          # 1=noci, 2=relay, 3=projection
    tau_class = 1,       # 快（noci 响应 ms 级）
    axis   = patch_idx,  # 0=front, 1=back, 2=left, 3=right
    index  = 0           # 单路径（无 reg/irr 区分）
)
```

**延迟计算**：
```
L_front_to_relay = 5.0 mm（背角内传导）→ delay = ceil(5.0 / 1.0) = 5 步
L_left_to_relay  = 10.0 mm（跨侧更长）  → delay = 10 步
```

**可行性评估**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 生物合理性 | ★★★★★ | 脊髓传导速度精确已知 |
| 实现复杂度 | ★★★★☆ | SomatosensoryChain 结构清晰，可仿照 chain_v2.py |
| 信号改善预期 | ★★★★☆ | 延迟可避免 left-right 时间同步干扰，改善方向分辨率 |
| 对现有回归影响 | ★★★★★ | soma 路径独立，FIFO 只引入延迟不改变权重 |

**优先级**：**P1（推荐首先实施）**

---

### 区域 B：Motor Layer（运动层输出）

**现状**：
- 3 个运动神经元（move_x/y/z）
- 接收 col→motor 束（强，VOR 映射）+ cross-axis 束（弱）
- 无传出拷贝（efference copy）延迟
- Body.step() 即时使用 motor 激活，无缓冲

**生物依据**：
- 运动皮层 → 脊髓前角（CST）：传导延迟 10-30 ms = 10-30 步
- 传出拷贝（efference copy）通过脊髓小脑前束：延迟 ≈ 5 步
- 运动指令与感觉反馈的时序分离对预测误差（Xin）计算至关重要

**网络层接入方案**：

```python
MotorAddress(
    region = 0x04,       # 脊髓前角
    layer  = 6,          # Motor（继续前庭 L1-L5 序号）
    tau_class = 2,       # 较慢（运动整合时间尺度）
    axis   = motor_idx,  # 0=x, 1=y, 2=z
    index  = 0
)
```

**核心应用：efference copy FIFO**：
- Col→Motor 命令经 FIFO(delay=10步) 延迟到达身体
- 同时经 FIFO(delay=5步) 提前到达小脑类比模块（比较预测 vs 实际）
- 当前 Xin 计算基于零延迟 → 传导延迟可提升 Xin 时间分辨率

**可行性评估**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 生物合理性 | ★★★★★ | 传出拷贝是运动控制核心机制 |
| 实现复杂度 | ★★★☆☆ | 需要修改 Body.step() 接口接收延迟指令 |
| 信号改善预期 | ★★★☆☆ | Xin 精度提升，但当前行为可能变化 |
| 对现有回归影响 | ★★★☆☆ | 延迟指令可能影响 T7.1（动能）等测试 |

**优先级**：**P2（中期实施，需回归评估）**

---

### 区域 C：DA 电路（多巴胺调制层）

**现状**：
- 3 个 DA 神经元 + 1 个 Xin 中继
- 输入：shadow_to_da（奖励预测）+ xin_to_da（预测误差）+ soma_to_da（热感受器）
- 无拓扑感知，所有 DA 神经元视为等价
- DA 神经元没有局部抑制或竞争机制

**生物依据**：
- VTA（腹侧被盖区）DA 神经元有拓扑组织：背侧 vs 腹侧区域对应不同行为
- D1/D2 受体分布不均匀 → 空间 DA 浓度梯度
- DA 神经元间有侧抑制（通过 GABA 中间神经元）

**网络层接入潜力**：

```python
DAAddress(
    region = 0x05,   # VTA
    layer  = 7,      # DA projection
    tau_class = 3,   # 慢（DA 动力学在秒级）
    axis   = da_idx, # 0/1/2 = 三个 DA 神经元
    index  = 0
)
```

**核心应用**：
1. DA 神经元间侧抑制（通过 nearby + FIFO 实现竞争放电）
2. 空间 DA 浓度 → 不同 Col 层接收不等量调制
3. 能量门控（G_eff）控制 DA 释放速率（低能量 → 低 DA → 冷漠状态）

**可行性评估**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 生物合理性 | ★★★★☆ | VTA 拓扑有文献支持 |
| 实现复杂度 | ★★☆☆☆ | DA 电路是懒加载的，拓扑改造需重构初始化 |
| 信号改善预期 | ★★★☆☆ | 理论上改善方向性奖励，但短期效果不确定 |
| 对现有回归影响 | ★★★☆☆ | 可能影响 T1.1（Noether violations）|

**优先级**：**P3（长期，需专项设计）**

### 区域 D：Shadow Sandbox（影子层）

**现状**：
- 只读副本：Enc→Col→Mot（主链的静态复制）
- 接收 Xin 张力驱动（`bundles_xin_to_shadow`）
- 已有 21 个节点的熵账本可见性
- 与主链的传导延迟为 0（同步更新）

**网络层接入潜力**：

```python
ShadowAddress(
    region = 0x06,     # 影子层（小脑类比）
    layer  = shadow_l, # 1=enc_copy, 2=col_copy, 3=mot_copy
    tau_class = 2,     # 与主链 Enc/Col 对齐
    axis   = axis_idx,
    index  = 0
)
```

**核心应用**：
1. 影子层 vs 主层的传导延迟差异 → 模拟"预测超前"
2. `nearby()` 查询：主层 Col vs 影子 Col 的地址距离 → 评估预测误差的空间分辨率

**可行性评估**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 生物合理性 | ★★★☆☆ | 小脑建模比较粗糙 |
| 实现复杂度 | ★★★★★ | Shadow 已有清晰结构，地址映射简单 |
| 信号改善预期 | ★★☆☆☆ | 影子层读取的是内部一致性，非独立观察 |
| 对现有回归影响 | ★★★★★ | 只读，无副作用 |

**优先级**：**P4（低，观测价值有限）**

---

### 区域 E：ECM（细胞外基质，跨层热传导）

**现状**：
- 每层一个 ECM，独立跟踪局部热场 + 离子缓冲
- 无跨 ECM 拓扑（各层 ECM 不通信）
- 热传导通过 `_thermal_delay_ve` / `_thermal_delay_ec` 缓冲器实现（variant_adapter.py 层面）

**网络层接入潜力**：
- ECM 间热扩散延迟：基于组织热扩散系数 α=0.14 mm²/s（Elwassif 2006）
- L1（MET）→ L4（Enc）热传导：距离 ≈ 3 mm → 延迟 ≈ 65 ms ≈ 65 步

**可行性评估**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 生物合理性 | ★★★★★ | 热扩散系数精确已知 |
| 实现复杂度 | ★☆☆☆☆ | ECM 拓扑结构特殊（纯热场，非神经），需要不同的地址空间 |
| 信号改善预期 | ★★☆☆☆ | 改善热觉精度，但热觉不是当前优先 |
| 对现有回归影响 | ★★★☆☆ | 热延迟改变可能影响 ECM 热场稳定性 |

**优先级**：**P5（最后，需专项热物理设计）**

### 区域 A 详细实施方案（推荐首选）

**Q1. 生物对应物**：
```
BIO: 脊髓 Aδ/C 纤维 → 背角 relay → 脊髓-丘脑束（Spinothalamic tract）
     传导速度 Aδ=5-30 m/s (thin myelinated), C=0.5-2 m/s (unmyelinated)
     BIO REF: Julius & Bhaskaran (2001) Nat Rev Neurosci; TRPV1 动力学
```

**Q2. 物理结构**：
```
SomatosensoryNetworkLayer（新文件：nexus_v1/somatosensory/network_layer.py）
├── SomatosensoryAddress(region=0x03, layer, tau_class, axis, index)
│     patch→noci: layer=1, tau_class=1
│     noci→relay: layer=2, tau_class=1
│     relay→da:   layer=3, tau_class=2
├── FIFODelayBuffer (复用 nexus_v1/vestibular/fifo_buffer.py)
│     patch→noci: delay = ceil(2.0 / V_COND_C_FIBER)  ≈ 10 步 (C 纤维)
│     noci→relay: delay = ceil(5.0 / V_COND_ADELTA)   ≈ 3 步
│     relay→da:   delay = ceil(30.0 / V_COND_ADELTA)  ≈ 18 步
└── gain_coeff: G_BASE=1.0, α_soma=2.0（较低，体感权重小于前庭）
```

**Q3. 参数来源**：
- C 纤维速度：0.5 m/s（文献值）→ V_COND_C_FIBER = 0.5 mm/ms = 500 mm/ms × dt=0.001 → delay = L/0.5 步
- Aδ 纤维速度：5 m/s → V_COND_ADELTA = 5000 mm/ms → delay = L/5 步
- L_patch_to_noci = 2 mm（皮肤厚度），L_noci_to_relay = 5 mm（背角厚度）
- L_relay_to_da = 30 mm（脊髓→脑干，缩比）

**文件结构**：
```
nexus_v1/somatosensory/
├── chain.py      (现有，无需修改)
├── chain_v2.py   (新建：SomatosensoryChainV2，含 FIFO 延迟)
└── network_layer.py  (新建：SomatosensoryNetworkLayer)
```

## 四、通用接入原则（适用于所有区域）

从前庭 v2.0 接入的经验归纳：

1. **新文件，不修改母本**：按 `chain_v2.py` 模式，新建 `*_v2.py`；通过继承适配器接入
2. **地址 region 区分**：各模态使用不同 region 值（前庭 0x02，体感 0x03，运动 0x04，DA 0x05）
3. **复用 FIFODelayBuffer**：`nexus_v1/vestibular/fifo_buffer.py` 已实现，无需重复
4. **VESTIBULAR_MODE 模式**：每个新接入遵循 PARALLEL_LOG → ACTIVE_DRIVE 两阶段验证
5. **回归前置**：任何接入必须通过 21/21 回归才能合并
6. **延迟参数来源**：必须有 BIO/REF 注释（与前庭 V_COND=1000 mm/ms 同等标准）
7. **禁止 if/sign/dot product**：方向性和调制必须从 FIFO + gain_coeff 结构中涌现

## 五、潜在风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 区域 A FIFO 延迟过长（18 步）→ soma→DA 学习滞后 | DR1 收敛更慢 | 使用较小 L_relay_to_da（如 10 mm）降至 2 步 |
| 区域 B Motor FIFO → Body.step() 行为变化 | T7.1 动能测试失败 | 先 PARALLEL_LOG 模式：Motor FIFO 记录但不传递给 Body |
| 区域 C DA 拓扑重构 → Noether 违规 | T1.1 失败 | DA 神经元 census 方法保持不变，只添加地址标签 |
| FIFODelayBuffer 多实例内存 | 每个 FIFO × delay_steps 缓冲区 | 使用 numpy deque 或 collections.deque；预估区域 A 额外内存 < 5 KB |

## 六、结论

**推荐立即启动：区域 A（SomatosensoryChain 网络层接入）**

原因：
1. 解决当前 soma→DA 路径无传导延迟的物理缺陷
2. 生物依据充分（脊髓 Aδ/C 纤维传导速度精确已知）
3. 实现可完全复用现有 FIFODelayBuffer + VestibularNetworkLayer 基础设施
4. 对现有回归零风险（FIFO 只引入延迟，不改变权重或激活机制）
5. 为热觉方向学习（Phase 5 DR1/DR4）提供时序精度提升

**区域 B-E 按需实施**：在 Phase 5 方向性验证结论出来后，根据信号链路诊断决定下一个接入目标。
