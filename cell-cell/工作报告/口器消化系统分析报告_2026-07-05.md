**日期：** 2026-07-05

**审查范围：** thermal_mouth → digestive_interface → energy_store → FeedRateCapacitor → 饱腹神经回路

## 一、口器-消化系统完整链路

### 1.1 物理链路图

```
World（热场）
    │
    │ T_env = world.temperature_at(mouth_world_pos)
    ▼
ThermalMouth（口器热交换器）
    │ thermal_mouth.step(world, body, ecm_temp, dt)
    │ 热传导：dT_mouth/dt = (T_env - T_mouth)/τ_heat - (T_mouth - T_body)/τ_cool
    │ energy_intake = η × conductance × area × max(0, T_env - T_mouth) × dt
    ▼
DigestiveInterface（ATP合酶类比）
    │ digestive_interface.tick(thermal_mouth, energy_store, dt)
    │ deposit = g_digest × thermal_mouth.energy_intake
    │ actual_stored = energy_store.deposit(deposit)  → deposit_rate 返回值
    ▼
EnergyStore（Capacitor，C=1000）
    │ deposit(amount): min(amount×0.9, available_space, max_deposit=0.12/step)
    │ withdraw(requested): 供血管/神经元消耗
    │ tick(dt): RC 漏电（r_leak=5000，基础代谢率）
    ▼
FeedRateCapacitor（换能 Capacitor，C=1.0）
    │ variant_adapter.step() → inject(_I_feed=deposit_rate, dt) + leak(R=1.0, dt)
    │ V_feed = FeedRateCapacitor.voltage  [V]
    ▼
IntakeSensorNeuron（换能边界，HC-009模式）
    │ intake_sensor_neuron.step(self._v_feed, dt)  ← 膜电位跟踪 V_feed，τ=RC=1000步
    │ activation = gated_conduct(vm) = (vm-0.3)²   ← 当前存在的问题（见第三节）
    ▼
bundle_intake_to_satiety（frozen, sg=1.0, w=1.0）
    ▼
SatietyNeuron（C=50, R=1, τ=50k步）
```

### 1.2 并行能量吸收路径

系统有两条并行能量吸收路径，均写入同一 EnergyStore：

| 路径 | 机制 | 代码 | 量级 |
|------|------|------|------|
| **皮肤直接吸收** | `world.consume_nearby()` → direct deposit | `variant_adapter.py:~1340` | deposit_rate=energy_absorbed |
| **口器-消化路径** | ThermalMouth → DigestiveInterface → deposit | `variant_adapter.py:~1350` | g_digest=1.0 passthrough |

两路 deposit_rate 相加后注入 FeedRateCapacitor：
```python
_I_feed = energy_absorbed + _deposit_rate_digest  # variant_adapter.py ~1444-1452
self._feed_rate_cap.inject(_I_feed, dt)
```

## 二、各组件物理参数

### 2.1 ThermalMouth（`components/thermal_mouth.py`）

- **位置：** `local_offset=[2.0, 0.0, 0.0]`（前向2mm突出，朝向热源）
- **热传导：** Fourier 模型
  - `τ_heat = 13步`（快速升温，≈13ms）
  - `τ_cool = 50步`（较慢降温至体温，≈50ms）
- **能量摄入：** `energy_intake = η × conductance × area × max(0, T_env - T_mouth) × dt`
  - `η = 0.02`（换能效率）
- **稳态口腔温度：** 在 T_env=5.0, T_body=0.15 时：
  - `T_mouth_ss = (T_env/τ_heat + T_body/τ_cool) / (1/τ_heat + 1/τ_cool) ≈ 4.0°C`

### 2.2 DigestiveInterface（`components/digestive_interface.py`）

- **生物对应：** ATP合酶（线粒体内膜）——化学能 → 机械能/神经能
- **传递函数：** `deposit = g_digest × thermal_mouth.energy_intake`，`g_digest=1.0`（单位增益）
- **作用：** 域边界桥接（热能域 → 化学能域），同时返回 actual_stored 用于 FeedRateCapacitor

### 2.3 EnergyStore（`components/energy_store.py`）

- **基础：** `Capacitor(C=1000)`，初始填充50%（= 500单位能量）
- **沉积约束（三重限制）：**
  - `amount × 0.9`（沉积效率90%，线粒体损耗）
  - `available_space`（不超过容量上限）
  - `max_deposit_per_step = 0.12`（每步最大沉积速率）
- **漏电：** `r_leak=5000`（基础代谢，τ=5×10⁶步，极慢）
- **填充分数：** `fill_fraction = energy / max_energy = C.voltage / V_max`

### 2.4 FeedRateCapacitor（`variant_adapter.py`）

- **类型：** `Capacitor(C=1.0)`, `R_FEED=1.0`，τ=1000步=1秒
- **作用：** 将 deposit_rate（能量/步）积分为平滑电压信号 V_feed
- **稳态：** `V_ss = deposit_rate × R = deposit_rate × 1.0`

## 三、5k步诊断结果（已知问题）

测试配置：body 固定于 [69, 50, 25]（距热源 [70,50,25] 约1mm），运行5000步。

### 3.1 信号链状态（实测）

| 信号 | 步骤=200 | 步骤=5000 | 设计预期（5k） | 差异倍数 |
|------|----------|----------|--------------|---------|
| `_v_feed` | 0.0002V | 0.5249V | ~1.0V（V_ss） | 0.5×（尚未饱和）|
| `intake_sensor V` | 0.0036V | 0.4321V | 随 _v_feed | 正常跟踪 |
| `intake activation` | 0.0000 | **0.0175** | **1.0（预期）** | **57×偏小** |
| `dwell_sensor V` | +0.004V | **-0.636V** | >0.5V（充电） | 反向 |
| `fill_rate_sensor V` | 0.0009V | 0.0163V | 小（RPE信号弱）| 正常 |
| `satiety_neuron V` | 0.0000V | **0.0001V** | **~0.016V** | **160×偏小** |

### 3.2 根因分析

#### 问题1：MOSFET二次方压缩（主要原因）

`IntakeSensorNeuron` 配置为标准 Neuron（非spiking，single-channel）。其激活计算：

```
gated_conduct(vm) = m_gate × conduct(vm)
m_gate = min(1, conduct(vm)/gm) = (vm-vth)/gm    # update_gate()
conduct(vm) = gm × (vm-vth)                        # 线性模型

→ gated_conduct = (vm-vth)/gm × gm×(vm-vth) = (vm-vth)²
```

在 vm=0.4321V 时：
- `activation = (0.4321 - 0.3)² = 0.01745`
- 而预期的换能器输出应该是 `≈ 0.43`（线性传递）

**57倍差距**来自 MOSFET 的双重压缩：m_gate × conduct 两次乘以 (vm-0.3)。

#### 问题2：换能器晚于设计进入工作区

- 饱和电流仅 `I = 0.01745 × G = 0.01745 × 0.415 = 0.00724A`
- 饱腹神经元 V_ss = `I × R = 0.00724V`
- 5k步中 intake 超过阈值仅约2000步：`V(2k) = 0.0072 × (1-e⁻²ᵏ/⁵⁰ᵏ) ≈ 0.00027V`

实测 0.0001V，理论分析 ~0.0003V，量级吻合（差异来自 _v_feed 初期偏低）。

#### 问题3：DwellSensor 反向（次要，行为设计相关）

- 体正在运动时，phasic_left/right 激活（测热梯度变化）
- `sg=-200` → 放电电流 = phasic_act × 200 >> bc=0.02
- 静止后 phasic 会安静下来，dwell 恢复充电
- **结论：5k步测试中 body 仍处于运动/到达阶段，非设计缺陷**

**DwellSensor 设计正确。** 在200k实验中，body 到达热源后稳定停留，phasic 静止，dwell 会在 ~35k步后过阈值。

## 四、修复方案：换能旁路（Transducer Bypass）

**原则：** 参照 `ThermalInputNeuron` 的 HC-009 模式——换能器神经元不应通过 MOSFET 压缩物理信号，应直接将物理域信号映射为 activation。

### 4.1 ThermalInputNeuron 的正确模式

```python
# somatosensory/transducer_neurons.py
def step(self, T_raw, dt):
    self.activation = max(0, T_raw - T_THRESHOLD)  # 直接设置，绕过 MOSFET
```

### 4.2 本修复（最小改动，不创建新文件）

在 `variant_adapter.py` 的 `step()` 中，调用 `.step()` 之后立即覆盖 activation：

```python
# --- IntakeSensorNeuron 换能旁路 ---
self.intake_sensor_neuron.step(self._v_feed, dt)
self.intake_sensor_neuron.activation = max(0.0, self._v_feed)  # 线性换能，绕过MOSFET二次方

# --- FillRateSensorNeuron 换能旁路 ---
self.fill_rate_sensor_neuron.step(max(0.0, _rpe_da), dt)
self.fill_rate_sensor_neuron.activation = max(0.0, min(1.0, _rpe_da))  # 夹住到[0,1]
```

### 4.3 修复后的预期信号链（5k步）

| 信号 | 修复前 | 修复后（估算） |
|------|--------|--------------|
| `intake activation` | 0.0175 | **0.52**（= _v_feed 直接） |
| bundle current | 0.0072A | **0.22A** |
| `satiety V_ss` | 0.0072V | **0.22V** |
| `satiety V(5k)` | 0.0001V | **~0.009V** |
| `satiety V(50k)` | ~0.0052V | **~0.14V（激活）** |

### 4.4 DwellSensor 无需修复

在 200k 长实验中：
- 到达期：phasic 激活 → dwell 清零（正确）
- 驻留期：phasic 静止 → dwell 在 ~35k 步充到 V_thresh ≈ 0.5V
- dwell_to_satiety bundle: 届时贡献 0.3 × G × 1.0 ≈ 0.04A 额外电流

## 五、完整行为链路预测（修复后）

```
热源吸引 → body 接近 → phasic 触发方向学习（D1已验证）
    ↓
body 到达热源（d<5mm）
    ↓
ThermalMouth: energy_intake = η×cond×area×ΔT×dt ≈ 1e-3/步
    ↓
DigestiveInterface: deposit_rate = g_digest × energy_intake ≈ 1e-3/步
    ↓
EnergyStore: fill 从0.5升至0.55（50k步）
FeedRateCapacitor: V_feed → 1.0V（饱和，τ=1000步）
    ↓

    ↓

    ↓

```

## 七、结论

**口器-消化系统链路物理上完整**，从热感知到能量吸收再到 FeedRateCapacitor 的通路均正确工作。**单一且明确的问题是 IntakeSensorNeuron（和 FillRateSensorNeuron）未采用换能旁路模式**——标准 MOSFET 的双重激活压缩（activation = (vm-vth)²）使信号比设计预期小57倍，最终导致 SatietyNeuron 在5k步内仅积累 0.0001V，而非预期的 0.016V。

**修复方法明确：** 在调用 `.step()` 之后直接覆盖 `.activation`，将物理信号（V_feed、RPE）线性映射为换能器的激活输出。这与 ThermalInputNeuron 的已验证 HC-009 换能模式完全一致，修改量极小（两行代码），不需要新文件，回归影响最小。
