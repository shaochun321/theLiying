## 一、DEG-016 定义

**缺陷编号**：DEG-016  
**描述**：N=1 单传入，每轴仅 1 条 afferent_regular + 1 条 afferent_irregular  
**生物对比**：C57BL/6 小鼠前庭神经共约 500–1000 条传入纤维（Desai et al. 2005）  
**增益代偿**：synapse_gain=16 是生物目标值（0.48）的 33×，全部用于补偿 N=1

## 二、当前结构能力边界

### 2.1 能做的事

| 能力 | 详情 | 数据来源 |
|------|------|---------|
| 编码稳态角速度 | amp > 4.0 时 f_reg 线性响应，R² > 0.98 | P0 扫描 |
| 编码稳态线性加速度 | amp > 4.0 时响应，范围 0.5–5.4 m/s² | P0 扫描 |
| 自发放电 | f_reg_0 = 1.0 Hz（规则），f_irr_0 = 0.0 Hz | P0 基线 |
| 区分 regular vs irregular | 两路 Aff 独立编码 DC/AC 分量 | 设计 |
| 驱动 Enc 层 | WP f_reg=9–23.5 Hz → V_ss=1.8–4.7V >> V_th=0.30V ✓ | P0 + 公式 |
| 通过死区保护 Enc | amp < 4 时 Enc 不受 33× 噪声放大影响 | 架构分析 |

### 2.2 不能做的事

| 限制 | 原因 | 量化 |
|------|------|------|
| 低幅度信号检测 | 死区 amp < 4.0 → f_reg = 1.0 Hz（无法分辨） | P0: 4/6 轴死区延至 amp=4.0–4.5 |
| 群体编码 | N=1 无法平均化噪声 | SNR ≈ 1.0 vs 生物 √500 ≈ 22 |
| 自然刺激频率分辨率 | 单 Aff 时序精度有限 | ISI=1/f_reg（无序列分析） |
| 独立验证 spike timing | 无多条 Aff 对比 | 设计限制 |
| 2Hz 以上高频动态编码 | 测试协议限于 2Hz | 未测试，理论上可以更高 |

### 2.3 SNR 量化

```
生物 SNR：√N = √500 ≈ 22（群体平均降噪）
当前 SNR：√1 = 1.0
SNR 差距：22×（≈ 87× 功率差）

synapse_gain 补偿 33× 增益（代偿信号强度但不改善 SNR）
实际噪声放大：33× 放大因子 × Langevin 噪声 → 死区必要
```

| 节点预算 | 可行 N | synapse_gain 目标 | SNR |

**当前决策**：≤50 节点，N=1 是唯一解，此为合理工程权衡（非错误）。

## 四、死区作为架构保护（P0 验证）

**Phase 1 假说**：死区 amp<3.5 是"响应不足"缺陷  
**P0 验证结论**：死区是 N=1 高增益架构的**必要保护机制**

```
无死区情况（若 amp < 4 时 Aff 仍响应）：
  Langevin 噪声（热噪声）→ Aff 随机发放 → 33× synapse_gain 放大 → Enc 虚放电
  → Column/Motor 随机激活 → 行为失控

有死区的情况（当前）：
  Langevin 噪声 → HC 未跨越激活阈值 → Aff 保持自发率 1 Hz → Enc 不响应
  → 行为稳定
```

**P0 实测死区**：各轴 amp=3.5–4.5 之间开始响应，与 HC 激活阈值一致。
