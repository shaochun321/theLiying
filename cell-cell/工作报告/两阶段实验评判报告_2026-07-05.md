## 逐条核查

### Q1：第一阶段——无热源时，fill 是否能因 BMR 下降？

**代码验证（energy_store.py）：**

```
YolkSac 供给：+0.001/step（来自 variant_adapter.py 的 YolkSac 组件）
RC 漏电：-0.0001/step（r_leak=5000 时 Q=500 的衰减率）
BMR：-0.002/step（P0-3 修复，energy_store.py tick()）
净变化：-0.0011/step
```

**计算验证：**
- 从 initial_fill=0.5（Q=500）开始，每步净消耗 0.0011
- 10k步后：Q = 500 - 11 = 489，fill = 0.489（可观测下降）
- 100k步后：Q = 500 - 110 = 390，fill = 0.390（hunger 开始显著激活，hunger = max(0, 0.5-fill) = 0.11）

**结论：✅ 正确。** 无热源时 fill 净下降 -0.0011/step，BMR 修复有效。

**但注意：** 如果 initial_fill=0.5，hunger 从 fill=0.5 时激活（hunger=0）→ hunger 信号较弱。建议第一阶段设 initial_fill=0.2（从饥饿状态起步），10k步内可直接观察到清晰的 hunger→DA 激活链路。

### Q2：第一阶段——冷区时 phasic 是否确实为零？

**T-033 实测结果：**
- pL = pR ≈ -0.000 全程
- 在 body 随机游走、无持续热信号时，relay ≈ slow_relay ≈ 0，phasic = 0

**物理解释：**
phasic = relay.activation - slow_relay.activation（差分热感知）
- 无热场：relay 无输入 → activation ≈ 0
- slow_relay 也随之归零（τ=15000，但信号本身就是0）
- phasic ≈ 0 → pre_trace → 0 → yaw STDP 无 LTP

**结论：✅ 正确。** 冷区 phasic 确实为零，P0-1 验证逻辑成立。

**附加意义：** 这同时验证了"phasic≈0意味着无方向学习"。第一阶段中 yaw 权重应该在缓慢衰减（纯 LTD）——这是正确的冷区基线。

---

### Q3：第二阶段——body 首次从冷区进入热场时，phasic 是否产生正值信号？

**物理推导：**

设 body 在冷区已运行足够久，relay.activation ≈ 0，slow_relay.activation ≈ 0。

当 body 首次进入热场（dist < 30）时：
- relay：快速响应热信号（τ_relay 较小，约 100-1000 步），迅速升至 relay_max
- slow_relay：τ=15000 步，建立极慢
- phasic = relay（快速上升）- slow_relay（仍≈0） = **大正值**

这个正值 phasic 驱动 spinal→yaw：
- 若右侧温度 > 左侧：relay_right > relay_left → phasic_right > phasic_left → CCW yaw 增强
- 这是真正的方向性差分信号

**结论：✅ 正确。** 从冷区起步的"首次接触热场"是产生有效 phasic 信号的唯一物理条件。T-033 因 body 从热场内起步（dist=20）而错过了这个关键时刻。

### Q4：第二阶段——DA 进食奖励脉冲是否会在首次接触时出现瞬时峰值？

**代码链路：**
```
body 进入热场 → HeatSource.consume_nearby() → EnergyStore.deposit()
                → DigestiveInterface 摄食 → intake_sensor_neuron.step(v_feed, dt)
                → bundle_intake_to_da_reward.propagate() → da_neurons
                → dopamine.concentration 上升
```

**T-033 实测：** DA@热源均值=0.6112，iDR（intake_sensor）在热场内稳定有值（0.05-0.06）。

**瞬时峰值的可能性：**
- 首次进入时，satiety 处于低值（第一阶段结束时 fill 低 → satiety 低）
- satiety→DA 的抑制电流 = satiety × sg(-1.0) × w(0.3) ≈ 0（satiety 低时）
- intake→DA 激励电流 = iDR × sg(+1.0) × w(1.0) ≈ 0.06A（无抑制）
- DA 应迅速升至较高值（可能接近 1.0）

**结论：✅ 正确。** 从低 satiety 状态首次接触热场时，DA 奖励脉冲会更清晰、更强（无饱腹抑制）。这是 yaw STDP 的最佳学习窗口。

### Q5：方案的 Δw > 0.01 门槛是否合理？

**T-033 数据：** 50k步内 Δw 从 -0.0008 → -0.0000（无分化）。

**分析：** 由于 phasic≈0，连 LTP 都无法发生，故 Δw 完全依赖随机游走的微小不对称。0.01 是一个合理的目标（约为初始权重 0.037 的 27%）。

**但实现 Δw > 0.01 的前提：**
1. phasic 正值（从冷区进入热场时产生）✅
2. DA > 0（进食奖励）✅
3. 足够的步数（接触热场后 STDP 需要时间积累）

**结论：✅ 合理。** 但需要在第二阶段跑足够长（至少 20k-50k 步的热场接触期）。
