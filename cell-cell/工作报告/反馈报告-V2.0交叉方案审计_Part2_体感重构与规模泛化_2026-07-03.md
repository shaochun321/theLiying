## 一、体感重构备忘录（11:52）审计

### 1.1 总体评判

**方向完全正确。体感重构是项目迄今最重要的架构升级，因为它同时解决三个积累已久的缺陷：**
- HC-009（直接注入）——信号路径绕过 Bundle，STDP 无法学习热觉-运动映射
- HC-014（thermal_stability Python soft-sigmoid）——环流耦合输入端被污染，阻断环流的结构化
- 贴片点采样——无面积、无热容、无 Noether 审计可见性

备忘录识别了这三个问题并给出了正确的解决路径。以下是具体评估。

### 1.2 信号路径污染图：正确且完整

备忘录第 2.2 节的污染图准确描述了现状：

```
环境温度 T → [直接注入 HC-009] → thermoreceptors
                                           ↓
                       relay → proj → DA（P2 已修复）
                                           ↓
                   [Python soft-sigmoid HC-014] → CPC
```

关键洞察："HC-007/002 修复了下游，但上游换能层仍然是直接注入"——这个分析是准确的。当前系统的热趋性是真实的（Phase 5 已确认），但它的**驱动路径**（注入 → relay → DA → STDP）在换能第一跳处是非结构性的，Xin 看不到换能层的权重变化。

### 1.4 换能束可塑性：错误已被识别和修正

备忘录（11:52）原始设计：`transducer_env_to_thermo_{pid}` plasticity=True。

综合反馈（13:36）对此提出了三层论证，均成立：

**第一层（量纲）**：SkinPatch 是温度标量，不产生 pre_trace。SynapticBundle 的 STDP 公式 `Δw = η × pre_trace × post_trace` 中，pre_trace 来自 source Neuron 的脉冲历史。温度值不能生成脉冲历史，因此 STDP 在换能层没有物理基础。

**第二层（系统演化）**："黑暗房间悖论"成立。如果换能束权重可塑，Xin（预测误差）最小化动力学会驱使权重趋向零——系统学会"不感知环境"以消除预测误差。这是错误结构设计导致的病态吸引子，不是偶然风险，而是确定性后果。

**第三层（生物学）**：TRPV1/TRPM8 的换能系数是物种进化固定的物理常数，不是个体突触可塑性的对象。学习在脊髓背角突触（thermoreceptor→relay）处开始，不在换能器处。

**修正结论**：所有换能束均 plasticity=False。这是修正附录（13:42）的最终裁决。

### 2.3 根本性结构缺口：SkinPatch 不是 Neuron

这是七份文档中均未被正面解决的核心工程问题。

**问题**：`transducer_env_to_thermo_{pid}` 设计为：
```python
BundleConfig(
    source_ids=[f"skin_patch_{pid}"],    # skin_patch 不是 Neuron
    target_ids=[f"thermoreceptor_{pid}"],
)
```

SynapticBundle 的 `propagate()` 方法：
```python
for src in self.sources:
    if not src.is_alive():          # ← SkinPatch 没有这个方法
        continue
    if src.config.spiking and ...:  # ← SkinPatch 没有 config.spiking
        a_src = src.calcium_rate
    elif src.config.spiking:
        a_src = src.pre_trace
    else:
        a_src = src.activation      # ← SkinPatch 没有 .activation
```

直接把 SkinPatch 作为 source 会在 `propagate()` 第一行崩溃。

**解决方案（二选一，需要明确决策）：**

**方案 A：SkinPatch 实现 Neuron duck-typing 接口**

让 SkinPatch 添加以下属性：
```python
class SkinPatch:
    @property
    def activation(self):
        return self.temperature / T_ref  # 温度归一化为激活值
    
    def is_alive(self):
        return True
    
    # config 使用简单的 mock 对象
    class _MockConfig:
        spiking = False
    config = _MockConfig()
```

优点：改动小，不需要新类。  
缺点：污染了 SkinPatch 的语义（物理热力学对象被迫模拟神经元接口）；不被 Noether 探针识别为神经元；`get_all_neurons()` census 中不可见。

**方案 B：引入 ThermalInputNeuron（推荐）**

创建一个非脉冲的 `ThermalInputNeuron`，由 SkinPatch 温度驱动：
```python
class ThermalInputNeuron(Neuron):
    """TYPE:BIO — 皮肤热换能层输入神经元（TRPV1/TRPM8 换能层映射）
    
    BIO: 热感受器（thermoreceptor）的换能层。
         temperature → activation 是 TRPV1/TRPM8 离子通道的物理转换。
         v_threshold 对应 TRPV1 激活阈值 ~43°C。
    REF: Desai et al. 2005 — thermoreceptor physiology
    """
    def __init__(self, patch: SkinPatch, config: NeuronConfig):
        super().__init__(config)
        self._patch = patch
    
    def step(self, dt):
        # 温度→激活（线性归一化，超阈响应）
        T = self._patch.temperature
        self._activation = max(0.0, (T - T_threshold) * GAIN_TRPV1)
        super().step(dt)
```

优点：干净的职责分离（SkinPatch 负责热力学，ThermalInputNeuron 负责换能）；被 census、Noether、ν 探针正确识别；符合项目"每个信号路径经过 SynapticBundle"原则。  
缺点：需要新增一个类（但符合"不修改母本"原则）。

**推荐方案 B**：实施工作量多约 2-3 小时，但架构一致性大幅提升，且消除了长期技术债。

### 2.4 P1-3：τ=5s 修正的实施风险

把 SkinPatch 时间常数从 5ms（5步）延长至 5s（5000步），这会：

1. **影响 ν 探针读数基线**：当前 ν_ema 基于现有 τ 建立。τ 改变后，thermo_to_relay 等 bundle 的 ν 会暂时剧烈波动（约需 5000步=5s 稳定）。  
   → **缓解措施**：修改 τ 后跑 50k 步预热，观察 ν 是否在 50k 内稳定，再进行正式实验。

2. **热趋性短程实验可能需要重新校准**：以往实验（Phase 3–5）基于 τ=5ms 的快速贴片响应设计信号幅度。τ=5s 后，patch_grad 在快速运动时严重滞后，DR5 的 patch_grad·v 可能下降。  
   → **这是预期的物理结果**，不需要阻止，但需要在下一个实验前说明这个基线变化。

3. **Noci（dT/dt）成为高速响应的主通道**：τ=5s 使 thermo 对绝对温度的响应极慢，dT/dt 通道在热前锋处反而抢先激活。这是正确的生物学行为（Noci 负责快速避害），但如果 Noci 的 synapse_gain 未同步调整，快速运动时 Noci 可能主导并压制 thermo 信号。  
   → **建议**：P1-3 完成后立即跑 noci 响应短程测试（P2-8），确认分工行为正确。

### 2.5 P1-4：Langevin 噪声幅度需要计算

方案给出了正确的离散化形式 `sigma * sqrt(dt)`，但 sigma 的计算：
```
sigma² = 2 × G_env × k_B × T_env² / (C_patch²)
```
（来自涨落-耗散定理，G_env = κ×A_patch/d_skin，C_patch = ρ·c·V_patch）

代入参数估算：
```
A_patch ≈ 10 mm² = 10×10⁻⁶ m²
d_skin = 0.5 mm = 5×10⁻⁴ m
κ = 0.3 W/m·K
G_env = 0.3 × 10×10⁻⁶ / 5×10⁻⁴ = 6×10⁻³ W/K

V_patch = 10 × 0.5 mm³ = 5 mm³ = 5×10⁻⁹ m³
C_patch = 1000 kg/m³ × 3500 J/(kg·K) × 5×10⁻⁹ m³ = 1.75×10⁻² J/K

k_B = 1.38×10⁻²³ J/K
T_env ≈ 300K

sigma² = 2 × 6×10⁻³ × 1.38×10⁻²³ × 300² / (1.75×10⁻²)²
        ≈ 3.4×10⁻²⁶ K²·s⁻¹

sigma ≈ 5.8×10⁻¹³ K/sqrt(s) — 极微小
```

热噪声幅度约 10⁻¹² 量级——比贴片温度（~0.1-5°C 范围）小约 12 个数量级。在单贴片尺度，Langevin 噪声几乎不影响行为，但在架构上仍必须实现（Noether 审计合法性要求）。实现时注意不要用 `float64` 数值精度损失把它抹零。

## 三、综合反馈-体感重构（13:36）补充评估

### 3.1 三条外部物理洞察的评判

**洞察 A：热噪声→N=3 的物理绑定**

> 贴片面积缩小（4→12，面积约 1/3）→ 热容减小 → ⟨ΔT²⟩ = k_BT²/C 增大 → 热噪声放大 √3 倍 → 需要 N=3 群体编码降噪（SNR∝√N）

这个推论在数学上成立。但注意：√3 倍热噪声放大对应 10⁻¹² 量级的绝对涨落，在仿真中的实际影响接近零（仿真本身没有热力学精度限制）。

**更准确的表述**：这个物理绑定在**生物学意义层面**是真实的约束（N=3 群体编码确实是对抗贴片热噪声的演化答案），但在当前数值仿真中，贴片面积缩小 1/3 带来的 Langevin 噪声放大（10⁻¹² 量级）不会对仿真行为产生可观测影响。该论证的价值在于**为 Phase B（N=1→3）提供了额外的物理动机**，而非驱动紧急的实施压力。

**洞察 B：全连接 O(N²) → 稀疏编码的涌现必然**

建构定律 η(N)=C(N)/P(N) 中，若 P_S∝N²（全连接），η 必然持续下降。系统为生存会被迫稀疏化。这个论证成立，但它依赖"系统有自发修剪机制"——当前项目的 STDP+Xin 驱动的结构生长（sprout/prune）确实提供了这个机制。需要确认在 N 扩展后 prune 机制仍然有效。

**洞察 C：阈值多样性（0.8×/1.0×/1.2×）构建量程分段 ADC**

正确，详见 Part 2 第四节规模泛化部分。

## 四、规模泛化备忘录（11:53）审计

### 4.1 总体评判

**框架正确，有一个逻辑缺陷（停靠判定）需要修正后才能进入实施。**

### 4.2 香农容量分析：成立

```
C = B × log₂(1 + SNR)
SNR = √N（群体编码噪声抑制）
```

在前庭 N=1→3→10→100 扩展路径上：

| N | SNR | 信道容量提升 | 增益代偿（需要的 synapse_gain 倍数）|
|---|-----|-----------|-----------------------------------|
| 1 | 1 | 基准 | 33×（当前工程值）|
| 3 | 1.73 | +45% | 11× |
| 10 | 3.16 | +106% | 3.3× |
| 100 | 10 | +246% | ~1×（生物目标）|

增益代偿公式 `synapse_gain_N = gain_1 × (1/N) × (1/√N) = gain_1 / N^(3/2)` 来自两个效应的叠加：
1. 每根纤维输入到下游神经元的比例降低（1/N 因子）
2. SNR 提升后阈值死区收窄（1/√N 因子）

这个推导逻辑清晰，可以直接用于 Phase B 的 synapse_gain 设计。

### 4.3 建构定律停靠判定：逻辑缺陷（必须修正）

备忘录第 4.2 节给出停靠判定：
```
if η(N_new) > η(N_current):
    PASS（扩展提升效率）
else:
    FAIL（停在当前N）
```

但第 4.3 节的 η(N) 表格显示：

| N | η(N) |
|---|------|
| 1 | 1.00 |
| 3 | 0.72 |
| 10 | 0.62 |
| 100 | 0.21 |

**η(N) 在任何合理的 P(N) 增长模型下单调递减。** 如果停靠判定是"η 必须上升才能扩展"，则系统永远无法从 N=1 向外扩展一步——判定条件与扩展目标自相矛盾。

**根本原因**：信道容量 C(N)∝log₂(1+√N) 是**对数增长**，而任何物理可行的 P(N) 至少**线性增长**（P_T∝N），所以 η=C/P 必然随 N 增长而下降。试图让 η 上升是在对抗信息论基本定律。

**修正方案（三选一）：**

**修正 A**：改为边际效率判据
```python
# 判断增加一个神经元的边际收益是否仍然值得
ΔC = C(N+1) - C(N)
ΔP = P(N+1) - P(N)
marginal_efficiency = ΔC / ΔP
if marginal_efficiency > threshold:
    PASS（扩展仍划算）
else:
    STOP（边际收益已不足，停靠）
```

**修正 B**：改为 η 下降速率判据
```python
# 效率下降过快时停靠
d_eta = (η(N) - η(N-1)) / η(N-1)  # 相对下降率
if abs(d_eta) < tolerance:  # 下降趋于平缓
    CONTINUE  # 继续扩展
else:
    STOP       # 下降速率超过容忍阈值
```

**修正 C**：引入绝对门槛而非比较判据
```python
if η(N_new) > η_min:  # 绝对效率下限
    PASS
else:
    STOP
```

推荐**修正 A（边际效率）**：它与建构定律"最大化流动效率"的原始精神最一致，也是经济学边际收益分析的标准方法。实现时需要确定 `threshold` 的数值（可在 Phase B 运行后从实测 ΔC/ΔP 值反推）。

### 4.4 触发条件矩阵评估

备忘录第 4.1 节列出了六个触发条件。评估各项当前状态：

### 4.5 Phase B 具体设计评估

前庭 N=1→3，每轴 Aff 从 2 条扩展到 6 条（reg×3 + irr×3），阈值多样性：

```
index=0: v_th = 0.8×base（低阈，敏感，打破死区）
index=1: v_th = 1.0×base（中阈，正常范围）
index=2: v_th = 1.2×base（高阈，防饱和）
```

这个设计是正确的"闪存模数转换器"架构。需要注意：

1. **三个 index 的 STDP 学习应当同步更新**：如果某个阈值段的 Aff 从不激活（低信号时 index=2 不响应），它的权重不会更新，可能永久静默。需要确认是否引入最小激活基线（bias current）。

2. **现有 hebbian.py 的 aff_reg/irr 实例化逻辑**：目前每轴只有 `aff_reg_{axis}_0` 和 `aff_irr_{axis}_0`（index=0）。Phase B 需要扩展到 index=0/1/2，这意味着 `HebbianCircuit.__init__` 中的 afferent 实例化循环必须修改。按"不修改母本"原则，这应该通过 `VariantCircuit` 的 `override` 机制实现，而非直接修改 `hebbian.py`。

3. **收敛比调整**：从 N=1 扩展到 N=3 时，每个 Enc 神经元同时接受 3 个 reg Aff 的输入，需要 `enc_bundle.synapse_gain` 相应缩小至约 1/3，否则 Enc 过饱和。
