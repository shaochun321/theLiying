# T3-C1R：分级电位线性中继与读出机制判别（R-A vs R-B）

## 一、任务背景

第十份交叉比对批判（`交叉比对/document - 2026-07-16T233942.569.md`）审查了 W2A 修复与
T3-C0 审计结果，指出：T3-C0 已证明共享 DN 分流池输出比例 `y_a/y_b` 精确线性，但下游
读取 channel Neuron 的公开 `.activation` 会破坏这个比例——未饱和区被 `activation=gm×V²`
的二次门控压缩成 `(y_a/y_b)²`，较大输入幅度下还会被 `.activation` 的 ±10.0 硬钳位
（`neuron.py:438`）彻底抹平比例信息。**参数重标（调 `gm`/`R_leak`/`C`）只能挪动饱和触发点，
不能改变"平方"这个函数阶数**——这是传递函数类型不匹配，不是拍脑袋调参能解决的问题。

批判据此提议新增 `GradedPotentialRelay`（分级电位线性中继）修复读出层，并给出 R-A（现有
二次 channel、降低增益）vs R-B（`GradedPotentialRelay`）的判别测试设计。我方核实批判①②③
点属实，④点新组件建议满足方案第十二节 12.1 机制缺口准入七问，用户已确认启动 T3-C1R。

本报告记录 `GradedPotentialRelay` 的实现与 R-A/R-B 判别测试的完整结果。

## 二、`GradedPotentialRelay` 实现

新文件 `nexus_v1/components/graded_potential_relay.py`（不改母本，独立新组件）。

**Q1 生物对应物**：非脉冲、分级电位传输的局部神经元/感受器（视网膜光感受器、水平细胞、
双极细胞——不通过全或无尖峰编码，在有限工作区间内以连续膜电位表达输入强度，REF: 经典
视网膜分级电位生理学）。这是项目已有 `Neuron` 类（二次门控/尖峰编码）之外的另一类真实、
常见的神经元行为模式。

**Q2 物理结构**：`DN 输出电流(y_i) → 中继膜电容状态(Capacitor, 复用) → 线性电导读出(a_i)
→ Bundle`。动力学（标准 RC 充电，复用 `Capacitor` 原语，不重新实现 RC 逻辑）：
```
τ_r · dV_i/dt = -V_i + k_i·y_i     （由 Capacitor.inject()+leak() 实现）
a_i = clip(g_r·V_i, 0, a_max)       （线性读出 + 软上限，非二次）
```
不修改现有通用 `Neuron.activation` 语义——本组件是独立新类，不影响项目里任何已使用
`Neuron`/`activation` 的其他系统。

**Q3 参数依据**：根据 T3-C0 已实测的 `y_i` 典型范围反推（覆盖 0.03~2.6 的实测区间，
含 T3-C0 共同尺度扫描最大场景）。取 `capacitance=1.0`（沿用 `Capacitor` 类默认约定）、
`r_leak=2.0`、`g_r=1.0`（使 `g_r·r_leak·y_max/a_max ≈ 0.52`，接近批判建议的安全边际
`β≤0.5`）、`a_max=10.0`（沿用 `Neuron.activation` 现有硬钳位惯例的同一量级，保证下游
Bundle 读到的数值范围与系统其余部分一致）。**首轮 EXP 起点，非最终标定**，同 T1 report
记录的多轮校准史，预期 T3-C1 阶段可能需要根据真实 ξ 输入范围重新标定。

**标定过程中发现的 dt 陷阱**（已记入代码 docstring）：本组件参数最初按 `dt=1.0` 直觉推导
`tau_r` 应在数百步内收敛到稳态，但 T3-B/T3-C0 测试全部用 `dt=0.001`（同 T1/T0 既有约定），
200~300 步只推进 0.2~0.3 个时间单位，远不足以让 `tau_r=2.0` 的中继在测试窗口内真正达到
稳态。**但这不影响比例保真度**——`GradedPotentialRelay` 是线性时不变系统（LTI），
`V_i(t)∝y_i` 在任意时刻 t 都成立，不只是稳态才成立（下节 R-B 实测的 eps_ratio 精确为 0
证实了这一点）。当前实测输出量级偏保守（远低于 `a_max`，未充分利用动态范围），若后续需要
更大输出量级供下游 Bundle 消费，可在 T3-C1 阶段按需重新标定，不影响本轮比例保真的核心
验收目标。

## 三、R-A/R-B 判别测试

### 3.1 测试设计

对照真实 `RPartCircuitT3` 电路（沿用 T3-B/T3-C0 同一冻结点对 28/31）驱动出的共享 DN 池
输出 `y_a(t)`/`y_b(t)`（比例保真的真值层），同步喂给两条候选读出通路：

- **R-A（对照组）**：现有二次 channel 配置，降低增益 `gm: 20.0 → 2.0`（原值的 1/10），
  只为验证"降增益能否避免钳位、但改不了平方关系"这个批判提出的假设。
- **R-B（候选方案）**：`GradedPotentialRelay`（默认参数）。

验收指标用 log-ratio（批判建议，对 1:3 与 3:1 更对称）：
```
eps_ratio = |log((o_a/o_b) / (y_a/y_b))|
```
扫描输入比 1:1/2:1/3:1/4:1 × 共同放大系数 α∈{0.25,0.5,1,2,4,8}，共 24 组场景，每组驱动
300 步（`dt=0.001`）。测试运行固定 `PYTHONHASHSEED=0`（本轮折中方案，保证判别实验本身
可复现；Bundle 级 hash 扰动的全项目级修复 `stable_hash()` 列为独立议题，不在本轮，见
下节 4.3）。

### 3.2 实测结果

| 场景 | y_a/y_b（真值） | R-A o比 | R-A eps_ratio | R-B o比 | R-B eps_ratio |
|---|---|---|---|---|---|
| 1:1, α=1 | 1.0525 | 1.1062 | 0.0497 | 1.0525 | 0.0000 |
| 2:1, α=0.25 | 2.1050 | 4.3979 | 0.7368 | 2.1050 | 0.0000 |
| 2:1, α=2 | 2.1050 | 2.2824 | 0.0809 | 2.1050 | 0.0000 |
| 3:1, α=0.25 | 3.1575 | 9.8251 | 1.1352 | 3.1575 | 0.0000 |
| 4:1, α=0.25 | 4.2100 | 17.3426 | 1.4157 | 4.2100 | 0.0000 |
| 4:1, α=8 | 4.2100 | 1.7354 | 0.8862 | 4.2100 | 0.0000 |

（完整 24 组数据见 `nexus_v1/tests/_diag_t3_c1r_readout_ab.py` 运行输出。）

**R-B**：全部 24 组场景 `eps_ratio` 精确为 `0.0000`——比例保真在浮点精度范围内完全成立，
不随输入比例或共同放大系数变化。这是 LTI 系统的固有性质：线性 RC 中继对任意输入都满足
`V_a(t)/V_b(t) = y_a/y_b`（只要初始条件相同，本例均为 0），不依赖是否到达稳态。

**R-A**：`eps_ratio` 最大达 `1.4157`（4:1, α=0.25 场景），且**呈非单调分布**——不是随 α
增大而单调靠近理论平方值，而是在中等 α 区间（如 2:1 的 α=2，eps=0.0809）短暂接近真值，
在小 α（未充分驱动）和大 α（部分饱和干扰）区间都明显偏离。这比批判理论预测的"纯平方关系"
更复杂，因为降低 `gm` 后系统同时受"二次门控压缩"和"未完全脱离小信号区/开始触及饱和"两种
效应叠加影响，进一步确认了批判②点结论——**调参只能移动效应的分布区间，不能消除传递函数
类型不匹配本身**。

### 3.3 正式验收测试

将诊断结果转为正式回归测试 `nexus_v1/tests/test_t3_c1r_readout_ab.py`（T-C1R-1~4）：

- **T-C1R-1**：R-B 在全部 24 组场景下 `eps_ratio < 1e-9`（浮点精度容差，非物理容差）；
- **T-C1R-2**：R-B 输出非负且不超过 `a_max`（大幅值场景 `y=2.61` 验证）；
- **T-C1R-3**：静默（`y_a=y_b=0`）时 R-B 输出精确为 0，不产生虚假比例；
- **T-C1R-4**：R-A 对照组在扫描网格中最大 `eps_ratio` 超过判定阈值 0.05，确认降增益不能
  修复二次门控问题（disqualify 断言，确认对照组失败是预期行为）。

四项全部 PASS（`PYTHONHASHSEED=0` 下运行）。

## 四、结论与后续影响

1. **T3-C1R 判别结论明确**：`GradedPotentialRelay` 满足"比例保真读出"的设计目标，
   `channel Neuron.activation`（无论是否降低增益）不满足，二者不是同一类可互相替代的方案。
2. **r_part/r_ρ 资格分层表得到最终实测支持**（批判十§三）：DN 输出层 `y_i` 是唯一的
   射影比例候选层，`GradedPotentialRelay` 首次让这个候选层的信号能被下游 Bundle
   实际读取而不失真——这是把 `y_i` 变成"可用输出"而非仅仅是"内部真值"的关键一步。
3. **本轮不升格 r_part → r_ρ**：T3-C1R 只解决了"读出机制该用哪个"这一个问题，
   尚未完成 T3-C1 定义的完整二级验收（共同尺度不变性正式验收/池启动衰减/动态输入比
   变化/下游 Bundle 实际接入/三元扩展），升格判断留待 T3-C1 及以后。
4. **hash 扰动的全项目级修复（`stable_hash()`）仍列为独立议题**，不在本轮——本轮判别
   实验固定 `PYTHONHASHSEED=0` 只保证实验本身可复现，不代表已解决 Bundle 级 hash
   扰动的项目级可复现性问题。
