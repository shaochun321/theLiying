## 关键发现

### 1. D1 消融后 DR5% 精确等于随机基线（50.0%）

这是最强有力的反诈胡证据：

- 有 D1 的情况（T-038）：DR5% = 60%（峰值 75%）
- 无 D1 的情况（T-039）：DR5% = **50.0%（精确随机）**

方向性完全由 D1 STDP bundle 驱动。删除 D1，热趋性消失到随机基线。

### 2. HC-016A 无法单独维持方向性

HC-016A（`thermo_left→yaw_ccw`, `thermo_right→yaw_cw`）是另一条热→yaw 路径，为 frozen 结构性反射。但 T-039 证明单独 HC-016A 不足以产生 DR5% > 50%。两者关系：
- HC-016A：即时反射，提供瞬时方向扰动
- D1 STDP：学习记忆，积累方向偏好

D1 + HC-016A 协同 = 热趋性（60-75% DR5%）；HC-016A 单独 = 随机游走（50% DR5%）

### 3. phasic 信号仍在产生（pPeak=0.262 全程稳定）

消融不影响 phasic 生成：relay - slow_relay 差分仍在计算，只是 D1 的 learn() 被冻结（不更新权重）。说明 cold→hot 过渡确实发生，物理信号链路完整。

### 4. T4.1 继续稳定上升（3.46x → 4.00x）

与 T-038 趋势一致，VOR axis 冻结修复有效。

**诈胡验证核心实验完全通过。** 方向性学习（Δw ≠ 0）唯一来自 D1 STDP bundle（`phasic→spinal` 弧）。删除 D1 后，DR5% 精确回落至 50%（随机基线），证明：

4. 整个方向性学习机制是物理涌现，符合生物 D1 dopaminergic 方向学习机制
