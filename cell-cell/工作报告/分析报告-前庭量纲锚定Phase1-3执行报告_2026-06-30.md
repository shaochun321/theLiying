## Phase 1：标定扫描结果

### 实验协议

```
信号：纯正弦，频率 2 Hz（Lasker et al. 2008 对齐）
幅度：0.5–10.0（步长 0.5，共 20 点）
步数：5000 步/点（前 3000 预热，后 2000 测量）
每点独立 VestibularChainV2（避免 STDP 历史污染）
测量：afferent_regular._spiked_this_step 计数 / window_s
```

### 关键发现 1：死区确认

**所有轴在 amplitude < 3.5 时 f_reg = 1.0 Hz（= 自发率）。**

死区机制：低幅度输入无法推动 MET → HC 链路跨越 HC 发放阈值，Aff 仅保持自发放电（1.0 Hz），无法区分信号与噪声。

| 幅度范围 | f_reg 行为 | 实验含义 |
|----------|-----------|---------|
| 0–3.0 | = 1.0 Hz（死区） | 系统对该幅度信号无响应 |
| 3.5–4.5 | 开始离开基线 | 过渡区，非线性 |
| 4.5–10.0 | 线性增长 | 可用工作区间 |

**工程意义**：当前 Phase 5/6 工作点 amp=6.0 处于有效线性区，但存在 54% 余量不足裕度，轻微扰动（amp→3.0）即可使系统哑火。

### 关键发现 2：非同构确认（最重要发现）

**相同代码的三个 canal 轴呈现 54% 斜率差异：**

| 轴 | 斜率 (Hz/unit) | 幅度范围 0.5–6 |
|----|----------------|----------------|
| yaw | **8.479** | 最敏感 |
| pitch | 4.913 | 中等 |
| roll | **3.084** | 最迟钝 |
| 均值 | 5.492 | — |
| **最大偏差** | **54.4%** | NON-ISOMORPHIC |

**耳石轴同样非同构（79%）：**

| 轴 | 斜率 (Hz/unit) |
|----|----------------|
| oto_x | **5.780** |
| oto_y | **0.846** |
| oto_z | 3.059 |
| **最大偏差** | **79.0%** |

**根因分析**：VestibularChainV2 代码对所有轴完全对称——非同构来自 STDP 权重在 5000 步测量窗口中的**实时演化**。每个扫描点启动新的 chain，但测量期间学习规则仍在更新权重，导致测量结果混入了"学习历史"。

**后续影响**：v2.0 S5 粒度决策结论应为 **NOT ISOMORPHIC → 独立锚定各轴**，而非统一模板。

### 关键发现 3：自发率

```
所有轴 f_reg_0 = 1.0 Hz  (tonic spontaneous discharge)
所有轴 f_irr_0 = 0.0 Hz  (irregular Aff 无自发放电)
```

f_irr 仅在足够强的突触驱动时触发，设计合理：irregular Aff 编码速度变化而非稳态。

## Phase 2：物理单位锚定计算

### Canal 锚定（Lasker et al. 2008）

**文献基准**：C57BL/6 小鼠，2 Hz 正弦，规则传入灵敏度 = 1.0 spikes/s per deg/s

```
方法：f_evoked = f_reg - f_spontaneous = f_reg - 1.0 Hz
每幅度单位产生的诱发发放率 = slope [Hz/unit]
物理锚定：1 model unit = slope / 1.0 [deg/s]
```

| 轴 | 斜率 (Hz/unit) | 锚定（deg/s/unit）| 链路灵敏度 (Hz/(deg/s)) |
|----|----------------|------------------|------------------------|
| yaw | 8.479 | 8.48 deg/s | 1.00 ✓ |
| pitch | 4.913 | 4.91 deg/s | 1.00 ✓ |
| roll | 3.084 | 3.08 deg/s | 1.00 ✓ |
| **均值** | **5.492** | **5.5 deg/s** | **1.00** |
| 范围 | — | 3.1–8.5 deg/s | — |

> 注：canal 锚定的灵敏度为 1.0 Hz/(deg/s)（= 文献值），这是**定义而非测量**——我们用文献值反推了 deg/s/unit。实际需要交叉验证 gm 是否与文献 MET 参数自洽。

### Otolith 锚定（Goldberg 2000）

**文献基准**：35 spikes/s per g = 3.57 Hz/(m/s²)

```
1 model unit = slope [Hz/unit] / 3.57 [Hz/(m/s²)] = slope/3.57 [m/s²]
```

| 轴 | 斜率 (Hz/unit) | 锚定（m/s²/unit）| 锚定（g/unit）|
|----|----------------|-----------------|--------------|
| oto_x | 5.780 | 1.62 m/s² | 0.165 g |
| oto_y | 0.846 | 0.24 m/s² | 0.024 g |
| oto_z | 3.059 | 0.86 m/s² | 0.088 g |
| **均值** | **3.228** | **0.90 m/s²** | **0.092 g** |

**工作点物理值（amp=6.0）：**

| 轴 | 物理幅度 | 相当于 |
|----|---------|--------|
| yaw | 6×5.5 = **33 deg/s** | 中等头部旋转 ✓ |
| pitch/roll | 6×4–8 = **19–51 deg/s** | 合理前庭刺激 ✓ |
| oto_x | 6×1.62 = **9.7 m/s²** ≈ **1g** | 直立重力对齐 ✓ |
| oto_y | 6×0.24 = **1.4 m/s²** | 微弱水平加速 ✓ |
| oto_z | 6×0.86 = **5.2 m/s²** | 垂直加速 ✓ |

**交叉一致性**：Canal 和 Otolith 工作点均在生物合理范围内，量纲映射无矛盾（< 10× 差异）。v2.0 S4.5 检查通过。

### synapse_gain 重推（hebbian.py 注释公式验证）

```
V_ss = f_Aff × W × g_syn × dt × R_enc
     = f_Aff × 2.5 × 16.0 × 0.001 × 5.0
     = f_Aff × 0.2
```

| f_Aff 场景 | V_ss | V_th | 余量 |
|-----------|------|------|------|
| 2 Hz（自发） | 0.40 V | 0.30 V | **+33%** ✓ |
| 7 Hz（oto_y 工作点最小） | 1.40 V | 0.30 V | **+367%** ✓ |
| 47 Hz（yaw 工作点） | 9.40 V | 0.30 V | **+3033%** ✗ 严重过饱和 |

**结论**：synapse_gain=16 专为维持 **f_Aff≈2 Hz** 时的最低触发而校准（FIX-P2）。在工作点（7–47 Hz）下，Enc 处于严重过饱和状态——但 coupler + adapt_vth 负责限制实际放电率，避免 Enc 达到 100% 占空比。

**生物对比**（DEG-016）：若 N_conv=10 Aff（生物值），目标 g_syn = 0.30/(50×2.5×0.001×5) ≈ 0.48。当前值 16.0 为生物值的 **33倍**，全部用于补偿 N=1 单传入。

## 后续实验可行性建议

### P0（立即可执行）：测量期间冻结 STDP

**问题**：Phase 1 扫描发现非同构（54%/79%）根因是测量中 STDP 权重演化。  
**方案**：在 `exp_vest_calibration_scan.py` 中测量期间临时禁用学习：

```python
# 在 scan_one() 中，MEASURE 步骤前后切换
for bundle in chain._all_bundles():
    bundle.config.stdp_lr = 0.0   # 冻结
# ... measure ...
for bundle in chain._all_bundles():
    bundle.config.stdp_lr = original_lr  # 恢复
```

**预期**：消除非同构后，6 轴斜率差异应 < 5%（同构），从而可以用统一锚定。  
**成本**：~1h 编码 + ~275s 重扫描  
**风险**：低。纯测量修正，不改变母代码。

---

### P1（推荐，2–4h）：otolith 轴 oto_y 死区修复

**问题**：oto_y 斜率仅 0.846 Hz/unit（其他轴均 > 3 Hz/unit），工作点 f_reg 仅 7 Hz，V_ss 余量在最小功能 Enc 边缘。  
**根因**：oto_y STDP 权重可能在初始化后就偏低（与 yaw 同构假设不成立时的副产品）。  
**方案**：
1. 先执行 P0（冻结 STDP 重扫）确认是否真实偏低
2. 若确认偏低：在 VestibularChainV2 中对 oto_y 单独设置 `initial_weight` 补偿
   - 需回答三问：Q1 BIO=椭圆囊（utricle）重力感受器，Q2 bundle 路径，Q3 initial_weight 依据

**可行性**：中等。RULES.md 允许参数调整，但需 BIO 来源。文献：Goldberg 2000 Otolith characterization in mouse。

---

### P2（中期，1–2 周）：清算 DEG-016（N=1 单传入）

**量纲分析揭示的最深层债务**：synapse_gain=16 是 33× 生物值，全部用于补偿 N=1 单传入。生物系统有 500–1000 条传入纤维，SNR ≈ 87× 高于当前模型。

**可行性评估**：
- **障碍**：增加 N 意味着在每轴创建 N_conv 个 Afferent 神经元，重构 VestibularChain 和 HebbianCircuit 中的 bundle 映射
- **代价**：大型重构，触及 hebbian.py 母代码核心
- **建议**：在 `VestibularChainV3` 中实现（继承 V2），通过 VariantCircuit adapter 注入。不修改 V2/hebbian 母代码。
- **前置条件**：P0 + P1 先完成（确保 V2 基线稳固），然后 DEG-016 作为独立 V3 研究项

---

### P3（结构性，需讨论）：oto_y 量纲异常的信号意义

**发现**：oto_y（y 轴线性加速度）的工作点灵敏度仅为 oto_x 的 17%（0.24 vs 1.62 m/s²/unit）。

**生物解读**：在生物上，水平（x）和前-后（z）加速度的耳石灵敏度略高于垂直方向（y 轴为侧向），但不应相差 6×。

**问题来源**：STDP 历史或初始权重偶然导致 oto_y 通路衰退。这是结构可塑性（prune/mitosis）的副作用还是初始化问题？

**建议**：在 P0 冻结测量后，运行 entropy audit 检查 oto_y 传入到 Enc 的信号深度（H_signal/H_thermal 比）。如果 oto_y Enc 信号深度 < 1.0，说明确实存在信号传递失效（可能为隐性 DEG）。

---

### P4（中长期）：动力学参数锚定（FIFO 延迟物理意义）

VestibularChainV2 的 MET→HC 2步延迟 和 HC→Aff 2步延迟（= 2ms）在当前 dt=0.001s 约定下对应实际神经传导时间。

文献：毛细胞→突触 latency ~1–3ms（Parsons & Sterling 2003），Aff 突触延迟 ~1ms → 2步合理。

**可行性**：纯文档注释，无代码更改，低成本，可随 P0 同步完成。
