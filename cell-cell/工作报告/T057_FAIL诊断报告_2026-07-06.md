## 二、Bug 诊断

### Bug-1：bundle 名字错误（|Δw| 测量完全失效）

T-055/T-056/T-057 脚本中使用了不存在的 bundle 属性：
```python
# T-057 中的错误代码
bl = getattr(c, 'bundle_relay_to_slow_left',  None)  # → None（不存在）
br = getattr(c, 'bundle_relay_to_slow_right', None)  # → None（不存在）
```

正确的属性名（来自 T-044 实验脚本 `exp_t044_50k_cross_inhibition.py:50-53`）：
```python
b_ccw = c.bundle_d1_phasic_left_to_spinal_ccw    # ← 正确
b_cw  = c.bundle_d1_phasic_right_to_spinal_cw    # ← 正确
```

**影响：** 所有 |Δw| 读数为 nan → 经过 `if not math.isnan` 处理后显示为 0。实际权重变化**可能**发生了，只是无法读取。

### Bug-2：T4.1 计算路径错误（NaN 全程）

T-057 脚本中：
```python
# 错误：c.vestibular.column 不存在或不是正确路径
cols = c.vestibular.column
```

正确实现（来自 T-044 脚本 `exp_t044_50k_cross_inhibition.py:58-70`）：
```python
def get_t41_ratio():
    axis_ws, cross_ws = [], []
    for b in c.bundles_col_to_motor:    # ← 正确属性
        ws = [m.w for row in b._memristors for m in row]
        avg_w = sum(ws) / max(len(ws), 1)
        if 'cross' not in b.id:
            axis_ws.append(avg_w)
        else:
            cross_ws.append(avg_w)
    avg_ax = sum(axis_ws) / max(len(axis_ws), 1)
    avg_cr = sum(cross_ws) / max(len(cross_ws), 1)
    return avg_ax, avg_cr, avg_ax / max(avg_cr, 1e-6)
```

**影响：** T4.1 全程 NaN，无法判断 Col→Motor 信号衰减情况。

## 三、物理问题诊断：fill 过快饱和

### 现象
fill 在 10k 步时已达 0.586，50k 步时 0.999，之后全程 fill=1.0。

### 对比
| 实验 | T-048状态 | fill@5k | fill@50k | STDP工作 |
|------|-----------|---------|---------|----------|
| T-041（08e4c76，T-048前） | 无 | 未记录 | 未记录 | ✅（\|Δw\|=0.295） |
| T-044（4ac8d98，T-048前） | 无 | 0.475（下降） | 未记录 | ✅（\|Δw\|=0.110） |
| T-057（当前，T-048后） | 有 | 0.586（上升） | 0.999（饱和） | ❌（STDP停止？） |

**关键观察：** T-044 中 fill 从 0.5 出发、在 5k 步时**下降**到 0.475，说明进食 < BMR 消耗。T-057 中 fill 在 10k 步时**上升**到 0.586，说明进食 > BMR 消耗。

### 根因假设
**T-048 _hunger_ema r_leak 调制** 使 relay 神经元在饥饿时更活跃（r_leak 降低 → 更低阈值），导致：
1. 热觉信号传导更强 → IntakeSensor 被更频繁触发 → 进食率提升
2. fill 更快到达 1.0 → DA_hunger 归零（饱腹） → phasic STDP 触发条件消失 → 权重冻结
3. 无 phasic 窗口 → STDP 方向分化停止 → DR5 退回随机基线

### DR5=50% 的解释
T-054（STDP全冻结）和 T-057（STDP开启）的 DR5 完全一致（均≈50%），说明 T-057 实际上处于"功能性的 STDP 冻结状态"——fill 饱和导致 DA 持续低，STDP 无法积累方向性权重差异。
