## 2. 供电电流方程

```
G(V_g)   = Σ_{n=1}^{N} g_c · max(0, V_g − θ)     电导支路（MOSFET triode 小 V_DS 段）
g_c      = gm / V_REF，V_REF = vdd = 1.0 V        单位换算，非新自由参数
I_fb     = G(V_g) · vdd / (1 + G·R_s)              负载线闭解
V_supply = vdd / (1 + G·R_s)
```

`PowerRail.draw(I_fb)` 返回电压作为闭解一致性自检通道（每步断言 |draw−V_supply|≤1e-12，违反即 RuntimeError）。canonical（vdd=1, R_s=0）下与第三轮数值**逐位一致**（修正零成本），外部 M1-M4 基线原样保持，未调参改判据。

## 3. 完整量纲

[g_c]=S/V，[G]=S，[G·V_supply]=A ✓。μ = N·gm·(vdd/V_REF)·dt/C 无量纲；vdd=0 ⇒ μ=0（解析层同样断电归零）。
