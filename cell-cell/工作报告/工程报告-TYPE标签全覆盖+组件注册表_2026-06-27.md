## Phase B — ComponentRegistry 实现

**文件：** `nexus_v1/ledger/component_registry.py`（TYPE:INFRA，Pattern-1范式）

### 扫描范围设计

```
扫描对象              census可见  kind
──────────────────────────────────────
get_all_neurons()     True        neuron
get_all_bundles()     True        bundle
shadow_sandbox.*      False       bundle/neuron
physics attrs         False       physics
dict containers       False       physics
ledger attrs          False       ledger
```

### 核心机制

```python
# TYPE自动读取（Phase A打标后免手工维护）
doc = inspect.getdoc(type(obj)) or ""
m = re.match(r'TYPE:(\S+)', doc.split('\n')[0])
tag = m.group(1) if m else 'UNTAGGED'

# 源码位置
src = inspect.getsourcefile(type(obj))
_, lineno = inspect.getsourcelines(type(obj))
```

注意：`inspect.getsourcelines()` 仅在 `print_report()` / `scan()` 时调用，不在仿真热路径中执行。

## 技术备注：git stash 事故

在回归验证中途因误 `git stash` 导致 .py 源文件改动回退，而 .pyc 缓存仍是新版（Python 运行新代码但源码显示旧版），制造了表现混乱的 T3.2 假性回归。解决方法：

```bash
# 从 stash 恢复所有已修改 .py 文件
git stash show --name-only stash@{0} | grep "\.py$" | xargs -I{} git checkout stash@{0} -- {}
```
