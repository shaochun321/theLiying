### 修改内容

```python
# 修改前
_W_RS = 1.0 / 5000.0
r_leak = 5000.0  # 两侧

# 修改后（物理约束：V_ss_slow = relay.act × _W_RS × r_leak = relay.act）
_R_SLOW = 15000.0
_W_RS = 1.0 / _R_SLOW   # 维持 V_ss 不变
r_leak = _R_SLOW         # 两侧同步
```

**重要修正**：原方案描述"先改一侧"已在补充裁决中升级为严重错误。非对称 τ 在对称热场中制造虚假空间梯度（左右 slow_relay 追踪速度不同 → spurious phasic 偏差 → 单侧偏转）。本次实现**双侧完全同步**。

另一关键修正：`_W_RS` 必须与 `r_leak` 同步更新，否则 `V_ss_slow = relay.act × (1/5000) × 15000 = 3 × relay.act`，slow_relay 过度追踪导致 phasic 永久负值。

## 三、Step 6：脊髓 Ia 推挽互抑

### 生物依据

**Ia 抑制性中间神经元**（Eccles, Eccles & Lundberg 1960）：拮抗肌单突触互抑，是脊髓运动回路中最基本的 WTA 选择机制。CCW（左转）活跃时主动抑制 CW（右转），反之亦然。行为从电路结构中涌现，无需 Python if/sign 逻辑。

### 实现结构

```
Sources               Bundle                    Target
spinal_ccw ─────[sg=-1.0, w=0.1, frozen]───→ spinal_cw
spinal_cw  ─────[sg=-1.0, w=0.1, frozen]───→ spinal_ccw
```

**传播顺序设计**（对称预计算）：
```
t 时刻：
  1. _inh_to_ccw = bundle_cw_to_ccw.propagate()  # 读 spinal_cw 的 t-1 活动
  2. _inh_to_cw  = bundle_ccw_to_cw.propagate()  # 读 spinal_ccw 的 t-1 活动
  3. spinal_ccw.step(d1_ccw + inh_to_ccw)        # 同时 step
  4. spinal_cw.step(d1_cw + inh_to_cw)           # 同时 step
```

两侧均使用对方的 t-1 激活，消除更新顺序偏差（若先 step CCW，CW 会看到 CCW 的 t 激活，产生非对称响应）。

### T4.1 变化解读

轴/交叉权重比从 3.20x 降至 1.13x 值得关注但不需处理：
- **原因推断**：Ia 互抑引入了对 motor 的对称性约束，两侧 spinal→yaw 驱动的选择性暂时下降（双侧都略受抑制）。这是推挽 WTA 的初始状态，STDP 成熟后权重分化会恢复。
- **下一步**：需要 200k 步长实验验证 T4.1 随 STDP 成熟恢复（参考 D1 验证实验模式）。

## 四、实验质量说明（T2.2、T3.2 高分的解读）

T2.2 从 3.52x → 19.03x，T3.2 从 7.0x → 4726x，这种大幅提升来自：

1. **slow_relay τ 延长**：较长的 τ 使 slow_relay 跟踪更稳定的 DC 基线，phasic 信号更干净。encoding selectivity 计算的是 vestibular_reg / thermal_irr 对比度，phasic 更干净 → 热觉干扰更少 → 比值更高。

2. **Ia 推挽**：spinal 层 WTA 压制弱侧 → 数值不稳定点减少，前庭编码路径更纯净。

3. **注意**：T3.2 比值 4726x 部分来自分母（min）趋近于 0.0000（某列 Column 处于完全静默状态），比值高不一定代表"更好"，只代表"分化更极端"。这本身是 WTA 竞争的预期结果。
