## 一、脑区构建（Brain Region Construction）

### 1.1 已完成部分

**地址体系（`circuit/region_topology.py`）**

定义了5个脑区及其物理距离矩阵：

| 代码 | 脑区 | 生物对应 |
|------|------|----------|
| 0x01 | SPINAL | 脊髓前/后角 |
| 0x02 | BRAINSTEM | 延髓/脑桥/中脑（前庭核、CPG）|
| 0x03 | MAIN | 皮层类比（编码、列、运动、DA）|
| 0x04 | HYPOTHALAMUS | 下丘脑（ARC/VMH/LH）|
| 0x05 | SHADOW | Shadow 沙箱（附着于 MAIN，距离 1mm）|

距离矩阵完整（例：SPINAL→MAIN = 4mm，MAIN→MAIN = 1mm），传导速度定义：
- 有髓鞘 1000 mm/s（脊髓反射、前庭）
- 无髓鞘 1 mm/s（稳态调制）

**全神经元标注（`variant_adapter.py:863` `_assign_regions()`）**

所有神经元在 `__init__` 末尾被批量打标：
- 脊髓神经元（运动、Renshaw、D1 的 spinal_ccw/cw）→ 0x01
- 脑干（CPGNeuron、前庭核 relay 类）→ 0x02
- 主层（编码、列、运动、DA、slow_relay、phasic）→ 0x03
- 下丘脑（energy_sensor、cpc_deviation）→ 0x04
- Shadow 层 → 0x05

**DelayedBundle（`circuit/bundle_v2.py`）**

完整实现了带传导延迟的 SynapticBundle 子类：
- 每对 (source, target) 建立独立的环形缓冲区（ring buffer）
- 延迟计算：τ_steps = round(d_mm / v_cond / dt_ms)
- 正确继承了 STDP、Xin、Ledger 跟踪
- 若神经元没有 `position` 属性则 fallback 到 delay=0

### 1.2 未完成部分（关键空白）

**`DelayedBundle` 是孤儿文件。** 全部约 60 条现有 `SynapticBundle` 实例都是即时传递的（delay=0），没有任何代码调用 `make_delayed()` 或 `DelayedBundle()`。

传导延迟所需的**神经元位置**（`NeuronConfig.position`）也几乎全未设置——只有 `ThermalDeltaNeuron`、少数 somatosensory 探针和 energy sensor 有位置坐标。没有位置 → 即使改用 `DelayedBundle`，所有延迟也会退化为 0。

**现状结论：** 脑区地址系统是设计文档的代码化表达，在运行时无物理效果。唯一的用途是被 Noether Ledger 和 EntropyLedger 用于区分层级统计，没有任何信号路径因脑区归属而产生延迟或拓扑变化。

## 二、环流耦合（Circulation Coupling）

当前有三条独立的"环流相关"路径，状态差异极大。

### 2.1 C3' 物理电路（CirculationProportionCircuit）— **活着**

**架构：**

```
thermal_stability → [Cap_H, τ=10s] → V_homeo ─┐
body_speed        → [Cap_M, τ=10s] → V_motor  ─┤→ V_total
feed_alignment    → [Cap_F, τ=10s] → V_feed   ─┘
fraction_homeo = V_homeo / V_total
V_ref = 0.7 (homeostatic set point, stored in Cap_ref)
deviation = [MOSFET, gm=1.0] (V_ref - fraction_homeo)
↓
→ cpc_dev_neuron.step(deviation) → bundle_cpc_to_vital → VitalOscillator amplitude mod (B1a)
→ ms.rho_homeo / rho_motor / rho_feed / homeo_deviation (MotionState 记录)
```

**现状：** 每步正常运行，产生 homeostatic 偏差信号并通过 B1a 束（`bundle_cpc_to_vital`）调制 VitalOscillator 的运动振幅。这条路径在热觉实验中实际有效。

**潜在问题：** `feed_alignment` 的输入质量低。目前计算为 `max(thermo_vals) - min(thermo_vals)`（patch 最大温差），量纲不明，和 `thermal_stability`/`body_speed` 不在同一尺度上。3个 Capacitor 的积分比例会受此影响，但这是精度问题而非死锁。

---

### 2.2 CirculationMeter（P/R/ρ/ν 观测）— **死的**

**架构意图：**

```
Col[axis_i] → Bind[axis_i, axis_j] → Mot[m] → feedback → Col[axis_i]
流强 φ = col_δa × binding_act × bind_mot_w × feedback_trace
P = 最强闭环路径，R = 次强
ρ 向量 = P/R 流强归一化分布
ν = dρ/dt（运动势）
```

**阻塞原因分析：**

`measure()` 中闭环路径的流强计算：
```python
flow = col_da * cell.activation * bind_mot_w * max(fb_trace, 0.001)
```

四个因子的实际值：
| 因子 | 设计意图 | 实际值 |
|------|----------|--------|
| `col_da`（列激活偏差）| 方向性激活 | 正常，但与其他因子相乘后被压制 |
| `cell.activation`（Binding 激活）| 跨模态时间一致性 | 绝大多数 < 0.01（被过滤掉）|
| `bind_mot_w`（Binding→Motor 权重）| 学习后的路径权重 | 全部初始化为 **0.001（dormant）**，无学习机制 |
| `fb_trace`（Motor→Col 反馈迹）| 闭环反馈强度 | 初始化为 0，无更新代码 |

**根本原因：** `_binding_motor_weights` 只在 `__init__` 时设为 0.001，循环体中有 `_binding_motor_weights[bid][mid] = 0.001` 的懒初始化，但没有任何 STDP 或 Hebbian 更新来提升这些权重。结果是所有路径流强 ≈ `col_da × 0.001 × 0.001 × 0.001 ≈ 1e-9`，远低于 `MIN_FLOW = 1e-5`，全部被过滤。

**输出去向：** 即使 CirculationMeter 产生了有效的 ρ 向量和 ν，这些输出目前只写入 `get_state()` 的诊断字典，没有任何代码读取它们来影响 STDP、DA、或运动决策。**是完全封闭的读取死路。**

---

### 2.3 Shadow ν → DA（C1）— **死的**

**架构：**

```
shadow_sandbox._k_ema (κ，收缩度 EMA) 
→ _nu = _k_ema(t) - _k_ema(t-1)   （收缩率 = 自由能变化率）
→ shadow_nu_neuron.step(_nu × 1/176)   （边界换能，NuThresholdNeuron）
→ bundle_shadow_nu_to_da.propagate()   （frozen bundle → DA）
```

**阻塞原因：**

`_nu` 的计算依赖 `_k_ema` 的变化。Shadow 层的 κ 是由 shadow Xin（各 shadow bundle 的 `xin_tension`）决定的。若 shadow bundle 的传播信号很弱（Xin ≈ 0），κ 几乎恒定，`_nu = _k_ema - _k_ema_prev ≈ 0`。

200k 实验日志证实：`nu_ema = 0.000000` 全程。

**根因：** Shadow 层的 Encoding→Column→Motor 被 Xin 信号的体（main 层）驱动，但 shadow 的 bundle 权重极小（`init_w=0.001` for shadow→DA），输出太弱；更深层的问题是 shadow 层没有接受足够强的 Xin 驱动输入，导致 κ 无法产生有意义的变化率。

## 三、T4.1 非确定性（附带问题）

**现象：** 三次连续运行结果 2.26x / 1.71x / 0.80x，约 1/3 概率在 1.5x 阈值以下失败。D1 commit 时的 3.07x 是单次幸运值，非稳定行为。

**来源：** 测试使用 `random.seed(42)` 后，每步 LangevinNoise（`random.gauss`）和 World 噪声（`world.py:180`）产生受控但对 STDP 轨迹敏感的噪声序列。在 10k 步短窗口内，col→motor 的轴向权重和跨轴权重差异（axis/cross ratio）仍在小数点后两位浮动，结果对种子敏感。

**不是 D1 引入的**——该问题在 relay_to_yaw 清理（5907b8b）后已存在，阈值从 2.0x 降至 1.5x 时在临界区暴露。

## 五、修复优先级建议

**P0（不修不能继续实验）：** T4.1 稳定性

方案：将阈值进一步降至 1.0x（物理下限：任何学习都应产生 axis > 0），或将测试窗口从 10k 步延长至 30k（增大 STDP 效果 / 噪声比），避免在临界区随机 fail。

**P1（环流耦合闭环）：** CirculationMeter binding→Motor 权重学习

binding_motor_weights 需要一个简单的 Hebbian 更新：`Δw ∝ binding_act × motor_act × da_conc`。目前连触发时机都有（1587行 binding_activations 已计算），只差权重更新代码。修复后 P/R/ρ/ν 才能产生有效信号。

**P2（Shadow ν 激活）：** 增强 shadow Xin 输入

shadow 层需要更强的信号驱动（增大 shadow bundle 初始权重或传播增益），使 κ 产生实质变化，_nu 才能非零。

**P3（传导延迟）：** DelayedBundle 接入关键路径

至少对 SPINAL→MAIN 路径（如 spinal_ccw/cw → yaw）使用 `DelayedBundle`，并为相关神经元设置位置坐标。传导延迟对 STDP 时间窗口有生物意义的影响（几毫秒延迟 ≈ STDP 敏感窗口宽度）。
