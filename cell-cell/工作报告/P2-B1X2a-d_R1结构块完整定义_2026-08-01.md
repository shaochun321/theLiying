## 二、实际改动

全部在 `nexus_v1/relations/r1_structure.py`（最终约550行）：

### 2.1 RelationGenLink字段修正（040602）

`link_address`拆成两个独立字段：
- `generation_link_address`：标识整条ℓ_gen（trace+bundle+collector的组合）
- `collector_address`：标识relation_collector这一个检测节点本身

同relation_type/link_type的区分一样，两者不能混用：
RelationOccurrence.collector_address的语义是"哪个collector产生了这次检测"，
应对应后者，不是前者。`project_to_relation_occurrence_fields()`同步更新。

### 2.2 R1PhysicalInterval（X2d_1）

从X2a的两字段占位升级为完整状态机（评判040602裁定必须分开I_R1和W_Y*）：

```
UNBOUND → SUPPORTED → RELAXING → CLOSED
```

- **UNBOUND→SUPPORTED**：support_a>threshold AND support_b>threshold AND
  collector_activity>threshold（两父实例都有物理支撑，且relation collector
  进入响应带）
- **SUPPORTED→RELAXING**：共同支撑解除、collector退出响应带、或父epoch改变
  （新epoch不能并入旧区间）
- **RELAXING→CLOSED**：trace和collector均回到基线带

`update(t_step, support_a, support_b, collector_activity, parent_a_epoch,
parent_b_epoch, _parent_a_epoch_at_enter, _parent_b_epoch_at_enter)`
不直接访问Neuron，由调用方从神经元读出值后传入（INFRA纪律）。

字段：s_enter / s_support_end / s_closed / state（_R1IntervalState枚举）

区间用途：R1实例身份；判断残响归属；同一区间只产生一个R1实例。

### 2.3 R1MeasurementWindow（X2d_2）

评判040602核心修正：I_R1 ≠ W_Y*。

```
R1区间记录"这条关系活了多久"；Y窗口记录"这条关系造成的作用要观察多久"。
```

两者不同的原因：R1本体不含ℓ_out，ℓ_out的电流尾部可能在s_closed^R1之后
仍未归零（s_closed^R1 ≤ s_relax^Y）。混用就让R1存在再次依赖输出能力，
与X2a'刚完成的修正相冲突。

`from_r1_run(r1_interval, y_trajectory, y_start_step, baseline_band, ...)` →
1. 先跑完整AℓB条件
2. 从I_R1^{AℓB}.s_enter + Y轨迹最后一个超阈步骤后一步 = W_Y*.s_end
3. X2c的所有反事实条件（∅/A/B/gen-cut/out-cut）使用同一W_Y*

## 三、发现的真实问题

### 3.1 collector_address与generation_link_address再次混用（040602修正）

`project_to_relation_occurrence_fields()`初版从`link_gen.link_address`填
RelationOccurrence.collector_address——这是跟relation_type/link_type类似的
同类混淆（"整条链路的地址"≠"检测节点本身的地址"），评判040602发现。
同一会话内连续犯了两次"把不同层次的地址混用"错误，说明字段分离约定需要
在代码里有明确注释（已在RelationGenLink docstring里写清楚）。

### 3.2 W_Y*和I_R1不能共用同一个s_exit字段（040602非阻塞）

原来R1PhysicalInterval只有s_enter/s_exit两个字段，无法区分"R1区间封闭时刻"
和"Y电流归零时刻"。这次拆成：
- R1PhysicalInterval：s_enter/s_support_end/s_closed（只追踪关系本体）
- R1MeasurementWindow：s_start/s_end（追踪Y轨迹归零）
