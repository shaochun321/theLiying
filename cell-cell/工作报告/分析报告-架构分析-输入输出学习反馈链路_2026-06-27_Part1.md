## 2. 感觉输入链路（INPUT）

### 2.1 热觉链路

**物理起点：** `world.temperature_at(position)` — 对所有 `cylindrical_sources` 求和，正确实现。

**皮肤热平衡（SkinPatch）：**
```
文件：nexus_v1/components/world.py
τ_skin = C / k = 10 / 2 = 5步（5ms 仿真时间）
实现：T_skin += (T_env - T_skin) × dt / τ_skin
```
含义：皮肤在第 1 步响应 63%，第 5 步达到 95%。对于 STDP 而言，热信号几乎是即时的（不存在"5000步延迟"的误解）。

**三层躯体感觉链（SomatosensoryChain）：**

| 层级 | 神经元类型 | 信号性质 | 生物对应 |
|------|-----------|---------|---------|
| Thermo | spiking=False | DC 温度（T_skin 绝对值） | 温敏 TRPV 受体 |
| Noci | spiking=True, v_peak=0.25 | AC dT/dt（变化率） | 伤害感受器 Aδ 纤维 |
| Relay WDR | spiking=False, τ=20 | 整合器 | 脊髓后角宽动态范围神经元 |

Relay 输出 → `Enc_therm` → `Col_therm`（沿标准 6 层信号链）。

**关键约束：** 当 body 静止时，Noci 输出为零（dT/dt=0），Thermo 持续激活。STDP pre_trace 依赖 Thermo（DC 通道），因此静止时 pre_trace 仍非零——这是造成对称死锁的物理前提。

**patch 布局（4 个方向）：**
```
therm_front（+x 方向皮肤） → therm_front_col  → 束 therm_front_to_move_x（synapse_gain=+10）
therm_back （-x 方向皮肤） → therm_back_col   → 束 therm_back_to_move_x （synapse_gain=-10）
therm_left （+y 方向皮肤） → therm_left_col   → 束 therm_left_to_move_y （冻结，w=0）
therm_right（-y 方向皮肤） → therm_right_col  → 束 therm_right_to_move_y（冻结，w=0）
```

定义位置：`nexus_v1/circuit/hebbian.py` 第 584-622 行。

### 2.2 前庭链路

**物理噪声注入：**
```
文件：nexus_v1/components/langevin_noise.py（104-130 行）
OU 过程：η[k] = decay × η[k-1] + noise_std × N(0,1)
σ₀ = 0.70，τ = 3.0s
T_bath = ECM 内淋巴液温度（动态）
```
噪声以**加速度**形式注入（乘以 OTOLITH_GAIN=500），进入耳石通道。耳石感知线加速度，椭圆囊/球囊通道 → 毛细胞（HC）→ 传入神经元（Aff）。

**信号链（6层）：**
```
MET(L1) → HC(L2) → Aff_reg/Aff_irr(L3) → Encoding(L4) → Column(L5) → Motor(L6)
轴：yaw, pitch, roll（半规管）+ oto_x, oto_y, oto_z（耳石）+ therm（热觉独立轴）
```

## 3. 处理层（PROCESSING）

### 3.1 Column 层（L5）功能

Column 是主要整合节点：
- 接收来自 Encoding(L4) 的多轴投射
- 通过 DivisiveNormalization 做增益控制（防止饱和）
- 通过侧抑制 bundle 相互竞争（多轴输入下可能全归零）
- 输出到 Motor(L6)

**当前已知问题：** Col→Motor 耦合弱（C6 合同在某些输入下失败）；横向抑制在多轴输入时可驱动所有 Column 归零。这些是已知问题（Current state v1.7.2）。

### 3.2 前庭信号 vs 热觉信号在 Column 的区别

- 前庭 Column：接收 6轴×2方向（reg+irr）= 12个投射源
- 热觉 Column：接收 4 patch 的 Relay 输出，独立轴

两者共用 Column 类但配置不同。STDP 学习主要发生在热觉轴的 `therm_col → motor` 束上。

## 4. 学习链路（LEARNING）— 三因子 STDP

### 4.1 资格迹（Eligibility Trace）

```python
# 文件：nexus_v1/circuit/bundle.py
# pre_trace：对应 |encoding 层激活| ，衰减时常数 τ_pre=20 步
pre_trace[i] = max(|enc_activation[i]|, decay × pre_trace[i])  # 实际实现为峰值衰减

# post_trace：对于非 spiking 神经元（Motor）= d(activation)/dt
post_trace[j] = |activation[j] - prev_activation[j]| / dt

# 资格迹积累
E[i,j] = E[i,j] × (1 - dt/τ_elig) + pre_trace[i] × post_act[j] × dt
```

关键：
- `τ_elig = 300步`：迹在 300步内衰减到 37%。约相当于 300ms 仿真时间。
- `eligibility_gain = 1e-5`（默认）：控制权重增长速率
- post_trace 对非 spiking 神经元是**变化率**，不是激活值本身

### 4.2 DA 信号（奖励调制）

```python
# 文件：nexus_v1/components/da_differential_gate.py（或 variant_adapter.py 内）
fill = energy_store.fill_fraction
DA = max(0.0, 7.5 × (fill(t) - fill(t-1)) / dt)   # 导数信号（RPE 门控）
hunger = max(0.0, 1.0 × (0.5 - fill))               # 背景饥饿基线
DA_total = DA + hunger
```

**核心性质：DA 是能量增速的导数，非能量绝对值。**

| 情景 | fill 变化 | DA | STDP |
|------|----------|-----|------|
| body 持续接近热源 | ↑ | 高 | 强烈 LTP |
| body 静止于热源附近 | 平 | ≈ 0 | 仅衰减 |
| body 远离热源 | ↓ | 0（截断） | 无 LTP，轻微 LTD |

### 4.3 权重更新

```python
ltp = eligibility_gain × E[i,j] × DA_total
ltd = eligibility_ltd_rate × dt × pre_trace × post_act
decay = weight_decay × dt × w[i,j]
dw_raw = ltp - ltd - decay

# 软边界（memristor 饱和）
dw = dw_raw × (w_max - w) if dw_raw > 0 else dw_raw × (w - w_min)
w[i,j] = clip(w[i,j] + dw, w_min, w_max)
```

`weight_max = 0.5`（hebbian.py 默认），`w_min = 0.0`。

### 4.4 Xin 张力（结构生长，非 STDP）

Xin 是**预测残差**，驱动 sprout/prune/mitosis 结构生长，与 STDP 权重学习是**独立机制**：
```
Xin = |predicted - actual|  （bundle 级别）
高 Xin → sprout（生长新连接）
低 Xin → prune（修剪静默连接）
```
Xin relay 神经元已存在但未有效连接到 DA，这是架构改动的潜在切入点（见 Part 2）。

## 5. 运动输出链路（OUTPUT）

### 5.1 Motor 输出路径

```
Col_therm → Motor_neuron（非spiking）
         → MuscleSystem.contract_all()
         → F = activation × gain(0.1) × 运动方向
         → body.velocity += F/mass × dt
```

延迟：2步（MuscleSystem FIFO buffer）  
增益：0.1（muscle.py 第 40-96 行）  
**Motor 对速度的贡献约 0.01 units/step**（激活量级 0.1 时）

### 5.2 物理力（绕过 Motor）

**k_conv 对流漂移：**
```python
# variant_adapter.py 第 757-763 行
grad_T = world.gradient_at(body.position)
body.velocity += k_conv × grad_T × dt
```
贡献：约 **0.12 units/step**（k_conv=0.5 时），是 Motor 的 **12 倍**。

**YAW 脊髓反射（只有一个调用点）：**
```python
# variant_adapter.py 第 750 行（唯一调用 apply_yaw_torque 的地方）
yaw_torque = (T_left - T_right) × YAW_GAIN(0.1)
body.apply_yaw_torque(yaw_torque, dt=0.001)
```
性质：硬连线反射，不可学习，不经过 STDP，不经过任何 Bundle。

### 5.3 力的叠加顺序（variant_adapter.step()）

```
1. YAW_GAIN 反射力矩
2. k_conv 对流漂移（速度直接修改）
3. Langevin OU 噪声（注入前庭感觉侧）
4. Motor → Muscle → body.velocity
5. VitalOscillator（基线运动）
6. SpinalReflex（脊髓反射）
```

Langevin 在感觉侧（前庭加速度输入），**不直接作用于 body.velocity**。

## 6. 反馈回路（FEEDBACK）

### 6.1 物理闭环

```
body.position(t) → world.temperature_at() → SkinPatch.step_thermal() (τ=5步)
→ soma_relay → Enc_therm → Col_therm → Motor → Muscle (delay=2步) → body.position(t+n)
```

**总感-运回路延迟约 14 步：**

| 环节 | 延迟 |
|------|------|
| 皮肤热平衡（63%响应） | 5 步 |
| soma_relay → Enc → Col | 3 步 |
| Col → Motor | 2 步 |
| Muscle FIFO buffer | 2 步 |
| Body 力学积分 | 1 步 |
| （Langevin 前庭另一回路） | +1步 |
| **合计** | **≈ 14 步** |

### 6.2 DA 反馈的特殊性

DA 不是位置的函数，而是**fill 变化率**的函数：

```
body 接近热源 → 温度↑ → ThermalMouth.intake ↑ → fill ↑ → Δfill/dt > 0 → DA↑
body 停止接近  → fill 平台 → Δfill/dt ≈ 0 → DA ≈ 0（仅 hunger 基线）
```

这意味着 STDP 学习信号只在 body **主动获取能量**的过渡阶段出现，静止时几乎为零。

### 6.3 Shadow Layer（只读）

Shadow 是对 Enc→Col→Motor 的结构拷贝，由主系统 Xin 张力驱动，计算自由能 / 收缩率，**不写回**任何值。当前 K_ema 无界增长是已知 bug（见 v1.7.2 状态）。Shadow 未连接到 DA，这是 Part 2 架构改动方案 C 的基础。

## 8. 热觉 STDP 学习的因果链（理论应有路径）

```
① body 向热源运动（velocity·∇T > 0）
② front skin 温度升高（therm_front_col 激活）
③ pre_trace 充电（τ=20步内衰减）
④ Motor_move_x 激活（Motor 向前运动命令）
⑤ post_trace 充电（activation 变化率）
⑥ 与步骤③同时存在 → E(t) 积累（τ=300步）
⑦ body 到达热源附近 → fill ↑ → DA 脉冲
⑧ dw_ltp = eligibility_gain × E × DA → w_front ↑
⑨ 下次 therm_front 激活时，move_x 响应更强 → 更快接近热源
```

**实际观察到的路径（Phase 3 失败原因）：**
```
① body 在 S1 附近双向振荡（Langevin 主导）
② front/back skin 交替激活（振荡时前后均接近 S1）
③ DA 双向对称（两个方向均增加 fill）
④ w_front 和 w_brake 同步 LTP → 比值≈1.0
```
