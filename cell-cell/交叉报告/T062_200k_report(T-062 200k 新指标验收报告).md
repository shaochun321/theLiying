## 三、关键发现

### 3.1 Foraging DR5 = 44.6%（低于随机基线）

> [!WARNING]
> 饥饿状态下的方向正确率 **低于** 50% 随机基线。STDP 在本次运行中产生的权重分化，实际上使方向选择 **更差**。

### 3.2 权重分化：短暂且不稳定

Δw_peak = 0.2154 发生在极早期（~step 2000 前后，Foraging 窗口内），此后权重快速回归对称：

```
Step   5k: w_ccw=0.2995, w_cw=0.2999  → |Δw|≈0.000（已回归）
Step  75k: w_ccw=0.2556              → 短暂 dip
Step 105k: w_ccw=0.2171              → 短暂 dip
Step 195k: w_ccw=0.0951              → 大幅下探
Step 200k: w_ccw=0.1779              → 回弹
```

权重在 Foraging 窗口打开时分化，关闭后回归。分化方向不一致。

### 3.3 与 T-060 (50k) 的对比：随机种子高度敏感

| | T-060 (50k) | T-062 (200k) |
|---|---|---|
| Foraging DR5 | **58.0%** | **44.6%** |

> [!IMPORTANT]

## 四、物理分析

### 4.1 fill 饱和动力学

```
fill 轨迹：0.30 → 0.36(5k) → 0.78(25k) → 1.00(35k) → 1.00(200k)
Foraging 步数：26,707 / 200,000 = 13.4%（主要在前 35k 步）
```

35k 步后 fill 永久饱和 → DA=0 → STDP 完全停止。86.6% 的时间系统处于"功能性 STDP 冻结"状态。

### 4.2 STDP 方向不一致的根因

Foraging 窗口内（前 ~30k 步），body 运动由 CPG 随机初相驱动：
- T-060：CPG 初相碰巧让 body 沿 +x 方向偏移 → 右侧热感知更强 → w_cw 被选择性强化
- T-062：CPG 初相让 body 在 y 方向振荡 → L/R 热感知交替 → 两束交替强化 → 净分化≈0

**根本问题**：STDP 的方向信号来自 phasic 左/右差异，但 CPG 驱动的随机运动在 Foraging 窗口内没有一致的偏转方向 → STDP 收到的信号是噪声。

### 4.3 T4.1 健康上升

```
T4.1: 3.95x → 5.34x (100k) → 4.69x (200k)
```

Col→Motor 耦合全程健康且逐步增强。这确认 bundle 传导路径正常。

## 七、结论

### 确认的事实
1. **STDP 确实修改权重** — L2a=0.215（真实分化，非噪声）
2. **bundle 传导路径正常** — T4.1=4.69×（健康）
3. **能量闭环正常** — fill 从 0.30 涨到 1.00，η=13.4%
4. **Foraging 窗口存在且可检测** — 26,707 步有效

### 暴露的问题
1. **STDP 分化方向不稳定** — 依赖 CPG 随机初相，不同种子结果截然相反
2. **权重分化 ≠ 行为改善** — |Δw|=0.215 但 fDR5=44.6%（更差）
3. **Foraging 窗口太短** — 仅 13.4%，且集中在前 35k 步
4. **无稳定收敛机制** — 权重振荡、回弹、方向翻转

### 后续建议

| 优先级 | 建议 | 原理 |
|--------|------|------|
| **P0** | 多种子统计（N=5+）| 确认 DR5/fDR5 的分布，而非单次采样 |
| **P0** | T-063 双热源鞍点 | 强制 L/R 选择，提供一致方向信号 |
| **P1** | CPG 初相控制实验 | 消融 CPG 随机性对 STDP 方向的影响 |
| **P2** | 静默中继框架 V1 | 4 束全连接（L→L, L→R, R→L, R→R），让 STDP 从更多通路中选择 |
