## 三、关键发现

### 3.1 多种子统计：STDP 是确定性的

> [!IMPORTANT]
> 五个不同随机种子产出 **完全相同** 的结果：
> - w_ccw = 0.2994, w_cw = 0.0029（全部五次）
> - \|Δw\| = 0.2965（全部五次）
> - dist ≈ 21.3（全部五次）
> - DR5 = 50.0% ± 0.1%（全部五次）

**含义**：
1. STDP 的权重分化不受随机种子影响 → 由系统 **确定性结构不对称** 驱动
2. `random.seed()` 对 VariantCircuit 的行为几乎无影响 → 系统被确定性组件主导
3. T-060 (fDR5=58%) vs T-062 (fDR5=44.6%) 的差异不是"种子敏感"，可能是步数差异或其他因素

### 3.2 |Δw| = 0.2965 但 DR5 = 50.0%：权重变化不影响行为

> [!CAUTION]
> STDP 将 w_cw 从 0.30 降至 0.003（99% 削减），但全程 DR5 精确等于随机基线。
> **权重通路与行为输出之间存在断路。**

可能原因：
- `d1_phasic → spinal` 束的增益相对于热对流和 CPG 驱动而言太弱
- `spinal_ccw/cw → yaw` 的输出被硬连线的 `relay → yaw` 直接通路压过
- 饱腹后（fill=1.0）DA=0，STDP 的权重变化不再有行为表达的时机

### 3.3 T-063：对称性由结构打破，非 STDP

```
Step 10k: dA=24.6, dB=23.5  → 几乎等距
Step 20k: dA=39.3, dB=0.8   → 已到达热源 B（STDP 尚未分化）
Step 20k-130k: 定居在 B 旁边, fill=1.000
```

Body 在第 20k 步就选择了热源 B 并定居——此时 w_ccw ≈ w_cw ≈ 0.30。
**选择完全由硬连线反射弧 + 热对流 + 初始运动扰动决定。**

SDI=94.7%（200k 步中 94.7% 的时间 fill>0.8）确认系统成功解决了生存问题。

## 四、认知修正：方向性是结构，不是学习目标

### 4.1 生物学事实

没有脊椎动物出生后才学习"左侧刺激→向左转"：
- 线虫 C. elegans：302 神经元连接图谱由基因组直接编码
- 鱼类 Mauthner 细胞：对侧听觉→同侧逃逸，胚胎期完成
- 哺乳动物：脊髓反射弧出生前已髓鞘化

**方向性映射 = 基因/发育产物，不是经验学习的目标。**

### 4.2 项目架构重评

| 组件 | 生物对应 | 评价 |
|------|---------|------|
| `phasic_left → spinal_ccw` (frozen) | 基因编码的反射弧 | ✅ 正确设计 |
| `T-043 交叉抑制` (frozen, W=0.020) | 脊髓交互抑制 | ✅ 正确设计 |
| `relay → yaw` 直接通路 | 先天趋性反射 | ✅ 正确设计 |
| 热对流 `_CONV_K=0.5` | 物理环境力 | ✅ 合理物理 |
| `d1_phasic → spinal` STDP 束 | **增益调制**（非方向学习） | ⚠️ 目标需重定义 |

### 4.3 DR5 作为指标的问题

DR5 测量的是"速度矢量与温度梯度的对齐度"。在系统已经通过结构完成趋热后：
- 定居状态：body 在热源附近小范围振荡 → 速度方向随机 → DR5 ≈ 50%
- 饱腹状态：无驱动力 → 随机游走 → DR5 ≈ 50%

**DR5 ≈ 50% 不代表"没学会"——它代表"已完成任务后无需继续定向移动"。**

## 五、系统行为模型

基于全部实验数据，系统的实际行为可以分为三个阶段：

```
阶段 1 (0 ~ 20k 步): 觅食
  驱动力: 硬连线反射弧 + 热对流 + CPG 随机运动
  fill: 0.30 → 0.80
  行为: 向热源方向运动（由结构决定）
  STDP: 开始分化（DA > 0），但尚未积累到影响行为的程度

阶段 2 (20k ~ 35k 步): 到达+进食
  驱动力: 热对流主导（body 在热场内被"吸"向中心）
  fill: 0.80 → 1.00
  行为: 趋向热源中心，进食
  STDP: 快速分化（DA 脉冲 + 方向信号），但 Foraging 窗口即将关闭

阶段 3 (35k+ 步): 定居
  驱动力: 无（fill=1.0, DA=0）
  fill: 1.000（长期饱和）
  行为: 在热源附近随机振荡
  STDP: 完全冻结（DA=0）
```

**成功指标不是 DR5，而是：**
- 到达时间（T-063: 20k 步）
- 定居稳定性（SDI=94.7%）
- 生存维持（fill_min > 0.28）

## 六、STDP 的真实角色

### 当前状态
STDP 在 `d1_phasic → spinal` 束上 **确定性地、一致地** 削弱 w_cw（0.30→0.003），但这个变化不影响行为（DR5=50.0%）。

### 可能的原因
1. **增益太低**：spinal→yaw 的传导被 relay→yaw 直接通路压过
2. **窗口太短**：86% 的时间 fill>0.85（STDP 冻结），仅 14% 可学习
3. **目标错位**：STDP 在学"哪个方向好"，但方向已由结构决定

### STDP 应该学什么（参照生物学）
| 学习内容 | 生物对应 | 实现路径 |
|---------|---------|---------|
| 增益调制 | 突触效能长时程变化 | 调整 phasic→spinal 权重影响转弯强度 |
| 习惯化 | 反复无奖励→突触抑制 | STDP + DA 门控（已有） |
| 条件性增强 | 新环境/新热源→重新探索 | 热源消失后增益重置 |
| 多模态整合 | 热+前庭+能量的权重分配 | Col→Motor 束的 STDP |
