## 二、P0 修复：代码确认

P0 改动已实装在 [bundle.py](file:///D:/cell-cc/2026.7.6/nexus_v1/circuit/bundle.py) 中，三处关键改动：

### 2.1 BundleConfig 新增字段 (L112-130)

```python
da_ema_tau: float = 5000.0        # EMA τ (simulation STEPS, not seconds)
lambda_metabolic: float = 1e-6    # passive decay (replaces 0.025/step)
```

### 2.2 learn() 中的 DA_ema 更新 (L378-383)

```python
if self.config.use_eligibility_trace:
    _beta = dt / (dt + self.config.da_ema_tau)
    self._da_ema = _beta * da_concentration + (1.0 - _beta) * self._da_ema
```

### 2.3 LTP/LTD 双门控 (L405-434)

```python
# LTP = η_elig × E(t) × DA_ema  (DA_ema替代点采样DA)
ltp = eligibility_gain * E[i][j] * self._da_ema

# LTD_active = ltd_rate × dt × pre × post × DA_ema  (同样DA_ema门控)
ltd_active = eligibility_ltd_rate * dt * pre * post * self._da_ema

# Passive decay (always-on, minimal: 1e-6 replaces 0.025)
decay = lambda_metabolic * w * dt
```

> [!IMPORTANT]
> P0 的核心物理逻辑：fill 饱和→DA_raw=0→DA_ema 在 5000 步内渐衰→LTP 和 LTD_active 同步归零→权重进入"冻结保鲜态"。passive decay (1e-6) 导致 175k 步后保留 ~84%。

| # | 缺陷 | 状态 | 影响 |
|---|------|------|------|

| **2** | 梯度 1D + 参考系漂移 | 📋 P3 远期 | 学到的关联不稳定 |

### 4.1 relay→yaw 直接通路的存在（断路 B 的本质）

```
relay_left ──[frozen, thermo_to_yaw]──→ yaw_ccw   ← 硬连线方向映射
phasic_left──[STDP, d1_phasic]──→ spinal_ccw──[frozen, w=0.5]──→ yaw_ccw
```

**两条通路目标完全相同**（左热→左转）。STDP 在第二条通路上分化权重，但第一条硬连线已经在做同样的事。行为由硬连线决定，STDP 的贡献是零边际。

### 4.2 修复路径执行顺序（方案评判修订后）
