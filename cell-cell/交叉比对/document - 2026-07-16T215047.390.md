**W0/W1 已经解决了“世界没有局部状态、没有通量过程、无法守恒记账”这一根本问题**：局部热状态、相邻扩散、外部注入、环境耗散和守恒残差都已经真实运行，专项测试 5/5、回归 21/21，守恒误差约在 (10^{-13}) 量级。

但它目前只能定性为：

[
\boxed{\text{动态热世界的机制原型完成}}
]

还不能定性为：

[
\boxed{\text{可直接替换旧世界的生产模型}}
]

剩余问题不要求再次推翻 W1，而应增加一个很短的 **W1.5 接口闭合阶段**，随后进入 W2。

# 一、W1 已经解决了什么

当前结构：

[
C_i\dot T_i
===========

\sum_j G_{ij}(T_j-T_i)
+
S_i
---

\lambda_i(T_i-T_{\mathrm{amb}})
]

已经具有项目需要的基本性质：

* 世界节点保存历史状态；
* 热量只能通过局部邻接交换；
* 外部热源成为注入，而不是直接指定任意位置的温度；
* 内部交换满足成对守恒；
* 耗散有明确出口；
* 世界状态可以随历史演化。

因此，**不需要再次回到“世界应不应该有过程”这个问题上**。

此外，报告中“对称扩散还没有有向通量”这一表述需要修正。即使：

[
G_{ij}=G_{ji},
]

热流仍然是有方向的：

[
J_{ij}=G_{ij}(T_i-T_j),
\qquad
J_{ji}=-J_{ij}.
]

其符号已经表示此刻热量从哪一节点流向哪一节点。W3 的介质搬运不是为了第一次产生方向，而是为了产生：

* 非梯度驱动运输；
* 持续流向；
* 热羽流；
* 环流或对流偏置。

所以 W1 已经能够支持“局部扩散通量方向”，只是还没有“介质流动方向”。

# 二、仍需修复的四个问题

## 1. 物理量纲尚未真正闭合

当前以 `Capacitor` 表示热状态是合理的，但：

* `capacitance=1.0` 仍是项目数值约定；
* 节点没有明确体积；
* 边没有明确交换面积；
* `kappa_0/d` 省略了有限体积离散中的面积和体积因素；
* 因而它还不能同时宣称是严格按真实海水扩散率标定的物理热场。

更准确的映射应是：

[
Q_i=C_i^{\mathrm{th}}\Delta T_i,
]

其中 `Capacitor.charge` 对应局部**相对热量** (Q_i)，`Capacitor.capacitance` 对应热容量：

[
C_i^{\mathrm{th}}=\rho c_pV_i.
]

边导热系数应写成：

[
G_{ij}
======

k\frac{A_{ij}}{d_{ij}}.
]

温度更新为：

[
C_i^{\mathrm{th}}
\frac{dT_i}{dt}
===============

\sum_jG_{ij}(T_j-T_i)+S_i-D_i.
]

首轮不必立刻使用真实焦耳和开尔文，但必须明确两种模式：

* **normalized 模式**：用于机制验证；
* **physical-anchor 模式**：具有长度、时间、温度、热容量和功率换算。

当前 W1 应标注为 normalized、物理锚定候选，而不是完全完成物理标定。

## 2. Fibonacci 球壳只能作为机制测试拓扑

`build_fibonacci_shell_graph()` 适合验证：

* 局部扩散；
* 稀疏邻接；
* 守恒；
* 梯度衰减。

但它不适合作为最终世界空间，因为皮肤点本身也是球壳结构。若世界热节点也固定为同一个球壳，很容易把“世界”和“身体表面”重叠起来。

生产版世界热场应固定在**世界坐标系**中，例如：

* 稀疏三维网格；
* 固定世界点云；
* 局部自适应节点图。

身体皮肤点则在运动过程中查询自己附近的世界节点，并形成动态接触权重。

因此：

[
\boxed{
\text{W1 的球壳图保留为测试夹具，不直接作为 W2 生产拓扑}
}
]

## 3. 旧热源的“温度”不能直接作为新世界的“功率”

旧世界中的热源提供的是：

[
T_{\mathrm{surface}}
\quad\text{或}\quad
T_{\mathrm{effective}},
]

它是温度参数，不是单位时间注入的热量。

新世界需要的是：

[
P_s
===

\frac{dQ_s}{dt}.
]

所以不能直接做：

```text
node injection = effective_temperature
```

必须新增动态热源语义，例如：

```text
DynamicHeatSource
    thermal_power
    remaining_energy
    efficiency
    spatial_kernel
```

热源向邻近节点注入：

[
S_i
===

P_s,w_{si},
\qquad
\sum_iw_{si}=1.
]

这样才能保证：

[
\sum_iS_i=P_s.
]

旧热源继续服务 `InstantFieldWorld`；新热源服务 `DynamicThermalField`。两者不应共用同一输出含义。

## 4. 数值稳定不等于物理合理

报告中的长程测试没有 NaN 或发散，但节点温度达到约 489.672。

这说明数值系统能运行，却不能证明温度范围、功率和热容量合理。

显式扩散还应加入稳定条件：

[
\Delta t
\frac{\sum_jG_{ij}}{C_i^{\mathrm{th}}}
\leq \eta,
]

其中首轮可以取：

[
\eta\leq1.
]

若超过条件，不应靠调小测试输入掩盖，而应：

* 自动子步进；
* 拒绝不稳定参数；
* 或给出明确诊断。

同时增加物理边界探针，但不要直接 clamp 温度，因为硬截断会破坏守恒。应通过：

* 热源功率；
* 热容量；
* 换热系数；
* 可用能量限制；

使温度保持合理。

# 三、下一步不是 W3，而是 W1.5 → W2

## W1.5：动态热世界接口闭合

这是一个小阶段，不是重新设计世界。

需要完成四项：

### 1. 热量维度契约

新增或记录：

```text
THERMAL_LENGTH_UNIT
THERMAL_TIME_UNIT
THERMAL_TEMPERATURE_UNIT
THERMAL_ENERGY_UNIT
```

明确：

```text
Capacitor.charge       ↔ excess thermal energy
Capacitor.capacitance  ↔ thermal capacity
Capacitor.voltage      ↔ temperature deviation
```

允许低于环境温度时相对热量为负，但必须有最低绝对温度或可提取能量限制。

### 2. 数值稳定守卫

加入：

```text
max_diffusion_number()
required_substeps(dt)
```

或者等价机制。

测试必须覆盖：

* 稳定参数正常运行；
* 不稳定参数被诊断；
* 子步进前后守恒一致；
* 节点顺序改变不影响结果。

### 3. 世界固定拓扑与采样接口

新增类似：

```text
ThermalFieldLocator
```

职责仅为：

* 根据世界位置找到附近节点；
* 返回非负权重；
* 保证权重和为 1；
* 不修改场状态。

世界可以读取坐标；神经系统仍不能直接读取坐标。

### 4. 动态热源注入接口

新增：

```text
DynamicHeatSource
ThermalSourceCoupler
```

确保热源功率按空间权重守恒注入节点。

完成这四项，W1 才从独立图原型变成能与身体和热源连接的世界底座。

# 四、W2：身体—世界热交换

W2 应正式增加两个状态对象。

## 1. 皮肤热状态

每个皮肤点 (a) 保存：

[
T_a^{\mathrm{skin}},
\qquad
C_a^{\mathrm{skin}}.
]

不再直接把世界温度送进感温神经元。

## 2. 热接触机制

皮肤点与附近世界节点交换：

[
Q_{ia}
======

h_{ia}
\left(
T_i^{\mathrm{world}}
--------------------

T_a^{\mathrm{skin}}
\right).
]

世界节点更新：

[
C_i^{\mathrm{world}}\dot T_i
============================

\cdots-Q_{ia},
]

皮肤更新：

[
C_a^{\mathrm{skin}}\dot T_a
===========================

## \sum_iQ_{ia}

Q_{a\rightarrow\mathrm{core}}.
]

两边必须使用同一份 (Q_{ia})：

[
\Delta E_{\mathrm{world}}
+
\Delta E_{\mathrm{skin}}
+
E_{\mathrm{core}}
+
E_{\mathrm{dissipation}}
========================

E_{\mathrm{source}}.
]

这样身体不是“读取”世界，而是与世界交换。

感温发生元最终读取：

[
\Delta T_a^{\mathrm{skin}}
]

或其变化率，而不是：

[
T_{\mathrm{world}}(x_a)
]

的瞬时函数结果。

# 五、W2 的正确调度顺序

建议固定为：

```text
1. Body 更新位置与姿态
2. ThermalFieldLocator 计算皮肤—世界邻接权重
3. DynamicHeatSource 计算本步功率注入
4. 世界内部所有 ThermalLink 用旧状态计算通量
5. 所有 ThermalContact 用旧状态计算世界—皮肤交换
6. 汇总世界节点、皮肤节点和身体核心的全部能量变化
7. 所有状态统一更新一次
8. 感温链路读取新的皮肤热状态
9. 更新世界—身体联合热账本
```

不能先更新某个世界节点，再用新状态计算下一个节点；也不能先更新皮肤，再从已经变化的皮肤状态扣除世界能量。

# 六、W2 必须通过的测试

至少需要：

1. **等温无流**
   [
   T_{\mathrm{world}}=T_{\mathrm{skin}}
   \Rightarrow Q=0.
   ]

2. **冷热交换反向正确**
   世界热时皮肤升温、世界降温；皮肤热时反向。

3. **闭合系统守恒**
   关闭源、环境耗散和身体核心交换：
   [
   \Delta E_{\mathrm{world}}+\Delta E_{\mathrm{skin}}\approx0.
   ]

4. **动态接触守恒**
   身体移动导致接触权重变化，但不能凭空创造或消除能量。

5. **插值权重合法**
   [
   w_i\geq0,\qquad\sum_iw_i=1.
   ]

6. **热惯性**
   皮肤不能一步跳到世界温度。

7. **脱离热区后的衰减**
   离开热区后，皮肤温度应按自身热容量和核心换热逐步恢复。

8. **旧世界零回退**
   W2 首轮仍旁路运行，旧 `temperature_at()` 保持生产输出，完整回归继续通过。
