是的。P1-A 已经证明身份、版本和边类型能够落地，并且还实际发现了“旧地址可被悄悄复活”的漏洞，说明这一层不是形式化装饰。9 项专项测试及 21/21 回归通过后，地址底座可以作为 P1-B/C 的可靠前提。 

但当前 V3 对 P1-B/C 的描述仍然只是**正确的框架**，还不足以直接编码。需要先冻结一份机制和验证规格。

最关键的原因有三个：

[
\boxed{
\text{“介质搬运”与“有序热能转移”尚未严格区分}
}
]

[
\boxed{
\text{多边共享源节点必然要求快照—汇总—提交}
}
]

[
\boxed{
\text{P1-C 必须验证实际更新算子，而不只是若干结果曲线}
}
]

# 一、P1-B 首先必须决定自己究竟是什么物理机制

V3 当前使用：

[
J_e^{tr}=a_eE_i
]

并称组件为 `AdvectiveThermalLink`。

这里存在一个必须正面处理的物理区别。

## 真正的介质平流

真实介质搬运通常是：

[
J_e^{adv}
=========

\dot m_e c_pT_i,
]

介质质量也随之转移：

[
m_i^{n+1}
=========

m_i^n-\dot m_e\Delta t,
]

[
m_j^{n+1}
=========

m_j^n+\dot m_e\Delta t.
]

于是节点热容：

[
C_i=m_ic_p
]

也会变化。

如果只搬走热能而不搬走质量和热容，它并不是严格意义上的介质平流。

## 当前项目适合的最小机制

当前世界仍处于 normalized 模式，也没有介质质量状态。因此现阶段更准确的机制应是：

[
\boxed{
\text{外部驱动的有序热能转移}
}
]

建议把组件改名为：

```text
OrderedThermalEnergyLink
```

或：

```text
OrderedHeatTransportLink
```

而不是 `AdvectiveThermalLink`。

它表示某个外部载流过程、传送过程或理想化流动，使热能从一个局部储能仓有序进入另一个储能仓；但暂不声称介质质量也被模拟。

以后进入 physical-anchor 模式并加入：

* 介质质量；
* 比热；
* 流量；
* 体积；
* 压力或流动驱动；

再升格为真正的 advection。

# 二、P1-B 的守恒变量必须是“储存能量”，不能直接是温度

定义节点的规范状态：

[
u_i
===

E_i^{stored}\geq0.
]

应直接读取 `ThermalCell` 内部账本所使用的储能状态，例如电容 charge，而不是从公开温度临时重算一个可能具有任意零点的量。

有序边：

[
e=(i,j)
]

在第 (n) 步的功率：

[
p_e^n
=====

a_e^n u_i^n,
\qquad
a_e^n\geq0.
]

单步转移量：

[
q_e^n
=====

p_e^n\Delta t.
]

节点贡献：

[
\Delta u_i^{tr}
===============

-\sum_{e:\operatorname{tail}(e)=i}q_e
+
\sum_{e:\operatorname{head}(e)=i}q_e.
]

每条边单独满足：

[
\boxed{
\Delta u_{\operatorname{tail}}^e
+
\Delta u_{\operatorname{head}}^e
=0.
}
]

这使有序边的热能转移账本独立于温度读出方式。

## 必须冻结能量零点

因为：

[
p_e=a_eu_i
]

依赖 (u_i) 的绝对零点。

如果实际代码使用的是任意平移后的规范化温度：

[
T_i'=T_i+c,
]

那么：

[
a_iC_iT_i'
\neq
a_iC_iT_i.
]

因此 P1-B 必须声明：

[
\boxed{
u_i\text{ 是有固定零点的储存能量状态，}
\text{不是任意偏置的温度信号。}
}
]

否则有序传输结果会依赖温标零点，这是结构性错误。

# 三、P1-B 必须使用统一快照，禁止逐边即时扣除

假设节点 (i) 有两条有序出边：

[
e_1=(i,j),
\qquad
e_2=(i,k).
]

正确计算是从同一个 (t_n) 快照得到：

[
q_1
===

a_1u_i^n\Delta t,
]

[
q_2
===

a_2u_i^n\Delta t.
]

然后统一提交：

[
u_i^{n+1}
=========

u_i^n-q_1-q_2+\cdots.
]

错误实现是：

1. 先扣除 (q_1)；
2. 再用已经减少的 (u_i) 计算 (q_2)。

这会导致边遍历顺序改变物理结果。

所以：

[
\boxed{
\text{P1-B 必须是 snapshot→aggregate→commit，}
\text{不能逐边 step。}
}
]

V3 已经列出的两阶段触发条件中，P1-B 会确定命中：

* 多个独立状态容器；
* 多条搬运边争夺同一源节点；
* 结果可能依赖应用顺序。

因此不应再写“可能需要计划—提交”。

更精确的裁定应是：

> 不建设全项目通用 `PhysicalStepPlan`，但 P1-B 必须建设一个范围受限的不可变 `ThermalTransportPlan`。

# 四、P1-B 的最小对象结构

## 1. 有序边

```python
@dataclass(frozen=True)
class OrderedThermalEnergyLink:
    identity: OrderedEdgeIdentity
    rate_per_time: float
```

约束：

[
a_e\in[0,\infty),
]

且必须为有限数。

首版不允许：

* 隐藏 callback；
* 根据坐标自动计算；
* 根据“朝向”选择端点；
* 在 `flux()` 中直接修改节点；
* 边自身偷偷保存上一步剩余能量。

它只根据快照返回：

[
p_e=a_eu_{\rm tail}.
]

## 2. 不可变计划

```python
@dataclass(frozen=True)
class ThermalTransportPlan:
    dt: float
    registry_revision: int
    state_revision: int
    edge_transfers: tuple[...]
    node_net_currents: Mapping[StructuralAddress, float]
    stability_report: JointStabilityReport
    ledger_preview: TransportLedgerPreview
```

计划应记录：

* 每条边稳定 UID；
* tail/head 地址与版本；
* 快照时的 tail 储能；
* (a_e)；
* 功率 (p_e)；
* 能量 (q_e)；
* 每节点总入流和总出流；
* 联合稳定性结果。

## 3. 两个阶段

```text
prepare_thermal_transport_step(...)
apply_thermal_transport_plan(...)
```

`prepare` 必须是纯函数或纯只读过程。

`apply` 必须：

* 只接受当前版本的计划；
* 只能执行一次；
* 拒绝 stale plan；
* 拒绝 double apply；
* 提交区不再做查找、参数计算或用户回调。

提交区应只剩下经过验证的基础状态写入。若提交区仍有可能抛出可预见异常，就需要保存快照并提供回滚。

# 五、P1-B 的联合稳定性需要补入环境泄漏

V3 当前使用：

[
\eta_i^{joint}
==============

\Delta t
\left[
\frac{
\sum_j\kappa_{ij}
+
\sum_sH_{is}
}{C_i}
+
\sum_{e:\operatorname{tail}(e)=i}a_e
\right]
\leq1.
]

它已经正确合并扩散、接触和有序传输。

但如果世界节点存在与环境之间的线性泄漏：

[
J_i^{loss}
==========

G_i^{env}(T_i-T_{env}),
]

它同样是一个出流通道。

完整预算应为：

[
\boxed{
\eta_i^{joint}
==============

\Delta t
\left[
\frac{
\sum_j\kappa_{ij}
+
\sum_sH_{is}
+
G_i^{env}
}{C_i}
+
\sum_{e:\operatorname{tail}(e)=i}a_e
\right]
\leq1.
}
]

若泄漏使用的是直接衰减率：

[
\dot u_i=-\lambda_iu_i,
]

则加入：

[
+\lambda_i.
]

不能让扩散、接触和搬运联合核算，却把泄漏留在预算外。

# 六、P1-B 应拆成四个小 Gate

## P1-B0：定义冻结

只出定义报告，不编码。必须回答：

* 搬运的是储存能量还是介质质量？
* 为什么现阶段不能叫真实 advection？
* 储存能量的零点是什么？
* (a_e) 的单位和来源是什么？
* 外部维持有序传输所需的驱动功是否属于当前账本？

建议首轮将：

[
a_e=\frac1{\tau_e}
]

其中 (\tau_e) 是标定的局部转移时间常数。

不允许为了让测试好看直接填一个 `0.1`。

## P1-B1：单边纯机制

仅两个世界节点，无扩散、无接触、无热源。

离散解析结果：

[
u_i^{n+1}
=========

(1-a\Delta t)u_i^n,
]

[
u_j^{n+1}
=========

u_j^n+a\Delta t,u_i^n.
]

因此：

[
u_i^n
=====

(1-a\Delta t)^nu_i^0.
]

连续参考解：

[
u_i(t)
======

u_i(0)e^{-at}.
]

必须同时通过一步解析比对和多步收敛比对。

## P1-B2：同源多边竞争

一个 tail，两条 head：

[
i\to j,
\qquad
i\to k.
]

验证：

[
q_{ij}=a_{ij}u_i^n\Delta t,
\qquad
q_{ik}=a_{ik}u_i^n\Delta t.
]

调换边的存储和遍历顺序，输出完全相同。

这一 Gate 通过后，才能证明快照—汇总语义真正成立。

## P1-B3：计划与故障语义

测试：

* 地址过期；
* 边版本过期；
* plan 生成后节点被重建；
* plan 重复提交；
* plan 生成后状态被其他步骤修改；
* 合并出流超预算；
* `rate=NaN/inf/negative`；
* prepare 中异常。

所有失败必须满足：

[
\Delta u=0.
]

# 八、P1-C 的验收矩阵

## C1：退化一致性

令所有有序边：

[
a_e=0.
]

完整 P1 执行轨迹必须与冻结的 P0/P1-0 轨迹一致：

[
u_{\mathrm{P1}}(t)
==================

u_{\mathrm{P0}}(t)
]

在浮点容差内逐步相等，而不只是最终温度接近。

这证明新增机制关闭时没有改变旧世界。

## C2：三级账本

### 边级

有序边：

[
R_e
===

\Delta u_{\mathrm{tail}}^e
+
\Delta u_{\mathrm{head}}^e
=0.
]

互易边也应记录一次真实转移的两端贡献。

### 节点级

[
R_i
===

## \Delta u_i

\left(
q_i^{source}
+
q_i^{diff}
+
q_i^{contact}
+
q_i^{transport}
---------------

q_i^{loss}
\right).
]

### 全局

[
R_G
===

## \sum_i\Delta u_i

E_{\mathrm{source,drawn}}
+
E_{\mathrm{loss}}.
]

容差不应只用固定 (10^{-9})，应采用尺度相关形式：

[
\boxed{
|R|
\leq
\varepsilon_{\mathrm{abs}}
+
\varepsilon_{\mathrm{rel}}
\max
\left(
1,
\sum_k|q_k|
\right).
}
]

否则在能量尺度改变后，固定阈值可能过松或过严。

## C3：组合失稳拒绝

必须构造一个场景：

* 单独扩散稳定；
* 单独接触稳定；
* 单独每条有序边稳定；
* 但所有出流相加后：

[
\eta_i^{joint}>1.
]

系统必须在任何状态修改前拒绝。

这项是 P1-0 教训在 P1-C 中的真正继承。

## C4：图同构

P1-A 已证明基础热图满足地址重命名同构。

P1-C 必须在加入：

* 有序边；
* 接触边；
* source；
* skin；
* 账本；

之后重新验证：

[
\phi(F_{\mathcal G}(x))
=======================

F_{\phi(\mathcal G)}(\phi(x)).
]

P1-A 的测试不能自动替代 P1-C，因为新机制引入了新的地址解析和账本路径。

## C5：一步矩阵审计

冻结：

* 拓扑；
* (a_e)；
* (\kappa)；
* (H)；
* 泄漏参数。

以储能向量：

[
u^{n+1}=M_Eu^n+q_E
]

表示实际更新。

测试：

[
M_{E,ij}\geq0,
]

封闭系统：

[
\mathbf1^\top M_E=\mathbf1^\top.
]

有泄漏时：

[
\mathbf1^\top M_E
\leq
\mathbf1^\top,
]

缺口应精确对应泄漏项。

然后以：

[
T=C^{-1}u
]

构造：

[
M_T=C^{-1}M_EC
]

并验证：

[
C^\top M_T=C^\top.
]

V3 对能量态和温度态的区分是正确的，应保留。

还需增加一个关键检查：

[
u_{\mathrm{runtime}}^{n+1}
\approx
M_Eu_{\mathrm{runtime}}^n+q_E.
]

否则矩阵可能自身守恒，却并不代表真实代码的更新算子。

## C6：时间步收敛

单边机制可使用连续解析解：

[
u_i(t)=u_i(0)e^{-at}.
]

运行：

[
\Delta t,\quad
\frac{\Delta t}{2},\quad
\frac{\Delta t}{4}.
]

定义误差：

[
e_{\Delta t}
============

|u_{\Delta t}(T)-u_{\mathrm{exact}}(T)|.
]

显式 Euler 应表现出近似一阶收敛：

[
\frac{e_{\Delta t}}
{e_{\Delta t/2}}
\approx2.
]

联合网络不必设置脆弱的精确阶数阈值，但至少要求误差随步长单调下降。

## C7：冻结段浸泡

关闭热源，固定 (a_e)，固定拓扑：

[
u^{n+1}=M_Eu^n.
]

对于单一连通守恒分量，应有一个守恒特征值：

[
\lambda_1=1.
]

其余模态：

[
|\lambda_k|<1.
]

估计：

[
\tau_{\mathrm{slow}}
====================

-\frac{\Delta t}{\ln|\lambda_2|}.
]

运行：

[
10\tau_{\mathrm{slow}}.
]

验证：

* 总能量不漂移；
* 所有储能非负；
* 无 NaN/inf；
* 局部与全局账本持续闭合；
* 状态趋向矩阵预测的稳态；
* 不发生因端点顺序导致的周期振荡。

需要选择具有正自环的参数：

[
\eta_i^{joint}<1,
]

而不是恰好等于 1，否则离散系统可能出现周期性。

## C8：驱动变化段

热源开启或使 (a_e(t)) 平滑变化，例如：

[
a_e(t)
======

a_0
\left[
1+\beta\sin(\omega t)
\right],
\qquad
0\leq\beta<1.
]

这里不使用固定 (\lambda_2)。

只验证：

* 能量有界；
* 无负值；
* 无 NaN；
* 每步联合稳定性通过；
* 所有变化能追溯到源项或边；
* 驱动停止后，能够进入冻结段并收敛。

使用平滑变化比人工分段的 `a=0→1→0` 更适合当前目的，因为 P1-C 不是事件切分测试。
