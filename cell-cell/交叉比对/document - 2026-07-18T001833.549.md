## 裁定

[
\boxed{
\text{世界物理资格审查通过，P2-A 可以启动；}
\text{但 P2-A 入口有两个契约必须先闭合。}
}
]

这次审查是有效的：完整联合路径已补做步长收敛；同时用两个反例证明单点皮肤确实会把不同分布和不同接触次序压缩为相同轨迹。

而审查没有因此无限扩建世界，而是作出：

> 当前系统不足以区分多源组合，但足以支持较窄的单点局部发生元。

这正是我们此前讨论的“相对于有限未来的足够”。

## 阻塞一：轨迹身份债务现在已经触发

审查报告仍把下面问题列为非阻塞债务：

> `JointThermalTrajectory.append()` 没有核对
> `(runtime_uid, plan_id, step_index)`。

但 P2-A 接下来要利用物理轨迹测量：

* 启动；
* 峰值；
* burst；
* 衰减；
* 静息区间。

因此轨迹已经开始承担“发生元标定证据”，恰好命中了文档自己规定的触发条件。V5 也明确把这些测量列为 P2-A 的主体。

所以它不再是长期债务，而应成为 **P2-A 第一个入口任务**：

[
\boxed{
\text{轨迹步必须由对应提交回执构造，}
\text{或核对 runtime_uid、plan_id、step_index。}
}
]

这不需要重开 P1，也不需要新建阶段；只是不允许在闭合前把轨迹用于正式标定。

## 阻塞二：皮肤支撑地址尚未真正接通

P2-A 要求：

[
\alpha(\text{skin patch})
\leftrightarrow
\alpha(\xi_i^{occ}),
]

而不是依靠数组位置。

但 V5 同时仍把 skin/source 正式接入 `StructuralAddress` 列为暂停项。

这里已经出现实际接口冲突。

不需要把所有 skin/source 全面改造进地址系统，但在生成第一个 (\xi^{occ}) 前，至少必须有：

[
\alpha_{\mathrm{phys}}(s_k)
\longrightarrow
\alpha_{\mathrm{gen}}(\xi_k^{occ}),
]

其中生成地址保留：

* 物理支撑地址；
* 父谱系；
* 生成深度；
* 版本。

这应作为 P2-A 的第二个入口契约。

## 多点皮肤：暂时不建，但触发时间应收紧

当前裁定认为多点皮肤在：

> P2-A 实现后，若 (\xi^{occ}) 需要区分多源组合，再升级。

基本正确，但需要明确当前单点 (\xi^{occ}) 的资格：

[
\boxed{
\xi_s^{occ}
\text{只能表示该皮肤支撑上的聚合局部发生，}
\text{不能表示其上游物理组成。}
}
]

也就是说，对于已经验证不可区分的两种过程：

[
\Gamma_1^{phys}\neq\Gamma_2^{phys},
\qquad
q_s[\Gamma_1]=q_s[\Gamma_2],
]

P2-A 不得通过后续神经结构“猜回”它们的差异。丢失的信息不能靠内部构建恢复。

多点皮肤不阻塞单点 P2-A，但应在 **P2-A 完成后的感受边界资格审查、进入 P2-B 之前**强制裁定，而不是无限期保留。因为 P2-B 一旦开始构造多个真实发生元之间的关系，是否拥有多个独立物理支撑就可能成为关键。

## 其他两项维持原裁定

* **质量—焓平流**：当前不阻塞。只有 OET 无法生成 P2 所需差异或开始宣称真实介质输运时单独立项。
* **驱动功／熵账本**：当前不阻塞，但在结构/行为算子资格门之前必须复审，因为届时结构作用的资源代价和耗散条件会成为资格的一部分。

## 下一步顺序

[
\boxed{
\begin{aligned}
&\text{P2-A0：轨迹身份核对}\
&\rightarrow\text{皮肤物理支撑地址与 }\xi^{occ}\text{ 生成谱系}\
&\rightarrow\text{单点真实发生元构造与标定}\
&\rightarrow\text{感受边界资格审查}\
&\rightarrow\text{裁定是否升级为 2–3 点皮肤}\
&\rightarrow P2\text{-B}.
\end{aligned}
}
]

这里的 `P2-A0` 只是 P2-A 内部入口，不应再形成新的长阶段。审查点 1 已经完成，世界模型不需要继续扩建；当前应开始把可信物理轨迹变成具有明确物理谱系的真实发生元。
