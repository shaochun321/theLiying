## 一、当前阶段不应再使用“传感器”作为核心术语

P2-A 当前真正需要的不是硬件传感器，而是：

[
\boxed{\text{局部感受转导结构}}
]

建议将链路改写为：

[
\boxed{
\text{世界物理状态}
\rightarrow
\text{皮肤局部物理支撑}
\rightarrow
\text{感受转导结构}
\rightarrow
\text{基础生成元}
\rightarrow
\xi_i^{\mathrm{occ}}
}
]

这与总纲现有的：

[
\text{world}\rightarrow\text{contact}\rightarrow
\text{skin state}\rightarrow\xi_i^{\mathrm{occ}}
]

是一致的；P2-A0 已经给皮肤支撑建立了稳定地址，并准备让发生元地址引用其物理父支撑。 

---

# 二、四个对象的严格定义

## 1. 皮肤物理支撑

记为：

[
s_i^{\mathrm{skin}}.
]

它是世界与生成元之间真正承受物理变化的局部结构。

当前软件实现中，它可以是：

* `SkinThermalState`；
* 一个局部 `ThermalCell`；
* 三节点皮肤图中的某个节点；
* 与世界节点存在接触交换的局部状态。

其状态写为：

[
x_i^{\mathrm{skin}}(t)
======================

\left(
q_i(t),T_i(t),J_i^{\mathrm{contact}}(t),\ldots
\right).
]

它有物理地址：

[
\alpha_{\mathrm{phys}}
\left(
s_i^{\mathrm{skin}}
\right).
]

这是“哪里真正承受了物理作用”。

---

## 2. 感受转导结构

记为：

[
\mathcal D_i.
]

它把皮肤局部物理状态变成基础生成元可以消费的连续驱动：

[
\boxed{
u_i(t)
======

\mathcal D_i
\left[
x_i^{\mathrm{skin}}(t)
\right].
}
]

当前第一版中，它不必是一个复杂动态系统，甚至可以只是明确的耦合关系：

[
u_i(t)=\kappa_i q_i(t)
]

或者：

[
u_i(t)
======

\kappa_i
\bigl(
T_i(t)-T_i^{\mathrm{rest}}
\bigr).
]

这里的 (u_i) 是**基础生成元输入端口量**，不是温度、焦耳或安培天然等同后的统一量。

感受转导结构必须满足：

[
\begin{aligned}
&\text{局部：只读取其支撑允许访问的物理状态；}\
&\text{因果：不能读取未来轨迹；}\
&\text{连续：不替生成元切分事件；}\
&\text{无语义：不输出“热、冷、危险、左侧”等标签；}\
&\text{可追溯：输出能回接到皮肤支撑地址；}\
&\text{可替换：以后可由真实硬件实现同一接口。}
\end{aligned}
]

它不产生自然单位，也不产生事件。

---

## 3. 基础生成元

基础生成元记为：

[
\mathcal G_i.
]

它接收连续驱动并维持自身内部状态：

[
\dot z_i
========

F_i(z_i,u_i),
]

然后产生发生输出：

[
\xi_i^{\mathrm{occ}}
====================

H_i(z_i).
]

它负责：

* 蓄积；
* 内部传播；
* 阈值跨越；
* 群体闭合；
* 耗散；
* 退出；
* 重新武装；
* 在相同当前输入下保留不同历史响应。

因此：

[
\boxed{
\mathcal D_i\neq\mathcal G_i.
}
]

(\mathcal D_i) 只负责把物理状态耦合进来；(\mathcal G_i) 才负责形成项目内部的发生过程。

---

## 4. 自然单位候选

自然单位既不是皮肤状态，也不是转导输出：

[
x_i^{\mathrm{skin}}\neq\mathfrak u_i,
\qquad
u_i\neq\mathfrak u_i.
]

自然单位候选是基础生成元完成一次自身闭合：

[
\boxed{
\mathfrak u_i^k
===============

\operatorname{Close}
\left(
\mathcal G_i,W_{i,k}
\right).
}
]

因此完整关系为：

[
\boxed{
x_i^{\mathrm{skin}}
\xrightarrow{\mathcal D_i}
u_i
\xrightarrow{\mathcal G_i}
\xi_i^{\mathrm{occ}}
\xrightarrow{\mathrm{闭合判据}}
\mathfrak u_i^k.
}
]

---

# 三、硬件传感器应怎样定义

未来真实硬件温度传感器可以记为：

[
S_i^{\mathrm{hw}}.
]

它是感受转导结构的一种物理实现：

[
S_i^{\mathrm{hw}}
\subset
\mathcal D_i^{\mathrm{hw}}.
]

例如：

[
T_i^{\mathrm{physical}}
\rightarrow
R_i
\rightarrow
V_i
\rightarrow
u_i.
]

但这只是未来接口后端之一。

统一合同可以写成：

[
\mathcal D_i:
x_i^{\mathrm{skin}}
\longrightarrow
u_i,
]

其当前软件实现为：

[
\mathcal D_i^{\mathrm{sim}},
]

未来硬件实现为：

[
\mathcal D_i^{\mathrm{hw}}.
]

两者满足同一输出合同：

[
u_i(t)\in\mathcal U_i^{\mathrm{in}}.
]

因此，当前完全不需要 GPIO、ADC、I²C 或真实热敏电阻。硬件只是未来替换 (\mathcal D_i^{\mathrm{sim}}) 的另一种物理实现，而不是本轮 P2-A 的默认前提。

# 四、“三点传感器阵列”应改名

之前说：

> 三个传感器分别驱动三个基础生成元。

这很容易被理解为三块真实硬件。

当前准确表述应是：

[
\boxed{
\text{三个局部皮肤物理支撑}
+
\text{三个局部感受转导端口}
+
\text{三个基础生成元实例}.
}
]

即：

[
s_1^{\mathrm{skin}}
\xrightarrow{\mathcal D_1}
\mathcal G_1,
]

[
s_2^{\mathrm{skin}}
\xrightarrow{\mathcal D_2}
\mathcal G_2,
]

[
s_3^{\mathrm{skin}}
\xrightarrow{\mathcal D_3}
\mathcal G_3.
]

当前三点结构可以完全由：

[
\texttt{ThermalFieldGraph}
]

中的三个节点和两条热连接实现：

[
s_1-s_2-s_3.
]

这三个节点是皮肤物理状态节点，不是三个外接传感器。

# 五、感受转导结构是不是基础生成元的一部分

这里需要确定一个层级口径。

## 工程组件口径

在代码模块中：

[
\mathcal D_i
\quad\text{与}\quad
\mathcal G_i
]

应分开。

原因是：

* 可以独立标定输入范围；
* 可以更换软件或硬件后端；
* 可以测试生成元是否依赖特定传感形式；
* 可以防止转导层偷偷执行事件检测。

## 完整物理发生链口径

当谈论“一个已经接入世界的基础生成元实例”时，可以写成：

[
\widehat{\mathcal G}_i
======================

\left(
s_i^{\mathrm{skin}},
\mathcal D_i,
\mathcal G_i
\right).
]

其中：

* (\mathcal G_i) 是基础生成元核心；
* (\widehat{\mathcal G}_i) 是接入真实或拟真物理后的完整发生链。

这样可以避免之前的两个极端：

[
\text{传感器就是生成元}
]

和：

[
\text{生成元与物理支撑完全无关}.
]

# 六、P2-A 当前的准确对象

当前 P2-A 不应写成：

[
\text{安装三个温度传感器}
\rightarrow
G_{10}.
]

而应写成：

[
\boxed{
\begin{aligned}
&\text{建立三点局部皮肤物理状态图};\
&\text{为每个皮肤点定义连续局部转导 }\mathcal D_i;\
&\text{将 }u_i(t)\text{接入现有基础生成元结构};\
&\text{测量生成元的启动、闭合、退出、恢复和频率};\
&\text{生成带皮肤父地址的 }\xi_i^{\mathrm{occ}}.
\end{aligned}
}
]

第一轮的物理链是：

[
\boxed{
\texttt{ThermalFieldGraph}
\rightarrow
\texttt{SkinThermalState}
\rightarrow
\mathcal D_i^{\mathrm{sim}}
\rightarrow
\mathcal G_i
\rightarrow
\xi_i^{\mathrm{occ}}.
}
]

不涉及外接硬件。

# 七、建议冻结的术语表

| 原模糊词  | 当前正式术语    | 定义                        |
| ----- | --------- | ------------------------- |
| 传感器节点 | 皮肤物理支撑    | 承受局部物理过程的状态节点             |
| 传感器接口 | 感受转导结构    | 将局部物理状态连续映射为生成元驱动         |
| 真实传感器 | 硬件转导实现    | 未来实现 (\mathcal D_i) 的物理器件 |
| 十神经元  | 基础生成元核心   | 负责内部动力学与发生闭合              |
| 传感器脉冲 | 禁止使用      | 传感器或转导层不直接生成单位脉冲          |
| 自然单位  | 生成元闭合单位候选 | 生成元完成一次触发—退出—重新武装过程       |

## 最终修正

此前方案中的：

[
\text{传感器}
\rightarrow
G_{10}
]

应统一替换为：

[
\boxed{
\text{局部皮肤物理状态}
\xrightarrow{\mathcal D_i}
\text{生成元连续输入}
\xrightarrow{\mathcal G_i}
\text{发生闭合}.
}
]

当前“传感器”只应在讨论未来硬件实现时出现。P2-A 第一版的对象是**软件中的局部感受转导结构**，不是外接真实传感器。
