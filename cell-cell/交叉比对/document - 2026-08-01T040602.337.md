这版可以正式裁定：

[
\boxed{\text{P2-B1X2a' 与 P2-B1X2b 可以冻结通过。}}
]

它已经完成了三项关键修正：

* (\kappa^{10}=(B_{\rm in},C^{10},S_{\rm dyn},B_{\rm out}))，明确“十”指最低功能核心规模；
* (\ell_{\rm gen}) 与 (\ell_{\rm out}) 完全分离，R1是否存在不依赖其是否接入DA；
* `RelationOccurrence` 被重新定型为
  [
  \Pi_\tau!\left(\mathfrak R_{AB}^{(1)}\right),
  ]
  即R1的时间投影和谱系审计，而非完整关系本体。

`relation_type` 与 `link_type` 的区分也是一次真正有价值的修复：

[
\text{检测到什么}
\neq
\text{使用什么机制检测}.
]

这为将来同一种关系由不同物理链路实现，或者同一种链路机制检测不同方向关系，留下了正确接口。

# 当前唯一阻塞：X2d不能只定义一个区间 (I)

报告目前计划用：

[
\texttt{UNBOUND}
\rightarrow
\texttt{SUPPORTED}
\rightarrow
\texttt{RELAXING}
\rightarrow
\texttt{CLOSED}
]

形成 R1 的物理区间，并让 X2c 在这个区间上计算：

[
|Y|_{2,I}.
]

方向是对的，但这里存在一个关键问题：

> 在 (\varnothing)、A-only、B-only、gen-cut 条件下，R1可能根本不会进入 `SUPPORTED`，因而没有自己的R1区间。

那么以下表达式就没有共同定义域：

[
Y_{A\ell B}
-----------

## Y_A

Y_B
+
Y_\varnothing.
]

不能让每个条件各自使用不同长度、不同起点的区间，否则二阶差分比较的是不同物理过程。

因此至少需要区分两个区间。

---

# 一、R1本体区间

定义：

[
\boxed{
I_{R1}
======

[s_{\rm enter}^{R1},s_{\rm closed}^{R1}]
}
]

它属于R1本体，负责回答：

> 这个R1结构块从什么时候形成，到什么时候仍属于同一次关系过程？

它只由：

* 两个父D1实例；
* (\ell_{\rm gen}) 的物理状态；
* relation collector；
* trace衰减和残响；
* 父谱系是否改变；

决定。

不应由：

* `RelationOccurrence`是否已经写入；
* DA电流是否出现；
* (\ell_{\rm out}) 是否存在；

来决定。

状态可以是：

```text id="8t52v8"
UNBOUND
   ↓ 两个父实例开始共同支撑ℓ_gen
SUPPORTED
   ↓ 共同支撑解除，但残余仍属于原关系
RELAXING
   ↓ 生成链路残余退出基线带
CLOSED
```

因此：

[
I_{R1}
======

I_{\rm supported}
\cup
I_{\rm relaxing}.
]

这个区间用于：

* R1实例身份；
* 同一区间只生成一个R1；
* 判断残余振荡属于旧关系还是新关系；
* 最终替代或补充当前父实例四元组去重。

# 二、X2c统一测量区间

另外定义：

[
\boxed{
W_Y^\star
=========

[s_{\rm measure,start},s_{\rm measure,end}]
}
]

它不是新的R1本体，而是反事实实验的统一观测窗。

最合适的产生方法是：

1. 先运行完整条件 (A\ell B)；
2. 由这次真实物理过程得到 (I_{R1}^{A\ell B})；
3. 再观察 (\ell_{\rm out}) 的电流何时回到基线带；
4. 得到统一窗口：
   [
   W_Y^\star
   =========

   [s_{\rm enter}^{R1},
   s_{\rm relax}^{Y}];
   ]
5. 对所有反事实条件使用完全相同的窗口。

也就是：

[
\boxed{
W_Y^\star
\text{由完整物理过程后验产生，}
\text{随后用于所有匹配干预实验。}
}
]

这样仍然不是硬编码固定50步，而是由真实过程决定起止。

随后：

[
K_{R1}
======

\left|
Y_{A\ell B}
-----------

## Y_A

Y_B
+
Y_\varnothing
\right|_{2,W_Y^\star}.
]

[
K_{\rm gen}
===========

\left|
Y_{A\ell B}
-----------

Y_{A\ell_{\rm gen-cut}B}
\right|_{2,W_Y^\star}.
]

[
K_{\rm out}
===========

\left|
Y_{A\ell B}
-----------

Y_{A\ell_{\rm out-cut}B}
\right|_{2,W_Y^\star}.
]

所有轨迹使用相同：

* 初始状态；
* 外部驱动协议；
* 采样步；
* 起止区间；
* 下游目标节点；
* 数值精度。

# 三、为什么R1区间和Y窗口不能完全等同？

因为R1本体不包含 (\ell_{\rm out})。

可能发生：

```text id="zrmkyd"
R1生成链路已经闭合
        ↓
relation→DA bundle仍有电流尾部
        ↓
Y尚未回到基线
```

所以：

[
s_{\rm closed}^{R1}
\le
s_{\rm relax}^{Y}.
]

R1区间回答“关系什么时候存在”；Y窗口回答“这次关系造成的下游作用什么时候测完”。

混在一起，就会再次让R1的存在依赖输出能力，这与X2a'刚完成的修正相冲突。

因此建议 X2d 实现两个对象：

```text id="grgg7r"
R1PhysicalInterval
├── s_enter
├── s_support_end
├── s_closed
└── state

R1MeasurementWindow
├── reference_r1_interval_id
├── s_start
├── s_end
├── baseline_band
└── target_address
```

# 四、X2d的进入、维持、退出条件

第一版可以冻结如下。

## `UNBOUND → SUPPORTED`

必须同时满足：

1. 父A实例已确定；
2. 父B实例已确定；
3. (\ell_{\rm gen}) 获得两父实例的共同物理支撑；
4. relation collector首次进入响应带。

写成：

[
S_A(s)>0,\qquad
S_B(s)>0,\qquad
C_{\rm rel}(s)\in\mathcal B_{\rm response}.
]

这里的 (S_A,S_B) 是实际链路状态，不是数据库标志。

## `SUPPORTED → RELAXING`

满足任一：

* 两父共同支撑解除；
* collector退出响应带；
* 当前父谱系中至少一个失去继续支撑资格；
* 生成链路进入纯残响阶段。

但不要因为新epoch出现，就把新父实例并入旧区间；新epoch只能开始新的候选区间。

## `RELAXING → CLOSED`

要求：

* trace状态返回基线带；
* relation collector返回基线带；
* 在迟滞区间内没有重新取得同一父实例共同支撑；
* 旧残响不能再触发新的R1实例。

这样 X1e 的去重防线可以继续保留，但成为INFRA安全层；X2d则提供正式的物理语义。
