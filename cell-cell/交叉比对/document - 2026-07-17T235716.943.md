**不应把三项各自立即扩展成独立工程阶段**。

更合适的是：

[
\boxed{
\text{在一次“世界物理资格审查”中分别裁定，}
\text{只有被后续阶段证明必要的项目才单独立项。}
}
]

V4 更新后，P1 已经整体完成，其定位也被明确限制为“未来结构/行为算子能够作用其上的可信物理过程底座”，而不是完整现实热力学模型；同时，世界物理资格审查已经正式触发。 

## 三项应当分别裁定

| 项目      | 当前是否必须实现  | 触发条件                                     |
| ------- | --------- | ---------------------------------------- |
| 质量—焓平流  | 暂不必须      | OET 无法产生 P2 所需的真实过程差异，或项目开始宣称真实介质输运      |
| 多点皮肤    | 可能较早触发    | 单点皮肤压平了发生差异，导致 (\xi^{occ}) 无法形成足够的局部关系区分 |
| 驱动功／熵账本 | 暂不阻塞 P2-A | 开始评价完整热力学资格、行为代价或外部驱动与结构维持关系时            |

### 1. 质量—焓平流：只能作为独立升级

当前 OET 只转移统一基线以上的过剩热量：

[
J_e^{oet}=a_eu_{\mathrm{tail}}^+.
]

它没有质量、比热、质量流率和焓状态。因此，一旦升级，就不是给现有类增加几个字段，而是更换物理机制：

[
J_e^{adv}
=========

\dot m_e h_e
\approx
\dot m_e c_pT.
]

这会影响：

* 节点质量及热容；
* 输运守恒；
* 稳定性条件；
* 驱动来源；
* 熵产生；
* 联合账本。

所以**若触发，必须单独讨论和实施**，不能混入 P2-A 小修。

但它目前不是进入 P2-A 的先决条件。当前问题只是：现有世界能否产生连续、可区分、可追踪的真实皮肤过程，而不是它是否完整模拟流体。

### 2. 多点皮肤：应在 P2-A 中用反例决定

多点皮肤与焓平流不同，它可能直接影响真实发生元。

单点皮肤把多个世界耦合压缩成一个状态：

[
{J_{1s},J_{2s},\ldots}
\longrightarrow
q_s.
]

如果两个不同物理过程在单点状态中变成相同轨迹：

[
\Gamma_1^{phys}\neq\Gamma_2^{phys},
\qquad
q_s[\Gamma_1]\approx q_s[\Gamma_2],
]

那么后续 (\xi^{occ}) 不可能恢复已经丢失的差异。此时多点皮肤就是阻塞项。

因此现在不需要直接建设大规模皮肤，而应在世界资格审查或 P2-A 入口做一个最小对照：

* 同总能量、不同接触分布；
* 同峰值、不同接触次序；
* 单点皮肤是否产生不可区分轨迹。

若不可区分性会破坏 P2-A，则升级到最小多点结构，例如 2–3 个物理支撑点；不应直接扩展到 64 点。

### 3. 完整驱动功账本：当前可以保留资格边界

OET 可以把热量从较冷节点搬到较热节点，因此它不是被动扩散。其外部驱动力尚未建模。

当前只要明确：

[
\texttt{transport_drive_mode}
=============================

\texttt{exogenous_normalized},
]

就可以承认：

* 热量两端守恒；
* 驱动功没有闭合；
* 不宣称完整第二定律资格。

这足以支撑 P2-A 的最低目的。

但在以下情形出现时，驱动功账本必须单独立项：

* 比较不同行为算子的能量代价；
* 判断结构是否真正通过物理过程维持或再入；
* 把耗散成本纳入算子可达性；
* 宣称系统具有完整热力学闭合；
* 外部驱动差异本身开始影响关系确认。

这与新理论尤其相关：未来行为算子不仅要改变后续轨迹，还需要有限资源代价和失效条件。因此，驱动功账本大概率会在**结构/行为算子资格门之前**变得必要，但没有必要现在提前实现。

## V4 更新带来的关键判断

V4 已经新增连续物理轨迹：

[
{X^n,Q_{\rm source}^n,Q_{\rm diff}^n,
Q_{\rm contact}^n,Q_{\rm oet}^n,Q_{\rm loss}^n}_{n=0}^{N},
]

而且禁止事件和语义标签。

这意味着资格审查现在可以基于真实轨迹回答，而不是概念推测：

1. 缺少焓状态是否改变 P2 所需要的轨迹类型？
2. 单点皮肤是否消除了必要差异？
3. 未记录驱动功是否使当前账本无法解释发生元，还是只限制了热力学宣称？

## 建议的处理方式

不要开三个并行长讨论。世界资格审查应输出三条独立裁定：

* **通过当前近似**：进入 P2-A；
* **带债务通过**：规定未来触发点；
* **明确阻塞**：只为该问题立项。

以当前证据，我的预判是：

[
\boxed{
\begin{aligned}
\text{焓平流}&:\ \text{带债务通过};\
\text{多点皮肤}&:\ \text{需要最小反例测试后裁定};\
\text{驱动功账本}&:\ \text{带债务通过，算子资格门前复审}.
\end{aligned}
}
]

所以并不是“这些都要先做完才能进入正轨”。真正可能阻塞 P2-A 的主要是**单点皮肤是否丢失必要的物理可区分性**；另外两项目前主要限制物理资格和未来宣称，而不是限制真实发生元的最低构造。
