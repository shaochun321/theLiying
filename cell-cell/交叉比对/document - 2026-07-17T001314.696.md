## 总体判断

这一次确实完成了一个关键机制闭合：

[
\text{DN 共享池输出}
\rightarrow
\text{分级电位中继}
\rightarrow
\text{公开连续输出}
]

不再经过二次门控，也没有在当前测试范围内触及钳位。R-B 在 24 组固定比例、共同尺度扫描中都保持了浮点精度级的比例一致，而 R-A 明确失败，因此 **`GradedPotentialRelay` 可以正式取代原 channel Neuron，成为 T3 的读出机制**。

这意味着此前反复修改的核心问题——“共享池中的正确比例如何成为下游可读状态”——已经解决。接下来不应再回头修改共享池、重新尝试二次 Neuron，或者改变 (r_\rho) 的资格定义。

但报告中有一处重要的理论表述需要收紧，否则 T3-C1 可能会再次因为验收对象定义不清而循环。

# 一、“任意时刻比例保真”只在固定历史比例下成立

报告称：

> 线性时不变系统在任意时刻都满足
> [
> V_a(t)/V_b(t)=y_a(t)/y_b(t).
> ]

这个表述一般情况下不成立。

分级中继实际输出为卷积：

[
V_a(t)
======

\int_0^t h(t-s)y_a(s),ds,
]

[
V_b(t)
======

\int_0^t h(t-s)y_b(s),ds.
]

只有当整个有效历史窗口中：

[
y_a(s)=c,y_b(s)
]

使用同一个常数 (c)，并且初始状态也满足相同比例时，才有：

[
V_a(t)=cV_b(t).
]

当前 24 组测试使用的是固定输入比例和共同尺度，因此：

[
y_a(t)=c,y_b(t)
]

在整个驱动期间成立。于是 `eps_ratio=0` 是正确结果，也是同构 LTI 中继必然应有的结果。

但当比例随时间变化，例如：

```text
1:1 → 3:1 → 1:3
```

通常有：

[
\frac{V_a(t)}{V_b(t)}
\neq
\frac{y_a(t)}{y_b(t)}.
]

中继输出表达的是两个通道的**共同时间核加权历史之比**，不是瞬时电流比。

这不是新组件失效，而是必须明确 (r_\rho) 到底是哪一种关系。

# 二、建议把 (r_\rho) 正式定义为窗口化射影关系

项目以过程为基本对象，所以我不建议强迫中继成为完全无记忆的瞬时复制器。

更合理的定义是：

[
z_i^\tau(t)
===========

(h_\tau*y_i)(t),
]

[
\boxed{
r_\rho^\tau(t)
==============

[z_1^\tau(t):z_2^\tau(t):\cdots:z_n^\tau(t)]
}
]

其中：

* (y_i) 是共享分流池输出；
* (h_\tau) 是分级电位中继的公共 RC 核；
* (\tau) 是关系的时间支撑尺度；
* 方括号表示射影等价类。

这意味着 (r_\rho^\tau) 表示：

> 在最近一个由中继动力学决定的历史窗口中，各发生通道以什么相对份额参与了共同过程。

这样当前中继的记忆不再是误差，而是关系生成元的时间支撑。

在固定比例输入下：

[
r_\rho^\tau(t)
==============

[y_1(t):y_2(t)]
]

精确成立。

在动态比例输入下，它会平滑过渡，表示历史参与关系，而不是瞬时跳变。

这与用户此前对基础关系生成元的定义非常一致：关系不是外部瞬时计算出的数，而是一个具有自身时间尺度的过程状态。

# 三、T3-C1R 尚未证明“经过 Bundle 后不失真”

报告写道，`GradedPotentialRelay` 使比例信号能够“被下游 Bundle 实际读取而不失真”。目前这个结论还略微超前。

当前测试证明的是：

[
\text{Relay.activation 比例}
==========================

\text{DN 输出比例}.
]

但报告没有显示已经接入一组真实下游 Bundle，再测量 Bundle 输出电流比例。

而 Bundle 还会引入：

[
I_i^{\mathrm{out}}
==================

w_i^{\mathrm{eff}}z_i.
]

若两条 Bundle 的实际电导不同：

[
w_a^{\mathrm{eff}}
\neq
w_b^{\mathrm{eff}},
]

那么：

[
\frac{I_a^{\mathrm{out}}}{I_b^{\mathrm{out}}}
=============================================

\frac{w_a^{\mathrm{eff}}}{w_b^{\mathrm{eff}}}
\frac{z_a}{z_b}.
]

此前已经发现 Memristor 的 hash 扰动会造成约 5%～8% 的固定不对称，所以新的下游 Bundle 很可能再次引入一层比例偏置。

因此当前准确结论应是：

[
\boxed{
\text{中继公开输出可被 Bundle 接口读取，}
\text{但通过 Bundle 后的比例协变尚待验证}
}
]

这应成为 T3-C1 的核心测试之一，而不是再新增一个 C1R 修改循环。

# 四、T3-C1 必须同时验证动态比例和真实 Bundle

建议 T3-C1 只做以下四项，不再扩大范围。

## 1. 动态比例变换

测试输入：

[
1:1
\rightarrow
2:1
\rightarrow
1:3
\rightarrow
1:1.
]

记录：

* DN 输出 (y_i(t))；
* 中继输出 (z_i(t))；
* 池状态；
* 中继膜状态。

不要用瞬时 (y_a/y_b) 作为唯一真值，而应计算：

[
\hat z_i(t)
===========

(h_\tau*y_i)(t)
]

并验证：

[
z_i(t)\approx\hat z_i(t).
]

这样是在验证中继实现自己的动力学定义，而不是错误要求有状态组件瞬时无记忆。

## 2. 比例交叉

当两个通道从：

[
y_a>y_b
]

变为：

[
y_a<y_b
]

时，测量：

* 关系输出翻转延迟；
* 是否产生过冲；
* 是否存在错误双占优；
* 翻转时间与 (\tau) 的关系。

这会给 (r_\rho^\tau) 一个真正可标定的时间尺度。

## 3. 下游 Bundle 实际接入

增加：

```text
GradedPotentialRelay_a ─ Bundle_a ─ observer_a
GradedPotentialRelay_b ─ Bundle_b ─ observer_b
```

同时记录：

[
\rho_{\mathrm{relay}}
=====================

z_a/z_b,
]

[
\rho_{\mathrm{transport}}
=========================

I_a^{\mathrm{out}}/I_b^{\mathrm{out}}.
]

判断 Bundle 的固定电导偏置是否：

* 小于允许容差；
* 可通过共同构造规则限制；
* 或必须作为结构基变换记录。

暂时不要自动补偿，否则容易重新引入 Python 比例校正。

## 4. 幅度可消费性

目前中继在 300 步、(dt=0.001) 下远未达到稳态，输出量级偏小。报告已经诚实记录这一点。

下一步不仅要验证：

[
z_i<a_{\max},
]

还要验证：

[
z_i>z_{\min}^{\mathrm{Bundle}},
]

即最小有意义输入下，输出足以经过 Bundle 驱动下游状态，而不是“数学比例完全正确，但物理幅度几乎不可用”。

建议给出工作区间：

[
z_{\min}
\leq
z_i
\leq
\beta a_{\max},
\qquad
\beta\leq0.5.
]

N_{\mathrm{clip}}

# 六、“软上限”措辞应改为“硬钳位”

报告将：

[
a_i
===

\operatorname{clip}(g_rV_i,0,a_{\max})
]

称为“线性读出 + 软上限”。

`clip()` 实际是硬钳位：

[
a_i=
\begin{cases}
0,&g_rV_i<0,\
g_rV_i,&0\leq g_rV_i\leq a_{\max},\
a_{\max},&g_rV_i>a_{\max}.
\end{cases}
]

应改称：

> 线性工作区 + 硬安全钳位。

这很重要，因为“软饱和”通常意味着连续可导的压缩函数，而当前一旦触及上限，比例会和旧 Neuron 一样受到破坏。
