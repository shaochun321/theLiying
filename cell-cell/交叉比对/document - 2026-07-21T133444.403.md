# 唯一阻塞：三点皮肤尚未证明“不同过程可区分”

当前测试证明了：

[
s_1\text{受刺激}
\Rightarrow
s_2\text{随后响应}
\Rightarrow
s_3\text{更晚且衰减响应}.
]

这能证明：

* 三点是独立状态；
* 传播具有延迟和衰减；
* 数值稳定；
* 能量守恒；
* 地址可挂载。

但它还没有回答 P2-A2 建设的原始理由：

[
\Gamma_1^{\mathrm{phys}}
\neq
\Gamma_2^{\mathrm{phys}}
\quad\Longrightarrow\quad
\mathbf q_{\mathrm{skin}}[\Gamma_1]
\neq
\mathbf q_{\mathrm{skin}}[\Gamma_2].
]

报告只列出了“刺激 (s_1)，观察 (s_2,s_3)”这一类核心测试，没有列出不同位置、不同次序和相同总输入下的反例对照。

而此前单点皮肤的债务，正是不同世界分布和不同接触次序被压平成同一皮肤轨迹。V6 也仍把 P2-A2 定位为对此债务的回应。

因此需要补一个很小的 **P2-A2b 差异资格门**：

### 位置反例

[
\Gamma_A:\ s_1\text{受输入},
\qquad
\Gamma_B:\ s_3\text{受同量输入}.
]

验证：

[
\mathbf q_A(t)\not\sim\mathbf q_B(t).
]

### 次序反例

[
\Gamma_C:\ s_1\rightarrow s_3,
\qquad
\Gamma_D:\ s_3\rightarrow s_1,
]

输入总量和作用时长相同，验证完整三点轨迹不同：

[
\mathbf q_C(t)\not\sim\mathbf q_D(t).
]

### 单点与共同作用

[
\Gamma_E:\text{只作用 }s_2,
]

[
\Gamma_F:\text{以相同总量同时作用 }s_1,s_3.
]

验证：

[
\mathbf q_E(t)\not\sim\mathbf q_F(t).
]

比较对象必须是：

[
\mathbf q(t)=
[q_1(t),q_2(t),q_3(t)],
]

不能再次汇总成单一总量。

在这些测试通过前，应把状态写成：

[
\boxed{\text{P2-A2 结构与传播资格通过，过程可区分资格待补。}}
]

# 非阻塞一：修复后的范围不是完整 `u_work`

修复后：

[
u=0.05\sim5.0
]

都产生约两次发生，看起来“整个测试范围都能工作”。但原因之一是：

[
\operatorname{activation}_{L1}
==============================

\min(200u,10).
]

当：

[
u\geq0.05,
]

L1 输出已经全部被钳在：

[
10.
]

因此：

[
u=0.05,\ 0.5,\ 5.0
]

对下游实际上可能近似相同。

这意味着修复消除了：

[
\text{PowerRail 崩溃},
]

但同时建立了一个明确的高端饱和区：

[
\boxed{
u\geq0.05
\Rightarrow
\text{L1 幅值辨识度显著下降或消失}.
}
]

报告把修复后的 (0.0005\sim5.0) 描述成扩展后的 `u_work`，这个结论仍然过强。

应该改成三类区域：

[
\mathcal A_{\mathrm{resp}}
==========================

{u:\text{能够产生发生}},
]

[
\mathcal D_{\mathrm{disc}}
==========================

{u:\text{输入变化仍能造成可区分输出}},
]

[
\mathcal S_{\mathrm{cap}}
=========================

{u:\text{受 L1 上限钳位而趋于等价}}.
]

当前只能说：

[
[0.0005,5.0]
\subseteq
\mathcal A_{\mathrm{resp}}.
]

不能说：

[
[0.0005,5.0]
============

u_{\mathrm{work}}.
]

真正适合 P2-A1b 的主要是：

[
\mathcal D_{\mathrm{disc}},
]

而不是只要“还能触发”就算工作区间。

# 非阻塞二：`_ACTIVATION_MAX=10` 修复成立，但需要范围审计

把 `ThermalDeltaNeuron` 恢复到与基类一致的有界输出纪律，是合理的修复方向。报告也通过逐层诊断证明，原问题来自无界 L1 输出压垮 ensemble PowerRail，而不是 HC、本体适应或执行顺序。

但该修改发生在通用的 `ThermalDeltaNeuron` 中，所以还应补一个轻量审计：

[
\operatorname{Uses}(\texttt{ThermalDeltaNeuron})
================================================

{C_1,C_2,\ldots}.
]

确认：

* 它是否还被其他非温感链路复用；
* 其他使用者是否依赖大于 10 的输出；
* 过去被冻结的测试是否只验证“不崩溃”，却没有验证响应形状；
* cap 是否应是类常量，还是应成为带来源的构造参数。

全量回归通过说明没有立即破坏现有测试，但不能证明所有未来依赖都不受响应压缩影响。

这不要求撤销修复，只需把：

[
\text{全局使用范围审计}
]

加入 FIX-019 的完成条件。

# 接下来的正确顺序

不建议立刻全面进入 P2-A1b。先做两个很小的收口步骤：

[
\boxed{
P2\text{-A2b}
\rightarrow
P2\text{-A1a-R}
\rightarrow
P2\text{-A1b}.
}
]

## P2-A2b：三点过程差异资格

补上位置、次序和共同作用反例，确认三点结构真正解决了单点压平问题。

## P2-A1a-R：修复后响应重分类

不必重新做大规模粗扫，只需要围绕两个区域精扫：

低端：

[
u\in[10^{-5},10^{-3}],
]

寻找真实静默／启动边界。

钳位转折附近：

[
u\in[0.02,0.08],
]

测量：

* L1 输出；
* ensemble 内部参与；
* 首次延迟；
* 完整发生频率；
* ACTIVE 持续时间；
* 重整时间；
* 是否仍具有幅值区分。

最终得到：

[
\mathcal D_{\mathrm{disc}}
\quad\text{与}\quad
\mathcal S_{\mathrm{cap}}.
]

## P2-A1b：皮肤—生成元接口标定

然后才选择：

[
u_i(t)
======

\operatorname{clip}
\left(
\kappa_i q_i^{\mathrm{skin}}(t)+b_i
\right).
]

原则应是：

* 常见皮肤变化主要落在 (\mathcal D_{\mathrm{disc}})；
* 极端输入可以进入 (\mathcal S_{\mathrm{cap}})，但不得成为常态；
* 原始皮肤轨迹继续保存，不能因 L1 钳位而丢失物理账本；
* 同时实现 `MANUAL_CALIBRATION/WORLD_COUPLED` 驱动权守卫。

## 最终结论

高输入静默根因排查是一次成功的真实问题发现：

[
\boxed{
\text{根因定位正确，修复有效，不需要撤回。}
}
]

但当前 V6 将下一步直接写成 P2-A1b，稍微早了一步。

应改成：

[
\boxed{
P2\text{-A2b 差异资格}
\rightarrow
P2\text{-A1a 修复后重分类}
\rightarrow
P2\text{-A1b}.
}
]

这两项都很小，不是路线扩张；它们分别防止：

1. 三点皮肤只证明“能传播”，却没有证明“能区分”；
2. 把“不会崩溃”错误等同为“全范围具有可用辨识度”。
