## 固定结构

`PhysicalEntryGate.step(spike_output, dt)` 的顺序应为：

1. 电容自然泄漏；
2. 在输入脉冲到来前，根据当前 (V_g) 判断门是否开放；
3. 仅当门开放且本步有脉冲时输出：
   [
   b_\alpha^\uparrow=1;
   ]
4. **每一枚输入脉冲**，无论是否被输出，都把门电压刷新并钳位到：
   [
   V_H;
   ]
5. 无输入时只泄漏，不执行软件复位。

即：

[
b^\uparrow(t_k)
===============

p(t_k)\mathbf 1[V_g(t_k^-)<\theta_g],
]

随后：

[
p(t_k)=1
\quad\Rightarrow\quad
V_g(t_k^+)=V_H.
]

必须避免两种错误：

* 只让首次通过的脉冲充电；
* 每枚脉冲无上限累加。

前者会在长脉冲簇中途错误开门，后者会造成永久锁死。

## 固定参数

首版直接使用已经审计过的项目默认值：

[
C=1.0,\qquad R=1.0,\qquad \tau_g=1.0,s,
]

[
V_H=1.0,\qquad \theta_g=0.3,
]

并令单次刷新满足：

[
\frac{Q_{\mathrm{spike}}}{C}\ge V_H.
]

首版可取等号：

[
Q_{\mathrm{spike}}=1.0.
]

对应开门时间：

[
t_{\mathrm{open}}
=================

# \tau_g\ln\frac{V_H}{\theta_g}

\ln\frac{1}{0.3}
\approx1.204,s.
]

它位于已测分离带：

[
0.316,s<t_{\mathrm{open}}<4.257,s.
]

本轮不网格搜索，也不为不同站点修改参数。

## 代码边界

`PhysicalEntryGate`内部只允许持有：

* `Capacitor`；
* `MOSFET`或现有硬阈值门控原语；
* Zener/钳位所需的既有结构；
* 物理参数。

禁止出现：

```python
_phase
_silence_count
t_step
gap_steps
rearm_min_steps
site_id
```

也不得读取或修改：

* `Occurrence`；
* `OccurrenceClosure`；
* `EntryBoundaryDetector`内部状态；
* collector的 `_w_adapt`；
* `pre_trace`。

`EntryBoundaryDetector`保留为历史参考检测器，不接入生产链，不要求与物理门逐步等价。

## 九项测试中最重要的四项

除了既定T-R1B-1～9，尤其要守住：

### 1. 长簇不会重复输出

构造总长度明显超过1204步、但相邻ISI始终不超过316步的脉冲簇。

即使：

[
t_{\mathrm{cluster}}>t_{\mathrm{open}},
]

仍只能产生一次 (b^\uparrow)。这直接验证每枚脉冲确实刷新门状态。

### 2. 分歧区间必须显式测试

至少测试：

[
\Delta t=600,\quad1000,\quad1203,\quad1205.
]

预期：

* 600、1000、1203步后仍关闭；
* 1205步后重新开放。

不要只用真实数据流，因为真实数据恰好跳过了 ([501,1204)) 的判别区间。

### 3. 阈下MOSFET行为锁定

明确断言：

```python
conduct(theta_g - 1e-6) == 0.0
```

因为当前门依赖现有实现的硬阈值行为；以后若MOSFET尾流实现被修改，这项测试必须立即报警。

### 4. 旧母本零改动

T-R1B-9应对 `occurrence.py` 做可执行守卫，例如文件哈希、git diff或目标源码快照断言，确保本轮没有顺手处理双时钟债务。

## 停止条件

出现以下任一情况就停止，不调参：

* 四站点不能共享同一参数；
* 长脉冲簇中产生第二次边界；
* 真实退出后不能恢复；
* 必须引入软件时钟或状态枚举；
