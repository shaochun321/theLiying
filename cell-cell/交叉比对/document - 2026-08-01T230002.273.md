## 唯一阻塞：两条关系不是 (A\prec B,\ B\prec C)

报告中的实际方向是：

[
T1:\quad 28\prec31
]

[
T2:\quad 28\prec23
]

所以它们组成的是：

[
\boxed{
28\prec31
\quad\land\quad
28\prec23
}
]

即共同起点的分叉：

```text
      31
     ↗
28
     ↘
      23
```

而不是：

```text
31 → 28 → 23
```

因此不能用它们直接验证：

[
A\prec B\land B\prec C\Rightarrow A\prec C.
]

报告把“几何上共享节点28”误当成了“代数上前一关系的终点与后一关系的起点相接”。

## 两条可行路线

### 低成本路线：保留现状，做分叉型R2

定义：

[
(28\prec31)\star(28\prec23)
]

研究：

> 同一次28发生，是否共同生成两条指向不同目标的R1，以及这两条R1能否再形成“共同源关系”。

这仍然是真正的关系—关系生成，而且不用重建T2。

### 原定传递路线

需要第一条关系变成：

[
31\prec28
]

再与：

[
28\prec23
]

组合：

[
31\prec28,\qquad28\prec23.
]

并且两个关系中的28必须回指**同一个**：

[
\operatorname{OccurrenceInstanceId}_{28},
]

不能只是共享站点地址28。
