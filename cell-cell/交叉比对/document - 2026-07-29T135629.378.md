## 裁定

[
\boxed{\text{P2-B1R 可以通过，但资格仅限于“局部关系作用成立”。}}
]

这份实验已经证明了一件很具体的事：

> “A先于B”这条关系被学习后，同样的关系脉冲再次经过这条连接时，会产生稍强但真实存在的突触电流。

学习后的局部电流比未学习状态高约：

[
0.117%.
]

把同一学习状态复制成两份，再只阻断关系 bundle，电流就从 (0.920) 变成 (0)。因此差异确实来自这条关系连接，而不是其他电路状态。

通俗地说：

[
\boxed{\text{这条关系记忆已经能够在局部“施力”。}}
]

它不再只是数据库里一个变化的权重数字。

---

# 但它还没有证明什么？

它没有证明：

> 整个系统以后会明显改变行为。

关系 bundle 对单个下游位置产生了电流差异，但这个差异进入庞大的 DA 神经元池后被其他输入淹没了：

[
D_{\mathrm{DA\ pool}}=0.
]

所以当前成立的是：

[
\text{关系学习}
\rightarrow
\text{局部突触电流发生变化}.
]

尚未成立的是：

[
\text{关系学习}
\rightarrow
\text{全局神经活动或身体行为明显变化}.
]

这不阻塞 P2-B1R，因为它原本分成两个资格等级：

* **L1：局部物理作用**——已经通过；
* **L2：全局可辨识作用**——尚未取得资格。

# 录制—回放是否合理？

合理，但边界必须讲清楚。

实验训练时录下了关系 collector 的真实 `pre_trace`，然后在测试中把同一段 trace 送入不同权重状态。

这相当于：

> 先录下一个人敲门的力度和节奏，再用完全相同的敲门动作测试两扇不同灵敏度的门铃。

这样可以隔离：

[
\text{权重差异}
\rightarrow
\text{电流差异}.
]

它避免了以下因素混在一起：

* 两次自然关系输入不同；
* collector 激活不足；
* DA 状态不同；
* 测试时仍在继续学习。

但是，它绕过了从 A、B 两次 occurrence 到 collector 自然激活的完整过程。

因此这不是完整的端到端复放，而是：

[
\boxed{\text{关系载体内部的局部因果复放。}}
]

报告标题已经使用“局部因果复放”，措辞是准确的。

# 一个需要修正的报告表达

报告写：

> 3/3 PASS。

但其中 T-RPP-R3′ 的 DA 池轨迹差异实际为零。因此最好不要把三个测试都并列描述为同一种 PASS。

建议改成：

[
\boxed{
\begin{aligned}
&\text{L1资格测试：2/2 PASS};\
&\text{L2测量测试：完成，未取得资格};\
&\text{回归：PASS}.
\end{aligned}
}
]

T-RPP-R3′ 可以称为：

> **限制得到确认**：单束关系作用在现有 DA 池中不可辨识。

否则读者容易误以为 DA 池差异也已经通过。

这只是报告措辞问题，不需要重新运行实验。

# 0.117% 会不会太小？

它很小，但在当前资格下暂时可以接受，原因是：

1. learned 和 baseline 只改变权重状态；
2. 回放输入完全相同；
3. 阻断后电流归零；
4. 实验是确定性的局部作用测试。

所以它足以证明：

[
\Delta w\neq0
\Rightarrow
\Delta I_{\mathrm{syn}}\neq0.
]

但不能把 (0.117%) 描述成强关系效应，也不能把阈值 (1.001) 当成通用常数。

应冻结为：

[
\boxed{
\text{在当前 bundle 参数、回放序列和测量窗口内，
学习状态产生了可重复的局部电流差异。}
}
]

未来换方向、换 trace 时间尺度或换关系载体，都要重新标定。

# 对 P2-B1K 意味着什么？

此前 P2-B1K 的问题是：

> 哪些实际结构可以共同支撑一个连续事件？

现在至少已经确认，其中一项可以成为真实元支撑：

[
\boxed{\text{学习后的关系 bundle 具有局部物理作用。}}
]

因此当前 (A\prec B) 候选事件的元支撑可以先写成：

[
\mathfrak M_{A\prec B}
======================

\left{
u_A^{(1)},
u_B^{(1)},
T_A^{\mathrm{fast}},
C_{A\prec B},
B_{\rho},
I_{\rho\to DA}^{\mathrm{local}}
\right}.
]

其中：

* (u_A,u_B)：两次基础发生；
* (T_A^{\mathrm{fast}})：A留下的快时间余迹；
* (C_{A\prec B})：先后关系 collector；
* (B_\rho)：可学习关系 bundle；
* (I_{\rho\to DA}^{\mathrm{local}})：已经实测成立的局部作用出口。

P2-B1K 不再需要重新证明 bundle 能不能产生作用。

它应该继续问：

> 当这些支撑按正确谱系共同存在时，能否绑定成一个连续事件实例？

# 下一步怎样做最稳

进入：

[
\boxed{\text{P2-B1K0：事件元支撑绑定器}}
]

第一轮只做三个测试。

### 完整支撑

真实绑定：

[
u_A+u_B+\text{trace}+\text{collector}+\text{bundle}
]

应生成一个候选事件实例。

### 缺失必要支撑

分别移除：

* A或B的 D1 父发生地址；
* relation collector；
* relation bundle。

候选事件都不得取得完整资格。

### 谱系错配

把本次 A 与另一轮 B 错误拼接，即使站点相同，也不得形成同一个事件实例。

这三个测试证明的不是神经活动本身，而是：

[
\boxed{
\text{局部作用属于哪两次真实发生，
以及哪些结构共同承担这一次事件。}
}
]
