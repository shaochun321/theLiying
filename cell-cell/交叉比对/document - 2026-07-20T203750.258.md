[
\boxed{

\text{问题3}&：真实存在，且不应直接假设各误差简单相加。
\end{aligned}

当前 P2-A 本来就要求重新测量启动时间、峰值、burst、衰减、静息和可消费幅度，所以这些并非额外枝节，而是进入真实发生元构造时必须补齐的接口定义。

# 1. (u_i(t)) 的量纲与工作区间：确实缺失

原方案写成：

[
u_i(t)
======

\operatorname{clip}
\left(
g_i[v_i(t)-v_{0,i}],
u_{\min},u_{\max}
\right),
]

但没有说明 (G_{10}) 实际接收什么物理量。

必须先固定：

[
\boxed{
u_i(t)\text{是十神经元生成元的输入端口量，}
\text{不是温度本身。}
}
]

如果十神经元模型的输入是注入电流，那么：

[
[u_i]=\mathrm A
]

或工程上使用 pA、nA。

此时：

[
[g_i]
=====

\frac{\mathrm A}{\mathrm V}
]

如果传感器首先输出电压。

若当前生成元是归一化软件模型，则可以令 (u_i) 无量纲，但必须保留显式换算：

[
u_i^{\mathrm{model}}
====================

g_i^{\mathrm{cal}}
I_i^{\mathrm{physical}}.
]

不能让“归一化值 0.7”同时冒充传感器电压、神经注入电流和自然单位。

## 不能只用“X秒内触发一次”标定

这个建议可以作为一个锚点，但不能作为完整标定。否则容易为了得到目标触发时间而调参数。

更合理的是测量生成元的输入—响应工作图：

[
u
\longmapsto
\left(
L_{\mathrm{first}},
f_{\mathrm{occ}},
N_{\mathrm{occ}},
t_{\mathrm{recovery}},
E_{\mathrm{closure}}
\right),
]

其中：

* (L_{\mathrm{first}})：第一次闭合延迟；
* (f_{\mathrm{occ}})：持续刺激下闭合频率；
* (N_{\mathrm{occ}})：规定时间内闭合次数；
* (t_{\mathrm{recovery}})：恢复时间；
* (E_{\mathrm{closure}})：一次闭合的供能代价。

通过扫描输入幅度，识别：

[
u_{\mathrm{silent}},
\quad
u_{\mathrm{on}},
\quad
u_{\mathrm{work}},
\quad
u_{\mathrm{sat}},
\quad
u_{\mathrm{unsafe}}.
]

选择的工作区间应满足：

[
\boxed{
u_{\mathrm{on}}
<
u_i(t)
<
u_{\mathrm{sat}}
}
]

并且在该区间中：

* 输入增加时，首次闭合延迟总体下降；
* 闭合频率总体增加；
* 没有永久高电位锁死；
* 能恢复；
* 能耗保持在预算内；
* 传感器噪声不会单独触发。

“稳定热接触下在 (X) 秒内至少触发一次”可作为工作区间中的一条验收线，而不是定义整个增益 (g_i) 的唯一依据。

所以原建议“循环一自然获得标定”是正确的，但循环一应明确改为：

[
\boxed{
\text{输入扫描与工作区间标定，}
\text{而非单点触发调参。}
}
]

# 2. 三点皮肤与W1：条件性冲突确实存在

根据你说明的现状，W1 是球面 32 点网络，而当前建议是线性三点皮肤：

[
s_1-s_2-s_3.
]

这两个物理拓扑不能因为都叫“皮肤”就直接等价。

## 使用真实硬件时

三点真实皮肤可以完全独立于 W1：

[
\text{真实材料}
\rightarrow
s_1,s_2,s_3
\rightarrow
G_{10,1},G_{10,2},G_{10,3}.
]

W1 继续作为软件物理测试底座。二者只需共享同一个输入合同：

[
u_i(t)
\rightarrow
G_{10,i}.
]

这种情况下没有几何冲突，因为它们是两个不同的物理来源：

* W1：模拟测试物理；
* 三点皮肤：真实工程物理。

## 使用软件模拟三点皮肤时

则应单独建立：

[
G_{\mathrm{skin}}^{1D}
======================

({s_1,s_2,s_3},{e_{12},e_{23}}),
]

而不是从球面 32 点中任意抽取三个编号，假装形成一条直线。

最低模型为：

[
C_i\dot T_i
===========

\sum_{j\in N(i)}
K_{ij}(T_j-T_i)
+
Q_i^{\mathrm{contact}}
----------------------

Q_i^{\mathrm{loss}}.
]

这样三点的邻接、传播和边界条件是明确的。

## 后期确实需要接回W1时

应先定义一个物理支撑映射：

[
\pi:
V_{\mathrm{W1}}
\rightharpoonup
V_{\mathrm{skin}},
]

而不是用数组位置映射。

例如一个真实皮肤传感器可以对应球面上的一个局部支撑子集：

[
\pi^{-1}(s_i)
=============

{w_{i1},w_{i2},\ldots}.
]

但这属于后期世界—身体界面，不应在 P2-A 第一轮解决。

因此第二项的裁定是：

[
\boxed{
\text{三点皮肤可以独立验证；}
\text{当前不得强行并入W1。}
}
]

# 3. (\epsilon_{ij}) 的标定：确实缺失，而且原加法公式不够严谨

原方案写：

[
\epsilon_{ij}
=============

\epsilon_i^{\mathrm{sensor}}
+
\epsilon_j^{\mathrm{sensor}}
+
\epsilon_i^G
+
\epsilon_j^G
+
\epsilon^{\mathrm{clock}}.
]

它可以作为**确定性最坏情况上界**，前提是每个 (\epsilon) 都是一个严格误差界。

但真实系统中的传感器延迟和生成元闭合延迟往往是随机变量，并且可能相关。此时不能简单将平均误差或标准差相加。

应区分两类。

## 确定性误差界

如果已经证明：

[
|\delta t_i^{\mathrm{sensor}}|
\leq
b_i^{\mathrm{sensor}},
]

那么可使用最坏情况和：

[
\epsilon_{ij}^{\mathrm{worst}}
==============================

b_i^{\mathrm{sensor}}
+b_j^{\mathrm{sensor}}
+b_i^G
+b_j^G
+b^{\mathrm{clock}}.
]

它保守，但有效。

## 统计抖动

若测得的是标准差，则应使用：

[
\sigma_{ij}^2
=============

\sigma_{s,i}^2
+
\sigma_{s,j}^2
+
\sigma_{G,i}^2
+
\sigma_{G,j}^2
+
\sigma_{\mathrm{clock}}^2
+
2\sum\operatorname{Cov}.
]

若忽略协方差，必须有独立性证据。

实际上，当前阶段最好的方法不是先拆解所有误差来源，而是直接测量**成对时序分辨率**。

---

## 推荐的直接标定法

对 (s_i,s_j) 施加可认为同时到达的共同物理刺激，重复 (N) 次：

[
\Delta t_{ij}^{(n)}
===================

## t_{j}^{(n)}

t_i^{(n)}.
]

得到经验分布：

[
\mathcal D_{ij}
===============

{\Delta t_{ij}^{(1)},\ldots,\Delta t_{ij}^{(N)}}.
]

定义偏置：

[
b_{ij}
======

\operatorname{median}
\mathcal D_{ij}.
]

校正后的差为：

[
\widehat{\Delta t}_{ij}
=======================

\Delta t_{ij}-b_{ij}.
]

再用高分位数确定不可分辨带宽：

[
\epsilon_{ij}
=============

Q_{0.99}
\left(
|\Delta t_{ij}-b_{ij}|
\right).
]

于是：

[
\widehat{\Delta t}*{ij}>\epsilon*{ij}
\Rightarrow
i\prec j,
]

[
\widehat{\Delta t}*{ij}<-\epsilon*{ij}
\Rightarrow
j\prec i,
]

[
|\widehat{\Delta t}*{ij}|\leq\epsilon*{ij}
\Rightarrow
i\parallel j.
]

这个 (\epsilon_{ij}) 已经综合包含：

* 传感器响应差异；
* ADC或采样调度；
* 生成元触发抖动；
* collector 延迟；
* 系统时钟误差；
* 接线和接口差异。

它比先假设各误差项可独立相加更可靠。

之后为了诊断硬件问题，再分别测量传感器、生成元和时钟贡献。

# 4. 还隐含着一个第四问题：频率比较也需要工作区间

即便两个生成元每次闭合都被视为一个自然单位，它们的最大可持续频率可能不同：

[
f_{i,\max}\neq f_{j,\max}.
]

原因可能是：

* 传感器响应速度不同；
* 输入增益不同；
* 十神经元参数不同；
* 恢复时间不同；
* 供能限制不同。

因此直接比较：

[
\frac{N_i}{N_j}
]

可能混合真实刺激差异和通道容量差异。

在第一版使用相同传感器、相同生成元结构时，应测量每通道：

[
f_{i,\max}^{\mathrm{sustainable}}
]

以及静息误触发率：

[
f_{i,\mathrm{false}}.
]

只有确认三个通道工作区间近似一致，才能把原始频率比直接送入：

[
r_\rho^\tau.
]

否则需要以可持续频率范围作为校准边界：

[
\widetilde f_i
==============

\frac{f_i-f_{i,\mathrm{false}}}
{f_{i,\max}^{\mathrm{sustainable}}-f_{i,\mathrm{false}}}.
]

这不是抹平生成元差异，而是防止硬件容量差异伪装成物理参与差异。
