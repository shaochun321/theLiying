## 二、方向、梯度、散度的定位是合理的

可以先采用下面的生成谱系。

### 方向生成元

方向不是基础空间坐标，而是基础发生、时间结构和空间结构共同作用的结果：

[
\mathcal C_{\mathrm{dir}}^{(2)}
===============================

F_{\mathrm{dir}}
\left(
\mathcal G_i^{(0)},
\mathcal G_j^{(0)},
\Theta_{ij}^{(1)},
\Sigma_{ij}^{(1)}
\right).
]

它输出的是一个能够继续作用的有向算子，而不只是：

```text
i在j左边
```

这种语义标签。

### 梯度生成元

梯度需要比较多个方向上的变化，并且通常必须显式介入尺度：

[
\mathcal C_{\mathrm{grad}}
==========================

F_{\mathrm{grad}}
\left(
{\mathcal C_{\mathrm{dir}}},
\Lambda^{(1)}
\right).
]

所以梯度不是直接读取外部数值差，而是由多个方向耦合生成元在某个项目尺度下重新组织。

### 散度生成元

散度可以理解为围绕同一个物理支撑位置，对多个流入／流出方向生成元的再耦合：

[
\mathcal C_{\mathrm{div}}
=========================

F_{\mathrm{div}}
\left(
{\mathcal C_{\mathrm{dir}}^{\rm in}},
{\mathcal C_{\mathrm{dir}}^{\rm out}}
\right).
]

这与当前共同源分叉拓扑有亲缘性，但不能直接把现有AND型R2改名为散度。当前R2只能作为未来散度生成元的链路基础。

## 三、生成元不应该依赖STDP和DA才能存在

这一点需要明确冻结：

[
\boxed{
\text{生成元存在资格}
\perp
\text{STDP／DA}.
}
]

一个非学习型生成元必须在：

[
\mathrm{STDP}=0,\qquad \mathrm{DA}=0
]

时仍能：

* 接受物理输入；
* 完成算子作用；
* 产生输出；
* 形成可追踪区间；
* 进入下一级耦合。

STDP、DA以后可以调节：

* 增益；
* 保留时间；
* 能耗分配；
* 结构可塑性；
* 哪些生成元更容易再次激活。

但不能决定：

> 方向算子是否是方向算子；
> 梯度生成元是否存在；
> 一次真实耦合是否发生。

生物系统也可作这种结构类比：许多感觉处理、反射回路和节律生成结构并不是生命个体从零学习出来的；学习主要调整阈值、增益、连接和适应，而不是每次重新发明基本物理算子。

# 五、恢复后的工程路线

## TSS-0：重新冻结三类结构生成算子

先做一个很短的定义与现有代码映射，不写新动力学：

[
\Theta^{(1)}:\text{时间生成算子},
]

[
\Sigma^{(1)}:\text{空间生成算子},
]

[
\Lambda^{(1)}:\text{尺度生成算子}.
]

每个只固定六项：

* 输入基础生成元；
* 物理载体；
* 作用区间；
* 输出；
* 可被下游读取的量；
* 禁止用来决定输出的语义字段。

同时判断当前R1哪些部分可以归入 (\Theta^{(1)})，哪些只是投影记录。

## TSS-1：空间生成元

构造第一条真正的空间生成算子。

它不能直接读取外部欧氏坐标，而应来自：

* 实际可达链；
* 局部传播；
* 阻断实验；
* 邻接与方向性作用；
* 结构之间的响应差异。

## TSS-2：尺度生成元

同一个物理过程通过不同结构窗口或分辨率产生不同投影：

[
\Lambda^{(1)}
:
(\mathcal G,I_{\lambda_a},I_{\lambda_b})
\mapsto
\text{可继续作用的尺度关系}.
]

尺度不是给数据贴“粗／细”的标签，而是实际改变下游可见结构和作用方式的算子。

## CG-0：第一个基础耦合生成元——方向

当时间与空间生成算子都取得最低资格后，构造：

[
\boxed{
\mathcal C_{\mathrm{dir}}
=========================

F_{\mathrm{dir}}
(\mathcal G^{(0)},\Theta^{(1)},\Sigma^{(1)})
}
]

然后才依次考虑：

[
\mathcal C_{\mathrm{grad}},
\qquad
\mathcal C_{\mathrm{div}}.
]

这样主线会真正到达你要求的耦合生成元，而不是停留在关系记录、人工AND门或学习竞争。
