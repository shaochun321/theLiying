[
\boxed{
Y=\text{候选R1链路在固定下游节点产生的局部突触电流轨迹}
}
]

不是测 relation collector 自己的膜电位，也暂时不用全局 entropy/energy ledger。

原因是：P2-B1R 已经证明，现有代码能够读取关系 bundle 对下游节点贡献的局部突触电流；同时也发现，作用进入整个 DA 池以后信号太弱，池状态没有形成可辨差异。

因此局部电流是目前：

* 最接近真实物理作用；
* 量纲最清楚；
* 因果位置最明确；
* 最少增加新结构；

的读出量。

# 一、Y具体是什么？

选定关系链路的一个固定下游目标 (q)，定义：

[
\boxed{
Y_c(s)
======

I_{\rho\rightarrow q,c}^{\mathrm{syn}}(s)
}
]

其中：

* (\rho)：当前候选R1关系结构；
* (q)：固定的下游神经元或目标端口；
* (I^{\mathrm{syn}})：这条关系 bundle 对 (q) 实际产生的突触电流；
* (c)：实验条件；
* (s)：区间内的物理过程步。

四种条件为：

[
c\in
\left{
\varnothing,\ A,\ B,\ A\ell B
\right}.
]

所以实际测量的是四条电流轨迹：

[
Y_\varnothing(s),\quad
Y_A(s),\quad
Y_B(s),\quad
Y_{A\ell B}(s).
]

这里的 (A\ell B) 不是软件标签“A先于B”，而是：

> A经过候选物理链路，与B真实发生耦合。

---

# 二、不要只测一个峰值

项目是耗散、振荡甚至可能出现混沌的系统，所以：

[
Y\neq \max I
]

也不应只取终点膜电位。

更合适的是把完整的区间轨迹作为 (Y)。

定义不可约交互轨迹：

[
\boxed{
\kappa_{R1}(s)
==============

## Y_{A\ell B}(s)

## Y_A(s)

Y_B(s)
+
Y_\varnothing(s)
}
]

然后用区间范数得到一个资格量：

[
\boxed{
K_{R1}
======

\left(
\sum_{s\in\mathcal I^\star}
\kappa_{R1}(s)^2\Delta s
\right)^{1/2}
}
]

使用平方范数是为了避免：

* 正负电流互相抵消；
* 振荡轨迹积分后恰好接近零；
* 一个大作用因为方向反转而被误判为无作用。

# 三、测量区间怎么定义？

四组实验必须用同一个比较区间：

[
\mathcal I^\star
================

[s_{\mathrm{enter}},s_{\mathrm{exit}}].
]

建议这样确定：

### 起点

共同实验协议中，第一次外部物理支撑开始作用的时刻。

在空条件 (\varnothing) 中虽然不实际施加作用，但仍从同一个协议时刻开始记录。

### 终点

四种条件全部完成后，取最晚的物理退出点：

* A、B父发生均完成；
* 候选链路低于退出阈值；
* 下游局部电流回到基线带；
* D1发生完成重新武装。

即：

[
s_{\mathrm{exit}}
=================

\max_c
s_{\mathrm{relax},c}.
]

这样不同条件的耗散尾部也被完整包含，而不是硬切固定50步。

# 四、为什么不能把relation collector本身作为主Y？

因为它是专门设计来检测 (A\prec B) 的。

如果测它自身：

```text
A+B满足关系条件
→ collector亮
→ 宣布关系不可约
```

容易变成定义上的循环证明。

因此：

[
\boxed{
\text{relation collector负责生成R1候选，}
\quad
\text{Y应在它的下游读取实际作用。}
}
]

可以复用 P2-B1R 中读取局部电流的代码路径，但不能复用“直接写入 `pre_trace`”的 replay 作为主实验。

P2-B1X2c 应使用已经完成的真实端到端场景：

[
\text{外部物理驱动}
\rightarrow
D1
\rightarrow
\text{关系collector}
\rightarrow
\text{关系bundle}
\rightarrow
Y.
]

P2-B1X1d 已经证明真实输入可以稳定生成 (A\prec B) 关系实例，因此具备这一测试基础。

# 五、四条件还不够，必须加一个链路切断条件

四条件证明的是：

> 组合条件中出现了不能由A、B单独相加解释的作用。

但还要证明这个作用来自候选链路。

增加第五组：

[
A\ell_{\mathrm{cut}}B.
]

外部输入与 (A\ell B) 完全相同，只切断候选关系 bundle 或指定链路段。

定义：

[
\boxed{
K_{\mathrm{cut}}
================

\left|
Y_{A\ell B}
-----------

Y_{A\ell_{\mathrm{cut}}B}
\right|_{\mathcal I^\star}
}
]

P2-B1X2c至少应同时满足：

[
K_{R1}>\varepsilon_{\mathrm{int}}
]

以及：

[
K_{\mathrm{cut}}>\varepsilon_{\mathrm{cut}}.
]

两者分别回答：

1. 组合是否产生不可加和的新作用；
2. 新作用是否真的依赖这条物理链路。

# 六、Y测哪一个具体电流？

建议第一版直接复用 P2-B1R 已有的：

[
\boxed{
I_{\rho\rightarrow DA}^{\mathrm{local}}(s)
}
]

但注意，它指的是：

> 关系 bundle 对 DA 池某个目标端口贡献的局部电流分量。

不是：

* 整个 DA 池的平均膜电位；
* DA浓度；
* 整个系统能量；
* 最终突触权重。

P2-B1R 已经显示，bundle 局部电流可测，但整个 DA 池轨迹差异为零或低于分辨率。

所以本轮资格只能表述为：

[
\boxed{\text{R1结构块产生了不可约的局部物理输出。}}
]

不能升格为：

[
\text{R1已经改变了全局系统行为。}
]

# 七、entropy/energy ledger放在哪里？

选项2不适合作为当前主Y。

原因不是它“不物理”，而是它过于全局：

```text
一个很小的局部关系作用
        ↓
混入整个系统能耗
        ↓
可能完全看不见
```

而且如果账本只是对已有神经活动求和，它也未必能区分：

* A与B分别消耗能量；
* A和B形成了不可约耦合；
* 关系bundle产生了额外作用。

所以 ledger 可作为以后第二级辅助量：

[
Y_{\mathrm{local}}
\rightarrow
Y_{\mathrm{regional}}
\rightarrow
Y_{\mathrm{ledger}}.
]

当前顺序应是：

1. 局部链路电流必须通过；
2. 下游膜电位差异可作为非阻塞指标；
3. 区域能量／熵变化以后再验证；
4. 全局行为改变放到结构／行为资格门。
