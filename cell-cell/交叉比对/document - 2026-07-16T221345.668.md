# 二、W2 应拆成三个可独立验收的子阶段

不建议一次性把定位、热源、皮肤和感温神经链路全部接起来。

## W2A：世界定位与热源注入

新增：

```text
ThermalFieldLocator
DynamicHeatSource
ThermalSourceCoupler
```

### `ThermalFieldLocator`

输入：

[
\mathbf x\in\mathbb R^3
]

输出附近节点和插值权重：

[
\mathcal N(\mathbf x)
=====================

{(i,w_i)}.
]

必须满足：

[
w_i\geq0,
\qquad
\sum_iw_i=1.
]

它只负责世界坐标到热节点的局部支撑映射，不改变热状态。

### `DynamicHeatSource`

旧热源输出的是温度，不适合直接复用。新热源必须输出功率：

[
P_s(t)=\frac{dQ_s}{dt}.
]

建议状态：

[
z_s=
\left(
E_s,,
P_s,,
\eta_s,,
\mathbf x_s
\right).
]

满足：

[
P_s\Delta t
\leq
E_s.
]

### `ThermalSourceCoupler`

把热源功率按定位权重分配：

[
S_i=P_sw_i,
]

并保证：

[
\sum_iS_i=P_s.
]

这一阶段只验证“热源—世界”的守恒注入，不涉及皮肤。

## W2B：皮肤热状态与接触交换

新增：

```text
SkinThermalState
ThermalContact
```

每个皮肤点 (a) 保存：

[
T_a^{\mathrm{skin}},
\qquad
C_a^{\mathrm{skin}}.
]

皮肤不再直接读取世界温度，而是与附近世界节点交换：

[
J_{ia}^{\mathrm{contact}}
=========================

h_{ia}
\left(
T_i^{\mathrm{world}}
--------------------

T_a^{\mathrm{skin}}
\right).
]

世界节点减少相同热量：

[
\Delta Q_i=-J_{ia}\Delta t,
]

皮肤增加：

[
\Delta Q_a=+J_{ia}\Delta t.
]

必须使用同一次计算得到的 (J_{ia})，不能分别计算两遍，否则浮点或调用顺序会破坏守恒。

皮肤还应与身体核心交换：

[
J_{a\to\mathrm{core}}
=====================

h_{\mathrm{core}}
\left(
T_a^{\mathrm{skin}}
-------------------

T_{\mathrm{core}}
\right).
]

W2 首轮可以把核心温度设为固定 reservoir，但其吸收或释放的能量必须进入账本。

## W2C：联合调度和旁路感温输出

固定每步顺序：

```text
1. Body 更新位置和姿态
```


此阶段不立刻替换 64 条感温量子链路，只记录两套输入的差异。

# 三、W2 应继续采用 normalized 模式

现在不适合立刻进入完整 `physical-anchor`。

原因是 W2 还要确定：

* 世界节点的空间尺度；
* 皮肤热容量；
* 接触面积；
* 接触换热系数；
* 身体核心交换时间尺度；
* 热源功率范围。

若现在就宣称焦耳、瓦特和摄氏度严格闭合，会再次进入大规模单位修补。

W2 建议使用：

[
Q=C_{\mathrm{norm}}\Delta T_{\mathrm{norm}},
]

但严格保证：

* 内部转移守恒；
* 源注入有界；
* 环境与核心耗散可追踪；
* 所有权重归一；
* 各时间尺度明确。

等 W2/W3 的拓扑和调度稳定后，再定义 physical-anchor 映射：

[
C_i^{\mathrm{phys}}
===================

\rho c_pV_i,
]

[
G_{ij}^{\mathrm{phys}}
======================

k\frac{A_{ij}}{d_{ij}}.
]

# 四、数值稳定守卫在 W2 应由“诊断”提升为“执行门”

W1.5 的 `is_stable()` 只诊断、不改变 `step()`，这个边界在 W1 是正确的。

但 W2 接入身体和热源后，不稳定参数不能继续执行。建议首轮采用 fail-fast：

```python
if not is_stable(graph, dt):
    raise ValueError("Unstable thermal diffusion configuration")
```

暂时不要自动子步进。

自动子步进会改变：

* 世界时间尺度；
* 皮肤发生时刻；
* (r_{\prec}) 的窗口解释；
* 世界 step 与神经 step 的相对比率。

应等 W4 做跨尺度标定后，再决定是否允许内部子步进。

# 五、W2 必须新增的测试

## W2A 热源—世界

1. 权重非负且和为 1；
2. 总注入量等于热源本步释放量；
3. 热源剩余能量正确减少；
4. 热源耗尽后不再注入；
5. 移动热源的支撑节点连续变化，无能量跳变；
6. 不稳定配置在 step 前被拒绝。

## W2B 世界—皮肤

1. 等温时接触通量为零；
2. 世界热、皮肤冷时方向正确；
3. 皮肤热、世界冷时方向反转；
4. 闭合系统世界+皮肤总能量守恒；
5. 皮肤存在热惯性，不一步跳到世界温度；
6. 身体移动导致接触权重变化，但不产生额外能量；
7. 离开热区后皮肤逐渐恢复；
8. 多皮肤点共享世界节点时，能量扣除只发生一次。

## W2C 联合调度

1. 节点遍历顺序不改变结果；
2. 皮肤点遍历顺序不改变结果；
3. 热源、扩散、接触使用同一时刻快照；
4. 联合账本残差保持在浮点误差范围；
5. 旧回归 21/21 不回退；
6. 契约失败集合不劣于父提交。
