# 一、当前调度不是报告写的顺序过程

报告把联合调度描述为：

[
\text{热源释放}
\rightarrow
\text{世界传播}
\rightarrow
\text{世界—皮肤交换}.
]

但实际记录的调用顺序是：

[
\text{稳定性检查}
\rightarrow
\text{定位}
\rightarrow
\text{接触通量快照}
\rightarrow
\text{source.release()}
\rightarrow
\text{graph.step()}.
]

而接触通量还被折叠进同一次 `graph.step()` 的注入字典。 

所以实际数值语义应是：

[
(T_w^n,T_s^n)
\longrightarrow
\left(
J_{\mathrm{diff}}^n,
J_{\mathrm{contact}}^n,
S^n
\right)
\longrightarrow
(T_w^{n+1},T_s^{n+1}).
]

也就是：

[
\boxed{
\text{同一步旧状态快照}
\rightarrow
\text{统一显式提交}
}
]

而不是先传播到新世界状态，再用新世界状态与皮肤交换。

这不是错误。相反，同步显式步进更容易保证守恒。但必须改正报告措辞，否则以后 P1 加入扩散、搬运、接触三类通量时，会再次出现“到底用本步前状态还是本步中间状态”的歧义。

建议将统一调度明确写成：

1. 对 (t_n) 的所有状态拍快照；
2. 计算所有源项、扩散通量、搬运通量和接触通量；
3. 验证稳定性及可用能量；
4. 一次性提交到 (t_{n+1})；
5. 更新联合账本。

# 二、现有稳定性守卫很可能没有覆盖接触边

原有 `is_stable()` 检查的是世界扩散数：

[
\eta_i^{\mathrm{diff}}
======================

\Delta t
\frac{\sum_jG_{ij}}{C_i}.
]

它是 W1.5 为 `ThermalLink` 建立的扩散稳定性诊断。

但 P0 新增了世界—皮肤接触导热：

[
H=hA,
]

[
J_{ws}=H(T_w-T_s).
]

对世界节点和皮肤节点的温差：

[
\Delta T=T_w-T_s,
]

显式步进给出：

[
\Delta T^{n+1}
==============

\left[
1-
H\Delta t
\left(
\frac1{C_w}+\frac1{C_s}
\right)
\right]
\Delta T^n.
]

因此接触边自身有稳定性数：

[
\boxed{
\chi_{\mathrm{contact}}
=======================

H\Delta t
\left(
\frac1{C_w}+\frac1{C_s}
\right).
}
]

数值不发散通常要求：

[
\chi_{\mathrm{contact}}<2,
]

如果项目希望温差单调衰减、不发生一步间正负翻转，则应采用更严格门槛：

[
\boxed{
\chi_{\mathrm{contact}}\leq1.
}
]

报告中的“不稳定配置拒绝”没有说明测试的是世界扩散不稳定，还是高 (h)、大面积、小皮肤热容导致的接触不稳定。

因此 P0 冻结前应补：

* 大 (h)；
* 大 `area`；
* 小 (C_s)；
* 大 `dt`；

四种接触失稳场景，并验证在 `source.release()` 前拒绝，三方状态均不变化。

最好将统一节点稳定数扩展为：

[
\eta_w
======

\Delta t
\frac{\sum_jG_{wj}+H}{C_w},
]

[
\eta_s
======

\Delta t
\frac{H}{C_s}.
]

这比只检查世界图更适合后面的多接触点扩展。

# 三、单位错误的发现很重要，但应升格为接口契约

本轮曾因为把接触通量预先乘一次 (dt)，又被 `graph.step()` 再乘一次 (dt)，产生 (dt^2) 错误；修复后守恒残差回到 (10^{-16}) 量级。

不应只把它留成代码注释。建议正式冻结以下量纲契约：

[
\boxed{
\texttt{external_injections}
\text{ 中的所有值一律是功率/电流，绝不是单步能量。}
}
]

即：

[
I\quad\text{或}\quad J
]

由统一状态更新器执行：

[
\Delta E=I\Delta t.
]

命名也应固定：

* `heat_flux`、`injection_current`：单位为能量/时间；
* `energy_transferred`、`delta_energy`：已经乘过 (dt)；
* 不允许同一个参数有时传功率、有时传能量。

P1 会再增加搬运通量，如果这条契约不正式化，(dt^2) 问题很容易复发。

## 最小动力学

使用节点实际储存能量 (E_i)，定义一条有向搬运边：

[
J_{i\rightarrow j}^{\mathrm{adv}}
=================================

a_{ij}(t)E_i,
\qquad
a_{ij}\geq0.
]

其中 (a_{ij}) 的量纲为：

[
[1/\mathrm{time}].
]

单步转移：

[
\Delta E_{i\rightarrow j}
=========================

J_{i\rightarrow j}^{\mathrm{adv}}\Delta t.
]

对称应用：

[
E_i^{n+1}
=========

E_i^n-\Delta E_{i\rightarrow j},
]

[
E_j^{n+1}
=========

E_j^n+\Delta E_{i\rightarrow j}.
]

必须满足：

[
\boxed{
\Delta t\sum_j a_{ij}\leq1
}
]

以防单步搬走超过源节点现有能量。

如果同一步还存在扩散和皮肤接触，应建立联合稳定性预算，而不是分别验证后假设组合仍稳定。

## P1 最小实验

只用：

* 5 个世界节点；
* 1 个有限热源；
* 1 条或 2 条有向搬运边；
* 1 个皮肤接触点；

测试至少包括：

1. 无搬运时退化为 P0；
2. 正向搬运时热量沿规定物理边移动；
3. 反转 (a_{ij}) 后搬运关系反转；

6. 扩散与搬运同时存在时仍闭合；
7. 同一瞬时温度分布、不同通量历史可以被 L2 接口区分；

最后一项很关键。P1 的价值不是“终于有了方向”，而是使世界出现：
