# 唯一需要在 P2-A1b-3 内验收的问题

当前映射为：

[
u(q)
====

\operatorname{clip}
\left(
0.0013759q-0.0550663,,
0,,
0.04
\right).
]

它对应的零输出转折约为：

[
q_{\mathrm{dead}}
=================

-\frac{b}{\kappa}
\approx40.02.
]

所以：

[
q<40.02
\Rightarrow
u=0.
]

这并非当前设计错误——它使静息和弱扰动不产生虚假发生；但它可能截掉真实皮肤传播轨迹的早期部分，造成：

* 较弱远端响应不再进入生成元；
* 不同节点的启动延迟被放大；
* 某些位置或次序差异在转导后消失。

这直接关系到后续 P2-A3 的时序分辨率，因此只需把它纳入 **P2-A1b-3 的接线验收**，不应另开阶段。

最低判据是：

[
\mathbf q^{\mathrm{skin}}_A(t)
\neq
\mathbf q^{\mathrm{skin}}_B(t)
]

经过转导和生成元以后，至少仍存在：

[
\Gamma_A^{\mathrm{occ}}
\neq
\Gamma_B^{\mathrm{occ}},
]

或者保留可测的启动顺序、延迟、发生次数或活动持续时间差异。

若早期轨迹被截断过多，只调整：

[
\kappa,\ b,\ u_{\min}
]

的接口配置，不回头修改皮肤动力学。

# P2-A1b-3 只做四件事

## 1. 驱动权归属守卫

建立明确模式：

[
m_i\in
{
\mathrm{MANUAL_CALIBRATION},
\mathrm{WORLD_COUPLED}
}.
]

要求：

* `feed()` 只能在手动模式调用；
* 皮肤转导驱动只能在世界耦合模式调用；
* 同一实例不能在运行中被双重驱动；
* 冲突必须立即报错，不能静默累加。

## 2. 正式接入转导映射

链路变为：

[
q_i^{\mathrm{skin}}(t)
\xrightarrow{\mathcal D_i}
u_i(t)
\xrightarrow{\mathrm{feed}}
\mathcal G_i.
]

同时保留原始：

[
q_i^{\mathrm{skin}}(t)
]

物理轨迹，不能只记录被 clip 后的 (u_i(t))。

## 3. 标定闭合参数

在真实映射轨迹下替换占位值：

[
\theta_\uparrow,\qquad
\theta_\downarrow,\qquad
t_{\mathrm{rearm}}.
]

只要求：

* 静息不触发；
* 一次连续作用只形成一次闭合；
* 作用撤去后能够退出；
* 满足重整条件后第二次输入能形成第二次发生；
* 弱噪声和阈值附近抖动不导致重复计数。

## 4. 验证过程差异没有被接口压平

复用已有的几个代表性皮肤过程即可，不必穷尽所有组合。至少验证：

* 不同位置；
* 不同次序；
* 单点与共同作用。

比较的是转导后生成元轨迹或发生边界，而不是只确认转导函数输出了不同浮点数。
