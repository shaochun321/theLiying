下一步应采用“**局部解耦、保持旧结构默认不变、用测试锁住边界**”的方式，而不是全局重构 `Memristor`。

[
\boxed{\text{先完成S0-bX1：候选身份与物理扰动解耦。}}
]

这是当前最有效、风险最低的构建方式。

## 一、不要直接删除旧扰动机制

旧机制：

[
\texttt{bundle_id}
\rightarrow \operatorname{crc32}
\rightarrow \delta w
]

在原有R1、R2链路里承担了打破完全对称的作用。现在的问题不是它普遍错误，而是候选池把：

[
\texttt{candidate_id}
]

嵌入了 `bundle_id`，导致审计名称间接影响初始物理权重。

因此不要全局改成“所有bundle都不再按ID扰动”。那可能影响已经冻结的P2结果。

应保留兼容行为：

```python
physical_seed=None
```

时仍采用旧规则：

```text
seed = crc32(bundle_id)
```

只有选择候选池显式传入：

```python
physical_seed
```

时，才改为：

```text
seed = physical_seed
```

于是：

[
\delta w=f(\texttt{physical_seed}),
\qquad
\delta w\perp\texttt{candidate_id}.
]

---

# 二、增加两个明确分离的身份

候选应同时具有：

```python
candidate_id      # 审计、谱系、日志
physical_seed     # 初始物理微扰
```

两者职责必须冻结。

### `candidate_id`

允许用于：

* 查找；
* 报告；
* 谱系记录；
* 测试结果对应。

禁止用于：

* 初始权重；
* 阈值；
* 资源配额；
* 更新顺序；
* 胜负判定。

### `physical_seed`

允许决定：

* 初始memristor微扰；
* 可复现的局部物理不均匀性。

但它也不能代表“预期胜者”。因此不要命名成：

```text
strong_seed
winner_seed
preferred_seed
```

只使用无语义数值，例如：

```python
physical_seed=73142
```

---

# 三、种子需要分三种用途

为了以后不再混淆，建议现在就区分：

[
\boxed{
s_{\rm audit},\quad
s_{\rm physical},\quad
s_{\rm stochastic}.
}
]

其中：

* (s_{\rm audit})：候选身份，实际就是 `candidate_id`；
* (s_{\rm physical})：结构初始微扰；
* (s_{\rm stochastic})：运行噪声或试验随机性，未来才可能使用。

当前只实现前两个。

不能让同一个字符串同时承担：

> 对象名称、结构地址、随机种子、物理差异来源。

这正是旧结构目前暴露的问题。

---

# 四、S0-bX1只做五个测试

## 1. 旧链路兼容性

未传入 `physical_seed` 时：

[
w_{\rm new}=w_{\rm legacy}.
]

确保P2的T1、T2、R2不被改变。

这项测试比立即跑大量仿真更重要，因为它直接锁定“旧冻结层不受影响”。

---

## 2. 同参、同种子、不同标签

构造：

[
\tau_0=\tau_1,
\qquad
s_0=s_1,
\qquad
candidate_id_0\ne candidate_id_1.
]

要求：

[
w_0=w_1,
]

并且：

[
Y_0(t)=Y_1(t)
]

在数值容差内逐步一致。

这是最直接的反身份泄漏测试。

---

## 3. 标签置换不变性

只交换：

```text
candidate_0 ↔ candidate_1
```

保持：

* 物理seed；
* (\tau)；
* 输入；
* 链路载体；

全部不变。

要求物理轨迹跟随物理配置，而不是跟随名称：

[
Y'_{\pi(i)}(t)=Y_i(t).
]

---

## 4. 不同种子产生可控差异

保持：

[
\tau_0=\tau_1
]

但设置：

[
s_0\ne s_1.
]

允许collector响应不同。

这样证明：

> 对称性打破机制仍然存在，只是它不再由候选标签控制。

---

## 5. 容器顺序不变

保留现在已有的存储顺序测试：

```text
[candidate_0, candidate_1, candidate_2]
```

和：

```text
[candidate_2, candidate_0, candidate_1]
```

结果按候选物理身份对应时保持一致。

但报告中要准确称为：

[
\text{容器顺序不变性},
]

不能再称为完整标签置换不变性。

---

# 五、不要立即解决“公平竞争”

S0-bX1完成后，只能得到：

[
\boxed{\text{候选身份不会直接进入物理动力学。}}
]

还不能得到：

[
\text{所有候选物理上绝对相同或竞争绝对公平}.
]

真实物理系统本来就可能存在微扰和不均匀性。竞争机制需要的是：

1. 微扰来源可追踪；
2. 微扰不由语义标签决定；
3. 多次试验时不固定偏向同一个审计身份；
4. 胜负能随环境和物理条件改变。

因此不需要把所有候选永久做成逐位完全相同。完全同参、同种子的场景只是**审计基线**。

---

# 六、S0-c之前再做一次资格门

S0-bX1通过后，先冻结候选输出接口：

[
a_i(t)=\mathcal O_{\rm candidate}(C_i,t).
]

需要明确竞争层到底读取：

* trace活动；
* collector活动；
* 还是候选输出电流。

我建议最终读取候选的统一局部输出，而不是直接读取内部trace：

[
\boxed{
a_i(t)=Y_i^{\mathrm{local}}(t)
}
]

原因是：

* trace只是关系生成链的内部中间态；
* collector或局部输出才代表候选已经取得R1式作用资格；
* 竞争层不应侵入候选内部挑选“有利信号”。

但S0-bX1不必马上新增输出链；先完成身份—扰动解耦，再单独冻结读取边界。

---

# 七、之后的推进顺序

建议接下来保持四步：

### S0-bX1：身份与物理种子解耦

解决当前唯一底层阻塞。

### S0-bX2：候选活动读取接口

冻结竞争层能读取的唯一活动量。

### S0-c0：批量资源请求接口

只收集同一物理步内的：

[
\mathbf r(t)=(r_1,\dots,r_N),
]

不进行胜者学习。

批处理必须满足S0-a已经冻结的：

[
\mathcal A(\pi\mathbf r)=\pi\mathcal A(\mathbf r).
]

顺序式 `try_allocate()` 已经被实验证明会产生先到先得，因此只能继续作为账本工具。

### S0-c1：最小竞争动力学

最后才加入公共抑制或资源分配。

## 最终建议

当前最有效的任务指令可以直接写成：

```text
执行S0-bX1，不进入竞争。

目标：
将候选审计身份candidate_id与Memristor物理初始化种子解耦。

要求：
1. 旧链路未显式传seed时保持原bundle_id哈希行为；
2. 候选池显式传physical_seed；
3. candidate_id不得参与权重、阈值或动力学参数计算；
4. 同参同seed不同标签时轨迹一致；
5. 只交换标签时物理结果不变；
6. 不同physical_seed允许产生可复现差异；
7. 不接资源池、公共抑制、DA、STDP或胜者逻辑。

通过后冻结S0-b。
```

这样既不会破坏已经冻结的P2底座，也能把旧机制的适用边界转化成一个明确、可复用的新接口。
