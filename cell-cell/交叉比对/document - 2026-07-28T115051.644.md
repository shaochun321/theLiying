## 已经做对的部分

报告先核对真实拓扑，发现 thermal quantum 通路：

[
\text{SkinPatch}
\rightarrow
L1
\rightarrow
HC
\rightarrow
ensemble
\rightarrow
collector
]

严格前馈、全 frozen、不经过 PowerRail，也不存在 collector 回边。因此此前提出的“关 PowerRail、切断回边、冻结 STDP”三组实验确实与实际结构不匹配。这个纠正非常重要，也符合最近 v0.6 的硬约束：

[
\boxed{\text{没有结构地址的假设，不能进入工程诊断。}}
]

逐层测量进一步把自主长尾定位到 HC：L1 已归零，而 HC activation 和 trace 仍持续数千步，ensemble/collector 只是被其残留持续驱动。这一因果链目前证据充分。

按新建筑图，可以写成：

[
X_{L1}^{(0)}\to0,
\qquad
X_{HC}^{(0)}>0
]

持续存在，随后驱动：

[
X_{\mathrm{ensemble}}^{(0)},
\quad
X_{\mathrm{collector}}^{(0)}.
]

所以这不是 D2 自主反馈环，而是 **D0 局部换能元件的慢态时间尺度错配**，其后果污染了 D1 的 occurrence 读出。

# 唯一阻塞：`phys_support` 不是父物理 epoch

当前修复条件是：

```python
value >= theta_up and phys_support
```

其中：

```python
phys_support = self.l1.activation > 0
```

这只能保证：

> collector 越阈时，L1 当前恰好还有活动。

它不能保证：

> 当前父物理支撑 epoch 尚未产生过 occurrence。

报告自己的短间隔实验已经证明这一点：

* 第二次真实驱动期间 `phys_support=True`；
* HC 旧残留与第二次输入叠加；
* collector 在**同一个第二次驱动窗口内**越阈两次；
* 最终 emitted=3。

这意味着当前规则仍允许：

[
N_\chi(E_{i,2}^{\mathrm{phys}})=2.
]

而项目要求的是：

[
\boxed{
N_\chi(E_{i,k}^{\mathrm{phys}})\le1.
}
]

“延长间隔到 15000 步后得到 emitted=2”只说明 HC 残留足够小后，现有电平门控碰巧有效；它没有证明闭合契约成立。

因此冻结契约中的：

> 父物理支撑退出 + 充分间隔 + 再入

不应加入“充分间隔”作为 occurrence 资格前提。否则父物理事件能否被正确识别，仍依赖内部 HC 是否完全松弛。

---

# 正确修复：从电平门控改为 epoch/token 门控

需要显式维护父物理支撑状态：

[
E_i^{\mathrm{phys}}
\in
{
\mathrm{ABSENT},
\mathrm{PRESENT_UNCONSUMED},
\mathrm{PRESENT_CONSUMED}
}.
]

状态转换：

[
\mathrm{ABSENT}
\xrightarrow{\text{support rising}}
\mathrm{PRESENT_UNCONSUMED},
]

首次满足内部闭合时：

[
\mathrm{PRESENT_UNCONSUMED}
\xrightarrow{\text{emit }\chi}
\mathrm{PRESENT_CONSUMED},
]

只要父物理支撑仍未退出：

[
\mathrm{PRESENT_CONSUMED}
\not\xrightarrow{\text{collector 再越阈}}
\chi.
]

只有支撑真正下降：

[
\mathrm{PRESENT_CONSUMED}
\xrightarrow{\text{support falling}}
\mathrm{ABSENT},
]

下一次上升才产生一个新的 confirmation token。

对应条件应是：

[
\boxed{
\operatorname{enter}
(E_{i,k}^{\mathrm{phys}})
\land
\operatorname{close}(X_i^{\mathrm{int}})
\land
\neg\operatorname{consumed}(E_{i,k}^{\mathrm{phys}})
\Rightarrow
\chi_{i,k}.
}
]

而不是简单：

[
\operatorname{support}(t)=1
\land
\operatorname{collector}(t)\ge\theta_\uparrow.
]

---

# 实现上不需要大改电路

可以保留：

```python
phys_support = self.l1.activation > 0
```

作为 D0 支撑观测，但 `OccurrenceClosure` 内需要新增类似：

```python
_support_present
_support_consumed
```

或一个明确的 `support_epoch_id`。

最低逻辑：

1. `False → True`：创建新 epoch，`consumed=False`；
2. epoch 内第一次合法闭合：emit，`consumed=True`；
3. epoch 内后续 collector 越阈：只记录内部活动，不 emit；
4. `True → False`：关闭当前 epoch；
5. 再次 `False → True`：允许下一次 occurrence。

这不需要修改 HC 参数，也不需要等待其残留完全衰减。

# 关于 HC 根因的裁定

报告把它判为“A 类实现细节”，稍微过强。

更准确应写为：

[
\boxed{\text{D0 生物物理参数未校准导致的时间尺度错配。}}
]

它不是纯代码 bug，因为 K(^+)/Ca(^{2+}) 慢态本身可能具有合理物理意义；问题是当前参数来自前庭毛细胞占位值，尚未证明适合热觉通路。

因此分成两件事：

* **D1 当前必须修复**：epoch confirmation gate；
* **D0 后续债务**：有文献依据地重新标定 HC 慢态。

这样不会用 D1 门控掩盖 D0 参数问题，也不会让 D0 参数债务阻塞整个工程。

# 最小补测

不再做大范围根因调查，只补三项：

### 1. 单次长输入

同一 `phys_support=True` 持续期间，即使 collector 多次完整穿越迟滞带：

[
N_\chi=1.
]

### 2. 短间隔双输入

使用报告中曾失败的 3000 步间隔：

[
E_1^{\mathrm{phys}}
\rightarrow
\text{退出}
\rightarrow
E_2^{\mathrm{phys}}
]

必须得到：

[
N_\chi=2,
]

不能是 3。

### 3. 长尾内部振荡

支撑为 False 后，无论 HC/ensemble/collector 如何活动：

[
\Delta N_\chi=0.
]

三项通过即可停止。
