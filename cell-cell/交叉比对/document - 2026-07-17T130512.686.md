# 一、P1-A：先补最小身份—拓扑契约

不建设完整网络地址系统，也不引入路由协议。只建立跨组件可审计的稳定身份。

建议地址形式：

[
\alpha(x)
=========

(
d_x,
u_x,
g_x,
v_x
),
]

其中：

* (d_x)：域，如 `world.cell`、`skin.patch`、`occ.thermal`；
* (u_x)：该域内稳定实例身份；
* (g_x)：生成深度；
* (v_x)：结构版本。

边身份：

[
\epsilon_e
==========

(
u_e,
\alpha_{\mathrm{source}},
\alpha_{\mathrm{target}},
m_e,
v_e
),
]

其中 (m_e) 表示机制类型：

[
m_e\in
{
\text{diffusion},
\text{contact},
\text{medium-transport}
}.
]

必须明确：

[
\boxed{
\text{地址不是坐标，端点顺序不是方向。}
}
]

## P1-A 验证

只新增结构测试：

1. 每条边的两个端点必须存在；
2. 端点域必须与机制兼容；
3. 对象列表重新排序后结果不变；
4. 节点索引改变但稳定地址不变时，物理结果不变；
5. 结构重建后版本递增，旧地址失效；
6. (e_{ij}) 与 (e_{ji}) 是两个不同的有序传输实例；
7. 禁止同一物理边被重复注册并重复扣账；
8. 所有状态变化都能追溯到明确源项或边身份。

其中最重要的是**排列等变性**。设节点顺序置换矩阵为 (P)，原更新算子为 (M)，重新编号后的算子必须满足：

[
M'
==

PMP^{-1}.
]

如果置换节点列表后物理结果发生了非置换意义上的变化，就说明代码仍偷偷依赖数组索引，而不是结构连接。

# 二、P1-A 同时引入最小计划—提交接口

此前只有 source、world、skin 时，可以把全部检查放在 `source.release()` 前。

P1 增加多条传输边后，正式进入：

[
\text{源项}
+
\text{扩散}
+
\text{接触}
+
\text{介质传输}
]

共同更新阶段。此时正适合建立最小的：

```text
prepare_physical_step(...)
apply_physical_step(plan)
```

`prepare` 只生成不可变的：

* 各节点拟增减能量；
* 每条边通量；
* source 拟释放量；
* 稳定性结果；
* 局部与全局账本预览；
* 参与的地址和结构版本。

`apply` 只接受已经验证的计划，并一次提交。

不需要复杂回滚，也不需要事务管理框架。核心约束只是：

[
\boxed{
\text{所有可能失败的检查均在第一次状态修改前完成。}
}
]

V3 已把这个接口列为“P1 引入更多输运边后再决定”的议题；现在正是应作出肯定决定的阶段。

# 三、P1-B：建设“有序介质传输”，不是方向

V3 中的 `AdvectiveThermalLink` 可以保留，但 P1 的正式名称应从：

> 守恒的介质搬运与非对称通量

进一步收紧为：

[
\boxed{
\text{P1：守恒的有序介质传输}
}
]

避免“非对称通量”又被理解成空间方向生成元。

对有序边：

[
e=(i,j),
]

定义：

[
J_e^{\mathrm{tr}}
=================

a_e(t)E_i(t),
\qquad
a_e(t)\geq0.
]

单步转移：

[
\Delta E_e
==========

J_e^{\mathrm{tr}}\Delta t.
]

并应用：

[
E_i^{n+1}
=========

E_i^n-\Delta E_e,
]

[
E_j^{n+1}
=========

E_j^n+\Delta E_e.
]

这里的 (i\to j) 只说明：

> 本次物理转移从哪个能量仓扣除、向哪个能量仓注入。

它不意味着：

* 前后左右；
* 环境方向；
* 自我方向；
* (r_\rightarrow)；
* 坐标轴上的正负。

## 联合稳定性

V3 已规定：

[
\Delta t\sum_j a_{ij}\leq1,
]

但 P1-0 已经证明，分开检查每种通道并不充分，必须联合核算。

对于世界节点 (i)，可以先使用一个充分的正性预算：

[
\boxed{
\eta_i^{\mathrm{joint}}
=======================

\Delta t
\left[
\frac{
\sum_j\kappa_{ij}
+
\sum_s H_{is}
}{
C_i
}
+
\sum_{e:,s(e)=i}a_e
\right]
\leq1.
}
]

它同时包含：

* 扩散出流；
* 世界—皮肤接触出流；
* 介质搬运出流。

更严格的测试方法是直接构造冻结参数下的一步能量更新算子：

[
E^{n+1}=ME^n+q.
]

封闭系统需要验证：

[
M_{ij}\geq0,
]

[
\mathbf1^\top M=\mathbf1^\top.
]

有环境泄漏时：

[
\mathbf1^\top M\leq\mathbf1^\top,
]

差额必须进入明确的泄漏账本。

这比单独检查几个经验阈值更能发现组合结构矛盾。

# 四、P1-C：原验证方案如何修改

## 已完成、只需保留为回归项

以下不再作为新的 P1 任务：

* 快照—验证—统一提交的调度措辞。

这些已经在 P1-0 完成。

## 应新增的验证

### 1. 局部、节点和全局三级账本

每条传输边：

[
\Delta E_{\mathrm{source}}^{e}
+
\Delta E_{\mathrm{target}}^{e}
=0.
]

每个节点：

[
\Delta E_i
==========

Q_i^{\mathrm{source}}
+
Q_i^{\mathrm{diff}}
+
Q_i^{\mathrm{contact}}
+
Q_i^{\mathrm{transport}}
------------------------

Q_i^{\mathrm{loss}}.
]

全系统：

[
\sum_i\Delta E_i
================

## E_{\mathrm{source,drawn}}

E_{\mathrm{loss}}.
]

不能只测最后一条，因为错误节点多扣、另一个错误节点多加，仍可能让全局账本为零。

### 2. 多边竞争

一个节点同时具有：

* 两条扩散边；
* 一条皮肤接触边；
* 两条搬运出边。

验证联合预算，而不是分别通过后拼接。

### 3. 拓扑置换

将五个节点的存储顺序完全打乱，保持地址和边连接不变，结果必须仅发生相同的索引置换。

### 4. 边端点交换

不要称“方向反转”。

应分别构造：

[
e_{ij}
]

和：

[
e_{ji}.
]

验证它们是两个不同的物理配置，并且能量扣减端和注入端正确交换。

### 5. 时间步收敛

使用：

[
\Delta t,\qquad
\frac{\Delta t}{2},\qquad
\frac{\Delta t}{4}
]

运行到同一个物理时刻，比较：

[
E(T;\Delta t),
\quad
E(T;\Delta t/2),
\quad
E(T;\Delta t/4).
]

应看到误差随步长减小而收敛，而不只是“都没有发散”。

### 6. P1 浸泡测试

P1-0 的 (10\tau_{ws}) 只覆盖单接触边。

P1 应按完整网络最慢非平凡模态设置浸泡时间。若一步算子的第二大特征值模为 (|\lambda_2|<1)，可以估计：

[
\tau_{\mathrm{slow}}
\approx
-\frac{\Delta t}{\ln|\lambda_2|}.
]

运行：

[
5\tau_{\mathrm{slow}}
\sim
10\tau_{\mathrm{slow}}.
]

只验证不变量：

* 能量不漂移；
* 状态非负且有限；
* 没有 NaN；
* 局部账本和全局账本持续闭合；
* 热源耗尽后无虚假注入；
* 固定输运结构下趋向正确稳态或持续流稳态。

# 五、V3 中一个验收表述必须修改

V3 当前写：

> L2 接口能区分“相同温度不同通量历史”。

这句话对当前计划的无记忆模型过强。

若：

[
J_e(t)=a_e(t)E_i(t),
]

则在同一时刻，若：

[
E(t)\text{ 相同},
\qquad
a(t)\text{ 相同},
]

通量必然相同，与历史无关。

所以当前 P1 能验证的是：

[
\boxed{
\text{相同温度状态}
+
\text{不同介质传输状态 }a
\rightarrow
\text{不同通量关系}.
}
]

即：

[
T^{(A)}=T^{(B)},
\qquad
a^{(A)}\neq a^{(B)}
]

导致：

[
J^{(A)}\neq J^{(B)}.
]

只有以后介质传输机制本身具有内部状态 (m(t))，例如惯性、流体储能或迟滞：

[
J_e
===

F(E_i,m_e),
]

才可能验证严格意义上的：

[
\text{相同瞬时温度和相同外部参数，}
\text{但不同历史产生不同通量}.
]

现阶段不应为了满足“历史”一词而强行增加介质记忆组件。
