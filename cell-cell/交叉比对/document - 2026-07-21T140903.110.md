## 唯一阻塞：低端启动边界存在实验不一致

新报告称：

[
u\leq0.0005
]

在 5000 步内全部不触发，而：

[
u=0.0007
]

首次触发，因此把启动边界定位到：

[
(0.0005,0.0007).
]

但此前 P2-A1a 粗扫描中：

[
u=0.0005
]

曾在第 4452 步产生一次发生。

FIX-019 的钳位只在：

[
200u\geq10
\quad\Longleftrightarrow\quad
u\geq0.05
]

时起作用，理论上不应改变 (u=0.0005) 的低端行为。因此两次结果不能简单归因于修复。当前报告把“5000 步未触发”称为“真正静默”也过强；它最多证明有限观测窗内静默。

P2-A1b 开始时应先执行一个短复核：

[
u\in
{0.0004,0.0005,0.0006,0.0007,0.0008},
]

每档至少：

* 多个全新生成元实例；
* 5000 步与更长观测窗；
* 固定随机性，或者确认整个链路完全确定；
* 记录首次触发时间的分布。

把边界写成有限窗口条件：

[
u_{\mathrm{on}}(T_{\mathrm{obs}})
=================================

\inf\left{
u:N_{\mathrm{occ}}(u;T_{\mathrm{obs}})>0
\right}.
]

在复核前，不冻结：

[
u_{\mathrm{on}}
]

的单一数值。

这不需要新增阶段，可作为 **P2-A1b-0**。

## 非阻塞一：当前 (\mathcal D_{\mathrm{disc}}) 只是 L1 级辨识区

报告根据：

但它还不能证明整个生成元在 (u<0.05) 范围内保持可辨识。HC、ensemble、collector 和闭合状态机可能再次压缩差异。

[
\mathcal D_{\mathrm{disc}}^{L1}
===============================

{u:a_{L1}(u)\text{可区分}},
]

[
\mathcal S_{\mathrm{cap}}^{L1}
==============================

{u:a_{L1}(u)=10}.

P2-A1b 要测量真正的生成元级区域：

[
\mathcal D_{\mathrm{disc}}^{G},
]

依据不能只看 `l1_activation_final`，而应至少比较：

[
R_G(u)=
\left(
L_{\mathrm{first}},
f_{\mathrm{occ}},
t_{\mathrm{active}},
t_{\mathrm{rearm}},
\mathbf a_{\mathrm{ensemble}},
\text{在线状态轨迹}
\right).
]

自然化和后续耦合真正使用的是：

[
\mathcal D_{\mathrm{disc}}^{G},
]

不是单独的 L1 线性区。

## 非阻塞二：P2-A2b 证明的是皮肤内部可区分，不是完整链路可区分

T-STP-6/7/8 已经有效证明三点皮肤结构可以保留：

* 不同作用位置；
* 不同作用次序；
* 单点与多点共同作用；

产生的完整三点状态差异，并且没有重新汇总成单标量。这足以通过三点皮肤自身的过程可区分资格。

但测试目前看起来是在三点皮肤上直接施加刺激，而原始债务来自：

[
world
\rightarrow
contact
\rightarrow
skin.
]

所以当前可以冻结：

[
\boxed{\text{三点皮肤内部过程可区分。}}
]

暂不能冻结：

[
\boxed{\text{不同世界过程经过接触以后仍然端到端可区分。}}
]

这不阻塞 P2-A1b，但应在审查点2前补一组端到端反例：

[
\Gamma_A^{world}
\neq
\Gamma_B^{world}
\Rightarrow
\mathbf q_{\mathrm{skin}}[\Gamma_A]
\neq
\mathbf q_{\mathrm{skin}}[\Gamma_B].
]
