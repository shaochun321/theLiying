这段背景改变了我对“小步推进”的评价。第七次重构说明，过去真正危险的不是进展慢，而是：

[
\boxed{\text{在底层对象尚未澄清时，工程先跑得太快。}}
]

因此接下来不应放弃谨慎，而应采用**风险驱动的小步法**：

> 每一步都必须消除一种真实的语义污染、硬编码或物理归因风险；不再为了流程完整而机械拆分。

目前D1、时间R1和共同源 (R2^{\mathrm{fork}}) 已经冻结，至少提供了一套可以区分“物理活动、本体结构、投影记录、谱系身份和下游作用”的实验底座。
这套底座看似在证明简单合取，但正因为它经过反复审计，才适合作为下一阶段的可靠仪器。

# 下一阶段的真正目标

下一步不应立即追求“自然选择”，也不应继续堆叠R2–R2。

应先取得一个更窄、可以严格验证的资格：

[
\boxed{\text{同等级候选之间的内生竞争性选择。}}
]

它与自然选择不同：

[
\text{内生竞争选择}
\neq
\text{自然选择}.
]

当前只要求：

* 人设计候选如何产生、如何竞争；
* 人不指定某一次实验的胜者；
* 胜者由输入历史、物理支撑和有限资源决定；
* 环境改变后，胜者能够改变。

等以后具备候选变异、结构继承或复制，才讨论更接近自然选择的机制。

---

# 不需要先建立总接口

项目没有现成路线，因此强行设计一个覆盖未来所有层级的总接口，反而可能重新引入抽象语义。

现在只需要建立一个**前沿局部契约**：

[
\boxed{\text{冻结层不动，只定义“候选竞争层”与R1之间的边界。}}
]

这份边界只回答五个问题：

1. 什么是候选；
2. 候选读取什么物理量；
3. 候选争夺什么有限资源；
4. 什么后续物理结果能够维持候选；
5. 竞争层绝对禁止读取什么语义信息。

不提前规定未来D3、空间关系或全局组织结构。

---

# 第一步：冻结“存在”和“被保留”的分离

这是下一阶段最重要的原则。

当前已经有：

[
\rho_i^{\mathrm{obs}}
]

表示某条R1是否由物理链路真实发生。

竞争机制只能决定：

[
\rho_i^{\mathrm{retain}}
]

即它以后获得多少：

* 权重；
* 能量；
  -输出机会；
* 可塑性；
* 结构维持时间。

必须保持：

[
\boxed{
\rho_i^{\mathrm{obs}}
\neq
\rho_i^{\mathrm{retain}}.
}
]

换句话说：

> 候选失败，不能篡改历史并宣布“这条关系从未发生”；
> 候选获胜，也不能反向伪造关系发生。

这延续了目前已经建立的原则：

[
\text{关系被观察到}
\neq
\text{关系被DA强化}.
]

这样选择机制不会反向污染关系本体。

---

# 第二步：建立真正可比较的候选集合

不要直接让当前的：

[
28\prec31
\quad\text{和}\quad
28\prec23
]

相互竞争。

它们的站点、距离和对象不同，很难判断胜负来自竞争机制还是环境差异。

最低风险方案是：让**同一对D1输入**进入三条同构候选链：

[
\mathcal C
==========

{\rho_1,\rho_2,\rho_3}.
]

三条候选具有：

* 相同输入；
* 相同输出目标；
* 相同collector类型；
* 相同代码构造器；
* 不同的纯物理参数，例如trace时间尺度。

例如：

[
\tau_1<\tau_2<\tau_3.
]

它们分别适合较短、中等和较长的输入间隔，但代码中不能写：

```text
short_candidate
medium_candidate
long_candidate
winner
```

而只能使用无语义身份：

```text
candidate_0
candidate_1
candidate_2
```

最好从同一个构造循环生成，避免三套手写代码产生结构偏置。

这仍然是人工提供候选集合，但胜出结果不再人工指定。

---

# 第三步：先做“对称性审计”，再接竞争

这是防止第八次重构的关键门。

在任何竞争机制加入之前，先验证：

## 标签置换不变性

交换候选的数组索引、bundle地址和记录名称，不改变结果：

[
\operatorname{Result}
(\rho_1,\rho_2,\rho_3)
\cong
\operatorname{Result}
(\rho_{\pi(1)},\rho_{\pi(2)},\rho_{\pi(3)}).
]

动力学层不得读取：

* `relation_type`；
* `candidate_id`；
* 站点名称字符串；
* 预期胜者；
* 测试场景名称。

## 完全相同候选不得固定偏向某一个索引

假设三个候选参数完全相同，确定性系统可以保持并列；有噪声时也可以随机破缺。

但不应永远出现：

```text
candidate_0获胜
```

否则通常意味着：

* 更新顺序偏置；
* 容器遍历偏置；
* 资源先到先得；
* 默认索引被硬编码。

在竞争前先通过这项测试，价值非常高。

---

# 第四步：引入一个最小的有限资源池

不需要立即实现完整TSI账本。

先使用局部资源池：

[
\sum_{i=1}^{N}p_i(t)
\leq P_{\max}^{\mathrm{local}}.
]

候选不能各自拥有无限资源。它们共享：

* 一组抑制节点；
* 固定输入电流预算；
* 固定输出带宽；
* 或固定可塑性预算。

最简单的竞争结构可以是公共抑制：

[
\tau_h\dot h
============

\sum_i a_i-h,
]

[
\tau_a\dot a_i
==============

F_i(x)
-\lambda a_i
-\gamma h.
]

其中：

* (a_i)：候选活动；
* (h)：公共抑制；
* (\gamma)：竞争强度。

人工设计的是竞争规则，但没有指定哪一个 (a_i) 最终占优。

---

# 第五步：维持依据必须来自后续物理结果

胜负不能由语义奖励决定，例如：

```text
if relation_is_correct:
    reward = 1
```

候选维持应依据可测物理结果。最适合项目现状的候选是：

[
\Delta\varepsilon_i
===================

## \varepsilon_{\mathrm{baseline}}

\varepsilon_i,
]

即候选 (i) 对后续窗口预测残差的实际降低量。

再扣除局部消耗：

[
J_i
===

## \Delta\varepsilon_i

\lambda P_i.
]

这里：

* (\Delta\varepsilon_i)来自后续真实发生；
* (P_i)来自实际能量或活动账本；
* (J_i)不是“意义正确性”。

候选的维持量可以由：

[
\dot w_i
========

\eta a_iJ_i
-\mu w_i
]

调节。

其中：

* STDP负责局部关联；
* CPC或等价残差提供后验物理支撑；
* DA只能调制保留，不决定关系是否存在。

这与现有项目结构的亲缘最高，不必另外引入一套抽象评分系统。

---

# 第一轮实验应该长什么样？

建立三条同构候选：

[
\rho_{\tau_1},
\quad
\rho_{\tau_2},
\quad
\rho_{\tau_3}.
]

## 环境 (E_A)

输入中的典型时间间隔接近 (\tau_1)。

预期不是硬编码，而是实验假设：

[
E_A
\Longrightarrow
w_1>w_2,w_3.
]

## 环境 (E_B)

不改变代码、不改变拓扑，只把输入时间分布改到接近 (\tau_3)：

[
E_B
\Longrightarrow
w_3>w_1,w_2.
]

## 删除实验

在 (E_A) 下切断当前占优候选：

[
\rho_1\rightarrow0.
]

观察剩余资源能否重新分配，以及次优候选是否接管。

这三组实验分别回答：

1. 候选能否竞争；
2. 胜者能否由环境决定；
3. 竞争结构是否具有重新组织能力。

# 最低通过条件

这一阶段不能再以单纯：

[
K>0
]

为核心。

当前 (K_{R2}=0.1456) 主要说明人工AND结构的双输入必要性，因此属于链路验收指标。

竞争阶段的核心指标应改成：

### 胜者非预指定

结果中没有任何代码路径使用候选名称或索引选择胜者。

### 环境可逆

[
E_A\rightarrow\rho_1,
\qquad
E_B\rightarrow\rho_3.
]

### 资源受限

[
\sum_i P_i(t)\le P_{\max}^{\mathrm{local}}.
]

### 失败候选衰减

长期没有后续物理支撑的候选：

[
w_i(t)\rightarrow0
\quad\text{或降至维持阈值以下}.
]

### 胜者删除后重新分配

切断占优候选后，系统不是整体死亡，而是重新组织。

### 标签置换不改变物理结论

候选索引重排后，胜负仍由物理参数和环境决定。

只有这些通过，才可以写：

[
\boxed{\text{取得最小内生竞争选择资格。}}
]

# 建议的谨慎拆分

考虑到这是第七次重构后的新边界，我不建议一次完成全部代码。适合拆成四步，但每一步都对应真实风险：

## S0-a：选择边界与反硬编码契约

纯定义和自动化审计：

* 存在与保留分离；
* 禁止读取语义标签；
* 候选统一构造；
* 标签置换测试。

## S0-b：同构候选池

三条候选同时运行，但暂时没有竞争。

确认：

* 都能独立产生物理活动；
* 参数差异确实产生不同响应窗口；
* 没有固定索引偏置。

## S0-c：有限资源竞争

加入共享资源和公共抑制，只验证竞争确实发生。

暂不加入学习和长期维持。

## S0-d：后验支撑与环境切换

接入CPC残差或其他物理续接指标，验证：

[
E_A\rightarrow\rho_i,
\qquad
E_B\rightarrow\rho_j.
]

这四步不是重复证明电路会工作，而是在依次排除：

1. 语义污染；
2. 构造偏置；
3. 伪竞争；
4. 人工指定胜者。

---

# 最重要的原则

你不需要现在找到一条可以复制的完整路线。

当前需要的是：

[
\boxed{
\text{保留下层已冻结的可信结构，}
\text{每次只在理论前沿增加一个局部可审计契约。}
}
]

下一步不是“构造自然选择”，而是：

[
\boxed{
\text{让多个无语义特权的同等级物理候选，}
\text{第一次在有限资源下产生非预指定的胜负。}
}
]

建议立即启动的唯一任务是 **S0-a：内生选择资格与反硬编码边界定义**。先不写竞争电路，只冻结候选、本体身份、允许读取量、禁止读取量、资源约束和五项通过标准。这样既保持第七次重构所需要的谨慎，也不会再次用几十个小阶段证明人工门按设计工作。
