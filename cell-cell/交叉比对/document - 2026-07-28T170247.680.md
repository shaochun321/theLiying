# 唯一需要修正的冻结措辞

报告现在说：

> 未发现有限的不可辨区／同时区。

这句话稍微过强，因为实验又定义了：

[
\eta_{ij}=4.
]

并使用：

[
\operatorname{Order}_{ij}
=========================

\begin{cases}
j\prec i,&\widetilde{\Delta t}*{ij}^{(1,\uparrow)}<-4,\
i\parallel j,&\left|\widetilde{\Delta t}*{ij}^{(1,\uparrow)}\right|\le4,\
i\prec j,&\widetilde{\Delta t}_{ij}^{(1,\uparrow)}>4.
\end{cases}
]

所以真正成立的是：

[
\boxed{\text{未发现动力学压平区，但存在由当前不确定度预算定义的操作性同时区。}}
]

两者必须区分。

## 动力学压平区

若不同外部间隔经过系统后变成同一个输出：

[
\Delta t_{\mathrm{ext},1}
\neq
\Delta t_{\mathrm{ext},2},
\qquad
\widetilde{\Delta t}_1
======================

\widetilde{\Delta t}_2,
]

这才是系统真正丢失时序差异。

本轮没有观察到这种现象：

[
\widetilde{\Delta t}*{ij}^{(1,\uparrow)}
\approx
\Delta t*{ij}^{(-1,\mathrm{ext})}.
]

## 操作性同时区

尽管系统仍保留差异，但在当前允许的初态变化范围内，小于不确定度预算的差异不取得可靠判序资格：

[
\left|\widetilde{\Delta t}\right|\le4
\quad\Longrightarrow\quad
i\parallel j.
]

因此在离散整数步实验下，可以冻结：

[
\boxed{
b_{ij}^{\mathrm{ord}}=5\text{步}
}
]

其含义是：

> 在当前预热平台、站点对、输入幅度和离散步长条件下，绝对间隔至少为 5 步时才取得有方向的顺序读出资格。

这不是说系统不能保存 1～4 步差异，而是这些差异仍位于当前操作性不确定区内。

# `C_{ij}` 暂不测是合理的

当前系统在相同条件下是确定性的，没有合法的 trial-to-trial 物理噪声模型。此时反复运行得到 100% 一致并不能代表现实意义上的概率可靠度。

所以暂时不定义：

[
C_{ij}.
]

但报告中最好避免使用“概率可靠”措辞，改成：

> 在已测试初态平台和确定性参数条件族内保持一致。

等到有物理依据的输入波动、元件噪声或参数分布后，再定义：

[
C_{ij}
======

P!\left(
\operatorname{Order}_{ij}^{\mathrm{read}}
=========================================

\operatorname{Order}_{ij}^{\mathrm{phys}}
\mid W
\right).
]

# `t_rearm` 的最终资格

这部分二轮修正正确：

[
t_\uparrow
]

可以承担发生启动时序；

[
t_\downarrow
]

描述活动退出；

[
t_{\mathrm{rearm}}
]

描述重新可用。

三者属于不同的 D1 时间读出，不能互换。

因此：

[
\boxed{
t_{\mathrm{rearm}}
\text{不是错误数据，只是没有判定发生先后的资格。}
}
]

它后续仍可用于：

* 重整周期；
* 闭合持续时间；
* 输入容量；
* 第二次 occurrence 可接受条件；
* HC 慢态诊断。
