# P2-A3 应严格做什么

P2-A3 现在不再研究单通道是否闭合，而是研究两个已经取得物理确认资格的发生之间，系统能够分辨怎样的时序关系。

输入对象应当是：

[
\chi_i^{(1)},\qquad \chi_j^{(1)},
]

而不是 collector 原始峰值。

## 1. 建立在线转换流

完整 `Occurrence` 只有在 rearm 后才形成，不适合直接承担在线时序关系。

需要同时输出：

[
\xi_i^\uparrow,\qquad
\xi_i^\downarrow,\qquad
\xi_i^{\mathrm{rearm}}.
]

其中：

* (\xi_i^\uparrow)：父物理 epoch 内第一次合法闭合启动；
* (\xi_i^\downarrow)：内部闭合退出；
* (\xi_i^{\mathrm{rearm}})：重新具备接受下一父物理 epoch 的能力。

完整记录继续保留为：

[
\chi_i=
\left(
t_\uparrow,
t_\downarrow,
t_{\mathrm{rearm}},
1,
\alpha_i
\right).
]

## 2. 测量成对时序分辨率

对两个独立生成元 (i,j) 扫描物理输入间隔：

[
\Delta t_{ij}^{\mathrm{ext}}.
]

至少覆盖：

[
i\prec j,\qquad
j\prec i,\qquad
i\parallel j.
]

测量系统能否稳定地区分：

[
\operatorname{Order}_{ij}
\in
{
i\prec j,,
j\prec i,,
i\parallel j,,
\text{不可分辨}
}.
]

## 3. 区分三类时间

P2-A3 不应再使用裸的“时间差”，而应分别记录：

### 外部物理间隔

[
\Delta t_{ij}^{(-1,\mathrm{ext})}.
]

### D1 发生启动间隔

[
\Delta t_{ij}^{(1,\uparrow)}
============================

t_{\uparrow,j}-t_{\uparrow,i}.
]

### D1 完整闭合间隔

[
\Delta t_{ij}^{(1,\chi)}
========================

t_{\mathrm{rearm},j}-t_{\mathrm{rearm},i}.
]

三者不能默认相等。

## 4. 形成 P2-A3 的最小输出

建议最终输出四个量：

[
\mathfrak T_{ij}^{(1)}
======================

\left(
b_{ij},
\varepsilon_{ij},
\tau_{ij}^{\mathrm{overlap}},
C_{ij}
\right),
]

其中：

* (b_{ij})：能够可靠判定先后的最小外部间隔；
* (\varepsilon_{ij})：观测到的启动时序误差；
* (\tau_{ij}^{\mathrm{overlap}})：两个 occurrence 可同时处于活动态的范围；
* (C_{ij})：多次重复下的顺序一致率。

这仍是 D1 发生之间的时序读出，不应提前称为 D2 时间关系算子。

# P2-A3 的停止标准

只需回答：

1. 两个真实 occurrence 是否可独立形成；
2. 多小的外部间隔仍可稳定区分先后；
3. 多小的间隔会被系统压成同时或不可分辨；
4. HC 慢态是否造成时序偏移、漏计或次序反转；
5. 在线状态流能否供 P2-B 使用。

满足后即停止，不要求在 P2-A3 中构造关系生成元。
