## 三、修正案（E-1~E-7）

**E-1（最重要）raw track 数据缺口——N3 当前不可计算**：
方案 §6-N3 的 A_i=∫_{W_i} a_i(t)dt 需要 occurrence 窗内的逐步活动轨迹，
但 G0-R1 交付的数据只有三边界+能量汇总（collector trace 仅存在于运行时
内存），`OccurrencePortV2.raw_track_ref` 当前指向的 closure_timing.csv
只有 t_up/t_down/t_rearm 列。**修正**：dataset_builder 必须重跑 parent
G0 并逐步录制 raw track（collector 值+支撑标志+输入 u）入
IMMUTABLE_CACHE（§25），port 重新生成、raw_track_ref 指向缓存文件。
这是 §24 物理轨迹预算（≤24 条）的主要花销——3 个 G0 × cal12/hold8
场景组合在预算内（relation 参数扫描走 replay 不耗物理轨迹）。

**E-2 §38 关键问题的实测答案与缺口定位**：
现有 tss/relations primitive（relation_event_adapter / r1_structure /
temporal_r_prec 系列）全部消费 **live 电路对象引用**
（`circuit.thermal_quantum_l1_warm[pid]`、collector 对象等），没有离线
port 入口——**不能直接消费 OccurrencePortV2**。但元件级可复用清单明确：
①RelationInputNeuron（关系电流换能边界，PHYS 直通先例）②relation
collector 电容标定模式（C=7.920427e-07，EXP-C0-02/C1-01 推导链）
③SynapticBundle/Capacitor 原语。**接口缺口 = 一个 replay 驱动 adapter**
（port/缓存轨迹 → 逐步输入电流序列）——按方案 §38 自己的分支："明确
记录接口缺口，再做最小新实现"。

**E-3 ŷ→relation 输入的强制换能路径**：
方案 §8 "优先复用 Capacitor/Neuron/SynapticBundle" 须收紧为强制合同：
自然化输出 ŷ 进入 relation cell 必须走 **HC-009 换能模式**（换能神经元
+ frozen SynapticBundle → relation cell），禁止在 step() 循环内
`_membrane.inject()` / 直接设电容电荷（红旗清单 HC-016/017/023/024
家族）。RelationInputNeuron 正是现成的这一层。否则 D2-M3（物理实现门）
会被"数学状态+直接注入"绕过。

**E-4 N1/N2 的因果性条款（合同级，本轮不阻塞）**：
N1 的 ϑ_i(t) 分母 t_rearm−t↑ 与 N2 的 f(τ_i,τ_j) 都要求 occurrence
**完成后**才可知的量——live 语境下是未来信息。本轮 replay-first（§26）
不受影响，但自然化合同应显式登记：**N1/N2 = REPLAY/REFERENCE 合法；
live 端到端需因果变体**（如用该生成元上一次 occurrence 的 τ 或 G0
canonical rearm=0.5s 作分母）——沿 live=S0/reference=S1 二分的同一
先例，避免未来 live 轮再付一次学费。

**E-5 §17 自激负对照直接继承既有门控**：
"无新父 occurrence ⇒ ΔC_phys=0" 的语义与 OccurrenceClosure 的
epoch/token 物理支撑门控（P2-A1b-3R 二轮修正）同构——relation closure
prototype（§21）应直接继承该机制（phys_support=父 port 活动在场），
勿重新发明。

**E-6 UTF-8 修复范围（§36）**：
属实且必修。建议范围：①研究区全部写入代码 `open(..., encoding="utf-8")`
（含 csv/json/jsonl）；②已冻结数据文件**字节不动**（不重写历史文件，
避免假 diff；今后重跑自然转为 UTF-8 时按冻结脚本零 diff 流程核对）；
③写入 exp-script 脚手架规范作为强制项。同意"不算新 G0 阶段"。

**E-7 预算与矩阵核算（确认项）**：
C0-C5 六类 × cal12/hold8 + 负对照四类：物理轨迹集中在 dataset_builder
一次性生成（E-1），relation 侧全部 replay 扫描 + adaptive boundary
search（O(log N)）——§24 上限（trajectories≤24 / params≤16 / seeds≤3 /
interventions≤6）可行。C6 history attack 按 §12 放在 C0-C5 通过之后，
与 hidden dynamics 复用（§13）合并为一步，节省干预预算。

## 四、方法学亮点（确认，无需修改）

- §15/§16 纯共现与无历史负对照 + §30 D2-M6：三层递进把"计算出关系值"
  与"产生关系过程"彻底分离——预期 NC1 结果 RELATION_SIGNAL=YES 而
  GENERATOR_CANDIDATE=NO 是正确的诚实预设

  防 Goodhart，与 T1-A 候选族纪律一致

  ——正确吸收 G0-R1 K7"完成数∈{0,1} 如实登记"的预注册风格
- §20 Δt_ρ=积分分辨率而漂移检查——D1/D2 时间债务教训的前置防复发
