# 五、P0-4：修正 F1 反馈量纲

母体真实定义：

\[
MOSFET.conduct(V)
=
g_m(V-\theta)
\]

返回的是**电流**。

因此当前形式：

\[
k\cdot MOSFET.conduct(V)\cdot V_{\rm rail}
\]

若 \(k\) 无量纲，则量纲为：

\[
A\cdot V=W
\]

不能作为电容注入电流。

必须修正。

优先方案：

\[
\boxed{
I_{fb}
=
\sum_{n=1}^{N}MOSFET_n.conduct(V)
}
\]

即使用 N 个同型反馈 FET 并联。

这样：

```text
N = 1,2,3...
```

是物理拓扑数量，不是凭空的连续 gain。

若必须保留：

\[
k
\]

则必须写清：

```text
[k] = ?
```

并给出真实物理来源。

不得再以：

```text
DA gate eta=7.5
```

作为 F1 feedback gain 的参数出处。

不同物理过程的数值相等不构成量纲或结构依据。

新 TSS 线路继续与 DA 隔离。
