更稳妥的做法是先关闭 P2-B 的接口债务，然后回到原主线进入 P2-C。事件核应暂时保留为后续候选，而不是现在提前升格为生产组件。

# 一、原冻结方案是什么？

7 月 21 日冻结的执行总纲明确规定：

[
\boxed{
P2\text{-A}
\rightarrow
P2\text{-B}
\rightarrow
P2\text{-C关系—关系生成}
\rightarrow
\text{结构／行为算子资格门}
\rightarrow
\Omega\text{或L3}
}
]

而且当时明确写了：

* P2-B0：单个 occurrence 自然化；
* P2-B1：两个自然化发生进入固定候选关系结构；
* P2-C：首次关系—关系生成；
* 地址化预生成、组织生长等问题放到 P2-C 后、结构算子资格门前再设计。

因此我们后来提出：

[
P2\text{-B1R}
\rightarrow
P2\text{-B1K0事件元支撑绑定器}
\rightarrow
P2\text{-B1K1事件核}
]

这不是原方案自然延续，而是一次**未经正式冻结的路线插入**。

# 二、目前已经发生的第一个偏移：P2-B1没有真正完成“两个 NaturalUnit 输入”

P2-B1 的原目标写得很清楚：

[
\text{两个 NaturalUnit 输入}
\rightarrow
\text{真实关系载体}
\rightarrow
\text{学习资格}.
]

但实际实现中，关系电路读取的是两个冻结站点 collector 的在线 (\xi) 输出；D2 关系地址也直接以两个皮肤站点物理地址为 parent，而没有使用完整的 `Occurrence.address` 或 `NaturalUnit.address`。报告自己也把这一点登记为非最终形态。

这意味着实际完成的是：

[
\boxed{
D1\text{在线发生信号}
\rightarrow
D2\text{关系电路}
}
]

但没有完整完成：

[
\boxed{
D1\text{有类型自然单位身份}
\rightarrow
D2\text{有谱系关系实例}.
}
]

这不是说 P2-B1 无效。它证明了真实关系检测和局部学习链路。

但它说明 P2-B 尚有一个接口债务：

> 关系信号来自真实 D1，但关系实例的身份谱系尚未真正经过 D1 NaturalUnit/Occurrence。

---

# 三、第二个偏移：P2-B1R降低了原验证目标

P2-B1R 原本要回答：

[
\Gamma_{\mathrm{with},\rho}^{+}
\not\sim
\Gamma_{\mathrm{without},\rho}^{+},
]

即关系记忆是否改变未来响应。

实际由于自然 collector 激活不足，以及单束作用在 DA 池中被淹没，方案改成直接录制和回放 `pre_trace`，最终只证明：

[
\Delta w
\neq0
\Rightarrow
\Delta I_{\mathrm{local}}\neq0.
]

L1 局部电流差异通过；DA 池整体轨迹差异为零。

这是一个有效的局部因果资格，但它不是完整的未来作用资格。

所以应冻结为：

[
\boxed{
\text{P2-B1R取得局部关系作用资格，}
\text{没有取得全局未来过程差异资格。}
}
]

这里最大的风险不是实验本身，而是后续把 L1 资格解释成：

> 已经有了可以组成连续事件的元支撑。

局部电流具有物理作用是必要条件，但尚不足以证明它是一个连续事件的必要元支撑。它可能只是关系电路内部极微弱的一条边。

---

# 四、第三个偏移：我们过早把“事件核”放到了 P2-C 前面

这是当前最需要停止的地方。

项目原路线之所以安排：

[
P2\text{-B关系}
\rightarrow
P2\text{-C关系—关系生成}
\rightarrow
\text{结构算子资格门},
]

是因为单一关系还不足以定义事件组织。

目前只有：

[
A\prec B
]

的一条 fast 方向可塑边。

尚未完成：

* 反方向关系；
* slow 时间尺度；
* 关系与关系的组合；
* 多关系共同支撑的组织；
* 关系结构的独立可辨未来效应。

此时直接定义：

```text
EventKernelSpec
EventSupportBinding
EventInstanceCandidate
```

会有两个危险。

## 危险一：语义先于结构

我们会在代码中预先命名：

```text
A_PRECEDES_B_FAST_EVENT
```

然后规定它需要哪些支撑。

这很容易变成：

> 设计者先声明这是一个事件，再让程序检查声明的材料是否齐全。

而不是：

> 多个关系结构首先形成可闭合、可复现、具有独立未来作用的组织，然后才取得事件资格。

这会触碰原总纲的“结构优先、禁语义硬编码”约束。

## 危险二：把地址绑定误当成事件形成

即使我们成功绑定：

[
u_A,\quad u_B,\quad \rho_{A\prec B},\quad B_\rho,
]

也只证明：

> 这些对象属于同一条谱系。

它还没有证明：

* 它们共同构成一个连续闭合过程；
* 移除其中一项会破坏未来组织；
* 这个组合不能被已有关系表示吸收；
* 它具有独立的事件边界。

所以 `EventSupportBinding` 当前更准确的名字应当是：

[
\boxed{\text{RelationLineageBinding}}
]

而不是事件元支撑绑定器。

---

# 五、因此现在应该怎样调整？

建议不实施 P2-B1K0，改成一个更小、更忠于原路线的收口阶段：

[
\boxed{\text{P2-B1X：D1→D2谱系与在线接口闭合}}
]

它不是新理论阶段，只是把 P2-B1 原目标中尚未完整落实的接口补齐。

# 六、P2-B1X 具体做什么？

只完成三件事。

## 1. 区分在线信号与完成后记录

D2 时序检测需要在线信号：

[
\text{TransitionEvent}
\rightarrow
\rho_{A\prec B}.
]

不能等待完整 `Occurrence` 到 rearm 后才开始判断先后。

但是关系实例完成注册时，应回填或绑定：

[
\rho_{A\prec B,k}^{(2)}
\rightarrow
\left(
\operatorname{OccurrenceAddress}*{A,i},
\operatorname{OccurrenceAddress}*{B,j}
\right).
]

因此需要一个显式桥接结构，例如：

[
\boxed{
\text{在线 epoch identity}
\longrightarrow
\text{完成后的 Occurrence/NaturalUnit identity}.
}
]

这正好延续此前已经冻结的“在线转换流与完整审计记录分离”原则，而不需要发明事件核。

---

## 2. 修正 D2 关系实例的 parent 谱系

当前：

[
\rho^{(2)}
\rightarrow
(\text{skin}*{28},\text{skin}*{31}).
]

目标：

[
\boxed{
\rho_{A\prec B,k}^{(2)}
\rightarrow
\left(
\mathfrak u_{A,i}^{(1)},
\mathfrak u_{B,j}^{(1)}
\right)
\rightarrow
(\text{skin}*{28},\text{skin}*{31}).
}
]

皮肤地址仍然保留，但作为 D1 的下游物理支撑，而不是被 D2 直接跨层使用。

---

## 3. 防止跨 epoch 错配

至少测试：

* 正确 A epoch 与正确 B epoch 能形成关系实例；
* 相同站点但不同轮次的 A、B 不能错误拼接；
* 缺少完整 occurrence 时，可以存在在线关系候选，但不能取得完成后的 D2 审计资格。

这一步完成后，P2-B 才真正实现：

[
\boxed{
\text{真实 D1 发生}
\rightarrow
\text{有类型、有实例身份的 D2 关系}.
}
]

---

# 七、之后回到 P2-C，而不是继续构建事件核

P2-B1X 完成后，按照原路线进入：

[
\boxed{\text{P2-C：关系—关系生成}}
]

P2-C 要回答的是：

> 多条已经有真实谱系的 D2 关系，能否形成一个新的、不可约的关系结构？

例如不是直接宣布“这是一件事件”，而是先验证：

[
\rho_1,\rho_2,\rho_3
\xrightarrow{\mathcal C^{(2)}}
O_{\rho\rho}.
]

然后测试：

[
\Gamma_{\mathrm{with},O_{\rho\rho}}^{+}
\not\sim
\Gamma_{\mathrm{without},O_{\rho\rho}}^{+}.
]

只有在这种组合结构取得独立未来作用以后，才有较充分基础讨论：

* 它是否构成事件核；
* 哪些关系是必要元支撑；
* 如何产生 enter/hold/exit；
* 如何从多个局部窗口粘合为连续事件；
* 如何形成残差源。

---

# 八、事件核的新理念不是放弃，而是重新定位

你最近形成的：

* 事件核；
* 元支撑；
* 过程连续条件；
* 后验重整；
* Mori–Zwanzig式未解析作用返回；
* 层论式跨窗口粘合；

都很有价值。

但现在更适合作为：

[
\boxed{
\text{P2-C之后“结构／行为算子资格门”的设计输入}
}
]

而不是 P2-B1 后马上写入生产代码。

也就是：

[
\begin{aligned}
P2\text{-B1X}
&:\text{关系实例身份和谱系};\
P2\text{-C}
&:\text{关系—关系形成组合结构};\
\text{资格门}
&:\text{验证组合结构的独立未来作用};\
P2\text{-K}
&:\text{从合格组合结构中抽取事件核与元支撑}.
\end{aligned}
]

可以把事件核阶段暂时改名为：

[
\boxed{\text{P2-K，而不是 P2-B1K。}}
]

这能避免误以为它仍属于 P2-B1 的局部收尾。

# 九、当前偏离审查结论

## 阻塞问题

[
\boxed{
\text{不能直接实施 P2-B1K0。}
}
]

它是未经正式修订的新路线，而且可能在关系—关系结构形成前，提前硬编码事件语义。

## 非阻塞问题一

P2-B1 没有完整落实两个 NaturalUnit 实例到 D2 关系地址的谱系，需要补接口，但不需要推翻关系电路。

## 非阻塞问题二

P2-B1R 只取得 L1 局部作用资格；L2 全局未来作用仍未通过。它可以作为后续证据，但不能作为“连续事件元支撑已经成立”的充分证明。
