## 二、勘误与修正案（E-1 ~ E-7）

### E-1（最重要，开工前必裁）：posterior 时点物理可达性缺口

方案 §6 硬要求 t_Δ > t_rearm,W。实测存档：

- **W 候选窗**：rc_main t_up/t_down/t_rearm = **3332/4931/5387**（`relation2_occurrence_candidates.csv` 第 2 行）；其余 4 候选 rearm ∈ [5258, 6358]，无更早者。
- **现有 site23 发生窗**：最晚 s23_far_b C=[4577,5216)（`site23_occurrence_manifest.csv`）。**没有任何现成 occurrence 窗起于 5387 之后**——§8 "如果现有 site23 trace 已足以构造 posterior event → NEW=0" 的乐观分支实际不成立，新轨迹是必然消费。
- **NF-1 封锁晚时刻录制**（`d21_negative_findings.json` + `dataset_builder.py` docstring 33-39 行）：换能潜伏期随 t_on 单调漂移（1000→521 步 … 5000→637 步）；t_on=5000 时 collector 越阈 k=5637 落在支撑窗（脉冲 [5000,5600)+L1 尾）外 ⇒ ΔC_phys=0 门拒绝 ⇒ 零 occurrence。
- **定量后果**：near 时点（δt=1×τ₂=456，需 t_up≈5400+）要求 t_on≈4790（按漂移外推潜伏≈620），紧贴 NF-1 失效边缘，成败未知；middle（δt=912）要求 t_on≈5300，大概率失效；far（δt=1824，t_up≈7200 ⇒ t_on≈6600）**物理不可达**。§30 预算的 4 条新轨迹可能全部消耗在探边上。

**修正案**：§19 的 {1,2,4}×τ_residual 三点网格在开工前改为"自适应+可达性前置探测"：先用 1~2 条新轨迹实测 t_on∈(4000,5000) 的可用上界，near 点若不可达则整轮按终态 B 变体（POSTERIOR_TIMING_UNREACHABLE，新登记项）诚实收口。三条出路需用户裁定（见 R-1）。辅助缓解：amp=0.04 使窗提前 51 步（M6 H3 先例，域内合法），量级不足以单独解决。

### E-2：Δ 与 Q 的通道身份未指定 + NF-2 约束

方案 §9/§14 未指定 ΔΓ 和 Q 从哪个物理通道进入。本架构只有 R（depth-1 关系端口）与 C（site23）两束。NF-2 实测（工作报告 §三.3）：

- **R 通道单独驱动越 θ₂（峰 +52%）**——rc_R_only 已是 occurrence 候选。若 Δ 走 R 通道，必然触发**新的 χ_ρ₂ occurrence**，落入方案 §22 自己定义的 PARALLEL_NEW_STATE 混淆：查询差异可能全部由新发生的 Z_Δ 承载而非旧 Z_W 被重组。
- **C 通道单独驱动峰阈下 −2.8%**——不触发新发生，是干净的 posterior 注入通道。

**修正案**：预注册 Δ 主通道=C；R 通道 Δ 作为副实验时必须带"新发生记账"（新 occurrence 的 epoch/谱系单独登记，且 §22 判别强制执行）。Q 亦为 C 窗时距 θ₂ 仅 2.8%——刀锋位意味着 occ_Q 0↔1 翻转是读出阈值对微小模拟差的放大（§14 称之为"最强结果"需加限定）：**必须并报模拟量 I_W（轨迹度量）与 probe margin（峰距 θ₂ 的裕量）**，防止把阈值放大效应当作强证据单独出售。

### E-3：M5 阻断半门在本架构退化为同义反复

§20 要求"Δ 保持存在，但阻断它进入 Z_W 的物理通路"。E4 先例的阻断=端口级移除（`future_action_attack.py:74` `_run([], …)`）。但在单细胞两束结构中，Δ 的唯一去处就是 cell——移除其端口后 Δ 在系统中**不存在任何物理痕迹**，该臂与 (W=1,Δ=0) 臂逐位相同，I_W→0 是恒真式，M5 阻断半门零信息量。

**修正案**：阻断改为"断 bundle_c 传播、tin_c 照常换能"——Δ 物理存在于输入神经元（膜态/能耗照常演化），仅不到达 Z_W 载体。这是最小的真阻断，按 DIAGNOSTIC_INTERVENTION 先例（E-9 家族）登记，禁入 production。M5 的因果重担相应主要由移植半门（机制成熟）承担。

### E-4：持久性（P1/M3）的结构性事实须先讲清楚

- 全部束 frozen、§5 明令禁加塑性/latch ⇒ **系统不存在任何可塑持久基质**。膜态差异指数衰减（τ₂=456 步；rc_main t_rearm⁺ 残余 ≈ θ_down·e⁻¹ ≈ 0.096，约再 +5000 步才降到 1e-6 地板）。"washout 后 Z_11≠Z_10"因此**只能相对 washout 时长成立**——washout 越长必然趋同，P1 不是二元属性而是衰减曲线上的读数。
- 例外：**PowerRail energy 是唯一单调持久的状态**（耗散路径依赖，不回充）。§12 允许 resource path 作为 Y，则"仅 energy 差、膜态已趋同"的臂间差异在字面上可过 M3——但那是代谢记账差异，不是"过去关系的组织方式被改变"。

**修正案**：预注册三件事：(a) washout 时长（建议 1×τ₂=456 步，与 §19 网格同锚）；(b) Z 状态分量清单（膜态=主载体；tin 内态=短时；energy=单列）；(c) 判读规则——"仅 energy 差异"单独归类（建议登记为 RESOURCE_TRACE_ONLY，不计入 P1/P2），防止事后挑选分量。Step A substrate audit 的输出应包含 τ_residual 实测曲线，供 §19 网格与 washout 取值引用。

### E-5：终态 B 的判据应从二元改为分级（预期管理）

rearm 是 `OccurrenceClosure` 只读状态机的读出概念，**物理膜态在 closure/rearm 时不发生任何 reset**（`recursive_physical_impl.py` cell=纯 RC Neuron；closure 全部在 x 序列之上评估）。因此 t_rearm⁺ 必有非零残余（上算 ≈0.096 ≫ ε_num=1e-6），"与 Z_∅ 不可区分"要到 t_rearm 后约 5000 步才发生。§5 的二元 POSTERIOR_SUBSTRATE_ABSENT 几乎不可能以"完全消失"形式触发——真实结局是"衰减窗内存在 + 有限边界"。修正案：Step A 输出改为 (存在窗长度, τ_residual, 边界步数) 三元组，终态 B 仅当存在窗 < 最小可用 δt 时触发。

### E-6：§14 与 §28 的 Q-scale 矛盾 + typed 合同约束

§14 条 3 "Q 不参与 calibration" 与 §28 "Posterior-0 只允许标定 … query probe scale" 字面冲突。且本架构的驱动是纯相位斜坡 ϑ∈[0,1]（`build_phase_drive` 只消费 (t_up,t_rearm) 两个整数，**无幅值自由度**）——若把"query probe scale"实现为驱动幅值乘子，等于在 typed 合同（RC-1 acceptance）之外新开 DOF。修正案：Q 的"scale"操作化为**窗口选择**（选哪条已录 occurrence 窗、放在哪个已录位置），不引入幅值参数；§14/§28 统一措辞为"Q 的窗口选择可在 hold lock 前调整，Q 不得用于任何 g/θ/rearm 类参数标定（本已冻结）"。

### E-7：常规工程条款补齐

1. **回归验证**：方案未提。纯 research/ 层轮次仍应在收口时跑 `test_regression` 21/21 + tss fast 43（先例：D2-0/D2-1 均双跑）。
2. **报告存档**：§33 四报告建议落 `research/posterior_v0/data/` 或与工作报告并存；项目规范的六段式工作报告（`cell-cell/工作报告/`）照写，两者不互替。
3. **预算口径**（§30）："prior-state replays ≤12" 未声明 2×2 各臂是否计入（4 套 × 2 个 W=1 臂 = 8 次已占 2/3）；开工前在 budget ledger JSON 里写明口径（D2-1 诚实登记先例，含首跑中止事件）。
4. **UTF-8**：沿既有纪律（Windows 原生终端加 PYTHONIOENCODING 前缀）。
5. **命名撞名**：§15 的 P0/P1/P2 三层与项目历史 Phase 0-8、优先级标签 P0/P1 撞名。建议报告与代码内改用 PL0/PL1/PL2（posterior level）或首次出现时显式声明，防跨文档检索混淆。

## 三、RULING_REQUIRED（开工前待用户裁定）

**R-1（硬阻塞）：posterior 时点可达性的三选一**

| 选项 | 内容 | 代价 |
|:---|:---|:---|
| (a) 缩窗 | 只做 near（+条件性 middle），far 登记 LIM-POSTERIOR-TIMING（NF-1 定量引用） | §19 三点降为 1~2 点，时窗结论弱化 |
| (b) 允许声明式时间轴偏移 | 组合时间轴上对整段 W 形成（ρ 端口+C 窗整体）平移到更早位置，Δ 用已录窗原位 | 新自由度；破坏 D2-1"窗口绝对时刻纪律"（NF-1 正是拒绝平移才诚实登记的）；若裁准需在方案层写明合法性论证 |
| (c) 延长脉冲扩支撑窗 | 新录轨迹 P=600→~900，令晚 t_on 的越阈仍落支撑窗内 | 新剂量/时长 DOF，须预注册且与 §18 "同 duration 对照"条款协调 |

评判建议：**(a) 为默认**（最保守、零新 DOF），(c) 作为 near 点探边失败后的后备（预注册条件触发）；(b) 仅在用户明确接受纪律修订时采用。

**R-2：Δ/Q 通道指派**——建议裁定 Δ 主通道=C（阈下、不触发新发生）、R 通道=副实验（带新发生记账与 §22 强制判别）；Q=C 通道已录窗 + margin 披露义务（E-2）。

**R-3：Z 分量清单与 washout 预注册**——按 E-4 建议值（washout=1×τ₂；膜态主载体；energy 单列为 RESOURCE_TRACE_ONLY）。若用户无异议可按建议值直接写入 p0_common.py 预注册块。

## 五、总裁定
