# 反馈：动态皮肤 P2-A 与“自然单位”概念修正

**日期：2026-07-20**  
**性质：对《评判：211325 对我方评判的反评判》的修正补充**  
**适用范围：P2-A 当前构建，不修改 P1 已冻结底座，不提前设计 Ω、Xin 或行为算子**

---

## 一、总裁定

前一轮评判中关于以下工程事实与执行修正可以保留：

1. 现有十神经元结构已经存在，当前任务是抽取、参数化和建立正式输入/输出合同，而不是从零重建。
2. 当前发生检测只充分实现了上升沿，尚未把“触发—退出—重新武装”抽取为生成元自身的闭合状态机。
3. P2-A 第一版采用软件参考实现；未来硬件接口只保留输入合同位置，不实现，也不作为冻结前置条件。
4. 应复用现有 `ThermalFieldGraph` 构造最小局部皮肤支撑，并执行输入工作区间、成对时序分辨率和通道容量标定。
5. 原始频率与通道容量应双轨保留，不能用归一化结果替代真实物理差异。

但需要撤回一项此前隐含的概念等同：

\[
\boxed{\text{生成元完成一次闭合}\neq\text{自然单位本身}}
\]

更准确地说：

\[
\boxed{\text{闭合为自然单位化提供可测量的局部作用范围}}
\]

自然单位的原始目的，是把不同物理量经过各自生成元后转成可进入共同关系耦合的**无量纲组织量**；它不是事件边界的另一名称，也不能替代电、能量、脉冲和物理时间账本。

因此，P2-A 不应在本轮冻结一个最终 `NaturalUnit` 数据结构或最终自然单位公式。

## 二、术语边界修正

### 2.1 皮肤物理支撑

第 \(i\) 个局部皮肤支撑记为：

\[
s_i^{\mathrm{skin}}
\]

它是软件物理世界中真正承受接触、热交换、扩散与耗散的局部结构，具有稳定地址：

\[
\alpha_{\mathrm{phys}}(s_i^{\mathrm{skin}})
\]

当前可由 `ThermalCell`、`SkinThermalState` 或最小 `ThermalFieldGraph` 节点承担。

它不是传感器，也不是基础生成元。

### 2.2 局部感受转导结构

定义：

\[
\mathcal D_i^{\mathrm{sim}}:
x_i^{\mathrm{skin}}(t)\longmapsto u_i(t)
\]

其中：

- \(x_i^{\mathrm{skin}}\) 是局部皮肤物理状态；
- \(u_i\) 是基础生成元输入端口量；
- \(\mathcal D_i^{\mathrm{sim}}\) 是当前软件转导实现。

当前不再用“传感器”指代这一对象。未来硬件传感器只可能成为：

\[
\mathcal D_i^{\mathrm{sensor}}
\]

的一部分，与当前 `D_i^sim` 共享输入端口合同，但本轮不实现。

### 2.3 基础生成元核心

定义：

\[
\mathcal G_i:
(u_i,z_i)\longmapsto(\dot z_i,\xi_i^{\mathrm{occ}})
\]

其中 \(z_i\) 是十神经元集合、SynapticBundle 与 collector 的内部状态。

基础生成元负责：

- 蓄积；
- 内部传播；
- 触发；
- 活动退出；
- 耗散；
- 恢复；
- 重新武装；
- 产生可被后续关系结构消费的发生轨迹。

转导结构不得替基础生成元执行事件切分、峰值判定、burst 生成或语义分类。

## 三、\(u_i(t)\) 的修正定义

\(u_i(t)\) 不是自然单位，也不能在未审计生成元输入端口前武断指定为安培、pA、nA 或无量纲值。

本轮应将其定义为：

\[
\boxed{u_i(t)=\text{基础生成元正式输入端口量}}
\]

其量纲与合法范围由现有神经元模型的输入合同决定。

软件参考转导可从一个最小映射开始：

\[
u_i(t)=\kappa_i\,q_i^{\mathrm{skin}}(t)
\]

或在代码实际使用温度偏离时：

\[
u_i(t)=\kappa_i\left(T_i(t)-T_i^{\mathrm{rest}}\right)
\]

其中 \(\kappa_i\) 承担必要的量纲转换与增益，不允许通过名称暗示 \(q\)、温度和神经输入天然同单位。

P2-A1 必须通过扫描获得：

\[
u_{\mathrm{silent}},\quad
u_{\mathrm{on}},\quad
u_{\mathrm{work}},\quad
u_{\mathrm{sat}},\quad
u_{\mathrm{unsafe}}
\]

并测量：

\[
u\mapsto
\left(
L_{\mathrm{first}},
f_{\mathrm{occ}},
N_{\mathrm{occ}},
t_{\mathrm{exit}},
t_{\mathrm{rearm}},
E_{\mathrm{generator}}
\right)
\]

不能只把参数调到“若干秒内发放一次”便宣布标定完成。

## 四、发生闭合合同：保留，但降级为测量边界

第 \(k\) 次基础生成元发生记为：

\[
\chi_i^k
\]

其三边界为：

\[
\chi_i^k=
\left(
t_{i,k}^{\uparrow},
t_{i,k}^{\downarrow},
t_{i,k}^{\mathrm{rearm}}
\right)
\]

分别表示：

- \(t^\uparrow\)：从未触发状态进入有效发生；
- \(t^\downarrow\)：活动退出有效区；
- \(t^\mathrm{rearm}\)：重新具备下一次触发资格。

对应局部作用窗口：

\[
W_{i,k}
=
\left[
t_{i,k}^{\uparrow},
t_{i,k}^{\mathrm{rearm}}
\right)
\]

这一合同用于：

1. 防止持续饱和被误计为无限发生；
2. 防止阈值抖动被重复计数；
3. 给物理账本与后续无量纲测度提供同一局部范围；
4. 明确一次发生何时可以再次参与关系生成。

但必须冻结以下否定：

\[
\boxed{\chi_i^k\text{是一次完整发生，不是自然单位的最终定义}}
\]

## 五、自然单位的当前工作定义

### 5.1 原始目的

自然单位的作用不是取代物理量，而是：

\[
\boxed{
\text{使不同类型生成元在不直接比较原始量纲的情况下进入共同关系耦合}
}
\]

未来温度、压力、应力、光照或加速度生成元的原始输入分别具有不同量纲，不能直接相加或比较。

它们需要经过各自物理转导与生成元动力学后，再产生无量纲的组织接口。

### 5.2 发生与测度分离

一次发生是对象：

\[
\chi_i^k
\]

自然单位化是施加在发生上的无量纲测度：

\[
\mathcal N_i:
\chi_i^k\longmapsto\mathfrak n_i^k
\]

因此：

\[
\chi_i^k\neq\mathfrak n_i^k
\]

在当前最低层，可以暂时只使用计数测度：

\[
C_i(\chi_i^k)=1
\]

并保留生成地址：

\[
\alpha_i=\alpha_{\mathrm{gen}}(\xi_i^{\mathrm{occ}})
\]

得到一个**尚未冻结为最终理论对象**的最低组织记录：

\[
\left(C_i(\chi_i^k),\alpha_i\right)
=
(1,\alpha_i)
\]

这里的 \(1\) 只表示“一次有效发生”，不表示一焦耳、一次神经元尖峰、一秒或任意物理量。

### 5.3 P2-A 不冻结最终自然单位

P2-A 只需要保证：

- 一次完整发生可辨识；
- 可以计数；
- 生成谱系可追溯；
- 物理账本完整；
- 原始脉冲轨迹保留。

本轮禁止：

- 新建一个宣称最终资格的 `NaturalUnit` 类；
- 把 collector 第一次上升沿直接命名为自然单位；
- 把一次闭合与无量纲测度等同；
- 把所有发生压成无身份的标量 \(1\)；
- 用无量纲比例替代原始物理账本。

## 六、双轨记录合同

每次发生 \(\chi_i^k\) 必须同时产生两类记录。

### 6.1 物理—运行轨

记为：

\[
\Lambda_{i,k}^{\mathrm{phys}}
\]

至少保留可获得的：

- 皮肤状态轨迹；
- 接触通量或输入来源；
- 生成元输入 \(u_i(t)\)；
- 原始尖峰或 `pre_trace`；
- 触发、退出和重新武装物理时刻；
- 电位、电流或模型状态；
- 供能、功率和耗散；
- 饱和、失败与恢复状态。

这一轨负责物理约束与审计。

### 6.2 组织—无量纲轨

当前只保留最小候选：

\[
\Lambda_{i,k}^{\mathrm{org}}
=
\left(
1,\alpha_i
\right)
\]

后续可以检验但不得预设的候选包括：

局部相位：

\[
\vartheta_{i,k}(t)
=
\frac{t-t_{i,k}^{\uparrow}}
{t_{i,k}^{\mathrm{rearm}}-t_{i,k}^{\uparrow}}
\in[0,1)
\]

内部参与占比：

\[
\rho_{i,k,m}
=
\frac{a_{i,k,m}}
{\sum_j a_{i,k,j}+\varepsilon}
\]

以及跨生成元投影关系：

\[
r_\rho^\tau
=
[z_1^\tau:z_2^\tau:\cdots:z_n^\tau]
\]

两轨关系为：

\[
\boxed{
\Lambda_{i,k}^{\mathrm{org}}
\parallel
\Lambda_{i,k}^{\mathrm{phys}}
}
\]

无量纲化不得删除物理轨；物理轨也不直接成为深层跨模态耦合接口。

## 七、时间与空间的资格边界

### 7.1 局部时间

单个基础生成元可以通过自身闭合窗口形成局部无量纲相位：

\[
\vartheta\in[0,1)
\]

但必须同时保留真实持续时间：

\[
\tau_{i,k}^{\mathrm{phys}}
=
t_{i,k}^{\mathrm{rearm}}
-
t_{i,k}^{\uparrow}
\]

局部相位统一不同生成元的过程进度，不等于删除物理时间差异。

### 7.2 空间

单个基础生成元不能凭自身地址产生项目内部空间。

皮肤地址只表示物理支撑谱系：

\[
\alpha_{\mathrm{phys}}(s_i)
\]

空间关系必须从多个发生元之间的：

- 共同参与；
- 重复时序；
- 传播延迟；
- 可达性；
- 关系延拓和破缺；

中产生。

因此，本轮 P2-A 不定义“空间自然单位”。空间无量纲化至少要等到 P2-B 的关系原语接入后再审查。

## 八、对 P2-A / P2-B / P2-C 的重新分工

### P2-A：构造可闭合的真实发生

交付物：

1. 抽取并参数化已有 10 ensemble + collector 结构；
2. 正式定义 `D_i^sim → G_i` 输入合同；
3. 实现触发—退出—重新武装状态机；
4. 形成带稳定父支撑地址的 \(\xi_i^{\mathrm{occ}}\)；
5. 保存完整物理—运行账本；
6. 对完整发生进行计数，但不冻结最终自然单位公式。

P2-A 的核心问题是：

\[
\boxed{\text{连续皮肤物理过程能否形成可重复、可退出、可恢复的发生}}
\]

### P2-B：检验自然单位化是否真的有用

把 P2-A 的真实发生送回已冻结关系原语：

\[
r_\prec^\tau,\qquad
r_\rho^\tau
\]

验证：

1. 不同生成元的发生能否在不比较原始量纲的情况下共同参与；
2. 射影占比是否保留真实差异，而非只反映通道容量偏差；
3. 局部相位、频率和参与占比中哪些是必要的；
4. 最低记录 \((1,\alpha)\) 是否足够，还是必须增加内部比例或相位；
5. 无量纲关系能否在换尺度、换幅值时保持组织等价，同时不破坏物理账本。

只有通过这些测试后，才可以冻结第一版自然单位合同。

### P2-C：检验递归自然单位化

关系—关系生成若形成新的关系发生：

\[
\chi_\gamma^m
\]

则检验是否可以再次施加同类测度：

\[
\mathcal N_\gamma(\chi_\gamma^m)
\]

并作为下一生成深度输入。

P2-C 的关键不是“关系输出了一个新脉冲”，而是：

\[
\boxed{
\text{关系发生能否以同一自然化合同递归进入更深耦合}
}
\]

## 九、修正后的执行顺序

1. **抽取现有基础生成元结构**  
   参数化冻结站点索引；保持 10 ensemble + 独立 collector 的现有结构，不从零重建。

2. **建立正式输入合同**  
   明确 `D_i^sim → G_i`；`D_i^sensor` 仅作为未来接口名占位，不实现。

3. **抽取闭合状态机**  
   把测试中的临时 `was_below` 逻辑提升为可复用的 trigger/exit/rearm 组件或生成元内部状态。

4. **P2-A1：工作区间扫描**  
   标定 \(u_{\mathrm{on}}\)、\(u_{\mathrm{work}}\)、\(u_{\mathrm{sat}}\)、恢复时间和能量代价。

5. **P2-A2：最小动态皮肤**  
   复用 `ThermalFieldGraph` 构造三节点软件皮肤：
   \[
   s_1-s_2-s_3
   \]
   不与 W1 强行融合。

6. **P2-A3：时序与容量标定**  
   测量 \(b_{ij}\)、\(\epsilon_{ij}\)、\(f_i^{\mathrm{raw}}\) 与 \(f_i^{\mathrm{capacity}}\)。  
   软件误差源包括：\(dt\) 离散、RC 失配、执行顺序、数值积分与 collector 抖动。

7. **完成 P2-A 三通道发生**  
   输出发生闭合记录、生成地址与双轨账本，不输出最终 `NaturalUnit` 实体。

8. **进入 P2-B**  
   用真实发生重新标定并验证 \(r_\prec^\tau\)、\(r_\rho^\tau\)，在此阶段裁定自然单位化的最小充分字段。

## 十、P2-A 冻结契约补充

P2-A 只有在以下条件满足时才能冻结：

1. `world → contact → skin state → D_i^sim → G_i → ξ_i^occ` 链路连续运行；
2. 不依赖外部事件起止标签；
3. 每次发生具有 trigger/exit/rearm 三边界；
4. 持续输入、阈值抖动和恢复过程不会造成伪计数；
5. 发生地址能回接到明确皮肤物理支撑；
6. \(u_i\) 的输入端口量纲、缩放和工作区间有显式合同；
7. 原始物理、电、能量与脉冲轨迹未被无量纲化删除；
8. 当前只登记“发生计数 + 谱系”，不宣称已得到最终自然单位；
9. 三点通道的真实时序与频率差异未被容量归一化抹平；
10. P2-B 所需的原始异步发生接口可直接消费。

## 十一、禁止捷径

- 不把软件局部感受转导称为硬件传感器；
- 不把 `pre_trace` 第一次上升沿单独称为一次完整发生；
- 不把完整发生直接等同于自然单位；
- 不把自然单位等同于单个脉冲；
- 不把无量纲化理解为删除能量与电运行模式；
- 不把皮肤物理地址直接当成内部空间；
- 不提前在 P2-A 冻结占比、相位或自然单位字段；
- 不因未来硬件后端存在而要求当前接入真实硬件；
- 不为得到理想触发时间而单点调参；
- 不把不同通道自身容量归一化后宣称其频率已经可直接比较。

---

## 十二、最终反馈

本轮不否定自然单位概念，但将其从 P2-A 的“已经定义对象”撤回为 P2-B 需要验证的**无量纲耦合原则**。

当前最稳妥的表述是：

\[
\boxed{
\text{P2-A 构造一次可闭合、可计数、带谱系并受物理账本约束的真实发生}
}
\]

\[
\boxed{
\text{P2-B 检验如何对这些发生施加无量纲测度，使不同生成元进入共同关系耦合}
}
\]

\[
\boxed{
\text{P2-C 检验这种自然单位化能否递归到更深生成关系}
}
\]

因此，下一轮实现不需要解决“自然单位最终是什么”，只需要确保 P2-A 输出保留足够的原始发生、时间、脉冲、能量和谱系信息，使 P2-B 可以对多种自然单位候选进行真实比较，而不必返工底层生成元。
