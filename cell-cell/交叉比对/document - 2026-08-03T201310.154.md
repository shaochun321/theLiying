TSS-2a可以通过，但需要修正两个表述，然后才能构造 (\Lambda^{(1)})。

[
\boxed{\text{TSS-2a证明了现有资产足以支持尺度实验，尚未证明尺度算子已经形成。}}
]

## 需要修正的两点

### 1. `radius=2.0/3.0`是外部场条件，不是内部尺度算子

改变HeatSource半径实际上得到的是两次不同的外部发生过程：

[
\omega_{r=2}[W]\neq \omega_{r=3}[W].
]

所以目前证明的是：

[
\omega_{r=2}\mapsto\mathfrak C_{2},
\qquad
\omega_{r=3}\mapsto\mathfrak C_{3},
]

两种物理作用范围产生了不同的活动云。

它还不是：

[
\Lambda_{\lambda_1}(\mathfrak C_\omega),
\qquad
\Lambda_{\lambda_2}(\mathfrak C_\omega),
]

即**同一个外部发生过程被两个内部结构尺度算子同时作用**。

因此报告中的“两个真实不同的尺度窗口”最好改成：

> 两个不同的外部物理支撑范围，为内部尺度算子的构造提供了多成员活动云资产。

### 2. 超出半径的站点为何激活，原因尚未完全证明

“纯几何预测与实测不一致”是真实发现，但目前最多可以确定：

[
\boxed{\text{外部几何距离不足以直接预测内部生成活动云。}}
]

暂时不能完全归因于“memristor哈希扰动＋饱和”。

因为memristor扰动可以放大已有微弱输入，却不能凭空从严格零输入产生物理信号。还可能涉及：

* 皮肤节点间传播；
* 上游残余状态；
* 公共内部链路；
* 生成元阈值与饱和的共同作用。

这个原因不阻塞下一步，但报告应写成“候选机制”，不要冻结为已证明因果。

# 下一步：TSS-2b，构造双尺度物理算子

核心要求是：**同一个外部发生、同一片生成活动云，同时进入两个不同结构窗口。**

[
\boxed{
\omega[W]
\rightarrow
\mathfrak C_\omega[W]
\rightarrow
\begin{cases}
\Lambda_{\mathrm{local}}^{(1)}
\rightarrow Y_{\mathrm{local}},\
\Lambda_{\mathrm{broad}}^{(1)}
\rightarrow Y_{\mathrm{broad}}.
\end{cases}
}
]

两个尺度载体可以是：

[
N_{\mathrm{local}}
\subset
N_{\mathrm{broad}},
]

例如：

* 局部尺度读取小范围锚定生成元；
* 广域尺度读取包含该局部范围的更大生成元集合。

但成员集合必须由结构地址和物理连接固定，运行时不得读取欧氏距离或HeatSource半径决定归属。

## 最低工程结构

```text
同一次HeatSource发生
        ↓
32点基础生成元活动云
        ├─→ local bundles → local scale collector → Y_local
        └─→ broad bundles → broad scale collector → Y_broad
```

这两个collector必须是独立物理载体，不能在测试代码中直接：

```python
sum(local_sites)
sum(broad_sites)
```

否则仍只是软件聚合。

## 最关键的资格测试

设广域独有部分为：

[
N_{\Delta}
==========

N_{\mathrm{broad}}
\setminus
N_{\mathrm{local}}.
]

切断 (N_{\Delta}) 到广域尺度算子的链路后，应满足：

[
Y_{\mathrm{local}}^{\mathrm{cut}}
=================================

Y_{\mathrm{local}},
]

而：

[
Y_{\mathrm{broad}}^{\mathrm{cut}}
\neq
Y_{\mathrm{broad}}.
]

这才证明两个输出差异来自真实结构支撑范围，而不是名称或软件标签。

同时要求：

* 同一个外部 `OccurrenceInstanceId`；
* STDP与DA关闭；
* 不读取站点语义名称；
* 重命名地址不改变成员资格；
* 两个尺度算子具有各自输出链路；
* 切断共享核心时两个输出都受到影响。

## 完成后的最低资格

通过TSS-2b后，可以宣称：

[
\boxed{
\text{同一外部发生过程形成的内部生成活动云，
可由不同物理支撑范围的非学习算子产生不同下游作用。}
}
]

这就是第一条：

[
\Lambda_{\mathrm{support}}^{(1)}
]

而不是简单的“粗粒度／细粒度”数据处理。

所以当前不修改现有电路，也不补新场景。冻结TSS-2a为**尺度资产审计**，下一步直接构造“同一活动云、双物理窗口、双独立输出”的TSS-2b。
