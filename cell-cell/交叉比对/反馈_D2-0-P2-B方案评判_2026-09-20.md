# 二、对 E-1：raw track 数据缺口

接受。

当前 `OccurrencePortV2` 已足以承担：

- instance identity；
- generation depth；
- lineage；
- trigger/down/rearm；
- physical timestamp；
- typed input provenance。

但不足以直接计算：

\[
A_i
=
\int_{W_i}a_i(t)\,dt
\]

等逐轨迹自然化候选。

因此 D2-0 第一轮 physical trajectory 生成必须显式增加：

\[
\boxed{
RawOccurrenceTrack
}
\]

最低记录：

```text
t_phys
generator/site identity
input u(t)
collector/activity signal
phys_support flag
occurrence epoch
energy/resource snapshot where available
```

这里必须强调：

**raw track 是外部实验记录，不是新的内部生成元状态。**

其目的仅为：

\[
\mathcal N
\]

提供可复现输入。
