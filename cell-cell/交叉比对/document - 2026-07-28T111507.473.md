**新版理论文档不替代原来的工程计划**，它只是把当前振荡问题的理论边界说清楚了：

[
\text{内部激活}
\neq
\text{新的父物理确认}.
]

原 V7 的工程路线需要做一处调整。V7 仍把 P2-A1b-3 写成已完成，并准备直接进入 P2-A3；但长尾振荡会重复制造 occurrence，因此闭合资格实际上尚未完成。

# 下一步确实要测查根因，但只查到足以决策

不是彻查“它是否是严格极限环”“周期为何是 637 步”之类理论问题，而是回答两个工程问题：

1. 振荡由哪个区域最先自行再生？
2. 它依赖持续供能、反馈闭环，还是某个状态没有正确耗散？

## 第一步：定位首个自主再生层

外部皮肤输入撤去后，同时记录：

[
q^{\mathrm{skin}},
\quad
u,
\quad
L1,
\quad
HC,
\quad
ensemble,
\quad
collector.
]

寻找最早满足：

[
a_{\mathrm{upstream}}\approx0,
\qquad
a_k\重新上升
]

的区域。

例如：

* L1、HC 已静息，ensemble 重新上升：问题从 ensemble 开始；
* ensemble 已静息，collector 自己继续起振：collector 的状态或实现有问题；
* L1 本身也周期性恢复：可能是输入接线、内部供能或单元慢变量。

这一步只定位，不需要解释全部微观动力学。

---

## 第二步：做三个有判别力的隔离实验

### A. 禁止 PowerRail 撤去输入后的补能

皮肤输入结束以后，临时关闭 PowerRail 恢复，只允许已有内部能量自然耗散。

若振荡消失：

[
\boxed{\text{持续供电 + 内部回路形成有源振荡}}
]

说明不是皮肤热量没散掉，而是内部电路不断获得补能。

若振荡仍在：

[
\boxed{\text{内部储能变量、泄漏或状态更新可能异常}}
]

### B. 切断最小反馈回路

检查并临时切断：

[
collector\rightarrow ensemble
]

以及 ensemble 内部可能的回边。

若切断某条边后振荡消失，就说明发生读取区被错误纳入了再生回路：

[
\boxed{\text{发生读取器同时成为了发生再生器}}
]

这就是“振荡发生区域设置不合理”。

### C. 冻结慢变量和可塑性

冻结：

* STDP；
* Memristor 更新；
* 适应或慢恢复变量中的候选项。

若冻结后振荡消失，则问题来自慢状态耦合；若仍然存在，则更可能是固定反馈拓扑、PowerRail 或离散更新顺序。

# 根因只需分到三类

完成上述测试后，只需要得到以下三种裁定之一。

## A 类：实现错误

例如：

* 状态没有衰减；
* 每步重复注入旧输出；
* 更新顺序形成伪反馈；
* collector 输出错误回接；
* 泄漏参数未实际生效。

处理：修复错误，然后重跑单次输入长程测试。

## B 类：结构位置不合理

ensemble 的振荡本身可能合理，但 collector 或 occurrence closure 不应直接把每次峰值都登记为新的物理发生。

处理：重新划分：

[
\mathcal G^{\mathrm{phys}}
\quad\text{与}\quad
\mathcal G^{\mathrm{internal}}.
]

例如：

[
q^{\mathrm{skin}}
\rightarrow
\mathcal G^{\mathrm{phys}}
\rightarrow
\xi^{\mathrm{phys}}
\rightarrow
\mathcal G^{\mathrm{internal}}.
]

内部组织区可以振荡，但不能反向制造新的：

[
\chi^{\mathrm{thermal}}.
]

## C 类：合法的内生动力学

如果确认它是持续供能下的正常内部动力模态，可以保留，但必须设置父物理支撑 epoch：

[
E_{i,k}^{\mathrm{phys}}.
]

同一父物理支撑过程中：

[
N_{\chi^{\mathrm{thermal}}}
\left(
E_{i,k}^{\mathrm{phys}}
\right)
\leq1.
]

即使内部振荡一万次，也不能增加同类物理 occurrence。新版理论文档中“纯内部循环不能增加真实确认”的原则正好为此提供了理论依据。

---

# P2-A1b-3R 的完成标准

只要满足以下三项，就停止根因调查，不继续深挖：

1. 单次皮肤物理作用，长程观察下只产生一次基础热 occurrence；
2. 输入撤去后，内部振荡可以保留，但不能继续产生新的物理确认；
3. 父物理支撑真正退出并重新进入后，第二次输入可以产生第二次 occurrence。

数学上：

[
\begin{aligned}
E_{i,1}^{\mathrm{phys}}
&\Rightarrow \chi_i^{(1)},\
a_i^{\mathrm{internal}}\text{ 自振}
&\nRightarrow \chi_i^{(2)},\
E_{i,2}^{\mathrm{phys}}
&\Rightarrow \chi_i^{(2)}.
\end{aligned}
]

# 然后才进入 P2-A3

P2-A3 不再负责解释振荡根因，而是在已经清洗过的物理确认流上测量：

[
\chi_i^{\mathrm{phys}}
\quad\text{与}\quad
\chi_j^{\mathrm{phys}}
]

之间的：

* 最小可分辨间隔；
* 先后顺序；
* 重叠条件；
* 相位／内部振荡干扰；
* 误计和漏计边界。

因此眼下的具体下一步应冻结为：

[
\boxed{
\begin{aligned}
1.&\ \text{撤去输入后的逐层活动与供能日志};\
2.&\ \text{关补能、断反馈、冻结慢变量三组隔离实验};\
3.&\ \text{裁定实现错误／结构边界／合法内生动力学};\
4.&\ \text{落实父物理支撑 epoch 与 occurrence 隔离};\
5.&\ \text{通过三条长程闭合测试后进入 P2-A3}.
\end{aligned}
}
]

所以答案是：**下一步要测根因，但不是无限彻查；查到能判断耗散、供能和反馈结构，然后立即完成物理确认隔离。**
