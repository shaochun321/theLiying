# 一、W2A：条件通过，但还缺“原子守恒事务”

W2A 对热源语义的修正是正确的：

[
\text{旧热源：温度参数}
\quad\longrightarrow\quad
\text{新热源：功率 }P=\frac{dQ}{dt}.
]

定位权重满足：

[
w_i\geq0,\qquad \sum_iw_i=1,
]

因此注入功率天然满足：

[
\sum_iP_i=P.
]

这部分成立。

## 但当前接口顺序可能破坏跨组件守恒

报告给出的逻辑是：

```text
source.release(dt)       # 扣除热源能量
locator.locate(...)
couple(...)
guarded_step(...)        # 这里可能因为不稳定而拒绝执行
```

按这一结构推断，如果：

1. `release(dt)` 已经减少了 `energy_remaining`；
2. 随后定位失败，或者 `guarded_step()` 因不稳定抛出异常；
3. 世界图没有收到能量；

那么会出现：

[
\Delta E_{\mathrm{source}}<0,
\qquad
\Delta E_{\mathrm{field}}=0.
]

也就是能量在热源和世界之间的**提交窗口中丢失**。

当前 T-TSC-6 只证明不稳定时 graph 状态未修改，没有证明 source 状态也没有修改。

### 推荐修复：两阶段提交

不要让 `release()` 同时承担“计算”和“扣账”。

改成：

```text
proposal = source.preview_release(dt)
weights = locator.locate(...)
injections = distribute(proposal.power, weights)

guarded_validate(graph, dt)

source.commit_release(proposal)
graph.step(dt, injections)
```

或者建立最小事务：

```text
ThermalInjectionTransaction
```

状态：

[
\mathcal T_s=
(Q_{\mathrm{planned}},
{Q_i},
\mathrm{committed}).
]

要求：

[
Q_{\mathrm{source\ debit}}
==========================

\sum_iQ_i
+
Q_{\mathrm{loss}}.
]

提交失败时，热源和世界都不改变。

这是 W2A 目前最重要的修复，不应留到 W2C。

# 二、W2A 的定位器还没有通过“运动连续性”

`ThermalFieldLocator` 使用 (k=4) 的反距离加权。这能保证每次查询：

[
\sum_iw_i=1,
]

却不保证位置连续运动时：

[
w_i(\mathbf x+\delta\mathbf x)
\approx
w_i(\mathbf x).
]

当第 4 和第 5 近邻交换名次时，支持节点集合可能突然改变。总注入仍守恒，但局部注入分布可能跳变：

[
\sum_iP_i(t^-)
==============

\sum_iP_i(t^+),
]

同时：

[
{P_i(t^-)}
\not\approx
{P_i(t^+)}.
]

报告已经诚实记录，目前只验证了不同位置分别守恒，没有验证连续轨迹无跳变。

在接入移动身体或移动热源前，应增加：

[
D_{\mathrm{inj}}(t)
===================

\sum_i
\left|
P_i(t+\Delta t)-P_i(t)
\right|.
]

沿平滑轨迹测试 (D_{\mathrm{inj}}) 是否出现不合理尖峰。

若确有跳变，可改用：

* 固定半径内的平滑核；
* 紧支撑高斯核；
* 基于局部四面体的重心插值；
* 或带滞回的邻接支持集合。

所以 W2A 的状态应记为：

[
\boxed{
\text{静态定位守恒通过；动态定位连续性待验证}
}
]

# 三、`DynamicHeatSource.efficiency` 的能量含义还需写清

因此暂时没有暴露问题。但当：

* 世界收到多少；
* 损失进入哪个账本。

正确的一种定义是：

[
Q_{\mathrm{draw}}
=================

\min(P_{\mathrm{nom}}\Delta t,E_s),

[
Q_{\mathrm{field}}
==================

\eta Q_{\mathrm{draw}},

[
Q_{\mathrm{loss}}
=================

(1-\eta)Q_{\mathrm{draw}},

[
E_s^{n+1}
=========

E_s^n-Q_{\mathrm{draw}}.
]

并满足：

[
Q_{\mathrm{draw}}
=================

Q_{\mathrm{field}}
+
Q_{\mathrm{loss}}.
]

如果当前暂时不准备做损耗账本，建议先锁定：

```text
efficiency = 1.0
```

并禁止其他值，而不是留下一个尚未闭合的自由参数。

# 五、T3-B 暴露出的关键问题：比例在哪一层成立？

共享分流池直接输出的电流满足：

[
y_a
===

i_aG(i_a+i_b),
]

[
y_b
===

i_bG(i_a+i_b).
]

因此在池读出层：

[
\frac{y_a}{y_b}
===============

\frac{i_a}{i_b}.
]

但随后 (y_a,y_b) 被注入两个非脉冲 Neuron。此前 T1 已经确认，该 Neuron 的公开 `activation` 在小信号区近似是二次门控：

[
a_i
\sim
g_m(V_i-V_{\mathrm{th}})^2.
]

如果未来下游 Bundle 读取的是 Neuron 的 `activation`，那么真正导出的关系信号可能是：

[
\frac{a_a}{a_b}
\neq
\frac{y_a}{y_b}.
]

甚至在准稳态近似下可能趋向：

[
\frac{a_a}{a_b}
\sim
\left(
\frac{y_a}{y_b}
\right)^2.
]

所以必须区分三层：

[
\text{源驱动比}
\rightarrow
\text{Bundle 有效电流比}
\rightarrow
\text{DN 输出比}
\rightarrow
\text{Neuron 导出 activation 比}.
]

目前一级验收只证明最终输出顺序基本正确，没有证明最后一层仍保持射影关系。

这是 T3-C 最应该优先回答的问题。

# 六、25% 的对称容差过宽

报告中观测到约 (8%) 的不对称，却把验收容差设为 (25%)。

这适合作为“电路没有彻底失效”的冒烟门槛，不适合比例关系的资格判定。因为一个稳定存在的 (20%) 通道偏置也会通过测试。

更重要的是，Bundle 的 hash 扰动意味着：

[
i_a^{\mathrm{raw}}
\neq
i_b^{\mathrm{raw}}
]

即使两个源被赋予相同的名义输入。

因此 T3-C 不应把“名义输入幅度”作为真值，应把 Bundle 传播后的有效电流作为真值：

[
\rho_{\mathrm{in}}
==================

\frac{i_a^{\mathrm{raw}}}
{i_b^{\mathrm{raw}}}.
]

然后验证：

[
\rho_{\mathrm{DN}}
==================

\frac{y_a}{y_b}
\approx
\rho_{\mathrm{in}},
]

以及真正导出的关系信号：

[
\rho_{\mathrm{out}}
===================

\frac{o_a}{o_b}
]

是否仍然是 (\rho_{\mathrm{in}}) 的稳定单调或射影映射。

同时应在多个 `PYTHONHASHSEED` 下运行，而不是用单次宽容差覆盖所有潜在扰动。

建议：

* 一级冒烟容差可暂保留 25%；
* T3-C 升格容差收紧到实测分布，例如 95% seed 范围；
* 报告给出均值、最大偏差和偏差符号，而不只给单次 PASS。
