## 结论

此前提出的新增组件并不是全部作废，而是要重新分类：

[
\boxed{
\text{物理过程组件保留，}
\quad
\text{通用关系载体保留，}
\quad
\text{预写语义的生成元组件取消。}
}
]

新的路线不是继续堆组件，而是先判断：

> 某个现象是现有物理结构的可观测关系，还是确实缺少一个能够承载状态的新机制？

因此，下一阶段需要新增的组件会比此前设想的少很多。

# 一、已经新增的 `GradedPotentialRelay` 是否还需要？

**需要，而且应当冻结。**

它解决的是一个与“占比”语义无关的通用物理缺口：

[
\text{连续关系电流}
\rightarrow
\text{有记忆的连续膜状态}
\rightarrow
\text{Bundle 可读取输出}.
]

它不是 `RatioReader`，也不是“占比计算器”，而是一种通用的分级电位换能机制。其内部结构是：

[
y_i
\rightarrow
\text{Capacitor}
\rightarrow
V_i
\rightarrow
\text{线性公开输出}.
]

它已经完成真实 Bundle 接入、动态卷积验证、幅度可消费性验证和独立账本，T3-C1 也已通过全部专项测试与 21/21 回归。 

因此它应重新定位为：

[
\boxed{
\text{通用连续关系状态载体}
}
]

未来可以承载：

* (r_\rho^\tau)；
* 边通量强度；
* 局部汇散强度；
* 感受关系强度；
* 带宽匹配关系；
* 结构闭合残差。

不再为每种关系重新造一个专用 Neuron。

---

# 二、`ThermalCell` 和 `ThermalLink` 是否还需要？

**不仅需要，而且它们现在变成了下一阶段最重要的底座。**

目前动态热世界已经用：

* `ThermalCell` 保存局部热状态；
* `ThermalLink` 表达节点间热通量；
* 热源注入和环境耗散驱动物理过程。

原方案把它们主要看成未来温感输入的世界基础；新路线下，它们还提供了第一个真正可测试的：

[
X+R\rightarrow R',
\qquad
R+R\rightarrow R'
]

环境。

在现有结构中已经天然存在：

[
T_i
]

节点状态；

[
T_j-T_i
]

边差异；

[
J_{ij}=G_{ij}(T_i-T_j)
]

边通量；

[
\sum_jJ_{ij}
]

节点汇散；

[
C_i\dot T_i
]

局部储能变化。

所以第一轮梯度—通量—散度构建，**不应新增**：

```text
TemperatureGradientGenerator
TemperatureFluxGenerator
TemperatureDivergenceGenerator
```

因为这些名字会把数学解释误当成新的物理机制。

它们首先只是现有物理结构的不同关系读出。

---

# 三、`ThermalFieldLocator`、`DynamicHeatSource`、`ThermalSourceCoupler` 是否还需要？

**仍然需要，但不作为当前新增任务。**

它们的职责是：

[
\text{世界坐标中的热源}
\rightarrow
\text{局部物理支撑}
\rightarrow
\text{能量守恒注入}.
]

这个职责并没有因为事件本体变化而消失。相反，结构诱导事件需要连续、局部、有限能量的真实物理过程，它们提供了合适的事件驱动来源。

但 W2A 已足够支撑第一轮世界内部实验，所以现在不必继续扩展它。当前应把它视为：

[
\boxed{
\text{连续物理过程发生器}
}
]

而不是温感事件标签生成器。

需要保留的后续欠账包括：

* 定位权重随运动的连续性；
* `efficiency<1` 时的损耗账本；
* 多组件真正计划—提交机制；
* `graph.step()` 意外异常后的跨组件一致性。

这些在世界—身体正式联调前处理，不阻塞关系微分实验。

---

# 四、`SkinThermalState` 和 `ThermalContact` 是否还需要？

**需要，而且在新路线中意义更大。**

此前它们只是 W2B 的“皮肤读新世界温度”接口。现在更准确的定位是：

[
\boxed{
\text{世界物理过程与身体结构之间的边界算子}
}
]

它们负责产生真实的：

[
J_{world\rightarrow skin}
=========================

H(T_{world}-T_{skin}).
]

没有它们，世界中的梯度、通量和散度只能形成世界内部事件，尚未成为身体可参与的事件。

因此它们仍应建设，但顺序应推迟到：

1. 世界内部关系微分已经验证；
2. 结构诱导事件的最小定义已经可运行；
3. 然后用 `ThermalContact` 把事件支撑扩展到身体边界。

不要现在立即做 W2B，否则会同时调试：

* 世界关系微分；
* 皮肤热状态；
* 接触交换；
* 感温发生；
* 神经关系。

变量太多。

---

# 五、以前建议的事务组件是否需要？

此前曾提出类似：

```text
ThermalInjectionTransaction
```

的事务对象。

**目前不需要立即新增。**

W2A 已用前置验证后的提交顺序关闭已知失败路径。它不是完整事务，但第一轮关系微分实验不会同时更新复杂的身体、世界、皮肤和核心状态。

等到 W2C 的联合调度出现：

[
\text{source}
+
\text{world}
+
\text{skin}
+
\text{core}
]

四方状态同时更新时，再决定是否需要通用：

```text
PhysicalStepPlan
PhysicalCommit
```

即使新增，也应是通用物理提交机制，而不是 `ThermalInjectionTransaction` 这种过窄组件。

---

# 六、`stable_hash()` 是否需要？

**需要，但不是下一步主线。**

T3-C1 已证明真实 Bundle 传输会产生约 (0%\sim4.52%) 的固定结构偏置，而且该偏置来自已知的 Memristor hash 扰动。项目没有做 Python 比例补偿，这是正确的。

长期必须把：

```text
Python hash seed
```

改成项目显式的：

```text
circuit_seed
memristor_seed
stable_hash(...)
```

否则相同物理结构的结果受解释器环境控制。

但这属于可复现性基础设施，不应阻塞梯度—通量—散度概念验证。首轮固定 seed 即可。

---

# 七、哪些组件现在不应该新增？

下面这些都不应新增：

```text
DirectionOperator
RatioDivider
EventSegmenter
GradientDetector
DivergenceDetector
ReceptiveFieldClassifier
BandwidthClassifier
MouthCoordinate
SelfCoordinate
```

共同问题是：

[
\boxed{
\text{它们把尚未涌现的解释提前写进了组件职责。}
}
]

特别是：

## `EventSegmenter`

事件边界应来自当前结构对连续物理过程无法继续延拓，而不是某个组件负责“切事件”。

## `GradientDetector`

梯度首先是温度状态与邻接/度量关系共同产生的边差分，不是一种要被检测的预设对象。

## `MouthCoordinate`

口器应该先作为真实身体接触面、热交换面、机械作用面和摄取面存在。坐标要从它与运动、前庭和感受关系的反复闭合中形成。

## `SelfCoordinate`

更不能现在新增。自我坐标应是局部关系图之间的稳定变换和闭环一致性，不是一个直接保存 (x,y,z) 的对象。

---

# 八、下一步最具体的建议

建议分为一个短收口和三个真正的新阶段。

# 阶段 A：T3-C2 三元扩展，短收口

仍建议做，但必须限定为一次性原语资格测试。

目标不是制造“三元占比事件”，而是证明：

[
r_\rho^\tau
]

能够接收任意局部活跃关系集合，而不是只能处理固定二元组。

只测：

* 三个输入共享一个池；
* 池每步只更新一次；
* 三个 Relay 使用同构时间核；
* 固定历史比例下射影关系保持；
* 动态比例下满足各自卷积定义；
* `n_clip=0`；
* Bundle 后偏置在已知范围；
* 账本完整。

通过后立即冻结，不做四元、五元、64 元扩展。

原因是未来一个节点周围可能同时有三条或更多实际通量关系。三元能力是关系汇散层的必要最低条件。

---

# 阶段 B：世界关系微分观测层

这是下一主任务。

## B1. 不新增机制，只暴露现有关系

给 `ThermalCell`/`ThermalLink` 增加只读接口或专项探针：

```text
temperature_difference(edge)
heat_flux(edge)
incoming_flux(cell)
outgoing_flux(cell)
net_flux(cell)
storage_rate(cell)
closure_residual(cell)
```

数学上：

[
dT_e=T_j-T_i,
]

[
J_e=G_e,dT_e,
]

[
D_i=\sum_eB_{ie}J_e,
]

[
R_i^{closure}
=============

C_i\dot T_i-S_i+D_i+L_i.
]

这些是已有物理过程的关系，不是新生成元组件。

## B2. 只用 3～5 个 Cell

构建一个最小不对称热网络，例如中心节点加三条边。

连续运行一个有限能量热源，不提供人工事件段标签。

记录：

[
T(t),\quad dT(t),\quad J(t),\quad D(t),\quad R^{closure}(t).
]

验收目标不是“识别热源事件”，而是确认关系链：

[
T
\rightarrow
dT
\rightarrow
J
\rightarrow
D
]

在真实物理状态更新中成立。

---

# 阶段 C：关系作为关系生成元输入

在 B 阶段通过后，使用已经冻结的 `GradedPotentialRelay` 和 (r_\rho^\tau)，不再新造数学算子。

## C1. 入射通量参与关系

一个节点周围有三条实际边通量：

[
J_1,J_2,J_3.
]

使用它们的物理非负通道形成：

[
r_{\rho,J}^{\tau}
=================

[
z_{J_1}^\tau:
z_{J_2}^\tau:
z_{J_3}^\tau
].
]

这表示：

> 在当前结构时间尺度内，哪些真实通量关系参与了该节点的热变化。

这是第一次明确的：

[
R+R+R\rightarrow R'.
]

## C2. 发生与关系的时序

比较：

[
T_i\text{ 的变化}
]

与：

[
J_{ij}\text{ 的建立},
\qquad
D_i\text{ 的改变}.
]

使用 (r_\prec^\tau) 形成：

[
r_\prec(T_i,J_{ij}),
]

[
r_\prec(J_{ij},D_i).
]

这是：

[
X+R\rightarrow R',
\qquad
R+R\rightarrow R'.
]

不提前命名为“扩散事件”或“热源事件”。

---

# 阶段 D：结构诱导事件原型

这一阶段也先做探针，不新增 `EventSegmenter`。

定义当前活跃关系支撑：

[
\mathcal A_t
============

{
i,e:
|\Delta E_i|>\varepsilon_E
\ \text{或}
|J_e|>\varepsilon_J
}.
]

阈值只是数值噪声下界，不是语义边界。

然后观察：

* 活跃子图拓扑是否改变；
* 通量参与关系是否进入新动力学区间；
* 局部汇散符号或闭合方式是否改变；
* 现有关系状态能否延拓到下一时刻。

最重要的验证应是构造两种物理过程：

### 过程 A：均匀升温

多个节点温度同步增加：

[
dT_e\approx0,
\qquad
J_e\approx0.
]

### 过程 B：传输中经过相同瞬时温度

某一时刻节点温度数值与 A 相同，但：

[
dT_e\neq0,
\qquad
J_e\neq0.
]

只有温度发生元时，两者可能不可区分；加入边差分和通量关系后，应当变得可区分：

[
\omega_A
\sim_{\mathcal S_0}
\omega_B,
]

但：

[
\omega_A
\not\sim_{\mathcal S_1}
\omega_B.
]

这就是生成深度增长的第一条直接证据。

---

# 九、之后再做 W2B

当世界内部已经形成：

[
T\rightarrow dT\rightarrow J\rightarrow D
]

以及初步结构事件切分后，再建设：

```text
SkinThermalState
ThermalContact
```

验证同一物理事件如何通过世界—皮肤边界改变身体结构中的可分辨关系。

此时口器也不先做“坐标”，而是作为特殊身体边界支撑：

[
S_{\mathrm{mouth}}
]

与：

* 世界通量；
* 接触面积；
* 机械交换；
* 摄取；
* 运动；

形成关系。坐标只在这些关系反复闭合后再讨论。

---

## 推荐执行顺序

[
\boxed{
\text{T3-C2 短收口}
\rightarrow
\text{世界关系微分观测}
\rightarrow
\text{关系—关系生成}
\rightarrow
\text{结构诱导事件原型}
\rightarrow
\text{W2B 身体边界耦合}
}
]

组件决策总结：

| 组件                                                    | 决策               |
| ----------------------------------------------------- | ---------------- |
| `GradedPotentialRelay`                                | 保留并冻结，通用连续关系载体   |
| `ThermalCell` / `ThermalLink`                         | 保留，下一阶段核心物理底座    |
| `ThermalFieldLocator` / `DynamicHeatSource` / Coupler | 保留，暂不扩展          |
| `SkinThermalState` / `ThermalContact`                 | 仍需新增，但放到关系微分验证之后 |
| 通用计划—提交机制                                             | W2C 时再决定         |
| `stable_hash()`                                       | 需要，独立基础设施任务      |
| 梯度/散度/事件检测专用类                                         | 不新增              |
| 口器坐标/自我坐标类                                            | 不新增，等待关系闭合涌现     |

最关键的是：**下一步不是再设计一个“正确的高阶生成元组件”，而是先证明现有物理结构中的关系能够成为其他关系生成元的真实输入。**
