**当前问题已经不是 T2 的接线设计有误，而是当前世界模型无法为项目正在构造的关系生成元提供相应的物理过程。**

现在的温度世界是：

[
T(x,t)=F(x;\text{source state at }t),
]

即每次调用 `temperature_at(pos)`，根据当前位置和热源当前状态立即计算温度。它有空间梯度，却没有热状态在空间中的局部存储、交换、运输和耗散过程。报告已经核实，无论旧点热源还是 World 2.0 高斯圆柱热源，温度都是瞬时空间函数。

这与项目的根本立场不一致：

[
\boxed{\text{项目以过程为基本对象，世界却仍以可查询函数为基本对象}}
]

# 一、当前 T2 的重新定向其实暴露了世界模型缺口

新版 T2 把原来的“热沿表面传播”改成了：

[
\text{身体 yaw 转动}
\rightarrow
\text{两个皮肤点依次扫过静态温度梯度}
\rightarrow
r_{\mathrm{edge-lag}}.
]

这个解释在当前世界中是物理成立的。

但它带来了一个新的结构问题：

[
\boxed{
\text{它不再是纯温感关系生成元，而是前庭—温感跨模态关系生成元}
}
]

因为其延迟尺度由：

[
\tau_{ab}
=========

\frac{\theta_{ab}}{\omega_{\mathrm{yaw}}}
]

决定，其中 (\omega_{\mathrm{yaw}}) 来自前庭运动状态，而不是温度场自身。

这与原双轨方案的“温感轨和运动轨独立构造、不建立跨模态 Bundle”发生了冲突。总纲现在一方面仍将 T2 放在温感轨，另一方面又把其物理依据改为前庭—皮肤耦合。

因此必须二选一：

1. 保留当前世界，则把现有 T2 移出温感轨，重命名为“具身扫掠关系生成元”；
2. 改变世界模型，使温度场本身具有局部演化和运输，重新获得纯温感方向关系的物理支撑。

我认为你提出的第二种更符合项目主线。

# 二、世界模型应从“查询式世界”变成“状态式过程世界”

当前结构近似是：

```text
热源参数 + 世界坐标
        ↓
temperature_at(position)
        ↓
瞬时温度数值
        ↓
感温链路
```

建议改成：

```text
局部热源注入
      ↓
世界局部状态演化
      ↓
节点间热流 / 流体携带 / 耗散
      ↓
身体与局部世界状态发生交换
      ↓
皮肤局部温度状态
      ↓
感温链路
```

核心变化是：

[
\boxed{
\text{热源不再直接决定某点温度，而只向世界注入能量}
}
]

温度由世界自身的历史演化产生。

# 三、建议的新世界底座：局部状态—通量网络

不必一开始建立高分辨率三维流体仿真。更适合项目的是一个局部交互图：

[
\mathcal W
==========

(V_{\mathcal W},E_{\mathcal W}).
]

每个世界节点 (i) 保存局部物理状态：

[
w_i(t)
======

\left(
E_i,
T_i,
\mathbf u_i,
c_i,\ldots
\right),
]

其中：

* (E_i)：局部热能；
* (T_i)：局部温度；
* (\mathbf u_i)：局部介质流动；
* (c_i)：局部物质或化学状态；
* 以后可以增加光、声、营养等状态。

节点之间的边不表示抽象距离，而表示真实局部交换通路：

[
e_{ij}\in E_{\mathcal W}.
]

边上具有热流：

[
J_{ij}(t).
]

局部能量更新为：

[
E_i(t+\Delta t)
===============

E_i(t)
+
\Delta t
\left[
\sum_jJ_{ji}(t)
---------------

\sum_jJ_{ij}(t)
+
S_i(t)
------

## D_i(t)

Q_{i\rightarrow\mathrm{body}}(t)
\right].
]

这里：

* (S_i)：热源局部注入；
* (D_i)：向环境的耗散；
* (Q_{i\rightarrow\mathrm{body}})：与身体的能量交换。

温度由局部能量状态决定：

[
T_i
===

T_{\mathrm{ambient}}
+
\frac{E_i}{C_i}.
]

这就把世界从函数：

[
T=F(x)
]

变成过程：

[
\dot{\mathbf W}
===============

\mathcal F(\mathbf W,\mathbf S,\mathbf B).
]

# 四、热运输应至少分成扩散和介质搬运

## 1. 局部扩散

最小热流可以写成：

[
J_{ij}^{\mathrm{diff}}
======================

\kappa_{ij}
(T_i-T_j).
]

它表达相邻局部状态之间的热交换。

重要的是，这个交换是逐步发生的。热源在节点 (i) 注入能量后，影响只能经相邻边逐步到达其他节点。

这样才有真实的：

[
i\rightarrow j
]

边运输过程。

## 2. 介质搬运

如果当前世界模拟海底环境，仅靠扩散可能过慢，也缺少环境流向。应增加局部介质流动：

[
J_{ij}^{\mathrm{adv}}
=====================

a_{ij}(t)E_i(t),
]

其中 (a_{ij}) 是介质从 (i) 向 (j) 运输热能的有向强度。

总热流：

[
J_{ij}
======

J_{ij}^{\mathrm{diff}}
+
J_{ij}^{\mathrm{adv}}.
]

于是世界可以自然产生：

* 温度梯度；
* 热羽流；
* 局部传播；
* 流向；
* 涡动；
* 延迟；
* 耗散。

方向不再是神经网络自行想象出来的标签，而是世界边上的真实通量：

[
J_{ij}>J_{ji}.
]

# 五、身体不能只“采样世界”，还应与世界交换

当前 `SkinPatch` 的作用基本是把身体局部点变换到世界坐标，然后读取该点温度。

建议改为每个皮肤点具有自己的热状态：

[
T_a^{\mathrm{skin}}(t).
]

世界与皮肤交换热量：

[
Q_a(t)
======

h_aA_a
\left(
T_{\mathrm{world},a}(t)
-----------------------

T_a^{\mathrm{skin}}(t)
\right).
]

皮肤状态演化为：

[
C_a^{\mathrm{skin}}
\frac{dT_a^{\mathrm{skin}}}{dt}
===============================

## Q_a(t)

D_a^{\mathrm{body}}(t).
]

感温发生生成元读取的应是：

[
\Delta T_a^{\mathrm{skin}},
]

而不是直接读取世界的解析温度值。

这样会自然产生：

* 皮肤热惯性；
* 局部接触时间；
* 升温和降温的非对称；
* 身体移动造成的动态采样；
* 世界传播与身体扫掠的叠加。

也就是说，原来被混在一起的两种过程会真正分离：

[
\text{世界热流传播}
]

和：

[
\text{身体运动扫掠}.
]

# 六、方向关系应因此拆成两种不同基础关系

世界模型改变后，不应再强行寻找一个统一的“方向生成元”。

## 1. 环境通量方向

世界热流本身产生：

[
r_{\mathrm{flux}}^{i\rightarrow j}
]

它由边上的运输状态产生：

[
r_{\mathrm{flux}}^{i\rightarrow j}
==================================

H(J_{ij},J_{ji}).
]

感温网络可以通过多个皮肤发生的先后和强度，后验重构这种方向。

这是一种环境对象关系。

## 2. 具身扫掠方向

身体运动导致：

[
r_{\mathrm{sweep}}^{a\rightarrow b}
]

它依赖：

* 身体转动或平移；
* 皮肤点的身体局部布局；
* 外部场梯度；
* 两种感官的共同发生。

这是跨模态关系：

[
r_{\mathrm{sweep}}
==================

\Omega_{\mathrm{sweep}}
[
\xi^{\mathrm{vest}},
\xi^{\mathrm{thermal}}
].
]

当前新版 T2 实际定义的就是它，而不是热传播方向。

因此当前 T2 报告不应丢弃，但应重新归档为：

[
\boxed{
\text{具身场扫掠关系生成元前置设计}
}
]

而不是温感轨内部的 (r_{\rightarrow})。

# 七、建议保留坐标在世界侧，但不向内部网络泄露

这并不违反项目的“内部无显式坐标”原则。

世界本身作为外部物理模拟器，可以拥有：

* 世界坐标；
* 局部网格；
* 距离；
* 流速；
* 边连接；
* 边界条件。

但内部神经系统只能接收：

* 局部换能信号；
* 局部脉冲；
* 身体运动信号；
* 关系生成元输出。

也就是：

[
\boxed{
\text{世界可以有坐标，系统内部不能直接读取坐标}
}
]

内部空间仍由：

[
\text{邻接}
+
\text{传播}
+
\text{共同发生}
+
\text{运动}
]

后验构造。

# 八、对当前温感 T0～T4 的影响

## T0：部分保留

可以保留：

* 32 个皮肤点；
* 冻结点索引；
* 关系层探针；
* census；
* Bundle 读取方式。

必须重做：

* 输入峰值；
* 启动延迟；
* burst 周期；
* 衰减；
* warm/cool 动态。

因为真实世界输入从瞬时查询改成了状态交换。

## T1：电路原型保留，真实源验证失效

T1-B1 合成脉冲验证仍然有效，因为它证明的是关系电路本身。

但 T1-B2 必须在新世界完成以后重做：

[
\text{新世界 }\xi^{\mathrm{occ}}
\Rightarrow
r_{\prec}.
]

原先约 400 步启动延迟和半自主振荡可能发生明显变化。

## T2：暂停当前温感轨实现

原 `r_edge-lag` 不再进入温感轨 T2。

分成两个后续任务：

* 新温感 T2：环境热通量/热梯度关系；
* 跨模态任务：身体运动扫掠关系。

## T3：机制可以继续，真实输入验收后移

共享分流池和射影占比关系的机制不依赖世界模型，可以继续完成组件级实现。

但真实 (\xi^{\mathrm{occ}}) 驱动下的参数和升格判定，要在新世界接入后重新做。

## T4：必须暂停

不能在旧世界输入上完成温感 T4，再把它当成新世界下的集成结果。

# 九、建议的世界模型重构阶段

## W0：旧世界行为封存

保存当前世界作为：

```text
InstantFieldWorld
```

它只用于：

* 回归对照；
* 单元测试；
* 确认新世界没有破坏其他系统。

不要直接删除旧实现。

## W1：局部热状态网络

新增：

```text
DynamicThermalField
ThermalCell
ThermalLink
```

第一版只需要：

* 局部能量；
* 局部温度；
* 相邻扩散；
* 热源注入；
* 环境耗散。

暂不加入身体和流体搬运。

## W2：身体—世界热交换

新增或扩展：

```text
SkinThermalState
ThermalContact
```

使皮肤拥有热状态，并与局部世界单元交换热量。

## W3：介质搬运和热羽流

加入：

* 局部流向；
* 热能随介质运输；
* 热源周围的动态羽流；
* 可逆或随机扰动。

这时环境中才真正存在有向热通量。

## W4：发生生成元重新标定

重新测量：

* (\xi^{\mathrm{occ}})；
* warm/cool；
* 局部梯度；
* 传播时延；
* 身体移动下的扫掠时序。

## W5：基础关系生成元回接

顺序建议为：

[
r_{\prec}
\rightarrow
r_{\rho}
\rightarrow
r_{\mathrm{flux}}
\rightarrow
r_{\mathrm{sweep}}.
]

先做纯局部关系，再做环境方向，最后做跨模态具身关系。

# 十、最小可实施版本

不建议一开始构造完整三维 PDE 世界。第一版可以使用稀疏三维图：

* 约 (10^2) 个世界节点；
* 每个节点只连接有限邻居；
* 每步局部能量守恒更新；
* 热源只向最近节点注入能量；
* 身体皮肤点通过空间查找连接最近的若干节点；
* 节点间热流进入耗散账本。

最小更新式：

[

======

\kappa_{ij}(T_i-T_j)
+
a_{ij}E_i,
]

[

=========

E_i^n

\left(
\sum_jJ_{ji}
------------

\sum_jJ_{ij}
+
S_i
---

## \lambda_iE_i

Q_i^{\mathrm{skin}}
\right).
]

每一步都应检查：

[
\Delta E_{\mathrm{world}}
=========================

## E_{\mathrm{source}}

## E_{\mathrm{dissipation}}

E_{\mathrm{body}}
]

允许数值误差，但必须进入账本。

这比继续用高斯函数直接返回温度，更符合项目对诺特追踪、耗散和跨尺度守恒的要求。

## 结论

改变世界模型是正确的，而且应该立即提升为基础生成元工程之前的独立主任务：

[
\boxed{
\text{世界不是被查询的背景，而应是与身体共同演化的局部过程}
}
]

当前世界可以产生空间差异，却不能产生空间过程。因此它只能支持：

* 位置相关的感知；
* 身体扫掠造成的先后；

不能支持真正的：

* 环境传播；
* 局部通量；
* 方向运输；
* 世界—身体共同耗散。

建议暂停温感 T2 和 T4，把下一阶段正式命名为：

[
\boxed{
\text{动态局部世界模型重构：状态、通量、身体交换与耗散}
}
]

T1 的合成电路成果和 T3 的共享分流机制继续保留，它们将作为新世界完成后的基础关系模块重新接入。
