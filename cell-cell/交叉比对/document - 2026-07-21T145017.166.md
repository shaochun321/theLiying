## 唯一阻塞：先消除 `hash()` 导致的跨进程结构漂移

报告实测表明，相同的 (u=0.0005) 在不同进程中会出现 (0/1/0) 次触发，而固定 `PYTHONHASHSEED=0` 后三次结果完全一致。原因是 Memristor 的对称性打破扰动依赖 Python 内置字符串 `hash()`，使同一个模型在不同进程中获得不同的实际参数。

这意味着当前更准确的边界不是：

[
u_{\mathrm{on}}=u_{\mathrm{on}}(T_{\mathrm{obs}}),
]

而是：

[
\boxed{
u_{\mathrm{on}}
===============

u_{\mathrm{on}}
\left(
T_{\mathrm{obs}};\zeta_{\mathrm{structure}}
\right),
}
]

其中 (\zeta_{\mathrm{structure}}) 是该网络实例的结构扰动实现。

结构差异本身可以保留，但必须来自：

[
\zeta_{\mathrm{structure}}
==========================

F(
\text{稳定结构地址},
\text{显式 model seed}
),
]

不能来自操作系统每次启动时隐式变化的 `hash()`。

### 最小修复

只做：

1. 用稳定地址摘要或显式 `model_seed` 生成 Memristor 扰动；
2. 同地址、同 seed 跨进程结果必须相同；
3. 不同显式 seed 可以产生不同结构实现，但必须可复现；
4. 用少量临界档位确认响应性质没有被改变。

不必再次运行完整的多档、多窗口深扫，也不必精确寻找新的 (u_{\mathrm{on}})。

这项修复完成以前，不宜冻结 (\kappa_i)，因为接口参数不能建立在进程偶然性上。

## 非阻塞二：ensemble 信息量问题留给 P2-B

本轮发现：

* (L_{\mathrm{first}})、(f_{\mathrm{occ}})、活动持续时间仍随 (u) 明显变化；

这说明当前生成元更可能通过**闭合时序**而不是 ensemble 峰值幅度保存输入差异。

这不妨碍 P2-A1b，因为 P2-A 当前只要求产生可辨识发生；但它确实限制了未来自然化候选：

[

## P2-A1b-2 现在怎样做

皮肤输出跨越约四个数量级，但这是实验剂量覆盖很宽造成的，不能把全部极值都线性塞入：

[
u<0.05.
]

应选定已有实验中的一个**参考物理过程集合**，根据其主要分布设计映射：

[
u_i(t)
======

\operatorname{clip}
\left[
\kappa_i
\left(
q_i^{\mathrm{skin}}(t)-q_{i,0}
\right)
+b_i
\right].
]

目标是：

[
q_{\mathrm{reference}}
\longmapsto
u_{\mathrm{interior}}
\subset
\mathcal D_{\mathrm{disc}}^{G},
]

并与两端保持裕量：

[
u_{\mathrm{on}}+\Delta_{\mathrm{low}}
<
u_{\mathrm{interior}}
<
0.05-\Delta_{\mathrm{high}}.
]

不要以最小值和最大值直接求 (\kappa_i)。极端输入允许被 clipping 压缩，原始：

[
q_i^{\mathrm{skin}}(t)
]

仍完整保存在物理轨迹中。
