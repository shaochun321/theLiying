## 核心问题：被抑制的脉冲不能“不充电”

方案当前规定：

> 首次脉冲通过并给电容充电；门关闭期间的重复脉冲被抑制，而且不再给电容充电。

这意味着门电压只记录：

[
\text{距离首次脉冲过去了多久}
]

而不是：

[
\text{距离最近一次脉冲过去了多久}.
]

假设一次持续发生中，每200步出现一个脉冲，门的恢复时间约1000步：

[
t={0,200,400,600,800,1000,\ldots}.
]

当前方案会出现：

* (t=0)：首次脉冲通过，电容充电；
* (t=200\sim800)：重复脉冲被抑制，但不刷新电容；
* (t\approx1000)：电容已经衰减到阈值以下；
* 下一枚脉冲再次通过。

于是同一次持续发生会被错误地产生多个：

[
b_\alpha^\uparrow.
]

而参考检测器的规则是：只要相邻脉冲间隔小于 `gap_steps`，就仍然属于同一次持续发生，不得再次输出首次进入边界。

因此，按当前S1实现：

[
b_{\mathrm{physical}}^\uparrow
\neq
b_{\mathrm{reference}}^\uparrow.
]

T-R1B-5几乎必然失败。

## 正确的物理结构：可重触发、有限饱和的抑制门

每一枚输入脉冲都应该**刷新抑制状态**，但不能无限累加。

定义抑制电压 (V_g(t))。

### 脉冲到来前先判断

[
b^\uparrow(t_k)
===============

p(t_k),
\mathbf 1
\left[
V_g(t_k^-)<\theta_g
\right].
]

只有门电压已经跌到阈值以下，该脉冲才作为新的首次进入边界通过。

### 随后每枚脉冲都刷新门电压

无论该脉冲是否被输出，都执行：

[
V_g(t_k^+)=V_H,
]

或采用有上限的充电：

[
V_g(t_k^+)
==========

\min
\left(
V_g(t_k^-)+\Delta V,,
V_H
\right).
]

脉冲之间自然泄漏：

[
V_g(t)
======

V_H
e^{-(t-t_k)/\tau_g}.
]

这样：

* 簇内每枚脉冲都把抑制恢复到固定高位；
* 不会因为持续输入而无限积累；
* 只有从**最后一枚脉冲开始**静默足够长，门才重新打开。

这在电路意义上是一个：

[
\boxed{\text{可重触发单稳态门／饱和刷新型去抖动门}}
]

而不是“首次充电后自行倒计时”的普通电容门。

项目现有的Zener钳位、PowerRail限制或MOSFET饱和充电模式，可以作为限制 (V_H) 的候选载体。审计中找到的 `CalciumRateIntegrator` 钳位结构反而比“不重复充电”的方案更接近所需拓扑。

## 参数表达也要修正

报告写：

[
\tau_{\mathrm{gap}}\in(0.32,s,4.2,s)
]

任取即可。

严格来说，决定重新开门时间的不是单独的RC时间常数 (\tau_g)，而是：

[
t_{\mathrm{open}}
=================

\tau_g
\ln
\frac{V_H}{\theta_g}.
]

所以真正需要满足的是：

[
0.316,s
<
\tau_g\ln\frac{V_H}{\theta_g}
<
4.257,s.
]

或者直接写成两个资格条件：

[
V_H e^{-0.316/\tau_g}>\theta_g,
]

保证最大簇内间隔后仍然关门；

[
V_H e^{-4.257/\tau_g}<\theta_g,
]

保证真实静默退出后已经重新开门。

这个区间非常宽，说明确实不需要网格搜索；但必须联合确定：

[
\tau_g,\quad V_H,\quad\theta_g,
]

不能只冻结 (\tau_g=1s) 就认为恢复时间已经确定。

## 单时钟还是双时钟？

当前证据支持：

[
\boxed{\text{E}^{\uparrow}\text{新支路采用单时钟。}}
]

但这应被表述为：

> E↑只检测“从最近一次脉冲开始是否已经经历足够静默”，退出与重新武装由同一个抑制状态跨阈过程完成。

不要宣称已经证明 `occurrence.py` 的双时钟在所有用途上都多余。它目前只能登记为继承债务，继续保持不动。

还有一个重要后果：

现有三态 `EntryBoundaryDetector` 使用：

[
gap_steps=500
]

后进入REFRACTORY，再额外等待：

[
rearm_min_steps=500.
]

它实际上需要约1000步静默才重新武装。

而单时钟物理门只用一次跨阈恢复。因此不能直接要求：

[
b_{\mathrm{physical}}^\uparrow
\equiv
b_{\mathrm{reference}}^\uparrow
]

同时又保留参考检测器的双时钟语义。

必须二选一：

1. 给参考检测器增加明确的“单时钟oracle模式”，例如 `rearm_min_steps=0`；
2. 用显式脉冲序列资格测试验证单时钟语义，不把旧三态检测器作为逐步等价标准。

否则测试比较的是两个定义不同的算子。
