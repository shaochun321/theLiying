## 当前裁定

### TSS-0：通过，不改

它正确冻结了：

[

都是非学习型生成算子，生成元存在不依赖STDP或DA；当前T1只是时间算子 (\Theta^{(1)}) 的一个原型。

### TSS-1：实验有效，但“空间可达性”宣称过强

当前实验实际证明的是：

[
\boxed{
\text{一次局部外部物理作用，会激活部分锚定生成元，而不激活远方生成元。}
}
]

报告中：

* 热源半径设为 (2.0)；
* 近点距离 (1.09<2.0)，产生响应；
* 远点距离 (3.81>2.0)，HeatSource衰减因子直接为零；
* `synapse_gain=0`切断后collector响应归零。

这证明：

[
\text{外部局部物理支撑}
\rightarrow
\text{内部生成元活动范围}
]

但尚未证明：

[
\text{基础生成元 }G_i
\rightarrow
\text{沿皮肤物理链传播}
\rightarrow
G_j.
]

原因是当前近点本身也被HeatSource直接作用；`synapse_gain=0`切断的是内部神经链路，不是皮肤物理空间中的传播边。

所以它更准确的名字应当是：

[
\boxed{\Sigma_{\mathrm{support}}^{(1)}：
\text{物理支撑局部性投影}}
]

而不是完整的：

[
\Sigma_{\mathrm{reach}}^{(1)}：
\text{生成元间物理可达性}.
]

的第一条实际资产。

# TSS-1需要怎样修改？

不必重跑物理实验，只修改报告与资格：

```text
原：
TSS-1：第一条真正的空间生成算子（局部可达性）

改：
TSS-1：Σ_support^(1)物理支撑局部性投影原型
```

冻结结论改为：

[
\boxed{
\text{局部外部物理发生能够通过锚定链路，
产生具有空间选择性的内部生成活动云。}
}
]

禁止宣称：

* 已证明皮肤点之间的物理传播；
* 已证明生成元之间的可达性；
* 已形成内部空间距离；
* 已形成方向或梯度；
* 已完成通用空间生成元。

## 真正的可达性以后需要额外满足

未来的：

[
\Sigma_{\mathrm{reach}}^{(1)}
]

至少需要：

1. 只刺激源物理支撑；
2. 目标不能被外部场直接刺激；
3. 响应必须经过皮肤真实物理耦合边；
4. 切断该物理边后目标响应消失；
5. 结果跟随物理结构，而不跟随站点名称。

当前实验还没有覆盖这些条件。
