# 最小动态皮肤与基础生成元接入方案

## 一、方案定位

本方案不模拟完整生物皮肤，也不把温度传感器阵列直接视为基础生成元。

采用以下主链：

[
\boxed{
\text{真实热过程}
\rightarrow
\text{连续皮肤材料}
\rightarrow
\text{局部传感器}
\rightarrow
\text{最低限度转导}
\rightarrow
\text{十神经元基础生成元}
\rightarrow
\text{自然单位候选}
}
]

其中：

* 连续材料承担真实热传播、延迟、衰减和局部耦合；
* 传感器只承担物理量到电信号的转导；
* 十神经元结构承担蓄积、传播、触发、耗散、恢复和历史状态；
* 自然单位候选是基础生成元完成的一次局部结构闭合，而不是传感器采样值或单神经元尖峰。

现有十神经元结构仍应视为可替换的构造性见证，而不是理论中不可更改的常数；真正需要保留的是“相同当前输出、不同内部历史可导致不同后续响应”的性质。

---

## 二、第一版的最小物理结构

### 2.1 采用一维三点皮肤

第一版不建设二维阵列，也不直接扩展至 64 点。

构造一条连续物理皮肤带：

```text
外部热接触
     ↓
连续导热材料
     ↓
[S1] —— [S2] —— [S3]
 ↓        ↓        ↓
G10-1    G10-2    G10-3
 ↓        ↓        ↓
ξ1       ξ2       ξ3
```

建议结构：

* 一块窄条状连续材料；
* 三个相互分离但处于同一材料上的测量位置；
* 三个相同类型的温度传感器；
* 每个传感器独立连接一个十神经元基础生成元；
* 不在传感器端求平均；
* 不在传感器端判断热源位置、传播方向或事件边界。

三个物理支撑记为：

[
S={s_1,s_2,s_3}.
]

物理安装坐标允许存在：

[
\mathbf x_i^{\mathrm{phys}},
]

但仅用于：

* 加工与安装；
* 实验复现；
* 建立真实材料邻接；
* 外部审计。

不得把坐标数值直接送入神经系统。

系统内部只保存：

[
\alpha_{\mathrm{phys}}(s_i),
]

即每个传感支撑的稳定物理地址。

当前 P2-A0 已经为皮肤支撑建立了地址挂载机制，并为后续发生元的 `GeneratedAddress` 保留父地址、生成深度和版本字段。

---

## 三、皮肤材料承担什么

连续材料不是装饰层，而是第一层真实物理计算介质。

它至少产生：

[
\Gamma^{\mathrm{phys}}
\longrightarrow
\bigl(T_1(t),T_2(t),T_3(t)\bigr).
]

其中包含真实的：

* 局部热容量；
* 横向热扩散；
* 接触热阻；
* 传播延迟；
* 峰值衰减；
* 环境散热；
* 材料不均匀性；
* 传感器安装误差。

第一版不要求复制表皮、真皮、血流和皮下组织。只需满足：

[
\boxed{
\text{刺激一个位置时，另外两个位置能以不同延迟和幅度受到影响。}
}
]

适合的最低结构是：

* 薄金属片或其他连续导热片作为热传播主体；
* 绝热或低导热背衬，减少不受控背面散热；
* 三个传感器固定在明确位置；
* 外部热源可以接触任一位置或沿皮肤带移动。

拟真软件皮肤继续保留，但定位为：

[
\boxed{\text{测试夹具，而非最终真实物理接口。}}
]

模拟皮肤与真实皮肤必须使用相同的生成元输入合同，避免为真实硬件另外设计一套发生机制。

## 四、传感器的资格边界

传感器输出记为：

[
v_i(t)=S_i[\Gamma^{\mathrm{phys}}].
]

它可以是：

* 电压；
* 电流；
* 电阻换算结果；
* 数字温度读数。

但传感器不负责生成自然单位。

传感器只回答：

[
\boxed{\text{这个物理支撑处的可测状态如何变化。}}
]

它不回答：

* 是否发生了事件；
* 事件何时开始或结束；
* 这是热还是危险；
* 刺激来自哪个方向；
* 哪两个皮肤点更接近；
* 应输出几个自然单位；
* 当前过程属于什么类别。

因此：

[
S_i\neq\mathcal G_i.
]

传感器是基础生成元的物理支撑之一，但不是完整生成元。

---

## 五、最低限度转导接口

传感器与十神经元结构之间只允许存在一个最低限度接口：

[
u_i(t)
======

\operatorname{clip}
\left(
g_i,[v_i(t)-v_{0,i}],
u_{\min},u_{\max}
\right).
]

其中：

* (v_{0,i})：静息或基准读数；
* (g_i)：物理输入到神经驱动的换算增益；
* `clip`：保护实际电路或数值系统；
* (u_i(t))：持续注入基础生成元的驱动量。

这一层允许：

* 零点校准；
* 增益校准；
* 单位换算；
* 抗混叠；
* 传感器安全范围限制；
* 采样保持；
* 丢包或传感器失效标记。

这一层禁止：

* 人工计算变化率并把它叫事件；
* 人工寻找峰值；
* 人工切分刺激窗口；
* 人工产生 burst；
* 人工加入冷热语义；
* 把三个传感器预先融合；
* 根据坐标决定生成元连接权重。

否则基础生成能力会被前处理层夺走。

## 六、基础生成元实例

第 (i) 个实际基础生成元定义为：

[
\boxed{
\mathcal G_i
============

\left(
\alpha_{\mathrm{phys}}(s_i),
\mathcal C_i,
G_{10,i},
\alpha_{\mathrm{gen}}(\xi_i^{\mathrm{occ}})
\right)
}
]

其中：

* (\alpha_{\mathrm{phys}}(s_i))：传感位置的物理地址；
* (\mathcal C_i)：最低限度传感器接口；
* (G_{10,i})：现有十神经元动力学核心；
* (\xi_i^{\mathrm{occ}})：发生输出；
* (\alpha_{\mathrm{gen}})：发生输出的生成地址。

生成地址的父支撑必须包含：

[
\operatorname{Parents}
\left(
\xi_i^{\mathrm{occ}}
\right)
=======

\left{
\alpha_{\mathrm{phys}}(s_i)
\right}.
]

这表示发生元来自哪个真实物理支撑，但不向内部提供“左、中、右”等语义。

三个传感器分别连接三个生成元：

[
s_1\rightarrow G_{10,1},
\qquad
s_2\rightarrow G_{10,2},
\qquad
s_3\rightarrow G_{10,3}.
]

第一版禁止：

[
(T_1,T_2,T_3)\rightarrow G_{10,\mathrm{single}}.
]

因为这种多对一结构会预先假设三个支撑共同构成一个不可分发生单元。

## 七、基础生成元的触发机制

### 7.1 连续驱动，不用外部触发标签

生成元持续接收：

[
u_i(t).
]

其内部状态记为：

[
x_i(t).
]

动力学抽象写成：

[
\dot x_i
========

F_G\bigl(x_i,u_i;\theta_i\bigr).
]

由现有十神经元结构自身产生：

* 膜电位蓄积；
* 神经元间传播；
* 群体激活；
* collector 或闭合输出；
* 不应期；
* 恢复；
* 耗散。

不允许采用：

```text
温度超过阈值
→ 程序直接发送一个事件脉冲
```

阈值可以存在于神经结构内部，但不得由外部程序直接替生成元完成事件切分。

### 7.2 闭合与重新武装

定义生成元内部闭合观测量：

[
c_i(t)=H_G[x_i(t)].
]

当生成元处于可触发状态，且：

[
c_i(t^-)
<
\theta_i^\uparrow,
\qquad
c_i(t)
\geq
\theta_i^\uparrow,
]

则输出一次发生：

[
\xi_i^{\mathrm{occ}}(t_{i,k})=1.
]

输出后生成元进入未武装状态。只有当内部活动衰减到：

[
c_i(t)
\leq
\theta_i^\downarrow,
\qquad
\theta_i^\downarrow<\theta_i^\uparrow,
]

并满足最低恢复条件后，才能再次触发。

迟滞机制用于避免：

* 阈值附近高频抖动；
* 一次持续发生被重复计算；
* 传感器噪声生成伪脉冲。

## 八、自然单位候选

第 (i) 个生成元的第 (k) 次完整闭合记为：

[
\chi_i^k
========

\operatorname{Close}
\left(
\mathcal G_i,W_{i,k}
\right).
]

其中 (W_{i,k}) 不是外部固定窗，而是从生成元具备触发资格，到完成一次闭合、耗散和恢复的局部过程范围。

对应自然单位候选写成：

[
\boxed{
\mathfrak u_i^k
===============

\left(
1,
\alpha_{\mathrm{gen}}(\xi_i),
t_{i,k}^{\mathrm{phys}},
\varepsilon_i^k,
m_i^k
\right)
}
]

其中：

* (1)：一次完整闭合；
* (\alpha_{\mathrm{gen}})：生成谱系；
* (t_{i,k}^{\mathrm{phys}})：真实物理发生时刻，仅供调度与审计；
* (\varepsilon_i^k)：此次闭合的供能和耗散；
* (m_i^k)：必要的内部模态或状态摘要。

统一性来自：

[
\text{每次闭合均计为一个组织单位}.
]

辨识度来自：

[
\alpha_{\mathrm{gen}}(\xi_i).
]

因此：

[
\boxed{
\text{单位计量相同，物理来源不被抹除。}
}
]

这只是 P2-A 的工程自然单位候选，不应在尚未通过深度耦合测试前上升为最终理论定义。

## 九、多生成元的频率与时序

### 9.1 完全异步运行

三个生成元分别输出：

[
\xi_i(t)
========

\sum_k
\delta(t-t_{i,k}).
]

不使用全局帧来强制同步，也不要求三个生成元具有相同频率。

输入强度和持续时间主要表现为：

* 闭合次数；
* 闭合间隔；
* burst 密度；
* 恢复时间变化；
* 发生持续参与程度。

不能通过重采样把不同生成元改成相同脉冲数。

### 9.2 局部衰减迹

对每个生成元维护：

[
\tau_i^\rho\dot z_i^\rho
========================

-z_i^\rho
+
\xi_i(t).
]

由三个衰减迹形成：

[
r_\rho^\tau(t)
==============

[z_1^\rho(t):z_2^\rho(t):z_3^\rho(t)].
]

该关系表示当前局部时间范围内各生成元的相对参与程度。

它同时保留：

* 最近是否发生；
* 发生频率；
* 发生后经过的相对衰减；
* 多个生成元是否共同参与。

### 9.3 到达先后

物理到达差为：

[
\Delta t_{ij}^{k\ell}
=====================

## t_{j,\ell}^{\mathrm{phys}}

t_{i,k}^{\mathrm{phys}}.
]

但不允许将任何微小差异都强制解释为确定先后。

定义实际不确定带宽：

[
\epsilon_{ij}
=============

\epsilon_i^{\mathrm{sensor}}
+
\epsilon_j^{\mathrm{sensor}}
+
\epsilon_i^{G}
+
\epsilon_j^{G}
+
\epsilon^{\mathrm{clock}}.
]

只有当：

[
\Delta t_{ij}>\epsilon_{ij}
]

时，才形成：

[
i\prec j.
]

当：

[
|\Delta t_{ij}|\leq\epsilon_{ij},
]

保留为并发或未分辨关系：

[
i\parallel j.
]

不能让数组遍历顺序替代真实发生顺序。

## 十、时序和空间关系的后续自然单位化

基础生成元输出：

[
\mathfrak u_i^k
]

进入关系生成元：

[
\mathcal R_\gamma:
\left(
\mathfrak u_i^k,
\mathfrak u_j^\ell
\right)
\longrightarrow
\mathfrak u_\gamma^m.
]

只有当关系生成元完成自己的一次局部闭合时：

[
\mathfrak u_\gamma^m
====================

\operatorname{Close}
\left(
\mathcal R_\gamma,
W_{\gamma,m}
\right),
]

它才成为下一生成深度的自然单位候选。

因此：

* 时间差本身不是自然单位；
* 物理邻接本身不是自然单位；
* 比率关系本身不必自动成为自然单位；
* 关系生成元完成的一次关系闭合才有资格进入下一深度。

生成深度只记录谱系：

[
d(\mathfrak u_i)=0,
]

[
d(\mathfrak u_\gamma)
=====================

1+\max
\left{
d(\mathfrak u_i),
d(\mathfrak u_j)
\right}.
]

它不表示高低、价值或抽象等级。

## 十一、能量与耗散账本

必须分开两个能量过程。

### 11.1 被感受的物理过程

例如外部热量通过材料传播：

[
Q_{\mathrm{thermal}}.
]

它改变传感器所在支撑的状态。

### 11.2 项目供电过程

传感器读取、转换电路、ADC、神经元和 collector 消耗：

[
E_{\mathrm{supply}}.
]

二者不能因为最终都变成电信号就被视为同一个守恒仓。

每个自然单位候选至少记录：

[
\varepsilon_i^k
===============

E_{\mathrm{sensor},i}^k
+
E_{\mathrm{interface},i}^k
+
E_{G10,i}^k.
]

并验证全局功率约束：

[
P_{\mathrm{skin}}
+
P_{\mathrm{generator}}
+
P_{\mathrm{relation}}
<
P_{\max}.
]

等号不作为正常运行状态。

传感器的优势在于供能和耗散易于测量，而不是它天然与被测热量属于同一物理单位。

## 十二、实施顺序

本方案不继续拆分成大量正式阶段，按四次实现循环完成。

### 循环一：单通道闭合

只连接：

[
s_2\rightarrow G_{10,2}.
]

验证：

* 连续传感输入能驱动生成元；
* 不依赖程序事件标签；
* 一次持续刺激不会在阈值附近无限抖动；
* 生成元能够恢复并再次触发；
* 每次闭合具有耗散账本；
* `GeneratedAddress` 正确引用皮肤父地址。

### 循环二：三通道并行

连接：

[
s_1,s_2,s_3
\rightarrow
G_{10,1},G_{10,2},G_{10,3}.
]

验证：

* 三个通道互不串扰；
* 每个发生可以回接自己的物理支撑；
* 不求平均；
* 不因代码执行顺序产生伪时序；
* 同一刺激位置产生可重复但非完全无噪声的轨迹。

### 循环三：时序与频率

构造：

* 单点短脉冲；
* 单点持续刺激；
* (s_1\rightarrow s_2)；
* (s_2\rightarrow s_1)；
* (s_1\parallel s_3)；
* 周期刺激；
* 不规则刺激。

验证：

[
r_\prec^\tau
]

与：

[
r_\rho^\tau
]

能够保留真实到达次序、频率和共同参与，而不依赖固定事件标签。

### 循环四：关系输入资格

验证三个基础生成元的输出能够被现有关系原语消费：

[
\xi_i^{\mathrm{occ}}
\rightarrow
r_\prec^\tau,\ r_\rho^\tau.
]

本轮只验证接口和工作区间，不提前构造结构/行为算子，也不实现 Ω 或 Xin。

## 十三、验收标准

### A. 物理资格

1. 每个发生均可追溯至真实皮肤支撑；
2. 热量必须经过连续材料和传感器，而不是程序直接注入事件；
3. 传感器失效、断线、饱和能被识别；
4. 物理坐标不进入神经信号；
5. 外部热过程和项目供电账本分开。

### B. 生成元资格

1. 相同当前传感读数、不同生成元内部历史可导致不同后续响应；
2. 输出由十神经元动力学产生；
3. 闭合后存在耗散和恢复；
4. 持续输入可以产生多次闭合，但频率受不应期和能量约束；
5. 不依赖人为事件窗口；
6. 不把传感器采样直接当自然单位。

### C. 多通道资格

1. 三个传感器分别驱动三个生成元；
2. 通道交换后，结果随地址映射等变；
3. 同时到达不会因循环顺序被伪造为先后；
4. 不同频率不会被人为重采样成相同频率；
5. 关系层可读取异步脉冲；
6. 任一通道不会因硬件量程独占全部关系活动。

### D. 资格边界

单个发生元：

[
\xi_i^{\mathrm{occ}}
]

只能表示对应皮肤支撑上的聚合局部发生，不能声称辨识其上游热源组成。当前文档已经明确禁止从单点皮肤中“猜回”物理上已经丢失的信息。

## 十四、当前明确不做

第一版不做：

* 完整生物表皮、真皮、血流模拟；
* 64 点阵列；
* 压力、应力和温度多模态并行；
* 多种传感器之间的单位归一；
* 人工感受野；
* 坐标输入；
* 语义冷热分类；
* 外部事件切分；
* 行为算子；
* Ω；
* Xin；
* 运动势实现。

未来加入压力或应力传感器时，仍采用：

[
\text{新物理转导支撑}
\rightarrow
\text{独立基础生成元实例}
\rightarrow
\text{统一闭合单位}
]

而不是把不同物理量先强行换算成同一个传感器标量。

[
\boxed{
\text{传感器提供真实物理支撑，}
