目的：固定D1/R1/R2^fork各自的本体/投影记录/生成链/输出链/已证明资格/

## D1（基础发生）

**本体**：`OccurrenceClosure`（`generators/occurrence.py`）——
触发-退出-重新武装迟滞状态机，读一个标量信号流（collector.pre_trace）。

**实例身份**：`OccurrenceInstanceId = (generator_address, epoch_id)`
（`Occurrence.instance_id`属性），不是裸地址——同一生成元不同epoch是不同实例。

**记录**：`Occurrence(t_up, t_down, t_rearm, address, epoch_id)`——三边界
完整发生记录，`count`恒为1，不携带任何无量纲测度/相位/占比字段。

**观察方式**：`CollectorOccurrenceTap`（`generators/occurrence_tap.py`）——
只读适配器，外挂到已有collector+L1通路，不拥有驱动权（不调用feed()/
tick()/_propagate()）。`phys_support`门控用`L1.activation > 0`。

**身份登记**：`OccurrenceIdentityRegistry`（`generators/occurrence_identity.py`）——
`OccurrenceInstanceId ↔ Occurrence/NaturalUnit`双向查找表。

**已证明资格**：
- 真实HeatSource驱动能产生唯一、可辨识的D1发生实例（P2-A1b-3R系列验证）
- 迟滞状态机正确吸收阈值附近抖动和长期饱和（不会计成无限次发生）

**禁止宣称**：
- 通用输入类型的覆盖（目前只验证过温感通路dT驱动，未验证其他感觉模态）
- 自然单位测度𝔫（P2-B阶段裁定：一次闭合χ≠自然单位𝔫本身）

## R1（发生-发生关系，时间合取型）

**本体**：`R1StructureBlock`（`relations/r1_structure.py`）——
`(κ_A^10, κ_B^10, ℓ_gen, I, Γ_AB^I)`，**不含**ℓ_out（评判030645阻塞
修正：关系是否存在不依赖是否已能向下游施力）。

**基元**：`KappaTen` = `(B_in, C^10, S_dyn, B_out)`——B_in=L1输入边界，
C^10=ensemble10个神经元（不可约核心规模，不是总元件数），S_dyn=HC支持
动力学，B_out=collector输出边界。

**生成链路**：`RelationGenLink`（ℓ_gen）——trace衰减积分器+AND门collector
重合检测，两个字段区分机制层（`link_type`）和语义层（`relation_type`）
不能混用；`generation_link_address`（整条链路地址）和`collector_address`
（检测节点本身地址）也不能混用（评判040602两次纠正的同类错误）。

**输出链路**：`R1OutputLink` + `R1OutputBinding`（ℓ_out，独立类，非本体
字段）——`__post_init__`强制校验`source_collector is r1.relation_collector`
（桥梁衔接）。仅在挂了ℓ_out的子类（如`RPrecCircuitT1Plastic`）存在。

**投影记录**：`RelationOccurrence`（`relations/relation_occurrence.py`）——
重新定型为`Π_τ(R1_AB^(1))`（评判"重新定型"非"降格"），R1本体在时间
尺度上的一次投影+谱系审计，不持有耦合轨迹/物理区间。`project_to_
relation_occurrence_fields()`把投影关系显式化为可测代码路径。

**物理区间**：`R1PhysicalInterval`——`UNBOUND↔SUPPORTED⇄RELAXING→CLOSED`
双向状态机（评判045235：短暂衰减不等于关系死亡，同一谱系内可恢复），
含迟滞阈值(θ_on>θ_off)+持续步数(m_on/m_off/m_close)+`lineage_broken`锁
（父epoch变化后禁止恢复）。

**测量窗口**：`R1MeasurementWindow`（评判040602：I_R1≠W_Y*，R1区间记录
"关系活多久"，Y窗口记录"作用要观察多久"，两者不能等同，因为R1本体不含
ℓ_out，ℓ_out电流尾部可能在R1关闭后仍未归零）。由完整AℓB场景后验产生，
用于所有反事实条件。

**去重**：`RelationFinalizer._registered_keys`——
(relation_type, parent_a_instance_id, parent_b_instance_id, trace_scale)
四元组防止残余振荡重复登记（评判203403，P2-B1X1e）。

**已证明资格**：
- 真实端到端场景（HeatSource驱动，L1→HC→ensemble→collector→ℓ_gen）
  自动生成正式RelationOccurrence，父实例是真实occurrence不是手工装配
  （P2-B1X1d）
- 反向输入不误报（B先于A时a_prec_b_fast不产生假阳性）
- K_R1/K_gen/K_out三个不可约资格量均>ε（P2-B1X2c，切断法用
  `synapse_gain=0`，`weight_max=0`实测确认不生效）
- 局部电流不可约资格：双输入耦合产生非零、链路依赖的局部输出

**禁止宣称**（评判213015/222037明确限定）：
- AND合取逻辑之外的复杂涌现
- 三个K代表三种数值独立的效应（当前AND门结构下A-only/B-only天然
  输出为零，三个K数学上退化为同一个`||Y_AℓB||`）
- 已形成梯度、散度或高阶组织
- 空间/尺度维度的投影（ρ^σ/ρ^λ，仅ρ^τ时间投影已验证）

## R2^fork（关系-关系关系，共同源分叉型）

**拓扑**（评判230002修正）：`(28≺31) ∧ (28≺23)`——**共同源分叉**，
不是传递链`31→28→23`。T1/T2都以站点28为共同起点（先发放节点）。

```
       31
      ↗  (T1: 28≺31)
  28
      ↘  (T2: 28≺23)
       23
```

**共同源资格**（评判232255关键修正）：不是"都来自站点28地址"，必须是
**同一个**`OccurrenceInstanceId(site28, epoch_n)`——相同地址不同epoch
不构成共同源（`R2ForkFinalizer`已验证拒绝不同epoch组合，T-R2F-2）。

**本体**：`R2ForkCircuit(RPrecCircuitT1, RPrecCircuitT2)`——T1+T2继承
组合，共享站点28的xi collector（实测`rprec_xi_a is rprec2_xi_b`）。

**生成链路**（ℓ_gen^R2）：T1/T2各自relation_collector → R2 trace
（`r2_trace_t1`/`r2_trace_t2`）→ R2 fork collector（AND门）。评判164327
核心修正：共同源≠瞬时同步——两条通路物理距离不同（d=1.09 vs 1.16），
响应延迟自然不同，trace中继层让自然错开的检测活动能在衰减窗口内产生
物理重叠，不要求同一采样步瞬时重叠。

**双时间尺度**（评判164327落地时定位的真实问题）：R2 collector的物理
重叠窗口（trace tau量级）和T1/T2从检测到正式RelationOccurrence闭合
所需时间（rearm_min_steps=500量级）是两个不同量级——`R2ForkFinalizer`
在R2 collector上升沿只记候选时刻，持续检查直到T1和T2都产生正式
RelationOccurrence后才做共同源核验，不在上升沿瞬间核验。

**投影记录**：`R2Occurrence`——`shared_source_instance_id`（共同源D1
实例）+ `parent_r1_t1_key`/`parent_r1_t2_key`（轻量身份键，非完整对象
引用）。命名用R2层（关系-关系关系），不说"D2关系"（D1/D2是旧的深度
体系，与R1/R2生成层次不是同一维度，评判232255明确区分）。

**输出链路**（ℓ_out^R2）：`R2ForkCircuitPlastic.bundle_r2_to_da`——
评判173204阻塞修正：直接拿`r2_fork_collector.pre_trace`当Y_R2会构成
循环证明（AND门被两路输入触发，就拿它自己的输出证明需要两路输入）。
`measure_r2_output_current()`读取这条独立于collector自身状态的bundle
输出。

**已证明资格**：
- 共同源分叉型R2Occurrence真实产生（T-R2F-3，非手工装配，t_detect=564
  真实上升沿，t_closed=1560等待双父R1都闭合后核验）
- K_R2/K_out_R2均>ε（P2-C1F-d，四条件复用同一次真实驱动，只切R2输入
  bundle的synapse_gain，不重新录制轨迹）
- 完整链路首次走通：真实外部作用→κ^10→D1→R1→RelationOccurrence→
  两条共同源R1真实活动→R2^fork→R2Occurrence→R2局部输出电流

**禁止宣称**（评判192053/193807明确限定）：
- R2超越AND合取（当前AND门结构下T1-only/T2-only天然输出为零，
  K_R2=K_out_R2数学上退化为同一表达式`||Y_T1∧T2||`）
- 已形成散度、因果树
- 通用共同源代数
- 高阶关系由系统自行发现（拓扑是人工选定的：站点28/31/23三点链）
- R2具有超过人工选定拓扑的涌现能力
- 传递型R2（31≺28≺23）——评判230002给出的备选路线，本轮全程未构造
- 非AND高阶结构

## 命名约定备忘

| 术语 | 含义 | 不要混淆为 |
|------|------|-----------|
| D1 | 基础发生（Occurrence） | R1/R2 |
| R1 | 发生-发生关系 | 旧D2记录层 |
| R2 | 关系-关系关系 | D2/D3 |
| D3 | 事件核（尚未开始） | R2 |
| `link_type` | 链路机制类型（用什么方法检测） | `relation_type` |
| `relation_type` | 语义关系类型（检测到什么） | `link_type` |
| `generation_link_address` | 整条ℓ_gen链路地址 | `collector_address` |
| `collector_address` | 检测节点本身地址 | `generation_link_address` |
| `I_R1`（R1PhysicalInterval） | 关系活了多久 | `W_Y*`（测量窗口） |
| `W_Y*`（R1MeasurementWindow） | 作用要观察多久 | `I_R1` |
| `R2_INPUT_NULL` | 两条R2输入链路都被切断（T1/T2仍在真实活动） | 系统无任何活动的∅ |
