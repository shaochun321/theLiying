## 一、核心理念动机

### 1.1 为什么体感重构是 V2.0 的“分水岭”

体感系统是项目中唯一一个同时具备以下特征的子系统：
- **物理接口**：直接与外部世界交互（温度场、热通量）
- **学习路径**：从换能层到运动层有完整的 STDP 链路
- **环流耦合**：是 CPC（CirculationProportionCircuit）的输入源之一（thermal_stability）
- **空间属性**：贴片天然具有面积、体积和位置

**体感系统的 V2.0 化，实际上是“网络化”理念的第一次完整落地。**

前庭 V2.0 是信号链路的地址化——它将已有的 6 条平行链路赋予地址，但不改变信号路径的拓扑。前庭重构的本质是“给已有的东西贴标签”。

体感 V2.0 则不同。它要重建的是一条被硬编码污染的信号路径——从贴片到换能束到脊髓到脑干到DA——让它从 V1 的 Python 直接注入升级为完整的 SynapticBundle 链路。这是**第一次从零开始构建一个完整的感知-运动通路**。

### 1.2 环流耦合依赖体感

环流耦合（CirculationProportionCircuit）的核心输入之一是 `thermal_stability`——身体的热稳态信号。这个信号来自体感系统的 thermoreceptors。在 V1 中，`thermal_stability` 被 HC-014 污染——用 Python soft-sigmoid 计算，而非从物理结构涌现。

**体感重构是环流耦合清洁化的前置条件。** 如果体感输入端仍然是硬编码注入，环流耦合就无法从结构中涌现。

### 1.3 面积和体积的物理合法性

V1 的贴片是“数学点”——0 面积、0 体积、0 热容。它从 World 读取温度但不产生能量交换，无法写入 TSI 账本，无法被 Noether 探针审计。

**V2.0 要求贴片是身体表面的物理部分**：
- 有面积（由 BodySurface 网格定义）
- 有体积（面积 × 皮肤厚度）
- 有热容（体积 × 密度 × 比热容）
- 有热导（面积 × 热导率 / 厚度）
- 有热噪声（Langevin，满足涨落-耗散定理）

贴片不再是“数学探测器”，而是**身体表面与外部环境进行能量交换的合法热力学节点**。

### 1.4 规模泛化的验证平台

体感重构是从 4 个贴片扩展到 12 个贴片的“规模泛化预演”。它验证：
- 地址系统能否承载更多节点（region=0x03 的 12+ 神经元）
- 面积/体积映射能否从抽象概念变为可执行代码
- 换能束的可塑性是否在规模扩大后仍然稳定

## 三、V2.0 体感重构目标形态

### 3.1 架构概览

```
身体表面（SkinMesh）
    │ 12 个贴片面片（BodySurface 网格定义面积/体积）
    │ 热力学方程（热容、热导、Langevin噪声）
    │ 每个贴片分配 region=0x03 地址
    ▼
换能束（transducer_env_to_thermo_{pid}）
    │ 可塑 SynapticBundle（STDP 学习温度-运动映射）
    │ 每个贴片一条
    ▼
热感受器（thermoreceptors）
    │ 非脉冲神经元，连续激活
    │ 输出 relay 驱动电流
    ▼
痛觉换能束（TRPV1/TRPA1 分离）
    │ transducer_dT_to_noci（冻结，伤害反射）
    │ transducer_damage_to_noci（冻结，损伤反射）
    ▼
relay → proj → DA（保留 P2 修复的干净路径）
    │
    │ ✅ thermal_stability 从 thermoreceptor 激活中涌现
    ▼
CPC（CirculationProportionCircuit）
    │ 输入端干净（来自物理结构）
    │ 输出端需 HC-016/017 清理（后续 V2.0 阶段）
```

### 3.2 与 V1 的关键差异

| 维度 | V1 | V2.0 |
| :--- | :--- | :--- |
| 贴片数量 | 4 | 12（3环×4点）|
| 贴片面积 | 0（点采样）| BodySurface 网格定义面积 |
| 贴片体积 | 0 | 面积 × 皮肤厚度 |
| 热容/热导 | 无 | 有（C, G）|

| 痛觉通道 | Python 融合（abs(dT)）| TRPV1/TRPA1 分离 |
| 环流输入 | Python soft-sigmoid（HC-014）| 从 thermoreceptor 激活涌现 |


## 四、贴片物理结构设计

### 4.1 BodySurface 网格

```python
class BodySurface:
    """Body surface mesh defining skin geometry and patch positions."""
    
    def __init__(self, geometry="sphere", radius=20.0):
        self.mesh = self._generate_mesh(geometry, radius)
        self.patch_areas = {}
        self.patch_normals = {}
        self.patch_positions = {}
    
    def compute_patch_geometry(self, patch_id, face_indices):
        area = sum(face_area for face in faces)
        normal = average_normal(faces)
        volume = area * SKIN_DEPTH  # 皮肤厚度常数
        return area, normal, volume
```

### 4.2 贴片布局（3环×4点=12个）

| 环 | z (mm) | 半径 (mm) | 贴片 |
| :--- | :--- | :--- | :--- |
| 上环 | +15 | 15 | top_front, top_back, top_left, top_right |
| 中环 | 0 | 20 | front, back, left, right |
| 下环 | -15 | 15 | bottom_front, bottom_back, bottom_left, bottom_right |

### 4.3 SkinPatch 热力学方程

```
C_patch × dT_patch/dt = G_env × (T_env - T_patch) + √(2 × G_env × k_B × T_env²) × η(t)
```

- 第一项：环境热交换（驱动项）
- 第二项：Langevin 热噪声（涨落-耗散定理）
- C_patch = ρ·c·V_patch（热容）
- G_env = κ·A_patch / d_skin（热导）

### 4.4 参数估算

| 参数 | 值 | 来源 |
| :--- | :--- | :--- |
| 皮肤厚度 d_skin | 0.5 mm | 组织学（小鼠皮肤）|
| 热导率 κ_skin | 0.3 W/m·K | 生物物理 |
| 比热容 c_skin | 3.5 J/g·K | 生物物理 |
| 密度 ρ_skin | 1.0 g/cm³ | 生物物理 |
| 贴片面积 A_patch | ~10 mm²（由网格计算）| BodySurface |

## 七、与环流耦合的衔接

体感重构完成后，`thermal_stability` 将从 Python soft-sigmoid 改为从 thermoreceptor 激活中涌现：

```python
# V1（HC-014 污染）
thermal_stability = 1.0 / (1.0 + thermal_err * 10.0)  # Python soft-sigmoid

# V2.0（物理结构涌现）
thermal_stability = thermoreceptor_activation_mean  # 从 SynapticBundle 传播
```

这使 CPC 的输入端干净，为环流耦合的结构化打下基础。
