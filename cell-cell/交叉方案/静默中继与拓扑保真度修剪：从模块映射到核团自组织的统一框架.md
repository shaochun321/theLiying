## 一、引言：从“人工脚手架”到“物理自组织”的统一视角

当前系统的热趋性行为依赖三层人工预设：

| 层级 | 当前设计 | 问题 |
| :--- | :--- | :--- |
| **第一层：拓扑** | `phasic_left → spinal_ccw`（左热→左转）| 方向映射是人写的，不是学出来的 |
| **第二层：增益** | `spinal_to_yaw`手调增益、T-043交叉抑制冻结 | 参数是人调的，不是自适应的 |
| **第三层：环境** | 单热源 + 精心选择的初始条件 | 环境是人配的，不是普适的 |

**统一核心理念**：与其“告诉系统该怎么做”，不如**构建一个让系统能够“自己发现该怎么做”的物理框架**。这个框架应允许系统在物理约束下，通过“探索-反馈-修剪”的自组织过程，自行发现并巩固正确的感觉-运动耦合。

“静默中继与拓扑保真度修剪”和“模块-核团映射与错误节点处置”两个框架，本质上是同一宏图的两个侧面：

| 维度 | 静默中继框架 | 模块-核团映射框架 |
| :--- | :--- | :--- |
| **关注点** | 网络如何**自组织** | 网络如何**组织起来** |
| **核心问题** | 什么连接该修剪？什么该保留？ | 模块如何映射到核团？错误节点如何处置？ |
| **时间视角** | 演化过程（阶段一→五）| 结构状态（初始→稳定）|
| **回答的问题** | “怎么学？” | “学什么？”和“错了怎么办？” |

合并后的统一框架形成了一个完整的“组织-演化-处置”闭环：

```

    ↓

    ↓
拓扑保真度修剪 → 错误节点处置（处置）
    ↓
动态拓扑演化（再组织）
```


## 二、生物学基础：统一框架的神经科学依据

### 2.1 发育期自发活动与赫布可塑性

在感觉经验介入之前，发育中的神经系统会**自发地产生有组织的神经活动模式**。2024年发表于*Science*的研究提供了**首个在体直接证据**：内源性自发活动模式以亚细胞精度指导轴突修剪，一个轴突分支的活动与相邻轴突或突触后神经元的相关性，可以预测该分支是被添加、稳定还是被消除。

这一定量关系可表达为：

$$
P(\text{branch\_survival} \mid \rho_i) \propto \sigma(\rho_i - \rho_{threshold})
$$

其中 $\rho_i$ 为第 $i$ 个轴突分支的活动与局部网络的相关性系数，$\sigma$ 为S型函数。

**对统一框架的启示**：系统应在CPG驱动的“自发活动”阶段，通过活动相关性来预配置网络结构，而非依赖人工预设的拓扑。

### 2.2 轴突生长的集体行为与自组织

轴突的生长锥持续探测细胞外环境中的化学信号，并据此调整生长方向。更重要的是，**生长锥之间会相互交流**，轴突的寻路是一个**协同的、自我组织的集体行为**。一群神经元合成化学排斥分子，通过轴突运输传递到生长锥，从生长锥扩散形成浓度梯度，生长锥优先向低浓度区域迁移，自洽地产生有限宽度的剖面。

**对统一框架的启示**：“基质电泳引导轴突生长”在生物学上有明确对应——轴突沿化学梯度定向，且这一过程是集体的、自组织的。

### 2.3 “静默中继”与模块化组织

发育中的神经系统存在一种**预配置的、动态的“静默中继”网络**——大量连接在早期是静默的，直到被特定的感觉-运动耦合模式“唤醒”并强化。这些连接**并非不存在**，而是**未被激活**。

同时，哺乳动物CNS呈现出清晰的**模块化结构-功能组织**：大鼠CNS的神经元网络包含840个节点和约81,434条直接互联（占全部可能连接的12%），通过无监督多分辨率共识聚类分析揭示了一个嵌套的模块层次结构。模块化组织与高度连接的枢纽（rich-club）共同构成了神经网络的骨架。

**对统一框架的启示**：修剪不是“删除”，而是**功能沉默**。被修剪的连接失去功能，但神经元胞体保留，未来可被重新激活（去沉默化）。模块不是静态的，而是嵌套的层次结构。

### 2.4 模块化组织的演化保守性

| 神经结构 | 核心功能 | 演化保守性 | 在统一框架中的对应 |
| :--- | :--- | :--- | :--- |
| **脊髓中间神经元** | 感觉运动转换、时序关联检测 | 极保守（脊椎动物共有）| 模块内连接 |
| **脊髓CPG** | 自主节律生成、相位重置 | 极保守（脊椎动物共有）| 自发活动驱动 |

| **基底节** | 强化学习、动作选择、多巴胺门控 | 保守（哺乳动物共有）| 修剪决策门控 |

## 三、统一框架的数理表达

### 3.1 模块-核团嵌入映射

定义模块集合$\mathcal{M} = \{M_1, M_2, ..., M_K\}$，每个模块$M_k$包含若干功能节点。模块到核团的嵌入映射：

$$
\Phi: \mathcal{M} \rightarrow \mathcal{N} \subset \mathbb{R}^3
$$

其中$\mathcal{N}$为核团中的物理节点集合，$\Phi(M_k)$将模块$M_k$映射到核团中的一个**区域簇**。每个节点$n_i \in \mathcal{N}$携带功能标签向量$\mathbf{f}_i$（诊断用，不参与内部微分方程计算）。

**三维vs二维vs混合方案**：保留三维物理坐标（用于延迟计算$\tau_{ij} = d_{ij}/(v_{cond} \cdot dt)$和距离惩罚$P_S \propto d_{ij}$），但在拓扑分析（ORC、里奇流）时投影到二维流形。

### 3.2 全连接初始化的距离依赖修正

根据护航预警一的修正，初始权重矩阵必须受物理距离调制：

$$
W_{ij}(0) = w_0 \cdot \exp(-\lambda \cdot L_{ij})
$$

其中$L_{ij}$为节点$i$、$j$之间的物理距离$[mm]$，$\lambda$为空间衰减常数$[mm^{-1}]$，$w_0$为极小初始权重（如0.001）。

### 3.3 Ollivier-Ricci曲率：拓扑重要性的数学定义

对于图$G = (V, E)$，边$e = (u, v)$的Ollivier-Ricci曲率定义为：

$$
\kappa(u, v) = 1 - \frac{W_1(\mu_u, \mu_v)}{d(u, v)}
$$

其中$W_1$为1-Wasserstein距离（最优传输距离），$\mu_u$、$\mu_v$为节点$u$、$v$的邻居分布，$d(u, v)$为节点间距离。

**曲率的物理直觉**：
- **正曲率（$\kappa > 0$）**：局部冗余连接，移除影响不大。
- **负曲率（$\kappa < 0$）**：全局关键桥接，移除会迅速降低网络性能。

**关键实证发现**：移除负ORC边会迅速降低整体神经网络性能，正ORC边的影响很小。

### 3.4 拓扑重要性指标

对于核团中的每个节点$n_i$，定义其拓扑重要性：

$$
I_{topo}(n_i) = \sum_{j \in \mathcal{N}(i)} |\kappa(e_{ij})| \cdot \mathbb{1}[\kappa(e_{ij}) < 0]
$$

其中$\kappa(e_{ij})$为边$e_{ij}$的ORC，$\mathcal{N}(i)$为节点$i$的邻居集合。

### 3.5 二维修剪判据

| 活动度$A_e$ | 拓扑重要性$\kappa(e)$ | 动作 |
| :--- | :--- | :--- |
| 低 | 低（正ORC）| **修剪**（功能沉默）|
| 低 | 高（负ORC）| **保留（静默中继）** |
| 高 | 高（负ORC）| **强化（LTP）** |
| 高 | 低（正ORC）| **削弱（LTD）** |

**数理表达**：

$$
\text{Prune}(e) = \mathbb{1}\left[ A_e < A_{threshold} \land \kappa(e) > \kappa_{threshold} \right]
$$

其中$A_e$为边$e$的活动度，$\kappa(e)$为其Ollivier-Ricci曲率。

**$\kappa_{threshold}$设定方法**：静态分位数法（静默期）→ 动态自适应法（学习期）→ 消融验证法（争议边）。

### 3.6 错误节点的物理定义（修正版）

根据护航预警一的修正，废除$\mathbf{f}_{task}$“上帝视角”定义，改用代谢-信息转化率：

$$
\text{Inefficiency}(n_i) = \frac{\text{Energy\_Consumed}(n_i)}{\text{Mutual\_Information\_Contribution}(n_i)} > \epsilon_{waste}
$$

其中$\text{Energy\_Consumed}(n_i)$为节点$i$在时间窗口内的总能耗，$\text{Mutual\_Information\_Contribution}(n_i)$为节点$i$的活动与系统全局运动势$\nu$下降之间的互信息。

**物理含义**：一个节点消耗了大量能量，但其活动从未与系统趋近热源（$\nu$下降）形成因果锁相→被判定为“热力学低效节点”。

### 3.7 节点状态分类与处置

| 节点状态 | 条件 | 处置 |
| :--- | :--- | :--- |
| **核心枢纽** | $A_n > A_{high}$ 且 $I_{topo} > I_{high}$ | 保留并强化 |
| **静默中继** | $A_n < A_{low}$ 且 $I_{topo} > I_{high}$ | 保护免修剪（负曲率边）|
| **低效节点** | $A_n < A_{low}$ 且 $I_{topo} < I_{low}$ | 连接被修剪 |
| **噪声节点** | $A_n > A_{high}$ 且 $I_{topo} < I_{low}$ 且激活模式随机 | 连接被削弱 |
| **幽灵节点** | $A_n < A_{low}$ 且 $I_{topo} < I_{low}$ 且 $C_{eff} < C_{th}$ | 完全静默，结构保留 |

**有效连通度**：

$$
C_{eff}(n_i) = \frac{1}{|\mathcal{N}|} \sum_{j \in \mathcal{N}} \mathbb{1}[W_{ij} > W_{threshold} \lor W_{ji} > W_{threshold}]
$$

当$C_{eff}(n_i) \to 0$时，节点进入“幽灵态”——功能上失去意义，但结构存在保留，可被重新激活。

## 五、与运动势垫支决策框架的关系

统一框架（静默中继+模块-核团映射）与运动势垫支决策框架是**前向兼容**的：

| 维度 | 统一框架（本方案）| 运动势垫支决策框架 |
| :--- | :--- | :--- |
| **阶段** | 学习期（自组织）| 学习完成后（决策执行）|
| **核心操作** | 修剪、保留、重新分配 | 读取核团脉冲输出，做出执行选择 |
| **可塑性** | 活跃（STDP + 拓扑修剪）| 冻结（核团已锁死）|
| **时序** | V1-V4逐步验证 | 核团锁死后部署 |

**接口**：统一框架的输出（已锁死的、经过修剪的、有清晰节点状态分类的核团）是运动势垫支决策框架的输入。


## 六、总结

| 问题 | 回答 |
| :--- | :--- |
| 两份方案能否合并？| ✅ 可以。它们本质上是同一架构的两个侧面——“怎么学”和“怎么组织” |
| 合并后的核心是什么？| 模块→核团映射（$\Phi$嵌入）+ 距离依赖初始化 + ORC拓扑识别 + 二维判据修剪 + 节点状态分类 + 动态拓扑演化 |
| 主要修正了哪些原设计缺陷？| 废除$\mathbf{f}_{task}$（上帝视角），改用代谢-信息转化率；废除均匀全连接，改用距离依赖指数衰减 |
| 与当前实验体系的关系？| V1-V4在T-072完成后启动，不阻塞当前实验 |
| 与运动势垫支决策框架的关系？| 统一框架的**输出**是决策框架的**输入**——前者“构建核团”，后者“利用核团” |

**核心论断**：

> 一个有效的“静默中继”机制，不是简单的“活动度门控”，而是一个**基于拓扑保真度的“流形保护机制”** 。它应能识别一个连接是否属于潜在的、正确的感觉-运动耦合流形，即使该连接当前是静默的。里奇流和Ollivier-Ricci曲率提供了实现这一目标的数学工具。模块-核团映射提供了“组织”这一目标的工程工具。两者共同构成从“预设拓扑+调整权重”到“全连接+自发探索+拓扑保真度修剪”的完整跃迁路径。
