# 最终执行方案（架构审计修正版）

**日期**：2026-07-06
**版本**：final-audited
**依据**：破局方案数理诊断 + 架构师最高级别拦截 + 阶段六剥夺验收


## 一、致命拦截的裁决确认

架构师对原方案两项致命拦截完全成立，必须立即修正：

**拦截一：否决阶段四（spinal→yaw 可塑化）。** 两个串联权重同时受同一全局DA信号门控，构成非凸优化信用分配灾难——DA不知道什么是“转向过度”，只要方向碰对了就同时双重LTP，两个权重双双撞死在上限。谢灵顿“最后共同通路”法则：神经肌肉接头高度固化，大自然不允许肌肉增益在漫游中随意波动。**坚决保持 spinal→yaw 冻结。**

**拦截二：阶段二参数不能盲设。** 原定参数（R=0.5, V_th=1.5）将点火门槛拉高300%，脊髓神经元可能陷入绝对静默。必须根据阶段一F-I曲线实测数据精准校准。


## 二、执行原则（不变）

- 每阶段可独立验证，有明确回滚条件。
- 不动已确认正确的物理基础设施（phasic、能量链、饱腹回路、slow_relay τ）。
- 不引入新的硬编码逻辑或Python条件判断。
- 阶段二参数由阶段一实测数据决定，禁止直觉盲设。


## 三、修正后的六阶段执行方案

### 阶段一：Motor基强度诊断（P0）

人工设置 spinal→yaw 权重为 [0.0, 0.001, 0.003, 0.005, 0.010, 0.020, 0.050, 0.100, 0.300]，各跑10k步。绘制F-I曲线和权重-位移曲线，找到脊髓神经元刚好开始点火（f≈1-2Hz）的“基流临界点（Rheobase）”。

**验收**：获得完整的权重-行为量化映射。此数据为阶段二的参数选择提供唯一依据。


### 阶段二：工作点漂移——精准临界态偏置（P0）

**动作**：

D1 bundle 的 initial_weight 从 0.1 降至 0.005。

根据阶段一实测F-I曲线，精准微调 spinal_ccw/cw 的 R_leak 和 V_th，使神经元在初始权重下刚好处于亚阈值悬停态——STDP未发生时，网络静默如瞎；只有当STDP将w推高数十倍，积分器才能越过阈值产生动作电位。

**禁止**：不使用原方案的盲设值（R=0.5, V_th=1.5）。一切参数由阶段一数据决定。


### 阶段三：控制STDP学习率（P0）

stdp_lr 降至 0.001，eligibility_ltd_rate 升至 0.02。避免CPG随机初始相位在早期主导权重演化，赋予系统足够的时空平滑窗口。

**回滚条件**：若200k步后 |Δw|<0.01，stdp_lr调回0.005。


### 阶段四：推挽交叉抑制——物理差分放大器（P1，核心）

**删除** spinal_to_yaw 的 ×10 硬编码增益。

**新增**两条冻结的交叉抑制Bundle：

- spinal_ccw → yaw_cw：sg=-2.0, w=0.5, frozen
- spinal_cw → yaw_ccw：sg=-2.0, w=0.5, frozen

**将正束 spinal→yaw 的 synapse_gain 拉高至 5.0**，保持 frozen（不可塑）。这是合法的巨型突触，产生的庞大突触电流被TSI账本严格征收传输税——100%物理合法。

**物理意义**：推挽差分放大器替代粗暴的标量乘法。左转信号不仅给左转马达加正电流，更通过 sg=-2.0 交叉抑制瞬间抽干右转马达膜电容电荷，净扭矩得到物理差分放大。共模抑制比（CMRR）极高，微弱的方向不对称被放大为清晰的转向指令。


### 阶段五：probe_emergence.py 终极剥夺验收（P1）

重跑剥夺实验脚本。

**终极标准**：

- 冻结 STDP 时，由于 w_init=0.005 且无 ×10 放大，系统必须丧失趋热能力——DR5% 下降至少5%，跌回随机基线。
- 开启 STDP 时，马达的 EMA 绝对不可能再一致到小数点后15位。STDP 驱动下的真实因果流形将主宰转向轨迹。
