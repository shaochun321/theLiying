## 二、环流耦合

### 2.1 三个环流通道

| 通道 | ρ占比 | 路径 | 功能 |
| :--- | :--- | :--- | :--- |
| **体征环流（主）** | ≈0.7 | ThermalMembrane→ECM→Enc→Col→ThermalMembrane | 维持基础稳态 |
| **运动环流** | ≈0.2 | Motor→Body→Otolith→Aff→Enc→Col→Motor | 自主运动反馈 |
| **进食环流** | ≈0.1 | 口器绝对温度/充能率→Col bias→Motor→Body→位置变化→热变化 | 热源追踪 |

**进食环流输入修正**：Col bias来源为**口器绝对温度或充能率**（tonic信号）。phasic信号在到达热源中心（dT/dt=0）时会归零，导致虚假的“环境信号消失”恐慌。真正的进食是稳态高温中的持续充能。

### 2.2 CPC（CirculationProportionCircuit）

CPC通过Capacitor+MOSFET实现稳态比例检测：

```
V_homeo = 体征环流电压
V_motor = 运动环流电压
V_feed  = 进食环流电压
ρ_homeo = V_homeo / (V_homeo + V_motor + V_feed)  ← 从电压比涌现
deviation = |ρ_ref - ρ_homeo|                       ← 稳态偏差
```

**CPC角色定位（P0修正）**：CPC只输出**标量deviation**。ρ是全局代谢压力，维度上无法分裂为三维向量。deviation注入脑干节律调制探索振幅（“油门”），方向由底层STDP差速权重决定（“方向盘”）。`homeostasis_relay_{x/y/z}`设计已删除。

### 2.3 修复路径

| 步骤 | 操作 | 优先级 |
| :--- | :--- | :--- |
| 删除HC-014 | thermal_stability改由ThermalMembrane MOSFET输出 | P0b（依赖体感重构） |
| 删除HC-016 | deviation→Motor直接注入改为SynapticBundle | P3a |
| 删除HC-024 | binding_motor_weights Python dict改为SynapticBundle | P2 |
| CPC deviation→脑干节律 | 标量deviation注入脑干振荡器振幅调制 | P2a |


## 三、时空耦合

### 3.1 核心概念

| 概念 | 定义 | 物理载体 |
| :--- | :--- | :--- |
| **ds²** | 微分能量 | shadow_sandbox |
| **ν（运动势）** | 耗散功率，量纲W | shadow_sandbox._nu |
| **TemporalCoupler** | 时间尺度桥接器 | temporal_coupler.py |
| **TimeIntegrator** | 单调递增Capacitor+阈值重置（量子化时间脉冲） | 新建独立组件 |
| **SpatialNavigator** | 航位推算/空间记忆 | 空壳待填充 |

**机制B Capacitor实体明确**：时间生成的“机制B（渐变信号）”为**独立新建的TimeIntegrator Capacitor**。EnergyStore Capacitor编码能量水平，TemporalCoupler电容编码适应性时间常数，两者均不承担纯时间积分功能。

### 3.2 ν→DA/AGC极性修正（P0c）

| ν状态 | 物理含义 | 输出 |
| :--- | :--- | :--- |
| ν < 0 | 误差消除，系统回归安全流形（“顿悟”） | → DA excitation（固化权重） |
| ν > 0 | 误差飙升，系统困惑/失控 | → AGC gain↑（放大探索噪声） |

**ν不是DA的直接信号源**。ν是宏观功率量纲（W）的全局积分量，DA释放是局部的电化学事件。实现时须通过一个具有自身膜电容动力学的阈值比较神经元，将ν的持续负向趋势转换为DA调制偏置。ν的角色是“宏观状态参考量”，触发DA的具体事件交还给局部Xin坍缩动力学。

### 3.3 修复路径

| 步骤 | 操作 | 优先级 |
| :--- | :--- | :--- |
| 修复B-layer电压=0 | 诊断c_slow/v_threshold/r_leak | P0a |
| 删除HC-015 | TemporalCoupler改用SynapticBundle | P0a |
| 接线ν→DA/AGC | ν<0→DA，ν>0→AGC（经阈值比较神经元） | P0c |
| 实现TimeIntegrator | 独立Capacitor单调充电+阈值重置 | P1a |
| 填充SpatialNavigator | Capacitor积分速度→估计位置→误差信号 | P1b |
| P/R互换 | \|dξ_space/dt\| vs \|dξ_time/dt\|比较 | P2b |

## 五、脑区空间归类

### 5.1 脑区分配

| 脑区 | region | 包含组件 | 坐标中心 |
| :--- | :--- | :--- | :--- |
| 脊髓反射层 | 0x01 | 制动束中间神经元、Renshaw细胞 | [45,50,25] |
| 脑干层 | 0x02 | 前庭核(36)、VitalOscillator(1) | [50,50,25] |
| 主层 | 0x03 | 体感链、Motor、yaw Bundle、DA神经元、CPG | [50,50,35] |
| 下丘脑层 | 0x04 | 能量感知链(7)、CPC | [55,50,50] |
| 影子层(附着) | 0x03+偏移 | ShadowSandbox全节点 | 继承主层 |

- 影子层通过地址偏移（主层+0x0500）附着，与主层距离1mm（微柱内邻接）
- 下丘脑内部三层：L0内感受（ARC）、L1稳态计算（VMH）、L2输出（LH）

### 5.2 关键约束

- 影子层Bundle信源只能是region 0x01-0x04内的神经元地址，不能直接引用World或环境变量
- 影子层输入的“运动状态”为Motor神经元膜电位（通过Bundle传播），Body环境坐标不得直接注入
- `homeostasis_relay_{x/y/z}`已删除——CPC只输出标量，不输出三轴向量

### 阶段C：趋热反射与避害反射

| 任务 | 说明 |
| :--- | :--- |
| C1：趋热束（可塑） | **phasic_relay**（relay - slow_relay）→ spinal_turn_toward_heat，STDP受DA门控 |
| C2：趋热→运动束（可塑） | spinal_turn_toward → motor_turn，启用TemporalCoupler匹配时序 |
| C3：接近→抑制束（可塑） | 信号源必须为phasic——停止在热源旁时刹车自动解除 |
| C4：避害束（冻结） | noci_relay → spinal_turn_away，从43°C伤害阈值反推增益 |
| C5：避害→趋热抑制（冻结） | 非对称交互抑制——保命永远高于进食 |

**C1信号源修正**：使用phasic_relay而非绝对温度。绝对温度（DC分量）在热源两侧对称等值，STDP会同时强化两侧导致对称死锁。只有phasic信号能在转向时产生不对称的因果配对。

### 阶段D：下丘脑能量门控与负反馈

| 任务 | 说明 |
| :--- | :--- |
| D1：能量→下丘脑束 | HungerDriveNeuron → hypothalamus |
| D2：下丘脑→脑干束 | hypothalamus → brainstem_oscillator（需物理化为AdEx爆发模式） |
| D3：接近→下丘脑束 | **废除**——改用绝对温度感受器或口器摄入量作为饱腹信号 |
| D4：饱腹→节律抑制束 | 饱腹神经元→brainstem_oscillator_inhibitory |

### 阶段E：影子层接口预留

阶段E前影子层只作只读观测器：
- 运动状态（Motor V_mem）→影子层输入（通过Bundle）
- 体感温度（thermoreceptors/relays）→影子层输入
- 能量状态（EnergyStore Capacitor）→影子层输入
- 影子层预测→下丘脑调制（上线后激活，仅调制门控幅度，不直接驱动运动）
