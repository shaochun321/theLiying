## 二、诈胡验证（最高优先级）

### 目的
冻结所有STDP，保留T-043/046/047/048，验证DR5是否仍>55%。如果是，说明新硬连线组件本身就在产生方向性，需要排查。

### 实验设计
```
条件：与T-044完全相同（50k步，冷启动，单热源）
差异：所有bundle的 stdp_lr = 0.0，eligibility_gain = 0.0
保留：T-043交叉抑制、T-046前庭N=3、T-047影子层输入、T-048饥饿敏化
```

### 通过标准
| 结果 | DR5 | 判定 |
| :--- | :--- | :--- |
| ✅ 通过 | ≤55% | 方向性来自STDP学习，非硬连线 |
| ⚠️ 边缘 | 52-55% | 重复一次确认非随机 |
| ❌ 失败 | >55% | 排查T-043的硬连线方向贡献 |

### 如果失败（DR5>55%）
说明T-043交叉抑制束本身就在产生方向性。此时需要**单独对T-043做消融**——保留其他所有STDP（开），仅将交叉抑制束权重归零，运行50k步。若DR5从76.5%跌至~60%，说明T-043是放大信号而非创造信号（可接受）；若DR5跌至~50%，说明方向性主要由T-043创造（需要重新评估架构）。

### 代码框架
```python
# exp_fraud_validation.py
def freeze_all_stdp(circuit):
    for b in circuit.get_all_bundles():
        b.config.stdp_lr = 0.0
        b.config.eligibility_gain = 0.0
# 运行50k步，记录DR5
```


## 三、两阶段实验（诈胡验证通过后）

两阶段实验直接对应P0-1/P0-2/P0-3的验证，在诈胡验证确认无硬连线泄露后执行。

### 第一阶段：冷环境验证（无热源）
**目标**：确认BMR驱动的饥饿信号能在冷区产生学习窗口，且phasic信号为零。

| 配置 | 值 |
| :--- | :--- |
| 热源 | 无 |
| body位置 | [10,50,25]（远离热源位）|
| 步数 | 20k-30k |
| initial_fill | 0.3（饥饿起步）|

**验收**：
- fill持续下降（BMR消耗）
- hypothalamus_hunger激活（随fill下降上升）
- DA门控打开（随hunger上升）
- phasic信号≈0（钳位生效）

### 第二阶段：引入热源（首次接触）
**目标**：验证首次接触热源时IntakeSensor→DA脉冲出现，yaw STDP方向分化启动。

| 配置 | 值 |
| :--- | :--- |
| 热源 | [70,50,25]，T=5，r=30 |
| body位置 | [10,50,25]（热场外，dist≈60）|
| 步数 | 20k（含首次接触后的学习窗口）|

**验收**：
- IntakeSensor→DA在首次接触时出现瞬时峰值（>0.5）
- yaw STDP在首次接触后出现方向分化（|Δw|>0.01）
- 非接近期权重稳定（无同步饱和）

**配置**：与T-041相同（200k步，单热源，冷启动，LOG=10k）

**验收**：
