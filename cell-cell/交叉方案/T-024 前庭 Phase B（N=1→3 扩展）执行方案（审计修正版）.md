## 二、三问闭环

### Q1：真实壶腹嵴上 N 个毛细胞的功能分工

| 分工维度 | Type I 毛细胞 | Type II 毛细胞 |
| :--- | :--- | :--- |
| **形态** | 杯状，被传入纤维的杯状末梢包裹 | 圆柱形，接收传统的bouton突触 |
| **分布** | 集中于壶腹嵴顶部 | 分布于壶腹嵴两侧斜坡 |
| **生理** | 高自发频率、不规则放电、高增益、对高频敏感 | 低自发频率、规则放电、低增益、对低频敏感 |
| **功能** | 编码快速头部运动（高频角加速度） | 编码慢速头部运动和静态位置（低频/tonic） |
| **比例** | ~60% | ~40% |

**REF**：Goldberg 2000 *Annu Rev Physiol* 62:121-155；Eatock & Songer 2011 *Curr Opin Neurobiol* 21:596-601。

**我们的N=3模型**：通过三个不同增益、阈值和**时间常数**的毛细胞模拟并行编码：

| HC | 增益 | 阈值 | τ（C×R） | 功能 |
| :--- | :--- | :--- | :--- | :--- |
| HC_0 | 1.2 | 0.00 | 快（C=5.0, τ=5步） | 高增益、低阈值、快响应——对高频微小加速度敏感（Type I类） |
| HC_1 | 1.0 | 0.02 | 中（C=10.0, τ=10步） | 中增益、中阈值、中响应——正常范围编码（混合类） |
| HC_2 | 0.8 | 0.05 | 慢（C=20.0, τ=20步） | 低增益、高阈值、慢响应——抗饱和、编码持续加速度（Type II类） |

**时间常数分频的物理依据**：RC漏积分电路的截止频率由τ=RC严格决定。差异化C值使三个HC在频域上形成分频滤波器组——HC_0响应高频瞬态（dω/dt峰值），HC_2平滑高频震荡、专心编码低频稳态加速度（ω的持续分量）。这实现了真正的Type I/Type II并行分频编码，而非仅仅是幅度缩放。

### Q2：N 个 HC 是否共享 Afferent？MET 如何分配？

**结构决策**：**3个HC共享同一个传入纤维（Aff_reg + Aff_irr）**。

**依据**：
1. **生物学**：壶腹嵴上多个毛细胞汇聚到同一个传入纤维，收敛比约2:1-3:1。
2. **物理学**：解剖收敛比通过突触数量实现空间整合。3个HC→1个Aff，通过3条独立突触，每条有独立的`initial_weight`和`synapse_gain`，在Aff膜上做KCL加法。
3. **工程约束**：不新增Aff，避免census污染（与D1原则一致）。

**MET→HC分配**：
```
MET_yaw_reg
    ├── [frozen, gain=1.2] → HC_yaw_reg_0（高增益、快τ、低阈值）
    ├── [frozen, gain=1.0] → HC_yaw_reg_1（中增益、中τ、中阈值）
    └── [frozen, gain=0.8] → HC_yaw_reg_2（低增益、慢τ、高阈值）
         ↓
    HC_0, HC_1, HC_2 → [各自独立frozen Bundle] → Aff_reg_yaw（共享传入纤维，KCL加法）
```

### Q3：每个HC的initial_weight/synapse_gain

**参数推导（KCL电流守恒）**：

当前N=1时：`MET→HC：synapse_gain=1.0；HC→Aff：synapse_gain=1.0`（当前Aff接收1个HC的输入）。

N=3扩展时：

**MET→HC阶段**（增益分级）：
| HC | synapse_gain | 功能 |
| :--- | :--- | :--- |
| HC_0 | 1.2 | 高增益，对微小加速度敏感 |
| HC_1 | 1.0 | 中增益，正常范围编码 |
| HC_2 | 0.8 | 低增益，抗饱和 |

**HC→Aff阶段**（KCL电流守恒缩放）：

> 为保持Aff总输入量级与N=1时电荷注入一致，根据KCL电流守恒，每个HC→Aff的`synapse_gain = 1.0 × (1/N) = 1.0/3 ≈ 0.33`。在此均值守恒的基础上，群体编码自然涌现出√3≈1.73倍的SNR物理提升——信号线性相加（×3），高斯白噪声正交相加（×√3），两者相除即得√3。**不需要、也不应该在突触电导上人工乘以1/√N——这会导致传入纤维接收到的总信号幅度衰减42.3%，破坏下游动态范围。**

**增益代偿递减**：
```
N=1: synapse_gain = 33×生物（当前硬编码补偿）
N=3: synapse_gain = 33/3 = 11×生物
N=10: synapse_gain = 33/10 = 3.3×生物
N=100: synapse_gain = 33/100 ≈ 0.33×生物（物理常数）
```
