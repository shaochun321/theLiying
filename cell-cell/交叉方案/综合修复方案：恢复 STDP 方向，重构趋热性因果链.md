# 综合修复方案：恢复 STDP 方向，重构趋热性因果链

**日期**：2026-07-03
**关联**：200k 基线实验、CPG-DA 相位错配诊断、三份分析文档
**性质**：修复方案（非重构）——在现有架构内调整 DA 驱动模式，恢复 STDP 方向


## 一、实验揭示的核心问题

200k 基线实验是 HC-009/014/017/021/022 修复后第一次真实测量。结果揭示了**三个错配**，它们共同解释了为什么趋热性在修复后消失：

| 错配类型 | 现象 | 根因 |
| :--- | :--- | :--- |
| **频域错配** | relay→DA front 权重 -82%（LTD）| CPG 2Hz phasic DA vs relay tonic 激活 |
| **空间错配** | body 在 d=9.5 后漂至 77.1，无返回 | HC-016 标量 deviation 各向同性注入 Motor |
| **量纲错配** | 换能层学习极慢、DR5 虚高 | stdp_lr 过低；DR5 在热场外测噪声梯度 |

**核心结论**：这不是“系统坏了”，而是真实的 STDP 学习路径第一次被测量，而方向是错误的。CPG→DA 的固定频率驱动与 relay 的 tonic 热激活在时间上错配，导致 STDP 产生 LTD 而非 LTP——这是物理因果律的必然结果。


## 二、频域错配的数学必然性（为什么是 -82% LTD）

STDP 是 AC 耦合的相位检测器，其更新方程在连续时间下积分：

$$\Delta w \propto \int (\text{LTP\_term} - \text{LTD\_term}) dt$$

| 信号 | 性质 | 对 STDP 的贡献 |
| :--- | :--- | :--- |
| **Front Relay（pre）** | Tonic（DC 恒亮）| 持续高 `pre_trace` |
| **DA（post）** | Phasic（AC 脉冲），2Hz 固定频率 | 脉冲后 `post_trace` 指数长尾 |

在热场中，Front Relay 常亮。DA 脉冲结束后，`post_trace` 经历漫长的指数衰减长尾。此长尾期间常亮的 Relay `pre_trace` 持续驱动 LTD 项，导致 LTD 面积远大于 LTP（约 82% 削弱）。

**信息论解读**：STDP 是一台严苛的因果律检测仪。当 Relay 持续放电而 DA 只按自己的固定节奏跳动时，系统判定“DA 的爆发不是我引起的”，遂启动 LTD 剪断该突触连接以节省 ATP 能量。


## 三、修复方案：三阶段执行

### 执行顺序总览

| 阶段 | 任务 | 工作量 | 验收标准 |
| :--- | :--- | :--- | :--- |
| **第一阶段** | P0（切除 CPG→DA）+ RPE 驱动 DA | 2-4h | relay→DA front 从 LTD 翻转为 LTP |
| **第二阶段** | 学习率提升 + DR5 静噪门 | 1-2h | 权重分化速度提升 |
| **第三阶段** | 空间错配修复（HC-016） | V2.0 阶段 | 方向性推力主导 |

### 第一阶段：恢复 DA 的物理语义（P0）

**目标**：将 DA 从“固定节拍器”恢复为“事件驱动型 RPE 信号”

**操作**：

1. **切除 CPG→DA 驱动**：在实验脚本中将 CPG→DA 增益置零
   ```python
   c.cpg_to_da.gain = 0.0
   ```

2. **启用 RPE→DA 路径**：确保 DADifferentialGate 的 DA 输出连接到 STDP 门控
   ```python
   # DA = max(0, k * d(fill)/dt)
   rpe_da = self.da_gate.step(fill_change_rate, dt)
   ```

**验收标准**：
- relay→DA front 权重从 -82% 趋势（LTD）翻转为正值增长（LTP）
- 仅需运行 50k 步短程即可验证方向翻转


### 第二阶段：参数调优与测量修正

**目标**：加速学习、清理测量噪声

**操作**：

1. **提升 stdp_lr**：`thermo_to_relay` 0.001 → 0.005（模拟外周感受器在极端环境下的快速敏化）

2. **添加 DR5 有效热场门控**：
   ```python
   if max(T_f, T_b, T_l, T_r) > 0.5:  # 仅当有效热辐射时统计
       total_valid_steps += 1
       if grad_dot_v > 0:
           positive_align_steps += 1
   ```


### 第三阶段：空间错配修复（P1，延后至 V2.0）

**目标**：将标量 deviation 从各向同性注入改为方向性推力

**当前处理**：延后，等待 V2.0 脊髓反射束构建。因为 HC-016 的修复依赖 V2.0 脊髓交叉反射束设计，而 P0（CPG→DA 切除）是当前优先级最高的独立任务。


## 四、执行顺序与验收标准

| 步骤 | 任务 | 验收 |
| :--- | :--- | :--- |
| 1 | 实验脚本中 CPG→DA 增益置零 | CPG→DA 不再驱动 DA |
| 2 | 启用 RPE→DA（fill 变化率）| DA 在 fill 上升时爆发 |
| 3 | 提升 thermo_to_relay stdp_lr 至 0.005 | 参数已修改 |

## 五、与环流耦合的关系

修复方案将 DA 驱动权从 CPG（人工振荡器）移交给 RPE/CPC（稳态偏差检测器），使 DA 信号与身体实际行为对齐：

| 步骤 | 内容 |
| :--- | :--- |
| 1 | DA 由 RPE（fill 变化率）驱动 → 接近→爆发→LTP |
| 2 | 验证趋热性方向信号建立 |
| 3 | 环流耦合结构化（thermal_stability、CPC deviation→DA）在正确方向基座上运行 |
