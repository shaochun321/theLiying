## 一、反对意见中必须采纳的三项修正

### 修正 1：能量簿记Bug修复（P0）

**问题**：`thermal_mouth.py` 固定从 `cylindrical_sources[0]` 扣除能量，导致E2/E3全程未消耗，温度场不衰减，小车无需迁移。

**修复**：在 `ThermalMouth.step()` 中，计算口器位置到所有热源的距离，从**最近的热源**扣除能量。

**代码位置**：
```python
# thermal_mouth.py 中 energy deduction 段
# 原代码：固定取 cylindrical_sources[0]
# 修改为：
nearest_src = min(world.cylindrical_sources, key=lambda s: dist_to_surface(pos, s))
if nearest_src and nearest_src.alive:
    nearest_src.absorb(total_heat_flux)
```

### 修正 2：非对称起始位置（P0）

**问题**：Phase 3 起始位置 `[50,50,25]` 是三源几何中心，处于对称鞍点，前 70k 步的对称振荡破坏方向性学习窗口。

**修复**：将起始位置改回 Phase 2 的有效位置 `[75, 35, 25]`，使 body 初始偏向 S1，创造非对称梯度。

### 修正 3：eligibility_gain 回退（P0）

**问题**：Phase 3 中 `eligibility_gain=3e-5` 导致权重在100k步内饱和，方向性分化窗口被压缩。

**修复**：恢复为 Phase 2 验证值 `1e-5`。


## 二、反对意见中部分采纳的方向（与架构改动并行）

### 方向：Motor增益提升 + k_conv降低（D方案）

反对意见认为 Motor 微弱（~0.01）是信用分配失效的根源——STDP 学到的权重对行为无影响，因为身体实际由 k_conv（~0.12）驱动。将 Motor 提升至 0.5，将 k_conv 降至 0.05，使 Motor 贡献从 12% 提升至主导地位。

**执行**：
- `Muscle.gain = 0.1 → 0.5`（实验脚本覆写）
- `k_conv = 0.50 → 0.05`（实验脚本覆写）

**预期**：当 Motor 贡献 ~0.05-0.1 units/step，大于 k_conv 的 0.01 时，身体轨迹由学习驱动，而非由物理力主导。STDP 的权重变化将直接影响行为，形成因果闭环。
