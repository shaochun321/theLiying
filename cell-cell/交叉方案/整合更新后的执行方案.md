### 2.2 T-060：L2指标重构（P0，1h）

**操作**：将原单一指标替换为三维指标。

**L2a：学习窗口期峰值分化度**

$$\|\Delta w\|_{peak} = \max_{t \in [0, 20000]} |w_{ccw}(t) - w_{cw}(t)|$$

通过标准：$> 0.15$

**L2b：方向选择指数（DSI）**

$$DSI(t) = \frac{\left|\int_{t-W}^{t} (A_{ccw}(s) - A_{cw}(s)) ds\right|}{\sigma_{net}(t) \cdot \sqrt{W} + \epsilon}$$

- 数据来源：`c.spinal_ccw.activation`，`c.spinal_cw.activation`
- 积分窗口：$W=5000$步
- 计算窗口：Foraging窗口（$fill < 0.85$ 且 $DA > 0.1$）
- 通过标准：$DSI_{peak} > 1.0$

**L2c：能量-学习耦合效率**

$$\eta_{E\to L} = \frac{T_{foraging}}{T_{total}} = \frac{\text{fill}<0.85 \text{ 且 } DA>0.1 \text{ 的步数}}{200000}$$

- T-059基线：6.56%（13,127步）
- 通过标准：$> 8\%$

**新L2通过条件**：**L2a AND L2b AND L2c** 全部满足。

### 2.5 T-063：双热源鞍点实验（P0，2h）

**物理意义**：双等强热源的中垂线是**不稳定鞍点**。微弱噪声使body向一侧偏移→该侧phasic信号增强→STDP正反馈强化该侧转向偏好→**对称性破缺**。

**配置**：
- 热源A：`[70, 30, 25]`，T=5，r=30
- 热源B：`[70, 70, 25]`，T=5，r=30
- Body初始：`[10, 50, 25]`（两源中垂线）
- initial_fill：0.3，200k步

**验收**：
- 选择一侧热源（dist < 10）
- $\|\Delta w\|_{peak} > 0.2$（双热源提供更强的方向分化需求）
- SDI > 80%
- 死锁率 < 10%

**生物学依据**：果蝇成体热趋向双选择实验是评估温度偏好的标准范式。

### 2.6 T-064：BMR调整（条件触发，5min+验证）

**触发条件**：T-062中$\eta_{E\to L} < 10\%$时执行。

**操作**：BMR从0.002提升至0.0025（+25%）。

**生物学依据**：
- 冷暴露下基础代谢率变化有充分的文献支持（Cannon & Nedergaard 2004；Speakman 2018）
- 运动代谢成本可占每日能量消耗的绝大部分
- 饥饿状态通过NMDA受体亚基切换控制STDP方向性——延长饥饿窗口=延长方向性STDP窗口

**短程验证（50k步）**：

| 检查项 | 通过标准 | 失败回退 |
| :--- | :--- | :--- |
| fill@50k | < 0.85 | BMR回退至0.002 |
| fill最低点 | > 0.2 | 降低BMR增幅 |
| Foraging DR5 | > 60% | 检查DSI是否>1.0 |

### 2.7 T-065：物理驱逐实验（可选深度验证，P1，1h）

**操作**：在200k长程实验进行到step 100k时，瞬间将热源坐标从`[70,50,25]`瞬移至`[10,90,25]`。

**预期涌现**：
1. 环境骤冷→fill下降→饥饿敏化启动
2. 已对称饱和的旧权重在eligibility trace与新phasic刺激下发生**重构**
3. 观测第二峰值的$\|\Delta w\| > 0.15$

**验收**：
- 驱逐后50k步内$\|\Delta w\| > 0.1$
- 驱逐后100k步内二次归巢（dist < 10）
- 二次归巢后SDI > 80%

**物理意义**：纠偏时间常数$\tau_{reset}$是衡量神经可塑性优劣的终极维度。这是最纯粹的“重新学习”测试——不修改任何学习规则，仅通过改变物理位置检验系统适应能力。

## 五、总结

| 问题 | 回答 |
| :--- | :--- |
| 两份新文档是否可取？| ✅ 高度可取——“绝对冻结”诊断了L2伪失败的数学本质；“修复方案更新版”提供了三维指标和双热源实验框架 |
| 为什么L2终态测量失效？| 单热源中心$\nabla T \approx 0$，系统抵达李雅普诺夫稳定平衡点。任何显向权重分化都会导致打转——对称饱和是生物“稳稳停在原地”的唯一合法突触流形 |
| 如何证明可塑性确实发生？| 动力学探针：捕获过渡期$\|\Delta w\|_{peak}$ + 局部吸引子扰动（热源瞬移） |
| 双热源实验为什么必要？| 单热源只能验证“梯度跟随”；双热源鞍点验证“方向选择”与“对称性破缺”——只有STDP驱动的系统才能打破布里丹之驴困境 |
| 能量-学习耦合效率的意义？| 饥饿状态通过NMDA受体亚基切换控制STDP方向性。$\eta_{E\to L}$度量“方向性STDP可用窗口”的占比 |
| 核心原则 | **不改物理系统，只升级测量探针与实验场景**——让评估体系配得上系统已经涌现的智能行为 |
