# T-057 修复与重启方案（整合版）

**日期**：2026-07-06
**版本**：3.0-final
**依据**：T-057 FAIL诊断 + 两份反馈


## 一、T-057 失败的双重根因

### 1.1 脚本探针故障（工程层）

| 探针 | 错误代码 | 正确代码 | 后果 |
| :--- | :--- | :--- | :--- |
| \|Δw\| | `bundle_relay_to_slow_left/right` | `bundle_d1_phasic_left_to_spinal_ccw/cw` | 权重读数为 0 |
| T4.1 | `c.vestibular.column` | 遍历 `c.bundles_col_to_motor` | T4.1 为 NaN |

**影响**：200k 步全程“蒙眼奔跑”，\|\Δw\|\=0 是读数错误，不代表权重未分化。

### 1.2 T-048 增益过调（物理层）

T-048 的 `gain_max = 1.5×` 导致 relay 神经元 `r_leak` 降至 2/3，稳态膜电位飙升 50%：

$$V_{ss} = I_{in} \cdot R_{leak}$$

$$R_{leak} \to \frac{2}{3}R_{base} \implies V_{ss} \to 1.5 \times V_{ss}^{base}$$

数字生物在极远距离就能“闻到”热源并高效进食：

$$\text{进食积极性} \propto \frac{1}{R_{leak}}$$

**动力学连锁崩溃**：

$$fill \to 1.0 \implies Hunger \to 0 \implies Satiety \uparrow \implies DA \to 0$$

在三因子 STDP 中，DA 是绝对门控：

$$\Delta w_{ij} = \eta \cdot \text{pre}_i \cdot \text{post}_j \cdot DA(t)$$

当 $DA \to 0$ 时，STDP 完全锁死。T-057 的 DR5=50.3% 与 T-054（冻结 STDP，DR5=51%）完全一致，证实系统处于“功能性 STDP 冻结”。


## 二、修复方案

### P0-A：脚本探针修复（工程，确定性）

#### A.1 \|Δw\| 监控探针

```python
# 错误
bl = getattr(c, 'bundle_relay_to_slow_left', None)   # → None
br = getattr(c, 'bundle_relay_to_slow_right', None)  # → None

# 正确
b_ccw = c.bundle_d1_phasic_left_to_spinal_ccw
b_cw  = c.bundle_d1_phasic_right_to_spinal_cw
w_ccw = b_ccw._memristors[0][0].w
w_cw  = b_cw._memristors[0][0].w
delta_w = w_ccw - w_cw
```

#### A.2 T4.1 计算

```python
def get_t41_ratio():
    axis_ws, cross_ws = [], []
    for b in c.bundles_col_to_motor:
        ws = [m.w for row in b._memristors for m in row]
        avg_w = sum(ws) / max(len(ws), 1)
        if 'cross' not in b.id:
            axis_ws.append(avg_w)
        else:
            cross_ws.append(avg_w)
    avg_ax = sum(axis_ws) / max(len(axis_ws), 1)
    avg_cr = sum(cross_ws) / max(len(cross_ws), 1)
    return avg_ax, avg_cr, avg_ax / max(avg_cr, 1e-6)
```

### P0-B：T-048 增益钳位（物理修复）

**问题**：`gain_max = 1.5×` 导致 $V_{ss}$ 飙升 50%，进食过载。

**修复**：钳位至 `1.15×`，使 relay 保持在亚阈值工作点，防止进食过载。

$$R_{leak}^{eff} = \frac{R_{base}}{1 + (G_{max}-1) \cdot H}$$

其中 $H = \max(0, 1 - fill)$ 是饥饿水平（0=饱腹，1=极饿）。

**钳位后**：

$$V_{ss}^{max} = I_{in} \cdot \frac{R_{base}}{1.15} \approx 0.87 \cdot I_{in} \cdot R_{base}$$

对比当前 1.5× 的 $0.67 \cdot I_{in} \cdot R_{base}$，增益降低约 23%。

$$V_{ss}^{peak} \approx 0.87 \times V_{ss}^{base}$$

T-042 确立的 `sp_peak ≈ 0.138` 窗口将被保留（而非 T-057 中因 $V_{ss}$ 过高导致持续放电）。

### P0-C：状态门控测量（新增）

DR5 全局 50% 不代表系统“不会找吃的”——而是“找到后已经吃饱了”。改用状态门控测量：

```python
if fill < 0.85 and DA > 0.1:      # 觅食期
    dr5_foraging += (grad_dot_v > 0)

sdi = (fill > 0.8).sum() / total_steps   # 生存驻留指数
```

验收标准：

| 指标 | 公式 | 目标 |
| :--- | :--- | :--- |
| Foraging DR5 | $DR5 \mid_{fill < 0.85, DA > 0.1}$ | > 60% |
| SDI | 全局 fill > 0.8 的步数占比 | > 30% |
| \|Δw\| | 峰值分化 | > 0.1 |

### P1（备选）：生态参数补偿

如 P0-B 钳位后 fill 仍过早饱和，降低 ThermalMouth.eta：

$$\eta_{new} = 0.06 \times \frac{1.15}{1.5} \approx 0.046$$

或直接设 $\eta = 0.04$。这延长进食窗口，为 STDP 留出积分时间。
