## 一、对两处纠偏的最终核实

### 1.1 §3.1 ν(t) 展开式的代数与符号错误

**架构师纠偏**：原公式 `ν = ξ²/R_ξ - ξ/C_ξ·|O-P|` 存在符号和系数双重错误，正确公式应为 `ν = ξ|O-P| - ξ²/R_ξ`。

**核实结果**：✅ **纠偏完全成立。**

从 KCL 方程 $C_{\xi} \frac{d\xi}{dt} = -\frac{\xi}{R_{\xi}} + |O - P|$ 同乘 $\xi$，左边即为 ν，因此：
$$\nu(t) = \xi|O - P| - \frac{\xi^2}{R_{\xi}}$$

原公式两处错误：多除了一个 $C_\xi$，且正负号颠倒。纠正后的物理含义清晰：第一项为误差信号注入的功率（正），第二项为焦耳热耗散功率（负）。ν > 0 对应充电/探索态，ν < 0 对应放电/固化态。

**对当前执行的影响**：无。ν 探针（`nu_probe.py`）尚未实现，属于远期任务（原 Phase 5）。当前执行的 P0-P4 不依赖此公式。

### 1.2 §5.1 “最小功率”概念错配

**架构师纠偏**：路径优化泛函的量纲是焦耳（J），而非瓦特（W）。应定性为**最小作用量原理**，而非最小功率原理。

**核实结果**：✅ **纠偏完全成立。**

$L_e/v_{cond} \cdot P_{spike}$ 的量纲 = [s] × [W] = [J]。该泛函优化的是单次信号传递的总能量消耗，而非瞬时功率。

**对当前执行的影响**：无。sprout/prune 逻辑尚未基于此泛函实现，属于远期架构设计。当前 P0-P4 不涉及拓扑生长。
