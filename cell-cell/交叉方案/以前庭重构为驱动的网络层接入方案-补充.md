## 一、该决策锁定了什么

非均匀分布不是一个“参数偏好”，而是一个**拓扑结构约束**，它固定了以下内容：

| 锁定项 | 具体含义 | 影响范围 |
| :--- | :--- | :--- |
| 半规管三轴（yaw/pitch/roll）之间的拓扑距离 | 恒为 1 | 簇内连接延迟短，布线税低，STDP 窗口窄 |
| 耳石三轴（oto_x/y/z）之间的拓扑距离 | 恒为 1 | 同上，但仅限耳石簇内部 |
| 半规管簇 ↔ 耳石簇之间的拓扑距离 | 恒为 3 | 跨簇连接延迟长，布线税高（3倍），STDP 窗口宽 |
| 跨簇连接的方向性 | 对称（簇间距离 3 无方向性） | 半规管→耳石 与 耳石→半规管 延迟相同 |

**关键推论**：簇间距离 3 大于资格迹时间常数 $\tau_{elig}=300$ 步的量级（延迟差约 3000 步 vs 资格迹 300 步），意味着**旋转和平移信号在时间轴上被彻底分离**，STDP 几乎不会将它们混淆到同一权重更新中。这是该决策的核心价值。

## 二、跨簇布线成本的具体含义

接受“跨簇布线成本”不只是口头同意，它将在三个层面产生具体的物理后果：

### 2.1 FIFO 延迟差

根据公式 `delay_steps = ceil(L_total / (v_cond × dt))`，对于跨簇连接（$L_{spatial}=3$）：

- 若 $L_{temporal}=0$，$L_{layer}=0$，则 $L_{total}=3$
- 假设 $v_{cond}=1.0$，$dt=0.001$，则 `delay_steps = 3000`
- 簇内连接（$L_{total}=1$）的 `delay_steps = 1000`
- **跨簇比簇内多 2000 步（2秒模拟时间）**

这一延迟差是固定的，不受能量状态影响。

### 2.2 布线维持税

根据 $P_S = \kappa_1 \sum w_{ij} \times L(a_i, a_j)$，跨簇连接（$L=3$）的静态维持税是簇内连接（$L=1$）的 **3 倍**。

具体到数值（基于合取报告的默认值 $\kappa_1$ 尚未标定）：

- 如果 $\kappa_1$ 最终标定为 0.001 fill/step/权重单位，则一条跨簇连接权重 0.25 的维持税为 $0.001 \times 0.25 \times 3 = 0.00075$ fill/step
- 簇内连接为 $0.00025$ fill/step
- **差距为 0.0005 fill/step/连接**

若前庭有 12 条跨簇连接（6 个半规管轴 × 6 个耳石轴的部分组合），每年（模拟）额外消耗约 $12 \times 0.0005 \times 86400 = 518$ fill——这是可承受的，但会在能量审计中体现为持续的“结构税”开销。

### 2.3 能量博弈阈值

当能量池 fill 低于某个阈值时，`nearby(radius)` 的 sprout 概率会优先淘汰跨簇连接（因为维持成本高而使用频率可能低）。该阈值由 $P_{available}$ 与 $P_{baseline}$ 的比值决定：

- 如果 $P_{available}/P_{baseline} < 0.3$，跨簇连接的维持优先级自动下降
- 簇内连接在该阈值下仍被保留

**这意味着系统在能量紧张时会“退化”为仅处理纯旋转或纯平移，牺牲复合运动精度以换取生存——这正是 TSI 理论期望的行为。**

## 三、该决策对网络层架构的约束

非均匀分布一旦锁定，网络层的距离函数 `L_spatial(axis_i, axis_j)` 被固定为：

```
if axis_i <= 2 and axis_j <= 2: return 1
elif axis_i >= 3 and axis_j >= 3: return 1
else: return 3
```

**这产生三个不可逆的架构约束**：

1. **地址轴的顺序不可更改**：axis=0,1,2 必须是半规管，axis=3,4,5 必须是耳石。任何重新排序都会破坏簇结构。
2. **新增前庭轴时（如第7轴）必须选择归属簇**：新轴要么加入半规管簇（间距=1），要么加入耳石簇（间距=1），否则需要重新定义簇间距离。
3. **影子层的超度量沉积需考虑此簇结构**：影子层如果要预测前庭信号，其内部沉积映射将自然形成两个子簇（旋转预测子簇和平移预测子簇），而非均匀分布。

## 一、锁定后的距离函数完整定义

前庭网络层的总距离函数 `L_total(a_i, a_j)` 最终确定为：

```
L_total = L_spatial + L_temporal + L_layer
```

其中：

| 分量 | 定义 | 前庭专用值 |
| :--- | :--- | :--- |
| `L_spatial` | 基于 axis 的簇结构 | 半规管簇内=1，耳石簇内=1，跨簇=3 |
| `L_temporal` | `\|τ_class_i - τ_class_j\| × 0.5` | MET/HC/Aff 的 τ_class=1，Enc/Col 的 τ_class=2，差值=1 → 0.5 |
| `L_layer` | `\|layer_i - layer_j\| × 1.0` | 相邻层差值=1 → 1.0 |

**前庭内部各类连接的典型 `L_total` 值（锁定后）：**

| 连接类型 | 示例 | L_spatial | L_temporal | L_layer | L_total |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 同簇、同τ、相邻层 | MET_yaw → HC_yaw | 1 | 0 | 1 | **2** |
| 同簇、异τ、相邻层 | Aff_yaw → Enc_yaw | 1 | 0.5 | 1 | **2.5** |
| 同簇、异τ、同层 | Enc_yaw → Col_yaw | 1 | 0 | 1 | **2** |
| **跨簇**、同τ、同层 | Enc_yaw → Enc_oto_x | **3** | 0 | 0 | **3** |
| **跨簇**、异τ、相邻层 | Aff_yaw → Enc_oto_x | **3** | 0.5 | 1 | **4.5** |
| **跨簇**、同τ、异层 | Col_yaw → Motor_translation_x | **3** | 0 | 1 | **4** |

**关键结论**：
- 跨簇连接的最小 `L_total = 3`（耳石 Enc ↔ 半规管 Enc，同层同τ），对应延迟 `3000` 步。
- 簇内连接的最大 `L_total = 2.5`（Aff → Enc，跨τ相邻层），对应延迟 `2500` 步。
- **跨簇与簇内的最小延迟差为 500 步**（`3000 - 2500`），仍大于资格迹时间常数 `τ_elig=300` 步，足以让 STDP 在时间轴上分离旋转和平移信号。
