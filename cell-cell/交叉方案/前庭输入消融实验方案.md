# 前庭输入消融实验方案

**日期**：2026-07-06
**版本**：1.0
**性质**：防诈胡补充验证
**前置**：T-057修复完成并验证通过


## 一、实验目的

T-054（冻结全部STDP）已验证方向性来自学习机制，T-043交叉抑制束被排除为硬连线方向源。但一个残留风险尚未排除：**如果前庭信号本身带有物理不对称性，STDP学到的方向可能部分来自这个硬连线偏置，而非纯粹的热场几何。**

本实验通过“前庭切除”模拟——将前庭输入信号增益降至极低水平——验证方向性学习的**内容**是否确实来自热感觉的空间梯度，而非前庭的固有偏置。

## 二、实验设计

### 2.1 核心操作

| 操作项 | 方法 |
| :--- | :--- |
| **前庭增益衰减** | 将前庭输入信号（`oto_x/y/z`、`yaw/pitch/roll`）的振幅乘以衰减因子 `α = 0.02`（降至原值的2%） |
| **保留项** | 所有STDP学习、T-043推挽差分、T-048饥饿敏化、影子层输入、能量链全部保留 |
| **对照组** | 相同配置下，`α = 1.0`（正常前庭输入） |

### 2.2 衰减因子的物理合法性

完全归零前庭信号（`α=0`）会切断运动环流（`Motor→Body→Otolith→Aff→Enc→Col→Motor`），导致运动不稳定。降至原值的2%保留了环流的基本稳定性，同时将前庭信号中可能蕴含的固有方向偏置压制到远小于phasic信号的水平。这一操作在生物实验中对应于前庭功能低下模型，是标准的神经科学验证方法。

### 2.3 实验配置

| 参数 | 实验组 | 对照组 |
| :--- | :--- | :--- |
| 前庭增益 α | 0.02 | 1.0 |
| 热源 | [70,50,25], T=5, r=30 | 同 |
| Body起始 | [10,50,25], fill=0.3 | 同 |
| 步数 | 50k | 50k |
| STDP | 全部开启 | 全部开启 |

## 三、预期结果与判定标准

| 结果 | 实验组DR5 | 判定 | 含义 |
| :--- | :--- | :--- | :--- |
| ✅ 通过 | 实验组DR5仍>60%（或下降<15%） | 前庭信号不是方向性来源 | STDP学习的是热感觉的空间梯度 |
| ⚠️ 边缘 | 实验组DR5下降15-25% | 前庭有轻度贡献 | 需进一步排查前庭链路不对称性 |
| ❌ 失败 | 实验组DR5降至~50%（与T-054随机基线一致） | 前庭信号是方向性的主要来源 | 方向性学习内容来自前庭固有偏置，需重新审计前庭链路 |

**通过标准**：实验组DR5下降 < 15%（即仍 > 61%），证明方向性学习内容来自热感觉信号而非前庭偏置。
