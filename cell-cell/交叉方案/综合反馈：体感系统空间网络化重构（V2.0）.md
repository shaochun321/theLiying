## 二、必须修正的设计错误：换能束 STDP

### 2.1 问题本质

原始方案在 5.1 节中设计了热换能束 `transducer_env_to_thermo_{pid}`，设置：

> `plasticity=True, # 可塑，允许 STDP 学习`

**这是必须修正的根本性设计错误。**

### 2.2 不可行性的三层论证

**第一层：量纲与因果性**

STDP 要求突触两端都是神经元，都发放动作电位（产生 pre_trace 和 post_trace）。换能束的一侧是 `skin_patch`——物理温度标量，不可能产生 STDP 所需的 `pre_trace`。热量不会因为马达转了一下就与神经产生“赫布因果律”。

| 检查项 | STDP 要求 | 换能束的实际条件 | 匹配？ |
| :--- | :--- | :--- | :--- |
| pre_trace | 突触前神经元 spike | skin_patch 是物理温度标量 | ❌ |
| post_trace | 突触后神经元膜电位 | thermoreceptor 由物理换能驱动 | ❌ |
| spike-timing | 两个神经元的发放时序 | 无 spike 信号参与 | ❌ |

**第二层：系统演化风险（“黑暗房间悖论”）**

如果换能束权重可塑，系统为了最小化预测误差（Xin），会将权重降至零，消除所有感觉输入。这在计算神经学中被称为“黑暗房间悖论”——系统主动让自己“失明”以避免误差。这不是语义硬编码，而是错误结构设计导致的病态退化。

**第三层：生物学僭越**

从皮肤温度转化为神经元电流的过程叫“感觉换能”，由 TRP 离子通道蛋白的物理构象改变介导。换能系数是物种演化写死在 DNA 里的物理常数，不是个体学习对象。感觉器只负责忠实地按物理常数转换信号，不参与学习。

### 2.3 修正指令

| 原始 | 修正 | 理由 |
| :--- | :--- | :--- |
| `plasticity=True` | `plasticity=False`（冻结） | 换能系数是物理常数，不是学习对象 |
| 无注释 | 添加 `CROSS-MODAL` 量纲注释 | 明确此为跨介质物理换能常数 |

```python
# CROSS-MODAL [A/°C]: 物理换能常数（TRPV1/TRPM8 离子通道跨导）
# 来源于物种演化（BIO: Desai et al. 2005），非个体学习
# plasticity=False：感受器不通过学习改变换能效率
```

## 四、外部反馈的额外物理洞察

### 4.1 热噪声悖论：体感重构与 N=3 的物理绑定

贴片面积缩小 → 热容减小 → 温度涨落方差增大（⟨ΔT²⟩ = k_BT²/C）→ 热噪声放大 √3 倍 → 需要群体编码降噪（SNR∝√N）。

**推论**：体感重构（4→12贴片，面积缩至 1/3）带来的热噪声放大，恰好需要前庭 Phase B（N=1→3）来抵消（SNR 提升 √3）。两者在时间上重合不是偶然，而是建构定律的物理必然。

这为规模泛化触发条件中的 N=1→3 提供了一个额外的物理动机——不仅是为了突破香农极限，也是为了抵消体感重构带来的热噪声。这个洞察不影响 Phase B 的实施路径，但强化了其物理必要性。

### 4.2 全连接 O(N²) 的诅咒：稀疏编码的涌现必然

建构定律方程 η(N) = C(N)/P(N) 中，分子随 N 对数增长，而分母如果是全连接则按 N² 增长。系统为了活下去，将被迫利用空间拓扑距离和修剪机制斩断长程连接，自发形成 O(N) 甚至 O(log N) 的稀疏拓扑。

**结论**：稀疏性不是设计选择，而是热力学逼出来的求生本能。

### 4.3 阈值多样性：量程分段的成本效益

N=3 时分配 0.8×、1.0×、1.2× 的阶梯阈值，构建了一个高动态范围的“闪存模数转换器”。0.8× 前锋打破死区，1.2× 后卫防止高温饱和。这是用最小节点成本压榨信道容量的最优策略。
