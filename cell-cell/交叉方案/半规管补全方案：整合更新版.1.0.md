## 一、为何半规管是下一阶段的首要任务

当前系统仅有耳石（oto_x/y/z）线性加速度通道，yaw/pitch/roll角速度通道恒为0。根据爱因斯坦等效原理，纯粹的线性加速度计在物理上**绝对无法区分“身体向前加速”和“身体向后仰倒”**（倾斜-平移模糊，Tilt-Translation Ambiguity）。

大自然解决这个物理学死结的唯一手段——也是现代无人机飞控的标准解法——是引入独立的角速度传感器（半规管），进行**正交维度的数据融合**。

补全半规管不是“加个功能”，而是为系统注入三维空间定向的**绝对刚性物理坐标系**。


## 二、生物物理模型

### 2.1 Steinhausen扭摆模型（1931）

完整模型是二阶ODE，描述壶腹嵴（Cupula）角位移$\theta$随头部角加速度$\alpha$的变化：

$$
I\ddot{\theta} + R\dot{\theta} + K\theta = I\alpha
$$

其中$I$为内淋巴惯性矩，$R$为黏滞阻力，$K$为Cupula弹性系数。

生物实际中，内淋巴黏滞阻力极大（过阻尼，$R \gg I, K$），惯性项$I\ddot{\theta}$在低频时可忽略，方程简化为：

$$
R\dot{\theta} + K\theta \approx I\alpha
$$

由于$\alpha = \dot{\omega}$（角速度的导数），对上式积分可知Cupula偏转角$\theta$与头部角速度$\omega$成正比。持续匀速旋转时，内淋巴最终与管壁同步，Cupula恢复原位，感觉消失——即**高通滤波特性**。

**时间常数**：$\tau_{cupula} = R/K \approx 4\text{s}$（哺乳动物，~3-6s区间）

### 2.2 离散实现（一阶高通滤波）

$$
\hat{\omega}[t] = \alpha \cdot (\omega_{raw}[t] - \omega_{raw}[t-1]) + \alpha \cdot \hat{\omega}[t-1]
$$

其中$\alpha = dt / (dt + \tau_{cupula})$，约0.00025（当$dt=1ms, \tau=4s$）。

**数值稳定性注意**：极小的$\alpha$在浮点数运算中可能产生累积误差。确保`_prev_angular`和`filtered_prev`变量正确维持状态，避免200k步长程仿真中的数值漂移。


## 三、工程实现规格

### 3.1 信号注入（阶段0）

在`VariantCircuit._apply_vestibular_input()`中，从body获取角速度，经Cupula高通滤波后写入`mechanical_inputs`：

```python
# 获取角速度
angular_velocity = {
    'yaw': body.angular_velocity.get('yaw', 0.0),
    'pitch': body.angular_velocity.get('pitch', 0.0),
    'roll': body.angular_velocity.get('roll', 0.0)
}

# Cupula高通滤波（τ≈4s）
for axis in ['yaw', 'pitch', 'roll']:
    raw = angular_velocity[axis]
    filtered = ALPHA * (raw - self._prev_angular[axis]) + ALPHA * self._prev_filtered[axis]
    self._prev_angular[axis] = raw
    self._prev_filtered[axis] = filtered
    
    # 写入mechanical_inputs（保留正负号）
    self.mechanical_inputs[axis] = filtered * ANGULAR_GAIN
```

### 3.2 增益标定

耳石器物理量纲为加速度$[m/s^2]$（或归一化重力$g$），半规管物理量纲为角速度$[rad/s]$。两者映射到同等神经电导增益的物理桥梁是生物体的**特征转动半径$R_{body}$**（质心到感官端点的距离）：

$$
\text{ANGULAR\_GAIN} \approx \frac{a_{max}}{\omega_{max} \cdot R_{body}}
$$

**示例**：若物理世界典型平移加速度饱和值为$1.0$，转向最大角速度为$2.0\ \text{rad/s}$，转动等效半径$R_{body}=0.5$，则`ANGULAR_GAIN≈1.0`。

**动态校准建议**：在阶段1短程实验中，同时打印耳石信号幅值和半规管信号幅值的滑动均值/峰值，调整`ANGULAR_GAIN`使两者在`mechanical_inputs`层级具有相似的动态范围。


## 四、废除融合层，让STDP自组织互补滤波

### 4.1 原设计（已废除）

原3.3节提议在Python层通过`freq`计算Sigmoid权重，混合耳石和半规管的幅值信号。该设计存在致命缺陷：

| 问题 | 严重程度 | 说明 |
| :--- | :--- | :--- |
| **方向坍缩** | ⚠️ 致命 | `(x²+y²+z²)^0.5`取模运算**摧毁了三维向量的方向性**—左转/右转的符号信息被抹除，Col层无法判断转向方向 |
| **上帝视角** | ⚠️ 致命 | 系统在实时ODE循环中**无法获知当前运动的“频率”**。计算freq需要FFT或过零点检测—底层神经元做不到 |
| **时机错配** | ⚠️ 严重 | 半规管信号已是高通滤波（高频可靠），耳石信号是全通/低通（低频可靠）。两者的融合**应在突触层面涌现**，而非Python硬编码 |

### 4.2 修正方案：纯净信号注入 + STDP自组织融合

**绝对禁止**在Python层对半规管和耳石信号进行任何形式的加权融合或取模。正确的做法是：

1. **将3路带符号的半规管信号（yaw/pitch/roll）** 直接注入`MET_yaw/pitch/roll`
2. **将3路带符号的耳石信号（oto_x/y/z）** 直接注入`MET_oto_x/y/z`
3. **让STDP在Col层完成互补滤波**：

面对高频震荡时，耳石噪声被STDP的LTD削弱，半规管的权重被LTP加强。系统不需要显式的融合算法——**STDP自己就是那个完美的互补滤波器**。

**这一设计的生物学验证**：前庭核神经元接收来自半规管和耳石的双重投射，其融合权重在发育早期通过活动依赖机制建立。半规管通路中的突触是结构预设的（`plasticity=False`），但耳石→前庭核的突触权重由STDP调制，使系统在经验中自发建立动态权重平衡。


## 五、结构预设 vs 可塑性的边界

半规管通路中的所有突触**不参与STDP学习**：

| 突触 | 是否可塑 | 理由 |
| :--- | :--- | :--- |
| 毛细胞→传入纤维 | ❌ 不可塑 | 物理换能，固定增益 |
| 传入纤维→前庭核 | ❌ 不可塑 | 硬连线中继，结构预设 |
| 前庭核→Col | ❌ 不可塑 | 方向感知骨架 |
| **Col→Motor** | ✅ **可塑** | **耦合学习——选择哪个预设方向** |

**生物学基础**：前庭眼反射（VOR）和前庭脊髓反射（VSR）的底层坐标映射在动物出生前就已由基因硬连线焊死。系统不需要通过STDP去学习“什么是左转”，它只需要在Col→Motor层通过DA门控去学习“何时选择哪个预设方向”。

### 阶段1：通路激活验证（2h + 15min运行）

- 短程实验（50k步），旋转body
- 验证yaw/pitch/roll通路激活
- **验收断言1**：旋转时，对应传入纤维发放率升至基线+3σ
- **验收断言2**：旋转突然停止（$\omega \to 0$）时，由于内淋巴惯性反冲，传入纤维发放率应出现瞬态“低于基线”的负向峰值（Hyperpolarization/Undershoot）

### 阶段2：结构预设锁定（1h）

- 确认半规管通路突触`plasticity=False`
- 确认Col→Motor通路`plasticity=True`
- **验收**：方向感知不依赖STDP，结构即“发育”就位

### 阶段3：前庭消融实验重做（1h + 4×15min运行）

- 四组实验（对照组 + 3组消融）
- **验收**：全前庭消融后DR5≈50%（随机基线），证明方向性行为依赖前庭输入

### 阶段4：200k长程验证（2h运行）

- 验证三维热趋向能力涌现
- 验收：DR5>60%，轨迹平滑度优于半规管补全前
