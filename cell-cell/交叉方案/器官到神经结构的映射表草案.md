# 器官到神经结构的映射表草案

## —— 物理几何 → 神经结构 → 学习链路的可计算映射

**日期**：2026-07-03
**范围**：前庭（Vestibular）、皮肤（Somatosensory）、口器（Thermal Mouth）
**目标**：为规模泛化和物理落地提供从几何到神经结构的映射规范


## 一、框架说明

### 1.1 核心原则

每个感觉器官的物理属性（体积、面积、换能面密度）决定其神经结构的规模（神经元数量、连接数、学习带宽）。这个映射通过运动势时空测度（ν）和TSI功率账本进行量纲验证。

### 1.2 统一量纲（DIMENSIONAL_CONTRACT）

所有物理量必须可转换为功率（W），才能进入TSI/ν框架审计：

| 物理量 | 转换方式 | 结果量纲 |
| :--- | :--- | :--- |
| 面积 A | 热通量 = κ·A·ΔT/d | W |
| 体积 V | 代谢率 = ρ_metabolic·V | W |
| 换能面密度 ρ_sensor | N_sensor = ρ_sensor·A | 无量纲（计数）|
| 神经元密度 ρ_neuron | N_neuron = ρ_neuron·V | 无量纲（计数）|

### 3.4 V2.0皮肤重建关键变化

| 变化 | 物理基础 | 对学习的影响 |
| :--- | :--- | :--- |
| 点采样 → 面片积分 | 贴片面积A_patch计算热通量 | 更真实的温度信号，减少采样噪声 |
| 无热容 → 热容C = ρ·c·V | 体积 = A·d_skin | 热信号有惯性，防止瞬时跳跃 |
| 无噪声 → Langevin噪声 | 涨落-耗散定理 | 合法热噪声，TSI账本可审计 |
| 直接注入 → 换能束（可塑）| 温度→神经信号的STDP学习 | 贴片-运动的映射可学习 |
