# 感温链路局部—耦合生成元 最终整合实施方案

## 一、理论→代码 符号映射表

| 理论符号 | 理论含义 | 代码实体 | 物理实现方式 |
| :--- | :--- | :--- | :--- |
| `ξ_i` | 第 i 个局部生成元（局部耗散事件） | `LocalThermalCollector[i]` 的 **膜电位 Vm**（连续模拟量） | `ThermalDeltaNeuron(±dT)` → 10阶梯温度计 → Collector |
| `W` | 耗散结构自身的固定耦合矩阵 | **冻结束的 `initial_weight` 数组** | 构造期根据球面坐标预先计算，`frozen=True`，不学习 |
| `Ω_dir` | 方向性耦合生成元（角向梯度） | `DirectionalRFCollector[dir]` 的 **膜电位 Vm** | 64个 ξ 源 → 按余弦衰减汇聚 → 10阶梯 → Collector |
| `Ω_div` | 中心-周围耦合生成元（散度/尖锐度） | `DivergenceRFCollector` 的 **膜电位 Vm** | 64个 ξ 源 → 兴奋路径(均匀) + 抑制路径(反相) → 10阶梯 → Collector |

**关键声明**：ξ 和 Ω 的输出都是 **Collector 的模拟膜电位（Vm）**，而非离散 spike 计数。这使它们作为连续强度信号接入后续组织生成元，保留了完整的幅度信息。

### 3.1 局部生成元 ξ 参数

| 参数 | 符号 | 值 | 备注 |
| :--- | :--- | :--- | :--- |
| 球面采样点数 | `N_LOCAL` | 32 | Fibonacci sphere 生成 |
| 球体半径 | `R` | 2.0 | 与 `_default_skin_patches` 一致 |
| 温度变化率增益 | `DT_GAIN` | **200.0** | 复用 `NOCI_DT_GAIN`，锚定 `ThermalDeltaNeuron` 输出量级 ~0.05 |
| 阶梯偏置步长 | `_Q_BIAS_STEP` | **-0.30** | 针对 ThermalDeltaNeuron 峰值(~0.05) 校准：0.05×6≈0.3，覆盖 k=0~9 |
| 输入权重 | `_Q_INPUT_W0` | **6.0** | 确保峰值(0.05)能激活 k=9：6.0×0.05−1.2 = 0.18 > 0 |
| Collector 阈值 | `_Q_COLLECT_THR` | 0.78 | 软 AND，10路×0.1 = 1.0 > 0.78 |
| Collector tau_gate | `_Q_COLLECT_TAU_GATE` | 3.0 | 粘合异步脉冲 |

> **校准逻辑**：`ThermalDeltaNeuron` 在 dT=0.001/step 时 activation ≈ 0.05×200 = 0.05（实际峰值）。取 `_Q_BIAS_STEP = -0.30`，k=9 偏置 -3.0。`W0=6.0` 时，k=9 有效电流 = 6.0×0.05 - 3.0 = -2.7（按理不该激活），所以需要重新算。**等一下，这里搞反了**。偏置是加到输入上的，`I_eff = I_in + bc`。k=9 的 `bc = -0.30×10 = -3.0`，太负了，根本激活不了。正确的校准应该是 `bc_k9 = -W0 × peak_activation`。如果 `peak_activation=0.05`，`W0` 要大到能让 k=9 过阈。让我们回到保守值：`_Q_BIAS_STEP = -0.12`，`_Q_INPUT_W0 = 3.8`（与前庭相同），然后通过 `DT_GAIN` 来调节 `ThermalDeltaNeuron` 输出。我们把 `DT_GAIN` 从 200 调高到 **800**，使得 dT=0.001/step 时 activation ≈ 0.8。这样 0.8×3.8 - 1.2 = 1.84，k=9 能激活。这个方法更干净，因为 `DT_GAIN` 本身就在 `transducer_neurons.py` 里是硬编码常数，改它不引入新参数逻辑。

| 参数 | 符号 | 最终值 | 备注 |
| :--- | :--- | :--- | :--- |
| 温度变化率增益 | `DT_GAIN` | **800.0** | 在 `transducer_neurons.py` 中改为 800.0（原 200.0） |
| 输入权重 | `_Q_INPUT_W0` | **3.8** | 复用前庭校准值，保持统一 |
| 阶梯偏置步长 | `_Q_BIAS_STEP` | **-0.12** | 复用前庭值，k=9 偏置 -1.2 |
| 峰值 dT（实验场景）| `dT_peak` | 0.001 / step | 对应 activation≈0.8，k=9 有效电流 1.84，全激活 |

### 4.1 新文件：`nexus_v1/components/skin_network.py`

```python
import math
from typing import List, Tuple

def fibonacci_sphere_points(n: int, radius: float) -> List[Tuple[float, float, float]]:
    """TYPE:MATH 球面近均匀点分布，黄金角螺旋法"""
    points = []
    golden_angle = math.pi * (3.0 - math.sqrt(5.0))
    for i in range(n):
        z = 1.0 - 2.0 * (i + 0.5) / n
        r_xy = math.sqrt(max(0.0, 1.0 - z * z))
        theta = i * golden_angle
        points.append((
            radius * r_xy * math.cos(theta),
            radius * r_xy * math.sin(theta),
            radius * z
        ))
    return points

def compute_coupling_weights(
    local_positions: List[Tuple[float, float, float]],
    rf_directions: List[Tuple[float, float, float]],
    sharpness: float = 2.0,
    base_weight: float = 0.5,
) -> List[List[float]]:
    """
    TYPE:MATH 构造期计算耦合矩阵 W
    返回：M（RF个数）× N（局部点数）的权重矩阵
    权重 = base_weight * max(0, cosθ)^sharpness
    """
    weights = []
    for d in rf_directions:
        row = []
        for p in local_positions:
            # 归一化点积（局部点已在球面上，|p|=R，|d|=1）
            cos_theta = (p[0]*d[0] + p[1]*d[1] + p[2]*d[2]) / 2.0  # 因为 |p|=2.0, |d|=1
            # 钳制到 [0, 1]
            cos_theta = max(0.0, min(1.0, cos_theta))
            row.append(base_weight * (cos_theta ** sharpness))
        weights.append(row)
    return weights
```

def _init_quantum_thermal_pathways(self):
    from ..components.skin_network import fibonacci_sphere_points, compute_coupling_weights
    from ..somatosensory.transducer_neurons import ThermalDeltaNeuron
    from ..world import SkinPatch  # 假设 SkinPatch 可独立实例化

    # 1. 生成 32 个球面点
    positions = fibonacci_sphere_points(_THERM_LOCAL_N, _THERM_LOCAL_R)

    # 2. 为每个点创建局部生成元 ξ
    for i, pos in enumerate(positions):
        pid = f"local_{i}"
        # SkinPatch（隔离，不挂 body）
        patch = SkinPatch()  # 需要验证构造签名
        self.local_patches.append(patch)

        # warm 通道
        warm_neuron = ThermalDeltaNeuron(neuron_id=f"therm_warm_{i}", position=pos)
        warm_ensemble = [Neuron(_quantum_ensemble_config(f"therm_warm_{i}_{k}", k, region=REGION_SPINAL, position=pos)) for k in range(10)]
        warm_collector = Neuron(_quantum_collector_config(f"therm_warm_{i}", region=REGION_SPINAL, position=pos, threshold=_THERM_Q_COLLECT_THR, tau_gate=_THERM_Q_COLLECT_TAU_GATE))
        # 束：warm_neuron → warm_ensemble
        self.bundles_local_input.append(SynapticBundle(
            BundleConfig(bundle_id=f"therm_warm_in_{i}", learning_rule="frozen", initial_weight=_THERM_Q_INPUT_W0, synapse_gain=1.0),
            [warm_neuron], warm_ensemble
        ))
        # 束：warm_ensemble → warm_collector
        self.bundles_local_collect.append(SynapticBundle(
            BundleConfig(bundle_id=f"therm_warm_col_{i}", learning_rule="frozen", initial_weight=_THERM_Q_COLLECT_W0, synapse_gain=1.0),
            warm_ensemble, [warm_collector]
        ))

        self.local_ensembles[f"{pid}_warm"] = warm_ensemble
        self.local_collectors[f"{pid}_warm"] = warm_collector

        # cool 通道（完全相同，喂 -dT）
        cool_neuron = ThermalDeltaNeuron(neuron_id=f"therm_cool_{i}", position=pos)
        # ... 重复上述逻辑，neuron_id 替换为 cool ...

    # 3. 收集所有局部 Collector 作为 ξ 源（64 个）
    xi_sources = list(self.local_collectors.values())  # 64 个 Collector 神经元（其 Vm 作为 ξ）

    # 4. 创建 6 个方向性耦合生成元 Ω_dir
    rf_weights = compute_coupling_weights(positions, _RF_DIRECTIONS, _RF_SHARPNESS_P, _RF_BASE_WEIGHT)

        # 10 阶梯神经元（偏置可略高，如 -0.15）

        rf_collector = Neuron(_quantum_collector_config(dir_name, region=REGION_SPINAL, position=dir_vec, threshold=_RF_COLLECT_THR, tau_gate=3.0))
        # 冻结束：64 个 ξ 源 → 10 个阶梯神经元，权重 = rf_weights[d_idx]
        for k in range(10):

            cfg = BundleConfig(
                bundle_id=f"rf_{dir_name}_to_{k}",
                learning_rule="frozen",
                initial_weight=rf_weights[d_idx][k] if k < len(rf_weights[d_idx]) else 0.0,
                # 实际上，我们需要为每个目标神经元独立设置权重，但 SynapticBundle 的 initial_weight 是标量
                # 解决方案：为每个目标神经元建一条束，汇聚所有源

## 五、验证协议（新增专项探针）

| 探针 ID | 验证内容 | 输入条件 | 通过标准 |
| :--- | :--- | :--- | :--- |
| `T-QT1` | 局部整流正确性 | 热源接近局部点（正 dT） | warm Collector Vm > 0.1，cool Collector Vm ≈ 0 |
| `T-QT2` | 温度计单调性 | dT 幅度递增（0.0001→0.001） | 激活的阶梯神经元数量单调递增 |
| `T-QT3` | 方向性 RF 空间偏好 | 热源置于 +X 方向 | `RF_{+X}` Collector Vm > `RF_{-X}` Collector Vm |
| `T-QT4` | 散度 RF 响应 | 单个点热源（模拟激光）vs 全局均匀热源 | 单点热源时 Div Vm 激增，均匀热源时 Div Vm 接近 0 |
| `T-QT5` | 耦合权重连续性 | 热源从 +X 缓慢旋转到 -X | 6 个方向性 RF 的 Vm 随角度连续变化（余弦²曲线） |
| `T-QT6` | census 隔离 | 调用 `get_all_neurons()` | 温感量子元不在列表中 |
