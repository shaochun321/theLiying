## 一、整体框架评估

### 1.1 框架本身是成立的

原始映射表草案提出的核心原则是成立的：

> **物理几何决定神经容量**——器官的面积、体积、换能面密度决定神经元数量、连接数、学习带宽。

这一原则与以下理论框架一致：
- **建构定律（Constructal Law）**：系统演化遵循“最大化能量效率”原则，结构规模由物理约束决定
- **TSI 账本**：所有物理量最终转换为功率（W），纳入统一审计
- **涨落-耗散定理**：探测器面积越小，热噪声越大，需要更多神经元做群体编码

三个器官的映射框架（前庭、皮肤、口器）在结构上是完整的，量纲转换链是闭合的。

### 1.2 该框架的战略意义

## 三、关键设计决策——确认与修正

### 3.1 SkinPatch 时间常数修正

**原始草案**：τ=5ms → 5s（约 5000 步）

**外部反馈确认**：正确。生物组织热扩散率约 0.14 mm²/s，穿透 1mm 皮肤需数秒。

**补充评估**：
- 这会给贴片温度引入严重的热滞后（Phase Lag）
- 这恰好证明了 Noci（dT/dt 通道）的绝对必要性
- 热滞后还会改变 ν 探针的读数基线，体感重构完成后需重新校准

**执行建议**：在 `SkinPatch` 类中将 τ 从 5ms 拉长至 5s，作为体感重构的第一刀。

### 3.2 贴片面积引入 Langevin 噪声

**原始草案**：σ² ∝ 1/A（涨落-耗散定理）

**外部反馈确认**：正确。这是项目从“数学点采样”走向“物理热力学节点”的标志性改动。

**工程警告（外部反馈）**：
- **错误写法**：`noise_term = random.gauss(0, sigma) * dt`
- **正确写法**：`noise_term = random.gauss(0, sigma) * math.sqrt(dt)`

**执行建议**：在 P1 阶段（添加 Langevin 热噪声）时，使用 `sqrt(dt)` 离散化。这是非协商的物理要求。

### 3.3 BodySurface 网格设计

**原始草案**：12 贴片（3环×4点）

**评估**：合理的空间采样率。贴片数从 4→12 是规模泛化的预演，可验证地址系统、面积映射和 Noether 审计的承载能力。

**外部反馈中未涉及的部分**：12 贴片的物理面积分配。建议在 BodySurface 网格设计时明确每个贴片的面积（由网格几何计算），而非均匀分配。


## 四、三大工程风险预警

### 4.1 风险一：SkinPatch τ=5s 带来的热滞后

| 维度 | 说明 |
| :--- | :--- |
| 现象 | 皮肤绝对温度（DC 通道）在快速运动时严重滞后 |
| 后果 | 仅靠 thermoreceptor 绝对温度驱动会导致响应不及时 |
| 必然解 | Noci（dT/dt 通道）将接管高速运动下的求生导向权 |
| 验证方法 | 体感重构后跑短程测试，观察 noci 是否在热前锋出现时抢先激活 |

### 4.2 风险二：SDE 离散化错误（外部反馈指出）

| 维度 | 说明 |
| :--- | :--- |
| 现象 | Langevin 噪声项用 `dt` 而非 `sqrt(dt)` 离散化 |
| 后果 | 噪声能量与仿真步长错误耦合，TSI 账本出现数量级畸变 |
| 约束 | 非协商——必须使用 `sqrt(dt)` |
| 验证方法 | Noether 探针审计能量守恒，确认噪声功率在理论范围内 |

### 4.3 风险三：密度数据内部矛盾

| 参数 | 矛盾 | 处理方式 |
| :--- | :--- | :--- |
| ρ_hc | 60,000-100,000 vs 20,000 个/mm² | 采用 20,000 作为保守值，标注范围 |
| ρ_noci | 100-200 vs 5-10 个/mm² | 标记为“待确认”，当前体感重构不依赖此参数 |

这些矛盾不影响体感重构的当前实施（12贴片仍然是抽象节点），但在进入规模泛化 Phase B 前需要解决。
