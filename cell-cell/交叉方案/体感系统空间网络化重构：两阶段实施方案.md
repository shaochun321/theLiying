### 详细设计

**P2-1：BodySurface网格**

```python
class BodySurface:
    def __init__(self, geometry="sphere", radius=20.0):
        # 12贴片：3环×4点
        self.patches = []
        for ring in [15, 0, -15]:  # z位置
            r = 15 if ring != 0 else 20
            for angle in [0, 90, 180, 270]:  # 前/右/后/左
                x = r * cos(angle)
                y = r * sin(angle)
                z = ring
                # 每个贴片自动计算面积、法线
                patch = Patch(center=(x,y,z), mesh_faces=[...])
                self.patches.append(patch)
    
    def compute_patch_geometry(self, patch_id):
        # 面积：由网格面片计算
        area = sum(face.area for face in patch.faces)
        # 体积：面积 × 皮肤厚度
        volume = area * SKIN_DEPTH
        # 热容：体积 × 密度 × 比热容
        C = volume * SKIN_DENSITY * SKIN_SPECIFIC_HEAT
        return area, volume, C
```

| :--- | :--- |
| τ=5s导致thermo响应滞后过长 | Noci（dT/dt）通道接管高速响应；若滞后影响行为，可微调τ（如3s）但保持秒级 |

| BodySurface网格实现复杂度超预期 | 先实现球面网格，后续可迭代升级为椭球 |
| 换能束×12+痛觉束×24导致节点数剧增 | 节点预算当前~97，扩展后约133，需确认仍≤0.8×P_input |
