# 规模泛化补充文档

**日期**：2026-07-01  
**关联方案**：前庭空间网络化重构方案 V2.0（最终版）  
**定位**：当前重构（V2.0，N=1）完成后的下一阶段蓝图  
**性质**：前瞻性设计文档，非当前执行计划


## 一、背景与动机

当前重构方案（V2.0）将前庭内部链路网络化为可寻址节点，地址系统使用 `(region, layer, τ_class, axis, index)` 标识每个实例。其中 `index` 字段已纯化为并发实例计数（0…N-1），为规模泛化预留了入口。

但规模泛化不仅仅是“增加 index”，它涉及三个根本性变革：

| 维度 | N=1（当前）| N=100（目标）| 变革 |
| :--- | :--- | :--- | :--- |
| 信噪比 SNR | 1 | 10（√100）| 群体编码降噪 |
| 信道容量 C | ≈B | ≈3.46B | 突破香农极限 |
| 死区 | 存在（amp<3.5）| 取消 | 恢复全频段带宽 |
| 增益代偿 | 33× | 1×（物理常数）| 去除人工补偿 |
| 动态范围 | 窄（阈值单一）| 宽（阈值多样性）| 多神经元接力 |
| 能量消耗 | 基准 | P_T↑100×，P_S↑10000× | 热力学约束 |

## 三、触发条件矩阵

规模泛化不是“节点预算足够就执行”，而是需要同时满足以下条件：

| 条件 | 量化阈值 | 状态 | 说明 |
| :--- | :--- | :--- | :--- |
| **节点预算** | 总节点数 > 50 | 当前≤50 | 硬性前置条件 |
| **热力学许可** | $P_{estimated}(N) \le P_{input\_max} \times 0.8$ | 待测量 | 新增条件，见§六 |
| **能量效率验证** | $\frac{C(N)}{P(N)} > \frac{C(1)}{P(1)}$ | 待计算 | 建构定律约束，见§七 |
| **ν 判据混淆** | >30% in 50k 步 | ν 探针未实现 | 结构稳定性要求 |
| **新模态需求** | 需前庭参与整合 | 未提出 | 需求驱动 |
| **TSI fill 下降** | >20% in 200k 步 | 未监测 | 能量可持续性 |

**执行原则**：所有条件满足时，才可触发 N 扩展。

## 五、阈值多样性实施方案（Phase B 引入）

当从 N=1 扩展到 N=3 时，不复制完全一样的克隆体。生物前庭的传入纤维拥有不同的激活阈值。

### 5.1 阈值分配公式

对于 N 个实例，将 `v_threshold` 围绕基准值 $V_{base}$ 按比例分布：

```
V_k = V_base × (1 + γ × (k - (N-1)/2) / ((N-1)/2))

其中 γ = 0.4（分布在 ±40% 范围）
```

对于 N=3：
```
index=0：V = V_base × 0.8（低阈值，敏感）
index=1：V = V_base × 1.0（中阈值，参考）
index=2：V = V_base × 1.2（高阈值，抗饱和）
```

### 5.2 物理效果

| 阈值类型 | 作用 | 生物学对应 |
| :--- | :--- | :--- |
| 低阈值（敏感）| 保证小信号不漏检 | 高增益传入纤维 |
| 中阈值（平衡）| 正常范围编码 | 常规传入纤维 |
| 高阈值（抗饱和）| 保证大信号不丢失 | 低增益传入纤维 |

**系统级效果**：低阈值保证死区被填充（灵敏度↑），高阈值保证高端不饱和（动态范围↑）。若 N=1 时死区从 3.5 开始，N=3 时低阈值实例可在 2.0 开始响应，有效扩展了低端响应范围。


## 六、热力学许可的计算方法（Phase B 前置检查）

扩展前必须证明系统能量预算足以支撑新结构。

### 6.1 P_T 估算

```
P_T(N) = N × (P_leak + P_spike)
```

其中：
- $P_{leak}$：单神经元漏电流耗能（MET/HC 焦耳热，Aff/Enc/Col 发放能耗）
- $P_{spike}$：单神经元发放能耗

**实测值**（基于 P0 数据）：
- 当前 N=1 的 P_T ≈ 基准值（待 Phase A 完成后精确测量）

### 6.2 P_S 估算

```
P_S(N) = N² × P_connection
```

其中 $P_{connection}$ 为单条突触的维持税。由于 Aff→Enc 收敛比为 N，连接数从 1 增长到 N²。

### 6.3 许可判定

```
if P_T(N) + P_S(N) ≤ P_input_max × 0.8:
    PASS（热力学许可）
else:
    FAIL（禁止扩展）
```

**示例**（假设值）：
- $P_{input\_max} = 50$ fill/step
- 当前 N=1：P_T + P_S ≈ 1
- N=3：P_T × 3 + P_S × 9 ≈ 9 + 9 = 18 ≤ 40 → **PASS**
- N=10：P_T × 10 + P_S × 100 ≈ 10 + 100 = 110 > 40 → **FAIL**


## 七、建构定律停靠点判定（Phase B/C/D 执行前）

建构定律（Constructal Law）规定：系统演化遵循“最大化能量效率”原则。只有在扩展后能量效率提升时，扩展才被批准。

### 7.1 能量效率指标

```
效率 η(N) = 信道容量 C(N) / 总功率 P(N)

其中：
  C(N) = B × log₂(1 + √N)   （香农容量）
  P(N) = P_T(N) + P_S(N)     （总功率）
```

### 7.2 扩展判定

```
if η(N_new) > η(N_current):
    PASS（扩展提升效率）
else:
    FAIL（停在当前 N，不扩展）
```

**物理意义**：
- 如果 N=3 的 η 高于 N=1，系统趋向 N=3（能量效率提升）
- 如果 N=10 的 η 低于 N=3，系统停在 N=3（能量效率下降，扩展得不偿失）

**自然结果**：系统在能量效率最优的 N 处自然停止，而非强行扩展到 100。
