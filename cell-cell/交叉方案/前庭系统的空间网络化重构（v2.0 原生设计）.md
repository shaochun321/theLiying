# 方案：前庭系统的空间网络化重构（v2.0 原生设计）

## 一、核心理念：从“6轴平行线”到“拓扑传感器阵列”

| v1.0 旧结构 | v2.0 空间网络化结构 |
| :--- | :--- |
| 6个独立轴，硬编码索引 0-5 | 6个传感器地址 $\{a_{vest, i}\}_{i=1}^6$，统一归入“感觉入口区” |
| MET→HC→Aff 逐层直连，延迟忽略 | 每层传递附带 **拓扑距离 $L$** + **FIFO 传导延迟** |
| HC→Aff 的 PowerRail 硬截断（$1 - I \cdot r_{supply} < 0 \Rightarrow 0$） | 替换为 **TSI 软饱和**：$I_{out} = I_{in} / (1 + I_{in} \cdot r_{supply})$，纳入 $P_T$ 审计 |
| Aff→Enc 标定裕量 3%（2 Hz 无法激活） | 通过 **地址相关的自适应阈值** $\Theta_{enc}(a_i)$ 解决，阈值与局部能量预算挂钩 |
| oto 轴仅依赖弱跨轴束（0.15权重） | oto 轴获得与角速度轴**等价的拓扑投影机会**，通过 STDP 竞争性学习平移运动映射 |

## 二、前庭在统一拓扑地址空间中的定位

根据合取报告中的“五脑区分配”，前庭子网横跨 **脊髓区（硬连线）** 和 **主层 L3-L5（可塑层）**。

我们为前庭神经元分配连续的地址段：

```python
# 地址定义（伪代码）
class VestibularAddress:
    # 感觉入口层（MET/HC/Aff）—— 地址锚定在“脑干前庭核团”区域
    REGION_BRAINSTEM = 0x02
    
    # 主层感知区（Enc/Col）—— 地址锚定在“主层感觉皮层”区域
    REGION_MAINLAYER = 0x04
    
    # 地址生成：a_i = (region << 16) | (layer << 8) | index
    # 例如：MET_yaw 地址 = (0x02 << 16) | (0x01 << 8) | 0x00
```

**关键设计**：6个轴的地址在拓扑距离矩阵 $D_{ij}$ 中**彼此相邻**（间距=1），而与热觉/体感地址相距较远（间距=10）。这保证了：
- 前庭内部连接成本低，容易形成密集短程连接（解决 `hc_to_aff` frozen 无法通过 STDP 增强的问题——虽然它仍是 frozen，但短距离降低了维持税）。
- 前庭到热觉的跨模态连接成本高，不会被随意 sprout，符合生物学的“多感觉整合延迟”。

## 三、逐层重构方案（含审计问题修复）

### 3.1 L1 MET → L2 HC：保留 frozen，但增加“软饱和”

**修改位置**：`vestibular/chain.py` 中的电流传导函数

**原代码问题**（审计 §4.1）：
```python
# 硬截断（v1.0）
scaled = W * act * gain / inertia
if scaled * r_supply > 1.0: 
    return 0.0  # 这是纯工程错误！
```

**v2.0 软饱和修复（纳入 TSI）**：
```python
def conduct_with_soft_saturation(I_in, r_supply):
    # I_in 是突触前电流
    # 输出永远 > 0，且渐近趋向 1/r_supply
    return I_in / (1.0 + I_in * r_supply)
```
**数理逻辑**：当 `I_in` 极大时，输出逼近 `1/r_supply = 20`（若 r_supply=0.05），而不是硬生生归零。这保证了强刺激下 Aff 仍能发放，同时 `P_T = I_out^2 * R_leak` 自动限制了功率爆炸（因为 $I_{out}$ 有上界）。

### 3.2 L2 HC → L3 Aff：标定解耦（修复 3% 裕量）

**核心修复**：不再依赖全局 `synapse_gain = 2.0` 来同时服务热觉和前庭。  
我们在 v2.0 的 `SynapticBundle` 初始化时，为 **前庭专用束** 传入独立的 `gain` 参数。

**新设计**：
- `synapse_gain` 保持 2.0（保护热觉回归测试）。
- 前庭 L3→L4 束的 **`effective_gain`** 通过地址查找表动态计算：
  
$$
G_{eff}(a_{Aff}, a_{Enc}) = G_0 \times \left( 1 + \alpha \cdot \frac{P_{available}}{P_{baseline}} \right)
$$

  其中 $P_{available}$ 是当前能量池余量。**当能量充足时，增益自动提高**，弥补物理驱动不足（2 Hz）；**当能量紧张时，增益降低**，防止 Enc 过度饱和浪费功率。这彻底消灭了“固定裕量3%”的静态缺陷。

### 3.3 L3 Aff → L4 Enc：引入传导延迟 FIFO（空间化核心）

在 v1.0 中，信号瞬间传递。在 v2.0 中，我们根据地址距离 $L(a_{Aff}, a_{Enc})$ 计算延迟步数：

```python
delay_steps = ceil(L / (v_cond * dt))
# 假设 v_cond=1.0, dt=0.001，L=3（脑干到主层的拓扑距离）
# delay_steps = 3000 步（3秒传导延迟，符合生物前庭眼动反射约 5-10ms，此处为模拟缩放）
```

**实现**：每个前庭 `Enc` 神经元维护一个 `FIFOQueue`，Aff 的尖峰先存入队列，延迟结束后再注入 Enc 的突触后电流。这使前庭信号具备“时空特征”，影子层未来可以学习到运动预测（例如：听到声音→预期前庭刺激）。

### 3.4 L4 Enc → L5 Col：oto_x/y/z 获得平等拓扑权

**原问题**（审计 §5-C）：oto 轴只有弱 cross bundle（W_max=0.15），而角速度轴有强拓扑束（W=0.4）。

**v2.0 解决**：取消“强拓扑 vs 弱跨轴”的硬编码区分。在初始化 50 节点拓扑时，**所有 6 个前庭轴**的 Col 节点都有同等概率连接到 Motor 的不同功能簇：

- Col\_angular (yaw/pitch/roll) → Motor\_rotation 簇（地址相邻）
- Col\_linear (oto_x/y/z) → Motor\_translation 簇（地址相邻）

初始权重均为 0.25。系统依靠 **STDP + 物理环境反馈**（Langevin 噪声驱动的平移运动）让 oto 轴的权重自然生长或消退，而不是人为预设弱连接。这是真正的“空间网络化学习”。

### 3.5 TSI 功率账本中的前庭专项审计

在 `EnergyStore` 中，增加前庭子网的专项功率项：

$$
P_{Vestibular} = \sum_{aff \in L3} E_{spike} \cdot f_{aff} + \kappa_{vest} \cdot \sum_{syn \in V} L(a_i, a_j) \cdot w_{ij}
$$

这确保了长程前庭连接（如 oto→Motor_translation）缴纳更高的结构税，迫使系统在能量紧张时优先修剪无用连接，保留高效通路。

## 四、新信号流与延迟链路（全景图）

```
物理运动 (加速度/角速度)
    ↓ [无延迟]
[L1] MET (地址: BR_01~06)
    ↓ 软饱和 + FIFO 延迟 50步
[L2] HC (地址: BR_07~12)
    ↓ frozen 束 + FIFO 延迟 100步
[L3] Aff_reg/irr (地址: BR_13~24)  → 发放率 2~10 Hz
    ↓ 能量门控增益 G_eff(P_avail) + FIFO 延迟 3000步
[L4] Enc (地址: ML_01~12)  → 激活值 0.1~0.8（不再静默）
    ↓ STDP 可塑束 + FIFO 延迟 500步
[L5] Col (地址: ML_13~24)  → 侧抑制 + 竞争
    ↓ 拓扑分簇束（角速度→旋转簇，线速度→平移簇）
[L6] Motor (地址: ML_25~32)  → 速度输出
```

## 五、与“最小底盘（50节点）”的集成接口

当你在 Phase 5 构建 50 节点底盘时，前庭将作为**第一个“全栈可塑传感器子网”**嵌入系统，提供标准化的接入范式：

| 脑区 | 为前庭预留节点数 | 节点地址段 |
| :--- | :--- | :--- |
| 脑干（节律+前庭核） | 14 个（MET×6 + HC×6 + 2个调节 interneuron） | `0x02_01_00` ~ `0x02_01_0D` |
| 主层 L4（前庭编码） | 8 个（6轴 + 2个多模态整合） | `0x04_04_00` ~ `0x04_04_07` |
| 主层 L5（前庭柱） | 8 个（同上） | `0x04_05_00` ~ `0x04_05_07` |
| 主层 L6（运动输出-旋转/平移） | 6 个（混合前庭/热觉输出） | `0x04_06_00` ~ `0x04_06_05` |

**迁移路径**：你不需要把旧的 `VestibularChain.py` 塞进新架构。我们将它**拆解**：
1. 神经元动力学（`MET/HC/Aff` 的 `step()`）保留，但移植到新的 `Neuron` 基类。
2. 连接逻辑（Bundle）替换为基于 `Address` 的通用 `SynapticBundle`。
3. 延迟和软饱和逻辑封装在 `FIFODelayBuffer` 和 `SoftSaturator` 工具类中，供所有感觉模态复用。
