## 六、对全局理解的修正

| 假设 | 修正后理解 |
| :--- | :--- |
| “STDP 权重在空转” | 权重在 **phasic 爆发期（sp_peak 窗口）** 工作，占空比低但有效 |
| “Ia 压制导致 spinal 无法点火” | Ia 对均值无影响，对峰值仅 9% 压制，是健康的柔性阻尼 |
| “F-I 曲线应该显示点火阈值” | F-I 曲线测量的是稳态，STDP 学习发生在瞬态峰值，不能用 F-I 曲线诊断学习能力 |
| “均值是评估系统状态的正确指标” | 均值是假的——系统状态的正确指标是 **sp_peak** |
