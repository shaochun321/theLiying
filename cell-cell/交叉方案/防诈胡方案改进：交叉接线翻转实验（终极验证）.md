## 一、当前防诈胡验证的漏洞分析

### 1.1 已完成的验证

| 验证实验 | 结论 | 有效性 |
| :--- | :--- | :--- |
| **T-054**（冻结所有 STDP）| 硬连线组件（T-043 等）不产生方向 | ✅ 有效——证明无 STDP 时系统无法趋热 |
| **T-061**（前庭消融）| 两组 DR5 均为 0%，统计学空洞 | ❌ 失效——基线本身无热趋性，消融无意义 |

### 1.2 真正的漏洞

T-054 证明了“无 STDP 不产生方向”，但**未排除以下可能性**：

> **STDP 只是在强化“拓扑上已有的不对称性”**——即 phasic_left → spinal_ccw 的初始权重略高，系统只是用 STDP 固定了这一个随机偏置，而非真正学习。

**关键问题**：如果初始拓扑存在微小的非对称偏置，STDP 可能只是将其放大并锁定。这仍属于“锁定偶然偏置”，而非“学习”。

**实验状态图**：

```
当前验证状态：
├── T-054（冻结STDP） ✅ 已通过 → 无STDP不产生方向
├── T-061（前庭消融） ❌ 失效 → 统计学空洞
└── 漏洞：STDP可能只是强化初始拓扑偏置，而非真正学习
```


## 二、改进方案：交叉接线翻转实验

### 2.1 实验原理

这是最严厉的诈胡测试——**强行扭转初始拓扑**，观察系统能否通过 STDP 逆转错误的接线。

如果系统只是“锁定初始偏置”，翻转接线后它会错误地远离热源且无法纠正。如果系统真正“学习”了热-运动映射，它应该能通过 STDP 逆转权重方向。

### 2.2 实验设计

| 配置 | 正常模式（对照组）| 翻转模式（实验组）|
| :--- | :--- | :--- |
| `phasic_left` → `spinal_ccw` | ✅ 正常（左转对应左热）| ❌ **翻转** → `spinal_cw` |
| `phasic_right` → `spinal_cw` | ✅ 正常（右转对应右热）| ❌ **翻转** → `spinal_ccw` |
| `phasic_left` → `spinal_cw` | 无连接 | ✅ **新增** → 权重初始 0.005 |
| `phasic_right` → `spinal_ccw` | 无连接 | ✅ **新增** → 权重初始 0.005 |
| STDP | 开启 | 开启 |
| 其他配置 | T-059 配置（gain_max=1.15，initial_weight=0.1）| 与对照组相同 |
| 步数 | 200k | 200k |

### 2.3 拓扑翻转的数理逻辑

在翻转模式下，初始运动-热映射关系被错误连接：

```
正常映射（正确）：
  phasic_left（左热） → 转向左（spinal_ccw）
  phasic_right（右热） → 转向右（spinal_cw）

翻转映射（错误）：
  phasic_left（左热） → 转向右（spinal_cw）← 错误的连接
  phasic_right（右热） → 转向左（spinal_ccw）← 错误的连接
```

如果系统只是“锁定初始偏置”，它将按错误方向远离热源：

```
左热更近 → phasic_left 激活 → 翻转到 spinal_cw → 向右转 → 远离左热 ❌
```

如果系统真正具备 STDP 学习能力，它应该逆转权重：

```
左热更近 → phasic_left 激活 → 翻转到 spinal_cw → 向右转（错误）
→ 远离热源 → 热量下降 → 预测误差增大 → STDP 削弱错误连接
→ 同时强化 phasic_left → spinal_ccw 的正确连接
→ 权重逆转 → body 转向正确方向 ✅
```

### 2.4 预期结果

| 结果 | DR5 | 权重方向 | 判定 |
| :--- | :--- | :--- | :--- |
| 系统转向热源，**权重逆转**（反转后的连接被削弱，正确连接被强化）| > 60% | 翻转束权重**下降**，正确束权重**上升** | ✅ **真正的学习涌现** |
| 系统因错误接线远离热源，无法纠正 | ≤ 55% | 翻转束权重维持高位 | ❌ **诈胡**——系统只是锁定初始偏置 |
| 系统卡在中间，无法决定 | ~50% | 两组权重均无法建立优势 | ⚠️ 部分学习，但速度不足 |

### 2.5 通过标准

| 指标 | 条件 |
| :--- | :--- |
| DR5% | > 60% |
| 权重逆转 | 翻转束（phasic_left→spinal_cw）的权重**低于**正确束（phasic_left→spinal_ccw）的权重 |
| 峰值分化 | 在 Foraging 窗口内，\|Δw\|_peak > 0.15 |
| 能量自持 | fill 最低 > 0.001，SDI > 80% |


## 三、执行配置

### 3.1 Bundle 配置

```python
# 对照组：正常映射
configs_normal = [
    BundleConfig(
        id="bundle_phasic_left_to_spinal_ccw",
        source=phasic_left, target=spinal_ccw,
        initial_weight=0.1, plasticity=True,
    ),
    BundleConfig(
        id="bundle_phasic_right_to_spinal_cw",
        source=phasic_right, target=spinal_cw,
        initial_weight=0.1, plasticity=True,
    ),
]

# 实验组：翻转映射
configs_swapped = [
    BundleConfig(
        id="bundle_phasic_left_to_spinal_cw_swapped",
        source=phasic_left, target=spinal_cw,  # ← 翻转
        initial_weight=0.005, plasticity=True,
    ),
    BundleConfig(
        id="bundle_phasic_right_to_spinal_ccw_swapped",
        source=phasic_right, target=spinal_ccw,  # ← 翻转
        initial_weight=0.005, plasticity=True,
    ),
    # 额外添加未翻转的连接，给系统一个“纠正”的路径
    BundleConfig(
        id="bundle_phasic_left_to_spinal_ccw_correct",
        source=phasic_left, target=spinal_ccw,
        initial_weight=0.005, plasticity=True,
    ),
    BundleConfig(
        id="bundle_phasic_right_to_spinal_cw_correct",
        source=phasic_right, target=spinal_cw,
        initial_weight=0.005, plasticity=True,
    ),
]
```

### 3.2 关键参数

| 参数 | 值 | 说明 |
| :--- | :--- | :--- |
| 翻转束 initial_weight | 0.005 | 极小初始值，必须通过学习才能驱动转向 |
| 正确束 initial_weight | 0.005 | 同样极小，给系统留出逆转空间 |
| 学习率 stdp_lr | 0.001 | 与 T-059 保持一致 |
| eligibility_ltd_rate | 0.02 | 与 T-059 保持一致 |
| gain_max | 1.15 | T-059 已验证有效 |
| w_max | 0.300 | 允许权重增长 60 倍（0.005→0.300）|

### 3.3 权重逆转的判定

**通过标准**：在 Foraging 窗口的最后 20%，满足：

$$
\frac{w_{correct}}{w_{swapped}} > 1.5
$$

物理含义：正确束的权重至少比翻转束高 50%，证明系统已通过 STDP 逆转了初始错误拓扑。

## 五、预期论证逻辑

### 5.1 如果实验 PASS（系统逆转权重，仍能趋热）

> **结论**：系统具备真正的因果学习能力——STDP 不是简单地锁定拓扑上已有的偏置，而是能根据环境反馈（phasic 信号 + DA 门控）重构运动-热映射。即使初始接线被强制错误，系统仍能通过突触可塑性逆转权重，找到正确的趋热方向。

### 5.2 如果实验 FAIL（系统无法纠正错误接线）

> **结论**：系统本质上是“锁定初始偏置”而非“学习”。STDP 只在初始拓扑方向正确时工作，无法覆盖错误的初始接线。需要重新审视 STDP 门控机制（可能 DA 信号与动作方向的相关性不足以支持逆学习）。
