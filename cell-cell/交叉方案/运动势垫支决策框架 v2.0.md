## 三、物理约束：三项绝对禁止条款

> **违反任一条，系统将在首个决策周期内物理崩溃或逻辑死锁。这些条款是设计铁律，不是建议。**

### 🚫 禁令一：禁止透视权重矩阵

**违反代码（绝对禁止）**：
```python
# 错误：直接读取下层核团的权重
def read_nucleus_state(nucleus):
    return nucleus.weights  # 物理透视，违反局域性
```

**物理谬误**：突触权重 $W$ 是镶嵌在细胞膜受体蛋白中的物理物质。在真实的物理或SNN宇宙中，上层神经元无法“隔空读取”下层神经元的突触权重数值。神经元之间唯一的通信语言是**膜电位与脉冲（Voltage & Spikes）**。

**合规替代**：见§4.1 置信度积分器（物理电压化）。

### 🚫 禁令二：禁止暂停时间做 `for` 循环探测

**违反代码（绝对禁止）**：
```python
# 错误：在step()中暂停时间，向三个方向各探测一次
for direction in [LEFT, RIGHT, FORWARD]:
    send_probe_movement(direction)
    wait_for_feedback()
    record_match_score()
# 时间倒流，回到探测前状态，执行argmax最优方向
```

**物理谬误**：时间是连续流淌的物理量。在微分方程的 `step()` 中不存在“暂停-试探-倒流”的操作。强行向三个方向发送物理运动，会在单个决策周期内消耗三倍能量，并产生决策颤振（高频抖动），迅速耗尽ATP。

**合规替代**：见§4.3 搭便车探测 + 内部模拟推演。

### 🚫 禁令三：禁止用逆模型（STDP核团）做正向预测

**违反操作（绝对禁止）**：
```python
# 错误：将动作指令送入STDP核团，试图得到感官预测
y_predicted = stdp_nucleus.forward(motor_command)  # 代数死锁
```

**数学谬误**：STDP核团存储的是**感觉→动作（S→M）**的逆模型映射。把一个动作指令 $M$ 塞进逆模型，得到的结果在数学上无定义——逆模型的反向传播路径不存在（逆矩阵不一定可逆，且高维S到低维M是降维投影，不存在唯一逆映射）。

**合规替代**：见§4.4 专属FSM（前向感官预测矩阵），物理隔离、误差驱动。

### 禁令物理层总表

| 禁令 | 物理层违规本质 | 合规替代方案 |
| :--- | :--- | :--- |
| 禁止透视权重 | 破坏神经通信的局域性（Localism）| 脉冲频率编码 → 电压积分 |
| 禁止暂停时间探测 | 破坏时间流形的连续性 + 三倍能量耗散 | 搭便车监听CPG + FSM内部模拟 |
| 禁止逆模型当正模型 | 代数死锁（Algebraic Loop）+ 维度不匹配 | 专属FSM（M→S映射） |


## 四、核心组件物理规格书

### 4.1 置信度评估器（物理电压化）

**功能定位**：将Layer 1核团的脉冲输出密度，物理转换为置信度电压（膜电位），替代v1.0中的数学方差计算。

**物理构造**：为每个STDP核团部署一个 **大电容漏积分神经元（Leaky Integrator Neuron）**。

**输入**：Layer 1对应核团的轴突脉冲（`spike_train_i`）

**输出**：膜电位 $V_{conf_i}$ ∈ [0, 1]（物理电压，代表置信度）

**微分方程**：

$$
\tau_{conf} \frac{dV_{conf_i}}{dt} = -V_{conf_i} + R_{in} \cdot \sum_{k} \delta(t - t_k^{(i)})
$$

其中：
- $\tau_{conf} = 5000$ 步（时间常数，与P0的DA_EMA对齐）
- $R_{in} = 1.0$（输入电阻）
- $\sum_k \delta(t - t_k^{(i)})$：第 $i$ 个核团的脉冲序列（狄拉克脉冲）

**物理意义**：
- 核团学得好（内部权重高且收敛）→ 感官输入到来时发出**高频稳定脉冲** → 积分器电荷充盈 → $V_{conf_i}$ 高（高置信度）
- 核团没学好或输入不匹配 → 发出**稀疏混乱脉冲** → 积分器电荷漏光 → $V_{conf_i}$ 低（低置信度）

**替换v1.0内容**：

| v1.0（废弃） | v2.0（强制） |
| :--- | :--- |
| 数学公式 $S = 1/(Var+\epsilon)$ | 物理微分方程 $\tau dV/dt = -V + R_{in}\cdot spikes$ |
| 每次step计算方差 | 漏积分神经元被动充放电，不额外计算 |

### 4.2 前向感官预测矩阵 FSM（Forward Sensory Matrix）

**功能定位**：专属的、物理隔离的轻量级突触矩阵，专门完成**动作→感官（M→S）**的正向预测，支撑Efference Copy闭环。

**物理隔离原则**：
- ❌ **禁止**：接入影子层状态节点（会混入实时感官输入，造成代数环）
- ❌ **禁止**：与STDP核团（逆模型）有任何突触连接
- ✅ **允许**：仅接收Efference Copy（来自最终决策输出的动作指令副本）
- ✅ **允许**：仅输出预测感官电流 $\hat{y}_{pred}$

**矩阵规格**：

| 参数 | 取值 | 说明 |
| :--- | :--- | :--- |
| 输入维度 | $N = 3$ | 动作空间：左转/右转/前进 |
| 输出维度 | $M = 2$ | 预测感官：温度变化率 + 身体角加速度 |
| 权重数量 | $3 \times 2 = 6$ | 极轻量级，几乎不耗能 |
| 学习规则 | **误差驱动**（非STDP） | 禁止STDP，仅基于预测误差更新 |
| 可塑性状态 | `plasticity=True` | FSM是唯一可在推理期更新的突触矩阵 |

**更新公式（禁止STDP，仅限误差驱动）**：

$$
\Delta W_{FSM} = -\eta_{fsm} \cdot \left( \hat{y}_{pred} - y_{actual} \right) \cdot M_{out}^T
$$

其中 $\eta_{fsm} = 1\times10^{-4}$（远慢于STDP学习率，确保不震荡）。

**物理意义**：
- 预测准确（误差≈0）→ 权重纹丝不动，不做无用功
- 环境变化（摩擦系数改变）→ 预测误差驱动FSM微调，**不影响已锁死的STDP核团**

### 4.3 执行验证器（误差比较器 + GABA抑制）

**功能定位**：将FSM输出的预测感官与实际感官反馈比较，产生的误差电流直接物理抑制当前决策神经元。

**物理构造**：

① **比较器（Comparator）**：一个简单的电流差分节点（KCL求和）

$$
I_{error} = \hat{y}_{pred} - y_{actual}
$$

② **误差神经元（Error Neuron）**：接收 $I_{error}$，当 $|I_{error}| > \theta_{error}$ 时发放抑制脉冲。

③ **GABA能抑制突触**：误差神经元的轴突连接到**当前活跃的DecisionNeuron**，带有负权重 $W_{inhib} = -1.0$。

**动作原理**：
- 执行正确（预测误差≈0）→ 误差神经元沉默 → 当前DecisionNeuron保持活性
- 执行错误（预测误差大）→ 误差神经元剧烈放电 → 向当前DecisionNeuron注入抑制电流 → **物理抽干其电荷** → 当前决策神经元哑火
- 备选决策神经元（电荷第二高者）自然上位 → 平滑切换

**替换v1.0内容**：

| v1.0（废弃） | v2.0（强制） |
| :--- | :--- |
| `if e < threshold: 维持 else: 切换到备选` | GABA能抑制电流物理抽干电荷 |
| 数学分支判断 | 物理KCL电流求和 |
| 硬切换（指令跃变） | 软让位（电荷泄漏速率由 $\tau_{neuron}$ 决定） |

### 4.4 微运动探测（搭便车 + 内部模拟）

**功能定位**：替代v1.0中的 `for` 循环主动探测，改为**被动搭便车**监听CPG自然扰动，并辅以FSM内部模拟推演。

**搭便车机制（物理省能）**：

项目已有 `VitalOscillator`（脑干CPG节律器），它在持续输出本能随机微小震荡（Dither）。这些微运动是**已经发生的物理运动**，其能量已经消耗，不存在额外能量代价。

决策框架的微运动探测改为：
1. **被动监听**：在CPG的自然微震荡发生时，记录每个备选动作方向对应的感官反馈变化量 $\Delta y_d$
2. **并行预测**：同时将CPG震荡指令的副本输入FSM，计算预测感官变化量 $\Delta \hat{y}_d$
3. **匹配度计算**：$M_d = -\|\Delta y_d - \Delta \hat{y}_d\|^2$（负平方误差）
4. **决策偏置**：匹配度最高的方向获得额外兴奋性电流注入决策神经元

**内部模拟推演（非物理探测）**：

当置信度差异极小时（各核团置信度电压相似），系统陷入布里丹之驴鞍点。此时：
1. **不发出任何物理运动**
2. 将备选动作指令 $d$ 分别注入FSM
3. FSM内部计算出预测感官 $\hat{y}_{pred}^{(d)}$
4. 比较器计算内部误差 $e_d^{internal} = \|\hat{y}_{pred}^{(d)} - y_{current}\|$
5. $e_d^{internal}$ 最小的动作获得额外兴奋性电流
6. **仅当内部模拟仍无法区分时**，才允许发出幅度极小的真实物理探测（强度 $\delta_{probe} = 0.001$，是正常运动的千分之一）

**替换v1.0内容**：

| v1.0（废弃） | v2.0（强制） |
| :--- | :--- |
| `for` 循环主动多方向探测 | 搭便车监听CPG自然扰动 + FSM内部模拟 |
| 每次决策消耗3倍能量 | 零额外能量（搭便车）或极小能量（内部模拟） |
| 暂停时间流形 | 完全在时间流内连续运行 |

### 4.5 决策输出（Softmax + 低通平滑）

**功能定位**：将决策神经元的电荷状态转换为最终执行指令，同时确保切换平滑无跃变。

**物理构造**：

① **WTA决策神经元组**：一组相互侧向抑制的神经元（对应LEFT、RIGHT、FORWARD），接收：
- 来自置信度积分器的兴奋性电流（$+V_{conf_i}$）
- 来自误差神经元的抑制性电流（$-I_{error}$）
- 来自微运动匹配度的偏置电流（$+M_d$）

② **侧向抑制**：决策神经元之间互相连接，权重 $W_{lateral} = -0.5$（固定，不学习），确保Winner-Take-All。

③ **Softmax概率输出**：将决策神经元的膜电位通过Softmax转换为概率分布：

$$
P(action = a_i) = \frac{\exp(V_{dec_i} / T)}{\sum_j \exp(V_{dec_j} / T)}
$$

其中 $T = 0.5$ 为温度参数。

④ **低通平滑滤波器**：最终输出经 $\tau_{smooth} = 500$ 步低通滤波后才发送至马达：

$$
\frac{dM_{out}}{dt} = \frac{M_{softmax} - M_{out}}{\tau_{smooth}}
$$

**替换v1.0内容**：

| v1.0（废弃） | v2.0（强制） |
| :--- | :--- |
| `argmax(决策信号 × 置信度)` | Softmax概率输出 + 低通平滑 |
| 硬切换备选核团 | GABA抑制抽干电荷 + 侧向抑制让位 |
| 指令突变为指令平滑跃变 | 由 $\tau_{smooth}$ 控制机械平滑度 |

## 附录A：完整生物学依据引用

（本附录为§2的展开版，供审阅和文档完整性参考）

### A.1 基底神经节的动作选择与门控

基底神经节（Basal Ganglia）是哺乳动物大脑中**动作选择的核心执行器**。其经典模型为“直接通路”和“间接通路”的抑制释放（Disinhibition）机制：

- 皮层向基底节输入多个备选动作的表征
- 纹状体（Striatum）中的D1/D2神经元评估每个动作的奖赏预期
- 黑质网状部（SNr）持续向丘脑发送**强直性抑制**（GABA能）
- 当某个动作被选中时，对应的纹状体神经元放电，**抑制SNr的投射神经元**，从而解除丘脑的抑制（Disinhibition），放行该动作
- 未被选中的动作继续保持抑制状态

**映射到决策框架**：
- 置信度积分器 → 纹状体神经元（评估核团置信度）
- 决策神经元组 → 丘脑（被门控放行）
- 侧向抑制 → SNr的强直性抑制（WTA）
- GABA抑制突触 → 直接通路/间接通路的GABA能投射

### A.2 小脑皮层的前向模型与预测编码

小脑皮层（Cerebellar Cortex）被广泛认为是**前向模型（Forward Model）** 的物理载体：

- 苔藓纤维（Mossy Fibers）传入当前状态和Efference Copy
- 平行纤维（Parallel Fibers）与浦肯野细胞（Purkinje Cells）形成突触
- 浦肯野细胞输出预测的感官后果（通过抑制小脑深部核团）
- 攀缘纤维（Climbing Fibers）传入来自下橄榄核的感觉预测误差信号
- 当预测误差发生时，攀缘纤维触发浦肯野细胞的**复杂脉冲（Complex Spike）** ，驱动平行纤维-浦肯野细胞突触的LTD（长时程抑制），实现前向模型的在线更新

**映射到决策框架**：
- FSM → 浦肯野细胞-平行纤维系统（M→S预测）
- 误差比较器 → 攀缘纤维输入（预测误差编码）
- FSM的误差驱动更新 → 攀缘纤维驱动的LTD（非STDP）
- 物理隔离 → 小脑皮层与深部核团的物理分离

### A.3 脑干/脊髓CPG与节律调制

中枢模式发生器（CPG）位于脑干和脊髓，是**自主节律运动**的源泉：

- CPG在无感觉输入和无大脑下行控制时仍能自主产生节律输出
- CPG的输出可以被感觉输入**相位重置（Phase Resetting）**
- 在运动执行中，CPG持续产生微小的节律性扰动（Dither），用于克服静摩擦和保持系统就绪

**映射到决策框架**：
- VitalOscillator → 脑干CPG（持续微扰动）
- 搭便车探测 → CPG的自然相位重置机制
- 主动感知的被动化 → 利用CPG的节律输出作为探测能量源

### A.4 逆模型与正模型的物理分离原则

在计算神经科学中，**逆模型（Inverse Model）与正模型（Forward Model）在物理空间和可塑性规则上必须分离**：

| 维度 | 逆模型（Layer 1 STDP） | 正模型（FSM） |
| :--- | :--- | :--- |
| 映射方向 | S → M（感觉→动作）| M → S（动作→感觉）|
| 物理位置 | 小脑深部核团 / 皮层 | 小脑皮层（浦肯野细胞）|
| 学习规则 | STDP（脉冲时序依赖）| 误差驱动LTD（幅度依赖）|
| 可塑性时间 | 慢（长时程）| 快（实时适应环境变化）|
| 学习状态 | 学习完成后**锁死** | 持续更新（适应环境变化）|
| 输入 | 感官信号 | Efference Copy + 当前状态 |
| 输出 | 动作指令 | 感官预测 |

**两个系统在物理上是分离的，违反此原则会导致交叉污染和系统崩溃。**

### A.5 主动推理与自由能最小化

卡尔·弗里斯顿（Karl Friston）的**主动推理（Active Inference）** 理论指出：

- 生物系统通过**行动**来最小化**预测误差（Surprise）**
- 系统同时维护两个模型：生成模型（Generative Model）和识别模型（Recognition Model）
- 行动改变感官输入，使实际输入更接近预测（降低Surprise）
- 学习改变生成模型，使其预测更准确

**映射到决策框架**：
- FSM + 决策框架 = 完整的主动推理回路
- 决策框架选择动作 → 改变感官输入（行动改变世界）
- FSM更新 → 改变预测（学习改变模型）
- 预测误差 $e$ = Surprise的物理编码
