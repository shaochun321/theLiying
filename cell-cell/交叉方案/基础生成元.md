## Phase 1 工程报告

### 《工程报告：基础时间关系生成元 (r_{\prec})——双向历史痕迹耦合实施》

只实现：

[
r_{\prec}^{ab}
==============

\Omega_{\prec}[\xi_a,\xi_b].
]

主要结构：

```text
ξₐ → 历史痕迹支路 ─┐
                    ├→ ξₐ ≺ ξᵦ Collector 组
ξᵦ ────────────────┘

ξᵦ → 历史痕迹支路 ─┐
                    ├→ ξᵦ ≺ ξₐ Collector 组
ξₐ ────────────────┘
```

人工 `SpikeGenerator` 只作为测试夹具；验证通过后必须替换成真实 (\xi) Collector。

原时间关系方案中值得保留的是：

* 双向检测；
* 多时间尺度；
* 独立 Collector；
* 暂不接下游。

但正反通道接线、纯延迟与 RC 痕迹的区别必须修正。

## Phase 2 工程报告

### 《工程报告：基础方向关系生成元 (r_{\rightarrow})——双向结构传播路径实施》

只实现：

[
r_{\rightarrow}^{ab}
====================

\Omega_{\rightarrow}
[\xi_a,\xi_b,\pi_{a\to b},\pi_{b\to a}].
]

第一版不在全部 64 个感温点上铺开，而是选择最小三节点链：

```text
ξ₁ ↔ ξ₂ ↔ ξ₃
```

对每一对相邻节点建立：

* (a\to b) 传播路径；
* (b\to a) 传播路径；
* 两个独立的方向响应 Collector。

本阶段验证“结构中的传播方向”，不使用：

* 运行时坐标差；
* `sign()`；
* 点积方向判定；
* 直接把 (+X/-X) 标签写入输出。

现有 6 个感温 RF 可以作为多源聚合与 RC 标定参考，但不能直接当作 (r_{\rightarrow}) 已经完成，因为它们是预设方向模态，而不是生成元之间的双向结构关系。

## Phase 3 工程报告

### 《工程报告：基础参与占比生成元 (r_{\rho})——共享池与分流抑制实施》

先实现二元版本：

[
r_{\rho}^{ab}
=============

(\rho_{a|ab},\rho_{b|ab}).
]

主要结构：

```text
ξₐ → 独立兴奋通道 ─┐
                    ├→ 共同总量池
ξᵦ → 独立兴奋通道 ─┘
                         │
                         ▼
                    共享抑制
                     ↙       ↘
                 ρₐ Collector  ρᵦ Collector
```

本阶段不能直接在 Python 中计算：

[
\frac{I_a}{I_a+I_b}.
]

只能利用现有神经动力学实现一个物理近似：

* 独立兴奋输入；
* 共同池积累；
* 共享抑制反馈；
* 两个输出 Collector 的相对响应。

在没有项目内精确除法组件的情况下，第一版验收目标应是：

* 输入占比排序正确；
* 输入交换后输出交换；
* 共同放大时输出关系基本稳定；
* 两个输出具有近似互补性。

在尚未验证近似归一化前，应称为：

[
\boxed{\text{参与占比关系原型}}
]

不能预先宣称已经得到严格数学比例。

## Phase 4 工程报告

### 《工程报告：基础关系生成元并行集成——时间、方向、占比三路无串扰验证》

Phase 4 不创建新类型的关系生成元。

它只选择同一组真实 (\xi)：

[
\xi_a,\xi_b
\quad\text{或}\quad
\xi_a,\xi_b,\xi_c,
]

同时接入：

[
\Omega_{\prec},
\qquad
\Omega_{\rightarrow},
\qquad
\Omega_{\rho}.
]

输出：

[
\left(
r_{\prec},
r_{\rightarrow},
r_{\rho}
\right).
]

验证内容包括：

* 同一 (\xi) 输出能否同时被三类 Bundle 读取；
* 新路径是否对上游 Collector 形成意外负载；
* 三类关系输出是否互不替代；
* 三类 RC 时间尺度是否产生串扰；
* census 是否完整；
* frozen 权重是否保持不变；
* 全量回归是否通过；
* 运行成本是否可接受。

Phase 4 仍然不接：

* (\Gamma)；
* Motor；
* Shadow Layer；
* TOPR；
* Xin；
* STDP；
* DA；
* CPC。

## 禁止新造的组件

不得为了让方案“看起来完整”而新增：

* `DelayLine` 新组件类；
* `RatioDivider` 新组件类；
* `DirectionOperator` 新组件类；
* `RelationGenerator` 抽象运行时组件；
* 独立于现有膜模型的数学滤波器；
* Python 直接计算的重合判定器；
* Python 直接计算的占比除法器；
* 运行时点积方向判定器；
* 绕过 Bundle 的私有膜电位读取；
* 新的外部全局时钟组件。

如果现有代码中没有经过核实的 `synaptic_delay_steps`，Phase 1 就不能把它写成已存在能力。应改用：

[
\text{现有非 spiking Neuron}
+
\text{膜 RC 痕迹}
+
\text{现有 Collector}
]

构造历史支路。

同样，Phase 3 不得假设项目已有精确除法器，只能用现有兴奋—抑制动力学构造占比近似。

# 五、实施顺序

严格顺序为：

[
\boxed{
0\rightarrow1\rightarrow2\rightarrow3\rightarrow4
}
]

进入下一阶段必须满足：

1. 当前阶段专项探针全部通过；
2. 完整回归通过；
3. 参数来源有实测记录；
4. 没有绕过 Bundle；
5. 没有新增项目外运行组件；
6. census 明确；
7. 工程报告完成。

因此不会先写一份“0～4 全部实现”的大方案再一次落地，而是：

* 总纲先固定边界；
* Phase 0 建立基线；
* Phase 1 完成并验证时间关系；
* Phase 2 完成并验证方向关系；
* Phase 3 完成并验证占比关系；
* Phase 4 最后合并验证。

这与现有前庭量子链路、感温量子元和感温 Ω 层的工程节奏一致：每次只改变一个明确结构，专项探针和完整回归同时通过后才进入下一层。
