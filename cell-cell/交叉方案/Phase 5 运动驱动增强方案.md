# Phase 5 运动驱动增强方案

> **基线**: 78dd39a（Phase 5 实验脚本 + 热觉列修正，前庭 v2.0 默认激活）  
> **目标**: 修复 DR2（宏观位移）和 DR5（热趋向对齐度），同时保持 DR1/DR3/DR6 通过  
> **原则**: 最小侵入、物理合法、软饱和约束下优化输出量级

---

## 一、问题定位

Phase 5 实验（500k 步）显示：
- DR1 PASS（|Δw| = 0.0213），方向性学习已建立
- DR2 FAIL：Δdist ≈ -0.29，远低于 1.0 阈值
- DR5 FAIL：grad_dot_v ≈ 0，因 body 速度极低（~0.001 unit/s）
- 前庭 v2.0 的软饱和使信号平滑，但其最大输出幅度被物理限制在 `1/r_supply` 附近（r_supply=0.05 → 上限 ≈ 20 单位电流，但后续 Motor 膜充电仍需足够电荷）

**根本原因**：前庭 v2.0 的净输出在 Motor 端产生的膜电压低于或仅略高于发放阈值，导致 Motor 放电率极低，身体位移积累缓慢。

**核心约束**：软饱和是必要的，它消除了硬截断尖峰（保障 T2.3/T5.1 稳定），不能被移除。因此，解决方案必须在软饱和之后增强信号，或者充分利用软饱和的线性区。

---

## 二、诊断步骤（阶段 1）

在改动任何参数前，必须确认当前前庭 v2.0 的实际工作点。

### 2.1 测量 G_eff 与 P_avail 传递

在 `VariantCircuit.step()` 中临时添加（或通过探针脚本）：

```python
p_avail = self.energy_store.fill_fraction
g_eff = self.vestibular_v2.network.gain_coeff(src, dst, p_avail)
print(f"p_avail={p_avail:.4f}, g_eff={g_eff:.4f}")
```

预期：p_avail ≈ 0.5（初始），g_eff ≈ 8.4。若 g_eff 偏离 ±2.0 以上，需检查 `gain_coeff()` 实现或 P_baseline 标定。

### 2.2 测量 Motor 端实际电压与放电

记录前庭 v2.0 单独驱动时（不叠加热觉信号）Motor 神经元的膜电位及放电率。若 Motor 稳定膜电位 V_ss 低于 v_peak（0.20），则驱动不足。

### 2.3 评估软饱和工作点

计算当前 HC 输出是否已接近软饱和上限 `1/r_supply`。若 HC 输出已达到上限的 80% 以上，则增加前庭输入幅度（阶段 2）收益极小，应直接采用后级放大。

---

## 三、路径选择逻辑

```
诊断结果：
  G_eff 正常 且 HC 输出未饱和（<80% 上限）
    → 阶段 2A：适度增加前庭输入幅度
  G_eff 正常 但 HC 输出已近饱和（≥80% 上限）
    → 阶段 2B：后级放大（DEVIATION_MOTOR_GAIN）
  G_eff 异常
    → 阶段 2C：修复能量门控引用，然后重新诊断
```

---

## 四、修复实施

### 4.1 阶段 2A：增加前庭输入幅度

**适用条件**：软饱和工作点尚有裕量。

**操作**：在 Phase 5 实验脚本中，将前庭输入信号 `oto_x` 等从当前 `3.0` 提升至 `6.0`，可逐步上调（如 `4.5`, `6.0`, `8.0`），每次运行 10k 步探测 Motor 放电变化。

**预期**：Motor 放电率从 0.007-0.014 EMA 提升至 0.02-0.05 EMA，body 速度从 0.001 提升至 0.003-0.008 unit/s。

**风险**：软饱和保证即使输入过强也不会产生尖峰，T2.3/T5.1 稳定。

### 4.2 阶段 2B：后级放大（DEVIATION_MOTOR_GAIN）

**适用条件**：软饱和工作点已近极限，或增加输入幅度无效。

**操作**：在 `variant_adapter.step()` 中，将前庭 v2.0 的 Motor 输出乘以一个后级增益因子（当前为 1.0），提升至 `2.0`。**不修改前庭信号本身**，只放大其行为效果。

```python
# 前庭驱动累加至 Motor 前
vestibular_drive = v2_out * self.motor_gain  # 原 motor_gain = 1.0
DEVIATION_MOTOR_GAIN = 2.0  # 临时参数，明确标记
self.motor_velocity += vestibular_drive * DEVIATION_MOTOR_GAIN
```

**约束**：
- 增益不超过 `3.0`，防止噪声放大。
- 标记为临时补偿，后续应通过校准 Motor 束的 `synapse_gain` 或肌肉增益来消除此参数。
- 运行前需确认此参数修改不与其他逻辑（如紧急驱动）冲突。

**预期**：body 速度可提升至 0.005-0.02 unit/s，500k 步内位移可达 2.5-10 units。

### 4.3 阶段 2C：修复能量门控

若诊断发现 G_eff 异常，检查 `gain_coeff()` 中 P_avail 的传递是否正确（应使用 `EnergyStore.fill_fraction`，非 `fill` 属性），并验证 P_baseline 标定（应为 1.0 对应满载）。修复后重新诊断，再决定进入 A 或 B。

## 五、短程验证（100k 步）

无论采用哪条路径，修改后需运行 100k 步探测：
- 监控 Motor EMA、body 速度、G_eff 变化
- 记录 grad_dot_v 是否出现持续正值（DR5 的早期迹象）
- 检查 T2.3、T5.1 回归测试是否通过（手动运行 test_regression.py 关键测试）

**通过标准**：
- Motor EMA ≥ 0.02，body 速度 ≥ 0.003 unit/s
- DR5 方向对齐（grad_dot_v 在靠近热源时正偏）
- 回归测试 21/21 或关键测试 PASS

## 六、500k 步主实验与验收

满足短程验证标准后，运行完整的 500k 步实验。

**验收标准**：
| 标准 | 目标 | 备注 |
|------|------|------|
| DR1 | \|w_right - w_left\| > 0.02 | 保持方向性学习 |
| DR2 | Δdist > 1.0 | 宏观位移达标 |
| DR3 | fill > 0 全程 | 代谢自持 |
| DR5 | grad_dot_v > 0 持续出现（>50% 时间） | 热趋向对齐 |
| DR6 | DA 无饱和 | 动态范围保留 |

若 DR2 仍未达标，但 DR5 有改善，可考虑**延长步数至 2M** 作为最后手段，但仅在前述路径均无效时采用。

## 七、风险缓解与回滚

1. **软饱和收益保护**：无论增加输入还是后级放大，都不会修改软饱和机制本身，T2.3/T5.1 稳定性不受影响。
2. **DEVIATION_MOTOR_GAIN 临时标记**：在代码注释中明确说明此参数为临时补偿，预计在 Phase 5 完成后移除，由更物理的增益校准替代。
3. **回滚**：若后级放大导致 Motor 饱和或行为异常，立即回滚至原值，并考虑更根本的 Motor 束增益调整。
