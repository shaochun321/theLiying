## 二、关于 ν_confusion 阈值 30% 的说明

AutoRun 协议设定 `ν_confusion > 30%` 作为触发 V2.0 的判据。这个阈值是**工程设定**，不是物理定律。它基于以下逻辑：当超过 30% 的 bundle 进入固化态（ν<0），意味着系统开始进入信息收敛阶段，预测误差减小，可能出现结构性瓶颈。当前 15% 的混淆度明确低于阈值，数据不支持启动 V2.0。


## 三、FIX-004（SA-II τ 推导）的技术路径

### 3.1 问题定义

500k 长程实验显示：slow_relay.vmem 在 500k 末期是 relay.act 的 **5-9 倍**。

**根因**：slow_relay 的 `τ=300k 步`（300s）太长。SA-II 纤维的真实时间常数约为 5-30s（5000-30000 步）。当前值比生物值高出 10-60 倍，导致 slow_relay 严重超调。

### 3.2 推导逻辑

```python
# 当前值（工程设定，无生物依据）
tau_slow_current = 300000  # 步 = 300s

# 文献值（SA-II 纤维适应时间常数）
tau_slow_bio_min = 5.0     # s
tau_slow_bio_max = 30.0    # s
tau_slow_bio_mid = 15.0    # s（中值）

# 映射到模型步数（dt=0.001s）
tau_slow_new = tau_slow_bio_mid / dt = 15000  # 步
```

### 3.3 预期效果

| 维度 | 当前（τ=300k）| 修正后（τ=15k）| 变化 |
| :--- | :--- | :--- | :--- |
| slow_relay 超调 | 5-9× relay.act | ~1.5-2× relay.act | 显著减少 |
| phasic DA 动态范围 | 不对称（正相位弱）| 更对称 | 改善 |
| 方向学习持久性 | ✅ 已验证 | 预期保持 | 不变 |
| 学习速率 | 被超调压制 | 可能提升 | 预期改善 |

### 3.4 实施方案

```python
# nexus_v1/circuit/variant_adapter.py :: _init_da_circuit()
# 修改 slow_relay 配置
cfg_slow = NeuronConfig(
    neuron_id=f"slow_relay_{pid}",
    capacitance=15.0,      # 原 300.0 → 15.0（τ=C×r_leak=15×1.0=15k步）
    r_leak=1.0,            # 保持不变
    inertia=1.0,           # 保持不变
    channels=[ChannelConfig(...)],  # 保持不变

)
```
