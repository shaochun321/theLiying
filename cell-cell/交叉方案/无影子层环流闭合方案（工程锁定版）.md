## 一、核心理念

影子层是高级认知结构。简单生命体没有皮层预测编码，它们靠底层物理信号完成行为决策：**饥饿打开学习窗口，饱腹关闭窗口并触发驻留。**

本方案所有新增组件均为物理节点（Neuron/Capacitor/Bundle），不引入Python层条件判断。所有换能接口有量纲桥接常数，可被Noether审计。


## 二、环流闭合路径

```
饥饿（EnergyStore fill 下降）
    ↓
hypothalamus_hunger 激活 ──→ DA 门控打开（学习窗口）
    ↓                            ↓
    ↓                     EnergyStore 基础代谢率降低（节能）
    ↓
CPC deviation → VitalOscillator 振幅调制（CPG物理化完成后）
    ↓
随机运动 → 触碰热源 → phasic dT/dt 产生
    ↓
phasic_relay → spinal_turn_toward STDP（方向学习，D1已验证）
    ↓
到达热源 → 口器摄入 + fill回升 + 热源驻留时间达标
    ↓
SatietyNeuron 激活 → 抑制 VitalOscillator 振幅 + 抑制 DA 发放
    ↓
饱腹驻留（固化/静止）+ 能量回升
    ↓
EnergyStore fill 恢复 → 饥饿信号消退 → 行为终止
```


## 三、最高优先级任务：CPG物理化

### 3.1 当前状态

VitalOscillator使用`math.sin(phi)`数学公式——HC-025违规（语义硬编码）。

### 3.2 电路选型：AdEx神经元 + 适应性变量w

单纯的交叉抑制（A→B, B→A）是双稳态触发器，不会自发振荡。要产生交替振荡，需要**疲劳/适应机制**。AdEx神经元内置适应性变量`w`，可自然实现“疲劳→释放抑制→对侧激活”的振荡循环。

**参数基准（需在单元测试中校准）**：

| 参数 | 建议值 | 说明 |
| :--- | :--- | :--- |
| `tau_w` | 100-200 ms | 适应时间常数，远大于膜时间常数，产生疲劳驱动的交替振荡 |
| `a` | 2-4 nS | 亚阈值适应耦合 |
| `b` | 50-100 pA | 每发放一个尖峰时适应电流的增量 |
| 背景驱动电流 | 持续兴奋性注入 | 提供起搏动力 |
| 交叉抑制束 gain | -2.0 | 确保一侧激活时对侧被压制 |

**验收标准**：`math.sin`调用已删除；两个AdEx神经元在无外部调制条件下产生稳定交替发放（相位差约180°，频率波动<10%，振幅波动<5%，两神经元均不永久静默或同时高频发放）；偏差电流可调制振幅。

### 3.3 单元测试要求

在合入主分支前，编写独立测试脚本（约50行），仅包含两个AdEx神经元和两条抑制性Bundle，验证交替波形。参数调至稳定后锁定，再集成进主体网络。

## 五、KCL时序与浮点精度（工程锁定）

### 5.1 时间片对齐

所有注入同一目标神经元的Bundle必须在`_propagate_bundles()`的**同一批次**中执行。实现方式：

```python
# 正确：先累加所有输入电流到缓存，再统一更新膜电位
I_total = 0.0
for bundle in input_bundles:
    I_total += bundle.propagate(dt)
V_mem += (I_total - V_mem / R) * dt / C
```

禁止：逐束交替propagate和更新膜电位（半显式-半隐式欧拉积分造成时序不一致抖动）。

### 5.2 浮点精度

当τ=50,000、dt=0.001时，漏电因子`exp(-dt/τ)≈0.99999998`。防护措施：
- 使用**双精度float64**进行积分
- 适度放大`w_intake`和`w_fill_rate`突触权重，使膜电压变化处于安全动态范围（建议目标：膜电压变化≥1e-6V/步）
- 在SatietyNeuron的`step()`中添加数值稳定性检查：`if abs(dV) < 1e-12: dV = 0`


## 六、DwellSensorNeuron物理规格

驻留时间传感器：大电容缓慢充电，仅在温度稳定（phasic_relay < 0.01）时接收微小充电电流。充电达v_threshold时发放脉冲，代表“驻留时间达标”。

| 参数 | 值 | 说明 |
| :--- | :--- | :--- |
| C | 1000.0 | 大电容，缓慢充电 |
| R | 1000.0 | 大电阻，缓慢漏电 |
| v_threshold | 0.5 | 达标阈值 |
| 充电条件 | phasic_relay < 0.01 | 仅温度稳定时充电 |
| 放电条件 | phasic_relay ≥ 0.01 | 温度变化时快速放电（重置驻留计时）|
