### 一、参数矩阵（最终版）

| 参数 | 数值 | 最终确认 / 来源 |
|------|------|---------------|
| 感官增益 | 0.02 | 理论可接受，但需 1k 步静态诊断确认 |
| 对流漂移 | **0.15**（折中值）| 保留初始引导，避免 Langevin 无法到达进食区 |
| 口器效率 | **0.15** | 提升供能至可覆盖代谢 |
| 热源初始能量 | **8000** | 匹配口器效率提升后的消耗速率 |
| 热源再生速率 | **0.01** | 确保 500k 步内持续可用 |
| YolkSac 初始能量 | 500 | 学习参考基线，不与热源竞争 |
| Z 轴 | 锁定在 Z=25 | 因无上下传感器/执行器 |
| 输入信号 | Langevin OU 噪声 | 打破对称性，避免正弦波坐标系撕裂 |
| 前进束 | `therm_front/back → move_x` | 偏航配合下，前进可对准任意世界方向 |
| 偏航束 | `therm_left/right → rotate_yaw` | 取代废弃的 `therm_left/right → move_y` |
| 废弃束 | `therm_left/right → move_y` | **明确废弃**，保留会造成运动模式冲突 |
| `eligibility_gain` | **从 1e-5 开始，可实时调整** | 在诊断脚本中预留配置项 |
| `K_impact` | 暂定 0.01，**在 Phase 2 中实时监控** | 碰撞频繁时动态下调 |
| `weight_max`（偏航/前进束）| **0.3** | 防止过早饱和 |
| `initial_weight`（偏航/前进束）| **0.01** | 从接近零开始学习 |
| `synapse_gain`（偏航/前进束）| **与感官增益联动，保持有效信号量级** | 与前序校准一致 |

**关于热源初始能量 8000 的计算依据**：口器效率从 0.02 提升至 0.15，热源消耗速率约提升 7.5 倍。Phase 1 中 342 单位/100k 步 → 预估 Phase 2 中约 2500 单位/100k 步。500k 步合计约 12500 单位消耗。8000 初始 + 0.01 再生（2500/500k）≈ 10500 单位总可用。这一量级与预估消耗接近，若进食时间占比低于预期，可能仍有缺口。5000 初始 + 0.005 再生的总可用约 7500，缺口明显；8000 + 0.01 将缺口从“必然耗尽”收窄至“仅在进食占比极高时接近耗尽”，通过实验可确认实际消耗是否低于预估。如果实测消耗更低，此参数有足够余量。

### 二、必须执行的三个诊断

#### 诊断 1：信号链静态诊断（感官增益 0.02 确认）

将 body 固定在距热源表面 10 单位的位置，运行 **1k 步**。测量：
- `enc_therm_*` 实际激活值
- `col_therm_*` spike 频率

**通过标准**：`enc_therm_*` 激活值 ≥0.05，`col_therm_*` spike 频率 ≥1Hz。若未通过，上调感官增益（至 0.03-0.04）直到满足条件。

#### 诊断 2：碰撞预算核算

在 Phase 2 监控中增加指标：
- 碰撞频率（次/10k 步）
- 修复提款量（`repair_cost` 平均值/步）

**通过标准**：在接近期内，碰撞频率 < 5 次/10k 步，`repair_cost` 均值 < 0.0005/步。若超出，在实验脚本中降低 `K_impact`（至 0.005 或 0.001）。

#### 诊断 3：热源能量预算审计

在 Phase 2 监控中增加热源能量追踪：
- 热源剩余能量（每 10k 步采样）
- 预估耗尽时间

**通过标准**：500k 步结束时，热源剩余能量 > 0，温度场未消失。若接近耗尽，在实验脚本中提高初始能量或再生速率。

---

### 三、前进束与偏航束的协同学习

确保两个通路的学习速率大致匹配：
- `eligibility_gain` 初始值相同（1e-5），在诊断脚本中预留实时调整变量
- `weight_max` 相同（0.3），防止任一通路过早饱和
- `initial_weight` 相同（0.01），从接近零开始

在 100k 步时检查两个通路的权重差值：
- 如果差值 > 0.05，说明学习速率不匹配
- 解决方案：调整 `eligibility_gain`（偏航束与前进束可独立调整），使较慢的通路获得更高增益
