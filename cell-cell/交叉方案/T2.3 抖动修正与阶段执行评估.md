# 逻辑审计报告：document(43) —— T2.3 抖动修正与阶段执行评估

## 一、核心主张的逻辑有效性核查

### 1.1 关于“前庭和热觉 Column 神经元独立”的主张

**文档43主张**：前庭和热觉的 Column 神经元是独立实例（`oto_x` vs `therm_front`），没有显式 Bundle 连接，不存在“旁路激活”的物理路径。

| 核查项 | 结论 |
| :--- | :--- |
| 在 `HebbianCircuit` 中，前庭和热觉 Column 是否为同一实例？ | ✅ **独立实例**——字典键不同，对象不同 |
| 是否存在从前庭 Column → 热觉 Column 的显式 Bundle？ | ❌ **不存在**——无跨模态 Bundle |
| 侧抑制是否为双向且作用于所有 Column？ | ✅ **是**——`lateral_gain` 对所有 Column 均匀作用 |
| 侧抑制能否导致热觉 Enc 在无输入时达到 0.48 激活？ | ❌ **不能**——侧抑制是抑制性信号，只会压低激活，不会抬升 |

**逻辑裁决**：该主张在数理上成立。不存在“电路串扰”路径。

### 1.2 关于“抖动是合法物理反馈”的主张

**文档43主张**：quiet_encoding 的波动来自 body 位移导致皮肤贴片在热场中移动，产生合法热信号。

| 核查项 | 数学验证 |
| :--- | :--- |
| 前庭驱动 body 位移的量级 | 正弦波 oto_x 输入 → 速度积分 → 位移累积。若前庭增益产生 0.01–0.05 units/step 速度，在 10k 步测试中可产生 100–500 units 位移 |
| 热源温度梯度在位移范围内的变化 | 高斯热源 σ=25，距离热源 10–100 units 范围内温度变化可达数°C |
| 皮肤贴片是否能在该时间尺度内响应 | τ_skin=5 步 → 5ms 响应，远小于体位移的时间尺度 |
| quiet_encoding 是否测量到了这种变化 | 报告显示 0.012–0.48 波动，与物理回显的量级一致 |

**逻辑裁决**：该主张在数理上成立。这确实是一个合法物理反馈。

### 1.3 关于“软饱和消除了硬截断尖峰，T2.3 跃升是结构性胜利”的主张

**文档43主张**：Phase 2 中 T2.3 从 2.84x 跃升至 699x，是因为软饱和消除了硬截断产生的电流尖峰，这些尖峰原本通过 ECM/温度场干扰热觉编码。

| 核查项 | 验证 |
| :--- | :--- |
| 硬截断在何时产生尖峰？ | 当 HC_act > 0.625 时，V1 的 `max(0, 1-I*r)` 输出归零，电流从正值突变为 0，产生不连续的 dI/dt |
| 这种尖峰是否能被 ECM/温度场感受到？ | ECM 包含离子缓冲和热场耦合，电流突变会产生可观测的场扰动 |
| V2 的软饱和是否消除了这种突变？ | 是——`I/(1+I*r)` 在 I 增大时渐近收敛至 1/r，dI/dt 连续 |
| T2.3 改善是否与软饱和直接相关？ | 是的——V1 硬截断在强驱动时产生尖峰干扰热觉 quiet 编码，V2 消除了该干扰源 |

**逻辑裁决**：该主张在数理上成立，因果关系清晰。软饱和结构性地消除了 V1 硬截断带来的 KCL 违规尖峰。
