# 前庭空间网络化重构方案 V2.0（最终版）

**日期**：2026-07-01
**依据**：P0-P3 综合执行报告、DIMENSIONAL_CONTRACT.md、审查文档修正
**前置条件**：P5（注释修正）已完成，21/21 PASS 确认
**目标**：将前庭内部链路（MET→HC→Aff→Enc→Col）从硬编码数组传递升级为网络化可寻址节点，纳入 TSI 账本审计
**原则**：组合优于继承，不改母代码，并行运行逐步替换


## 一、背景与动机

前庭内部链路当前是硬编码数组传递，不经过 `delay()` 和 `energy_cost()` 审计：

| 问题 | 描述 |
| :--- | :--- |
| **物理特权** | 内部链路零拓扑距离、零结构税，ν 框架的 O(t) 观测信号处于“特权”地位 |
| **热力学漏洞** | MET/HC 的非脉冲电流耗能未被纳入 P_T 审计 |
| **结构计算缺失** | 内部链路无 L_spatial/L_temporal 约束，无法参与 ν 驱动的拓扑演化 |
| **扩展锁死** | `index` 字段被语义污染（0=reg,1=irr），未来 N 扩展无槽位 |


## 二、设计原则

| 原则 | 说明 |
| :--- | :--- |
| **接口不变性** | 对外接口（Col→Motor、nearby()）保持不变，体感系统不受影响 |
| **组合优于继承** | V3 不继承 V2，而是全新类，实现相同 `step()` 接口 |
| **并行逐步替换** | 阶段1并行日志 → 阶段2隔离验证 → 阶段3正式替换 |
| **量纲一致性** | 复用 DIMENSIONAL_CONTRACT.md 已锁定量纲 |

**关键设计**：未来 N=100 扩展时，只需增加 `index=1…99` 的实例，语义纯净，无需改动地址结构。


## 四、拓扑距离（含修正：局部高传导速度）

### 4.1 L_spatial 和 L_temporal（沿用 V-N2）

```
L_spatial：半规管簇内=1，耳石簇内=1，跨簇=3
L_temporal：|τ_class_i - τ_class_j| × 0.5
L_layer：|layer_i - layer_j| × 1.0
L_total = L_spatial + L_temporal + L_layer
```

### 4.2 修正：内部局部高传导速度

基于审查修正2，引入局部传导速度：

```python
def get_internal_delay(src, dst):
    L_total = compute_L_total(src, dst)
    # 前庭内部链路使用局部高传导速度（1000 mm/ms）
    # 确保 L_total=2 → 2步（2ms），与 P4 生物延迟一致
    return ceil(L_total / V_COND_INTERNAL / dt)
```

| 连接 | L_total | delay_steps | 生物合理性 |
| :--- | :--- | :--- | :--- |
| MET→HC | 2 | 2步（2ms）| ✓ 突触延迟 |
| HC→Aff | 2 | 2步（2ms）| ✓ |
| Aff→Enc | 2.5 | 3步（3ms）| ✓ |
| Enc→Col | 2 | 2步（2ms）| ✓ |


## 五、内部 P_T 审计（修正：模拟信号耗能计入）

基于审查修正4，对非脉冲层级（MET、HC）按焦耳热模型计费：

```python
def compute_internal_pt(neuron, dt):
    if neuron.is_spiking:
        # 脉冲神经元：使用 spike_cost()
        return neuron.spike_count * SPIKE_ENERGY_COST
    else:
        # 非脉冲神经元（MET、HC）：焦耳热模型
        # I_out = soft_saturate(neuron.current)
        return I_out ** 2 * neuron.r_leak * dt
```

**审计范围**：
- MET：机械电转换电流的焦耳热
- HC：膜电位维持的漏电流耗能
- 所有层纳入 `EnergyStore` 的 P_T 审计


## 六、实施阶段（含修正：阶段2对比逻辑+组合优于继承）

### 6.1 阶段0：地址分配与接口定义

- 创建 `vestibular/vestibular_addresses.py`：地址枚举 + `get_internal_delay()` + `get_internal_cost()`
- 创建 `vestibular/chain_v3.py` 框架（组合模式，不继承 V2）

### 6.2 阶段1：V3 封装与并行日志

**架构**：`VestibularChainV3` 是全新类，实现相同 `step(mechanical, dt)` 接口，内部完全从零组装：

```
VestibularChainV3
├── 地址系统（vestibular_addresses.py）
├── 神经元实例（MET/HC/Aff/Enc/Col，通过地址索引）
├── FIFODelayBuffer（复用 V2 已有）
├── 内部 Bundle（通过地址查询延迟/成本）
└── step() 接口（与 V2 签名一致）
```

**并行模式**：V2 驱动行为，V3 运行但输出不接入 Motor，能耗只记入虚日志（不触发 EnergyStore）。V2 与 V3 通过适配器并行：

```
variant_adapter.py:
  self.vestibular_v2 = VestibularChainV2()
  self.vestibular_v3 = VestibularChainV3()  # 并行记录
```

**输出**：V2 与 V3 的各层输出记录到日志，供阶段2对比。

### 6.3 阶段2：隔离验证（含修正：相移剥离）

基于审查修正1，对比 V2 与 V3 输出时剥离 FIFO 相移：

```
# 正确对比方式：V3 剥离 FIFO 延迟后与 V2 对标
V2_aligned = get_V2_at_time(t)
V3_aligned = get_V3_at_time(t + delay)  # 或强制 V3.delay_steps=0

# 验证软饱和与路由代数正确性
assert abs(V2_aligned - V3_aligned) < 1%  # 代数一致性
assert V3.delay_steps == expected_delay    # 延迟物理正确
```

**验证项目**：
1. V3 代数输出（剥离延迟后）与 V2 差异 < 1%
2. V3 延迟步数与 L_total 计算一致
3. V3 内部 P_T 审计值在合理范围
4. 21/21 PASS 不受影响

### 6.4 阶段3：逐步替换

```
VariantCircuit 模式切换：
  VESTIBULAR_MODE = "V3_PARALLEL_LOG"  → 阶段1-2
  VESTIBULAR_MODE = "V3_ACTIVE_DRIVE"  → 阶段3（正式替换）
```

**能耗接入**：阶段3时，V3 的 P_T 正式接入 EnergyStore，V2 的能耗同时关闭（不双重扣费）
