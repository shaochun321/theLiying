### 二、P0修复：DA慢积分 + 活动性LTD门控

**位置**：`nexus_v1/circuit/bundle.py` → `learn()` 方法

**问题细化**：若仅对DA做EMA（τ=5000），饱腹期（175k步）仍会使DA_slow指数衰减至≈0，活动性LTD持续磨蚀权重至零。

**修正后的更新规则**：

设DA_ema的递推为：
```
DA_ema[t] = β * DA_raw[t] + (1-β) * DA_ema[t-1]
β = dt / (dt + τ_DA)，τ_DA = 5000步
```

权重更新方程：
```
Δw = DA_ema * (LTP_term - LTD_active_term) - λ_metabolic * w
```

**物理含义**：
- DA_ema作为**全局乘子**，同时门控LTP和活动性LTD
- 当fill饱和，DA_raw→0，DA_ema在τ内衰减至→0 → Δw≈0 → 权重进入“冻结保鲜态”
- λ_metabolic为极小的物理衰减常数（~1e-6/步），代表突触分子半衰期，非活动性LTD
- 第二次饥饿时DA_ema重新爬升，权重从冻结态继续累积

**工程注意事项**：
- 初始化：`DA_ema(0) = DA_raw(0)`，避免前5000步被EMA压低错过首次学习窗口
- 该机制将使跨周期权重保留率从≈0%提升至>80%


### 三、P1修复：竞争侧抑制（WTA）

**位置**：`variant_adapter.py` → D1弧构造区域

在`spinal_ccw`和`spinal_cw`之间添加两条frozen抑制束：

| 参数 | 值 | 说明 |
| :--- | :--- | :--- |
| signal_gain | -1.0 | 抑制性 |
| initial_weight | 0.1-0.15 | 避免高频振荡死锁（Chattering）|
| plasticity | False | 结构预设，不学习 |

**物理效果**：两侧同时升温时（共模信号），侧抑制抵消同步增强；微弱不对称刺激时，差分放大形成赢家通吃（WTA）。


### 四、P2远期：学习目标重定向（增益调制）

**诊断**：STDP不该学方向极性（已由relay→yaw硬连线提供），应学上下文→反射增益调制。

**架构蓝图**：
- 新建增益门控节点（Gain Modulator），其激活值作为**乘法因子**（或通过调节R_leak）缩放relay→yaw硬连线的有效传递率
- STDP从前膜（phasic或上下文状态）连至该门控节点
- 输出形式：`Motion = W_hardwire * Sensation * f(W_STDP * Context)`（非线性调制，非线性叠加）
