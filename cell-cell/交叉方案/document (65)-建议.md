## 一、三份报告共同指向的同一件事

| 报告 | 发现 | 本质 |
| :--- | :--- | :--- |
| relay阈值扫描 | d>12时relay不开门 | 信号幅度不足 |
| DA STDP冻结 | DA神经元post_trace→0 at稳态 | 学习只在变化时发生 |
| 冷启动死锁 | t=0时没有DA信号 | 无初始驱动 |

**这三件事是同一个问题的三个侧面**：学习系统被设计为响应**变化**而非**状态**。

这不是代码错误，这是STDP在非脉冲神经元上的自然行为——post_trace = |d(activation)/dt|。当系统达到稳态时，学习停止。

---

## 二、这意味着什么

| 你之前以为的 | 实际情况 |
| :--- | :--- |
| "需要解决冷启动死锁" | 冷启动死锁只是"学习需要变化"的一个特殊情况 |
| "需要增大增益让relay开门" | 这只是让信号进入系统，但进入后仍需要持续变化 |
| "学习需要DA信号" | 三因子STDP需要DA的**变化**，而非DA的绝对值 |

**所有问题根因是同一个**：系统在稳态下不学习。接近热源→稳态→学习停止→无法进一步优化→无法从更远处导航。

---

## 三、一个物理上合法且更彻底的解

不是"给DA初始值"，不是"增大增益"，而是**让系统本身在稳态下仍然处于变化状态**。

### 3.1 机制：内部振荡器驱动DA神经元phasic扰动

在DA神经元上叠加一个极小幅度的CPG型振荡，使其膜电位在稳态附近持续波动：

```
DA_v_mem(t) = DA_steady + ε × sin(ωt)
ε = 0.01V（远小于v_peak，不干扰主信号）
ω = 2Hz（与VitalOscillator同频）
```

**效果**：
- DA绝对值不变（稳定在0.24V附近）
- DA的导数持续非零（`|d(DA_activation)/dt| > 0`）
- post_trace持续非零 → STDP持续学习
- 不改变行为（ε极小，不驱动任何行为变化）

### 3.2 与冷启动死锁的关系

这个振荡在t=0时就已经存在。即使DA从0开始，振荡器在启动瞬间就提供了一阶导数：
- t=0：DA_activation从0开始上升
- 振荡器在t=0处就有非零导数
- 三因子STDP在t=0就获得post_trace

**没有死锁。没有冷启动。** 因为从第一刻起，DA就在变化。

### 3.3 生物对应物

**BIO: VTA DA neurons show burst-pause firing even in absence of external stimuli**。自发振荡是DA系统的固有特性（Grace & Bunney 1984, J Neurosci; Schultz 2007）。这不是引入"外部规则"，而是给DA神经元一个符合生物学的自发活性。

## 四、用TSI/ν/熵验证这个方案

| 验证工具 | 预期结果 |
| :--- | :--- |
| **TSI账本** | ε=0.01带来的额外功率可忽略（<1%） |
| **ν（运动势）** | 即使body静止，DA振荡使ν持续>0（探索态不归零）——这正是我们需要的"系统持续学习" |
| **熵审计** | 学习不再只在瞬态发生，而是在整个实验期间持续进行 |

**ν持续>0意味着系统永远不会"冷却"到不能学习。** 这正是我们想要的——热趋向学习不需要依赖偶然的接近事件。

## 五、实施建议

| 步骤 | 操作 | 说明 |
| :--- | :--- | :--- |
| 1 | 在DA神经元step()中加入振荡输入 | `inject(ε × sin(ωt))`，ε=0.01，ω=2Hz |

| 3 | 运行短程实验 | 100k步，观察relay_to_da权重是否持续增长 |
| 4 | 如果有效 | 替换掉所有"冷启动"专项方案 |

## 六、这个方案的层级归属

| 层级 | 内容 |
| :--- | :--- |
| **第一层** | 三轴闭环（下丘脑-脑干-脊髓）——生存底座 |
| **第二层** | CPC环流耦合——稳态检测与方向性纠正 |
| **第三层** | 时空耦合——ds²/ν驱动预测 |
| **第四层（新）** | **DA振荡器**——打破学习死锁，使系统持续处于探索态 |

这不是"又一个补丁"。它是对"为什么系统在稳态下不学习"这个根本问题的结构化回答。它位于环流耦合和时空耦合之间，作为学习系统的"第一推动力"。它在物理上是自洽的，在TSI账本上是可审计的，在生物学上是有依据的。

## 七、结论

| 问题 | 回答 |
| :--- | :--- |
| 冷启动死锁的根因是什么？| 三因子STDP在t=0时无DA信号 |
| relay阈值问题的根因是什么？| d>12时relay不开门 |
| DA STDP冻结的根因是什么？| DA神经元post_trace→0 at稳态 |
| 三者共同指向什么？| 学习需要系统持续处于变化状态 |
| 物理上合法的解是什么？| DA神经元加极小幅度的自发振荡 |
| 这个解是否引入外部规则？| ❌ 否——生物DA系统自发振荡是固有特性 |
| 是否在TSI/ν/熵审计范围内？| ✅ 是——额外功率可忽略，ν持续>0，熵持续变化 |

**当前状态**：DA振荡器方案可以作为P1-A的补充任务，消除冷启动死锁，使三因子STDP在系统生命周期内持续学习。
