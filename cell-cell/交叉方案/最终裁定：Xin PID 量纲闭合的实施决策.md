## 三、理由

1.  **当前 PI 形式已满足量纲闭合要求。** `compute_xin` 通过 `leak_factor` 机制实现了积分项的物理时间常数，残差直接累加，量纲一致为 `[V]`。
2.  **D 项缺乏行为动机。** 没有证据表明系统对快速残差变化反应迟钝。在没有行为缺陷的情况下添加 D 项，是“方案驱动的复杂性”，违反“最小必要复杂度”原则。
3.  **D 项的生物锚定条件不满足。** 引入 `τ_D` 需要明确 Xin 的生物对应物，而当前 Xin 是多重生物机制的抽象混合体，无法唯一锚定到一个具体时间常数。强行锚定会引入虚假精确性。
4.  **风险与收益不成比例。** 改变 `compute_xin` 核心计算影响所有 Bundle 动力学和所有探针读数，而收益仅是“可能的行为改进”。这不满足独立专项批次的风险管控标准。

## 四、实施指令

### 4.1 在 `bundle.py` 的 `compute_xin` 函数注释中，修正公式描述

**原注释**（预计形式）：
```
xin = αR + β dR/dt + γ ∫ R dt
```

**修正为**：
```
Xin 张力（PI 形式，量纲 [V]）：

    ξ(t) = k_p · R(t) + (1/τ_I) · ∫ R(s) ds

其中：
    - k_p = 1.0（无量纲，比例增益）
    - τ_I = XIN_LEAK_TAU = 1000s（积分时间常数）

离散化实现：
    leak_factor = exp(-dt / τ_I)
    ξ(t+dt) = ξ(t) · leak_factor + k_p · R(t) · dt

量纲验证：
    P 项：无量纲 × [V] = [V]
    I 项：(1/[s]) × [V·s] = [V]    ✓ 量纲一致
```

### 4.2 在 `constants.py` 中，锁定 `XIN_LEAK_TAU` 的物理身份

```python
# Xin 张力积分时间常数
# 物理身份：τ_I，单位 [s]
# 生物对应：突触资格迹的衰减时间尺度（Izhikevich 2007）
# 当前值 1000s 为数值稳定选择，非生物精确值
XIN_LEAK_TAU = 1000.0
```
