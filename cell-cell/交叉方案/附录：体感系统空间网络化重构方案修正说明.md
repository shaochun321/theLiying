## 二、修正依据

### 2.1 不可行性的三层论证

**第一层：量纲与因果性**

STDP 要求突触两端都是神经元，都产生可计量的发放事件（pre_trace 和 post_trace）。换能束的一侧是 `skin_patch`——物理温度标量，不可能产生 STDP 所需的 `pre_trace`。热量不会因为马达转了一下就与神经产生赫布因果律。

| 检查项 | STDP 要求 | 换能束的实际条件 |
| :--- | :--- | :--- |
| pre_trace | 突触前神经元 spike | skin_patch 是物理温度标量 |
| post_trace | 突触后神经元膜电位 | thermoreceptor 由物理换能驱动 |
| spike-timing | 两个神经元的发放时序 | 无 spike 信号参与 |

**第二层：系统演化风险（“黑暗房间悖论”）**

如果换能束权重可塑，系统为了最小化预测误差（Xin），会将权重降至零，消除所有感觉输入——系统主动让自己“失明”以避免误差，这是错误结构设计导致的病态退化。

**第三层：生物学僭越**

换能系数是物种演化写死的物理常数（TRPV1/TRPM8 离子通道构象改变驱动的跨导），不是个体学习对象。感觉器忠实地按物理常数转换信号，不参与学习。

### 2.2 生物学对照

| 结构 | 可塑性 | 生物学对应 |
| :--- | :--- | :--- |
| transducer_env_to_thermo | **冻结** | TRPV1/TRPM8 离子通道跨导（物种演化固定）|
| thermoreceptor → relay | **可塑** | 脊髓背角→延髓中继（突触可塑性）|
| relay → proj → DA | **可塑** | 脊髓-丘脑束→VTA（STDP 学习）|

## 四、与外部反馈的整合说明

### 4.1 热噪声与 N=3 的物理绑定（建构定律推论）

贴片面积缩小（4→12，面积缩至约1/3）→ 热容减小 → 温度涨落方差增大（⟨ΔT²⟩ = k_BT²/C）→ 热噪声放大 √3 倍 → 需要群体编码降噪（SNR ∝ √N）。

**推论**：体感重构带来的热噪声放大，恰好需要前庭 Phase B（N=1→3）来抵消（SNR 提升 √3）。两者在时间上重合不是偶然，而是建构定律的物理必然。这为规模泛化触发条件中的 N=1→3 提供了一个额外的物理动机——不仅是为了突破香农极限，也是为了抵消体感重构带来的热噪声。

### 4.2 全连接 O(N²) 的诅咒（稀疏编码的涌现必然）

建构定律方程 η(N) = C(N)/P(N) 中，分子随 N 对数增长，而分母如果是全连接则按 N² 增长。系统为了活下去，将被迫利用空间拓扑距离和修剪机制斩断长程连接，自发形成 O(N) 甚至 O(log N) 的稀疏拓扑。

**结论**：稀疏性不是设计选择，而是热力学逼出来的求生本能。
