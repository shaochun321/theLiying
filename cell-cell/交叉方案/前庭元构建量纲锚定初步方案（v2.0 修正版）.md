# 前庭元构建量纲锚定初步方案（v2.0 修正版）

> **版本**：v2.0（修正版）
> **修正原因**：根据《运动势时空测度语言》v1.1 的增益分类法则，修正原方案中“所有增益无量纲”的错误表述，明确跨模态增益的物理量纲
> **核心修正**：全链路增益标注物理单位；锚定计算和增益反推中加入量纲验证
> **状态**：可执行


## 一、当前状态与技术债

前庭 v2.0 已完成架构升级，但**信号链路的输入端仍使用无量纲参数**：

| 参数 | 当前值 | 缺乏的物理单位 |
|------|--------|----------------|
| `oto_x` 幅度 | 6.0 | 不知道对应多少 m/s² |
| `yaw/pitch/roll` 幅度 | 3.0 | 不知道对应多少 rad/s |
| MET `gm` | 2.0 | 不知道对应多少 A·s/rad |
| HC→Aff 增益 | 未显式定义 | 缺失 1/(V·s) 量纲 |
| `synapse_gain` Aff→Enc | 16.0 | 缺失 V·s 量纲 |
| Motor 转换增益 | 未定义 | 缺失 N/V 量纲 |
| `G_eff` α_vest | 5.0 | 无量纲，工程值 |

**核心矛盾**：许多“无量纲”增益实际上是跨模态转换（角速度→电流、发放率→电压、电压→力），它们必须携带物理量纲。当前所有增益数字都是对未知输入量纲失配的“总补偿”，无法独立验证。


## 二、前置探索与采样需求

### 2.1 扫描实验一：半规管通道（角速度）

**目标**：测量 `yaw` 输入幅度 → Aff 发放率 的稳态关系。

**方法**：
- 在隔离的 VestibularChainV2 中注入不同幅度的正弦 `yaw` 信号（幅度 0.5–10.0，步长 0.5，频率与文献对齐：2 Hz）。
- 每种幅度运行 5000 步，记录最后 2000 步的 Aff_reg 平均发放率（Hz）。
- 输出曲线：**无量纲输入 → 发放率**。

**同构性检验（新增）**：对 yaw/pitch/roll 分别执行相同协议。若三条曲线的线性区斜率差异 < 5%，判定为同构，采用统一模板；否则独立建模。

### 2.2 扫描实验二：耳石通道（线性加速度）

**目标**：测量 `oto_x` 输入幅度 → Aff 发放率 的稳态关系。方法同上。

### 2.3 扫描实验三：全链路功率审计

**目标**：在已知输入幅度下，测量前庭链路的功率消耗。按 $P_T = P_{MET} + P_{HC} + P_{Aff} + P_{Enc} + P_{Col}$ 分层记录。

## 四、锚定假定与锚定计算

### 4.0 锚定假定（显式声明）

**约定**：在扫描曲线的线性区，无量纲幅度 1.0 对应于 1.0 deg/s (≈ 0.01745 rad/s)。

**验证策略**：以此假定反推 $g_{MET}$ 和灵敏度，与文献独立测量值对比。若偏差 ≤±20%，假定自洽；否则调整并重新验证。

### 4.1 锚定计算

利用扫描曲线和文献灵敏度（1.0 spikes/s/deg/s），计算无量纲输入与物理角速度的映射因子。

### 4.2 交叉一致性检查（新增）

完成角速度与加速度通道锚定后，验证两者的量纲映射是否均落在生物合理运动范围内，避免量级差异 >10×。


## 五、增益反推与全链路量纲对齐

以下公式严格区分跨模态增益（携带量纲）与同模态增益（无量纲）。

### 5.1 增益定义与量纲

| 增益 | 输入 → 输出 | 量纲 | 类型 |
|------|------------|------|------|
| $g_{MET}$ | ω (rad/s) → I (A) | **A·s/rad** | 跨模态 |
| $G_{HC}$ | I → I | 无量纲 | 同模态 |
| $G_{HC\_Aff}$ | V_HC → f_Aff (spikes/s) | **1/(V·s)** | 跨模态 |
| $G_{Aff\_Enc}$ | f_Aff (spikes/s) → V_Enc | **V·s** | 跨模态 |
| $G_{Enc\_Col}$ | V_Enc → V_Col | 无量纲 | 同模态 |
| $G_{Col\_Motor}$ | V_Col → V_Motor | 无量纲 | 同模态 |
| $\eta_{motor}$ | V_Motor → F (N) | **N/V** | 跨模态 |

### 5.2 锚定与反推步骤

1. 从文献确定 $g_{MET}$ 和传入灵敏度。
2. 利用锚定假设计算无量纲 `yaw` 对应的物理角速度，验证模型 $f_{Aff}$ 与文献灵敏度一致。
3. 通过 Enc 阈值（$V_{Enc,target}=0.30$ V）和生物收敛比（$N_{conv}=10$），推导 $G_{Aff\_Enc}$（V·s）：
   ```
   G_Aff_Enc = V_Enc,target / ( f_Aff × Q_spike × N_conv )
   ```
   其中 $Q_{spike} = r_{supply} \times dt$ (C)。
4. 从 body 速度与 Motor 电压的关系，反推 $\eta_{motor}$（N/V）。

### 5.3 能量门控 α 推导

在平衡能量状态下，解 $G_{eff} = G_{base} \times (1 + \alpha \times P_{avail}/P_{baseline}) \times (...)$ 得到 α。若推导值与当前工程值同量级，说明原有标定并非任意。


## 六、更新后的执行步骤与决策点

| 步骤 | 任务 | 说明 |
|------|------|------|
| S0 | 文献收集 + 物种数据源确认 | 获取每个增益的**数值 + 物理单位** |
| S1 | 扫描实验（含同构性检验） | 无量纲→发放率标定曲线，判定角速度轴同构性 |
| S2 | 功率审计 | 分层测量前庭 $P_T$ |
| **S3** | **锚定假定声明** | 显式记录 `1.0 = 1 deg/s`，附验证策略 |
| S4 | 锚定计算 | 确定输入映射因子，反推跨模态增益值及量纲 |
| **S4.5** | **交叉一致性检查** | 验证半规管/耳石锚定后物理量级无矛盾 |
| **S5** | **数据驱动的粒度决策** | 基于 S1 同构性检验与 S4 锚定结果，决定采用统一元构建模板还是按 axis 独立建模 |
| S6 | 全链路增益校准与量纲验证 | 更新代码参数并添加物理单位注释；验证量纲闭合 |
| S7 | ν 一致性验证 + 回归测试 | 21/21 PASS + 功率审计 + ν 波形验证 |

**S5 粒度决策**：依据 S1 同构性判定和 S4 锚定结果，在“统一模板+参数覆写”与“独立建模”之间做出选择，避免过度设计或过度简化。

## 八、预期成果

完成本方案后，前庭系统成为首个**完全物理锚定的元构建**：
- **输入**：具有明确物理单位（rad/s, m/s²）
- **增益**：可推导，跨模态增益携带量纲，同模态增益无量纲
- **功率**：可独立审计（$\nu_k$ 核算）
- **可复现性**：任何参数变更都有物理依据，不再依赖工程标定

量纲锚定、元构建定义和网络构建不再是三个独立的任务，而是同一个物理一致性问题的三个视角。
