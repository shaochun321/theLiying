
## 一、问题本质：失去单变量控制

| 如果同时修改 | 失败后无法归因 |
| :--- | :--- |
| slow_relay τ（内部时间尺度）| 是 DA 脉冲太短导致 STDP 没来得及刻录？|
| World 2.0 Phase 3（外部空间结构）| 还是 K_VANE 把车锁死在鞍点？|

**如果两者同时改，一旦失败，你面对的是耦合变量，而不是可追溯的单变量。** 这不是“并行开发”能解决的，是“实验设计”的根本缺陷。

## 二、强制串行化的修正方案

### 阶段一：FIX-004（大脑校准）——在旧环境中验证

| 项目 | 内容 |
| :--- | :--- |
| **修改** | `slow_relay.capacitance` 300.0 → 15.0（τ=15k步）|
| **环境** | 双热源旧环境（`exp_dual_source_long_run.py`）|
| **步数** | 100k-200k（不是500k，只需确认DA波形）|
| **验收** | ① DA无明显超调（slow_relay/relay.act < 3×）<br>② wR-wL > 0.005（方向正确）<br>③ 21/21 PASS |

**目标**：确认新τ的多巴胺引擎在环境不变的前提下消除了超调，且仍能正确编码方向。

### 阶段二：World 2.0 Phase 3（生态测试）——在确认大脑健康后

| 项目 | 内容 |
| :--- | :--- |
| **环境** | 三热源正三角形布局（eta=0.50，K_VANE=0.001）|
| **步数** | 500k |
| **前提** | 阶段一的所有验收指标均已通过 |

**目标**：在多热源复杂环境中，验证导航能力与代谢可持续性。

## 三、如果阶段一失败

| 失败类型 | 归因 | 修复方向 |
| :--- | :--- | :--- |
| DA波形仍然超调 | τ=15k 仍然太长，或太短 | 调整 capacitance 至 10.0 或 20.0 |
| wR-wL < 0.005 | τ=15k 导致 DA 脉冲太短，LTP窗口不足 | 延长 capacitance（如 20-30）|
| 回归测试失败 | τ 改动影响了其他回路 | 检查 slow_relay 是否被其他 bundle 依赖 |

**此时不会怀疑 Phase 3 的环境参数**——因为在阶段一阶段，Phase 3 根本没启动。

## 五、阶段一的快速验收标准（100k步即可）

由于目标只是确认 DA 动力学，不需要跑满 500k：

| 检查项 | 通过条件 | 检查时机 |
| :--- | :--- | :--- |
| DA 无超调 | slow_relay.vmem / relay.act ≤ 3× | 100k 步终点 |
| 方向正确 | wR-wL > 0.005 | 50k 步后 |
| 回归测试 | 21/21 PASS | 任意时刻 |

如果 100k 步时满足上述三项，阶段一完成，立即进入阶段二。
