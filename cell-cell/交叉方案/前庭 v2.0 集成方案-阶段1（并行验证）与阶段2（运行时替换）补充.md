## 二、`fifo_utilization()` 逻辑规格

**实现位置**：`vestibular/chain_v2.py`，`VestibularChainV2` 类中新增方法。

**逻辑定义**：

```python
def fifo_utilization(self) -> float:
    """
    返回所有 FIFO 缓冲区的平均填充率。

    统计范围：所有通过 `network.delay()` 查询并创建的 FIFO 缓冲区。
    （包括 MET→HC、HC→Aff、Aff→Enc、Enc→Col 共 4 层 × 6 轴 = 24 个 FIFO）

    单个 FIFO 填充率 = current_size / capacity
    平均值 = sum(填充率) / len(所有FIFO)

    正常范围：0.3 ~ 0.7
      - 过低（< 0.3）：预填充噪声已耗尽，信号到达前队列已空 → 检查 prefill_noise 初始化
      - 过高（> 0.7）：信号堆积 → 检查 delay_steps 是否过长或 v_cond 参数失配
    """
    total_fill = sum(buf.current_size / buf.capacity for buf in self._all_fifos)
    return total_fill / len(self._all_fifos)
```

**约束条件**：
- 该方法在阶段1中每步被 `probe` 记录，用于诊断 FIFO 健康状况。
- 如果平均填充率连续 1000 步 < 0.1 或 > 0.9，应在阶段1验证报告中标记为“FIFO 异常”并终止阶段1。

###对三项方法的逻辑确认

**`spike_cost()`** 的统计范围是正确的。在v2.0架构中，MET、HC、Enc、Col均为非脉冲神经元（spiking=False），只有Aff_reg和Aff_irr是脉冲神经元。12个Aff神经元（6个reg + 6个irr）的发放次数乘以`SPIKE_ENERGY_COST=0.005`，与v1.0的能量审计基线保持一致，阶段2中直接累加至`EnergyStore.drain()`不会产生单位偏差。

**`fifo_utilization()`** 的24个FIFO计数需要确认。方案假设4层连接（MET→HC、HC→Aff、Aff→Enc、Enc→Col）× 6轴 = 24个FIFO。从V-N3的FIFO初始化逻辑来看，如果每对相邻层之间都创建了FIFO，这个数字是正确的。但需要额外确认：MET→HC是否使用了FIFO？之前的延迟链路图显示MET→HC延迟为2步，这意味着MET→HC也有FIFO。如果确认，24个FIFO的计数成立。正常范围0.3~0.7是合理的——噪声预填充σ=0.01在2步延迟的FIFO中占据约1%的幅度，信号到达后将填充率稳定在中等水平。

**`last_gain`** 属性需要在`step()`中赋值。`G_eff`的计算发生在Aff→Enc的信号传播段（通过`network.gain_coeff()`），将此值保存到`self.last_gain`后，阶段1的probe可以记录增益随能量波动的完整曲线。

###关于`_all_fifos`的维护

`fifo_utilization()`依赖一个统一的FIFO列表来遍历。V-N3阶段创建的FIFO缓冲区需要通过一个属性暴露。如果当前实现中FIFO是分散在各个层连接中的局部变量，需要添加一个`self._all_fifos`列表，在每创建一个FIFO时`append`进去。这个改动不影响现有逻辑，只是增加一个引用集合。

###阶段1启动前的完整前提条件

你的清单中列出的五个条件，第四条（`_all_fifos`列表）需要特别关注。它在V-N3中可能未被显式创建——如果当前FIFO是通过独立的变量名（如`self.fifo_met_hc_yaw`）维护的，那么需要新增一个统一的列表来汇总所有FIFO引用。其余四个条件（VestibularChainV2可实例化、三个新方法/属性）都是确定性的，只需按规格实现即可。

###对阶段1集成方案的理论补充

这三个方法不仅服务于监控和审计，它们在TSI框架中各有对应的物理量：

- **`spike_cost()`** 对应TSI中 $P_T$ 分量的脉冲发放部分——每次脉冲消耗固定的`SPIKE_ENERGY_COST`，能量审计器追踪这些消耗并确保 $P_T + P_S + P_I \le P_{input}$。
- **`fifo_utilization()`** 是“时间测度 $\mathcal{T}$”的一个诊断指标——FIFO的填充率反映了信号在时间维度上的分布密度。如果FIFO持续空载，说明信号到达频率过低（时间测度稀疏）；如果FIFO持续满载，说明延迟参数过大（时间测度过密）。
- **`last_gain`** 是能量门控的物理状态变量——它编码了“当前能量状态对感觉灵敏度的影响程度”，是内稳态势（$\nu_{th}$）与感觉-运动环（$\nu$）之间的耦合系数。
