# 诈胡验证实验方案（整合最终版）

**日期**：2026-07-05
**实验目的**：彻底排除方向性学习由隐藏硬编码、结构不对称或初始条件偶然性导致的诈胡
**背景**：T-035/T-036 已涌现方向性分化，w_ccw 强化、w_cw 弱化。需确认此分化是否真正由物理时序差（phasic → spinal STDP）驱动，并随热场几何翻转。


## 一、验证策略三层递进

| 层级 | 实验 | 验证目标 |
| :--- | :--- | :--- |
| **核心验证** | **实验一：Bundle消融** | 方向性是否**唯一**来自 D1 热趋性 Bundle（删除后分化消失） |
| **辅助验证** | **实验二：热源侧向反转** | 方向是否**真实响应**热源空间位置（反转热源方向，偏好反转） |
| **极端验证** | **实验三：权重冻结锁死** | 方向性是否**依赖持续学习**（锁死权重后自适应消失） |

**原则**：不做任何参数调整，仅改变连接或初始条件。如果方向性是真实的，删除关键 Bundle 会使其消失；如果是硬编码，删除 Bundle 不会影响。


## 二、实验一：Bundle 消融实验（核心验证）

### 2.1 设计

在 T-036 相同实验条件下（冷区起步，200k 步），**注释掉连接 `phasic_relay → spinal_ccw/cw` 的两条 Bundle**：

```python
# 注释掉 D1 热趋性学习弧
# bundles_phasic_to_spinal_ccw: phasic_left → spinal_ccw
# bundles_phasic_to_spinal_cw: phasic_right → spinal_cw
```

其余所有结构（DA、饱腹、BMR、能量链）完全保持不变。

### 2.2 预期结果

| 场景 | 预期 | 解释 |
| :--- | :--- | :--- |
| 方向性来自 D1 Bundle（真实）| Δw ≈ 0，无分化 | 删除唯一方向信号源，学习消失 |
| 方向性来自其他隐藏硬编码 | Δw ≠ 0，仍分化 | 存在未被识别的 HC 或结构不对称 |

### 2.3 判定标准

- **通过（真实学习）**：200k 步后 `|w_ccw - w_cw| < 0.005`，两侧权重无方向性分化
- **疑似诈胡**：Δw 仍显著（>0.01），需排查其他方向源

### 2.4 若实验一 Δw ≠ 0 的排查路径

1. `get_all_bundles()` 列出所有 Bundle，检查是否有其他连接 phasic→spinal 或 relay→yaw 的可塑性束
2. 检查 body 初始 yaw 是否为零
3. 检查皮肤贴片空间分布是否对称
4. 检查前庭链路是否产生方向性偏置（如 Ca²⁺ 通道不对称）

**实验一是验证方向性真实性的最干净实验，必须执行。**


## 三、实验二：热源侧向反转实验（辅助验证）

### 3.1 设计

与 T-036 相同配置，但**将热源从右侧移到左侧**：

| 参数 | 原配置 (G1) | 反转配置 (G2) |
| :--- | :--- | :--- |
| Body 起始位置 | [10, 50, 25]（热源右侧远端）| 保持不变，或适当调整确保冷区起步 |
| 热源位置 | **[70, 50, 25]**（body 右侧）| **[30, 50, 25]**（body 左侧）|
| 预期方向偏好 | w_ccw↑, w_cw↓（左转偏好）| w_cw↑, w_ccw↓（右转偏好）|

运行 200k 步（或至少 50k 步），观察 Δw 方向。

### 3.2 预期结果

| 场景 | 预期 Δw 方向 | 解释 |
| :--- | :--- | :--- |
| 方向性来自物理热场（真实）| **反转**（G1: w_ccw 高；G2: w_cw 高）| 方向跟随热源位置变化 |
| 方向性来自固定偏置（假象）| **不变**（两组均 w_ccw 高）| 存在固定方向偏好 |

### 3.3 判定标准

- **通过（真实学习）**：G1 Δw 符号 ≠ G2 Δw 符号，且与首次接触时 phasic 正值所在侧一致
- **疑似诈胡**：两组 Δw 符号相同

**如果实验一和实验二均通过，诈胡概率降至极低（<1%）。**


## 四、实验三：权重冻结锁死实验（可选，极端验证）

### 4.1 设计

在 T-036 运行至 10k 步（方向分化刚完成）时，将 `bundles_phasic_to_spinal_ccw` 和 `bundles_phasic_to_spinal_cw` 的学习规则改为 `frozen`（锁死当前权重），继续运行至 200k 步。

### 4.2 预期结果

| 场景 | 预期行为 | 解释 |
| :--- | :--- | :--- |
| 方向性来自持续学习（真实）| 锁死后，body 失去自适应能力，行为退化 | 方向性依赖持续 STDP 更新来维持或调整 |
| 方向性来自固定硬编码（假象）| 锁死后行为不变 | 方向性不依赖学习 |

### 4.3 判定标准

- **通过**：锁死后行为退化（如 DR5 下降、方向偏好逐渐消失）
- **未通过**：锁死后行为维持不变


## 五、补充验证：方向随起始位置翻转（可选）

在不重置权重的情况下，将 body 起始位置从热源一侧移到另一侧，验证已建立的偏好是否能被新经验反转。例如，先在右侧起步运行 20k 步（建立 CCW 偏好），然后不重置权重，将 body 移到左侧起步再运行 20k 步，观察 CW 偏好是否能建立。此实验验证方向信号的动态性和可逆性。


## 六、执行顺序

```
1. **实验一（Bundle 消融）**
   ├── 注释掉 D1 Bundle，运行 200k
   └── Δw ≈ 0 → 核心验证通过

2. **实验二（热源反转）**
   ├── 热源移到左侧，运行 200k
   └── Δw 方向反转 → 辅助验证通过

3. （可选）实验三（权重冻结）
   └── 10k 步锁死权重，运行至 200k → 验证依赖性
```

**建议优先执行实验一，因为它最干净、最直接。如果实验一通过，实验二可作为交叉验证。实验三和前向翻转实验可按需执行。**
```
**本方案是 T-035/T-036 方向性学习真实性判定的最终关卡。通过后，方向性学习的物理涌现将获得不可证伪的证据。**
```
