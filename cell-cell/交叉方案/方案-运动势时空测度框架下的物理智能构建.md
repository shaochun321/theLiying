## 一、核心理念

> **物质是最好的时空坐标。** 所有认知结构必须从物理约束中涌现，而非从语义标签中定义。

我们的数理体系不“规定”量纲，而是通过定义流形上的合法映射来对齐不同物理投影。这意味着：

| 传统做法 | 我们的做法 |
| :--- | :--- |
| 用不等式约束参数 | 用实测映射审计参数效果 |
| 预设量纲统一 | 在流形上建立投影间映射 |
| 外部单位系统 | 内部物理响应定义合法范围 |


## 二、T/O/P/R/Xin统一框架

### 2.1 时间测度 T

信号沿物理拓扑传播的延迟：

$$
\tau_{ij} = \frac{d_{ij}}{v_{cond} \cdot dt}
$$

- $d_{ij}$：节点 $i$ 到 $j$ 的物理距离
- $v_{cond}$：传导速度（模型常量，代表轴突传导速度）
- $dt$：仿真时间步长

**实现**：所有 `SynapticBundle` 废除瞬时矩阵乘法，引入 `RingBuffer` 缓存历史激活值 $a_i(t - \tau_{ij})$。

### 2.2 空间测度 S

空间关系由物理拓扑距离矩阵 $\mathbf{D}$ 定义：

$$
\mathbf{D}_{ij} = \| \mathbf{p}_i - \mathbf{p}_j \|_2
$$

- $\mathbf{p}_i$：节点 $i$ 的物理坐标（三维空间）

**实现**：`NeuronConfig` 锁定 `position: (x, y, z)` 属性，废除所有基于字符串的语义标签。

### 2.3 信息功率 I

信号传输功耗包含两部分：

$$
P_T(t) = \sum_i \left( I_{syn,i}^2(t) \cdot R_m + \frac{V_i^2(t)}{R_{leak}} \right)
$$

- 第一项：突触电流的焦耳热
- 第二项：静息膜电位维持的漏电耗散

**量纲验证**：
- $I_{syn,i}^2 \cdot R_m$：$A^2 \cdot \Omega = W$
- $V_i^2 / R_{leak}$：$V^2 / \Omega = W$

### 2.4 结构功率 S

结构重塑的能量代价，包含距离惩罚：

$$
P_S(t) = \eta_s \cdot \sum_{ij} \left( \frac{dw_{ij}}{dt} \right)^2 \cdot d_{ij}
$$

- $dw_{ij}/dt$：突触权重变化率
- $d_{ij}$：突触两端物理距离
- $\eta_s$：结构重塑能效系数

**物理意义**：长程突触的重塑代价远高于短程突触，迫使网络自然形成“局部密集、长程稀疏”的小世界拓扑。

### 2.5 Xin 张力（预测误差的 PID 升维）

Xin 张力不再只是简单漏积分器，而是 PID 算子：

$$
\xi_i(t) = \alpha \cdot R_i(t) + \beta \cdot \frac{dR_i}{dt} + \gamma \cdot \int_0^t R_i(s) \, ds
$$

其中 $R_i(t) = |O_i(t) - P_i(t)|$ 是预测残差。

| 分量 | 作用 | 生物对应 |
| :--- | :--- | :--- |
| $\alpha \cdot R_i$ | 当前剥夺感 | 即刻疼痛/饥饿 |
| $\beta \cdot dR_i/dt$ | 变化趋势（前瞻阻尼）| 预期性焦虑 |
| $\gamma \cdot \int R_i$ | 历史累积（异稳态记忆）| 长期资源错配债 |

### 2.6 运动势 ν（功率量纲修正）

$$
\nu(t) = \sum_i \frac{1}{R_{\xi}} \cdot \xi_i(t) \frac{d\xi_i(t)}{dt}
$$

- $R_{\xi}$：认知网络等效流形阻抗（量纲：Ω）
- $\nu > 0$：探索态（系统偏离稳态，可塑性强）
- $\nu < 0$：固化态（系统回归稳态，结构冻结）

**量纲验证**：$\xi$ 的量纲为电压 $[V]$，$R_{\xi}$ 的量纲为电阻 $[\Omega]$，因此 $\nu$ 的量纲为 $[V^2/\Omega] = [W]$。


## 三、TSI 功率账本

系统总功率必须满足：

$$
P_{in}(t) \ge P_T(t) + P_S(t) + P_I(t)
$$

| 项 | 定义 | 量纲 |
| :--- | :--- | :--- |
| $P_{in}$ | 环境能量输入（VascularCooling 模型）| W |
| $P_T$ | 传输功率（突触+静息耗散）| W |
| $P_S$ | 结构功率（突触重塑代价）| W |
| $P_I$ | 信息功率（Xin 动力学）| W |


## 四、空间网络化构建

### 4.1 全局时延队列（步骤 1-2）

在 `VariantCircuit.__init__` 中一次性生成所有节点间的物理拓扑距离矩阵 $\mathbf{D}$。每个 `SynapticBundle` 引入 FIFO 环形队列，延迟由 $\tau_{ij}$ 决定。

### 4.2 结构功率的距离惩罚（步骤 7）

在 STDP 更新中，$P_S$ 的结算必须挂钩 $\mathbf{D}$ 矩阵：

```python
# 每次权重更新后
dW = w_new - w_old
P_S += eta_s * dW**2 * distance_matrix[i][j]
EnergyStore.drain(P_S * dt)
```

### 4.3 刚体动力学的去中心化

废除 `move_x`、`move_y` 等绝对方向马达，替换为锚定在局部坐标系上的推力单元：

```
Left_Thruster（左推进器）  → 向量推力与重心的物理力臂叉乘 → 偏航力矩
Right_Thruster（右推进器） → 向量推力与重心的物理力臂叉乘 → 偏航力矩
```

偏航角演化由刚体力学自然解算，不由语义标签指定。


## 五、量纲锚定与审计框架

### 5.1 增益扫描（步骤 1）

固定 body 在 $d=20$，扫描 `THERMAL_TRANSDUCTION_GAIN`，测量：

| 增益值 | relay_activation_mean | 状态 |
| :--- | :--- | :--- |
| 0.1 | ... | relay 未开门 |
| ... | ... | 过渡区 |
| gain_min | ≥0.01 | relay 首次开门 |

### 5.2 增益-能耗映射（替代静态不等式）

建立实测映射：

$$
\text{drain\_rate}(gain) = f(gain, \text{relay\_act}, \text{发放率})
$$

**判定标准**：

| 条件 | 通过 | 失败 |
| :--- | :--- | :--- |
| `relay_activation_mean ≥ 0.01` | 信号已进入系统 | 增益不足 |
| `drain_rate(gain) < fill_capacity / 50k` | 有足够缓冲期 | 增益可能过高 |
| `ν(gain) > 0`（参照）| 系统处于探索态 | 增益可能饱和 |
| `entropy(gain)` 继续增长（参照）| 信息在增加 | 增益可能无效 |

### 5.3 冷启动 DA

```python
# 系统 t=0 时，饥饿驱动提供基线 DA
v_mem = max(0, (fill_ref - fill_fraction)) + ε
ε = 0.01V（微幅振荡，提供持续 post_trace）
```

- 不需要外部 DA 注入
- 不需要初始权重
- 三因子 STDP 从第一刻起即获得 `post_trace`
