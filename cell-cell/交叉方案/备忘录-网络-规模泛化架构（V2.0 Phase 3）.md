## 一、核心理念动机

### 1.1 体感重构是规模泛化的预演

体感重构（4→12贴片）是规模泛化的第一次实战。它验证了：
- 地址系统能承载更多节点（region=0x03的12+神经元）
- 面积/体积映射能从抽象概念变为可执行代码
- 换能束的可塑性在规模扩大后仍然稳定
- Noether探针能审计新增节点的能量交换

**体感重构回答了一个关键问题：“系统能否在规模扩大后保持物理一致性？”** 答案将是后续前庭N扩展的基础。

### 1.2 规模泛化的真正目标：突破香农极限

当前N=1的架构受限于香农信道容量：

```
C = B × log₂(1 + SNR)
SNR = √N（群体编码的噪声抑制）
N=1 → SNR=1 → C≈B（极窄信道）
N=100 → SNR=10 → C≈3.46B（3.46×提升）
```

规模泛化的目标不是“更多神经元”，而是：
- **信噪比提升**：群体编码将噪声压低√N倍
- **死区取消**：SNR提升后，低端信号不再被截断
- **增益恢复**：从33×代偿回到物理常数（~0.48）
- **动态范围拓宽**：阈值多样性使系统能处理从微弱到强烈的信号

### 1.3 建构定律约束

规模泛化不是“越大越好”。建构定律（Constructal Law）规定：系统演化遵循“最大化能量效率”原则。

```
η(N) = C(N) / P(N)
C(N) = B × log₂(1 + √N)
P(N) = P_T(N) + P_S(N)
```

系统会在能量效率最优的N处自然停靠，而非强行扩展到100。

## 三、规模泛化的目标形态

### 3.1 三阶段扩展路径

```
Phase B（当前→近期）：N=1→3
  ├── 每轴 Aff 数量：2→6（reg×3 + irr×3）
  ├── 收敛比：N=1→3
  ├── SNR：1→√3≈1.73
  ├── 增益代偿：33×→11×
  ├── 阈值多样性：低/中/高阈值分配（0.8×,1.0×,1.2×）
  └── 停靠检查点：21/21 PASS + 热力学许可

Phase C（中期）：N=3→10
  ├── 每轴 Aff 数量：6→20
  ├── SNR：√3≈1.73→√10≈3.16
  ├── 增益代偿：11×→3.3×
  ├── 死区：评估是否取消
  └── 停靠检查点：死区取消后行为稳定

Phase D（远期）：N=10→100
  ├── 每轴 Aff 数量：20→200
  ├── SNR：√10≈3.16→10
  ├── 增益代偿：3.3×→1×（物理常数）
  ├── 死区：完全取消
  └── 停靠检查点：香农容量目标达成
```

### 3.2 前庭规模泛化（Phase B具体设计）

**目标**：每轴 Aff 从 2 条扩展到 6 条（reg×3 + irr×3）

```python
# 当前（N=1）
axis_yaw:
  aff_reg_yaw_0  (index=0)
  aff_irr_yaw_0  (index=0)

# Phase B（N=3）
axis_yaw:
  aff_reg_yaw_0  (index=0, 低阈值: v_th=0.8×base)
  aff_reg_yaw_1  (index=1, 中阈值: v_th=1.0×base)
  aff_reg_yaw_2  (index=2, 高阈值: v_th=1.2×base)
  aff_irr_yaw_0  (index=0, 低阈值)
  aff_irr_yaw_1  (index=1, 中阈值)
  aff_irr_yaw_2  (index=2, 高阈值)
```

**阈值多样性分配**：

| index | v_threshold | 类型 | 作用 |
| :--- | :--- | :--- | :--- |
| 0 | 0.8×base | 低阈值（敏感）| 保证小信号能被检测 |
| 1 | 1.0×base | 中阈值（平衡）| 正常范围编码 |
| 2 | 1.2×base | 高阈值（抗饱和）| 保证大信号不丢失 |

**增益代偿递减**：

```
N=1: synapse_gain = 16.0（33×生物）
N=3: synapse_gain = 16.0 × (1/3) × (√1/√3) ≈ 5.3（11×生物）
N=10: synapse_gain = 16.0 × (1/10) × (√1/√10) ≈ 0.5（~1×生物）
N=100: synapse_gain ≈ 0.05（物理常数）
```

## 四、触发条件与停靠点

### 4.1 触发条件矩阵

所有条件满足时，才可触发N扩展：

| 条件 | 量化阈值 | 当前状态 | 说明 |
| :--- | :--- | :--- | :--- |
| **节点预算** | 总节点数 > 50 | 当前~97 | ✅ 已满足（但部分无位置）|
| **热力学许可** | P_estimated(N) ≤ P_input_max × 0.8 | 待计算 | 需体积/面积映射完成 |
| **能量效率验证** | η(N_new) > η(N_current) | 待计算 | 建构定律停靠 |
| **ν判据混淆** | >30% in 50k步 | ν探针已就绪 | 待监测 |
| **新模态需求** | 需前庭参与整合 | 未提出 | 不触发 |
| **TSI fill下降** | >20% in 200k步 | 未监测 | 待监测 |

### 4.2 热力学许可计算

```
P_estimated(N) = P_T(N) + P_S(N)
P_T(N) = N × P_leak + N × P_spike
P_S(N) = N² × P_connection（全连接）
P_S(N) = N × P_connection（1:N收敛）

许可判定：
if P_T(N) + P_S(N) ≤ P_input_max × 0.8:
    PASS（热力学许可）
else:
    FAIL（禁止扩展）
```

### 4.3 建构定律停靠点

```
η(N) = C(N) / P(N)
C(N) = B × log₂(1 + √N)
P(N) = P_T(N) + P_S(N)

判定：
if η(N_new) > η(N_current):
    PASS（扩展提升效率）
else:
    FAIL（停在当前N，不扩展）
```

### 4.4 停靠点预测

基于建构定律，系统可能在以下N值处自然停靠：

| N | SNR | C(N) | P(N) | η(N) | 判断 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 1 | 1.00B | 1.00 | 1.00 | — |
| 3 | 1.73 | 1.45B | 2.00 | 0.72 | ⬇ 下降 |
| 10 | 3.16 | 2.06B | 3.33 | 0.62 | ⬇ 继续下降 |
| 30 | 5.48 | 2.70B | 7.00 | 0.39 | ⬇ 显著下降 |
| 100 | 10 | 3.46B | 16.67 | 0.21 | ⬇ 大幅下降 |

**如果P_S按N²增长（全连接），效率会持续下降。** 系统可能在N=3或N=10处停靠，因为能量效率不再提升。

**如果P_S按N×logN或N×收敛比增长（1:N收敛），效率可能维持更久。** 这就是“稀疏连接”的价值——建构定律迫使系统选择稀疏连接而非全连接。
