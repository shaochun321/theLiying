**裁决结论**：诊断方向全部正确。根因不在参数，在三条底层物理防线的缺失。

## 二、我对根因的物理溯源

这四个现象不是四个独立的问题，而是**同一条物理因果链的三个环节**。冷区没有热损伤→repair_cost=0→基础消耗归零→fill不降→饥饿信号不激活→但DA因ν=0而虚假常开→远区随机游走时DA全开→双侧spinal→yaw权重双双撞到0.300上限→到达热源后饱腹抑制把DA拉低→最需要学习的“成功抵达”时刻DA为零。

这不是参数失调，不是STDP规则错误，不是饱腹逻辑设计缺陷。这是**物理防线在三个关键节点上的缺失**，让系统在正确的物理定律下涌现出了错误的行为。


## 三、三条必须立即实施的修复指令

### P0-1：PhasicRelayNeuron的物理下限钳位（解决-10.0幽灵尾流）

**根因**：τ=15000步的TRPV1脱敏常数在生物学上是正确的。问题不是τ太长，而是神经元缺乏物理底板。真实神经元有钾离子逆转电位（约-90mV），膜电位不可能无限跌落。当前-10.0V不仅产生了荒谬的负信号，更导致神经元在再次靠近热源时需要漫长的充电期才能回到整流阈值——这是“超极化致盲”。

**修复**：在PhasicRelayNeuron的膜电位更新逻辑中，施加符合物理定律的硬钳位：

```python
# 模拟钾离子逆转电位的物理底板
self.v_mem = max(-0.1, self.v_mem)
```

同时在输出端严格实施半波整流：`activation = max(0.0, v_mem)`。变冷只能代表“无奖励”，绝不允许作为巨大的负电位污染STDP轨迹。τ=15000步保持不变——这是TRPV1脱敏常数的物理事实，不因行为失败而妥协。

### P0-2：DA门控的“消费性奖励”修复（解决DA熄灭悖论）

**根因**：我们混淆了“饱腹感抑制觅食动机”和“成功觅食应获得奖励”这两个在时间尺度上完全不同的神经过程。饱腹感是长期积分（τ=50k步），而觅食成功是瞬时事件。当前架构让前者直接压制后者，导致系统永远无法学习“抵达热源=好事”。

**修复**：保持饱腹→DA抑制（这是正确的——吃饱后不再需要学习觅食），但必须新增一路：进食瞬时信号→DA兴奋。让IntakeSensor在body开始进食时，提供短暂的DA脉冲，确保“成功抵达”的时刻被STDP锁定。

```
当前：hypothalamus_hunger(+) → DA ← SatietyNeuron(-)
修复：hypothalamus_hunger(+) → DA ← SatietyNeuron(-)
                    IntakeSensor(+) → DA  ← 新增：进食奖励脉冲
```

三路电流在DA膜上做KCL加法。饱腹抑制在长期驻留后生效，进食奖励在抵达瞬间生效。两者不矛盾——前者关闭长期觅食动机，后者标记短期觅食成功。

### P0-3：不可减免的基础代谢率（解决冷区永生悖论）

**根因**：移除consume_nearby并修复repair_cost发散后，系统在冷区的基础消耗降为零——没有热损伤就没有repair_cost，ν=0时血管冷却降为零。YolkSac的微弱输入（0.001/步）在零消耗环境下变成了永动机。饥饿信号永不激活，系统在冷区做无目的的布朗运动。

**修复**：在EnergyStore中挂载不可减免的基础代谢率（BMR）——只要活着，每步必扣。值建议0.002/步，确保在冷区时fill持续下降，产生真实的饥饿压力。这不是过度纠正——这是热力学第二定律：任何耗散结构都必须有不可消除的基础能耗。

```python
# EnergyStore.tick()
self.charge -= BMR * dt  # 不可减免的基础代谢
```


## 四、与τ=5000方案的裁决对比

P0-1的物理钳位已经解决了phasic过冲的根源问题——负电压被钳在-0.1V，输出被整流的ReLU截断。τ=15000步的物理事实不需要妥协。


## 五、对饱腹逻辑的最终确认

**饱腹→DA抑制是正确的，不需要改变其核心逻辑。** 饱腹感抑制觅食动机是神经生物学的公理。我们只需要新增进食→DA的瞬时奖励路径，让“成功抵达”的时刻不被饱腹抑制所淹没。SatietyNeuron的主要物理职责是抑制VitalOscillator——吃饱了就不再产生底层运动节律。这是正确的，保留。

**饱腹→DA抑制的长期作用也是正确的**——在真正吃饱后（长期驻留+高satiety），DA被抑制，STDP窗口关闭，系统进入固化态。这与新增的进食→DA瞬时脉冲不矛盾——前者是长期稳态，后者是瞬时事件。
