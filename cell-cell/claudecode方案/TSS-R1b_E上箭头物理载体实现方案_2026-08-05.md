## v1 否决记录（保留为失败反例，勿删）

v1 的 S1 步骤 4 规定："若门不导通 → 输出 0（抑制重复），**不再额外充电**"。

**这是错的，且是推导层面的错，不只是实现层面的错。**

该规定让门电压测量的是「距首次脉冲过去了多久」，而 E^↑ 需要的是
「距**最近一次**脉冲过去了多久」。持续发生中每 200 步来一枚脉冲、门恢复约
1200 步时，v1 会在簇中途自行开门，同一次持续发生被输出多个 b_α^↑：

```
t=0     首枚通过，充电 V_H
t=200~  重复脉冲被抑制，但不刷新 → 电容继续单调衰减
t=1204  电容跌破阈值，门自行打开（此时簇还在继续！）
t=1400  下一枚脉冲再次输出 b^↑  ← 错误：同一次发生输出了 2 次
```

v1 的 S2 不等式同样有缺口：只约束了「单次充电后经过一个 ISI_max 仍关门」
（`Q/C·exp(-ISI_max/τ) > v_th`），没有约束「经过整个簇长 T_burst 仍关门」。
实测簇长可达数千步 ≫ ISI_max=316 步，所以 v1 即使参数取在自己算出的区间内
也必然在 T-R1B 阶段失败。

v1 之所以写"不再充电"，是为了防「持续驱动下门永久锁死」（v1 风险 R1）。
那个风险是真的，但正确解法是**钳位**，不是拒绝充电——见下面 Q2。

## 强制三问（RULES.md）

### Q1 生物对应物

**首次进入产生脉冲 + 同一发生内抑制重复 + 每枚脉冲刷新抑制 + 抑制量有饱和上限
+ 静默后自动恢复** = 感觉神经元的 **spike-frequency adaptation / 阈值调适**，
其中"刷新 + 饱和"对应 Ca²⁺ 依赖 K⁺ 通道的**池饱和**特性：

- 每枚 spike → Ca²⁺ 内流 → Ca²⁺ 池充电（**每枚都充，不只第一枚**）
- 池容量有上限（缓冲蛋白饱和 / 泵-漏平衡）→ 抑制量不无限累积
- Ca²⁺ 被泵出 → 抑制按 τ = C·R 衰减 → 阈值恢复

REF（项目内既有引用链，不引入新生物声明）：
- `neuron.py:129` FatigueCapacitor 注释：`BIO: Na+ channel slow inactivation
  + Ca2+-dependent K+ channels`
- `compensation.py:211-247` CalciumRateIntegrator：`Circuit: Capacitor (Ca²⁺ pool)
  + MOSFET Zener clamp`、`Zener clamp at V_clamp prevents saturation`
- `occurrence.py:19-21` Q1：触发—退出—重新武装迟滞 = 阈值调适 / 不应期

**关键**：v1 引用 FatigueCapacitor 作唯一先例是不够的——FatigueCapacitor
**没有钳位**，持续发放下它靠"充电率 vs 泄漏率"达到率依赖稳态，恢复时间
取决于发放率。E^↑ 要求恢复时间与簇长/发放率**无关**，所以必须用
`CalciumRateIntegrator` 那条带 Zener 钳位的拓扑。这是评判修正的实质。

### Q2 物理结构

```
Sources                      载体                              Targets
───────────────────────────  ───────────────────────────────  ──────────────
collector（既有 Neuron,       _gate_cap : Capacitor            b_α^↑(t)
spiking=True, 产生 p_α(t),    _gate_fet : MOSFET（阈值判定）    （门通过的脉冲）
经 CollectorBoundaryPort      _clamp_fet: MOSFET（Zener 钳位）
读 spike_output）                    ↑
        │                            │
        └──── 每枚 spike 都充电 ──────┘（可重触发；钳位限幅在 V_H）
```

单步顺序（严格对齐 `neuron.py:481-516` FatigueCapacitor 的既有顺序：
先泄漏 → 再判定 → 再充电）：

```
1. _gate_cap.leak(r_leak, dt)                    # 恢复（RC 衰减）
2. V_g = _gate_cap.voltage                       # 读门电压（脉冲到来前的值）
3. gate_open = (_gate_fet.conduct(V_g) == 0.0)   # 阈值判定，交给 MOSFET
4. b_up = 1.0 if (is_spike and gate_open) else 0.0
5. if is_spike:                                  # ★ 无论是否输出，都刷新
       _gate_cap.charge += Q_spike * capacitance
       if _gate_cap.voltage > V_H:               # Zener 钳位（同 compensation.py:279-285）
           excess = _gate_cap.voltage - V_H
           heat += _clamp_fet.conduct(V_g) * excess * dt   # 钳位耗散，登记入热
           _gate_cap.discharge_to(V_H)           # 硬钳位到 V_H
6. return b_up
```

- **不新建 Neuron**：E^↑ 是对既有 collector 输出的门控，不是新细胞。
- **不新建 SynapticBundle**：spike-frequency adaptation 是同一细胞内的通道
  动力学（Ca²⁺-K⁺ 环），不经过突触。硬接一条 bundle 是错的建模。
- 无 `_phase` 枚举、无 `_silence_count`、无 `t_step` 参数——状态全在
  `Capacitor.charge` 里。`step()` 签名不含 `t_step` 本身即"无软件时钟"的
  结构性证据（可作断言，同 T-R1A-4 手法）。

### Q3 参数依据

评判指出：决定重新开门的不是 τ 单独，而是三者联合：

```
t_open = τ · ln(V_H / θ_g)          （从最后一枚脉冲起算的静默时长）
```

**三个参数全部取项目既有默认值，零自由参数**：

| 参数 | 值 | 来源（不是本轮新填的数字） |
|---|---|---|
| `V_H`（钳位电压） | 1.0 | `compensation.py:247` `CalciumRateIntegrator.v_clamp: float = 1.0` |
| `θ_g`（门阈值） | 0.3 | `semiconductor.py:130` `MOSFET.v_threshold: float = 0.3` |
| `τ = R·C` | 1.0 s（C=1.0, R=1.0） | collector 既有 AdEx 适应时间常数 `tau_w=1.0`（`variant_adapter.py:386`）；同一细胞的两个慢恢复过程都源自 Ca²⁺/离子泵动力学，时间尺度相近是生理自洽的 |
| `Q_spike` | 1.0 | 由"单枚 spike 必须直接饱和"反推：需 `Q_spike/C ≥ V_H` → 取等号。理由见下 |

代入：

```
t_open = 1.0 × ln(1.0 / 0.3) = 1.204 s = 1204 步（dt=0.001）
```

**验证落在实测分离带内**（EXP-R1A-01）：

```
簇内 ISI 上界      316 步  ─┐
                            ├─ 分离带，几何中位 √(316×4257) = 1160 步
真实退出间隔下界  4257 步  ─┘

t_open = 1204 步，与几何中位差 3.8%
```

三个既有默认值凑出的 t_open 自动落在分离带中位附近。这不是挑参数凑区间——
是先固定三个来源明确的值，再算出 t_open，然后验证它落在带内。

评判给出的两个资格不等式均满足：
```
V_H·exp(-0.316/τ) = exp(-0.316) = 0.729  > 0.3 = θ_g   ✓ 最大簇内间隔后仍关门
V_H·exp(-4.257/τ) = exp(-4.257) = 0.0142 < 0.3 = θ_g   ✓ 真实退出后已开门
```

**为什么必须单枚 spike 就饱和（Q_spike/C ≥ V_H）**

评判给的刷新式 `V_g ← min(V_g + ΔV, V_H)` 只在 `ΔV ≥ V_H` 时才等价于硬刷新。
若 `ΔV < V_H`：

```
孤立单枚 spike 后：V_g = ΔV   → t_open = τ·ln(ΔV/θ_g)      （较短）
长簇多枚 spike 后：V_g = V_H  → t_open = τ·ln(V_H/θ_g)     （较长）
```

恢复时间就变成**簇历史的函数**——同一段静默在不同前史下判定不同，违反
"同一持续发生只输出一次"的位置无关性，也无法跨站点共用一份参数。
所以必须 `Q_spike/C ≥ V_H`，取等号 1.0 最简。

此时"充电 + 钳位"在数值上等于硬刷新 `V_g ← V_H`，但**实现必须走充电+钳位
而不是直接赋值**——赋值是软件操作，充电+Zener 钳位是 `CalciumRateIntegrator`
已有的物理拓扑。这个区别属于资格本身，不是代码风格问题。

## 等价性判据的重新定义（评判"必须二选一"→ 选 2）

评判 `170306.100` 指出：参考检测器是双时钟（gap 500 + rearm 500 ≈ 1000 步静默），
物理门是单时钟一次跨阈，因此不能既要求 `b^↑_physical ≡ b^↑_reference`
又保留参考检测器的双时钟语义，必须二选一：

```
选项 1：给参考检测器增加单时钟 oracle 模式（如 rearm_min_steps=0）
选项 2：用显式脉冲序列资格测试验证单时钟语义，
        不把旧三态检测器作为逐步等价标准
```

**本方案选 2。** 理由是选项 1 也做不到逐步等价——本轮算出的三个开门阈值互不相同：

| 算子 | 重新开门所需静默（T-R1B-8 探测式实测值） |
|---|---|
| 参考检测器 `rearm=500`（R1a 冻结值） | 999 步 |
| 参考检测器 `rearm=0`（选项 1 的 oracle 模式） | 500 步 |
| 物理门（本方案，t_open = τ·ln(V_H/θ_g)） | 1204 步 |

（初稿曾手推为 501 / 1001，实测为 500 / 999。测试里已改为**实测**这两个值
而不是填写手推数字——手推数字没有依据就是 Q3 违规。）

三者都不相等。若强行让物理门逐步等价于任一 oracle，就必须把 τ 从
「501 或 1001 这个软件整数」反推出来——**用软件常数标定物理常数，因果方向
恰好倒过来**，与 R1a→R1b 整条主线（把软件规则落到物理载体）冲突。

**关键澄清（本轮独立复核发现，评判文档未提）**：物理门与两个 oracle 在实测流上
事件计数一致，但这是**数据集巧合，不是算子相等**。分歧区间为：

```
vs rearm=0  oracle：gap ∈ [500, 1204)   → oracle 输出新 b^↑，物理门抑制
vs rearm=500 oracle：gap ∈ [999, 1204)  → 同上

实测流的 gap 分布：簇内 ≤ 316 步，真实退出 ≥ 4257 步
                  → 没有任何 gap 落进上述任一区间 → 计数自然一致
```

（区间边界 500/999 为 T-R1B-8 探测式实测值，不是手推数字。）

这正是项目反复抓到过的那类错误（"在一条实测流上一致" 被当成 "算子相等"，
如 TSS-2b 的 Λ 资格）。所以：

- **计数一致只作旁证，不作资格判据**，且测试里必须显式断言
  "实测流无 gap 落在分歧区间"，把这个前提从隐含假设变成可验证条件。
- **资格判据用构造脉冲序列**，直接测评判列的 9 条（见 S3）。

附带结论：两个 oracle 变体（rearm=0 / rearm=500）在实测流上给出**相同**的
事件计数——即实测数据根本分辨不出第二个时钟做了什么。这是 R1b-3
"τ_rearm 是去抖动滤波器而非独立生理时钟" 的又一条独立旁证。

## 执行步骤

### S1 建立可重触发饱和 RC 门（评判改写版）

新建 `nexus_v1/relations/entry_gate.py`：

```
PhysicalEntryGate
  ├─ _gate_cap : Capacitor      # 抑制量载体（Ca²⁺ 池）
  ├─ _gate_fet : MOSFET         # 门阈值判定（v_threshold = θ_g）
  ├─ _clamp_fet: MOSFET         # Zener 钳位（同 CalciumRateIntegrator）
  └─ step(spike_output, dt) -> float    # 返回 b_α^↑(t)
```

`step()` 严格按 Q2 的 6 步顺序。三条相对 v1 的硬性改动：

1. **每枚 spike 都刷新**（不管是否输出 b^↑）——v1 的"不充电"被否决
2. **刷新必须有物理上限**（Zener 钳位到 V_H），不得无限累加
3. 判定用**脉冲到来前**的 V_g（即步骤 1 泄漏后、步骤 5 充电前的值）——
   顺序错了会让同一枚 spike 自己关自己的门

另需一个 `heat` 累计量（钳位耗散），供能量账本查询；E^↑ 是旁路，
不接入主 KCL 环，但耗散量要可读出（同 `CalciumRateIntegrator.update()`
返回 `heat_clamp` 的既有做法）。

## 风险与对应

**R1（改写）：持续驱动下门永久锁死。**
v1 用"被抑制的 spike 不充电"来防这个，被评判否决（那会导致簇中途自行开门）。
正确解法是 **Zener 钳位**：V_g 永不超过 V_H，所以末枚 spike 后恒定从 V_H 起衰减，
恢复时间 = t_open 与簇长/发放率无关。
→ 守卫：T-R1B-5（5000 步满占空比驱动后仍在 ≈1204 步恢复）。

**R2：`_w_adapt` 与门电压混同。**
collector 既有 AdEx 适应电流（`b_adapt=0.01, tau_w=1.0`）抑制的是 **collector
自身发放**，E^↑ 门抑制的是**门的输出**。两者时间常数同量级（这是 Q3 选 τ=1.0
的旁证），但物理位置不同，不能互相替代或复用同一状态变量。
→ 守卫：`PhysicalEntryGate` 用独立 `Capacitor`，不读不写
`neuron._w_adapt` / `neuron._fatigue_cap`；T-R1B-1 断言这一点。

**R3：顺手改 `occurrence.py` 会引入不可控回归。**

**R5（新增，本轮独立发现）：`MOSFET.conduct()` 阈下分支的注释与实现不一致。**
`semiconductor.py:151-159` 注释承诺阈下有指数尾流（"physical drain current =
