### 1.1 T-061 前庭消融的实现细节

**关键发现**：在当前实现中，`mechanical_inputs['yaw/pitch/roll']` 从未被写入（体角速度不反馈进 mechanical_inputs）。真实前庭信号是：
```
mechanical_inputs['oto_x/y/z'] = body.acceleration × 500 + Langevin噪声 × 500
```
这在 `variant_adapter.step()` 第1475行内部计算，不在外部 `mechanical_inputs` 字典中。

**正确的消融实现**（不改母本代码）：
```python
def step_ablated(c, alpha=0.02, dt=1.0):
    """前庭消融：缩放体加速度，仅影响 oto 信号，不影响热感信号"""
    body = c.world.body
    real_acc = list(body.acceleration)
    body.acceleration = [a * alpha for a in real_acc]
    c.step({}, dt)
    body.acceleration = real_acc  # 还原
```
这不触及 `body.angular_velocity`（已由 `apply_yaw_torque` 正常驱动），只缩放线加速度信号到前庭耳石器官的通路。

**需在实验脚本中确认**：`body.acceleration` 是否可直接赋值（属性 vs 属性 setter）。如果是只读属性，需用 `body._acceleration = ...`。

2. **多热源动态生态系统（阶段5）正确推迟**：仅保留物理驱逐（T-065，热源瞬移），避免了 HeatSource 架构修改
3. **L2 三维设计逻辑自洽**：L2a（过渡期权重分化）+ L2b（方向选择统计）+ L2c（能量-学习耦合效率）互补覆盖

### 2.2 一项中等风险：L2a 在快速归巢场景下可能失效

**风险描述：**
- L2a 定义：`max|Δw|` 在步骤 `t ∈ [0, 20000]`，通过标准 `> 0.15`
- T-059 全程跑数据：step 10k 时 `|Δw| = 0.0022`（body 已抵达中心，两束对称激活）
- T-058 20k 诊断跑数据：step 10k 时 `|Δw| = 0.283`（同配置，不同 CPG 随机相位）

**根因分析：**

L2a 能否 PASS 依赖 body 是否在抵达热源中心**之前**完成权重分化。T-059 显示 body 可在 10k 步内就抵达中心，此时 |Δw| 仍接近0。T-058 诊断跑则在同样步数内维持较大的 |Δw|。

这两次结果的差异来源于：
- T-059 全程跑：CPG 初始相位不同 → 运动轨迹不同 → 抵达时间和左右激活对称性不同
- T-059 中 body 几乎沿 x 轴直线冲到热源（dist 从60 → 0.4），前期 L/R patch 温差极小

**风险量化：**
- T-058 诊断：同配置跑了一次，|Δw|@10k = 0.283（✅）
- T-059 全程：同配置跑了一次，|Δw|@10k = 0.0022（❌ L2a）
- 两次结果截然相反，说明 L2a 对 CPG 随机初相位的依赖性高

**建议处理方式（三选一，优先级由高到低）：**

| 选项 | 操作 | 优点 | 缺点 |
|:---|:---|:---|:---|
| **A（推荐）** | L2a 改为在 Foraging 窗口内测量：`max|Δw|` 仅在 `fill<0.85 AND DA>0.1` 步数中取最大值 | 与 L2b/L2c 逻辑一致，抗快速归巢场景 | 需改实验脚本逻辑 |
| B | 延长 L2a 测量范围至全程200k，但去除 `> 0.15` 要求，改为"是否曾出现 `>0.1` 的窗口" | 捕获"重新学习"中的权重分化 | 判据变弱 |
| C | 保留原方案，如 T-060 中 L2a FAIL 则改为选项 A | 先用原方案，失败再调整 | 增加一轮迭代 |

**推荐选项 A**：将 L2a 改为 Foraging 窗口内的峰值分化度，与 L2b/L2c 的窗口定义保持一致，从逻辑上更自洽。

## 四、新指标实现规格

### L2a（修订版，Foraging 窗口内峰值分化度）

```python
dw_peak_foraging = 0.0
for step in range(total_steps):
    # ... 运行电路 ...
    w_ccw, w_cw = get_yaw_weights(c)
    if fill < 0.85 and da > 0.1:  # foraging 窗口
        dw = abs(w_ccw - w_cw)
        dw_peak_foraging = max(dw_peak_foraging, dw)

# L2a 通过：dw_peak_foraging > 0.15
```

### L2b（DSI，方向选择指数）

```python
ccw_buf, cw_buf = [], []
dsi_peak = 0.0
W = 5000
eps = 1e-6

for step in range(total_steps):
    if fill < 0.85 and da > 0.1:  # foraging 窗口
        ccw_buf.append(c.spinal_ccw.activation)
        cw_buf.append(c.spinal_cw.activation)
        if len(ccw_buf) >= W:
            net = [a - b for a, b in zip(ccw_buf[-W:], cw_buf[-W:])]
            integral = abs(sum(net))
            mean = sum(net) / len(net)
            sigma = (sum((x - mean)**2 for x in net) / len(net)) ** 0.5
            dsi = integral / (sigma * (len(net)**0.5) + eps)
            dsi_peak = max(dsi_peak, dsi)

# L2b 通过：dsi_peak > 1.0
```

### L2c（能量-学习耦合效率）

```python
foraging_steps = sum(1 for f, d in zip(fill_history, da_history) 
                     if f < 0.85 and d > 0.1)
eta = foraging_steps / total_steps

# L2c 通过：eta > 0.08（T-060 短程基线；T-062 验收标准）
```
