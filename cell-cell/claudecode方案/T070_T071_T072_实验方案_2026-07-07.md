## T-071：T-068 STDP断路诊断

**前提**：T-070 η≥15% PASS 后执行  
**脚本**：待创建 `nexus_v1/tests/exp_T071_stdp_circuit_trace.py`  
**步数**：50k  

**核心问题**：STDP权重变化真实存在（|Δw|=0.2965），但DR5=50%（随机基线）。断路在哪？

**测量方案**：每100步采样以下信号链各节点电流/激活值：

```
phasic_left.activation          ← D1束输入端
spinal_ccw.activation           ← D1束输出端
I_d1_to_spinal_ccw              ← bundle_d1_phasic_left_to_spinal_ccw.propagate()[0]
I_spinal_to_yaw_ccw             ← bundle_spinal_ccw_to_yaw.propagate()[0]（若存在）
I_relay_to_yaw_ccw              ← 对照：relay→yaw直接通路电流
yaw_ccw_neuron.activation       ← yaw层激活
motor_ccw.activation            ← Motor层激活
body.angular_velocity           ← 最终行为输出
```

**断路假说与判定**：

| 假说 | 判据 | 断路位置 |
|------|------|---------|
| H-A | spinal_ccw≈0 即使 phasic_L>0 | D1束增益不足 |
| H-B | I_spinal_to_yaw << I_relay_to_yaw（>10×） | relay主导，spinal被压制 |
| H-C | yaw_ccw≈0 即使 I_spinal_to_yaw>0 | spinal→yaw阈值过高 |
| H-D | motor_ccw≈0 即使 yaw_ccw>0 | yaw→Motor传导弱 |

**预期**：最可能是 H-B（relay→yaw直接通路压过spinal贡献10×以上）。

**输出**：各节点时序数据CSV + 断路位置结论报告

## T-072：T-069 热源消失多周期实验

**前提**：T-070 PASS 后执行（需要η≥15%以确保fill能周期性下降）  
**脚本**：待创建 `nexus_v1/tests/exp_T072_heat_source_vanish.py`  
**步数**：200k（三周期）  

**实验流程**：

```
Phase 1 (0~50k):   正常运行，等待fill饱和 → 记录第一次STDP权重分化
Phase 2 (50k触发): src.energy = 0 / src.temperature = 0（热源耗尽）
Phase 3 (50k~80k): fill下降（BMR=0.003），Foraging窗口重新开放
Phase 4 (80k~150k): body再次找到新热源（REGEN_PROB=0.001），第二次STDP
Phase 5 (150k触发): 第二次热源耗尽（可选，测试第三周期）
Phase 6 (150k~200k): 第三次Foraging
```

**判定标准**：

| 指标 | 阈值 | 含义 |
|------|------|------|
| η_total ≥ 20% | PASS | 多周期窗口总量 |
| \|Δw\|_cycle2 > \|Δw\|_cycle1 | PASS | 跨周期学习累积 |
| T_relocate2 < T_relocate1 × 0.8 | PASS | 第二次找源更快（学习迁移） |
| w_ccw > 0.20 最终 | PASS | STDP方向收敛 |

**关键观测**：
- 热源消失后权重在fill饱和期的保留率（LTD侵蚀速率）
- 第二次Foraging窗口开放时，已有权重是否加速分化（迁移学习）
- 多周期后w_ccw/w_cw是否逐渐稳定收敛
