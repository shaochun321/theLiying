## 一、架构概述

```
体验饥饿 / 低 fill                             [已存在]
    ↓ bundle_hunger_to_da（已存在）
DA 门控打开（STDP 学习窗口）                    [已存在]

随机运动 → 碰到热源 → phasic dT/dt             [D1 已验证]
    ↓ spinal_turn_toward STDP（D1）
接近热源 → 能量摄入 + fill 回升

─── 新建：饱腹信号采集 ─────────────────────────
intake_sensor_neuron （摄食速率换能）
fill_rate_sensor_neuron（能量回升速率换能）
dwell_sensor_neuron   （驻留时间积分）
    ↓ 三路 KCL 叠加
satiety_neuron（τ=50k步，float64）

─── 新建：饱腹信号输出 ─────────────────────────
SatietyNeuron → [sg=-1.0] → VitalOscillator amplitude_mod（抑制运动）
SatietyNeuron → [sg=-1.0] → DA 神经元（关闭 STDP 学习窗口）

行为结果：吃饱 → 驻留静止 + STDP 冻结 → 能量消耗降低 → fill 回升
```

## 三、新建组件规格

### 3.1 IntakeSensorNeuron（摄食速率换能）

**Q1 BIO：** 肠道 CCK / GLP-1 释放神经元（迷走传入，营养吸收率→饱腹感）  
**REF：** Berthoud 2008 Physiol Behav 94:681-692

**Q2 物理结构：**
```
self._v_feed (FeedRateCapacitor 电压) → intake_sensor_neuron.step(v_feed, dt)
    [HC-009 类型换能：Capacitor 域→神经元域边界]
    → bundle_intake_to_satiety (frozen, sg=+1.0, w=1.0) → satiety_neuron
```

**Q3 参数：**
| 参数 | 值 | 来源 |
|------|------|------|
| C | 1.0 | 快速响应（τ=R×C=1×1=1s=1000步）|
| R (r_leak) | 1.0 | 快速衰减（无摄食时信号迅速清零）|
| w (bundle) | 1.0 | 初始等权 |

**换能量纲：**  
进食时 `_v_feed` ≈ 1.0V（已在脆弱点3中标定，deposit_rate≈2e-4 → V_ss=1.0）  
IntakeSensorNeuron 稳态 V ≈ 1.0V → activation ≈ 1.0（v_peak 默认）

---

### 3.2 FillRateSensorNeuron（能量回升速率换能）

**Q1 BIO：** 肝门静脉葡萄糖传感（迷走传入），感知血糖回升速率→ 饱腹确认  
**REF：** Schmitt 2005 Cell Metab 1:63-72

**Q2 物理结构：**
```
_rpe_da (da_gate.step 输出，仅正值，表示 fill 回升速率)
    → fill_rate_sensor_neuron.step(_rpe_da, dt)   [换能边界]
    → bundle_fillrate_to_satiety (frozen, sg=+1.0, w=1.0) → satiety_neuron
```

**Q3 参数：**
| 参数 | 值 | 来源 |
|------|------|------|
| C | 5.0 | 适度平滑（τ=5s）|
| R (r_leak) | 1.0 | 配合 C=5 → τ=5000步 |

`_rpe_da` 量级参考：fill 从 0 升至 1 需要摄食能量，速率约 1e-3/步，经 da_gate 放大后约 0.01~0.1 量级（实际值需首次实验后校准权重）。

---

### 3.3 DwellSensorNeuron（驻留时间积分）

**Q1 BIO：** 海马时间细胞（time cells）+ 场所细胞（place cells）复合体；  
感知"在热源处持续停留时间 > 阈值"→ 饱腹触发  
**REF：** MacDonald et al. 2011 Science 333:595-599

**Q2 物理结构：**
```
bc_current (偏置电流，持续微小充电 = 时钟滴答)
    → dwell_sensor_neuron (大电容，缓慢积分)
phasic_left / phasic_right
    → bundle_phasic_to_dwell (frozen, sg=-RESET_GAIN, w=1.0)
    → dwell_sensor_neuron (移动时快速放电/重置)
dwell_sensor_neuron 电压超过 v_threshold → 向 satiety_neuron 传递信号
```

**Q3 参数（推导）：**

目标：稳定驻留 20k 步（20 秒）后达到阈值。

- `C = 1.0, R (r_leak) = 50.0` → τ = RC = 50s = 50000步
- `bc_current = 1.0/50 = 0.02` → V_ss = bc × R = 0.02 × 50 = 1.0V（超过阈值）
- 达阈值 0.5V 的时间：t = τ × ln(2) ≈ 0.693 × 50000 = 34650步 ≈ 35秒

放电参数（phasic → dwell 重置）：
- phasic 激活量级预计约 0.001~0.01（D1 实验中未直接测量，首次实验后校准）
- `sg = -200.0`：放电电流 ≈ phasic_act × 200，覆盖充电电流 bc=0.02（100倍安全边距）

⚠️ **首次实验后必须校准 sg 值：** 若 DwellSensor 在接近期仍不放电（一直积满），降低 sg；若驻留 35k 步后仍未充满，升高 bc_current 或降低阈值。

---

### 3.4 SatietyNeuron（饱腹信号整合）

**Q1 BIO：** 弓状核 POMC 神经元 + NTS（孤束核）二级饱腹积分  
**REF：** Cowley et al. 2001 Nature 411:480-484

**Q2 物理结构：**
```
intake_sensor → bundle_intake_to_satiety (frozen, sg=+1.0, w=1.0) → satiety
fillrate_sensor → bundle_fillrate_to_satiety (frozen, sg=+1.0, w=0.5) → satiety
dwell_sensor → bundle_dwell_to_satiety (frozen, sg=+1.0, w=0.3) → satiety
hypothalamus_hunger → bundle_hunger_to_satiety (frozen, sg=-1.0, w=0.5) → satiety
  （饥饿信号负向压制饱腹：饿着时不能触发饱腹）
satiety → bundle_satiety_to_vital (frozen, sg=-1.0, w=0.5) → VitalOscillator deviation_mod
satiety → bundle_satiety_to_da (frozen, sg=-1.0, w=0.3) → all DA neurons
```

**Q3 参数：**
| 参数 | 值 | 来源 |
|------|------|------|
| C | 50.0 | float64！τ=RC=50×50=2500s 太长，改为 C=50, R=1.0 → τ=50s=50k步 |
| R (r_leak) | 1.0 | — |
| dtype | float64 | τ=50k步 × dt=0.001=50s，exp(-0.001/50)≈0.99998，避免浮点侵蚀 |

**浮点防护（τ=50k步）：**
- Python 内建 float = float64，Capacitor.charge 为 float64，默认安全
- 每步 ΔV_bc ≥ 1e-6V 检查（若输入均为 0 则 ΔV=0，无下溢风险）
- 不需要额外 dtype 声明（原方案的 float64 担忧适用于 numpy 数组，此处不涉及）

## 四、KCL 时序对齐（工程锁定）

SatietyNeuron 接收三路 Bundle。正确的时序：

```python
# 正确：在 _propagate_bundles() 中同一批次累加
_I_sat = 0.0
for _b in [bundle_intake_to_satiety, bundle_fillrate_to_satiety,
           bundle_dwell_to_satiety, bundle_hunger_to_satiety]:
    if _b is not None:
        _cur = _b.propagate()
        if _cur:
            _I_sat += _cur[0]   # satiety_neuron 是单目标
# 然后统一更新
self.satiety_neuron.step(_I_sat, dt)
```

禁止：逐 Bundle propagate 后立即 step（半显式积分误差）。  
注：SatietyNeuron 的 3 个输入 Bundle + 1 个 hunger 抑制 Bundle 应在同一批次处理。
