## 一、评判结论

原方案结构正确，核心逻辑可直接执行。以下逐项分析分歧与补充。

### 1.1 诈胡验证设计 ✅ 接受

原方案最重要的贡献是把诈胡验证放在最高优先级。T-043 是 frozen 差分放大器——它会无条件将 spinal 的激活差异注入 yaw，在没有 STDP 的情况下也会放大任何来自 CPG 或 D1 phasic 系统的不对称信号。55% 阈值合理（T-039 D1 消融基线 = 50%，5% 安全边际覆盖热场边缘效应）。

**唯一技术补充：** STDP 冻结需明确覆盖所有相关字段。bundle 有三类：
- `learning_rule="frozen"` → 已冻结，无需操作（T-043/T-047等）
- `learning_rule="stdp"` → 设 `stdp_lr=0.0`
- `learning_rule="stdp_eligibility"` → 设 `stdp_lr=0.0` + `eligibility_gain=0.0`

需要在冻结后打印"已解冻 N 条 bundle"以便核查完整性。

### 1.2 诈胡失败分支 ⚠️ 补充中间场景

原方案仅覆盖两个端点（T-043 消融后 DR5→60% 或 DR5→50%），未定义 52-58% 区间的处置。

**我的补充：**

| T-043 消融后 DR5 | 含义 | 处置 |
|-----------------|------|------|
| > 60% | T-043 之外还有硬连线方向源 | 查 D1 phasic 非对称性，回到全冻结排查 |
| 55-60% | T-043 放大效果显著但非唯一来源 | 接受T-043，缩小 W_CROSS（0.020→0.010）后重跑 |
| 50-55% | T-043 是主要方向来源 | 重新评估 T-043 架构（见下文备注） |
| ≤ 50% | T-043 贡献可忽略，其他因素是来源 | 检查 CPG 相位/D1 phasic 初始化 |

**备注**：T-043 "创造方向性"（DR5=50% after ablation）不一定是坏事——它意味着 STDP 学习后 spinal 权重的不对称直接传导到 yaw。这需要区分 STDP 建立的不对称（合法）vs 初始化不对称（问题）。

### 1.3 两阶段 Phase 1 设计 ✅ 接受，补充监控字段

原方案的冷区验证目标正确。需确认以下字段可读：

| 指标 | 访问路径 | 已验证 |
|------|----------|--------|
| fill | `c.energy_store.fill_fraction` | ✅ T-034/T-036 已用 |
| hunger EMA | `c._hunger_ema` | ✅ T-048 实现时确认 |
| DA concentration | `c.dopamine.concentration` | ✅ 多次实验已用 |
| phasic activation | `c.phasic_left.activation`, `c.phasic_right.activation` | ✅ |

验收标准补充：phasic 信号检查应改为"phasic_left + phasic_right < 0.01（钳位生效）"，而非 phasic ≈ 0（可能有基线泄露）。

### 1.4 两阶段 Phase 2 起始位置 ⚠️ 建议修改

原方案：body=[10,50,25]，热源=[70,50,25]，距离=60，热场半径=30。  
→ body 起始时在热场**外 30 个单位**，需要运动才能进入热场。  
→ 20k 步内能否进入热场取决于 motor 速度，从 T-036 观察体感速度约 0.001-0.01 m/步，30 单位需 3k-30k 步，有不确定性。

**建议：** body 起始位置改为 [40,50,25]（距热源 30，恰好在热场边缘）。首步即开始接收热觉信号，20k 步学习窗口利用充分。

### 1.5 200k 长程验收 ✅ 接受

T4.1 ≥ 3.0× 在 T-037 修复后稳定（T-041 验证 3.65×→5.56×），是合理的长程保底线。DR5 > 60% 与 T-041（T-044=76.5%）匹配。

## 三、T-054 诈胡验证脚本设计

```python
# exp_T054_fraud_validation.py
# 诈胡验证：冻结所有 STDP，检查 DR5 是否仍 > 55%

STEPS = 50_000
DT = 1.0

def freeze_all_stdp(circuit):
    """冻结全部可学习 bundle，返回解冻数量供审计。"""
    count = 0
    for b in circuit.get_all_bundles():
        if b.config.learning_rule not in ("frozen",):
            b.config.stdp_lr = 0.0
            if hasattr(b.config, 'eligibility_gain'):
                b.config.eligibility_gain = 0.0
            count += 1
    return count

def get_dr5(c):
    """patch 温差 · body 速度 > 0 （正确 post-P0 指标）"""
    pT = c._patch_temps if hasattr(c, '_patch_temps') else {}
    T = {pid: pT.get(pid, (0.0,))[0] for pid in ['front', 'back', 'left', 'right']}
    vx = c.world.body.velocity[0] if hasattr(c.world.body, 'velocity') else 0.0
    vy = c.world.body.velocity[1] if hasattr(c.world.body, 'velocity') else 0.0
    gx = T.get('right', 0) - T.get('left', 0)
    gy = T.get('front', 0) - T.get('back', 0)
    return (gx * vx + gy * vy) > 0

# 验收：
# DR5 ≤ 55%（≈50% 随机基线）→ PASS，方向来自 STDP，不是硬连线
# DR5 > 55% → FAIL，进入 T-054b T-043 消融验证
```

**关键检查点：**
- 打印 `已冻结 N 条 bundle`（期望值 ≈ 20-30 条 STDP 束）
- 打印 T-043 束权重（应不变，因为 T-043 是 frozen，不受上述操作影响）
- 每 5k 步报告 DR5% 瞬时值

**期望结果：** DR5 ≈ 50%（类 T-039 D1 消融结果）
