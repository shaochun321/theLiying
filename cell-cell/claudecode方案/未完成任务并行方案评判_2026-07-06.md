### P1-G：状态依赖增益调制（饥饿敏化）

**代码现实**：  
- `energy_store.fill_fraction`：在VariantCircuit中可直接读取
- relay neuron的r_leak：通过`relay.config.r_leak`访问
- 动态修改：在每步`relay.step(input, dt)`前更新`relay.config.r_leak`

**实施路径**：
```python
# 在 VariantCircuit.__init__ 中：
self._hunger_ema = 0.0   # 平滑后的饥饿值

# 在步进循环中（每步）：
hunger_raw = max(0.0, 1.0 - self.energy_store.fill_fraction)
self._hunger_ema += (hunger_raw - self._hunger_ema) / 1000.0   # τ=1000步EMA
effective_gain = min(1.5, 1.0 + 0.5 * self._hunger_ema)
for relay_n in self.relay_neurons:
    relay_n.config.r_leak = relay_n._base_r_leak * effective_gain
```

需要在`__init__`中保存`_base_r_leak`快照（一次性记录初始值）。

**评判**：生物学强（orexin K2P机制，非突触电流），物理合法（r_leak修改不增加功耗），实施简洁。**在T-043完成后立即实施，与P0-B并行。**
