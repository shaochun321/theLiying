## Context（为什么做）

已有的"量子元"（quantum meta-unit）结构——1个连续源 → 10神经元阶梯偏置温度计（ensemble）→ 1个AND门collector——目前只用在前庭 6 轴×正负 12 条链路上（详见 `工程报告-量子元链路分离实施_2026-07-09.md`）。用户希望把同一套"结构生成元"应用到感温链路，但**不是简单照搬 12-patch 体感系统**，而是提出了一个更根本的构想：

> "生成元应该放置到皮肤中，我们用一个三维球体网络层外皮，让生成元以序列形式分布在网络层中，接收点源梯度，后续才是耦合成空间梯度场。"

即：本次范围**只做**——在皮肤（球面）上用公式生成 N 个位置点，每个点独立放一套量子元生成元，把该点的局部温度变化率(dT/dt)量子化为离散事件；**不做**跨点耦合、不做空间梯度场重建（用户原话："现在不是处理温感和方向性的耦合"）。范围边界与前庭一致：只打通到 collector 为止，不接 Body/Motor，不做 WTA，不加学习。

**关键调查结论**（已完整核实代码）：
1. `world.temperature_at(pos)`（`world.py:553`）已支持**任意 3D 坐标查询**，`SkinPatch`（`world.py:97-253`）已实现带热惯性的 Newton 冷却物理积分器（非理想温度计），`.dT` 属性就是"局部点源温度变化率"——**这两者可直接复用，无需新建**。
2. 全项目**没有**球面均匀点生成算法（Fibonacci sphere / icosphere 等），12-patch 的坐标是手写三元组——**这是唯一需要新建的几何基础设施**。
3. 量子元的批量实例化模式（`_QUANTUM_DIRECTIONS` 12项表 + for循环 + list-comp 生成10神经元）与本次需求**完全同构**，且现有的 `_quantum_ensemble_config`/`_quantum_collector_config` 工厂函数已经是通用签名（label/k/region/position），**可直接复用，无需重写**。
4. 温度是单极物理量，但**温度变化 dT/dt 带符号**（用户已确认量子化对象为 dT/dt）。感温链路已有 `ThermalDeltaNeuron`（`somatosensory/transducer_neurons.py:252`）：`activation = max(0, dT_raw × 200)`，MOSFET 半波整流。这个类本身不专属于某个 patch——**同一个类喂 `+dT` 得"升温方向"，喂 `-dT` 得"降温方向"**，与前庭 antimet 的整流手法完全同构，**零新增类代码**。
5. 现有 12-patch 体感系统（`SomatosensoryChain`）依赖 `body.skin_patches` 这个固定列表——**本次新建的球面网络必须完全独立于 `body.skin_patches`**（不修改、不注入），避免破坏既有系统（这也是已知的"两套并行系统"惯例的延续，见 `分析报告-赫布超图底座与影子层构建_2026-07-11.md` 感温部分）。

## 设计（强制三问）

### Q1 生物对应物
- 球面上 N 个点 = 皮肤表面均匀分布的游离神经末梢感受野（free nerve ending receptive fields），密度化的皮肤热感受器群，类比 `ThermalDeltaNeuron` 现有注释"Type II AMH (A-δ) fibers at skin surface"（Norris 2021; LaMotte & Campbell 1978）。
- 每点的"升温/降温"双通道 = 该感受野内 warm-onset 与 cool-onset 两类纤维亚群（生物上确有独立的 warm/cold 感受器类型，如 TRPM8 冷感受器 vs TRPV3/4 温感受器，链路上已用 `ThermalInputNeuron`/`NociInputNeuron` 体现类似分化）。
- ensemble(10)+collector = 与前庭同构：脊髓/脑干中间神经元群体编码（population vector coding，Georgopoulos 1986）。
- **地址**：region 建议为 `REGION_SPINAL`（0x01）——皮肤游离神经末梢→背根神经节→脊髓背角是外周初级传入的解剖真实路径，区别于前庭量子元的 `REGION_BRAINSTEM`（前庭核在脑干，而皮肤温觉初级传入在脊髓背角，与既有 `soma_proj` 神经元的 `REGION_SPINAL` 归类一致）。

### Q2 物理结构
```
球面 N 个点（Fibonacci sphere 公式生成，非手写）
  │
  ├─ 每点独立 SkinPatch 实例（复用 world.py 现有类，与 body.skin_patches 完全隔离）
  │     .sample(world, body, dt) → (T, dT)
  │
  ├─ 升温源：ThermalDeltaNeuron(patch_id=f"therm_pt{i}", position=pt) 喂 +dT
  ├─ 降温源：ThermalDeltaNeuron(patch_id=f"therm_pt{i}_cool", position=pt) 喂 −dT
  │     （同一类，整流由 max(0,...) 天然涌现，无 if/sign 新增）
  │
  ├─ [frozen bundle, sg=+1] → ensemble_warm(10, 阶梯偏置温度计) → [frozen] → collector_warm(AND门)
  └─ [frozen bundle, sg=+1] → ensemble_cool(10, 阶梯偏置温度计) → [frozen] → collector_cool(AND门)
```
每点 2 个"方向"（warm/cool），完全独立、互不连接（不做跨点/跨方向耦合，遵守用户范围边界）。

**复用**：`_quantum_ensemble_config(label, k, region, position)` / `_quantum_collector_config(label, region, position)`——这两个工厂函数已在 2026-07-09 的地址化工作中改造为通用签名，直接传入 `label=f"therm_pt{i}_warm"` 等即可，**不新增工厂函数**。

**新增**（唯一新代码）：
1. `fibonacci_sphere_points(n, radius)` — 纯几何函数，新文件 `nexus_v1/components/skin_network.py`（TYPE:MATH），黄金角螺旋算法：
   ```python
   golden_angle = math.pi * (3 - math.sqrt(5))
   for i in range(n):
       z = 1 - 2*(i + 0.5)/n
       r_xy = math.sqrt(max(0.0, 1 - z*z))
       theta = i * golden_angle
       yield (radius*r_xy*cos(theta), radius*r_xy*sin(theta), radius*z)
   ```
   这是标准的球面近均匀分布算法（非任意选择），对任意 N 都成立，O(N)，不像经纬度网格两极过密。
2. `_init_quantum_thermal_pathways(self)` / `_step_quantum_thermal_pathways(self, world, body, dt)`（`variant_adapter.py`，仿照 `_init_quantum_pathways`/`_step_quantum_pathways` 的既有模式）。

### Q3 参数依据
- **N（点数）**：建议 `N_THERMAL_POINTS = 32`，Fibonacci sphere 公式生成（非拍脑袋常数，是"多大密度算合理网络"的工程折衷——数值非重点，后续可调，结构（公式生成、非手写）才是重点）。
- **半径**：复用现有 patch 的量级 `R=2.0`（与 `_default_skin_patches` 的 `effective_radius=2.0` 同量级，几何一致）。
- **_Q_BIAS_STEP / _Q_INPUT_W0 等量子化参数**：**不可直接照搬前庭数值**（前庭校准锚点是 MET 峰值 0.32；`ThermalDeltaNeuron` 的峰值量级由现有代码注释"EXP-BASE-200K: warm approach dT≈0.00025/step → activation=0.05"提示约为 0.05，量级不同）。需要**新一轮校准**（同前庭当初"先测源峰值→反推 W0/bias_step"的流程），本方案先占位复用前庭公式结构，实现后先跑一段合成升温场景测出 `ThermalDeltaNeuron` 实际峰值，再反推 `_THERM_Q_INPUT_W0`/`_THERM_Q_BIAS_STEP`（同 `document-2026-07-09T213410` 的校准方法论）。
- **region=REGION_SPINAL**：复用已导入常量，零新参数。
- **position**：Fibonacci sphere 公式直接给出，非借用其他源坐标（比前庭量子元的"借用坐标"更干净——这是本次结构的天然优势）。

## 代码改动

**新文件**：`nexus_v1/components/skin_network.py` —— `fibonacci_sphere_points(n, radius)` 纯几何函数。

**唯一改动的电路文件**：`nexus_v1/circuit/variant_adapter.py`（与前庭量子元同一模式，新增独立方法，不碰母本/不碰 SomatosensoryChain/不碰 body.skin_patches）：

1. 模块级常量：`_THERM_Q_N_POINTS=32`（或最终校准值）、`_THERM_Q_N_ENSEMBLE=10`、`_THERM_Q_BIAS_STEP`/`_THERM_Q_INPUT_W0`/`_THERM_Q_COLLECT_THR`/`_THERM_Q_COLLECT_TAU_GATE`（待校准）。
2. `__init__` 末尾：
   ```python
   self._thermal_quantum_patches: list = []       # N 个独立 SkinPatch（与 body.skin_patches 隔离）
   self.thermal_quantum_warm = {}                  # point_id → ThermalDeltaNeuron(+dT)
   self.thermal_quantum_cool = {}                  # point_id → ThermalDeltaNeuron(-dT，同类复用)
   self.thermal_quantum_ensembles = {}             # f"{point_id}_{warm|cool}" → List[Neuron](10)
   self.thermal_quantum_collectors = {}
   self.bundles_thermal_quantum_in = []
   self.bundles_thermal_quantum_collect = []
   self._init_quantum_thermal_pathways()
   ```
3. `_init_quantum_thermal_pathways(self)`：仿照 `_init_quantum_pathways`（:1310起）——用 `fibonacci_sphere_points(N, R)` 生成坐标列表，逐点建 `SkinPatch` + 2 个 `ThermalDeltaNeuron`（warm/cool）+ 2 套（ensemble(10)+collector），bundle 全 frozen。
4. `_step_quantum_thermal_pathways(self, world, body, dt)`：仿照 `_step_quantum_pathways`——对每个独立 `SkinPatch` 调 `.sample(world, body, dt)` 拿 `(T, dT)`；warm 源喂 `+dT`，cool 源喂 `-dT`；传播 bundle、step ensemble/collector；frozen，不 learn/compute_xin。
5. `step()` 里 `super().step()` 之后调用。已确认 `world`/`body` 引用方式：`self.world.body`（`variant_adapter.py:1637` 现成用法 `self.world.body.sample_skin(self.world, dt)`）——故调用为 `self._step_quantum_thermal_pathways(self.world, self.world.body, dt)`。
6. census：**不加入** `get_all_neurons()`（同前庭量子元的 T4.1 保护理由——数量可能达数百，避免稀释 `energy_per_neuron`）；bundle **加入** `get_all_bundles()`（Noether/Xin 记账）。
7. **不修改** `SomatosensoryChain`、`body.skin_patches`、`ThermalMembrane`——三套系统并行不干扰（延续项目已有的"两套并行温感系统"惯例，本次是第三套独立系统）。
