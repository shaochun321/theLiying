### A3. D_REGION 矩阵 + 延迟计算函数

**新建文件**：`nexus_v1/circuit/region_topology.py`

```python
"""nexus_v1.circuit.region_topology — Brain-region distance matrix and delay routing.

TYPE:INFRA

Physical distance matrix D_REGION[from_region][to_region] in mm.
Source: 《脑区空间归类与地址系统升级（物理化修订版）》§2.2
Regions: 0x01=spinal, 0x02=brainstem, 0x03=main, 0x04=hypothalamus, 0x05=shadow
"""

# D_REGION[row][col]: physical distance between region centers [mm]
# Indexed by region code directly (0x01..0x05, index offset -1)
D_REGION = {
    (0x01, 0x01): 1, (0x01, 0x02): 3, (0x01, 0x03): 4, (0x01, 0x04): 6, (0x01, 0x05): 8,
    (0x02, 0x01): 3, (0x02, 0x02): 1, (0x02, 0x03): 3, (0x02, 0x04): 5, (0x02, 0x05): 7,
    (0x03, 0x01): 4, (0x03, 0x02): 3, (0x03, 0x03): 1, (0x03, 0x04): 3, (0x03, 0x05): 5,
    (0x04, 0x01): 6, (0x04, 0x02): 5, (0x04, 0x03): 3, (0x04, 0x04): 1, (0x04, 0x05): 4,
    (0x05, 0x01): 8, (0x05, 0x02): 7, (0x05, 0x03): 5, (0x05, 0x04): 4, (0x05, 0x05): 1,
}

# Conduction velocities [mm/s]
V_MYELINATED = 1000.0    # high-speed myelinated axons (emergency / reflex)
V_UNMYELINATED = 1.0     # standard unmyelinated (homeostatic modulation)


def synaptic_delay_steps(
    from_region: int,
    to_region: int,
    dt: float = 0.001,
    myelinated: bool = True,
) -> int:
    """Compute synaptic delay in simulation steps.

    τ = round(d_mm / (v_cond_mm_s × dt_s))

    Args:
        from_region: source region code (0x01..0x05)
        to_region:   target region code (0x01..0x05)
        dt:          simulation timestep [s]
        myelinated:  True = 1000 mm/s (reflex); False = 1 mm/s (homeostatic)

    Returns:
        Delay in steps (minimum 1).
    """
    d = D_REGION.get((from_region, to_region), 1)
    v = V_MYELINATED if myelinated else V_UNMYELINATED
    return max(1, round(d / (v * dt)))
```

这个函数在 Phase B/C 建 DelayedBundle 时直接调用，Phase A 只是建立基础设施，不在任何 Bundle 上应用延迟。

### B1. HC-023 替代：Motor 侧抑制物理化

**当前 HC（`variant_adapter.py:688-693`）**：
```python
motor_inhib = self.motor_lateral_inhibition.compute_inhibition(axis_acts)
for idx, mkey in enumerate(motor_keys):
    if motor_inhib[idx] < 0:
        mot = self.motor_neurons[mkey]
        mot._membrane.inject(motor_inhib[idx], dt)   # ← HC-023
```

**三问（需在动手前确认）**：
- Q1. BIO: Renshaw 细胞（脊髓腹角 IaIN）由 motor 轴突侧枝激活，抑制同侧及对侧运动神经元，防止同步过激。REF: Renshaw 1941; Eccles et al. 1954 J Physiol 126:524。
- Q2. 结构：`motor_neurons['move_x']` → [axon collateral Bundle, gain=1.0] → `spinal_renshaw_interneuron` → [抑制性 Bundle, synapse_gain<0] → `motor_neurons['move_y'], ['move_z']`
- Q3. `synapse_gain=-0.5`（方案值）：原 `compute_inhibition()` 最大抑制幅度约 -0.1A（需核查 `InhibitorySynapse.compute_inhibition()` 实现确认），-0.5 的增益配合 w=0.3 估算：`act_renshaw × (-0.5) × 0.3 ≈ -0.05A`，与原 inject 量级相近。需在实施前核查原 HC 实际注入量。

**步骤**：
1. 新建 `spinal_renshaw_interneuron`（region=0x01），`v_threshold=0.01`，位置 [45,50,25]
2. 建两条 Bundle：
   - `motor_x_to_renshaw`（frozen，gain=1.0，w=0.3）：motor_move_x → renshaw
   - `renshaw_to_motor_yz`（frozen，gain=-0.5，w=0.3）：renshaw → motor_move_y + move_z
3. 在 `_propagate_bundles()` Motor 步之后传播这两条束
4. 删除 L688-693 的 `_membrane.inject()` 调用
5. 保留 `InhibitorySynapse` 对象（供其他用途）或删除（需检查是否有其他引用）

## Phase C：hunger→motor 新功能（独立决策，不属于 HC 修复）

**背景**：方案 §4.1 描述的 `hypothalamus_hunger → motor_move_x` 是在接口二（hunger→DA 调制路径）之外**新增**一条饥饿→运动直驱路径。不是 HC 替代，是新的行为设计。

**前置三问（必须先回答才能动手）**：

- Q1. BIO: LH orexin/hypocretin 神经元直接投射脊髓前角，饥饿时增强运动觅食。REF: Saper et al. 2002 Nature 417:835（LH→脊髓前角运动驱动）；de Lecea et al. 1998 PNAS（orexin 唤醒/运动促进）。✓ 生物依据充分。
- Q2. 结构：`hypothalamus_hunger` (0x04) → [DelayedBundle, τ=3步, myelinated=True] → `motor_neurons['move_x']` (0x03)，d=3mm，v=1000mm/s。
- Q3. **synapse_gain=3.0 无推导，这是执行前必须补全的项**。需要：
  - 确认 hypothalamus_hunger 的典型 activation（fill=0.1时，饥饿最重）
  - 确认 motor_move_x 的激活阈值（v_threshold=0.01，低阈值）
  - 若 act_hunger=1.2（fill=0），gain=3.0，w=0.3 → I=1.2×3.0×0.3=1.08A → 极大，Motor 必然饱和
  - 合理估算：目标 I ≈ 0.05A（与接口二 DA 贡献等量级）→ gain=0.05/(1.2×0.3)=0.14
  - **方案 gain=3.0 按推导会饱和，建议改为 gain=0.1~0.15，等 200k 基线后校准**

**Phase C 触发条件**：
1. 200k 基线完成
2. Q3 gain 值重新计算并用户确认
3. 接口二与 hunger→motor 双重驱动的叠加效应已在基线中评估
