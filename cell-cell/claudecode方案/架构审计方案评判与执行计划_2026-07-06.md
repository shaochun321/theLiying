## 一、逐阶段实际评判

### 阶段一：Motor基强度诊断（F-I曲线）
**评判：完全成立，立即执行。**

spinal 神经元当前参数（代码实测）：
```
capacitance=1.0, r_leak=5.0, v_threshold=0.01, gm=1.0, spiking=False
```
V_th=0.01 非常低，神经元基本上在任何正输入下都会有激活。但"激活多少"是未知的——是否处于线性区、是否饱和，需要扫描才能知道。阶段一有效地填补了这一空白。

D1 bundle 当前参数（代码实测）：
```
initial_weight=0.1, weight_max=0.3, stdp_lr=0.005,
eligibility_ltd_rate=0.01 (constitutive, DA=0时也在衰减)
eligibility_tau=300.0
decay_rate_by_stage=(0.001, 0.0005, 0.0001)
```

### 阶段二：工作点漂移（initial_weight 0.1→0.005）
**评判：理论正确，但风险极高。执行前必须有阶段一数据。**

关键问题：`eligibility_ltd_rate=0.01` 是**无条件衰减**（DA=0时也在减权重）。T-041 中饱腹期（DA=0，约30k步）能把权重从0.30压到0.09。如果初始权重是0.005，进入饱腹期后直接归零——DA=1的饥饿期根本学不回来。

现有 Ia 互抑束（Step 6 已有）：
```
bundle_spinal_ccw_to_cw: sg=-1.0, w=0.1, frozen  ← 已存在
bundle_spinal_cw_to_ccw: sg=-1.0, w=0.1, frozen  ← 已存在
```
Ia 互抑电流 ≈ 0.1 × spinal_act × 1.0 ≈ 0.05（当 spinal=0.5）。
D1 bundle 在 initial_weight=0.005 时的驱动电流 ≈ 0.005 × phasic × 1.0 ≈ 0.0005（当 phasic=0.1）。
**Ia 互抑比 D1 驱动强 100倍 → D1 无法打穿，双侧 spinal 均被互抑到0，学习不可能发生。**

结论：阶段二如果把 initial_weight 降到 0.005，同时不修改 Ia 参数和 spinal 参数，会导致学习完全熄灭。**必须先做阶段一，根据数据决定是否需要、需要降多少。**

### 阶段三：STDP 参数调整（stdp_lr 0.005→0.001，eligibility_ltd_rate 0.01→0.02）
**评判：单独做 stdp_lr 降低有意义，两者同时做风险过高。**

eligibility_ltd_rate 从 0.01→0.02 会使宪法性 LTD 加倍。当前 T-041 已显示在饱腹期（30k步）权重能从 0.30 衰减到 0.09（约70%衰减），LTD 已不弱。加倍后衰减到 ~0.002，趋于归零。

如果只降 stdp_lr 0.005→0.001（不动 ltd_rate）：学习变慢5倍，但方向仍然正确。20k步到达上限的实验中，会延长到~100k步——在 200k 步实验中还能工作，只是更慢。这是合理的修改。

如果两者同时改：T-041 的 spinal 自修复振荡（饱腹期权重衰减→饥饿期反弹）会消失，因为 LTD 太强。**不推荐同时做。**

### 阶段四：推挽交叉抑制（spinal→yaw-opposite 束）
**评判：生物合理，结构合法，但 Q3 未答。**

文档提出的新束（注意不同于现有 Step 6）：
- 现有 Step 6：spinal_ccw → **spinal_cw**（互抑，在中间神经元层）
- 阶段四新束：spinal_ccw → **yaw_cw**（在运动神经元输出层）

两者不同，共存是合法的（双层推挽放大器）。**但参数 sg=5.0/-2.0, w=0.5 没有生物推导。**

三问拦截：
- Q1 ✓：脊髓 Ia 抑制性中间神经元到拮抗运动神经元（Eccles 1960，已有 BIO: 标注）
- Q2 ✓：Sources=spinal_ccw/cw（已有对象）→ Bundle → Targets=yaw_cw/ccw（已有对象）
- Q3 ✗：sg=-2.0, w=0.5 无推导来源；sg=5.0 正束也无推导

**阶段一的 F-I 曲线将给出 Q3 的实测依据。等阶段一完成后可以回答 Q3。**

### 阶段五：剥夺验收
**评判：与 T-039 重复，不需要重做。**

T-039 已证明：消融 D1 → DR5%=50%（精确随机基线）。剥夺实验的核心结论已经有了。只有当阶段四实质性改变电路结构后，才有必要重验证。

### "删除 ×10 硬编码增益"（阶段四前提）
**评判：错误。w=0.020 是实验验证值，不是硬编码。**

w=0.020（原 0.002 的 10×）来自 T-036 200k步实验的实测授权（EXP: T4.1 regression analysis 2026-07-04）。代码注释明确写了验证依据。删除它需要提供同等量级的实验依据，而非文档内的技术判断。阶段一数据可以决定是否需要调整这个值。

## 二、我的执行方案（四步）

**原则：** 阶段一先行，数据驱动后续；不同时做 Phase 2+3；先做无创结构验证，再做侵入性参数调整。

---

### Step A：F-I 曲线诊断（阶段一）+ Ia 互抑对照

**内容：** 编写 `exp_t042_fi_curve.py`，在不修改母本代码的前提下，实例化后动态修改 D1 bundle 权重，做**两组**扫描：

**扫描 A（有 Ia）：** Step 6 束保持默认（bundle_spinal_ccw_to_cw, bundle_spinal_cw_to_ccw，sg=-1.0，w=0.1）。测量的是"被 Ia 互抑压制后的有效阈值"。

**扫描 B（无 Ia）：** 实验脚本中将两条 Ia 互抑束权重归零（不修改母本），重复相同扫描。测量的是"D1 本身不受 Ia 干扰时的原始能力"。

两组对比可以精确量化 Ia 对 D1 信号的压制比：
`suppression_ratio = rheobase_B / rheobase_A`

**扫描范围：**
```
w_list = [0.001, 0.003, 0.005, 0.010, 0.020, 0.050, 0.100, 0.200, 0.300]
```
每个配置跑 8k 步（前 2k 热身，后 6k 统计）。D1 束在实验脚本中冻结（learning_rule='frozen'，weight=w_target）——固定权重才能得到干净的 F-I 曲线，不让 STDP 在诊断期间改变权重。

**输出：** 
- 两条 F-I 曲线表格（有/无 Ia）：每个 w 值对应的 phasic 均值/峰值、spinal 均值/峰值、yaw 均值
- `rheobase_A`（有 Ia 时的等效阈值）
- `rheobase_B`（无 Ia 时的原始阈值）
- `suppression_ratio = rheobase_A / rheobase_B`：Ia 对 D1 信号的压制倍数
- 是否当前 w=0.1 已处于饱和区

**为阶段四参数推导提供两个关键数据：**
1. D1 到 yaw 的实际增益曲线（决定 W_CROSS/SG_CROSS 量级）
2. Ia 压制比（决定阶段二是否需要调整 Ia 参数）

---

### Step B：阶段四交叉抑制束（依据 Step A 数据）

**内容：** 在 `variant_adapter.py` 中，在 `_init_yaw_bundles()` 内新增两条冻结束：
```python
# BIO: Ia inhibitory interneuron → antagonist VMN inhibition (Eccles 1960).
# PHYS: push-pull at motor pool level — spinal_ccw fires → suppresses yaw_cw.
# EXP: T-042 F-I curve: at spinal_act=0.5, yaw excitation ≈ X. 
#      cross-inhibition set to cancel 50% of contralateral yaw input: sg_cross = -0.5 * sg_pos.
self.bundle_spinal_ccw_to_yaw_cw = SynapticBundle(
    _frozen_cfg('spinal_ccw_to_yaw_cw', W_CROSS, SG_CROSS), 
    [self.spinal_ccw], [self.yaw_cw_neuron])
self.bundle_spinal_cw_to_yaw_ccw = SynapticBundle(
    _frozen_cfg('spinal_cw_to_yaw_ccw', W_CROSS, SG_CROSS), 
    [self.spinal_cw], [self.yaw_ccw_neuron])
```

**参数 W_CROSS 和 SG_CROSS 由 Step A 数据决定：**
- 从 F-I 曲线得到：当 D1 weight=0.1 时，spinal_act≈X，yaw_act≈Y
- 设计目标：当 spinal_ccw 略强于 spinal_cw（差值 δ），yaw_ccw 获得 2× 净差放大
- 推导：SG_CROSS = -W_POS / W_CROSS × α，其中 α 是放大比（可选 1.5x）

**不修改现有正束（保持 w=0.020, sg=1.0）。**  
**不删除 ×10 增益。**

这两条新束必须加入 `get_all_bundles()` 返回列表（TSI/Noether 强制审计要求），同时加入 `_do_learning()` 的注册（虽然 frozen 不学习，但 Noether 的 KCL 核查需要看到所有 bundle 的电流流向），并在 step() 的 yaw 电流汇总处加入 propagate 调用。

### Step C：独立运行 50k 验证

**内容：** 复用 T-038 设置（body=[10,50,25], heat=[70,50,25], fill=0.3），50k步。

验证：

### Step D：如果 Step A 显示 spinal 过饱和

**仅在 F-I 曲线显示 w=0.1 已明显超过饱和点（如饱和点在 w=0.02 处），才执行：**

- 将 D1 initial_weight 从 0.1 降至 **`rheobase × 2`**（阶段一实测，不是 0.005）
- 仅修改 initial_weight，**不改变 stdp_lr 和 eligibility_ltd_rate**
- 运行 50k 验证确认学习仍可发生（|Δw| > 0.02）

## 三、不做的事

| 不做 | 理由 |
|------|------|
| Phase 2+3 同时执行 | Ia 互抑 100× 压过 D1 驱动（w=0.005）；constitutive LTD 2×使饱腹期权重归零 |
| 删除 w=0.020（×10增益） | 实验验证值（T-036 EXP:标注），需同等量级实验依据才能删除 |
| stdp_lr 0.005→0.001 同时 ltd_rate 0.01→0.02 | 双重减弱，学习可能完全熄灭 |
| 重复剥夺验收（阶段五） | T-039 已证明。新结构上线后再跑一次即可，不需要单独先跑 |
| Phase 5 ablation as separate step | 合并到 Step D 200k 验证中即可 |
