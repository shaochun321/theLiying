## 二、当前执行主线（2026-07-17 批判十六细化，P1/P2 各拆三层）

P1-A（身份/拓扑契约） → P1-B（有序介质传输） → P1-C（联合验证）
  → P2-A（动态皮肤→ξ^occ） → P2-B（回接关系原语） → P2-C（关系-关系生成）

### P1-A（待启动）：身份/拓扑契约

**核查结论（批判十六①，2026-07-17）**：现有 `ThermalFieldGraph.cells` 已是
`Dict[int, ThermalCell]`（按 `node_id` 键控），`ThermalLink`/`ThermalContact` 全部用
显式 `node_id` 字段查表，全仓库无一处按数组位置寻址——"排列等变性"bug 类在现有架构下
已结构性不存在。**用户已裁定采用完整版身份地址系统**（覆盖我方"轻量版已够用"的建议，
作为长期基础设施投入）：

- 节点地址 `α(x)=(d_x, u_x, g_x, v_x)`：`d_x`=域（如`world.cell`/`skin.patch`/
  `occ.thermal`）、`u_x`=域内稳定实例身份、`g_x`=生成深度、`v_x`=结构版本；
- 边身份 `ε_e=(u_e, α_source, α_target, m_e, v_e)`：`m_e∈{diffusion, contact,
  medium-transport}`；
- **明确**：地址不是坐标，端点顺序不是方向。
- 8项结构测试：边两端点存在/端点域与机制兼容/对象重排序结果不变/节点索引变但稳定
  地址不变时物理结果不变/结构重建后版本递增旧地址失效/`e_ij`与`e_ji`是两个不同有序
  传输实例/禁止同一物理边重复注册重复扣账/所有状态变化可追溯到明确源项或边身份。
- 关键测试：排列等变性——节点顺序置换矩阵`P`，更新算子`M`满足`M'=PMP^{-1}`。

### P1-B（待启动）：有序介质传输（不是方向）

正式命名从"守恒的介质搬运与非对称通量"收紧为**"守恒的有序介质传输"**，避免被理解成
空间方向生成元。`AdvectiveThermalLink`（与`ThermalLink`同层的真实输运机制，不是语义
算子）：对有序边`e=(i,j)`，`J_e^tr=a_e(t)·E_i(t)`（`a_e≥0`），单步转移
`ΔE_e=J_e^tr·Δt`，对称应用。`i→j`只说明"本次物理转移从哪个能量仓扣除、向哪个能量仓
注入"，**不意味着**前后左右/环境方向/自我方向/`r→`/坐标轴正负。

### P1-C（待启动）：联合验证

**联合稳定性**（P1-0 修复②方法论的直接推广，见`skin_thermal_contact.py`
`contact_stability_numbers()`先例）：
```
η_i^joint = Δt·[(Σ_j κ_ij + Σ_s H_is)/C_i + Σ_{e:s(e)=i} a_e] ≤ 1
```
同时覆盖扩散出流+世界-皮肤接触出流+介质搬运出流，不是分开检查三个数后假设组合仍稳定。
更严格方法：构造冻结参数下一步能量更新算子`E^{n+1}=ME^n+q`，验证`M_ij≥0`、
`1^⊤M=1^⊤`（有泄漏时`≤1^⊤`，差额入泄漏账本）。

**新增验证**（P1-0 已完成项不再重复，只保留为回归项：接触边稳定性/四种失稳拒绝/
逆向交换/单接触10τ_ws浸泡/量纲契约/调度措辞）：
1. 局部/节点/全局三级账本（每条边`ΔE_source^e+ΔE_target^e=0`；每节点
   `ΔE_i=Q_i^source+Q_i^diff+Q_i^contact+Q_i^transport-Q_i^loss`；全系统
   `ΣΔE_i=E_source,drawn-E_loss`）——不能只测全局，两个节点错误可能互相抵消；
2. 多边竞争：一节点同时有2条扩散边+1条接触边+2条搬运出边，验证联合预算而非分别通过后
   拼接；
3. 拓扑置换：5节点存储顺序打乱，地址/边连接不变，结果只发生相同的索引置换；
4. 边端点交换：**不称"方向反转"**，构造`e_ij`和`e_ji`两个不同物理配置，验证能量
   扣减端/注入端正确交换；
5. 步长收敛：`Δt`、`Δt/2`、`Δt/4`跑到同一物理时刻，误差应随步长减小而收敛（不只是
   "都没发散"）；
6. 浸泡测试：按完整网络最慢非平凡模态设置浸泡时间（第二特征值`|λ_2|<1`估计
   `τ_slow≈-Δt/ln|λ_2|`，运行`5~10τ_slow`），只验证不变量（能量不漂移/状态非负有限/
   无NaN/局部与全局账本持续闭合/热源耗尽后无虚假注入/趋向正确稳态）。

**表述订正（批判十六②，2026-07-17，接受）**：P1 最小实验验收项原写"L2接口能区分
'相同温度不同通量历史'"——**此表述过强**：`J_e=a_e(t)·E_i(t)`是无记忆瞬时函数，相同
`E(t)`+`a(t)`必然给出相同`J(t)`，与历史无关。当前 P1 能验证的准确表述是：
```
相同温度状态 + 不同介质传输系数a → 不同通量关系
（即 T^(A)=T^(B)，a^(A)≠a^(B) ⟹ J^(A)≠J^(B)）
```
不是"相同瞬时状态但不同历史产生不同通量"（后者需要传输机制本身有内部记忆状态如惯性/
流体储能/迟滞，`J_e=F(E_i,m_e)`，当前设计没有，不应为了满足"历史"一词强行加记忆
组件）。

最小实验范围：5个世界节点/1个热源/1~2条搬运边/1个皮肤接触点，验收覆盖无搬运退化为
P0/正向搬运沿规定边移动/反转`a_ij`后关系反转（措辞用"两个不同物理配置"，不用"方向
反转"）/守恒/高流率拒绝/扩散搬运共存仍闭合/皮肤能感受到搬运造成的动态差异。

### L3 决策（P2-C通过后再评估，门槛已细化）

不仅要求"P0+P1+P2都通过"，还需满足：①连续物理过程没有外部事件分段标签；②关系状态
来自真实发生和真实输运；③不同物理过程能够形成不同关系轨迹；④区分不依赖坐标/方向
