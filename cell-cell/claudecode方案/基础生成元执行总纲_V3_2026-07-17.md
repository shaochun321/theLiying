**类型化订正（批判十七①②③④，2026-07-17，接受）**：

- **地址拆两类**（原统一四元组混淆了物理层级和生成递归深度）：
  - `α_phys(x)=(d_x, u_x, v_x)`：用于世界节点/皮肤支撑/热源/物理边界——这些是关系
    生成依赖的物理支撑，不是"零阶关系生成元"；
  - `α_gen(x)=(d_x, u_x, P_x, δ_x, v_x)`：用于 `ξ^occ`/`r≺^τ`/`r_ρ^τ`/未来关系-关系
    生成物——`P_x`=父支撑或父关系地址集合，`δ_x`=生成深度。P1-A 本轮只实现两个地址
    类型的数据结构，`α_gen` 暂不接实体（留给 P2 使用）。
- **边身份拆两类**（原统一机制集合会给互易边偷偷塞进永久方向）：
  - `ε_e^sym=(u_e, {α_i,α_j}, m_e, v_e)`：扩散边/接触边，端点是**无序集合**——
    `J=κ(T_i-T_j)`/`J=H(T_w-T_s)` 本质是两端点间互易耦合，source/target只是某次
    计算的符号约定，不是边永久属性；
  - `ε_e^ord=(u_e, α_tail, α_head, m_e, v_e)`：只有 P1-B 的介质传输边（`m_e=
    "medium-transport"`）——`J_i→j^tr=a_ij·E_i` 的公式本身依赖哪端是`i`，是真正
    有序的。
  - `m_e ∈ {diffusion, contact, medium-transport}`。
- **排列测试升级为图同构**：不用矩阵置换 `M'=PMP^{-1}`（降级为线性子系统的具体实现
  测试），改用地址重命名双射 `φ:V→V'`，验证 `φ(F_G(x))=F_{φ(G)}(φ(x))`——同时覆盖
  节点状态/边端点/热源定位/皮肤接触/账本地址/生成元映射。**引入两层身份**：
  `local_key`（容器内部当前查表键，如 dict 的整数 key）vs `stable_uid`（跨重建保持的
  物理身份，即 `α.u_x`）——两者必须是不同字段，否则"索引变但地址不变"这条测试本身
  无法构造。
- **版本号递增条件**：`v_x` **仅**在身份连续性被破坏时递增（对象销毁后用同一UID重建/
  皮肤支撑被拆分或合并/物理节点角色发生结构性替换/父生成关系集合改变），**不**因
  普通状态变化（温度/能量/接触面积/边权）递增——否则地址每步失效。边有独立的
  `v_e`，不因节点动态状态变化而改变。

**8项结构测试**：边两端点存在/端点域与机制兼容/对象重排序结果不变/`local_key`变化但
`stable_uid`不变时物理结果不变/结构重建后版本递增旧地址失效/`e_ij`与`e_ji`是两个

**不实现**（避免"完整版地址系统"被误解为要建通信网络，批判十七九.第二步明确列出）：

### P1-B0（已冻结定义，批判十八/十九，2026-07-17）：有序过剩热能转移机制契约

**核心订正①（批判十八）**：不叫`AdvectiveThermalLink`（真正介质平流需要质量转移
`J^adv=ṁ_e·c_p·T_i`+节点热容`C_i=m_i·c_p`随之变化；当前`THERMAL_FIELD_MODE=
"normalized"`无介质质量状态，只搬热能不是真平流）。

**核心订正②（批判十九，已用代码实测验证）**：`ThermalCell.capacitor.charge`
**不是绝对热能，是相对该节点自身`ambient_temperature`的偏差量**——`ambient_
temperature`是逐节点字段，`temperature=ambient_temperature+capacitor.voltage`。
两个`ambient_temperature`不同的节点，`charge=0`代表的实际温度可以完全不同（实测：
`ambient=100`/`ambient=0`两节点`charge=0`时温度分别是100.0/0.0）。且`charge`可以
为负（节点低于自身基线时），此时若不处理会让转移方向翻转但边身份不变，破坏"非负
有序通量"这个P2-C已依赖的前提。

**正式命名 `OrderedExcessThermalEnergyLink`**（比批判十八的`OrderedThermalEnergyLink`
再收紧一层——语义从"搬运全部能量"进一步收紧为"只搬运统一环境基线以上的过剩部分"，
命名须反映真实语义；未来进入physical-anchor模式、加入质量/比热/流量/体积才升格真正
advection）。

**冻结定义**（在批判十八7项基础上，批判十九订正②③④⑤，新增⑧⑨）：
1. **机制命名**：`OrderedExcessThermalEnergyLink`，语义为"有序过剩热能转移"，不是
   "方向"、不是"介质平流"、不是"总热能转移"。
2. **状态变量与过剩钳位（批判十九①，订正）**：`u_i^+=max(q_i,0)`，`q_i=
   ThermalCell.capacitor.charge`——节点低于自身环境基线时不提供过剩热量，
   `p_e=a_e·u_i^+`恒`≥0`，tail/head身份不会因符号翻转而颠倒。**不再声称**
   `charge`是"绝对能量零点"（原表述有误，已订正）。
3. **两端基线一致性前提（批判十九①，新增）**：有序边两端必须
   `ambient_temperature_tail=ambient_temperature_head`，否则转移物理上不对等——
   `step_ordered_transport()`在执行前校验，不满足则拒绝，状态不变。
4. **`a_e`参数来源（批判十九③加强措辞）**：`a_e=1/τ_e`，**`τ_e=2.0`是EXP机制
   测试起点，尚未物理标定**（不再只说"首轮起点"，需明确"尚未标定"）——未来标定
   路径：已知参考时间`t_r`内应保留比例`r`则`a_e=-ln(r)/t_r`，或半衰时间
   `a_e=ln(2)/t_half`。
5. **单边非负性稳定门（批判十九④，新增，已用代码验证是真实bug）**：
   `rate_per_time·dt≤1.0`时递推`u^{n+1}=(1-a_eΔt)u^n≥0`恒成立；超出时
   `step_ordered_transport()`在任何状态修改前`raise ValueError`（fail-fast，
   **不用`min()`静默钳制**——那会把线性模型悄悄变成分段模型并掩盖不稳定配置）。
   实测：`a_e=2.0,dt=1.0`（`a_eΔt=2.0>1`）此前会让tail从10变成-10，现已拒绝。
6. **`ThermalTransportPlan`**：范围受限（不是全项目通用`PhysicalStepPlan`，那个仍
   按批判十七裁定推迟）的不可变计划对象，**批判十九⑤建议与多边竞争合并**：
   P1-B2改为"计划生成与多边竞争一起实现"（不再是"先B2后B3"两个独立阶段）——
   多边竞争正是计划对象存在的原因，没有计划阶段无法保证多条边都从同一份快照
   计算。
7. **联合稳定性公式（批判十九②，订正量纲）**：
   `η_i^joint = Δt·[(Σ_j κ_ij + Σ_s H_is + G_i^env)/C_i + Σ_{e:tail(e)=i} a_e] ≤ 1`
   `G_i^env=1/r_leak_ambient`（**导纳形式**——`Capacitor.leak(resistance,dt)`
   的参数字面是电阻，`r_leak_ambient`是电阻量，必须先取倒数变成导纳才能与
   `κ`/`H`同处理进同一个分子括号；原表述"λ_i来自r_leak_ambient"只改了变量名
   没给换算关系，是真实疏漏，已订正）。
8. **三级账本字段**：边级`R_e=Δu_tail^e+Δu_head^e=0`；节点级
   `R_i=Δu_i-(q_i^source+q_i^diff+q_i^contact+q_i^transport-q_i^loss)`；全局
   `R_G=Σ_iΔu_i-(E_source,drawn-E_loss)`。
9. **驱动机制欠账声明（批判十九⑦，新增）**：`p_e=a_e·u_i^+`不依赖温差，可以把
   过剩热量从较冷节点搬到较热节点——不是被动扩散，是主动/未建模介质驱动的过程；
   能量两端守恒不代表完整热力学账本闭合（驱动该转移的机械功/压力差未建模）。
   新增`transport_drive_mode="exogenous_normalized"`标志字段，声明当前不对
   驱动机制的外部机械功/熵增/热力学第二定律做资格宣称。
10. **P1-C固定测试夹具**（记录供P1-C使用）：夹具A（5世界节点+1热源+2扩散边+2条
    共享tail的有序出边+1接触边+1皮肤状态）；夹具B（1世界节点+2皮肤点+2条接触边，
    专测`Σ_sH_is`求和情形，验证联合预算不能分别通过后拼接）。

**统一快照纪律**（批判十八③，接受）：同一tail节点多条有序出边时必须"先全部快照→

**矩阵测试需为分段线性做准备（批判十九⑧，新增设计要求）**：`u_i^+=max(q_i,0)`钳位
后系统全局不再是单一固定线性算子，只在所有参与tail全程`q_i>0`的工作区间内才能写成
`u^{n+1}=Mu^n+q`——P1-C矩阵测试须拆两部分：**线性正域测试**（整个运行过程`q_i>0`
的夹具，验证真实运行算子等于`M_E`）+ **边界测试**（`q_i→0`时验证不出现负转移/不
发生供体受体隐式翻转/账本闭合/零可用能量后该边功率归零）。

**矩阵守恒测试需明确状态变量（批判十七⑤，2026-07-17，接受）**：构造冻结参数下一步
更新算子前，必须先明确用哪个状态向量，两者守恒条件不同（`E_i=C_i·T_i`，节点热容不同
时不等价）：
- 能量态：`E^{n+1}=M_E·E^n+q_E`，验证 `1^⊤M_E=1^⊤`；
- 温度态：`T^{n+1}=M_T·T^n+q_T`，验证 `C^⊤M_T=C^⊤`（`C^⊤=(C_1,...,C_n)`）。
不能用温度矩阵却检查列和为1（那是能量态的条件），否则在不同热容节点间会得出错误
结论。两种形式都要求 `M_ij≥0`（有泄漏时列和`≤`对应右端，差额入泄漏账本）。

**新增验证**（P1-0 已完成项不再重复，只保留为回归项：接触边稳定性/四种失稳拒绝/
逆向交换/单接触10τ_ws浸泡/量纲契约/调度措辞）：
1. 局部/节点/全局三级账本（每条边`ΔE_source^e+ΔE_target^e=0`；每节点
   `ΔE_i=Q_i^source+Q_i^diff+Q_i^contact+Q_i^transport-Q_i^loss`；全系统
   `ΣΔE_i=E_source,drawn-E_loss`）——不能只测全局，两个节点错误可能互相抵消；
2. 多边竞争：一节点同时有2条扩散边+1条接触边+2条搬运出边，验证联合预算而非分别通过后
   拼接；
3. 拓扑置换（**升级为图同构测试**，批判十七③，见P1-A）：5节点存储顺序打乱，地址/边
   连接不变，结果只发生相同的地址映射；
4. 边端点交换：**不称"方向反转"**，构造`e_ij`和`e_ji`两个不同物理配置，验证能量
   扣减端/注入端正确交换；
5. 步长收敛：`Δt`、`Δt/2`、`Δt/4`跑到同一物理时刻，误差应随步长减小而收敛（不只是
   "都没发散"）；
6. **浸泡测试拆两段**（批判十七⑥，2026-07-17，接受——特征值方案只在参数冻结/线性/
   拓扑固定/`a_e(t)`不变时唯一存在，`a_e(t)`若随时间变化就没有单一`λ_2`）：
   - **封闭冻结段**：热源关闭，`a_e`固定，`E^{n+1}=ME^n`，用第二特征值
     `τ_slow≈-Δt/ln|λ_2|` 确定运行长度（`5~10τ_slow`），验证收敛/不变量/账本；
   - **驱动变化段**：热源开启或`a_e(t)`变化，不使用单一时间常数，只验证能量有界/
     局部与全局账本闭合/无负能量/无NaN/所有状态变化可追溯到边或源项/驱动停止后能
     进入冻结段并收敛。

**表述订正（批判十六②，2026-07-17，接受）**：P1 最小实验验收项原写"L2接口能区分
'相同温度不同通量历史'"——**此表述过强**：`J_e=a_e(t)·E_i(t)`是无记忆瞬时函数，相同
`E(t)`+`a(t)`必然给出相同`J(t)`，与历史无关。当前 P1 能验证的准确表述是：
```
相同温度状态 + 不同介质传输系数a → 不同通量关系
（即 T^(A)=T^(B)，a^(A)≠a^(B) ⟹ J^(A)≠J^(B)）
```
不是"相同瞬时状态但不同历史产生不同通量"（后者需要传输机制本身有内部记忆状态如惯性/
流体储能/迟滞，`J_e=F(E_i,m_e)`，当前设计没有，不应为了满足"历史"一词强行加记忆
组件）。

最小实验范围：5个世界节点/1个热源/1~2条搬运边/1个皮肤接触点，验收覆盖无搬运退化为
P0/正向搬运沿规定边移动/反转`a_ij`后关系反转（措辞用"两个不同物理配置"，不用"方向
反转"）/守恒/高流率拒绝/扩散搬运共存仍闭合/皮肤能感受到搬运造成的动态差异。
