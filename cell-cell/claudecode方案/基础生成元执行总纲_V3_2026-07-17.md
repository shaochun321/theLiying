## 二、当前执行主线

```
P1（守恒的介质搬运与非对称通量）→ P2（真实发生元重标定+关系回接）→ L3 决策
```

### P1（待启动）：`AdvectiveThermalLink`

不是"方向生成元"，是与 `ThermalLink` 同层的真实输运机制。最小动力学：
`J_i→j^adv = a_ij(t)·E_i(t)`（`a_ij` 量纲 `[1/time]`），单步转移
`ΔE_i→j = J_i→j^adv·Δt`，对称应用到两端节点。约束：
`Δt·Σ_j a_ij ≤ 1`（防止单步搬走超过源节点现有能量）；若同一步还有扩散+接触，需建立
**联合**稳定性预算（同 P1-0 修复②的"联合核算不能分开检查"教训）。

最小实验范围：5个世界节点/1个热源/1~2条搬运边/1个皮肤接触点，验收覆盖无搬运退化为P0/
正向搬运沿规定边移动/反转`a_ij`后关系反转/守恒/高流率拒绝/扩散搬运共存仍闭合/L2接口
能区分"相同温度不同通量历史"/皮肤能感受到搬运造成的动态差异。

### P2（P1通过后）：真实发生元重标定 + 关系回接

从动态皮肤状态重新测量 `ξ_i^occ` 的启动时间/衰减/burst/支撑范围；让真实发生进入
`r≺^τ`/`r_ρ^τ`；用三条真实通量做首次"关系-关系生成"（`r_ρ,J^τ=[z_J1^τ:z_J2^τ:z_J3^τ]`，
复用已冻结的三元共享池，不再是人工给定的三条感温脉冲）。

### L3 决策（P2通过后再评估）

"结构诱导事件"是否值得作为独立方向启动，留到 P0+P1+P2 全部通过、观察到真实的"相同
温度不同通量历史"数据后再评估，不预先承诺。
