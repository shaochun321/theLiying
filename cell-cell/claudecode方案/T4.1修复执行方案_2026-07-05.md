## 根因确认（与最终裁决文档的差异）

最终裁决文档认为 T4.1 塌陷是"CPG过度强化 Cross 路径"。实际代码分析：

| | Axis bundles | Cross bundle |
|--|--|--|
| initial_weight | 0.4（远高于稳态） | 0.05（接近稳态） |
| stdp_lr | 0.05 | 0.0005（100× 慢） |
| STDP 稳态公式 | w_eq = 2×pre×post | w_eq = 2×pre×post（相同）|
| 稳态 w_eq | ≈ 0.001（col/motor 激活低） | 同 ≈ 0.001 |
| 收敛速度 | 极快（~10k步，高 stdp_lr） | 极慢（>500k步） |

**真实机制：** Axis 权重以 100× 更快的速度从 0.4 衰减至稳态 ~0.001，Cross 权重在 200k 步内基本未动（仍在 ~0.05-0.10）。T4.1 = 0.001/0.05 = 0.02。

**正确修复方向：** 阻止 Axis 权重参与 STDP 更新（冻结），而不是"提升 synapse_gain/weight_max"（方案文档 P0 建议，无效）。

## 执行修改

### 修改 A（P0）— 冻结 VOR Axis bundles 的 STDP

**文件：** `nexus_v1/circuit/variant_adapter.py`，`_do_learning()` 方法，约第 2434 行

**三问验证：**
- Q1. 生物对应物：VOR（前庭眼反射）弧是脑干解剖硬连线，不依赖 Hebbian 可塑性。BIO: Jones & Milburn 1991 Rev Neurol 147:569 — VOR reflex arc is anatomically fixed; gain adaptation occurs via cerebellar, not brainstem, plasticity.
- Q2. 物理结构：`column_neurons['yaw']` → `motor_neurons['move_x']`（frozen propagation, STDP disabled）；bundle_id 规则：axis = 无 'cross' 无 'therm'
- Q3. 参数依据：`initial_weight=0.4`（原始设计，注释 "C2: strong topological bias (VOR hardwire)"）；冻结后权重固定；synapse_gain=10.0 不变。输出：I = 0.4 × 10.0 × col_act = 4.0 × col_act。col_act≈0.1时，I=0.4A → V_ss_motor = 0.4 × r_leak（由 motor 配置决定）。

**修改：**

```python
# 修改前（约 2433-2436）：
# Column → Motor: PNN × DA × sync × body_inertia
for b in self.bundles_col_to_motor:
    b.learn(dt, plasticity_gate=gate_col * da_lr_mod * g_sync * body_lr,
            fill_fraction=fill, da_concentration=da_conc)

# 修改后：
# Column → Motor: PNN × DA × sync × body_inertia
# VOR axis bundles (yaw/pitch/roll → move_x/y/z) are anatomically hardwired.
# BIO: Jones 1991 Rev Neurol — VOR brainstem arc has fixed topographic gain;
#      STDP disabled to prevent equilibrium-driven weight collapse (T4.1 bug).
for b in self.bundles_col_to_motor:
    if 'cross' in b.id or 'therm' in b.id:
        b.learn(dt, plasticity_gate=gate_col * da_lr_mod * g_sync * body_lr,
                fill_fraction=fill, da_concentration=da_conc)
```

**效果：** Axis bundles 停止 STDP 更新，权重固定在当前值（初始化时为 0.4）。Cross 和 therm bundles 继续正常学习。

### 修改 B（P2）— 提升 spinal_to_yaw 输出权重

**文件：** `nexus_v1/circuit/variant_adapter.py`，`_init_yaw_bundles()` 方法，约第 809-812 行

**三问验证：**
- Q1. 生物对应物：脊髓中间神经元（spinal interneuron）→ 前庭运动神经元（VMN）的上行突触。BIO: Eccles et al. 1960 J Physiol 154:89 — spinal interneurons project to brainstem motor nuclei; weight is a structural synaptic conductance.
- Q2. 物理结构：`spinal_ccw` → `yaw_ccw_neuron`（frozen, sg=1.0）；`spinal_cw` → `yaw_cw_neuron`（frozen, sg=1.0）。`yaw_ccw_neuron` → `body.apply_yaw_torque()` × `YAW_GAIN=0.1`。
- Q3. 参数依据：当前 w=0.002，代码注释 "EXP: T4.1 regression analysis 2026-07-04; tune upward after 200k D1 validation." T-036 是满足该条件的 200k 验证实验（全部 PASS）。目标 w=0.020（10×）：spinal_ccw.activation≈0.10（T-036 观测值），I=0.020×1.0×0.10=0.002A → V_yaw = 0.002 × r_leak_yaw ≈ 0.01V → torque=0.01×0.1=0.001 rad/step。在允许范围内，不超过 0.1（YAW_GAIN=0.1 下饱和阈值）。

**修改：**

```python
# 修改前（约 809-812）：
self.bundle_spinal_ccw_to_yaw = SynapticBundle(
    _frozen_cfg('spinal_ccw_to_yaw', 0.002, 1.0), [self.spinal_ccw], [self.yaw_ccw_neuron])
self.bundle_spinal_cw_to_yaw = SynapticBundle(
    _frozen_cfg('spinal_cw_to_yaw', 0.002, 1.0), [self.spinal_cw], [self.yaw_cw_neuron])

# 修改后：
self.bundle_spinal_ccw_to_yaw = SynapticBundle(
    _frozen_cfg('spinal_ccw_to_yaw', 0.020, 1.0), [self.spinal_ccw], [self.yaw_ccw_neuron])
self.bundle_spinal_cw_to_yaw = SynapticBundle(
    _frozen_cfg('spinal_cw_to_yaw', 0.020, 1.0), [self.spinal_cw], [self.yaw_cw_neuron])
```

**效果：** D1 弧的 yaw 输出信号强度提升 10×，使已验证的方向性学习（T-036 |Δw|=0.2991）能更有效地转化为 body 旋转扭矩。
