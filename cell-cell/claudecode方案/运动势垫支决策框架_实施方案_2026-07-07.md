## 一、必改项（进入阶段A的门票）

### Fix-M1：废弃 Softmax → WTA 自然输出

**违规原因：** Softmax `P = exp(V/T)/Σexp` 是纯 Python 数学，无生物原语对应，也无生物文献支持（T=0.5 参数无来源）。

**修复方案：**
- 删除 Softmax 层
- WTA 决策神经元的 `activation` 直接作为选择信号强度（侧向抑制天然产生 WTA）
- 低通平滑改用 `Capacitor(capacitance=500.0, r_leak=1/500)`
- BIO: 基底节 SNr-丘脑 disinhibition 的输出不是概率分布，是"允许/禁止"的二值信号

**工作量：** 极小（删除计算公式，保留 WTA + Capacitor）

---

### Fix-M2：废弃范数计算 → Capacitor 误差积分

**违规原因：** `M_d = -||Δy_d - Δŷ_d||²` 是 Python 范数，直接决定哪个方向获得偏置电流（语义硬编码）。

**修复方案（完整物理电路）：**

```
I_err_d = ŷ_d(FSM输出) - y_actual(感官实际)  ← KCL 差分（无Python）
    ↓
误差 Capacitor_d（每方向一个，C=1, r_leak=0.005）
    ↓ 积分误差电流
V_err_d（电压）= 积分后误差大小
    ↓
MOSFET_d（Vth=0.05, gm=0.5）将 V_err_d 转为抑制电流
    ↓
注入对应方向决策神经元（误差大 → 更强抑制 → 该方向被压制）
误差最小的方向自然胜出（物理涌现，无 Python 选择）
```

**Q1 BIO：** 小脑浦肯野细胞（误差信号 via 攀缘纤维）→ 深部核团抑制 → 方向选择。  
**Q2 SEMI：** Capacitor（误差积分）+ MOSFET（阈值门控）+ frozen SynapticBundle（抑制）。  
**Q3 参数推导：**
- C=1, r_leak=0.005 → τ_err = C/r_leak = 200步（误差记忆窗口，约 0.2s 生物时间）
- Vth=0.05: 感官信号的 5σ 本底噪声（在 ShadowSandbox 安静期测量后确认）
- gm=0.5: 使满量程误差产生 ~0.1 的抑制电流（与决策神经元膜电位量级匹配）

**工作量：** 中（3个 Capacitor + 3个 MOSFET + 3条 frozen 抑制 Bundle）

## 三、组件接线规格

### 3.1 置信度积分器（ConfidenceIntegrator）

**TYPE: HYBRID（生物整合器 + 电容物理）**

| 参数 | 值 | 推导 |
|:---|:---|:---|
| 监听目标 | spinal_ccw.activation / spinal_cw.activation | D1 弧输出端（已学会的方向信号）|
| 电容 C | 5000 | τ_conf = 5000步（≈ DA EMA 对齐；待标定后调整）|
| r_leak | 1/5000 | 配合 C 使 τ = 5000 |
| 输入增益 | 1.0 | 脉冲电流直接充电 |

**实现：**
```python
# BIO: striatal MSN integrates cortical spike trains (Mink 1996)
# SEMI: large Capacitor as leaky integrator
self._conf_ccw = Capacitor(capacitance=5000.0)  # confidence for CCW action
self._conf_cw  = Capacitor(capacitance=5000.0)  # confidence for CW action
# 每步 step() 中：
self._conf_ccw.inject(abs(c.spinal_ccw.activation), dt)
self._conf_ccw.leak(1/5000, dt)
```

**注意：** τ_conf = 5000步是初始估算，**必须在阶段A的第一个实验中测量**：用单次 spinal burst 的自然时间常数校准。

---

### 3.2 FSM 前向感官预测矩阵

**TYPE: BIO（小脑浦肯野-平行纤维系统）**

| 参数 | 值 | 推导 |
|:---|:---|:---|
| 输入（efference copy）| [yaw_ccw.activation, yaw_cw.activation, motor_move_x.activation] | 实际执行的动作信号 |
| 输出（预测感官）| [ΔT_pred, Δω_pred] | 温度变化率 + 角加速度预测 |
| 实现 | 6个 SynapticBundle（3输入 × 2输出）| 每条 frozen 初始，error_driven 更新 |
| 初始权重 | 0.001 | 几乎零（从零学起）|
| 学习率 η_fsm | 1e-4 | 推导见下 |
| 学习规则 | LMS（非 STDP）| BIO: 攀缘纤维驱动 LTD（非时序依赖）|

**η_fsm 推导：**
- 感官变化典型幅度：`Δy_typical ≈ 0.01`（ThermalMembrane 输出量级）
- 学习收敛步数目标：`10k-50k步`
- `η_fsm ≈ Δy_typical / steps = 0.01 / 10000 = 1e-6`（保守值）
- 文件1 取 1e-4 是加速学习；阶段B先用 1e-5 观察，根据收敛曲线调整

**实现方式：** 在 `learn()` 调用中传入 `da_concentration = -I_error`（负误差 = LTD）

---

### 3.3 误差比较器 + 误差神经元 + GABA 抑制

**TYPE: BIO（攀缘纤维 → 浦肯野 LTD + SNr GABA）**

```
误差 Neuron_err:
  mode='simple'
  NeuronConfig(v_threshold=0.05, tau_membrane=100)
  输入: I_err = ŷ_pred - y_actual (KCL 差分节点)
  输出: 脉冲（当 |I_err| > θ_err）

GABA抑制束（对每个决策神经元）:
  SynapticBundle(
      bundle_id='gaba_err_to_dec_XXX',
      learning_rule='frozen',
      initial_weight=1.0,
      synapse_gain=-1.0  ← 抑制性
  )
  sources=[neuron_err], targets=[decision_neuron_XXX]
```

**θ_error 推导：** 在 ShadowSandbox 安静期（无热源）测量感官通道本底噪声标准差 σ，设 θ_error = 3σ。**必须在阶段A实验中测量后确认。**

---

### 3.4 WTA 决策神经元组

**TYPE: BIO（丘脑门控神经元）**

| 神经元 | 接收的兴奋性输入 | 接收的抑制性输入 |
|:---|:---|:---|
| `dec_ccw` | _conf_ccw 电压 + CPG match bias | GABA误差抑制 + dec_cw侧抑制 |
| `dec_cw`  | _conf_cw 电压 + CPG match bias | GABA误差抑制 + dec_ccw侧抑制 |
| `dec_fwd` | 前进置信度 + CPG match bias | GABA误差抑制 + 两侧侧抑制 |

**侧向抑制：**
```python
# BIO: Ia 互抑制（Eccles 1965）
SynapticBundle(frozen, initial_weight=0.5, synapse_gain=-1.0)
# dec_ccw → dec_cw: 抑制
# dec_cw  → dec_ccw: 抑制
# dec_fwd → dec_ccw, dec_cw: 抑制
```

**W_lateral = 0.5 推导：**
使胜出方（activation ≈ 0.3）对失败方产生约 0.15 的抑制，大于失败方的自然衰减速率（τ_membrane/dt ≈ 0.01），确保在 ~50步内分离。待阶段A测量后确认。

---

### 3.5 低通平滑输出

**TYPE: SEMI（RC 低通滤波器）**

```python
# BIO: 运动输出平滑（小脑深部核团 → 脑干 RC 滤波）
# SEMI: Capacitor as RC low-pass filter
self._smooth_ccw = Capacitor(capacitance=500.0)
# 每步：
self._smooth_ccw.inject(dec_ccw.activation * 0.001, dt)  # 充电
self._smooth_ccw.leak(1/500, dt)                          # 放电
# 输出 self._smooth_ccw.voltage → 接入 yaw 控制（仅阶段C开始）
```

τ_smooth = 500步 推导：Muscle 系统时间常数约 100步，平滑应 5×（过平滑）→ 500步合理，阶段C测量机械冲击后调整。

## 九、静默中继可取部分的纳入策略

静默中继框架（原方案 V1-V4）有三个核心概念与当前架构兼容，可以直接合并到运动势垫支实施方案中，无需废除任何现有拓扑。

### 9.1 自然衰减差异化（对应 λ_metabolic 修剪）

**概念来源：** 静默中继框架的"ORC 修剪"思路，但去除了 Python 语义控制，改为物理速率差。  
**纳入方式：** 在 `DecisionCircuit.__init__` 中，为不同角色的 SynapticBundle 设置不同的 `lambda_metabolic`：

| Bundle 类型 | lambda_metabolic | 含义 |
|:---|:---|:---|
| 高 Xin 核心束（D1弧、relay→column）| 1e-8 | 极慢衰减，几乎永生 |
| 决策框架新束（FSM、置信度）| 1e-6 | 正常衰减，未使用则自然消退 |
| 误差束（GABA抑制）| 1e-5 | 快速衰减，无误差时自动退缩 |

**合规性：** 纯物理速率差，无 Python 条件控制。λ 值在阶段A通过后根据 Xin tension 实测校准。

---

### 9.2 Xin 效率探针（对应互信息→物理替代）

**概念来源：** 静默中继的"代谢-信息效率"指标，将互信息（违规）替换为 Xin tension（物理量）。  
**纳入方式：** 在 `nexus_v1/ledger/` 新增 `XinEfficiencyProbe`（TYPE:INFRA），每 1000 步计算并输出：

```python
# BIO: metabolic cost per unit prediction residual (Bhaskara 2011)
efficiency_ratio = bundle.energy_consumed_per_step / (abs(bundle.xin_tension) + 1e-9)
# 仅输出报告，不驱动任何决策
```

这个探针是**纯只读**的，类似 `EntropyLedger`，仅用于诊断哪些 bundle 高耗低产。
不驱动修剪，修剪通过 λ_metabolic 差异化（9.1）自然完成。

### 9.3 4束全连接方向涌现 MVE（阶段A并行实验）

**概念来源：** 静默中继 V1 的核心假设（全连接初始化→STDP→方向分化）。  
**纳入方式：** 在阶段A的影子模式中，额外添加 **4 条观察束**（不接入任何现有决策路径）：

```python
# BIO: bilateral spinal connections observed during development (Eccles 1965)
# SEMI: frozen-lr observer bundles (lambda=0, stdp_lr=0.01)
self._obs_L2L = SynapticBundle(obs_cfg('obs_phasic_left_to_spinal_ccw', 0.001, 1.0), ...)
self._obs_L2R = SynapticBundle(obs_cfg('obs_phasic_left_to_spinal_cw',  0.001, 1.0), ...)
self._obs_R2L = SynapticBundle(obs_cfg('obs_phasic_right_to_spinal_ccw',0.001, 1.0), ...)
self._obs_R2R = SynapticBundle(obs_cfg('obs_phasic_right_to_spinal_cw', 0.001, 1.0), ...)
# 注：这4条束的输出电流极小（w=0.001），不影响 spinal 神经元激活
```

**200k 步后观察：**
- 若 L2L / R2R（正确方向束）权重增长 > L2R / R2L（错误方向束）：✅ 静默中继 V1 核心假设成立
- 若随机：❌ 静默中继需要更强的结构约束（距离依赖初始化、初始相位偏置）

**代价：** 4 条 bundle，4 个参数，完全不影响主回路和决策框架。21/21 回归必须仍 PASS。
