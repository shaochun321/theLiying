## 现状审计（读代码，未执行仿真）

### 1. Λ_nested的已确认状态（generator_lambda.py）

TSS-2b修正轮实测（对齐`physical_seed`消除命名污染后）：

```
Y_broad^cut ≡ Y_local   (2.328029 == 2.328029, diff = 0.00e+00)
```

local/broad两个collector分别对`N_LOCAL`(9站点)/`N_BROAD`(16站点)求和，
`N_BROAD`限制到`N_LOCAL`支撑集后逐位恒等于`Y_local`——不存在两个算子，
只有一个求和collector作用在两张不同大小的输入表上。补测不可约性：
`Y_broad=3.5424` vs `Y_local+Y_delta=3.9983`（ratio 0.886），次可加性
仅来自collector自身`v_peak`钳位与漏电非线性，local用的是同一个非线性，
广域侧没有出现细尺度不可见的量。这是**输入集合大小差异**，不是尺度
专属变换。已在模块文档（generator_lambda.py第4-30行）与测试恒等断言
里冻结。

### 2. 全局搜索粗粒化/重整化操作

搜索关键词`coarse_grain / downsample / aggregate / pool / pooling /

**没有**任何对同一批传感/激活数据做多分辨率聚合的代码。

### 3. Ω层是否构成尺度转换的候选

`variant_adapter.py:1791`的`_init_thermal_coupling_generators`
（Ω层）用`compute_coupling_weights`对全部64个xi collector按方向
（cos²投影）做加权求和，6个方向性`Ω_dir`各自读取**同一组**64个源，
只是权重按方向变化，不产生不同分辨率下的同一物理量——这是方向投影，
不是尺度转换。同一组数据在Ω层被读取7次（6个方向+1个中心-周围），
每次都是全集，没有"粗粒度版本"和"细粒度版本"的对应关系。

## 审计结论

**当前代码库不存在任何真正的尺度专属转换物理载体。**

现有的"两个不同大小输入集合"资产（`Λ_nested`）已经证明是同一算子
在两张输入表上的读出，不满足尺度算子的不可约性要求（升格所需检验：
`Y_broad`必须无法由`{Y_local, Y_delta}`经细尺度同类运算重构——当前
恰好可以重构，是次可加性由collector自身非线性决定，非结构性差异）。

**明确冻结**：

```
当前尚无Λ物理载体。
Λ_nested^(1)：嵌套支撑集合的结构读出，保持降格状态。
不恢复Λ_nested的尺度生成算子资格。
```

## 若要升格所需的最低条件（复述TSS-2b已列出的要求，本轮不实现）

真正的尺度算子需要证明：广域侧存在一个无法由局部+独有部分重构的量。
候选方向（仅记录，不展开设计）：
- 广域collector的动力学本身引入局部collector没有的非线性状态
  （而非共享同一个非线性）
- 或者存在显式的多站点聚合前处理（如真实的空间平均/降采样），产生
  局部collector访问不到的统计量

两者当前都不存在。
