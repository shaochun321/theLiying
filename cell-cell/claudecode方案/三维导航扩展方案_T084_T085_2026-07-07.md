## 二、T-084：Z轴热觉接线

### 三问

**Q1 生物对应物：**
> BIO: 水生动物体表背腹热感受器的对应电路。背侧（top）贴片热→向上游（趋热水面），腹侧（bot）贴片热→向下游。对应脊髓背侧/腹侧温度感知的背腹轴分化（Craig 2002 Nat Rev Neurosci 3:655；Bhaskara 2011 下丘脑代谢门控背腹分支）。

**Q2 物理结构（完整 Sources → Bundle → Targets）：**

```
col_therm_top_front  ──┐
col_therm_top_back   ──┤ 4条STDP束（gain=+2.5各）→ move_z（excite）
col_therm_top_left   ──┤
col_therm_top_right  ──┘

col_therm_bot_front  ──┐
col_therm_bot_back   ──┤ 4条STDP束（gain=−2.5各）→ move_z（inhib）
col_therm_bot_left   ──┤
col_therm_bot_right  ──┘
```

**增益推导：** 中层 `front → move_x` 单束 gain=+10.0；4个top贴片等效总增益应匹配 → 每束 +10/4 = +2.5。  
4个top柱同时激活时总电流 = 4 × 2.5 × avg_col_act ≈ 10 × avg_col_act，与 `therm_front → move_x` 量级一致。

**所有源神经元（已存在）：**
```python
c.column_neurons['therm_top_front']   # 已存在，已有激活
c.column_neurons['therm_top_back']    # 已存在
c.column_neurons['therm_top_left']    # 已存在
c.column_neurons['therm_top_right']   # 已存在
c.column_neurons['therm_bot_front']   # 已存在
c.column_neurons['therm_bot_back']    # 已存在
c.column_neurons['therm_bot_left']    # 已存在
c.column_neurons['therm_bot_right']   # 已存在
c.motor_neurons['move_z']             # 已存在，物理接入 body.step()
```

**Q3 参数推导：**

| 参数 | 值 | 来源 |
|:---|:---|:---|
| `initial_weight` | 0.1 | 对齐 `therm_front_to_move_x` 初始权重（hebbian.py L596）|
| `weight_max` | 0.5 | 对齐热觉 col→motor 上限 |
| `synapse_gain` | ±2.5 | 推导见上（4束×2.5 = 等效单束10.0）|
| `stdp_lr` | 0.05 | 对齐中层热觉 col→motor STDP 学习率 |
| `learning_rule` | `'stdp'` | 与中层一致，STDP 学习 |
| `bundle_role` | `'feedforward'` | 与所有 col→motor 一致 |

### 实施方式

**不修改 `hebbian.py`**（母代码）。在 `nexus_v1/circuit/variant_adapter.py` 的 `__init__` 末尾加装，通过继承叠加：

```python
# ── T-084: Z-axis thermal navigation bundles ──
# BIO: dorsal/ventral thermoreceptor opponency → vertical thermotaxis
# REF: Craig 2002 Nat Rev Neurosci 3:655; hebbian.py thermal_differential_map pattern
# Q3: gain=±2.5 per bundle → 4 top bundles sum = ±10.0 (matches front→move_x single-bundle scale)
_Z_THERMAL_PAIRS = [
    ('therm_top_front', +2.5), ('therm_top_back',  +2.5),
    ('therm_top_left',  +2.5), ('therm_top_right', +2.5),
    ('therm_bot_front', -2.5), ('therm_bot_back',  -2.5),
    ('therm_bot_left',  -2.5), ('therm_bot_right', -2.5),
]
self.bundles_therm_z: List[SynapticBundle] = []
for col_key, gain in _Z_THERMAL_PAIRS:
    col_n = self.column_neurons.get(col_key)
    mot_n = self.motor_neurons.get('move_z')
    if col_n is None or mot_n is None:
        continue
    b = SynapticBundle(BundleConfig(
        bundle_id=f'{col_key}_to_move_z',
        learning_rule='stdp',
        initial_weight=0.1,
        weight_max=0.5,
        stdp_lr=0.05,
        synapse_gain=gain,
        bundle_role='feedforward',
        coupler_capacitance=1.0,
        coupler_r_leak=2.0,
        coupler_adapt_vth=0.2,
        coupler_adapt_gm=2.0,
    ), sources=[col_n], targets=[mot_n])
    self.bundles_therm_z.append(b)
```

**并在 `get_all_bundles()` 末尾追加：**
```python
bundles.extend(self.bundles_therm_z)
```

**并在 `_propagate_bundles_variant()` 的 col→motor 传播段后追加：**
```python
_iz = 0.0
for _b in self.bundles_therm_z:
    _cur = _b.propagate()
    _iz += _cur[0] if _cur else 0.0
self.motor_neurons['move_z']._membrane.inject(_iz, dt)
```

## 三、T-085：spinal_fwd FORWARD 意图核团

### 三问

**Q1 生物对应物：**
> BIO: 脊髓中间兴奋性中间神经元（EIN，lamprey）— 左右 RS 神经元同时激活（双侧输入）→ 驱动前进 CPG（Grillner 1996 Curr Opin Neurobiol 6:758）。热源正前方时 phasic_left + phasic_right 双侧同时响应 → 前进驱动。类比：CA1 place cells 收敛于 head-direction + speed 信号后驱动前进（O'Keefe 1976）。

**Q2 物理结构：**

```
phasic_left  ──┐ STDP束（w_init=0.001，学习同D1弧）
               ├──→ spinal_fwd ──[frozen, w=0.200, sg=+1.0]──→ move_x
phasic_right ──┘ STDP束（w_init=0.001）
```

**方向性涌现机制（无硬编码）：**
- 热源偏左：`phasic_left > phasic_right` → spinal_fwd 激活弱 → 转向竞争胜出
- 热源偏右：`phasic_right > phasic_left` → 同上，对称
- 热源正前方：两侧 phasic 共同激活 → spinal_fwd 双倍输入 → 前进强于转向

**这与 Mato-Marom (2022 eLife) 的双侧收敛前进驱动机制吻合**——无需 Python if 判断，纯物理电流求和。

**所有新增神经元：**

```python
# spinal_fwd: 双侧前进意图核团（类比 spinal_ccw/cw）
self.spinal_fwd = Neuron(NeuronConfig(
    neuron_id='spinal_fwd',
    capacitance=1.0,
    r_leak=10.0,          # 与 spinal_ccw/cw 一致
    v_peak=0.05,          # 同 spinal_ccw/cw
    v_threshold=0.02,     # 同 spinal_ccw/cw
    tau_membrane=50.0,    # 同 spinal_ccw/cw
    region=0x01,          # REGION_SPINAL
))
```

**Q3 参数推导：**

| 参数 | 值 | 来源 |
|:---|:---|:---|
| `spinal_fwd` 神经元参数 | 与 `spinal_ccw/cw` 完全相同 | EXP-D1: spinal_ccw/cw 参数已校准，生物等效 |
| STDP bundle `initial_weight` | 0.001 | 与 D1 弧 `bundle_d1_phasic_*` 一致（从零学起）|
| STDP bundle `stdp_lr` | 与 D1 弧相同（查 `_stdp_d1_cfg`）| EXP-D1 校准值 |
| `spinal_fwd → move_x` 冻结权重 | 0.200 | EXP: T-071-fix-A Step3 校准值（spinal→yaw=0.200 有效）|
| `spinal_fwd → move_x` gain | +1.0 | 前进驱动（正向，与 yaw 方向无关）|

**注意：** `spinal_fwd → move_x` 的 w=0.200 使前进驱动与转向驱动**同量级**，由双侧收敛自然决出优先级，而不是由 Python 强制选择。

### 实施位置

在 `variant_adapter.py` 中 D1 弧定义之后，继承叠加（**不修改 hebbian.py**）：

```python
# ── T-085: spinal_fwd — bilateral forward intention nucleus ──
# BIO: EIN (excitatory interneuron) receiving bilateral RS input (Grillner 1996)
# Q2: phasic_left + phasic_right (bilateral) → spinal_fwd → move_x (frozen)
# Q3: w_init=0.001 (from zero, same as D1 arc); spinal→motor w=0.200 (T-071 calibrated)
self.spinal_fwd = Neuron(NeuronConfig(
    neuron_id='spinal_fwd', capacitance=1.0, r_leak=10.0,
    v_peak=0.05, v_threshold=0.02, tau_membrane=50.0, region=0x01))

self.bundle_d1_phasic_left_to_spinal_fwd  = _stdp_d1_cfg(
    'phasic_left_to_spinal_fwd', self.phasic_left,  self.spinal_fwd)
self.bundle_d1_phasic_right_to_spinal_fwd = _stdp_d1_cfg(
    'phasic_right_to_spinal_fwd', self.phasic_right, self.spinal_fwd)

self.bundle_spinal_fwd_to_move_x = SynapticBundle(
    _frozen_cfg('spinal_fwd_to_move_x', 0.200, 1.0),
    [self.spinal_fwd], [self.motor_neurons['move_x']])
```

**并在 `_propagate_bundles_variant()` 中：**
```python
# T-085: spinal_fwd bilateral forward drive
_fwd = self.bundle_spinal_fwd_to_move_x.propagate()
self.motor_neurons['move_x']._membrane.inject(_fwd[0] if _fwd else 0.0, dt)
```

**并加入 `get_all_bundles()` 和 `get_all_neurons()` census。**

## 四、与运动势垫支的整合

T-084 + T-085 完成后，运动势垫支决策框架的"动作空间"变为：

| 动作 | STDP 核团 | 置信度信号来源 |
|:---|:---|:---|
| CCW 转向 | `spinal_ccw` | D1 弧学习输出 |
| CW 转向 | `spinal_cw` | D1 弧学习输出 |
| 前进 | `spinal_fwd` | 双侧收敛学习输出 |
| 上升 | `col_therm_top_*` (4个) | Z 轴 STDP 束输出 |
| 下降 | `col_therm_bot_*` (4个) | Z 轴 STDP 束输出 |

置信度积分器（阶段A）需要相应扩展：
- 原方案：`_conf_ccw`, `_conf_cw`（2个 Capacitor）
- 扩展后：`_conf_ccw`, `_conf_cw`, `_conf_fwd`, `_conf_up`, `_conf_dn`（5个 Capacitor）

FSM 预测矩阵也相应扩展：3动作→5动作，输出预测维度：`[ΔT_pred, Δω_pred, Δz_pred]`（3维）。
