## 四、Phase B1a：HC-016 替换（DEVIATION_MOTOR_GAIN → Bundle）

### 三问

**Q1. BIO**：下丘脑-脑干节律耦合（丘脑下部外侧区 → 脑干 CPG）。偏差（deviation）是全局代谢压力，映射为脑干振荡振幅调制，不是直接驱动运动神经元。  
REF: Satinoff 1978 Science 201:16（体温调节行为 = 脑干 CPG 输出，非皮层指令）；  
V3.0 §2.2："deviation 注入脑干节律调制探索振幅（油门），方向由 STDP 差速权重决定（方向盘）"。

**Q2. 物理结构**：
```
CPC.deviation（scalar）
  → CPC Neuron（新建，region=0x04，接收 deviation 信号）
  → [SynapticBundle，跨区 0x04→0x02，τ=5步（d=5mm，v=1000mm/s）]
  → VitalOscillator（region=0x02，振幅调制输入）
```
不再直接驱动 motor_neurons，方向性由 VitalOscillator → oscillator → Encoding → Column → Motor 正常信号链决定。

**Q3. 参数推导**：
- 当前 HC：`motor_drive = (deviation-0.1) × 1000`（dt=0.001 时），典型 deviation≈0.19 → motor_drive ≈ 90A（极大）
- 替代目标：deviation 信号作为振幅调制偏置，量级与 VitalOscillator 输入相当（约 0.1-1.0 A）
- 需要先读 VitalOscillator 的 `step(dt)` 输入量级，再反推 initial_weight
- **这个参数必须在 200k 基线实验后根据实际 deviation 分布校准**，不能预设

**风险**：当前 DEVIATION_MOTOR_GAIN=1000 是系统唯一的强制运动驱动。删除后 Motor 可能长期静默。需在 200k 实验中先观测删除效果，再决定新 Bundle 的增益。

## 六、Phase C1：ν→DA/AGC 接线

### 三问

**Q1. BIO**：  
ν<0（消耗功率 > 注入，系统收敛）→ DA burst（"顿悟"奖励信号）。  
REF: Schultz et al. 1997 Science 275:1593（负 RPE → DA 抑制；正 RPE → DA burst）——此处 ν<0 类比负误差后的收敛确认，触发固化。  
ν>0（注入功率 > 耗散，系统发散）→ AGC gain↑（增大探索噪声，类比 locus coeruleus NE 释放）。  
REF: Aston-Jones & Cohen 2005 Annu Rev Neurosci（LC-NE 在不确定性增高时增益探索）。

**Q2. 物理结构**：
```
NuProbe.system_nu（只读标量，每步计算）
  → NuThresholdNeuron（新建，region=0x04）
      膜电容积分 ν 的持续负向趋势
      v_threshold < 0（负向阈值）→ DA Bundle
      v_threshold > 0（正向阈值）→ AGC Bundle

  → [SynapticBundle：NuThreshold → DA neurons（0x04→0x03）]
  → [SynapticBundle：NuThreshold → AGC input（0x04→0x03）]
```

**Q3. 参数**：
- `NuThresholdNeuron.v_threshold`：设为 `ν_mean ± 1σ`（V3.0 §9 建议），需先跑 200k 统计 ν 分布再设定
- **在统计完成前不设定阈值，不实施此步骤**

## 七、Phase D：趋热反射弧

### D1. phasic_relay → spinal_turn_toward（可塑，STDP+DA门控）

**信号源修正（关键）**：V3.0 §3-C1 明确：  
使用 **phasic_relay**（relay - slow_relay），而非绝对温度。  
原因：绝对温度在热源两侧对称，STDP 会同时强化左右两侧，导致对称死锁。只有 phasic 信号在转向时产生不对称的因果配对（靠近热源时 relay 升高，slow_relay 追上后差值归零，刹车自动解除）。

三问在实施前补全（依赖 Phase C 完成）。
