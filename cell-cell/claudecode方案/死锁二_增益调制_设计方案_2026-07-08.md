# 死锁二（学习目标冗余）修复设计：反射增益调制

**日期：** 2026-07-08
**前置：** DA 源重标已完成（commit 928d92a），锁一（DA 饱和）已解，DA 恢复 RPE 编码。
**目标：** 让 STDP 学习**反射的上下文增益**，而非重建已由硬连线提供的方向极性。
**核心原则：** "乘法门控"必须是物理机制（MOSFET 跨导），不是 Python 的 `*`。

---

## 一、问题复述

当前冗余（缺陷1）：

```
thermo_left ──[frozen, Memristor w=0.3]──→ yaw_ccw   ← 先天反射，恒定增益，已给方向
phasic_left ──[STDP]──→ spinal_ccw ──[frozen]──→ yaw_ccw   ← 学的是同一方向极性（冗余）
```

STDP 分化再"成功"，DR5 也不变——行为由硬连线定死。STDP 应学的是**"在什么上下文下，
放大或抑制这个天生反射"**（增益调制），而非重造方向。

---

## 二、核心洞察：MOSFET 是物理乘法器

补充方案提出 `I_motor = I_thermo × G_eff`，方向正确，但 Python 乘法 = 语义硬编码。
**物理上唯一诚实的实现是 MOSFET 跨导**——栅压调制漏源电导，这本身就是乘法。

代码已有基础设施（`semiconductor.py:116` MOSFET）：

```python
def gated_conduct(self, v_gate) -> float:
    # I = m_gate × gm × f(Vgs)
    return self.m_gate * self.conduct(v_gate)
```

- `m_gate`：慢门控变量（`tau_gate`），由**上下文信号**驱动（缓慢跟踪）
- `conduct(v_gate)`：瞬时电导，由**热反射信号**驱动
- 二者相乘 = **上下文 × 热信号** → 真实物理乘法门控

**先例：** shadow 层 Ca²⁺ 门控（HC-008 二次方 gated_conduct）已用此模式——非新原语。

## 三、架构设计（Sources → Bundle → Targets）

### 3.1 拓扑

```
                      ┌── 上下文源（非方向性）──┐
  hypothalamus_hunger ─[STDP, DA-gated]──┐      │
  DA-RPE / 接近相位    ─[STDP, DA-gated]──┼──→ gain_gate 神经元
  satiety             ─[STDP, DA-gated]──┘      │  (activation → m_gate)
                                                 │
                                                 ↓ 设定 m_gate (慢, tau_gate)
  thermo_left  ──[MOSFET 增益门]──→ yaw_ccw      │  I = m_gate(上下文) × thermo(方向)
  thermo_right ──[MOSFET 增益门]──→ yaw_cw   ────┘  同一 gate 调制两侧
```

### 3.2 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 门控位置 | 突触前（axo-axonic），在 thermo→yaw 束上 | 选择性调制该反射，不影响 yaw 其他输入（Rudomin 1999 突触前抑制） |
| 门的方向性 | **单一全局门**（同调制 L/R） | 方向 100% 来自 frozen 反射；门只管"何时/多强"，**与方向零重叠**=非冗余 |
| 乘法实现 | MOSFET `gated_conduct`（m_gate×瞬时） | 物理跨导，非 Python `*` |
| 门范围 | 有界（如 0.3×~2× 基线增益） | 保护性反射不可完全关断（MOSFET 亚阈→饱和自然有界） |
| 学习 | 三因子 DA-gated STDP（上下文→gate） | DA 现编码 RPE（锁一已解）→ "增益在何时带来奖励"可学 |

### 3.3 为什么这不冗余（关键）

- **方向**：始终来自 frozen `thermo_left→yaw_ccw`（L/R 反射），STDP 完全不碰。
- **增益**：门由**非方向性上下文**（饥饿/DA/饱腹）驱动，STDP 学的是"上下文→增益档位"。
- 二者正交：STDP 不再重造方向 → 不再冗余 → 有了"学习的空间和必要"。

## 四、三问（Q1/Q2/Q3 草案）

**Q1 生物对应物：**
- 突触前抑制门控初级传入反射增益：Rudomin & Schmidt 1999, Exp Brain Res 129:1（脊髓 Ia 突触前抑制门控牵张反射）。
- 动机状态（饥饿）调制觅食反射增益：AgRP/下丘脑 → 觅食反射易化（Sternson 2013）。
- MOSFET 跨导 ≈ 突触前终末的电导型增益控制。

**Q2 物理结构：**
- 新神经元 `gain_gate`（1 个全局，或对称，region 待定）。
- 上下文源 → [STDP, DA-gated Bundle] → gain_gate。
- gain_gate.activation → MOSFET.m_gate（经 update_gate，tau_gate 慢）。
- thermo_L/R → MOSFET.gated_conduct → yaw_ccw/cw。
- **实现为新组件**（如 `GatedReflexBundle`，独立文件），经 adapter 继承接入，**不改母本**。

**Q3 参数依据：**
- 门范围：MOSFET v_threshold/gm 标定使 m_gate∈[0.3,2.0]（反射不可关断，上限防失控）。
- 初始 gate = 1.0×（基线）→ 初始无行为改变（诈胡防复发）。
- tau_gate：上下文是慢变量（饥饿 τ~1000+ 步），tau_gate 匹配。
- STDP lr/eligibility：沿用现有 DA-gated 三因子束参数。
- 每个数值须在实施时补 REF/推导，不得无源填写。

## 五、涌现验证签名（这才是"STDP 有意义"的证明）

关键：frozen 反射的增益是**恒定**的，与生理状态无关。因此——

> **若学习后热趋性强度随饥饿变化（饿→强趋热，饱→弱/停），就证明增益调制涌现了**，
> 因为这是 frozen 反射**做不到**的行为。

判定（配合诈胡消融）：
- E1 **上下文调制**：DR5/接近速度 在 `fill<0.5` 显著高于 `fill≈1.0`（增益随饥饿开合）。
- E2 **学习依赖**：消融上下文→gate 束（冻结 STDP）后，E1 的调制消失/减弱（证明是学来的非天生）。
- E3 **权重分化**：上下文→gate 权重随"放大反射→得奖励"而增强（DA-gated LTP）。

注：本方案目标是"**学会何时/多强地趋热**"（增益），**不是**"学会往哪个方向"（方向仍天生）。
后者需先解缺陷2（1D 梯度 + 参考系漂移），是更大改动，不在本方案。

## 九、反馈整合（v2，2026-07-08）

对《交叉比对/反馈.md》逐条评判，采纳有效项，澄清一处框定。

### 9.1 隐忧2（混淆路径）— **最有价值，采纳，改验证设计**

反馈正确指出：`hunger→DA→VitalOsc` 已存在（T-048），E1（饿→趋热强）可能由此**直接路径**
主导，gain_gate 实际没学到东西；简单消融门后直接路径仍在 → 假阳性。

**采纳，但解法比反馈更强——不换上下文，改用差分消融（within-subject）：**

> E2 改为 **gate-ON vs gate-FROZEN 两臂，直接路径在两臂都保留**。
> 门的因果贡献 = E1(gate-ON) − E1(gate-FROZEN)。直接路径在两臂是**恒定基线，自动抵消**。

这比"换正交上下文"更干净：satiety 同样喂 DA（satiety_to_da）与 vital，并不正交；差分消融把
任何非门的 hunger 效应作为公共基线扣除。**新判据 E2′：hunger-调制幅度(gate-ON) 显著 > (gate-FROZEN)。**
（可选加强：消融时同步冻结 `hunger→DA` 束，双重隔离。）

### 9.2 隐忧1（缺陷2 参考系）— 澄清框定 + 采纳旋转验证

**澄清：gain_gate 本身是旋转不变的。** 门 = f(hunger)，hunger 是**标量代谢态、无空间参考系**。
它对 thermo_L/R 同倍缩放，body 旋转后 thermo_L/R 重新指派是 **frozen 反射固有的问题（缺陷2）**，
门只是等倍缩放、不加剧也不修复它。所以"增益调制在旋转后失效"不成立——**失效的是方向（缺陷2），
不是增益门**。

**采纳反馈的旋转验证，但作为"作用域边界确认"而非门的风险：** MVE 加随机初始朝向，预期观测到
**门调制(增益随饥饿开合)在旋转后仍稳定，而方向正确率(DR5)随旋转退化**——正好把缺陷2 与死锁二
的边界钉死，避免过早宣布"方向也解了"。

### 9.3 隐忧3（对称性）— 采纳，加验收判据

单一全局门 → 同一 m_gate 乘两侧，构造上对称。仍加验收：**E4 两侧增益差异 < 5%**（防实现 bug
或 gain_gate 意外带方向偏差重新引入冗余）。

### 9.4 逻辑断点补充

| 断点 | 补充 |
|------|------|
| 门范围 0.3×~2× 来源 | **物理+生物双锚**：MOSFET 亚阈(下界)→饱和(上界)工作区提供物理有界；生物锚=突触前抑制调制反射约 2~3× 但极少全抑（Rudomin 1999）。实施时 Q3 用 v_threshold/gm 标定到该区间并补 REF。 |
| tau_gate vs DA τ | **两个时间常数、两个角色，不该混：** m_gate 追踪**行为相关的上下文**(hunger τ~1000)，要够快调制行为 → tau_gate≈1000；DA_ema(τ=5000)门控**学习**(STDP eligibility)，是慢奖励积分。二者解耦：一个管"此刻增益多大"，一个管"这次增益改变要不要固化"。 |
| E2 假阴性 | 由 §9.1 差分消融解决：不看绝对残留，看 ON−FROZEN 差值。 |
| 多上下文汇聚（和/竞争）| **加法（KCL 汇入同一 gate 神经元）**，非竞争。hunger/DA-RPE/satiety 可共存（非互斥），多束电流在 gate 神经元求和，由其膜动力学积分。竞争(WTA)只适用于互斥选择，此处不适用。 |

### 9.5 更新后的验收判据（MVE）

- **E1** 上下文调制：接近速度/趋热增益 在 fill<0.5 高于 fill≈1.0
- **E2′** 差分因果：E1(gate-ON) 显著 > E1(gate-FROZEN)　←　隔离直接路径混淆
- **E3** 权重分化：hunger→gate 权重随"放大反射得奖励"增强（DA-gated LTP）
- **E4** 对称性：gate 对 L/R 增益差异 < 5%
- **E5**（旋转边界）：随机初始朝向下，门调制稳定而 DR5 随旋转退化（钉死缺陷2 边界）
- **回归** 21/21 PASS；上线前跑 T-084 式 DA 源分解确认门不引入新正反馈
