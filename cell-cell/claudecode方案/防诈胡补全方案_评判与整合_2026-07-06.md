η% 累积 Foraging 步数约 9180 步，在 step ~115k 时 η 跌破 8% 分界线。  
最终预测 η ≈ 9180/200000 = **4.59%**，低于 8% 阈值。

- 效果机制：BMR 加快能量消耗 → body 在热源附近短暂游走期间 fill 下降更快 → `fill < 0.85` 条件更易满足 → Foraging 窗口占比增加

### 1.3 DSI 量纲标注（用户建议 Adjustment 3）

本次 DSI = 4,738,187 的根因：
- 单热源场景下 spinal_ccw 信号持续单向占优，σ_net ≈ 0
- 分母趋近 `EPS_DSI=1e-6`，DSI 爆到百万量级

**DSI 阈值 1.0 的适用范围重新定义**：

| 场景 | DSI 含义 | 阈值 | 备注 |
|------|---------|------|------|
| 双热源竞争（T-063）| 两方向信号交替，σ 有意义 | **> 1.0** | 原始设计意图，有效 |
| 单热源单侧锁定（T-062）| 信号单向，σ→0，DSI→∞ | **不适用，仅记录** | 不作为 PASS/FAIL 依据 |

后续实验报告中，DSI 仅在双热源场景下用于判定。

## 二、交叉接线翻转实验评判

### 2.1 原始方案的三个问题

**问题 A：实现路径违反母本约束**

D1 phasic 束（`bundle_d1_phasic_left_to_spinal_ccw` 等）在 `VariantCircuit.__init__` 内部构建，无外部配置接口。方案中的 `configs_swapped` 是伪代码，若创建新束而不移除原有束，等于在正确束和翻转束之间竞争，而非纯翻转测试。

**问题 B：三因子 STDP 不具备逆学习能力**

方案预设的纠错逻辑依赖"错误→DA降低→LTD削弱错误束"，但系统 STDP 架构为：

```
Δw ∝ eligibility_trace × DA_concentration
```

- DA 在接近热源时上升，远离时下降/归零
- 翻转束使 body 远离热源 → DA=0 → 正确束无法获得 LTP → 无纠错动力
- 这是强化学习的探索-利用困境：无 DA → 无学习，无学习 → 无 DA

需先核查 `bundle.py` 的 STDP 更新代码：LTD 项（`eligibility_ltd_rate`）是否完全依赖 DA，还是有基线 LTD（即使 DA=0 时也会削弱 causal 时序错误的连接）。若 LTD 不依赖 DA，翻转实验在技术上仍有可能成功。

**问题 C：DR5>60% 阈值过严**

正确接线系统（T-059）经 200k 步达到 DR5=66.3%，且期间绝大多数时间 body 已在热源中心（DR5 此时归零，因无方向梯度）。翻转接线系统的起始动态更差，200k 步内能否逆转并达到 60% 存疑。建议降低为 DR5>45%（优于随机基线 ~50% 的统计显著性即可），配合权重比判定。

### 2.2 修订后的可行实现方案

**无需修改母本代码的实现路径**：

```python
# Step 1：正常创建电路
c = VariantCircuit()

# Step 2：将原有 D1 束权重置为接近零（"软断开"）
for b_name in ['bundle_d1_phasic_left_to_spinal_ccw',
                'bundle_d1_phasic_right_to_spinal_cw']:
    b = getattr(c, b_name, None)
    if b and b._memristors:
        for row in b._memristors:
            for m in row:
                m.w = 0.001   # 极小但非零，保留 LTD 退化通道

# Step 3：获取源/目标神经元（需读 variant_adapter 确认属性名）
# 预期：c.d1_phasic_left_neuron, c.d1_phasic_right_neuron
#        c.spinal_ccw, c.spinal_cw
phasic_L = getattr(c, 'd1_phasic_left_neuron', None)   # 需核实
phasic_R = getattr(c, 'd1_phasic_right_neuron', None)  # 需核实

# Step 4：手动创建翻转束（post-init 注入）
from nexus_v1.circuit.bundle import SynapticBundle, BundleConfig

cfg_swap_L = BundleConfig(
    id='swap_phasic_left_to_spinal_cw',
    initial_weight=0.010,
    weight_max=0.300,
    stdp_lr=0.001,
    eligibility_ltd_rate=0.02,
    plasticity=True,
)
b_swap_L = SynapticBundle(cfg_swap_L, [phasic_L], [c.spinal_cw])

cfg_correct_L = BundleConfig(
    id='correct_phasic_left_to_spinal_ccw',
    initial_weight=0.010,
    weight_max=0.300,
    stdp_lr=0.001,
    eligibility_ltd_rate=0.02,
    plasticity=True,
)
b_correct_L = SynapticBundle(cfg_correct_L, [phasic_L], [c.spinal_ccw])

# 同理创建 phasic_R 的翻转束和正确束（共4束）
extra_bundles = [b_swap_L, b_correct_L, b_swap_R, b_correct_R]

# Step 5：在 step 循环中手动驱动额外的束
for step in range(STEPS):
    c.step({}, DT)
    for b in extra_bundles:
        b.step(DT)
```

**前置确认（实现前必须完成）**：
1. 读取 `variant_adapter.py`，确认 phasic_left/right 神经元的实际属性名
2. 确认 `SynapticBundle.__init__` 签名（sources/targets 顺序、BundleConfig 必填字段）
3. 确认 `bundle.py` 中 LTD 是否依赖 DA（核心可行性条件）

### 2.3 修订后的判定标准

原始方案判定标准修订：

| 指标 | 原始标准 | 修订标准 | 修订原因 |
|------|---------|---------|---------|
| DR5% | >60% | >45% | 翻转场景动态更差，60% 过严 |

## 三、镜像几何实验（新增替代方案）

**原理**：比翻转接线更简单的诈胡测试——不改代码，只改热源和 body 位置，翻转空间几何关系。

若 STDP 真正追踪"哪侧更热"，几何翻转后权重胜出方应翻转：

```
正常几何：body=[10,50,25] → src=[70,50,25]（body从-x方向接近）
          → 某方向（如 CCW）胜出

镜像几何：body=[90,50,25] → src=[30,50,25]（body从+x方向接近）
          → 若真正学习：对应反方向（如 CW）胜出
          → 若结构性偏置：仍然 CCW 胜出
```

| 实验组 | 几何配置 | 代码改动 | 成本 |
|--------|---------|---------|------|
| G1（正常）| body=[10,50,25], src=[70,50,25] | 无（即 T-062）| 已有数据 |
| G2（镜像）| body=[90,50,25], src=[30,50,25] | 仅改2行参数 | 极低 |

**通过标准**：G1 和 G2 的权重胜出方向不同（CCW/CW 与接近方向相关）。

**优先级**：建议作为 T-066 加入实验序列，在交叉接线翻转实验之前执行，低成本给出初步答案。
