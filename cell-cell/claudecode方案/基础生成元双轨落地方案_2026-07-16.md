## 一、方案评估

### 1.1 优点（与项目规范高度一致，建议采纳）

| 维度 | 评价 |
|---|---|
| 结构优先、零语义硬编码 | 完全符合 RULES.md / CLAUDE.md「Structure-First」：禁 `sign()`/点积/Python 除法，方向从结构涌现 |
| 只用已有组件 | 明确禁止新造 `DelayLine`/`RatioDivider`/`DirectionOperator` 类，强制复用 Neuron/SynapticBundle/Collector |
| Phase 门控 + 全量回归 | 每阶段专项探针 + 完整回归双通过才进下一层——与刚完成的**温感 Ω 层**节奏一致（`memory: project_omega_coupling_generator_complete`） |
| 终止于 Collector | 不接下游，回归 21/21 不受冲击（Ω 层同样策略：collector 神经元排除出 census） |
| 已吸取历史教训 | 显式区分「纯延迟 vs RC 痕迹」、用 `synapse_gain=-1.0` 实现抑制（Memristor 权重非负） |

### 1.2 需要澄清/修正的隐患（落地前必须处理）

1. **「ξ」一词二义性（关键）**。方案里的「ξ Collector」实指前庭12/感温64的**尖峰特征检测器**（sensory feature），而代码里 `Xin=|ξ|` 特指 `BundleConfig.xin_tension`（PI 预测残差）。二者**不是同一个东西**。方案沿用的是前者（特征检测器）的口径——这对温感轨没问题，但对运动轨会造成 ξ 源歧义（见第三节路线分析）。

2. **r→ 与现有温感 Ω 层不可混淆**。温感 Ω 层的 6 个方向 collector 是**预设方向模态**（cos² 几何硬接线），而方案的 r→ 是**生成元之间的双向结构传播**（ξ₁↔ξ₂↔ξ₃ 最小三节点链）。二者是不同结构，r→ 必须新建三节点链，不能复用 Ω 的 RF collector 冒充完成。方案第 115 行已自我声明这一点——需在落地时严格执行。

3. **rρ 是替换硬编码的机会**。运动侧 `MotionState.polarization = max|ν_i|/Σ|ν_i|`（`variant_adapter.py:2166`）是**Python 直接算的占比**——正是方案禁止、rρ 应结构化替代的对象。这是把 rρ 应用到运动侧的**最强理由**。

4. **RC 时间尺度必须逐生成元重标**。Ω 层血泪教训（`memory: project_omega_coupling_generator_complete`）：新聚合层复用旧电容常量 `C=0.5`，因上游阵发性输出而**完全不发放**；修复 = 独立 `_OMEGA_*_CAPACITANCE=0.05/0.002`。每个新生成元都要走一遍 Phase 0 的峰值/衰减/静息探针重标，禁止复用 ξ 层电容。

5. **census / T4.1 保护**。新 collector 神经元必须**排除出 `get_all_neurons()`**（照搬 Ω 层策略，避免稀释 energy_per_neuron → 破坏 T4.1 col→motor STDP）；bundles 则**必须进 `get_all_bundles()`**（供 Noether/Xin/熵账本追踪）。方案 census 要求已覆盖，但需显式写死这条排除规则。

**评估结论：方案方法论可直接采纳。** 温感轨基本无障碍；运动轨需先解决 ξ 源定义（下节）。

## 二、双轨并行架构

两条**独立**轨道，各走一遍 Phase 0→4，各用独立分支/探针/工程报告，**不建跨模态 Bundle**。共享同一套 config-factory 范式（`_omega_ensemble_config`/`_omega_collector_config` 的复制—重标模式）。

```
温感轨 (thermal track)                运动轨 (motor track)
ξ源 = 64 warm/cool collectors        ξ源 = 见第三节路线分析
   │                                    │
   ├ Phase0 基线+探针                    ├ Phase0 基线+探针
   ├ Phase1 r≺（时间）                   ├ Phase1 r≺（时间）
   ├ Phase2 r→（三节点链）               ├ Phase2 r→（三节点链）
   ├ Phase3 rρ（占比）                   ├ Phase3 rρ（占比，替换 polarization 硬编码）
   └ Phase4 三路并行无串扰               └ Phase4 三路并行无串扰
```

- 探针命名：温感轨 `T-TG*`（r≺=`T-TRP`, r→=`T-TRD`, rρ=`T-TRHO`），运动轨 `T-MG*`（`T-MRP/MRD/MRHO`）。各自独立文件，**不塞进 count-locked `test_regression.py`**。
- 每轨每 Phase：独立分支 + commit + 探针文件 + 工程报告（存 `cell-cell/工作报告/`）。

## 三、运动侧 ξ 源 —— 路线分析报告

**核心事实**（已代码核实）：
- Bundle 读取源信号只有三条路（`bundle.py:243-256`）：spiking→`pre_trace`、spiking+CRI→`calcium_rate`、非spiking→`activation`。**源必须是一个 Neuron 对象**。
- `xin_tension` 是 `BundleConfig` 上的 **float**（`bundle.py:44`），**不是** Neuron 属性 → **Bundle 无法直接读取**。
- 运动侧已存在「误差神经元」范式（`decision_adapter.py:272-275`）：`err_dT.step(pred.activation − actual, dt)`——把残差作为电流注入神经元，转成可被 Bundle 读取的 activation。

### 三条路线对比

| | 路线1 复用运动神经元 | 路线2 新建运动ξ采集层 | 路线3 复用 xin_tension |
|---|---|---|---|
| ξ 源 | `move_x/y/z`、`yaw_ccw/cw` 的 activation | efference error / ν_xyz 包成误差神经元 | 各运动 Bundle 的 `xin_tension` |
| 语义 | 运动**特征/状态**（非残差） | 运动**预测残差**（真 ξ） | 代码定义的**真 ξ**（PI 残差） |
| 结构可行性 | ✅ spiking 神经元，`pre_trace` 直接可读，**零新结构** | ⚠️ 需建误差神经元层，但**范式已存在**（err_dT/err_domg） | ❌ float 无法被 Bundle 读取 |
| 与方案 ξ 口径一致性 | ✅ 与温感64（也是特征检测器，非残差）**同口径** | ✅ 最贴近「ξ=预测残差」原意 | ✅ 最贴近，但… |
| 硬编码风险 | 无（走 pre_trace） | 低（pred−actual 是差分放大器，同 yaw ccw−cw 已被接受的边界） | **高**：直接读 float = 绕过 Bundle = 违反「禁绕 Bundle 私读膜电位」 |
| 工作量 | 最小 | 中（但部分已有 err_dT/err_domg 可复用） | —— |

### 关键结论（对用户「1和3都可以」的修正）

> **路线3 无法独立实现**：`xin_tension` 是 float，要喂给生成元**必须先用一个神经元把它注入转成 activation**——而那正是**路线2 的机制**。因此「naive 路线3」= 绕过 Bundle 直读 float = 硬编码违规；「proper 路线3」在结构上**塌缩成路线2**。
>
> 真正的选择只在 **路线1（运动特征，最小）** 与 **路线2（运动残差，最忠实）** 之间。

### 推荐

**Phase 0～4 首轮走路线1**：
- 理由：① 与温感轨 ξ 口径严格对称（两轨都以「底层尖峰特征检测器输出」为 ξ，方法论完全平行）；② 零新结构，回归风险最低；③ `move_x/y/z`+`yaw_ccw/cw` 是真实物理运动信号，r≺/r→/rρ 之间的关系（谁先动、传播方向、轴间占比）有明确物理意义。
- rρ 首轮即可结构化替代 `polarization` 硬编码（轴间占比 = move_x:move_y:move_z 的 rρ）。

**路线2 作为后续「真 ξ」升级**（独立 Phase，非首轮）：复用已有 `err_dT/err_domg` 误差神经元范式，把 efference error 包成运动残差 collector。等首轮验证方法论跑通后再上，避免一次引入两处新结构。

**路线3（naive）拒绝采用**（float 绕 Bundle）；如坚持要 xin_tension，等价于先做路线2。

## 四、Phase 落地清单（每轨相同骨架）

严格顺序 `0→1→2→3→4`，每阶段专项探针 + 全量回归双通过才进下一层。复用 Ω 层的 `_init_*` / `_step_*` / config-factory 范式（`variant_adapter.py:1791-1908`）。

### Phase 0 —— 基线与夹具隔离（不新增关系电路）
- 核实 ξ 源：温感轨 = `thermal_quantum_collectors`（64）；运动轨 = `motor_neurons['move_x/y/z']` + `yaw_ccw/cw`。
- 统一读取方式（`pre_trace`），隔离测试用 `SpikeGenerator`（仅夹具，验证后替换为真实 ξ）。
- 建立通用**峰值/衰减/静息**探针 + RC 标定夹具（照 `_diag_omega_burst.py`），**逐生成元独立电容常量**。
- 确认回归基线 21/21。

### Phase 1 —— r≺ 时间关系（双向历史痕迹耦合）
- 每对 ξ 建**双向**结构：`ξₐ→历史痕迹支路(非spiking Neuron + 膜RC)─┐ + ξᵦ ─┘→ ξₐ≺ξᵦ Collector`，反向对称。
- 用**现有非spiking Neuron 的膜 RC 痕迹**构造历史支路（**禁**新造 DelayLine；`synaptic_delay_steps` 未经核实不得假设存在——已确认 `BundleConfig.delay_steps` 存在于 `bundle.py:266-269`，可用作纯延迟，但历史「痕迹」用 RC 而非纯延迟）。
- 多时间尺度 + 独立 Collector，暂不接下游。

### Phase 2 —— r→ 方向关系（最小三节点链 ξ₁↔ξ₂↔ξ₃）
- 每对相邻节点建 a→b、b→a 两条传播路径 + 两个独立方向响应 Collector。
- **禁**运行时坐标差/`sign()`/点积/直接写 ±X 标签。方向从传播结构涌现。
- 不复用温感 Ω 的 RF collector 冒充（那是预设方向模态，非双向结构关系）。

### Phase 3 —— rρ 占比关系（共享池 + 分流抑制）
- 结构：`ξₐ→独立兴奋通道─┐ + ξᵦ─┘→共同总量池→共享抑制→ρₐ/ρᵦ 双 Collector`。
- 抑制用 `synapse_gain=-1.0`（非负 Memristor）。
- **禁** Python 算 Iₐ/(Iₐ+Iᵦ)。验收 = 占比排序正确 / 交换输入则交换输出 / 共同放大关系稳定 / 双输出近似互补。称「参与占比关系原型」，不宣称严格数学比例。
- **运动轨额外收益**：用 rρ 结构化替代 `variant_adapter.py:2162-2168` 的 `polarization` Python 除法（登记为一次硬编码消除）。

### Phase 4 —— 三路并行无串扰
- 同一组 ξ 同时接 Ω≺/Ω→/Ω_ρ，验证：单 ξ 能否被三类 Bundle 同时读取 / 是否对上游 Collector 形成意外负载 / 三类关系互不替代 / 三类 RC 无串扰 / census 完整 / frozen 权重不变 / 全量回归通过 / 运行成本可接受。
- **仍不接** Γ/Motor/Shadow/TOPR/Xin/STDP/DA/CPC。

## 五、关键约束（落地时写死）

1. **census 规则**：新 collector 神经元 → **排除** `get_all_neurons()`（护 T4.1）；新 bundles → **进** `get_all_bundles()`（供账本）。照 `variant_adapter.py:4279-4290 / 4381-4396`。
2. **全 frozen**：`learning_rule="frozen"`, `initial_weight==weight_max`, `remodel_cost_kappa=0.0`（`bundle.py:336-337` 短路 learn）。
3. **独立 RC 常量**：每生成元自带电容/r_leak，禁复用 ξ 层 `C=0.5`（Ω 教训）。
4. **不改母本代码**：全部走 `VariantCircuit` 的新 `_init_*`/`_step_*` 方法叠加（RULES.md）。
5. **强制三问**：每个新 Bundle 先答 Q1 生物对应物 / Q2 物理结构 Sources→Bundle→Targets / Q3 参数依据（`# BIO:`/`# REF:`/`# EXP:` 注释），答不出即停。
