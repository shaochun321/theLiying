## 二、术语与命名规范（写入代码，不止写报告）

三个「ξ」是不同工程对象，必须在**代码命名 + 注释**中区分：

| 符号 | 工程对象 | 含义 | 本方案用法 |
|---|---|---|---|
| **ξ^occ** | 感温/运动 Collector（尖峰发生检测器） | 局部物理发生 | 本轮双轨的 ξ 源 |
| **ξ^err** | 误差 Neuron/Collector（pred−actual） | 预测—实际残差发生 | 运动路线2，后续独立构建 |
| **ξ^PI** | `BundleConfig.xin_tension` | Bundle PI 张力参数 | 禁止直接读取喂生成元 |

- 新生成元命名前缀统一体现 `occ`（如 `occ_rprec_*`、`occ_rpart_*`），避免与 `xin_tension` 混淆。
- 报告与注释中一律用上表符号，不再泛称「ξ」。

**关系生成元命名（纳入批判二点8）**：占比关系首版一律命名 **r_part / 参与竞争关系原型**（代码前缀 `rpart`），**不得**在实测「共同尺度近似不变」前提前叫 `r_ρ` 或宣称除法归一化。达到二级验收后才升格 `r_ρ`（重命名 + 报告确认）。

## 三、运动侧 ξ 源路线（路线1 优先，路线1/2 并存非替换）

**核心事实**（已代码核实）：Bundle 只能读 Neuron 的 `pre_trace`/`activation`/`calcium_rate`（`bundle.py:243-256`）；`xin_tension` 是 `BundleConfig` 上的 float（`bundle.py:44`），Bundle 读不到 → 路线3（直读 xin_tension）绕 Bundle = 硬编码违规，不采用。

**首轮走路线1（运动局部发生生成元 ξ^occ）**：以 `move_x/y/z`、`yaw_ccw/cw` 的 spiking `pre_trace` 为 ξ^occ 源。零新结构，与温感轨 ξ^occ 口径严格对称。

**重要更正（纳入批判点3）**：路线1 的准确表述是**「运动局部发生生成元轨」**，不是「真 ξ 预测残差轨」。路线2（ξ^err，用已有 `err_dT/err_domg` 范式包 efference error）表达的是**不同的物理对象**：
- 路线1（ξ^occ）：运动**发生了什么**；
- 路线2（ξ^err）：预测与运动之间**破缺了什么**。

二者**未来可能并存，而非必然替换**。路线2 作为后续独立构建，不称为路线1 的「升级」。

### T1 —— r≺ 时间关系（二元，最小支撑）
- **只选 2 个真实 ξ^occ**（ξ_a, ξ_b），完成一个二元时间关系生成元 r≺^ab。
- 双向结构：`ξ_a→历史痕迹支路(非 spiking Neuron + 膜 RC)─┐ + ξ_b─┘→ ξ_a≺ξ_b Collector`，反向对称。

### T2 —— r→ 方向关系（三节点局部邻接链）【Gate C：先出电路定义报告】
**编码前必须先单独出一份「方向关系电路定义报告」**（纳入批判二点7）。核心：**方向不是 Bundle 名称**——把 Bundle 命名为 a→b 不会让它自动成为方向关系；若只建 `ξ_a→D_a→b`、`ξ_b→D_b→a`，输出只能证明「哪个源激活」，退化成源身份检测。

方向检测必须**同时**满足三要素：
1. **结构邻接**：(a,b) 确实相邻（用 T0 冻结的邻接边）；
2. **起点痕迹**：ξ_a 的活动沿 a→b 支路传播（传播中继/RC 痕迹 `P_a→b[ξ_a](t)`）；
3. **终点耦合**：传播痕迹与 ξ_b 的**当前**活动在终点耦合。

最小结构（每条邻接边双向）：
```
ξ_a → a→b 传播中继/RC痕迹 ─┐
                            ├→ D_a→b Collector    d_a→b(t) = C(P_a→b[ξ_a](t), ξ_b(t))
ξ_b ────────────────────────┘
```
- 与 r≺ 的区别（我方补充，批判未点破）：仅「邻接」不足以区分 r→ 与「恰好邻接的 r≺」——若传播支路与 r≺ 历史支路用同一种**对称** RC 机制，两者无法区分。真正的区别须是：**r→ 的 a→b 与 b→a 传播支路物理不对称**（方向性的延迟/衰减，体现空间传播），而 r≺ 的两条历史支路对称（只比先后）。此点写入 T2 定义报告。
- **运行时方向不得靠坐标计算**（禁 `sign()`/点积/坐标差/写 ±X 标签），方向从「传播痕迹 × 终点发生的重合」物理涌现。
- 不复用温感 Ω 的 RF collector 冒充（那是预设方向模态）。

### T3 —— r_part 参与竞争关系（先二元后三元；升格 r_ρ 需实测）【Gate D】
**首版命名 r_part（参与竞争关系原型），不叫 r_ρ**（纳入批判二点8，结论保留）。但**前提须纠正**（我方代码核实）：批判称「项目无精确除法组件」不准确——`DivisiveNormalizationReceptor`（`compensation.py:295-324`）已实现 Carandini-Heeger 除法归一化 `R_i=L_i^n/(σ^n+Σ_j L_j^n)`，且是**分流抑制物理电路，非 Python 除法**（`I_eff=I_raw×σ/(σ+V_pool)`，复用 Capacitor 池），已在 shadow enc 使用（`shadow_sandbox.py:52`）。**局限**：它是 per-neuron 独立池（`shadow_sandbox.py:537`），追踪单神经元自身输入的时间平均（增益控制），**不是**跨通道横向池 Σ_j——这才是"降格 r_part"结论仍然成立的**真正原因**。

因此 T3 设两条候选路径，设计报告须先择定：
- **路径 A（减法抑制，保守，批判原方案）**：`ξ_a→独立兴奋通道─┐ + ξ_b─┘→共同总量池→共享减法抑制(synapse_gain=-1.0)→ y_a/y_b`。产生 `y_a≈φ(I_a−λI_Σ)`，与除法归一化不天然等价（共同放大 αI 时可能整体增大/饱和/归零）→ 只能停在 r_part。
- **路径 B（分流抑制，逼近真占比，我方新提）**：把「共同总量池」接 **DN 式分流** `×σ/(σ+V_pool^shared)`（V_pool 来自 a、b 共享横向池，而非 per-neuron），物理逼近 `I_a/(σ+ΣI)`，仍是合法分流抑制电路（非 Python 除法）。**状态更新（2026-07-16，T3-B/T3-C0/批判十）**：路径 B 已实现并接成真正 Neuron/Bundle 电路（`ratio_r_part.py`），Gate D 一级验收通过；T3-C0 四层信号审计证实 **DN 输出层（`y_a/y_b`）比例精确线性**，但 **channel Neuron 的公开 `activation` 导出层不合格**（未饱和区被二次门控平方、饱和区被硬钳位彻底抹平比例）——正在用 T3-C1R（见第十九节）解决输出换能问题，未通过前仍称 r_part，不升格 r_ρ。
- 两路都**禁** Python 直接算 `I_a/(I_a+I_b)`。先二元后三元（二元通过才扩展三元）。
- **两级验收**：
  - **一级（必须达到）**：较大输入→较大输出 / 交换输入则输出交换 / 单输入时对应通道占优 / 等强输入输出近似相等 / 静默时无虚假占比。
  - **二级（实验性目标）**：共同放大时排序保持 / 输出差异对共同尺度相对稳定 / 多通道竞争后近似归一化 / 输出总量变动在有限范围。
- **只有二级（共同尺度近似不变）经实测证明后，才升格重命名 r_ρ 并在报告确认**；否则一律停在 r_part。

## 十三、T2 物理前提重审：温度场无传播速度，观测时差是身体运动学产物（2026-07-16，我方独立发现）

### 13.1 核查结论

用只读探索核查 `components/world.py` 的世界热场模型，得到以下事实链：

1. **`HeatSource.effective_temperature()`**（`world.py:39-95`）：单点位置 + 有限空间范围，`温度 × (1-d/r)` 线性衰减；热源可缓慢漂移（`_drift` speed=0.001/step），但**没有传播速度概念**。
2. **`World.temperature_at(pos)`**（`world.py:553-571`）：对给定世界坐标，所有热源做**瞬时空间叠加**——只有距离项，**没有任何时间/波速/传播项**。给定坐标 → 温度当场确定，不存在"这个温度值传到这里花了多久"的物理过程。
3. **`SkinPatch.world_position(body)`**（`world.py:177-194`）：把采样点的 `local_offset`（身体局部坐标系固定偏移）先绕 `body.yaw` 旋转、再加 `body.position` 平移，得到世界坐标。
4. **T0/T2 用的 32 个感温球面采样点**（`variant_adapter.py:1702-1729`，`fibonacci_sphere_points(32,2.0)`）**全部是 body-frame 固定偏移**——身体转向/平移时，这些点随身体刚体运动。

**结论**：给定当前世界模型，感温点 28 号与 31 号先后"感受到"温度变化的时间差，**主要由身体整体转向速度（yaw 角速度）/ 平移速度决定**——两点被身体运动依次带入温度梯度区的先后——**与两点间的局部球面距离（~1.09）/ 所谓"热传导速度"几乎无关**。也就是说：

> **T2 报告 §四.2 依赖的物理假设"`delay_ab = d_ab/v_edge`（几何距离/传导速度=传播延迟）"，在当前世界模型里没有对应的真实物理过程。**

### 13.2 这比第十二节 12.2 第3点更深一层

12.2 第3点（批判五）指出的是"升格判据不可操作"——即使 delay 机制本身没错，也无法证明它和 r≺ 有本质区别。**本节指出的是更早一步的问题**：delay 机制本身要建模的"沿边传播"这件事，在当前世界物理里根本不存在对应物——不是"证明起来困难"，是"要证明的东西不是真的"。如果直接按原报告 §四.2 的设计实施，会构造一个**结构合法但物理叙事虚构**的组件：Bundle/delay_steps 的接线方式没问题（符合"结构优先"），但支撑其参数取值的"# BIO: 轴突传导延迟"式注释会是编造的——真正驱动观测到的时差的是身体运动学，不是沿球面局部边的热传导。这正是 RULES.md"每个组件映射到真实生物/物理对象"要严格把关的那类问题，只是这次不是 Python 硬编码语义，而是**参数标定的物理叙事本身站不住脚**。

### 13.3 重新定向的候选方向

**方向 A（推荐）：把"传播延迟"重新锚定为"身体运动学扫掠顺序"，而非"热传导"**

现象本身是真实的、结构化涌现的：身体绕 yaw 轴旋转时，body-frame 上固定的两个球面点，会以一个**由角速度和两点角距离决定的、确定的先后顺序**依次扫过温度梯度——这不是编造的，是真实运动学。**重新定义**：`r_edge-lag` 不再检测"热沿边传播"，改为检测"运动扫掠是否以与两点几何布局一致的顺序、在合理时间窗内先后激活"——本质上是一种**运动诱发的空间梯度扫掠一致性关系**，物理对应物明确写为"前庭-皮肤耦合的空间扫掠信号"，而非"轴突传导延迟"。

**具体标定路径**：`v_edge` 不再是虚构的"传导速度"，改用项目**已有、已标定的真实角速度常量**——`memory: project_vestibular_dim_anchoring` 记录的权威锚定（P0 冻结值，`vest-P3-complete` tag，`nexus_v1/vestibular/DIMENSIONAL_CONTRACT.md`）：canal 六轴均值 1.80 deg/s/unit，**yaw 专轴值 1.21 deg/s/unit**（T2 关注的是 yaw 转向扫掠，应取 yaw 专轴值而非六轴均值）。用两点间的**角距离**（非原来的欧氏弦距离）除以 yaw 角速度（1.21 deg/s/unit），得到该角速度下"扫过这两点"所需的真实步数——这是可推导、有生物物理依据的标定，不是拍脑袋凑数量级。**待核实**：此锚定值来自 P0 测量，15 天前的记忆，实施时需对照 `DIMENSIONAL_CONTRACT.md` 现状重新确认数值未过期。

### 16.3 W2A 设计（世界定位 + 动态热源守恒注入）

**新文件**：`nexus_v1/components/thermal_source_coupling.py`（与 `dynamic_thermal_field.py` 分开，关注点不同：后者是图/扩散，前者是定位/注入语义），不改 `dynamic_thermal_field.py` 的 `ThermalFieldGraph.step()` 本体。

**`ThermalFieldLocator`**（Q1 生物对应物：定位查询，同 `skin_network.py`"坐标生成器不应知道电路"的纯几何工具定位——不是 Bundle，是几何/数学工具，TYPE:MATH，与 `fibonacci_sphere_points`/T0 `site_selection.py` 的最近邻查找同类）：
```
locate(x: Tuple[float,float,float], graph: ThermalFieldGraph, k: int = 4) -> Dict[int, float]
```
返回 `{node_id: weight}`，`weight>=0`，`Σweight=1`。实现：k 近邻反距离加权（inverse-distance weighting，标准插值方法，非拍脑袋），只读 `graph.cells[*].position`，不修改任何状态。

**`DynamicHeatSource`**（Q1 BIO：海底热泉功率输出，同 `heat_source.py` 场景但换成功率语义而非温度语义；Q3：`energy_remaining`/`power`/`efficiency` 首轮为 EXP 标注的测试尺度常量，不宣称精确物理标定，与 `THERMAL_FIELD_MODE="normalized"` 一致）：
```
state: energy_remaining E_s, power P_s, position x_s, efficiency η_s
release(dt) -> float   # 返回本步实际可注入功率，满足 P_s·dt <= E_s，energy_remaining 相应扣减；耗尽后返回0
```

**`ThermalSourceCoupler`**（组合函数，不新增有状态类；Sources=`DynamicHeatSource.release()` + `ThermalFieldLocator.locate()` → Targets=注入字典，供 `ThermalFieldGraph.step(dt, external_injections=...)` 直接使用，不改 `step()` 接口）：
```
couple(source: DynamicHeatSource, locator_weights: Dict[int, float], dt: float) -> Dict[int, float]
    power = source.release(dt)
    return {node_id: power * weight for node_id, weight in locator_weights.items()}
    # 由 Σweight=1 保证 Σ注入 = power，天然守恒，不需要额外归一化步骤
```

**Fail-fast 包装**（不改 `ThermalFieldGraph.step()` 本体，新增独立函数）：
```
def guarded_step(graph, dt, external_injections=None, eta=1.0):
    if not is_stable(graph, dt, eta):
        raise ValueError(f"Unstable thermal diffusion configuration: max diffusion_number={max(diffusion_number(graph, dt).values()):.4g} > eta={eta}")
    graph.step(dt, external_injections)
```
W1/W1.5 已有测试继续调用 `graph.step()` 本身（不受影响）；W2A 起的新代码用 `guarded_step()`。暂不做自动子步进（批判自己也建议"等 W4 跨尺度标定后再决定"）。

**`DEFAULT_KAPPA_0` 命名拆分**（`dynamic_thermal_field.py`，批判八点4）：保留 `DEFAULT_KAPPA_0` 作为向后兼容别名（W1.5 测试已引用，不破坏），新增更精确的命名 `SEAWATER_DIFFUSIVITY_REFERENCE`（= 现有 `_TAU_REF_STEPS` 推导链的说明性别名）+ `NORMALIZED_KAPPA_DEFAULT`（= `DEFAULT_KAPPA_0` 的新首选名），docstring 说明二者关系，避免单一常量名同时暗示"机制测试参数"和"现实物理参数"两种角色。

### 17.2 T3-B 设计（真实 Neuron/Bundle 二元电路，Gate D 一级验收）

复用 T0/T1 已冻结的 28/31 两点（`FROZEN_THERMAL_SITES["t1_pair"]`），与 T1 使用同一对点，保证跨生成元可直接对比。复用 T3 路径判别阶段已验证的路径 B 机制（共享分流池，`dt=0` 只读技术，12.2 第1点），首次把它接成真正的 Neuron/Bundle 电路（此前只在 `_calib_t3_path_ab.py` 校准脚本里验证过合法性，未接成生产电路原型）。

**新文件**：`nexus_v1/relations/ratio_r_part.py`（与 `temporal_r_prec.py` 同目录、同范式），仿照 `RPrecCircuitT1(VariantCircuit)` 先例，子类叠加，不改母本。

```
Sources: ξ_a = thermal_quantum_collectors["thermpt28_warm"]（复用 T0/T1 冻结点 a）
         ξ_b = thermal_quantum_collectors["thermpt31_warm"]（复用 T0/T1 冻结点 b）

Bundle_a: ξ_a -[frozen]-> channel_a_collector（单目标）
Bundle_b: ξ_b -[frozen]-> channel_b_collector（单目标）

shared_pool = DivisiveNormalizationReceptor(sigma, pool_capacitance, pool_r_leak)
              （复用既有组件 `compensation.py`，不新造类）

step_rpart(dt):
    i_a_raw = bundle_a.propagate()[0] if targets else 0.0
    i_b_raw = bundle_b.propagate()[0] if targets else 0.0
    shared_pool.normalize(i_a_raw + i_b_raw, dt)     # 真实dt，更新池一次
    y_a = shared_pool.normalize(i_a_raw, 0.0)        # dt=0，只读
    y_b = shared_pool.normalize(i_b_raw, 0.0)        # dt=0，只读
    channel_a_collector.step(y_a, dt)
    channel_b_collector.step(y_b, dt)
```

**强制三问**：
- Q1：与 T3 分析报告已确立的生物对应物一致——DN 分流抑制/横向抑制池是真实皮层机制（REF: Carandini & Heeger 2012），这里首次让 a/b 两通道共享同一个池实例（而非各自独立池），物理对应"两个感受野竞争同一片横向抑制神经元"。
- Q2：`Sources(ξ_a,ξ_b) → SynapticBundle(Bundle_a,Bundle_b) → Targets(channel_a_collector,channel_b_collector)`，DN 作为插入在 `propagate()` 输出和 `.step()` 输入之间的补偿级联，与 `compensation.py` 里其他补偿组件（VoltageRegulator/BiasCurrent）的使用方式同构，不是新发明的写入路径。`propagate()` 本身无副作用（已读代码确认 `bundle.py:229-266`），先算原始电流、经 DN 处理、再显式 `.step()`，符合"多路输入汇聚前先求和"的 8 步调度协议（这里"多路"指共享池的两路输入，不是同一目标的多路——池更新必须用两路之和，读出必须分别用 `dt=0`，顺序不能颠倒，已在 12.2 第1点验证过）。
- Q3：`Bundle_a/Bundle_b` 权重、DN 的 `sigma`/`pool_capacitance`/`pool_r_leak` 首轮为 EXP 标注的起始值（仿照 T1 的做法：先给出物理动机 + 参照既有 DN 默认值，再走"Model before tune"实测标定），**明确预期需要多轮校准**（同 T1 report 记录的 5 轮标定史，不是一次到位）。

**验收范围（Gate D 一级，合成脉冲，同 T1 Gate B1 方法论）**：较大输入→较大输出 / 交换输入则输出交换 / 单输入时对应通道占优 / 等强输入输出近似相等 / 静默时无虚假占比。**二级验收（共同尺度不变性，真实 ξ 输入，三元扩展，升格 r_ρ）留作 T3-C，本轮不做**——同 T1 拆 B1/B2 的先例，不一次性把两级验收压进一轮。

### 17.3 测试清单

1. 较大输入→较大输出（`i_a > i_b` ⟹ `y_a > y_b`）；
2. 交换输入则输出交换（`swap(i_a,i_b)` ⟹ `swap(y_a,y_b)`，同 T1 T-TRP-8 的交换协变性方法论）；
3. 单输入时对应通道占优（只驱动 a 时 `y_a` 远大于 `y_b`，反之亦然）；
4. 等强输入输出近似相等（`i_a≈i_b` ⟹ `y_a≈y_b`，容差待标定后定）；
5. 静默时无虚假占比（`i_a=i_b=0` ⟹ `y_a=y_b=0`，不产生伪占比）。

### 17.4 范围声明

本轮只做 T3-B 一级验收（合成脉冲电路原型）。**T3-C（二级验收/真实 ξ 输入/三元扩展/升格 r_ρ）作为下一个独立里程碑**，与 T1 拆 B1→B2 的既定节奏一致，不在本轮批准范围内。世界模型 W2B 保留为已暂停但随时可恢复的独立支线，不在本轮触碰。

### 17.5 实测发现：Bundle 级 hash 扰动导致的结构性不对称（同 T1 已知机制的复现）

电路建成后首次跑 T-RPT-1~6，4/6 通过；T-RPT-2（交换协变性）/T-RPT-4（等强输入近似相等）以精确相等断言失败，实测 `i_a_raw/i_b_raw` 比值约 1.049（不是1.0）。**根因核实**：`bundle_rpart_xi_a_to_channel`/`bundle_rpart_xi_b_to_channel` 两条 Bundle 用不同的 `bundle_id` 字符串，`Memristor` 构造时按 `hash((bundle_id,i_s,i_t))` 施加对称性打破扰动（`bundle.py:169-171`，T1 已记录的同一机制，`memory: project_stdp_root_cause`/T0 五项核实提到的既知特性），导致两条 Bundle 在相同标称权重下电导实际不同——这是**电路结构本身的真实特性**（每个 Bundle 独立随机化，防止病理对称性），不是 DN 池数学有误（DN 池本身是精确对称的，扰动来自更上游）。**处理方式**：同 T1 T-TRP-5/T-TRP-8 先例，把精确相等断言改为容差断言（容差需覆盖已观测的 ~5% 量级偏差，留足余量），不强行让 hash 扰动"消失"——扰动本身是有意的物理噪声源，测试应适应它而不是绕过它。

```python
def couple_and_step(source, locator, graph, dt, eta=1.0):
    """原子化版本：稳定性检查 + 定位查询都在 source.release()（唯一有副作用的调用）
    之前完成，任何一步失败时 source/graph 均未被触碰。"""
    if not is_stable(graph, dt, eta):
        raise ValueError(...)          # 尚未触碰 source/graph
    weights = locator.locate(source.position, graph)   # 只读，尚未触碰 source/graph
    power = source.release(dt)         # 唯一的副作用点，到这里才提交
    injections = {nid: power * w for nid, w in weights.items()}
    graph.step(dt, injections)
```

**①"任意时刻比例保真"表述过强——接受，已用代码实测复现验证**：分级中继实际是卷积
`V_i(t)=∫h(t-s)y_i(s)ds`，只有当驱动历史中 `y_a(s)=c·y_b(s)` 全程用同一常数才有
`V_a(t)=c·V_b(t)`。**我方追加实测**（分段驱动 1:1→3:1→1:3，各150步，`dt=0.001`）：
切换到 3:1 后 150 步，`z_a/z_b` 从 1.014 缓慢爬升到仅 2.037（未达 3.0）；再切到 1:3 后，
比值从 2.019 缓慢衰减到 450 步时仅 0.970（远超"瞬时"）——**证实报告原表述确实错误**，
T3-C1R 报告的 24 组测试全部是固定比例场景，`eps_ratio=0` 是"固定历史比例"这一特例下的
正确结果，不能推广为"任意动态输入下瞬时比例保真"。

**②建议正式定义窗口化射影关系 `r_ρ^τ`——接受，是精确表述已有行为，非新增语义**：
`z_i^τ(t)=(h_τ*y_i)(t)`，`r_ρ^τ(t)=[z_1^τ(t):⋯:z_n^τ(t)]`——这与项目"关系是有自身时间
尺度的过程状态，不是外部瞬时计算出的数"的一贯哲学吻合（`h_τ` 是中继已有的 RC 核，不是
新增计算逻辑，只是给已经存在的卷积行为一个正式数学名称）。固定比例输入下精确退化为
`[y_1:y_2]`（T3-C1R 已证实），动态输入下表示"最近一个由中继动力学决定的历史窗口内，
各通道以什么相对份额参与了共同过程"——采纳为 r_ρ 的正式定义。

**③"经Bundle后不失真"结论超前——接受，是我方报告的真实疏漏**：T3-C1R 只测过
`GradedPotentialRelay.step()`的直接输出比例，从未接一条真实下游 Bundle 测量
`I_a^out/I_b^out`。已知 Memristor hash 扰动会造成两条 Bundle 电导~5-8%的固定不对称
（T3-B 17.5 节已记录），新 Bundle 大概率会再引入一层偏置——这必须实测，不能预先断言
"可被读取而不失真"。

**④T3-C1 四项验收范围（动态比例/交叉/真实Bundle/幅度可消费性）——接受，设计合理**。

**⑤独立账本（N_relay/N_step/V_max/Q_max/E_leak/N_clip，`N_clip=0`作硬门槛）——接受**：
已核实 `GradedPotentialRelay` 目前零内部计数（无step计数/无clip计数/无能耗追踪），
`Capacitor` 只追踪累积电荷（`_q_out`）不追踪能量，需仿照 `TemporalCoupler.stored_energy`
的 `E=½CV²` 差分模式（`temporal_coupler.py:171-175`）自行计算 `E_leak`。`N_clip=0` 作为
r_ρ 资格硬门槛的设计（触及 `a_max` 时该时段 r_ρ 失格）与批判十的 r_part/r_ρ 资格分层表
（第十九节19.1③）逻辑一致，采纳。

**⑥"软上限"应改"硬钳位"——接受，纯措辞订正**：`clip()` 确是分段函数意义上的硬钳位，
"软饱和"一词通常指连续可导压缩函数，用词不准确，已在组件 docstring 订正。

**⑦总纲状态未同步——接受，已在本节顶部状态块+T4段落+资格状态表订正**（"三类"→"两类"
的历史遗留措辞已一并修正，未来 `r_flux` 接入后再改回三类）。

### 20.2 T3-C1 设计（四项验收 + 独立账本，一次性验收，不再拆分）

采纳批判"T3-C1 只做以下四项，不再扩大范围"的态度——账本作为第五项与前四项同轮完成。

**1. 动态比例变换 + 交叉测试**（新增测试/诊断脚本，不改现有组件）：
- 分段驱动 `1:1→2:1→1:3→1:1`（真实 `RPartCircuitT3` 驱动出 `y_a(t)/y_b(t)`），同步驱动
  `GradedPotentialRelay` 记录 `z_a(t)/z_b(t)`；
- 显式数值卷积计算参考基准 `ẑ_i(t)=(h_τ*y_i)(t)`（纯测试脚本内的数学参考量，不进生产
  路径，不是新组件），验证 `z_i(t)≈ẑ_i(t)`——即验证中继正确实现了自己声明的 RC 核动力学，
  而非要求"瞬时无记忆"这个不成立的假设；
- 比例交叉（`y_a>y_b`→`y_a<y_b`）：测量翻转延迟、是否过冲、是否存在错误双占优时长——
  给 `τ_r` 一个真正可观测、可标定的时间尺度指标。

**2. 下游 Bundle 实际接入**（核心新设计决策，需强制三问，已完成 Q1/Q2/Q3）：

现状（已用 Explore 子代理核实）：`SynapticBundle.propagate()`（`bundle.py:244/251/253/256`）
要求 source 满足 `is_alive()`、`config.spiking`、`.activation` 三个契约点；
`GradedPotentialRelay` 目前只有 `.voltage`/`.step()`，不满足。项目里没有"非 Neuron 对象
直接做 Bundle source"的先例——既有模式是"Bundle 输出 → 显式 `.step()` 注入下游 Neuron"，
中继/池永远在 Bundle 的下游，从未在上游。

若给 `GradedPotentialRelay` 接一个标准 `Neuron` 作为"输出适配器"（把 `z_i` 喂给
`Neuron.step()` 再读 `.activation`），会重新触发 `gm×V²` 二次门控——**正是 T3-C1R 刚刚
解决掉的问题会在这一步被重新引入**，绝不可取。

**采纳方案**：直接给 `GradedPotentialRelay` 本身新增三个 Bundle-source 契约点（duck typing，
不继承 `Neuron`，不修改 `neuron.py`/`bundle.py`）：
- `is_alive() -> bool`：本轮恒返回 `True`（EXP 起点，标注；中继是否需要"死亡"判据留待
  后续，本轮不涉及）；
- `.config`：新增极简 `RelayConfig` dataclass（只含 `spiking: bool = False` 一个字段，
  不复用完整 `NeuronConfig`——那会带入 `channels`/`v_threshold` 等与本组件无关的字段，
  语义不符）；
- `.activation`：只读属性，返回"最近一次 `step()` 的返回值"（即已经算好的
  `a_i=clip(g_r·V_i,0,a_max)` 本身，不重新计算，不引入二次门控）。

  - **Q1**：生物对应物同 `GradedPotentialRelay` 本身——分级电位神经元对外的突触前信号，
    不需要新的 BIO 依据，只是把细胞已有的内部状态暴露给下游读取接口（同一个细胞，不是
    新细胞类型）。
  - **Q2**：`Sources(GradedPotentialRelay_a, GradedPotentialRelay_b) → SynapticBundle
    (frozen) → Targets(observer_a, observer_b)`，Bundle 走既有 `propagate()`/
    `apply_to_targets()` 路径不变，不改 `bundle.py`。`observer_*` 用现有非 spiking
    `Neuron`（简单读出器，同 T1/T3-B 已有的 collector 范式）。
  - **Q3**：新增的三个契约点不需要新参数标定（`is_alive()`恒真无参数；`RelayConfig.
    spiking=False`是布尔常量；`.activation`直接复用已标定的`a_max`/`g_r`/`r_leak`），
    只是接口暴露，不引入新物理量。

- 测试记录 `ρ_relay=z_a/z_b` vs `ρ_transport=I_a^out/I_b^out`，量化 Bundle 自身 hash
  扰动引入的偏置量级（预期约 5~8%，同已知 Memristor hash 扰动量级，见方案17.5）。**不做
  自动补偿**（按批判建议，避免重新引入 Python 比例校正）——只如实测量并记录偏置量级，
  判断是否落在可接受范围（小于容差 / 可通过共同构造规则限制 / 或需记录为结构基变换）。

**3. 幅度可消费性**：需要先定义"下游 Bundle 有意义驱动"的最小阈值 `z_min^Bundle`——
从 `Memristor`（`semiconductor.py`）的 `conduct()` 实际灵敏区间反推（用第2项已接入的
真实下游 Bundle 直接测量：多大的 `z_i` 才能让 `observer_*` 产生可观测的状态变化）。
验证工作区间 `z_min ≤ z_i ≤ β·a_max`，`β≤0.5`（复用已确定边际）。

**4. 独立账本**：`GradedPotentialRelay` 新增内部计数状态：`_step_count`、`_clip_count`、
`_v_max`、`_q_max`、`_cumulative_energy_out`（`E_leak`，仿照 `TemporalCoupler.
stored_energy` 的 `E=½CV²` 差分模式，`temporal_coupler.py:171-175`，在每次 `step()`
内部计算 `e_before`/`e_after_leak` 差值累加）。新增只读方法 `relay_ledger_stats() ->
Dict`，返回 `{n_step, n_clip, v_max, q_max, e_leak}`（`N_relay` 由持有中继的电路统计，
同 `rpart_relation_pool_stats()` 的 `pool_instance_count` 模式，不在 relay 自身里）。
**`n_clip=0` 作为 r_ρ 资格硬门槛**：T3-C1 验收测试断言扫描窗口内 `n_clip` 必须为 0，
否则该场景下 r_ρ 视为失格（测试层面用断言体现，不需要运行时抛异常）。

**5. 措辞订正**（同批完成，非独立执行项）：
- `graded_potential_relay.py` docstring：软上限→硬钳位；补充 `r_ρ^τ` 窗口化定义说明；
- T3-C1R 报告（`T3-C1R_分级电位线性中继与读出机制判别_2026-07-17.md`）不回改原文（保留
  历史记录），在新的 T3-C1 报告开头加"订正"小节指出①③点的表述范围修正（同第十八节18.5→
  第十九节的先例）。
