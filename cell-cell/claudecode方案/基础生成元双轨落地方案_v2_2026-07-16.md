## 一、核心原则：设计并行，实施分轨串行

```
共同总纲（术语/组件约束/census/frozen/报告格式/测试门槛）
   ├── 温感轨  T0 → T1 → T2 → T3 → T4      ← 首轮实施
   └── 运动轨  M0 → M1 →（M2）→ M3 → M4    ← 温感轨跑通后再切入
```

- **两轨文档设计可并行**，但**代码实施分轨串行**：绝不在同一未验证提交中同时给 `VariantCircuit` 加两轨。
- **温感轨优先**：已有 64 个明确 ξ^occ、RC 动态已测、不涉及运动侧语义选择、不影响现有 Motor/polarization。
- **每 Phase 独立分支**（非一个 `feat/base-generators-all`）：
  ```
  feat/thermal-basegen-p0 / -rprec / -rdir / -rrho / -integration
  feat/motion-basegen-p0  / -rprec / -rrho / -integration   （M2 独立分支待定）
  ```
- 每 Phase 专项探针 + 全量回归 21/21 双通过才进下一 Phase。回归失败可精确归因到单轨单阶段。

**门控结构（纳入批判二点12，温感轨适用，运动轨走同款）**：
```
共同总纲
    │
    ▼
Gate A：T0 真实 ξ^occ 选点、冻结与关系层账本核实
    │
    ▼
Gate B：T1 时间关系电路（可直接按方案设计进入）
    │
    ▼
Gate C：T2 方向传播—终点耦合定义（须先出电路定义报告，方向≠Bundle命名）
    │
    ▼
Gate D：T3 竞争参与度可否达到占比近似（r_part → 二级验收 → 是否升格 r_ρ）
    │
    ▼
T4 并行集成（关系层账本强制验收 + 决定 r→/r_part 资格）
```
未通过对应 Gate 不得进入下一 Phase。

## 二、术语与命名规范（写入代码，不止写报告）

三个「ξ」是不同工程对象，必须在**代码命名 + 注释**中区分：

| 符号 | 工程对象 | 含义 | 本方案用法 |
|---|---|---|---|
| **ξ^occ** | 感温/运动 Collector（尖峰发生检测器） | 局部物理发生 | 本轮双轨的 ξ 源 |
| **ξ^err** | 误差 Neuron/Collector（pred−actual） | 预测—实际残差发生 | 运动路线2，后续独立构建 |
| **ξ^PI** | `BundleConfig.xin_tension` | Bundle PI 张力参数 | 禁止直接读取喂生成元 |

- 新生成元命名前缀统一体现 `occ`（如 `occ_rprec_*`、`occ_rpart_*`），避免与 `xin_tension` 混淆。
- 报告与注释中一律用上表符号，不再泛称「ξ」。

**关系生成元命名（纳入批判二点8）**：占比关系首版一律命名 **r_part / 参与竞争关系原型**（代码前缀 `rpart`），**不得**在实测「共同尺度近似不变」前提前叫 `r_ρ` 或宣称除法归一化。达到二级验收后才升格 `r_ρ`（重命名 + 报告确认）。

## 三、运动侧 ξ 源路线（路线1 优先，路线1/2 并存非替换）

**核心事实**（已代码核实）：Bundle 只能读 Neuron 的 `pre_trace`/`activation`/`calcium_rate`（`bundle.py:243-256`）；`xin_tension` 是 `BundleConfig` 上的 float（`bundle.py:44`），Bundle 读不到 → 路线3（直读 xin_tension）绕 Bundle = 硬编码违规，不采用。

**首轮走路线1（运动局部发生生成元 ξ^occ）**：以 `move_x/y/z`、`yaw_ccw/cw` 的 spiking `pre_trace` 为 ξ^occ 源。零新结构，与温感轨 ξ^occ 口径严格对称。

**重要更正（纳入批判点3）**：路线1 的准确表述是**「运动局部发生生成元轨」**，不是「真 ξ 预测残差轨」。路线2（ξ^err，用已有 `err_dT/err_domg` 范式包 efference error）表达的是**不同的物理对象**：
- 路线1（ξ^occ）：运动**发生了什么**；
- 路线2（ξ^err）：预测与运动之间**破缺了什么**。

二者**未来可能并存，而非必然替换**。路线2 作为后续独立构建，不称为路线1 的「升级」。

## 四、温感轨 T0 → T4（最小支撑，不铺满 64 源）

**总目标不是「把所有 ξ^occ 都接入」，而是：证明一套最小基础关系生成元能由真实 ξ^occ 稳定产生。** 全网络扩展是后续独立阶段。

复用 Ω 层的 `_init_*`/`_step_*`/config-factory 范式（`variant_adapter.py:1791-1908`）与探针模板（`tests/test_thermal_coupling_generators.py`）。

### T0 —— 基线与夹具隔离（不新增关系电路）【Gate A】
- 核实并选定 2~3 个真实感温 ξ^occ（从 `thermal_quantum_collectors` 中按 `skin_network.py` 球面点局部邻接挑选）。
- **选点结果必须冻结落盘**（纳入批判二点11）：保存 ① 点索引 ② warm/cool 极性 ③ 邻接边 ④ 选点理由 ⑤ 各点输入峰值与爆发周期。T1~T4 **只读该冻结集合**，不得每次初始化重新动态搜最近邻（否则不同运行支撑不同，破坏可重复性）。存为常量表或 JSON 夹具。
- 统一读取方式（`pre_trace`），隔离 `SpikeGenerator`（仅夹具，验证后替换真实 ξ^occ）。
- 建立通用**峰值/衰减/静息**探针 + RC 标定夹具（照 `_diag_omega_burst.py`），**逐生成元独立电容常量**（禁复用 ξ 层 `C=0.5`）。
- **建立关系层独立账本**（纳入批判二点9）：新增专项统计（先在测试中按保存容器统计，或加 `get_relation_generator_neurons()`/`get_relation_generator_bundles()`），报告 ① 关系中继神经元数 ② 关系 Collector 数 ③ 每步膜积分调用次数 ④ 峰值功率/近似能耗 ⑤ 新 Bundle 数 ⑥ 相对原系统运行成本增量。**明确：排除全局 census 是暂时隔离，不是无能耗。**
- **核实 `delay_steps`**（纳入批判一§六）：即使字段存在（`bundle.py:266-269`），需核实 ① 是否对当前 Bundle 类型生效 ② 延迟队列存 `activation` 还是最终电流 ③ 多源 Bundle 延迟单位 ④ 是否与 `pre_trace` 二次时间扩展 ⑤ 是否进入 census/复制。**结论前，T1 主方案锁定为非 spiking Neuron 的 RC 历史痕迹**，`delay_steps` 仅用于 A/B 对照探针。
- 确认回归基线 21/21。

### T1 —— r≺ 时间关系（二元，最小支撑）
- **只选 2 个真实 ξ^occ**（ξ_a, ξ_b），完成一个二元时间关系生成元 r≺^ab。
- 双向结构：`ξ_a→历史痕迹支路(非 spiking Neuron + 膜 RC)─┐ + ξ_b─┘→ ξ_a≺ξ_b Collector`，反向对称。
- 多时间尺度 + 独立 Collector，暂不接下游。

### T2 —— r→ 方向关系（三节点局部邻接链）【Gate C：先出电路定义报告】
**编码前必须先单独出一份「方向关系电路定义报告」**（纳入批判二点7）。核心：**方向不是 Bundle 名称**——把 Bundle 命名为 a→b 不会让它自动成为方向关系；若只建 `ξ_a→D_a→b`、`ξ_b→D_b→a`，输出只能证明「哪个源激活」，退化成源身份检测。

方向检测必须**同时**满足三要素：
1. **结构邻接**：(a,b) 确实相邻（用 T0 冻结的邻接边）；
2. **起点痕迹**：ξ_a 的活动沿 a→b 支路传播（传播中继/RC 痕迹 `P_a→b[ξ_a](t)`）；
3. **终点耦合**：传播痕迹与 ξ_b 的**当前**活动在终点耦合。

最小结构（每条邻接边双向）：
```
ξ_a → a→b 传播中继/RC痕迹 ─┐
                            ├→ D_a→b Collector    d_a→b(t) = C(P_a→b[ξ_a](t), ξ_b(t))
ξ_b ────────────────────────┘
```
- 与 r≺ 的区别（我方补充，批判未点破）：仅「邻接」不足以区分 r→ 与「恰好邻接的 r≺」——若传播支路与 r≺ 历史支路用同一种**对称** RC 机制，两者无法区分。真正的区别须是：**r→ 的 a→b 与 b→a 传播支路物理不对称**（方向性的延迟/衰减，体现空间传播），而 r≺ 的两条历史支路对称（只比先后）。此点写入 T2 定义报告。
- **运行时方向不得靠坐标计算**（禁 `sign()`/点积/坐标差/写 ±X 标签），方向从「传播痕迹 × 终点发生的重合」物理涌现。
- 不复用温感 Ω 的 RF collector 冒充（那是预设方向模态）。

### T3 —— r_part 参与竞争关系（先二元后三元；升格 r_ρ 需实测）【Gate D】
**首版命名 r_part（参与竞争关系原型），不叫 r_ρ**（纳入批判二点8，结论保留）。但**前提须纠正**（我方代码核实）：批判称「项目无精确除法组件」不准确——`DivisiveNormalizationReceptor`（`compensation.py:295-324`）已实现 Carandini-Heeger 除法归一化 `R_i=L_i^n/(σ^n+Σ_j L_j^n)`，且是**分流抑制物理电路，非 Python 除法**（`I_eff=I_raw×σ/(σ+V_pool)`，复用 Capacitor 池），已在 shadow enc 使用（`shadow_sandbox.py:52`）。**局限**：它是 per-neuron 独立池（`shadow_sandbox.py:537`），追踪单神经元自身输入的时间平均（增益控制），**不是**跨通道横向池 Σ_j——这才是"降格 r_part"结论仍然成立的**真正原因**。

因此 T3 设两条候选路径，设计报告须先择定：
- **路径 A（减法抑制，保守，批判原方案）**：`ξ_a→独立兴奋通道─┐ + ξ_b─┘→共同总量池→共享减法抑制(synapse_gain=-1.0)→ y_a/y_b`。产生 `y_a≈φ(I_a−λI_Σ)`，与除法归一化不天然等价（共同放大 αI 时可能整体增大/饱和/归零）→ 只能停在 r_part。
- **路径 B（分流抑制，逼近真占比，我方新提）**：把「共同总量池」接 **DN 式分流** `×σ/(σ+V_pool^shared)`（V_pool 来自 a、b 共享横向池，而非 per-neuron），物理逼近 `I_a/(σ+ΣI)`，仍是合法分流抑制电路（非 Python 除法）。**需核实**现有 `DivisiveNormalizationReceptor` 能否复用为共享横向池版，或需在 T3 用一个被 a/b 共同驱动的 pool 神经元 + 各通道 shunting 搭建。路径 B 有望直接达二级验收，值得优先试。
- 两路都**禁** Python 直接算 `I_a/(I_a+I_b)`。先二元后三元（二元通过才扩展三元）。
- **两级验收**：
  - **一级（必须达到）**：较大输入→较大输出 / 交换输入则输出交换 / 单输入时对应通道占优 / 等强输入输出近似相等 / 静默时无虚假占比。
  - **二级（实验性目标）**：共同放大时排序保持 / 输出差异对共同尺度相对稳定 / 多通道竞争后近似归一化 / 输出总量变动在有限范围。
- **只有二级（共同尺度近似不变）经实测证明后，才升格重命名 r_ρ 并在报告确认**；否则一律停在 r_part。

### T4 —— 三路并行无串扰（同一最小支撑）
- 用 **T1~T3 的同一最小支撑集合**（不扩展到全皮肤网络），同一组 ξ^occ 同时接 Ω≺（r≺）/ Ω→（r→）/ Ω_part（r_part）。
- 验证：单 ξ^occ 能否被三类 Bundle 同时读取 / 是否对上游 Collector 形成意外负载 / 三类关系互不替代 / 三类 RC 无串扰 / census 完整 / frozen 权重不变 / 全量回归通过 / 运行成本可接受。
- **关系层独立账本列为强制验收项**（纳入批判二点9）：报告关系层神经元/Collector/膜积分次数/近似能耗/运行成本增量，确认隔离≠零能耗。
- **在 T4 才决定** r→、r_part 是否达到「基础方向生成元」「基础占比生成元」资格（r_part 达二级验收才升格 r_ρ）。
- **仍不接** Γ/Motor/Shadow/TOPR/Xin/STDP/DA/CPC。

## 五、运动轨 M0 → M1 →（M2）→ M3 → M4

温感轨全部通过后再切入。运动轨 ξ^occ = `move_x/y/z`、`yaw_ccw/cw` 的 `pre_trace`（路线1）。

- **M0**：明确运动 ξ^occ，建立探针与 RC 基线（同 T0 骨架）。
- **M1**：二元 r≺ 时间关系（如 move 发生 vs yaw 发生，谁先）。
- **M2（方向关系，两案并存）**：
  - **默认主线：暂缓 M2**。运动轨走 M0→M1→M3→M4。理由：move_x↔y↔z 轴链无物理根据，只会生成「手工排列的轴顺序」。等找到真实传播支撑（路线B：前庭 ξ→中继/运动神经元→Body 反馈 ξ 的因果链，比较 π_{a→b} vs π_{b→a}）后单独设计——但路线B 会触碰 Motor/Body，超出「只读 ξ、终止 Collector」范围。
  - **可选分支：降格为对向结构关系原型**。若必须完整走 0→4，用真实 push-pull 结构：`yaw_cw↔yaw_ccw` 或前庭量子链路 `ξ_yaw+↔ξ_yaw-`（MET/antimet 反向物理通道，已存在于 `_QUANTUM_DIRECTIONS`）。**必须明确标注它是「极性竞争关系」，尚不等于普遍空间传播方向生成元。**
  - 走哪条到 M2 阶段再定。
- **M3**：轴间参与竞争原型 **r_part**（ξ_x, ξ_y, ξ_z 的竞争参与度，两级验收同 T3，未升格前不叫 r_ρ），**输出停在 Collector，与现有 `polarization` 并行存在，不替换任何东西**（见第六节）。
- **M4**：M1/M3（及可选 M2）已有关系并行，无下游替换。

## 六、Phase 3/M3 与 polarization —— 拆分，实置换移出 0-4（纳入批判点2）

v1 的「Phase 3 替换 polarization」与「终止于 Collector」矛盾，因替换 = 接入现有运动状态计算 = 改变下游行为。拆为三段：

- **M3（= 3A）参与竞争关系原型**：`(ξ_x,ξ_y,ξ_z) → (r_part,x, r_part,y, r_part,z)`（命名同 T3，未达二级验收前不叫 r_ρ），输出停 Collector，与 `MotionState.polarization`（`variant_adapter.py:2162-2168`）**并行存在，不替换**。回归只验隔离性。
- **3B 占比输出校准与影子比较**（离线）：比较 ρ_struct（r_part 或已升格的 r_ρ 输出）与 ρ_python（现有 polarization），覆盖 排序一致性 / 共同尺度变化 / 静默 / 单轴主导 / 两轴竞争 / 三轴等强。仍不切生产路径。
- **后续独立 Phase 5：硬编码替换**：只有结构输出（且已达 T3/M3 二级验收升格为 r_ρ）证明足够稳定后，才用其替代 `polarization = max|ν_i|/Σ|ν_i|`。

故 0-4 方案中「替换 polarization」改述为：**为未来替换 `polarization` 提供结构化候选输出和影子比较数据。**

## 七、关键约束（落地时写死）

1. **census + 关系层账本**：新 collector/中继神经元 → **排除** `get_all_neurons()`（护 T4.1 energy_per_neuron）；新 bundles → **进** `get_all_bundles()`（供 Noether/Xin/熵账本）。照 `variant_adapter.py:4279-4290 / 4381-4396`。**但排除全局 census 只是暂时隔离、非无能耗** → 必须另建关系层独立账本（T0 建立，T4 强制验收），统计关系神经元/Collector/膜积分次数/近似能耗/成本增量。
2. **全 frozen，权重远离饱和**：`learning_rule="frozen"`, `remodel_cost_kappa=0.0`（`bundle.py:336-337` 短路 learn）。权重满足 `initial_weight == weight_max`，且**默认必须 `0 < w_0 = w_max < 1`，禁 `=1.0`**（纳入批判二点10；`memory: project_memristor_saturation_edge_bug`：w=1 附近与随机扰动/PowerRail 饱和相撞）。首轮从 `w_0 ∈ [0.1, 0.5]` 扫描，具体值由实测电流与 RC 充电时间决定。**例外（我方补充）**：约束的真正对象是**有效写入权重**，非 base 常量本身——若权重经构造期几何衰减写入（如 Ω 层 `_RF_BASE_WEIGHT=1.0 × cos²θ`，有效值 <1），base=1.0 可接受；新生成元若用类似衰减写入，需在参数表中注明"有效权重<1"并给出推导，不能只看 base 常量判断是否违反本约束。
3. **独立 RC 常量**：每生成元自带电容/r_leak，禁复用 ξ 层 `C=0.5`（Ω 教训，`memory: project_omega_coupling_generator_complete`）。

5. **最小支撑**：T1/M1=2 源，T2=3 邻接源，T3/M3=先2后3；不铺满全网。全网扩展 = Phase 0-4 之后独立阶段。
