## 一、问题背景

当前前庭系统中，VestibularChain 有 6 轴：canal(yaw/pitch/roll) + otolith(oto_x/y/z)。  
但在 `VariantCircuit.step()` 中，canal 三轴的 `mechanical_inputs` 始终为 0——半规管通路虽已建好，却无信号输入。

这导致：
- body 只能感知线性加速度（耳石），无法感知角速度（半规管）
- yaw 转向时，vestibular MET_yaw / HC_yaw / Aff_yaw 全程静默
- "前庭消融" T-061 结论实为两组均无 canal 信号，结论 INCONCLUSIVE（HC-061 已登记）

## 二、生物物理基础（Steinhausen 扭摆模型）

半规管 Cupula 偏转 θ 与头部角速度 ω 的关系（过阻尼极限）：

```
τ_cupula × dθ/dt + θ = ω × τ_cupula
θ_ss = ω （持续旋转时，偏转与角速度成正比）
θ 适应时间：τ_cupula = R/K ≈ 4 s（Fernández & Goldberg 1971）
```

离散 IIR 高通滤波实现（检测旋转变化，适应恒速）：

```
θ[t] = ALPHA × (ω[t] - ω[t-1]) + (1-ALPHA) × θ[t-1]
ALPHA = dt / (dt + tau_cupula_steps)
tau_cupula_steps = 4000（4s at 1ms/step convention）
```

**DT 陷阱**：`ALPHA` 必须从 `dt` 动态计算，而非硬编码 `0.00025`（DT 改变时会破坏物理量纲）。

## 三、实现内容（Phase 0 + Phase 0.5）

### Phase 0：信号注入（T-076 本次执行）

**修改文件**：`nexus_v1/circuit/variant_adapter.py`

**__init__ 新增状态**：
```python
# Cupula high-pass filter state (T-076 Phase 0)
self._cupula_omega_prev: float = 0.0   # ω[t-1] for IIR filter
self._cupula_theta: float = 0.0         # θ[t] Cupula deflection
```

**step() 新增注入**（插入 oto_z 注入之后）：
```python
_TAU_CUPULA = 4000.0
_ALPHA_CUPULA = dt / (dt + _TAU_CUPULA)
_ANGULAR_GAIN = 5000.0  # Phase 0 initial; Phase 0.5 will calibrate
raw_omega_yaw = self.world.body.angular_velocity
self._cupula_theta = (
    _ALPHA_CUPULA * (raw_omega_yaw - self._cupula_omega_prev)
    + (1.0 - _ALPHA_CUPULA) * self._cupula_theta
)
self._cupula_omega_prev = raw_omega_yaw
mechanical_inputs['yaw'] = mechanical_inputs.get('yaw', 0.0) + self._cupula_theta * _ANGULAR_GAIN
# pitch / roll: World 2.0 Phase 1 planar — both remain zero
```

**验收**：`python -m nexus_v1.tests.test_regression` → 21/21 PASS

### Phase 0.5：增益校准（T-076b，下一步）

运行短程旋转实验（5k 步），同时打印：
- `mechanical_inputs['yaw']`（canal 信号幅值）
- `mechanical_inputs['oto_x']`（耳石信号幅值）
- `body.angular_velocity`（实际角速度）

目标：canal 信号与耳石信号在 `mechanical_inputs` 层级动态范围相近（±1 个数量级内）。  
调整 `_ANGULAR_GAIN`，目前初始值 5000.0（阶段0.5 实测后更新）。

## 五、不做什么（架构保护）

- **不修改** VestibularChain / HebbianCircuit / bundle.py（母本代码保护）
- **不用 Python 公式计算方向性**（禁止硬编码如 `sign(ω)` → "左转/右转"）
- **不融合 canal 与 otolith**（方向感知由 STDP 在 Col→Motor 层自组织涌现）
- **不修改 canal 通路的 STDP 参数**（canal→MET→HC→Aff→Enc→Col 全链 plasticity=False）
