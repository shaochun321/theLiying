## T-076：半规管 Cupula 信号注入

### 问题

VestibularChain canal 三轴在 `VariantCircuit.step()` 中始终注入 0，
导致 yaw 转向时 MET_yaw→HC_yaw→Aff_yaw 全链路静默。

### 方案

**生物模型：** Steinhausen (1931) 扭摆 — 过阻尼 Cupula 高通滤波器。

**信号方程：**
```
θ[t] = ALPHA × (ω[t] - ω[t-1]) + (1-ALPHA) × θ[t-1]
ALPHA = dt / (dt + τ_cupula)     # τ_cupula = 4000 步（τ=4s at dt=1ms）
mechanical_inputs['yaw'] += θ × ANGULAR_GAIN
```

**关键设计决策：**

1. **ALPHA 动态计算**（`dt/(dt+4000)`，禁止硬编码为 0.00025）
   - 原因：DT 陷阱。`dt/(dt+4000)` 中的 dt 取决于调用现场，
     部分测试以 `dt=1.0` 调用而非 `dt=0.001`，硬编码会造成数量级误差。

2. **ANGULAR_GAIN = 300,000**（而非线性估算的 100,000）
   - 原因：MET 传输函数为平方律 `gm×(V-Vth)²`，且峰值是瞬态（非稳态）。
     线性比例估算误差 3×。实测迭代：5,000→100,000→**300,000**。
   - 目标：MET_yaw ∈ [0.1, 5.0)（非饱和激活范围），实测 0.32。

3. **注入位置**：耳石注入（`mechanical_inputs['yaw']`）之后，`VestibularChain.step()` 之前。
   - 无需修改 VestibularChain / HebbianCircuit。

**修改范围：** 仅 `variant_adapter.py` 的 `__init__` 和 `step()`，共 +10 行。

|:---|:---|:---|
| T-076a（增益校准） | `exp_T076a_canal_gain_calibration.py` | 4/4 PASS |
| T-076b（旋转激活） | `exp_T076b_rotation_activation.py` | 4/4 PASS |

- STOP 后 Cupula θ = -1.22e-6（物理反向正确）

## T-071：D1 STDP 弧断路诊断（H-B 根因）

### 问题

长程实验（200k 步）权重 |Δw|=0.2991（STDP 学习真实发生），但 DR5=50%（随机基线）。
行为与学习脱钩。

### 诊断方案

**信号链拆解：**
```
D1 学习弧：phasic_left → [D1 STDP bundle] → spinal_ccw → [sp2y: w=0.020] → yaw_ccw
HC-016 反射弧：thermo_left → [th2y: w=0.29] → yaw_ccw
```

**四假说框架（H-A~D）：**

| 假说 | 测量方法 | 判定 |
|:---|:---|:---|
| H-A: phasic_left ≈ 0 | 直接读取 activation | ❌ phasic 有信号（max=0.10） |
| **H-B: I_spinal << I_thermo** | 计算 act×w×sg 电流比 | **✅ 确认！比值 0.09%（1000:1）** |
| H-C: yaw_ccw ≈ 0 despite spinal | 读取 yaw_ccw.activation | ❌ yaw 有激活（由反射弧驱动） |
| H-D: body 不响应 yaw | 读取 angular_velocity | ❌ 行为传导正常 |

**H-B 三层成因：**

1. **结构权重过弱**：`bundle_spinal_ccw_to_yaw.w = 0.020`（T-042 标定）。
   D1 满权重时最大电流 = 0.064×0.020 = 0.0013，反射弧峰值 = 4.68×0.29 = 1.36。
   结构上 1000:1 压制。

2. **学习窗口时序错误**：体在热源外 relay_left=0（无 phasic 信号）；
   进入热源时 phasic 被 P0 钳制为 -0.1V（防伪奖励机制）。
   D1 弧学到的是**进热源时减少 yaw 激活**（方向反转）。

3. **负强化效果不可见**：因权重 1000:1 压制，D1 弧即使学到了负强化，
   对行为的影响也 < 0.1%，DR5 仍由反射弧完全主导。

### 修复选项（待用户决策）

| 选项 | 做法 | 风险 |
|:---|:---|:---|
| A | sp2y_w: 0.020 → 0.2~0.5 | T4.1/T4.2 需重新标定 |
| B | 移除 D1 弧 | 失去长期 STDP 可塑性 |
| C | 维持现状 | 行为由反射弧驱动，21/21 PASS |

**当前状态：** 选项 C（诊断结论已记录，用户决策中）

## T-065：物理驱逐实验（热源瞬移）

### 目的

验证体在完成第一轮填充后，当热源瞬移至对侧时，能否重新定位并到达新热源。
测试涌现行为的泛化能力（不是固定路径记忆，而是结构性热趋性）。

### 方案

**实验流程：**
```
Phase 1 (0~50k):  正常运行（体从 [10,50,25] 出发，热源在 [70,50,25]）
Phase 2 (step=50k): 热源瞬移 [70,50,25] → [10,50,25]（体此时在热源旁）
Phase 3 (50k~100k): 体在旧源位置，新源在体出发点对侧
```

**判定标准：**
- J1: Phase1 末 fill > 0.5（第一轮热趋性成功）
- J2: 瞬移后 30k 步内进入新源（dist < 30）
- J3: Phase3 期间最近距新源 < 30
- J4: Phase3 fill 最低值 < 瞬移时 fill - 5%（脱离旧源开始消耗）

**脚本：** `nexus_v1/tests/exp_T065_heat_source_teleport.py`

**结果：** 运行中（100k 步，预计 ~5 分钟）
