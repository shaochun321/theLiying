## 二、V2.0 Phase 2：功能实现计划

### 2.1 τ_ij 轴突传导延迟（RingBuffer）

**生物对应**：神经轴突传导速度 v_cond = 0.5-2.0 m/s（无髓鞘纤维；有髓鞘 10-100 m/s）。前庭轴突（Scarpa 节→脑干）为 A 类有髓鞘，v_cond ≈ 50 m/s。

**计算**：τ_ij = d_ij / (v_cond × dt)，单位为步数（int）

例：前庭轴突 d=2mm，v=50mm/ms，dt=1ms → τ = 2/50 ≈ 0.04步 ≈ 0步（微小，可忽略）
例：皮层轴突 d=20mm，v=1mm/ms → τ = 20步（显著）

**实现方案（V2.0 Draft）**：

```python
# nexus_v1/circuit/bundle_v2.py (新文件，继承 SynapticBundle)
class DelayedBundle(SynapticBundle):
    """TYPE:BIO — SynapticBundle with τ_ij axonal conduction delay.
    
    BIO: v_cond from fiber type (myelination):
      - Aα (vestibular): ~50 m/s = 50 mm/ms
      - C fiber (nociceptor): ~0.5 m/s = 0.5 mm/ms
    REF: Bear, Connors & Paradiso 2016 "Neuroscience" — axon physiology
    """
    def __init__(self, config, sources, targets, v_cond_mm_per_ms=50.0, dt=0.001):
        super().__init__(config, sources, targets)
        # τ_ij delay matrix (in steps)
        # delay[i][j] = ceil(d_ij / (v_cond * dt))
        self._delay = self._compute_delays(sources, targets, v_cond_mm_per_ms, dt)
        max_delay = max(max(row) for row in self._delay.values())
        self._buffer = {(i, j): deque([0.0] * max_delay) 
                        for i in range(len(sources)) 
                        for j in range(len(targets))}
    
    def _compute_delays(self, sources, targets, v_cond, dt):
        import math
        delays = {}
        for i, src in enumerate(sources):
            delays[i] = {}
            ps = src.config.position
            for j, tgt in enumerate(targets):
                pt = tgt.config.position
                if ps is None or pt is None:
                    delays[i][j] = 0
                else:
                    d_mm = math.sqrt(sum((ps[k]-pt[k])**2 for k in range(3)))
                    delays[i][j] = max(1, round(d_mm / (v_cond * dt)))
            return delays
```

**注意**：DelayedBundle 不修改 SynapticBundle，通过继承扩展。VariantCircuit 中将某些关键 bundle 替换为 DelayedBundle（仅影响有位置信息的 bundle，如前庭链）。

**当前推迟原因**：
1. 前庭轴突 d≈2mm，v=50mm/ms，dt=1ms → τ≈0步（实际无延迟）
2. 更重要的延迟来自皮层/脊髓轴突（d=10-30mm，v=1-10mm/ms，τ=1-30步）
3. 需先完成所有神经元的位置赋值（目前 49 个无位置）

### 2.2 P_S 距离惩罚 STDP

**生物对应**：突触可塑性的代谢成本随距离增加（长距离轴突 myelination 代谢昂贵）。

**公式**：P_S = η_s × (dw/dt)² × d_ij  

意义：权重变化代价与距离成正比 → 长距离连接倾向于弱化（局部性偏好）

**实现注意**：
- `η_s` 需要有生物依据（可能来自突触可塑性代谢功率研究）
- 需先有完整 D 矩阵（目前 24/73 神经元有位置）
- 这是一个持续作用的"惩罚力"，不是新的信号路径

### 2.3 剩余神经元位置赋值

**优先级**：
1. ThermalMembrane / Noci / Relay（热感受器链，d=0-5mm 体表分布）
2. DA 神经元（VTA 位置，~0mm 相对位置？或抽象轴？）
3. Encoding / Column / Motor（大脑皮层，解剖位置不确定）

**问题**：HC 系统（Hebbian circuit）神经元是"抽象"神经元（无解剖学位置），DA 神经元也无明确解剖学坐标。可能需要在 position=None 的情况下跳过延迟计算，而非强行赋值。
