## 一、什么是"时空耦合模块"

项目中使用"时空耦合"一词时，指的是**一组彼此关联但职责不同的代码组件和理论概念**，而不是单一模块。这 6 个东西常常被混在一起讨论，需要先拆开：

| 组件 | 文件 | 角色 | 状态 |
|------|------|------|------|
| **TemporalCoupler** | `components/temporal_coupler.py` | 时间尺度桥接器——每条 Bundle 后端的 RC 滤波器 + B/C 双层自适应 | ✅ 完整实现，但 B-layer 电压=0 未生效 |
| **TemporalBindingLayer** | `components/binding_temporal.py` | 前庭-热觉因果不对称绑定——前庭轴时间卷积(τ_w=30)，热觉轴瞬时通过 | ✅ 完整实现，Phase 4 引入 |
| **SpatialNavigator** | `circuit/motor_decision.py L266-290` | 路径积分/空间记忆——空壳 | ❌ 只有占位符，`update()` 什么都不做 |
| **ShadowSandbox 的 ds²/ν/κ** | `components/shadow_sandbox.py` | 内生时空测度（ds²）、运动势（ν=dK/dt）、收缩度（κ） | ✅ 都已计算，但**全部无人读取** |
| **FBCap 传出副本** | `circuit/variant_adapter.py L1312-1342` | Motor→Capacitor→Column 反馈，闭合大环流 | ✅ 实现，但走 `_membrane.inject()` 而非 SynapticBundle |
| **CirculationMeter** | `circuit/circulation.py` | 环流流量测量（P-path/R-path/ρ/ν） | ✅ 实现，纯观测仪表 |

> **核心矛盾**：时空耦合的概念层非常丰富（ds²/ν 度规框架、自身=标尺、因果不对称绑定、驻波垫支），但物理层的组件要么是空壳（SpatialNavigator），要么信号断连（ds²/ν 无人读取），要么被软短路（TemporalCoupler B-layer=0）。

## 三、认识论基础：自身 = 标尺

> 来源：[[docs/concept_C004_autogenous_spacetime]]

### 3.1 核心原则

**项目（生物体）没有访问 World.py 中的坐标函数。** 项目能感受到的只有输入流：
- 前庭输入流：col_yaw, col_pitch, ... col_oto_z（自身运动状态）
- 热输入流：col_therm（外部变化）
- 这些输入流之间的时序关联（绑定层 + 影子层）

所有"外部位置/距离/方向"概念都不是从全局坐标读取的，而是从**自身运动与感觉变化之间的统计关联**中生成的。

### 3.2 度量替换表

| 度量 | 外部标准 (World.py) | 项目内部标准 | 实现位置 |
|------|-------------------|------------|---------|
| **距离** | 米 | "移动了多少 → 热变了多少" | `w_cross(oto_x, therm)` |
| **方向** | 角度 | "转了多少 → 热变了多少" | `w_cross(yaw, therm)` |
| **时间** | 秒 | "多少个处理周期" + "能量耗散了多少" | `dt, τ_RC, τ_methyl, ds²/ν` |
| **速度** | m/s | "环流占比的变化率" | `ν = dρ/dt` |

### 3.3 认识论框架

| 哲学框架 | 对应 | 项目实现 |
|---------|------|---------|
| 康德先验直觉 | 空间和时间不是世界的属性，而是认知的形式 | ds² 和 ν 从结构生成 |
| 具身认知 | 身体是知识的基础 | 自身=标尺 |
| 自创生 (Autopoiesis) | 系统生成自己的交互域 | 权重学习 = 世界建构 |
| 自由能原理 (FEP) | 减少预测误差 | Xin = predicted - actual |
| Noether 对称性 | 守恒量对应对称性 | 环流守恒 ↔ 结构不变性 |

> **这不是一个工程决策——这是项目的认识论立场。** 外部世界只通过输入流进入项目。时空只在项目内部通过自身结构生成。

### 3.4 主体性门槛

当系统同时具备以下三者时，主体性萌芽（2026-05-24 实验已证实）：

1. **自体测度**: `w_cross(vestibular, vestibular)` → "我是什么形状"（增长 +66%，快速锁定）
2. **对象测度**: `w_cross(vestibular, thermal)` → "外面有什么东西"（增长 +7%，保持可塑）
3. **区分能力**: 两组权重的学习轨道不同 → "我 ≠ 它"（跨模态绑定晚 3.4 倍激活）

## 四、时空测度 ds² 与运动势 ν

> 来源：[[专题分析/运动势与时空测度-概念-定义-演化]] + [[2026-05/analysis_unified_master_method.2026.5.24]]

### 4.1 ds² 定义

$$ds^2 = \sum_{i,j} w_{\text{cross}}(i,j) \times \delta a_i \times \delta a_j$$

| 符号 | 含义 | 来源 |
|------|------|------|
| $w_{cross}(i,j)$ | 影子层跨轴权重（BCM 学习），**就是度规张量 g_ij** | `shadow_sandbox.py` cross-axis bundles |
| $\delta a_i$ | 列层激活的偏离（a_i − ā_i，M1 基线减法） | `_get_delta_a()` |
| $ds^2 > 0$ | 空间关系（两轴同向 = spacelike） | — |
| $ds^2 < 0$ | 时间关系（两轴反向 = timelike，因果相关） | — |

代码实现：`shadow_sandbox.py` `_compute_ds2()` (L805-831)。使用 M1 基线减法（`_get_delta_a()` 返回 `a − ā`），度规 g_ij 是 cross-axis bundle 的 mean_weight()。

### 4.2 ν（运动势）定义

$$\nu = \frac{dK}{dt}, \quad K = \text{EMA}(\Sigma \xi_i^2)$$

| 符号 | 含义 | 物理对应 |
|------|------|---------|
| $K$ | 自由能（影子层总 Xin² 的 EMA） | 系统对当前状态的"惊奇"程度 |
| $\nu$ | K 的变化率 | "急迫程度"——非平衡态驱动力的量度 |
| $\nu > 0$ | 惊奇增加 → 系统偏离稳态 | 积累误差，远离平衡 |
| $\nu < 0$ | 惊奇减少 → 系统回归稳态 | 趋近均衡，误差减少 |

代码实现：`shadow_sandbox.py` `_update_free_energy()` (L690-698)。`_nu = _k_ema - _k_history[-1]`（当前 EMA 减上一步 EMA）。

### 4.3 κ（收缩度）定义

$$\kappa = \frac{\Sigma g_{ij} \cdot \delta a_i \cdot \delta a_j}{\Sigma |\delta a_i| \cdot |\delta a_j|}$$

| κ 值 | 含义 |
|------|------|
| κ > 1 | 扩张（信号丰富，cross-axis 耦合强） |
| κ ≈ 1 | 中度 |
| κ < 1 | 收缩（信号单调，cross-axis 耦合弱） |

代码实现：`shadow_sandbox.py` `_update_kappa()` (L862-902)。用 cross-axis bundle weight × col_da(src)×col_da(tgt) 的加权和除以未加权和，EMA(α=0.01) 平滑。

### 4.4 热力学量纲

```
ds² = Σ ΔV²_i × C_i    [V² × F = J] → 微分能量（系统的储能变化）
ν   = Σ I²_j × R_j    [A² × Ω = W] → 耗散功率（系统的即时功耗）
ds²/ν                   [J/W = s]  → 热力学时间
```

> **ds²/ν 的物理意义**：它不是钟表时间，而是"以当前耗散速率，系统的储能能维持多久"。小鼠代谢快 → ds²/ν 小 → 生物时间快。大象代谢慢 → ds²/ν 大 → 生物时间慢。**REF: Kleiber's Law (1932): P ∝ M^{3/4}**

### 4.5 五层理念映射

| 项目理念 | ds²/ν 语言 | 具体对应 |
|---------|-----------|---------|
| MOSFET 阈值 | 度规的退化边界 | V<V_th → det(g)=0 → 该方向不可测量 |
| STDP/BCM | 度规更新规则 | 共变增加度规接近度 |
| Xin | 测地线偏离 | P = 沿度规的测地线外推；Xin = 偏离度量 |
| 环流 μ | 度规空间中的体积流 | μ = Σ flow → ρ → ν = dρ/dt |
| 绑定层 | 非对角度规分量 | 条件完备性（vest&therm → 因果绑定） |
| PNN 成熟 | 度规冻结 | 流体→固体相变（Fruit ripe = 结构固化） |

### 4.6 核心问题：ds²/ν/κ 全部计算但无人读取

```
ds² → _compute_ds2() → 只用于 audit() 的 diagnostic 输出 → 从未被任何行为模块读取
ν   → _nu → 只用于 audit() 的 diagnostic 输出 → 从未驱动 DA 或行为
κ   → _kappa_ema → 只用于 remodel_cost_kappa（影子层内部剪枝）→ 从未输出到主系统
```

影子层是一个"高完成度的独立子系统，但完全断连"（system_narrative 2026-05-31:228）。它计算了时空测度但没有任何下游消费者。

## 五、三个时间生成机制

> 来源：[[2026-05/analysis_timespace_circulation.2026.5.29]]

大脑没有石英振荡器。它用三种互相耦合的机制**制造**时间感：

### 机制 A：节律振荡器（时间的"经纱"）

海马 theta 节律（4-8 Hz）由抑制性中间神经元网络的互抑制自发产生。

**项目对应**：CPG / VitalOscillator（f≈2Hz）。已有基础，但 CPG 当前用 `math.sin(phi)` 而非振荡电路（HC-025）。

### 机制 B：渐变信号（时间的"沙漏"）

前额叶 ramping neurons 从事件发生时线性递增，到达阈值触发动作后重置。

**项目对应**：Capacitor 充电 V(t)=V₀(1−e^{-t/τ}) 近似线性增长。但当前没有独立的"时间积分器"神经元——Capacitor 只用于信号滤波，不是用于编码时间流逝本身。

### 机制 C：序列编码（时间的"珠链"）

海马 time cells 按序列激活——序列顺序 = 时间表征。通过 STDP + 抑制性竞争自发涌现。

**项目对应**：增益链 Met→HC→Aff→Enc→Col→Mot 已经是序列。但编码的是信号传播顺序，不是时间——因为它没有**循环连接**（Mot→Met 或 Col→Enc 的反馈）来让序列"重复"。

## 六、空间生成机制

### 机制 A：网格细胞（连续吸引子网络）

内嗅皮层 grid cells 的六角晶格放电模式不是从外部地图读取的——是通过**连续吸引子网络**自发生成的。其中速度信号推动活动包移动，网络在循环连接 W 中维持位置。

**项目状态**：有速度信号（body.velocity），但没有"活动包"网络来积分它。SpatialNavigator 是为此预留的占位符，但 `update()` 是空的。

### 机制 B：头方向细胞（角速度积分）

$$\theta_{head}(t) = \theta_0 + \int_0^t \omega(\tau) d\tau$$

**项目状态**：前庭系统有 yaw/pitch/roll 输入，但没有积分器维持方向状态。输入直接驱动信号后即消散，不留下持久的方向表征。

## 七、时空互为 P/R

> 来源：[[2026-05/analysis_timespace_circulation.2026.5.29]] §3

### 7.1 Theta 序列的启发

在一个 theta 周期（~125ms）内，位置细胞按**空间顺序**激活，但它们的激活**时间**（theta 相位）编码了当前位置在序列中的位置（phase precession）：

$$
\phi_i(t) = \phi_0 - 2\pi f_\theta \cdot \frac{x(t) - x_i}{\Delta x_i}
$$

位置 x 的变化导致相位 φ 的前进：**空间运动驱动时间演化**。

### 7.2 互为 P/R 的数学表达

**当运动时**（主体在空间中移动）：
- P 环流 = 空间路径（位置细胞序列：A→B→C→D）
- R 环流 = 时间节律（theta 相位）
- Xin = 到达位置 C 的时间与预期不符

**当等待时**（主体静止）：
- P 环流 = 时间流逝（ramping neuron 的递增）
- R 环流 = 空间稳定（位置细胞持续放电）
- Xin = 等待时间超出预期

$$P \leftrightarrow R \text{ 的切换条件：} \frac{\partial |\xi_{space}|}{\partial t} > \frac{\partial |\xi_{time}|}{\partial t}$$

当空间预测误差变化更快时，空间 = P（注意力聚焦在"我在哪"）；当时间预测误差变化更快时，时间 = P（注意力聚焦在"现在几点"）。

### 7.3 时空互相预测，Xin 是轨迹超预期

> 来自用户直觉（2026-05-29）：
> "时间空间彼此互为 P/R？Xin 是信息所表现轨迹的超预期"

- 如果时间和空间可以互相预测对方，则一个的预测残差就是另一个的输入
- 时空不匹配 = Xin（信息轨迹的意外程度）
- 在熵账本上，时空可能表现出不同的偏导

## 八、组件逐项审计

### 8.1 TemporalCoupler — 时间尺度桥接器

**文件**：`components/temporal_coupler.py`（218 行），TYPE:SEMI。

**三层结构**：

| 层 | 机制 | 时间尺度 | 生物对应 |
|----|------|---------|---------|
| **Base** | Capacitor 积分 + leak（R 由 B 调制） | τ_base = C×R_eff | 树突膜 RC |
| **C-layer**（快） | MOSFET 读取下游 ema → 增加 leak（逆行信使反馈） | 每步 | 内源性大麻素/NO |
| **B-layer**（慢） | 差分 MOSFET 比较器（ema_up vs ema_down）→ 慢 Cap 积分 → 调制 R_leak | ~1000 步 | Turrigiano 2008 突触缩放 |

**C-layer 吸引子**：Vm_down → adapt_vth（半饱和）—— 下游过饱和时自动增加 leak，欠驱动时自动减少 leak。

**B-layer 吸引子**：ema_up ≈ ema_down —— 上游和下游激活平衡。

**关键参数**：（工厂配置，不是硬编码——通过 BundleConfig 传入，不同 Bundle 可不同）：
```
capacitance=1.0, r_leak=2.0, v_clamp=2.0
adapt_vth=0.0, adapt_gm=0.0  (C-layer 默认关闭)
blayer_c_slow=0.0             (B-layer 默认关闭)
```

**HC 状态**：

| HC | 严重度 | 问题 |
|----|--------|------|
| HC-015 | HIGH | `vestibular/chain.py` 用 if/else dispatch 而非 `bundle.apply_to_targets()`，绕过 TemporalCoupler 触发 |

**已知 bug**：审计 v1.0 发现 **B-layer 电压 = 0.0**（未生效）。C-layer 在工作，但长时间基线追踪功能从未实际运行。这意味着 coupler 只有快适应，没有慢适应——τ_base 不会根据长期活动平衡自动漂移。

### 8.2 TemporalBindingLayer — 因果不对称绑定

**文件**：`components/binding_temporal.py`（135 行），TYPE:BIO。

**设计**：BindingCell 的增强版。前庭轴通过 leaky integrator（τ_w=30 步，对应 30ms STF 时间窗）做时间卷积；热觉轴瞬时通过。结果：

```
"vest(前庭) 动了之后 therm(热) 变了" → BindingCell 激活强（因果符合）
"therm 变了之后 vest 动了" → BindingCell 激活弱（因果反向被抑制）
```

**生物对应**：突触前 Ca²⁺ 残留驱动的短时程易化（STF）。**REF: Zucker & Regehr 2002, Annu Rev Physiol 64:355-405**。

**参数**：`tau_w=30`（30 步 = 30ms at dt=0.001），`co_activation_threshold=0.0`（学习窗口全开，因为时间卷积的信号衰减到 ~0.632× 峰值，不需要额外的阈值过滤）。

**状态**：✅ 完整实现，Phase 4 随补丁 B 引入。时间卷积衰减因子：`decay = exp(-1/30) ≈ 0.967`，`update = 0.033`。每步保留 96.7% 旧值 + 3.3% 新值。

### 8.5 对称性与 Noether 守恒

> 来源：[[2026-05/analysis_spacetime_circulation.2026.5.18]]

赫布超图是一个**驱动耗散系统**，不是封闭系统。在驱动和耗散平衡时，达到**近似稳态**，展现**近似对称性**：

```
近似时间平移对称性:
  circulation period ≈ 常数（但不严格）
  → 近似守恒量: E_circuit ≈ 常数
  → "守恒"是幻觉：随 hunger 周期性波动

近似空间平移对称性:
  encoding 层 z_t 神经元大致等价（但不完全等价）
  → 近似守恒量: 环流电流 J ≈ 常数
  → "守恒"是幻觉：随 STDP 学习缓慢漂移
```

**对称性破缺 = 学习**：
- encoding 层所有 bundle 初始权重相同（初始对称性）
- STDP 逐渐打破它 → 权重分化
- 破缺方向由物质决定（介质的传播特性），不是抽象的"选择规则"

**物质赋予的近似对称性**（用户直觉验证）：
- CPG 周期近似守恒 → 因为两个神经元的离子通道有相似时间常数
- encoding 层初始对称 → 因为所有 bundle 初始权重相同
- 物质的物理属性赋予了初始对称性，STDP 逐渐打破它

### 阶段 3：时空耦合（P/R 互换）

## 十、驻波垫支（孤岛 B4）

> 来源：[[00_Dashboard/孤岛-B组-部分失联]] B4

"时间测度、空间测度、运动势都可以被系统结构垫支。垫支的实现形式就是结构，而垫支的内容由占据结构中信号轨迹的驻波来完成。"

**含义**：影子层的结构**本身**就是一个预先铺设好的"轨道"，外部信息通过这些轨道时形成驻波（稳定振荡），驻波节点 = 信息位。

**四个维度**：
1. 拓扑维度 (T) — 突触连接的权重结构
2. 能量维度 (E) — 电压 + 电流 + 功耗分布
3. 时间维度 (τ) — 信号传输延迟 + 处理时间
4. 信息维度 (I) — Xin 张力 + 果实状态

四个维度的张量积 = 影子层的"空间"。

**与 TemporalCoupler 的驻波条件**（来自 `analysis_adaptive_coupler_math` §4.3）：

```
前端频率 f₁ ←→ [coupler τ] ←→ 后端频率 f₂
驻波条件: f₁ / f₂ = 整数比 (m/n)
```

当 coupler 的 τ 恰好让两端功率传输最大化时（阻抗匹配），驻波最稳定。已有结构对应：`bundle.py C4 ZCR`（零交叉率驻波引导修剪）。

## 十三、核心结论

### 13.1 一句话

> **时空耦合是本项目认识论的核心——"自身=标尺，时空从结构中生成"。ds²/ν/κ 的理论框架完整、代码已计算、生物对应清晰，但所有组件要么断连（无人读取 ds²/ν）、要么空壳（SpatialNavigator）、要么软失效（B-layer=0）、要么被绕过（HC-015）。概念层丰富，物理层贫瘠。**

### 13.2 三个层次的不匹配

| 层次 | 状态 | 代表 |
|------|------|------|
| **概念层** | 丰富完整 | 内生时空认识论、ds² 度规框架、时空 P/R 互换、驻波垫支、因果不对称绑定 |
| **数学层** | 部分形式化 | ds² 公式、ν=dK/dt、热力学量纲、勒让德变换、驻波条件 |
| **代码层** | 破碎断连 | 三个组件计算但无人读、两个组件是空壳、一个组件 B-layer 失效 |

### 13.3 V1→V2.0 的桥接

时空耦合不需要完全推倒重来。大部分概念和框架可以直接迁移，最小 P0/P1 修复即可让框架首次闭合：

1. **修复 B-layer** → 时间尺度分离生效 → coupler 能做慢适应
2. **接线 ds²/ν** → 影子层时空测度被行为模块消费 → 闭环首次形成
3. **填充 SpatialNavigator** → 内部空间表征 → "我在哪"不再是外部读取

这三个修复完成后，ds²/ν 框架将从一个"计算但无人读"的诊断工具升级为驱动行为的学习框架——从二阶涌现进入一阶驱动。
