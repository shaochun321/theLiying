# 分支、漂移与讨论代际

## 1. 本聊天不是单一收敛线

理论轨后期更倾向用户理念，受上下文限制又反复重谈相同对象。因此应同时保存“方向变强”和“定义仍竞争”：重复出现说明对象重要，不等于某版本已经胜出。

## 2. 可见讨论代际

### A：2026-07-20 较具体约定

- 自然化在输出端；
- 耦合先形成组织候选；
- 自身闭合和输出后才增加深度；
- 比例/时序关系不自动成为生成元；
- 组织不自动成为结构算子；
- P/R 不是固定层；
- 旋转在组织形成后；
- 极限环不是统一出生机制；
- 旧代码 Xin 不等于理论 Xin。

### B：2026-07-28 v0.6 方法整理

它是方法论整理，不能覆盖 7 月 20 日更具体约定。其自身仍承认时间、空间、信息形式、事件等价、提升映射以及 Xin、运动势、完整 TOPRXin 等未完成。

### C：2026-08-02 候选定理探索

先提出五层体系，后依据工程报告把优先级移到谱系—区间实例不增殖。这是从宏观架构向经验定理核的研究策略修正。

## 3. 已识别漂移

| 漂移 | 恢复 |
|---|---|
| 把定值解释成校准或版本机制 | 回用户原定义 |
| 自然化成为独立层 | 恢复输出端 |
| 关系表示自动升格 | 增加闭合与接口资格 |
| 组织形成即结构算子 | 增加未来可达性 |
| P/R 成固定层 | 恢复转换网格定位 |
| 旋转成出生机制 | 恢复后置位置 |
| 旧代码 Xin 定义理论 Xin | 隔离语义 |
| 极限环成为统一机制 | 降回活动模态 |
| 直接建立 TOPRXin 基本定理 | 先审计和最低物理公约 |

## 4. 暂停创制

原典未恢复前，不新建基础元定义、深度编号、统一生成链、Xin/P/R/运动势解释或统一算法；也不让宏大理论词覆盖缺失物理接口。

## 5. 保留但不升级

| 分支 | 保留价值 | 禁止宣称 |
|---|---|---|
| 五层候选定理 | 组织研究空间 | 已证明体系 |
| 后验再作用 | 核心候选 | 已解释全部后验 |
| 谱系—区间不增殖 | 经验定理核 | 已原创或已证明 |
| 窗口边界 | 可形式化 | 普适启动律 |
| 时序辨识 | 局部实验支撑 | 所有信息在过程 |
| 外部坐标不足 | 内部空间约束 | 外部几何无意义 |
| 观察/DA 分离 | 架构原则 | DA 永不影响未来 |

## 6. 保存分歧

$$
\text{版本 A}
\quad\Vert\quad
\text{版本 B}
\xrightarrow{\text{原典与资格审计}}
\text{保留/扩展/撤销/待裁定}.
$$

不以折中措辞抹除真实分歧，也不让方案轨的工程裁定反向删除理论轨曾探索的可能性。
