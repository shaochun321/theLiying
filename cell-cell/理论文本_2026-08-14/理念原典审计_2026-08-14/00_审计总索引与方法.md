# 理念原典审计：总索引与方法

> 审计对象：共享聊天《Toward a Physical Theory》及本聊天用户补充  
> 审计日期：2026-08-14  
> 性质：原典恢复与版本判读，不是新的理论综合

## 1. 审计目的

本卷回答：

1. 哪些表述来自用户直接提出或修正？
2. 哪些是聊天中引用的早期项目文档约定？
3. 哪些是助手依据报告提出的候选形式？
4. 同一术语反复讨论时，哪些是扩展、漂移或仍待裁定？

## 2. 双轨前提

$$
\boxed{
\text{理论探索轨}
\parallel
\text{方案收敛轨}}
$$

- 理论探索轨后期不断向用户理念倾斜，允许反复讨论与候选竞争；
- 方案收敛轨负责产出方案，用户有意减少天马行空内容，因而相对严谨；
- 日期更晚、篇幅更长、重复更多，都不自动产生覆盖权；
- 理念被明确移交并通过方案研判后，才取得收敛轨资格。

## 3. 证据层级

### E0：用户直接原话或本轮修正

最高优先，包括共享聊天用户发言及本聊天对“双轨并行”的说明。

### E1：聊天明确引用的用户已确认文档

例如共享页引用的 2026-07-20 文档。它们是二手可追溯证据：可恢复其被引用结论，不能假装看到分享页之外的完整原文。

### E2：已执行工程报告与事实

能支持或反驳候选命题，但不能自行定义用户理念。

### E3：助手整理、解释与候选公式

可作为研究分支；未被用户明确接受前，不升级为原典定义。

## 4. 文本忠实度

| 标记 | 含义 |
|---|---|
| [原句] | 共享页中连续可读的直接文本 |
| [引文转述] | 聊天声称来自早期文档的转述 |
| [规范化转写] | 网页公式拆行后按可确认关系恢复 |
| [解释] | 对原句的最小语义说明 |
| [候选重建] | 为审查提出，非原典 |
| [缺文] | 分享页无法恢复 |

## 5. 确认强度

| 等级 | 意义 |
|---|---|
| F3 冻结边界 | 用户明确修正/排除，或较早确认且后文保护 |
| F2 稳定内核 | 多处一致，但完整数学仍缺 |
| F1 方向偏好 | 用户明确期待，尚未定义 |
| C 候选 | 助手提出或报告导出的命题 |
| U 未决 | 多版本竞争或缺少原典 |

## 7. 边界

本审计不能恢复分享链接未包含的逐轮原文，也不能凭助手曾说“过去明确写过”补出缺失定义。审计结论分成“可确认内核”和“待原典”，不以流畅性掩盖空白。
